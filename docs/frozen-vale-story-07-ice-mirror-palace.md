## 1. 역할과 진입

지역ID FV-07, 권장Lv19~20. 직전 스토리 FV-06 완료가 서사 선행이다. 레벨은 안내값이며 XP 곡선과 함께 검증한다. 장소·대사·적 수·장치 수·보상은 초안이다.

마지막 기억은 여왕이 왕좌의 연료 징발과 추가 전쟁을 막으려 자기 백성과 함께 얼어붙는 길을 택한 장면이다. 그녀는 기록을 풀면 왕이 다시 깨어날까 두려워한다. 플레이어는 여왕을 죽여 핵을 빼앗는 대신 세 거울에 징발·저항·희생의 기억을 복원해 봉인 명령과 대립을 끝낸다. 두 번째 봉인핵은 여왕의 동의와 대체 안정화 뒤 회수한다.

보스 공터136×128stud. HP100~70%에 냉기 부채꼴/거울1,70~35%에 얼음 선 공격/거울2,35% 아래에 복합 예고/거울3을 둔다. 각 보호막은 기본 전투로 약화하고 공통 상호작용으로 해당 거울을 복원한다. 세 번째 기억 복원과 보호막 해제 뒤 여왕은 전투를 멈추며 HP0 사망 연출/처치 목표를 쓰지 않는다. 거울 복원 중 안정화 창을 제공해 솔로도 처리하고 전투 안에서 긴 대사를 읽게 하지 않는다.

입구 A는 안전 스타트 포인트 `FV-07-SP`다. 첫 시작/처음부터는 A, 이어하기는 유효 체크포인트, 리조인은 같은 실행의 안전 합류 지점을 쓴다. 적 스폰·추격·광역 공격과 분리한다.

## 4. 사건과 성공 조건

| 단계 | 행동 | 결과 |
| --- | --- | --- |
| 1 | 외곽 경비 돌파·마지막 기억 조각 확인 | 기억 증거3와 보스 전 체크포인트 |
| 2 | 여왕의 보호막 약화·거울3개 순차 복원 | 비살상 대면 승리 확정 |
| 3 | 여왕과 봉인 안정화·핵/기록 확인 | 교역로 재개·안전 귀환 |
| 4 | 피난처/왕도 개인 보고 | 공개 선택·스토리7/에픽2 완료·다음 원정 해금 |

위 필수 목표와 완료 지점/보고를 충족해야 성공한다. 선택 탐험·완벽 방어·특정 동료·속성·궁극기·Lv20 전직은 요구하지 않는다. 특정 몬스터 전멸 자체가 필수인지 여부는 위 목표의 위협 해제 범위로 한정한다.

공개할 단서: 기억3: 여왕의 동결 선택. 루칸은 무분별한 공개의 위험을 경고하고 세렌은 왕도 명령에 의문. 왕좌 중심 의식의 현재 생존은 제3장 발견으로 남김. 대사 초안: “기억을 풀어 주는 것과, 같은 희생을 되풀이하는 것은 달라요.”

## 5. 체크포인트·실패·보상

외곽 기록/증거3는 유지한다. 전멸 시 여왕HP·거울3개 전투 상태·효과는 초기화하며 증거 수집을 반복하지 않는다. 비살상 승리를 별도 확정하고 이후 끊기면 기록/핵/귀환/개인 보고만 이어간다. 핵 회수는 지역 봉인을 붕괴시키지 않는 안정화 연출 뒤 이뤄진다.

처음부터 재플레이는 새 실행으로 시작하며 영구 완료·장비·레벨·개인 선택·초회 보상 기록을 지우지 않는다. 같은 파티의 진행을 혼자 초기화하지 않는다. 동일 실행이 사라진 재접속은 개인 확정 목표로 새 실행을 복구하고, 진행 중 교전 HP/효과는 복원하지 않는다.

첫 완료 Coins900·퀘스트XP450·두 번째 봉인핵1개/희생 기록·개인 공개 선택·다음 에픽을 초안으로 둔다. 재플레이 퀘스트 보상은 Coins270·첫 퀘스트XP25%를 시험한다. 초회 장비/기록/핵/선택은 반복 지급하지 않는다. 일반 전투XP/전리품은 별도이며 반영된 고정 퀘스트XP를 수령자 레벨로 다시 환산하지 않는다.

Queen Ice Elf 보상은 **비살상 대면 완료**를 기준으로 별도 영수증을 남긴다. 살해·시체 약탈이나 여왕 모델 교체를 요구하지 않는다. 반복 전투는 기억 재현이며 여왕을 다시 적으로 만드는 정사를 저장하지 않는다. 개인 공개 선택의 두 방향은 필수 성능 보상/다음 에픽에서 동등하다.

## 6. 협동·공유 자산·검증

1~4인, 파티 전체 전투AI 상한은 인간1/2/3/4명에2/2/1/0명이다. NPC 대화 인물을 이유로 4인에 추가 전투AI를 붙이지 않는다. 회복·보호·상호작용도 참여로 인정한다. 자격 있는 현장 참여자의 공통 목표만 공유하고 미완료 선행·초회·개인 선택은 호스트 진행으로 덮어쓰지 않는다. 모든 장치는 솔로 순차 처리 가능하다.

TD 설원 맵의 석조 성벽/다리·설송·청회색 절벽·빙하·보라 포탈, 해당 몬스터 원본과 공통 목표/지도/결과 메뉴를 공유한다. 원본을 새 외형으로 재생성하지 않는다. 익명 주민/기록 소품은 기존 NPC/환경 키트 활용을 우선 조사한다. 신규 소품이 필요하면 원본 부족분만 제작한다.

검증: 네 클래스/동료0/전직0/궁극기 미사용 비살상 완주, 보스 후 재접속, 개인 공개 선택과 초회 보상 분리. 공통으로 네 클래스 솔로·동료0명,1/2/4인, 체크포인트·재시작·리조인·보상 중복을 확인한다. 현재는 문서이며 실제 맵/전투 테스트 결과가 아니다.

## 리뷰 보충 · 반복 실행 완료와 일회성 후일담

첫 진행은 위의 핵/기록·개인 선택/보고까지 마쳐야 에픽 완료다. 이미 에픽을 끝낸 사람의 재플레이는 새 실행의 필수 외곽 목표와 보스 승리로 반복 퀘스트 보상 자격을 확정하고, 최초 결말/후일담을 다시 선택하도록 요구하지 않는다. 과거 사건의 기록 연출은 건너뛰거나 다시 볼 수 있다. 실행ID와 개인 수령 기록으로 같은 실행의 재접속/중복 요청을 구분해1회만 지급한다. 영구 완료 플래그만으로 새 실행의 보스를 건너뛰어 반복 보상을 받게 하지 않는다. 처치/전투 승리 전리품과 반복 퀘스트 보상은 별도 기록이다.
