# 마법 학파·속성 분류와 단계별 학습

버전0.24 · 2026-10-27 · [전직·스킬트리](class-advancement-and-skill-trees.md) · [게임 기획](game-design.md)

## 1. 전직과 마법 학습의 구분

사용자가 제안한 성장 순서는 **초반 비전/바람 기초+간단한 물 마법 → Lv20 Pyro/Cryo 전직 → Lv40 Pyro는 대지, Cryo는 번개 학습 → Lv60 대규모 광역 마법 → Lv80 최강 마법**이다. 같은 마법사 클래스 안에서 두 전직 경로를 유지하며 단계마다 새로운 조작과 전술을 배운다.

비전술사/바람술사는 Lv1~19의 입문 호칭·훈련 방식으로 표현한다. 내부 원형 클래스는 동일한 Mage이며, 입문 훈련과 무관하게20레벨에 Pyro 또는 Cryo를 선택할 수 있다. 기본 주문 Mana Bolt·Water Ball·Gravity는 공용으로 익히고, 이를 화염/빙결 이후에도 활용한다. 초반 훈련 선택이 영구적인 제3·제4 전직 계열이 되지는 않는다.

바람·기초 물·비전은 공용, 대지는 Lv40 Pyro 경로, 번개는 Lv40 Cryo 경로다. 선택 경로의 고급 주문·궁극기·각성은 해당 전직 자격을 요구하며, NPC 성녀의 지원 기술·엘프의 고유 기술을 가져오는 방식으로 구현하지 않는다.

| 성장 단계 | Pyro 경로 | Cryo 경로 | 플레이 변화 |
| --- | --- | --- | --- |
| Lv1~19 | 비전/바람 입문+기초 물 마법 | 같은 공통 입문 과정 | 조준·거리 확보·젖음과 환경 반응 |
| Lv20 1차 | Pyromancer 화염술사 | Cryomancer 냉기술사 | 주력 원소와 전직 방향 선택 |
| Lv40 2차 | 대지 마법 추가 | 번개 마법 추가 | 화염+대지, 빙결+번개의 두 원소 조합 |
| Lv60 3차 | 용암 분출 같은 대규모 광역 | 빙뢰 폭풍 같은 대규모 광역 | 배운 두 원소로 전장을 설계 |
| Lv80 4차·각성 | 화산의 심판 같은 최강 주문 | 영원의 빙뢰 같은 최강 주문 | 계열을 완성하는 궁극기 |

대지와 화염의 결합은 용암/분출, 물·빙결·번개의 결합은 젖음/서리 표식과 연쇄 타격으로 게임 내 규칙을 설계한다. 특정 조합이 유일한 정답이나 무한 제어가 되지 않도록 적용 조건·상한·보스 반응을 정한다. 고급 주문명은 제작용 가칭이다.

## 2. 학파 → 속성 → 기술 형태

마법을 세 가지 축으로 분류한다. 학파는 힘의 근원, 속성은 전투 성질, 기술 형태는 시전 방식이다. ‘결계’와 ‘화염’을 같은 층에 섞지 않는다. 화염 결계는 원소 학파·화염 속성·결계 형태로 표현할 수 있다.

| 학파 | 속성 | 핵심 성질 | 현재 기획에서의 위치 |
| --- | --- | --- | --- |
| 원소 | 화염 | 화상·연소·폭발 | Lv20 Pyro의 주력 속성 |
| 원소 | 빙결 | 둔화·서리·빙쇄 | Lv20 Cryo의 주력 속성 |
| 원소 | 번개 | 순간 타격·연쇄·짧은 감전 반응 | Lv40 Cryo의 추가 속성 |
| 원소 | 바람 | 밀치기·거리 확보·경로 조절 | 초반 입문·양쪽 공용 기초 |
| 원소 | 대지 | 지면 융기·엄폐·충격·진로 제어 | Lv40 Pyro의 추가 속성. UI는 ‘대지(땅)’ 표기 |
| 원소 | 물 | 물방울·젖음·주변 환경과 연계 | 초반의 간단한 공용 주문 |
| 원소 | 금속 | 금속 투사체·방호·자기적 상호작용 | 후속 확장 후보, 드워프 무기 기술과 구분 |
| 비전 | 마력 | 원소에 의존하지 않는 마력탄·마력창 | 초반 비전 입문의 기반 |
| 비전 | 공간 | 점멸·짧은 위치 이동·공간 표식 | 후속 추가 학습 후보 |
| 비전 | 중력 | 끌어당김·무게·낙하/압박 | 후속 확장 후보 |
| 비전 | 시간 | 제한적인 지연·가속·시전 순서 | 후속 확장 후보. 세계/서버 전체 시간 정지로 구현하지 않음 |
| 비전 | 환영 | 미끼·위장·시야/표적 판단 유도 | 후속 확장 후보 |

추가 속성은 기존 원소의 색만 바꾸지 않는다. 고유한 전투 판단·환경 반응·적 대응·시각/음향 식별이 있어야 한다. 표의 확장 후보는 이번 기본 제작 분량에 전부 포함한 약속이 아니다.

| 기술 형태 | 예시 | 주된 판단 |
| --- | --- | --- |
| 투사체·직선 타격 | 화염탄·번개창 | 방향·거리·대상 선택 |
| 광역·장판 | 눈보라·화염 지대 | 적의 이동과 시전 위치 |
| 결계·방벽 | 마력 장벽·돌기둥 | 예고를 읽고 보호/엄폐 위치 선택 |
| 제어 | 돌풍·중력장 | 적 진로·자세·위험 시전 관리 |
| 이동 | 점멸·공간 표식 | 위험 회피와 공격 위치 확보 |
| 부여·봉인 | 마력 부여·봉인 인장 | 조건·유지 시간·해제 순서 |

소환은 별도 AI·활성 수·경로·성능 검증이 필요한 후속 기술 형태다. 기술 분류표에 있다는 이유로 모든 속성×형태의 조합을 제작하지 않는다.

## 3. 기술 해금과 제작 예산

공통3개+Pyro3개+Cryo3개의 마법사 액티브9개 안에서 구성을 다시 설계한다. 전체4클래스의 기본 액티브 예산은 **36개**, 궁극기는 **12개**다. NPC 성녀의 지원 기술/AI는 별도 제작량이다. 최종 주문 이름·세부 계수는 초안이며 새 속성과 주문을 더 도입하면 제작량을 다시 산정한다.

| 구분·해금 | 기술 가칭 | 역할 |
| --- | --- | --- |
| 공통·Lv1/5/10 순차 | Mana Bolt / Water Ball / Gravity | 비전 투사체·기초 물·중력 제어. 실제 학습 순서와 해금은 미구현 |
| Pyro·Lv20 | 불씨창 | 화염 주력 공격·화상 시작 |
| Pyro·Lv40 | 대지융기 | 지면/엄폐/진로를 읽고 불씨와 연결 |
| Pyro·Lv60 | 용암분출 | 화염+대지의 대규모 광역 공격 |
| Cryo·Lv20 | 서리창 | 빙결 주력 공격·서리 누적 |
| Cryo·Lv40 | 연쇄번개 | 젖음/서리 표식과 번개 연결, 연쇄 수·거리에 상한 |
| Cryo·Lv60 | 빙뢰폭풍 | 빙결+번개의 대규모 광역 공격 |
| 공통 궁극기·Lv15 | 마력집중 | 짧은 마력 운용/다음 주문 보조. 최강 주문은80레벨에 별도 해금 |
| Pyro 궁극기·Lv80 | 화산의 심판 | 화염/대지 조합을 완성하는 최강 주문 |
| Cryo 궁극기·Lv80 | 영원의 빙뢰 | 빙결/번개 조합을 완성하는 최강 주문 |

공통3+현재 전직3의 최대6개 후보 중 기본 최대3개, Lv20/40/60 전직 완료 후 각각 최대4/5/6개를 장착한다. 슬롯 개방은 기술 자동 습득을 뜻하지 않는다. Lv80에 해당 계열 최강 궁극기 주문을 선택할 수 있으며 궁극기 독립 슬롯 여부는 미정이다. 원형 기본 공격·마력 장벽·회피는 액티브 슬롯과 별개다. 입문 훈련에 따라 순서를 바꾸더라도10레벨까지 공통3개를 모두 익히며 추가 포인트를 지급하지 않는다.

편성 예시는 불씨창+대지융기+Gravity, 서리창+연쇄번개+Water Ball이다. Lv60에는 주력 광역 주문을 넣기 위해 기존 기술 하나를 바꾸는 선택이 생긴다. ‘60레벨 광역’은 전장의 넓은 구역을 다루는 대표 고급 주문을 뜻한다. 초반의 작은 범위 타격까지 전부 금지하는 규칙은 아니다. 80레벨 최강 주문은 긴 준비·예고·마력/궁극기 자원으로 균형을 맞추고 일반 기술을 무의미하게 만들지 않는다.

## 4. 학습과 스킬트리

마법은 레벨·전직 자격과 교관의 짧은 실습/서약 시험으로 배운다.20레벨에는 주력 원소,40레벨에는 추가 원소,60레벨에는 두 원소의 광역 응용,80레벨에는 최강 주문을 시험한다. 필수 스토리를 희귀 무작위 마법서나 구매로 잠그지 않는다. 전직 전 공통 주문은 두 경로가 계속 사용하며, 계열 재선택으로 학습 기록이 사라지거나 복제되지 않는다.

**기술은 학습 완료로 해금하고 스킬트리는 운용을 보강**한다. 개인79포인트·플레이어 전체216노드 기준안을 따른다. T/V/M층의 기술 보강 노드는 해당 주문을 실제로 배운 뒤 투자 가능하다. 마법사 T2/V2는40레벨 추가 원소, T3/V3는60레벨 광역 주문 해금을 기다리며, 노드 층이 열렸다는 이유로 기술까지 조기 해금하지 않는다. A층의 계열 궁극기는80레벨 각성을 요구한다.

학파별 심화 트리·추가 주문·전용 숙련을 도입할 때에는 노드 수·포인트·레벨별 해금·전문화 차이를 별도로 설계한다. 아직 정하지 않은 학습 레벨이나 전용 트리가 완성된 것처럼 표시하지 않는다.

## 5. TD 자산과 세계 인물 활용

Arcanist·Zephyrmancer는 초반 비전/바람 교관, Pyromancer·Cryomancer는20레벨 전직 교관, Geomancer는40레벨 Pyro의 대지 교관, Voltmancer는40레벨 Cryo의 번개 교관 후보로 둔다. 물 마법 교관·소품·시전 모션은 적합한 기존 자산이 없다면 신규 제작한다. 같은 타워의 메시·장비·VFX는 플레이어 기술에도 부분 활용할 수 있다.

교관의 타워명과 플레이어 전직명은 일치할 필요가 없다. 플레이어에게 필요한 시전 모션·조준·피격 판정·효과는 RPG 기준으로 새로 만들거나 변형한다. 기존 타워의 자동 공격 코드를 그대로 플레이어 기술로 취급하지 않는다.

## 6. 저장·UI·검증

주문마다 `spellId`, 학파, 속성 태그, 기술 형태, 공용/전직 고유 구분, 학습 조건, 적용 가능한 노드 태그를 둔다. 추가 학습 기록은 RPG 캐릭터의 `learnedSpells`에, 전직 자격은 기존 계열/시험 기록에 관리한다. 공통 Diamonds 지갑이나 TD 타워 해금이 주문 학습을 자동 완료하지 않는다.

서버는 마법사 클래스·학습 완료·레벨/임무 조건·현재 전직 자격·마력/쿨다운·장착3개 한도를 검증한다. Mana Bolt/Water Ball/Gravity는 공통 자격, 대지는40레벨 Pyro, 번개는40레벨 Cryo, 주력 광역은60레벨 해당 경로, 최강 주문은80레벨 각성 자격을 요구한다. 다른 경로에서 과거에 배운 고유 주문도 현재 경로가 맞지 않으면 활성화하지 않는다.

마법서 UI는 학파→속성→주문 목록을 기본으로 하고 공격/방어/제어/이동 등의 형태로 필터링한다. `학습 가능`, `학습 완료`, `전직 고유`, `장착 중`을 구분한다. 캐릭터창의 전직 계보와 마법서 학습 목록을 별도 화면으로 읽을 수 있어야 한다.

필수 검증은 두 입문 방식에서20레벨 두 전직 모두 선택 가능, 공통 물/바람 유지, Lv19/20·39/40·59/60·79/80 경계, 추가 원소의 경로/레벨 제한, 기술보다 앞선 노드 투자 거부, 최강 주문 조기 사용 거부, 계열 재선택·저장/재접속,3슬롯 초과, 속성 강화 오적용, 연쇄/제어 상한, 대지융기 길막/잔류, 모바일 조준과 광역 이펙트 가독성이다. 이는 기획 기준이며 구현 검증 결과가 아니다.

이 단계별 학습 방향은 사용자 제안이며 주문명·학습 순서·계수는 제작 초안이다. [결정표](decisions.md)와 [변경 이력](CHANGELOG.md)을 함께 참조한다.
