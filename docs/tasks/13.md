# 10. 작업을 세분화할 때


큰 콘텐츠 티켓은 `TLT-061/DW-01/quest`처럼 부모ID와 지역/분야 부번을 연결한다. 부모를 쪼개도 기존 ID를 새 의미로 재사용하지 않는다. 각 하위 작업에 읽을 원천·영문 문자열 키·단일 편집 담당·예상 실제 제작 단위·실행/수용·미검증·증거 경로를 붙인다.

일정은 [계획의 산정법](../../plan.md)을 따른다. 추정치를 작업 완료나 예약된 인력으로 표시하지 않는다. 우선순위나 제공 범위를 바꿀 때 결정 사유·영향받는 의존/검증·실제 공개 안내를 함께 갱신한다.
