## 1. 역할·진입·이야기

HG-06, 권장Lv36~38. 직전 HG-05 완료가 서사 선행이다. 레벨·적 수·대사·보상·장치 수는 테스트 초안이다.

Death Knight는 왕릉 원본을 지키라는 명령을 반복한다. 플레이어는 두 통행 봉인을 풀고 수호대를 돌파한다. 쓰러진 수호자의 검에 원본 보관실로 이어지는 문양이 남아 있다. 기존 기록을 파괴하지 않았다는 사실이 마지막 방의 문을 연다.

입구 A는 `HG-06-SP` 안전 스타트다.40×32stud 유효 마당과4명/동료 개별 생성 슬롯을 시험한다. 적 추격/광역 공격에서 분리하고 실제 바닥/좌표/카메라는 블록아웃에서 확인한다.

## 4. 사건·성공·단서

필수: **통행 봉인2개·Death Knight 격파·문양/통행 기록·F 도착**. 현장 위협 해제/조사 → 다음 상호작용 활성 → 종점/보고 → 개인 스토리 완료 순서다. 선택 추모/유품/장비·특정 클래스/동료·완벽 방어·궁극기·Lv40전직은 필수가 아니다.

공개 단서: 왕릉에 사본이 아닌 원본이 있음. 아직 내용을 미리 공개하지 않음.

## 5. 체크포인트·재시작·보상

외곽 봉인과 보스 전 안전실을 저장한다. 전멸 시 HP/임시 맹세 표식만 초기화한다. 처치 확정 뒤 끊기면 통행 기록/F부터 이어가고 재처치를 강제하지 않는다.

첫 시작/처음부터는 SP, 이어하기는 유효 체크포인트, 리조인은 동일 실행의 안전 합류 지점이다. 보스 도중 접속은 안전실 대기 후 합류하고 입퇴장으로 HP를 재계산/회복하지 않는다. 서버/실행이 사라지면 개인 확정 목표로 새 실행을 복구하고 미완료 교전HP/임시 효과는 초기화한다. 처음부터는 새 실행이며 영구 레벨/장비/완료/선택/초회 수령을 지우지 않는다. 공동 실행을 혼자 초기화하지 않는다.

첫 완료 Coins1200·퀘스트XP975·왕릉 통행 기록·방어구1개가 초안이다. 재플레이 퀘스트 Coins360·첫 퀘스트XP25%를 시험한다. 증거/이름/안식/핵/초회 장비/개인 선택은 반복 지급하지 않는다. 처치XP/보스 전리품은 별도 영수증이며 묘지 전용 인장 종류/수량은 미정이다.

## 6. 협동·공유 자산·검증

인간1~4인/전투AI 상한2/2/1/0. 셀레네는 성녀NPC/선택 지원 동료이고 플레이어 클래스가 아니다. 미영입/미편성/성기사 없이도 장치/이름 복원은 공통 상호작용으로 가능하다. 모든 장치는 순차 조작하며 분기 위치를 동시에 밟지 않는다. 보호/회복/조사도 참여로 인정한다. 자격 있는 현장 참여자의 공통 목표만 공유하고 개인 선행/이름 기록/초회/선택은 호스트가 덮어쓰지 않는다.

TD 묘지 몬스터 원본·낮은 묘비/석관·앙상가지·폐예배당·석조 다리·보라 포탈과 공통 메뉴/지도/결과/아이콘을 공유한다. 베이르는 Lich Sovereign 원본의 같은 정체성을 유지한다. 기억/영혼 표현은 상태 표식/소품/VFX를 분리하고 새 몬스터 외형을 재생성하지 않는다.

검증: 네 클래스 솔로/동료0·전직/궁극기 미사용,1/2/4인, 모든SP 시작/이어하기/처음부터/리조인, 조사/장치/보스 뒤 종료, 증언NPC 오조준 방지·안개/카메라·보상 중복. 실제 플레이 검증은 아직 없다.
