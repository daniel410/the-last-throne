## 1. 역할·진입·이야기

en-US 가칭: **The Oath Before Dawn** · 유형: 메인 스토리/퀘스트 · 안전 시작: `FC-05-SP` · 선행: `FC-04` 개인 완료. 권장 `78→80 목표·안전 전직 안내`는 미검증 위치 목표이며 실제 입장 레벨 제한을 확정하지 않는다.

왕좌가 보이는 전실에서 지역 담당자들은 각자 자기 불빛을 시험한다. 플레이어는 다섯 역할의 신호를 하나씩 확인하고, 끊겼을 때 돌아갈 순서를 연습한다. 최종 작전은 이미 제7장에서 해 본 실패 복구를 다시 확인하는 것이지 갑자기 새로운 기적을 배우는 과정이 아니다.

안전 공간에서 미완료 전직 시험으로 돌아갈 통로와 성장 안내를 제공한다. Lv80이라도 최종 전직 전에는 궁극기가 열리지 않는다. 시험을 마치지 않거나 궁극기를 쓰지 않아도 본편 문은 열린다. 돌아가고 싶은 이유를 담은 짧은 연락 뒤 왕의 제안을 들으러 나아간다.

**완료 결과:** 최종 전투 전 안전 정비·Lv80 전직 안내와 재도전 동선을 확보한다. 레벨을 이벤트 보상으로 강제 설정하지 않는다.

위 세 국면의 필요한 확정이 완료돼야 다음 이야기로 진행한다. 각 국면 안의 실제 장치 수·적 수·세부 저장 필드는 구현 단계에서 정한다. 이야기 이유 없는 왕복 보고는 추가하지 않는다. 실패/전멸로 이미 확보한 개인 완료·기록을 지우지 않는다.

## 3. 동선·교전과 대응

`FC-05-SP 안전 전실 → 국면1 구역 → 국면2 구역 → 국면3 확인 → 안전 출구/다음SP`가 공간 흐름이다. 좌표·크기·Place 분할은 미정이다. 중력/위상 연출도 공통 충돌 바닥을 유지하고 전투 전에 경고를 읽을 여유를 둔다.

적대 교전은 없다. 대화·판단·기록으로 진행하며 훈련 표적/배경 경비를 보상용 처치로 세지 않는다.

선택 보스는 이 이야기의 완료 조건이 아니다. 비살상 인간 경비·정지할 장치·처치할 포탈 생물의 승리 유형을 분리하고 중립/항복 NPC를 재공격할 수 없게 한다. 필수 상호작용은 모든 클래스의 공통 조작으로 가능하다.

## 4. 체크포인트·재도전·협동

준비 확인과 전직 완료는 다른 기록이다. 전직 시험으로 이동해도 본편 단계/보상은 유지한다.

전멸은 가까운 안전 SP에서 무료 재시도한다. 미완료 교전의 HP/일시 소환/효과만 초기화하고 확정 목표는 보존한다. 전투 도중 복귀는 안전 전실에서 대기 후 안전 시점에 합류한다. 호스트 이탈/서버 소멸은 개인 확정 기록으로 새 실행을 구성한다. 재합류 유예 시간과 실제 구현 필드는 미정이다.

파티는 공통 전투/현장 목표를 자격 있는 참여자에게만 공유한다. 피해량/막타 경쟁 대신 보호·회복·상호작용도 참여로 인정한다. 개인 선택/초회 수령은 호스트가 덮어쓰지 않으며 대사 넘김이 다른 사람의 영구 진행을 바꾸지 않는다.1~4인·전투AI2/2/1/0,특정 동료 미편성도 통신/현지 기록으로 필수 이야기를 전달한다.
