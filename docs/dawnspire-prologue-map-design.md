## 1. 기존 왕도의 일부를 재사용

승인된 [Dawnspire 로비 원본](../assets/concepts/2026-10-27-shared-ui-v2/world/dawnspire-lobby-v1.png)의 청금/왕관·석조 성벽·분수 광장·훈련장·보라 포탈을 공유한다. TD 공통 모델/메뉴/아이콘은 기존 레지스트리를 우선하며 새 캐릭터 외형을 생성하지 않는다. 훈련장/거리/성문/원정 마당을 왕도 외곽의 작은 탐험권역으로 묶는다.

초기안은 RPG Place 안에서 파티 실행의 이벤트 구역/연출을 분리하는 것이다. 신규 이용자마다 공용 로비의 성벽/왕좌를 꺼뜨리거나 다른 사람의NPC/충돌을 바꾸지 않는다. 공용 Dawnspire와 프롤로그는 지형/자산을 공유하되 임무 적·파괴 연출·개인 진행은 실행 범위로 분리한다. 별도 Place 분리는 로딩/성능 검증 후 결정한다.

## 2. 축척과 배치

외곽 예산800×800stud. 북쪽=-Z/높이=Y,SVG x=X+400/y=Z+400,도면1단위=1stud다. 사각형은 구역 예산이고 내부 연결도는 축척이 없다. 전체를 평탄한 빈 지형으로 만들거나 최종 충돌 경계로 사용하는 그림이 아니다.

| 구간 | 중심 X/Y/Z | 예산 X×Z | 핵심 유효 공간 |
| --- | --- | --- | --- |
| DS-01 훈련장 | -210 / 0 / 150 | 160×150 | 첫 생성40×32·훈련 표적64×56 |
| DS-02 성장/서약 광장 | 0 / 4 / 90 | 170×160 | 대화/안내48×40·작은 의뢰 순환 |
| DS-03 주민 거리 | 210 / 0 / 120 | 180×180 | Goblin 공터64×56·주민 엄폐40×32 |
| DS-04 성문/원정 | 0 / 0 / -160 | 260×240 | 성문 순차 교전96×96·보고40×32·포탈대기40×32 |

주동선18~24stud/장식 뒤 유효16stud 이상,성문 공터의 회피 여유와 큰 몸체/카메라를 검증한다. 경사는12도 이하를 목표로 하고 필수 점프/추락·유료 이동을 요구하지 않는다. 높이는 중심 예산이며 SP 좌표는 지면/출구/카메라에 맞춰 블록아웃에서 정렬한다. 시간15~20분은 초기 목표이며 실제 측정 전이다.

## 3. 구역과 이동

훈련장→성장 광장→주민 거리→성문/보고는 도보로 연결한다. 사건 시작 전 짧은 안전 연출로 침공을 알리고 프롤로그 실행 안에서만 적을 생성한다. 주민은 적과 분리한 엄폐로 짧게 이동한다. 성문 위협을 해제한 뒤 안전한 원정 마당의 포탈로 Deepwood DW-01-SP에 도착한다. 레벨·XP·Coins·포인트·장비를 유지하며 출발 때 캐릭터 상태를 리셋하지 않는다.

훈련장 표적은 처치 보상이 없고 반복 연습 가능하다. 성장 광장은 적0/소비0으로 설명을 마칠 수 있다. 거리의 Goblin2마리는 같은 교전ID로 보상/복구를 추적한다. 고블린은 일반 종이며 미완료HP/효과만 초기화한다. 세렌/리라/루칸 연출은 전투 위에 긴 문서를 겹치지 않고 피격 없는 보고 위치에 배치한다.

## 4. 스타트와 복구

DS-01-SP~DS-04-SP에40×32stud 안전 마당과 개별 생성 슬롯을 둔다. 첫 시작/처음부터는 자격 있는 구간SP,이어하기는 저장된 목표 다음 안전 지점,리조인은 같은 실행의 안전 합류 지점이다. 서버가 사라지면 개인 목표/논리 처치ID/수령 기록으로 새 실행을 복구한다. 무료 재도전이며 이미 받은XP/장비/포인트·안내 확인은 유지한다.

훈련/의뢰/접속을 반복해 초회 보상을 다시 받지 않는다. 완료자의 재현은 모든 퀘스트/처치XP·Coins0이며 실제 게임 플레이가 아닌 기록 재현이다. 신규 캐릭터는 자기 초회 자격으로 보상받는다. 고블린 격퇴 후 접속 종료는 보고부터 이어가고 Deepwood 이관은 Lv5·0XP·프롤로그 총유입198Coins를 기준으로 검증한다.

## 5. UI/기술 수용

TD 공통 영웅/성장/가방/스킬·퀘스트·배틀/결과/포탈 셸을 공유한다. 지도 숫자/선은 설계 기호이며 새 게임 아이콘이 아니다. 모바일/PC/컨트롤러에 맞게 입력 안내를 치환하고 미리보기/취소·간편 설명·다시 보기와 배분 미완료 진행을 지원한다. 최신 리셋권 수익화는 확정 배분 초기화에만 적용하고 안내를 닫거나 취소하는 행동에 아이템을 소비하지 않는다.

1~4인/기존AI 상한을 지키며 프롤로그는 동료를 강제하지 않는다.4인에 세렌을 추가 전투AI로 넣지 않는다. 개인 메뉴가 공용 전투를 정지하지 않으며 다른 참가자의 안내/소비/성공을 호스트가 덮어쓰지 않는다. 시각 메시·플레이 바닥·AI/공격 쿼리·스트리밍 준비를 분리 검증한다.

현재 산출물은 전체 지도1장·내부 연결도4장·좌표/시나리오 데이터·검토 보드·기획 문서다. 실제 Roblox Terrain/Part/튜토리얼UI/저장 구현은 아직 없으며 네 클래스·미배분/오배분·리셋권·부분 재접속/재현·성문 후 보고·공용 로비 비오염·Deepwood 이관을 후속 검증한다.
