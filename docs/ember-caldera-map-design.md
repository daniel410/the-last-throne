## 1. 공간의 이야기

남서쪽 잿빛 관문에서 높은 도시로 올라간 다음 동쪽 광산/냉각 수로로 내려간다. 동쪽 가문의 설계고에서 대안을 찾고 북쪽 시험로를 거쳐 분화구 중앙 안쪽의 대용광로에 도달한다. ‘도시를 지키는 시설’과 ‘지하에서 치르는 비용’을 높이 차로 표현한다. 분화구 외곽을 돌다가 중앙으로 파고드는7구역 동선과 점차 내려가는 단면을 함께 사용한다. 최종 핵을 빼기 전에 보호막 유지가 확인되는 공간/상호작용을 제공한다.

기존 TD의 짙은 자주회색/갈색 현무암, 다른 높이/기울기의 돌기둥, 깨진 분화구, 석조 성벽/다리, 얇은 주황 용암 균열, 보라 포탈을 공유한다. 넓은 어두운 바닥을 남기고 용암이 걷는 길처럼 보이는 연속 주황 도로가 되지 않게 한다. 전경 기둥은 카메라를 가리지 않게 낮추고 밝은 용암 벽/열기 왜곡이 적 예고를 덮지 않게 한다. TD U턴/타워 패드는 RPG 자유 이동과 교전 공간으로 재구성한다.

## 2. 축척·높이·유효 공간

외곽 예산2,000×1,700stud,Roblox Y위/북쪽-Z,SVG x=X+1000/y=Z+800이다. 전체 지도는 도면 단위1=1stud, 구역 사각형은 제작 예산 경계다. 내부 SVG7장은 축척 없는 연결도다. 모든 면이 걸을 수 있는 평지이거나 별도 Place라는 뜻은 아니다.

## 3. 연결·개방·포탈

| 연결 | 방식 | 조건/연출 |
| --- | --- | --- |
| Frozen Vale/원정 → EC-01 | 에픽 원정 포탈 | 개인 보고/선행 확인 후 안전 SP |
| EC-01 → EC-02 | 보행+화물 승강기 | 노동자/제어기 복구, 목적지 바닥 준비 후 이동 |
| EC-02 → EC-03 | 보행/광산 램프 | 구조 의뢰 수락, 구매/전직 강제 없음 |
| EC-03 → EC-04 | 보행 | 지지 장치/구조 후 안정화한 작업 통로 |
| EC-04 → EC-05 | 장치 해제 후 보행 | 냉각 유량 안정화로 증기문 개방 |
| EC-05 → EC-06 | 보행 | 안전 합의/도면 확보 후 시험로 접근 |
| EC-06 → EC-07 | 격리문 해제 후 보행 | 시험 인증으로 대용광로 문 개방 |
| EC-07 → EC-02 | 안전 귀환 포탈 | 본 전환/핵/기록 후 도시 정비/개인 선택 |
| 도시/왕도 → Haunted Graveyard | 원정 포탈/공통 메뉴 | 개인 보고/에픽 완료, 두 복구 선택 모두 동일 자격 |

EC-05에서 도시로 돌아오는 작업 승강기/단축길을 해금한다. 지도 보라 점선은 귀환 연결 예산이며 직선 경사/실제 콜라이더가 아니다. 승강기는 기본 안전 발판·재호출·연결 끊김 시 출발/도착 복구를 제공한다. 지연/미로딩 상태에서 공중 이동을 확정하지 않는다. 걷는 길/개인 진행 자격은 분리하고 친구가 연 문으로 선행/초회 보상이 자동 완료되지 않게 한다.

## 4. 일곱 구역의 블록아웃

### EC-01 잿빛 관문

석조 포탈 앞 안전 마당에서 도시의 보호막을 원경으로 보여 준다. Imp 교전2+2 뒤 노동자 엄폐와 승강기 제어실이 이어진다. Lava Slime 선택 가지는 앞으로 합류한다. 승강기 바닥은 충분히 넓고 난간이 있으며 대기/재호출 시 적이 들이닥치지 않는다.

### EC-02 용광로 도시

보호막 광장을 중심으로 노동자 대표·장로 기록관·정비·광산 출구를 짧은 고리로 묶는다. 적0, 시민과 전투 경계 분리. 장로/노동자 면담이 상점 소비에 막히지 않는다. 보호막은 원경/천장 연출이고 플레이어 카메라를 가리지 않는다. 브란은 이야기NPC 또는 선택 동료로 같은 외형을 공유한다.

### EC-03 무너진 공명광산

지지 장치2개를 따라 구조 통로가 열린다. 광부는 위협 해제 뒤 안전 구역으로 이동한다. 웜은 넓은 작업 공터에서 지면 예고 후 등장하며 좁은 갱도를 뚫고 화면 밖 공격을 하지 않는다. 강제 추출관은 마지막 조사 위치에서 보이게 해 원인 발견 순서를 지킨다. 끝없는 랜덤 낙석/즉사 낙하는 없다.

### EC-04 갈라진 냉각 수로

건조 중앙 보행로 양옆으로 냉각수/용암을 분리한다. 두 밸브 가지는 유량실로 합류하며 솔로 순차 조작 가능하다. 슬라임 분열전은 배수 마당에 두고 좁은 발판에 쌓이지 않게 한다. 완성한 외곽 회로는 최종 보스의 임시 냉각 장치와 구분한 색/문양/상태를 쓴다.

### EC-05 가문의 설계고

기록 경비 뒤 원본 도면/사고 장부를 읽는 안전 공간이 있다. 중재는 이곳의 보고/통신 대화로 처리해 대표를 만나러 긴 왕복을 강제하지 않는다. 위험 공개/작업 중단권/시험 합의를 확인하고 시험로로 나간다. S 유품은 선택이다. 도시 귀환 작업 승강기/지름길은 끝까지 도착한 뒤 해금한다.

### EC-06 지열 심장 시험로

외곽 제어기2개를 지나 보스 전 안전실로 들어간다. Magma Golem은 넓은 중앙에서 상대하고 외곽 냉각 배출구는 순차 접근 가능하다. 보스 처치 뒤 남는 시험 계기 공간에서 최소 보호막 공급을 검증한다. 시험 인증과 본 전환 완료를 같은 상태로 저장하지 않는다.

### EC-07 대용광로

외곽 전환기2개→안전실→Inferno Overlord→열원 본 전환실→핵/기록 순서다. 보스 공터는 고리형 회피로/낮은 엄폐/안전 바닥을 확보한다. 임시 냉각 장치2개는 동시에 누르지 않아도 처리 가능하고 상호작용 안정화 창을 둔다. 승리 후 전환실에서 지열 공급·보호막 유지·추출 차단의 확인 표식을 보여 준 뒤 핵을 활성화한다. 중앙 구덩이 낙하가 조작 목표가 되지 않게 한다.

## 5. 스타트·이어하기·처음부터·리조인

EC-01-SP~EC-07-SP를 각 A에 배치한다. 포탈이 아니라 안전 입구/진행 안내인 SP도 있다. JSON 좌표는 구역 내 예산 앵커이며 지면/도로/카메라에 맞춰 재정렬한다.4명/동료 개별 생성 슬롯과 추격/광역 피해 차단 경계를 검증한다.

| 동작 | 위치/상태 | 보존 |
| --- | --- | --- |
| 첫 시작 | 선행 확인 후 해당SP | 이전 영구 진행 |
| 이어하기 | 유효 안전 체크포인트, 없으면SP | 확정 구조/장치/도면/시험/보스 |
| 처음부터 | 새 실행의SP, 현재 실행 목표 초기화 | 장비/레벨/영구 완료/개인 선택/초회 수령 |
| 파티 리조인 | 동일 실행의 안전 합류 지점 | 개인 자격/기여/진행 |
| 서버/실행 소멸 후 접속 | 개인 확정 목표로 새 실행 복구 | 미완료 적HP/효과는 초기화 |

전멸은 무료 안전 복귀다. 외곽 회로와 보스 임시 장치를 분리해 저장한다. EC-06 처치 후에는 시험계기,EC-07 승리 후에는 본 전환/핵/기록/보고부터 이어가고 보스를 다시 죽이지 않는다. 핵 회수 전에 보호막 본 전환이 확인돼야 한다. 개인 복구 선택은 호스트가 덮어쓰지 않는다. 공동 재시작은 동의 흐름을 제공하고 한 명의 클릭으로 파티 전체 진행을 지우지 않는다. 유예/보관 기간은 후속 서버 사양이다.

## 6. 선택 구역·안전·기술

| ID | 지도 중심 X/Z 초안 | 역할 |
| --- | --- | --- |
| EC-S1 불씨 약탈단 둥지 | -700 / -220 | Magma Imp·도시 보급 회수 선택 |
| EC-S2 화산 주술사의 제단 | 650 / 650 | King Volcano Shaman·협곡 가지 선택 |
| EC-S3 분화구 거인의 분지 | 650 / -600 | Caldera Titan·에픽 후 선택 도전 |

선택3곳의 내부 상세전은 후속 작업이며 필수 핵/전직/레벨 자원을 독점하지 않는다. 용암/절벽의 경계는 시각 메시와 별도 판정으로 만들고 낙하 시 유료 부활 없이 안전 복귀한다. 열기 지속 피해/갈증 게이지를 필수로 도입하지 않는다. Cryo 물마법이나 화염 면역으로만 통과하는 장벽은 없다.

TD 공통 메뉴/원정/지도/결과·아이콘·포탈·몬스터 모델 원본을 연결하고 부족한 제어기/계기/배관만 파생 제작한다. 검토 보드 선/숫자/도형은 도면 기호이며 게임 UI 신규 아이콘이 아니다. Visuals/Collision/Encounters/Interactions/SafeSpawns/Connections를 구역별로 분리하는 구조를 제안한다. 시각 메시·발판·AI 경로·공격/시야 쿼리를 각각 검증한다. 용암 원경/증기/그림자는 예고 대비와 모바일 성능 측정 후 예산을 정한다. 스트리밍 상태/목적지 바닥을 확인한 뒤 이동시키며 현재 그림으로 성능을 보장하지 않는다.

## 7. 제작/검증

관문/도시/승강기 → 광산/수로 → 최종 보스/본 전환 → 설계고/시험로 연결 순서로 검증한다. 최종 던전20~30분은 목표이며 전체 지역 시간이 아니다. 네 클래스 솔로/동료0·전직/궁극기 미사용, 선택3곳 생략, 주동선Lv30,1/2/4인, 모든SP 재시작/리조인, 승강기/장치/보스/본 전환/선택 사이 종료, 서로 다른 개인 선택/선행과 초회 중복을 검사한다.

산출물은 에픽1문서·시나리오7문서·공간 사양·전체 지도1장·내부 연결도7장·좌표/출처JSON·선택형 HTML 보드다. 실제 Roblox Terrain/Part/맵 파일·저장/이동/전투 구현은 아직 수행하지 않았다.
