# Throne Chronicles RPG 전체 기획안

가제: **Throne Chronicles: The Last Covenant**  
한국어 가제: **왕좌 연대기 최후의 서약**  
작성일: 2026년 10월 26일  
기획 방향: Throne Defense의 세계와 시각 자산을 출발점으로 삼는 별도 RPG 프로젝트

플레이어는 수정 왕좌를 지키던 수호자로 출발해, 왕좌가 유지해 온 세계의 비밀을 발견하고 다섯 세력과 함께 세계의 질서를 다시 세운다. 직접 조작하는 전투, 동료와의 관계, 발견할 가치가 있는 지역, 장비와 직업의 성장, 친구와 기억할 만한 보스전이 하나의 모험으로 이어진다.

이 기획의 기준은 전체 게임의 완성상이다. 첫 제작 분량에 맞춰 이야기를 줄이지 않으며, 전체 서사와 최종 콘텐츠를 먼저 설계한다. 이하의 고유 인물·역사·지역 확장·시스템 수치는 새 RPG를 위한 창작 제안이다. 플레이 시간과 성능 수치는 제작 후 검증할 목표다.

## 1 게임이 약속하는 경험

**내가 선택한 영웅으로 미지의 땅을 탐험하고, 동료와 강적을 쓰러뜨리며, 지켜야 할 세계의 미래까지 결정하는 판타지 액션 RPG.**

왕좌는 모험의 출발점이자 돌아오는 장소다. 처음에는 왕좌를 지키기 위해 싸우지만, 여정이 끝날 때는 왕좌가 누구를 위해 존재해야 하는지 결정한다. 지역을 구할수록 성채에 주민과 동료가 돌아오고, 상점·건물·대화·음악이 바뀐다. 성장의 결과를 캐릭터 능력과 세계 양쪽에서 확인하게 한다.

| 설계 축 | 완성된 게임에서 제공할 경험 |
| --- | --- |
| 전투 | 공격 예고를 읽고 회피·차단·연계로 승리한다. 장비가 좋아져도 보스의 핵심 행동을 이해해야 한다 |
| 탐험 | 지도에 표시되지 않은 길, 환경의 비밀, 주민의 사연과 보물이 연결된다 |
| 성장 | 무기와 특성 조합으로 플레이 방식이 변한다. 같은 직업도 다른 역할을 만들 수 있다 |
| 서사 | 주인공·동료·지역 갈등이 최종 결말에 기여한다. 중요한 선택은 이후 대사와 세계 상태에 남는다 |
| 협력 | 솔로에서도 완결된 모험을 즐기고, 친구와는 연계·구조·역할 분담의 재미가 더해진다 |
| 세계의 변화 | 구한 사람과 복원한 지역이 성채에 반영되고 최종전 지원으로 돌아온다 |
| 지속성 | 본편의 결말 이후에도 세계의 균열, 고난도 던전, 길드와 생활 콘텐츠에 목적이 생긴다 |

‘최고의 RPG’는 콘텐츠 양만으로 판단하지 않는다. 이동과 타격의 감각, 다음 행동의 명확성, 세계에 대한 애착, 납득할 수 있는 보상, 친구와 함께한 사건이 각각 높은 완성도를 가져야 한다.

## 2 장르와 전체 구성

| 항목 | 기획 방향 |
| --- | --- |
| 장르 | 스토리 중심 협동 액션 RPG |

| 카메라 | 캐릭터와 공간을 읽을 수 있는 3인칭 시점. 전투 중 거리와 방향 조절 지원 |
| 기본 모험 | 솔로 또는 1~4인 파티 |
| 소셜 공간 | 왕도와 지역 거점에서 다른 모험가를 만나는 공유 공간 |
| 대규모 콘텐츠 | 본편 이후 8인 레이드와 다수 참여 필드 이벤트 |

| 성장 구간 | 영웅 레벨 1~60, 이후는 전문화·장비 조합·명예 중심 |
| 플레이 길이 | 5~10분의 작은 발견, 15~25분의 원정, 30~45분의 던전, 45~60분의 레이드 |

넓은 세계는 여러 지역을 연결하는 구조로 만든다. 지역 사이에는 자연스러운 관문과 이동을 두며, 처음부터 전 지역을 하나의 거대한 서버에 올리는 방식을 전제하지 않는다. 플레이어가 느끼는 세계의 연결성과 실제 서버 구성은 각각 설계한다.

## 3 Throne Defense에서 이어받을 정체성

기존 제품의 핵심 기반은 수정 왕좌, 보라 포탈, Knight·Elf Archer·Dwarf Axe Thrower·Mage·Priest의 다섯 영웅, 다섯 팩션의 타워, 숲·설원·화산·묘지 테마다. RPG에서는 영웅의 직접 행동과 세계 탐험이 중심이 된다.

| 기존 기반 | 새 RPG에서의 발전 |
| --- | --- |
| 수정 왕좌 | 세계의 봉인을 유지하는 장치이자 이야기의 핵심 갈등 |
| 포탈 | 침공로·고대 이동망·던전 입구·현실 붕괴 현상 |
| 다섯 영웅 | 플레이 직업과 전문화의 출발점 |
| 팩션 타워 | 고유 인격을 가진 동료, 팩션 병력, 공성 지원 유닛 |
| Deepwood | 엘프·고블린·오크의 생활과 전쟁이 얽힌 대삼림 |
| Frozen Vale | 과거의 기억과 봉인이 얼어붙은 북방 왕국 |
| Ember Caldera | 드워프 도시·고대 용광로·화산 심층 세계 |
| Haunted Graveyard | 잊힌 왕조와 산 자·죽은 자의 약속이 남은 땅 |
| 왕좌 수호전 | 이야기의 전환점에 등장하는 복합 전투 |
| 영웅과 타워의 조합 | 직접 전투·동료 전술·진영 지원의 연계 |

기존 적은 왕좌 방향으로 행진하고 영웅을 무시하도록 설계돼 있다. RPG의 추적·공격 예고·어그로·플레이어 피격·회피·지형 대응은 새로 설계해야 한다. 모델과 세계관을 활용할 수 있다는 사실이 기존 전투를 바로 RPG 전투로 사용할 수 있다는 뜻은 아니다.

## 4 세계의 기원과 중심 갈등

### 세계와 수정 왕좌

대륙의 이름은 **에테리아 Aetheria**다. 오래전 다섯 문명은 서로 다른 방식으로 세계의 마력인 ‘공명’을 다뤘다. 기사는 서약, 엘프는 생명, 드워프는 물질, 마법사는 지식, 성직자는 기억과 영혼을 맡았다.

700년 전 차원의 경계가 무너진 ‘첫 균열’이 일어났다. 초대왕 **아우렐리안 Aurelian**과 다섯 수호자는 수정 왕좌를 만들어 대륙을 봉합했다. 왕은 자신의 의식을 왕좌에 연결했고, 최초의 수호자 **리라 Lyra**는 봉인의 중심에 남았다. 후세의 역사는 이를 왕이 세계를 구한 성전으로 기록했다.

왕좌는 수백 년 동안 균열을 막았지만, 손상된 봉인을 유지하기 위해 죽은 이들의 기억과 영혼을 연료로 쓰기 시작했다. 점차 한계를 넘자 살아 있는 존재의 공명까지 거둬들였다. 지역의 마력이 메마르고, 죽은 자가 돌아오며, 왕좌의 수호 기능 자체가 새로운 균열을 만들었다.

왕좌 속 아우렐리안은 멸망을 반복해서 보며 변했다. 이제 그는 자유로운 문명은 다시 전쟁을 일으킬 것이므로 모든 생명과 기억을 하나의 의지로 묶어야 영원한 평화가 온다고 믿는다. 최종 적은 왕좌 안에서 완성돼 가는 **영원의 왕 The Eternal King**이다.

### 플레이어의 위치

플레이어는 변경의 작은 마을에서 자란 견습 수호자다. 어린 시절 포탈 사고에서 살아남으며 리라의 공명 조각을 받았다. 이 때문에 봉인의 기억을 볼 수 있지만, 왕위를 계승할 자격이나 세계를 통치할 운명은 없다.

모험을 통해 드러나는 사실은 ‘한 사람이 모든 힘을 짊어져야 한다’는 왕좌의 전제가 틀렸다는 것이다. 다섯 문명이 힘과 책임을 나누면 한 명을 희생시키지 않고도 세계를 지킬 수 있다. 주인공의 역할은 최강의 왕이 되는 것과 함께, 서로를 믿지 않는 이들을 다시 연결하는 데 있다.

### 이야기의 질문

안전을 위해 어느 정도의 자유를 내줄 수 있는가. 과거의 희생을 기린다는 이유로 같은 희생을 계속 요구해도 되는가. 적으로 배운 존재와 공존할 수 있는가. 이 질문은 대사와 선택, 보스의 행동, 지역을 복원하는 방식에 반복해서 등장한다.

동료는 임무를 주는 인물에 그치지 않는다. 야영지에서 논쟁하고, 다른 동료와 관계가 바뀌며, 자신의 지역으로 돌아갔을 때 플레이어와 다른 판단을 내릴 수 있다. 호감도는 선물 반복보다 중요한 대화·개인 임무·전투 중 행동으로 쌓는다.

## 6 풀 스토리

### 프롤로그 무너진 수호식

왕도 외곽에서 견습 수호자의 서약식이 열린다. 플레이어는 무기를 선택하고, 세렌과 함께 연습하며, 상인과 아이들의 작은 부탁을 해결한다. 첫 10분 안에 캐릭터 조작과 마을의 평범한 삶을 보여준다.

서약식 도중 왕좌의 빛이 꺼지고 포탈이 열린다. 플레이어는 민가에서 주민을 구하고, 무너지는 성문에서 세렌을 도와 거대 오우거를 막는다. 구조한 주민은 이후 성채에서 다시 만난다. 전투 중 리라의 목소리가 들리고, 왕좌를 향한 적과 왕좌에서 흘러나오는 마력이 같은 공명을 가진다는 첫 단서를 본다.

왕좌를 재가동하려면 네 지역의 봉인핵과 중앙 관제의 서약이 필요하다. 섭정 루칸은 플레이어에게 첫 원정을 맡긴다. 플레이어는 자신이 구한 주민과 수리 중인 성채를 뒤로하고 숲으로 떠난다.

### 제1장 대삼림의 검은 뿌리

무대는 **Deepwood**다. 엘프는 포탈 오염의 원인을 고블린의 불법 채굴로 의심한다. 에린은 플레이어를 침입자로 경계하지만, 숲의 정령을 구하면서 협력한다.

플레이어는 파괴된 고블린 마을을 발견한다. 일부 고블린은 난민이며, 전쟁을 이끄는 주술사 세력이 포탈의 힘을 이용해 오크와 오우거를 장악하고 있다. 동굴 슬라임, 감염된 나무, 버려진 엘프 감시탑을 지나며 숲 전체가 봉인 장치의 뿌리와 연결됐음을 확인한다.

중간 보스는 오크 군벌, 최종 보스는 세계수의 뿌리를 잠식한 **King Shaman**이다. 전투 중 뿌리의 결박을 끊고 포로를 구하면 오우거가 지배에서 풀려나 전투 구도가 바뀐다.

주술사를 쓰러뜨린 뒤 엘프의 성역만 보호할지, 일부 봉인 자원을 나눠 고블린 난민의 거점도 복원할지 선택한다. 두 선택 모두 메인 스토리를 진행시키며, 성채에 돌아오는 주민과 최종전 정찰 지원이 달라진다. 첫 봉인핵에는 왕좌가 숲의 생명력을 거둬들이고 있었다는 기록이 남아 있다.

### 제2장 얼어붙은 왕의 기억

무대는 **Frozen Vale**다. 얼음 폭풍 속 마을은 왕도의 지원을 기다리다가 고립됐다. 북방의 여왕은 왕좌를 불신하며 봉인핵 반출을 막는다.

플레이어는 Ice Wolf의 사냥터, 빙하 아래 폐허, 얼어붙은 군대의 전장을 조사한다. 과거 북방 왕국이 왕좌의 연료 징발에 저항했고, 그 전쟁이 역사에서 지워졌음을 알게 된다. 여왕은 이 기억을 봉인하기 위해 자기 백성과 함께 얼어붙는 길을 선택했다.

**King Ice Golem**을 돌파한 뒤 **Queen Ice Elf**와 싸운다. 여왕은 단순한 적이 아니라 기억을 풀어 주면 왕이 다시 깨어날까 두려워하는 수호자다. 플레이어는 얼음 거울에 갇힌 세 기억을 복원해 전투를 끝낸다.

두 번째 봉인핵과 함께 왕좌의 희생 기록을 얻는다. 왕도에 돌아가면 루칸은 기록을 공개할 경우 전 지역이 봉인을 거부해 대륙이 무너질 수 있다고 경고한다. 세렌도 처음으로 왕도의 명령에 의문을 품는다.

### 제3장 꺼지지 않는 용광로

무대는 **Ember Caldera**의 드워프 도시와 지하 용광로다. 브란은 왕좌를 유지하는 장치가 자신의 가문이 만든 것임을 밝힌다. 도시는 용광로의 보호막으로 살아가지만, 용광로는 산 아래 생명과 공명을 빨아들인다.

플레이어는 광산 구조, 용암 수로 재배치, 파업한 노동자와 장로회의 중재를 진행한다. 전투뿐 아니라 도시가 왜 잘못된 장치를 끌 수 없었는지 체험한다. 마그마 웜의 이동이 지진을 일으키고, 화산 주술사들이 봉인핵을 차지하려 한다.

최종 보스 **Inferno Overlord**는 용광로가 과열되며 형체를 얻은 공명체다. 전투에서 냉각 수로를 열고 드워프 장치를 운용해야 한다. 플레이어와 브란은 도시를 살릴 대체 열원을 가동한 후 세 번째 봉인핵을 회수한다.

핵심 발견은 왕좌의 중심 의식이 아직 살아 있다는 사실이다. 동시에 왕도에서 왕좌가 재가동되며 피난민의 기억이 사라지기 시작한다. 원정의 목적이 재가동에서 진실 확인으로 바뀐다.

### 제4장 죽은 자들의 증언

무대는 **Haunted Graveyard**와 지하 왕릉이다. 교단은 셀레네에게 리치 군주를 정화하라고 명령한다. 그러나 망자들은 플레이어를 공격하면서도 자신의 이름을 기억해 달라고 외친다.

플레이어는 묘비 이름을 복원하고, 살아 있을 때의 집을 찾아 주며, 왕릉의 기록을 읽는다. 망자들의 상당수는 왕좌를 위한 제물로 사라졌지만 반역자로 기록됐다. 베이르는 진실을 지키기 위해 망자를 붙들어 두었고, 이제 그 자신도 죽은 이들의 자유를 빼앗고 있다.

**Death Knight**와 왕릉의 수호대를 돌파한 뒤 **Lich Sovereign**과 싸운다. 승리 후 베이르는 리라가 자원한 희생자가 아니었고, 다섯 문명의 협약을 왕이 독점했다는 원본 기록을 넘긴다. 플레이어는 기록을 남긴 채 망자들이 떠나도록 돕는다.

셀레네는 교단의 정화 명령을 거부하고, 영혼을 연료로 쓰는 체계를 끝내기로 한다. 네 번째 봉인핵을 얻지만, 주인공의 공명 조각이 왕좌를 완전히 깨우는 마지막 열쇠라는 사실도 드러난다.

### 제5장 하늘에 남은 다섯 번째 서약

무대는 새 지역 **Aether Spire**, 붕괴한 부유 학술도시다. 이리아는 네 봉인핵을 왕좌에 돌려주면 영원의 왕이 완성된다고 판단한다. 왕좌 없이 균열을 막는 방법을 찾기 위해 최초의 관제 도시로 향한다.

중력을 바꾸는 도서관, 사라진 시간대가 겹치는 연구실, 공명으로 남은 시민의 하루를 탐험한다. 플레이어는 아우렐리안이 처음부터 악인이 아니었고, 실제로 첫 균열에서 많은 생명을 구했다는 사실도 본다. 구국의 공적과 이후의 폭정을 함께 이해하게 한다.

다섯 번째 서약은 별도의 힘의 핵이 아니라, 다섯 문명이 서로의 권한을 제한하는 공동 제어 규칙이다. 왕은 이를 지우고 중앙 왕좌가 모든 힘을 독점하도록 바꿨다. 이를 복원하려면 각 세력이 자발적으로 자신의 봉인 장치를 맡아야 한다.

최종 보스 **The First Warden**, 리라의 전투 기억으로 만들어진 수호체와 싸운다. 승리 후 실제 리라와 대화하고, 그녀를 왕좌에서 구하겠다는 약속을 한다. 왕좌를 대신할 **새로운 서약망 Covenant Network**의 설계도를 확보한다.

### 제6장 갈라진 성채

왕도로 돌아오면 루칸은 비상 통치를 선포하고 봉인핵을 요구한다. 포탈 침공은 계속되고, 왕좌를 끄자는 이들과 왕좌만이 살길이라는 이들이 충돌한다.

플레이어는 도시의 세 구역을 오가며 주민을 구하고, 동료들의 주장을 듣고, 앞선 지역에서 얻은 증언을 공개한다. 이야기는 긴 연설 한 번으로 해결되지 않는다. 마력 공급을 잃을 병원, 가족의 기억을 돌려받으려는 사람, 포탈 앞에서 버티는 병사에게 각각 대안을 마련해야 한다.

루칸은 아우렐리안과 연결돼 새로운 왕의 대리인이 된다. 보스전은 주민 대피와 왕좌 연결 장치 차단을 병행한다. 플레이어가 루칸을 쓰러뜨리면 그는 통제에서 풀려나 자신이 한 선택의 책임을 인정한다. 살려 재판에 세울지, 전선에서 속죄할 기회를 줄지 결정하며 이후 등장 방식이 달라진다.

아우렐리안은 성채 아래의 왕좌를 버리고 균열 너머 원형 왕좌로 이동한다. 하늘에 거대한 포탈이 열리고, 세계의 여러 지역이 한 공간으로 겹치기 시작한다.

### 제7장 다섯 깃발의 원정

각 세력은 새로운 서약망을 가동할 준비를 하지만 서로의 의도를 의심한다. 플레이어는 다섯 지역의 대표와 마지막 협약을 맺고, 개인 이야기에서 성장한 동료들이 자신의 세력을 설득한다.

앞선 선택은 원정대의 모습으로 돌아온다. 고블린을 도왔다면 비밀 통로가 열리고, 북방의 기억을 복원했다면 얼음 장벽이 피난민을 보호하며, 드워프 도시를 구했다면 공성 장치가 도착한다. 필수 임무로 얻는 기본 지원만으로도 본편을 완주할 수 있고, 추가 선택은 전투 방식과 장면을 풍부하게 한다.

이 장의 주요 임무는 이동하는 공명 수정 호송, 분리된 전선의 연결, 성채 최종 방어다. 왕좌 수호전에서는 적을 막는 동시에 포탈을 닫고, 쓰러진 아군 지휘관을 구하고, 최종 원정로를 연다.

**Dread Commander**가 연합군을 분단하려 하지만 플레이어는 동료들의 연계로 이를 돌파한다. 마지막 야영지에서는 각 동료와 모험을 돌아본다. 플레이어는 자신이 사라지면 모두 해결된다는 희생안을 거부하고, 함께 짊어지는 방식을 선택한다.

### 제8장 영원의 왕좌

무대는 **The Fractured Crown**, 기억 속 왕도와 포탈의 심연이 겹친 최종 지역이다. 지나온 숲·설원·화산·묘지의 일부가 뒤섞여 나타나며, 세계를 하나의 의지로 묶으려는 왕의 계획을 공간으로 보여준다.

왕은 플레이어에게 후계자가 되면 죽은 사람을 돌려주고 모든 전쟁을 끝내겠다고 제안한다. 대신 사람들은 슬픔뿐 아니라 선택할 자유도 잃는다. 주인공은 죽음을 부정하는 약속을 거절하고, 잃은 이들을 기억하며 살아가는 세계를 택한다.

최종전은 세 단계다. 첫 단계에서는 왕의 검과 서약 공격을 읽고 맞선다. 두 번째에서는 다섯 문명의 힘을 빼앗은 왕이 전장을 바꾸며, 동료들이 각 봉인을 되찾는다. 세 번째에서는 왕이 모든 공격 예고와 기억을 지우는 ‘완전한 정적’을 시도하고, 플레이어가 지역에서 모은 공명과 동료의 신호를 따라 새로운 서약망을 연결한다.

주인공은 힘으로 왕좌를 차지할 기회를 얻지만 중앙의 독점 권한을 해제한다. 아우렐리안의 의식은 처음 구하려 했던 사람들의 기억과 마주한 뒤 소멸한다. 리라는 왕좌에서 풀려나고, 자신의 이름으로 남을 마지막 기록을 부탁한다.

주인공이 받은 리라의 조각은 그녀와 함께 사라진다. 캐릭터가 모험으로 습득한 기술과 장비는 유지된다. 이야기는 타인의 희생으로 받은 권한을 놓고 스스로 쌓은 힘으로 돌아오는 것으로 마무리된다.

### 에필로그 우리가 지킬 세계

새로운 서약망은 중앙의 왕 없이도 작동하기 시작하지만, 사람들의 정치와 갈등까지 자동으로 해결하지 않는다. 플레이어는 최종 협약의 운영 형태를 선택한다.

| 결말 선택 | 세계의 운영과 후일담 |
| --- | --- |
| 다섯 의회의 서약 | 지역 대표가 힘을 나눈다. 성채는 공동 의회와 모험가의 거점이 된다 |
| 열린 왕관의 서약 | 왕좌의 군사·마력 독점을 폐지하고 제한된 왕권과 지역 의회를 둔다. 플레이어는 왕관의 수호자 직책을 맡는다 |
| 자유 수호자의 서약 | 각 지역이 장치를 운영하고 수호자 연맹이 상호 감시한다. 플레이어는 직위를 내려놓고 세계를 여행한다 |

모든 결말은 영혼을 연료로 쓰는 체계를 끝낸다. 결말에 따라 대사·기념물·거점 인물이 바뀌며, 특정 결말만 최강 장비나 레이드를 열도록 만들지 않는다.

마지막 장면은 프롤로그에서 구한 주민이 성채의 일상을 이어가는 모습이다. 성문 밖에 작은 균열이 다시 열리지만, 이제 다섯 지역의 장치가 함께 빛난다. 동료는 ‘이번에는 우리 차례’라고 말하며 플레이어와 다음 모험으로 나선다.

## 7 지역과 탐험 설계

| 지역 | 탐험의 성격 | 대표 콘텐츠 | 해결 후 변화 |
| --- | --- | --- | --- |
| Dawnspire 왕도 | 성채와 생활권, 숨겨진 과거 | 지하 수로, 왕실 문서고, 주민 사건 | 귀환 주민·상점·기념물·음악 변화 |
| Deepwood | 수직 숲과 지하 생태계 | 나무 위 길, 포자 동굴, 세계수 뿌리 | 숲과 난민 거점의 회복 |
| Frozen Vale | 날씨와 기억의 유적 | 눈보라 피난처, 빙하 동굴, 얼음 궁전 | 폭풍 완화와 북방 교역 재개 |

| Haunted Graveyard | 영혼과 현실이 겹치는 공간 | 이름 없는 묘지, 종탑, 지하 왕릉 | 안식한 망자의 기억과 정원 |
| Aether Spire | 중력과 시간의 퍼즐 | 공중 회랑, 관측소, 기억 도서관 | 지역 간 이동망과 연구 거점 |
| The Fractured Crown | 여러 지역이 붕괴하며 겹치는 공간 | 왜곡된 왕도, 공명 심연, 원형 왕좌 | 결말 이후 균열 원정의 기원 |

각 지역은 독립된 생활권과 작은 이야기의 결말을 가진다. 지역을 구한다는 일이 지도 색칠에 그치지 않도록, 상인 한 명의 이동이나 새로 열린 다리도 주민의 사정과 연결한다.

탐험 보상은 장비·재료·세계 기록·이동 경로·동료 대화·외형으로 나눈다. 모든 숨겨진 장소에 같은 상자를 두지 않는다. 고유한 풍경이나 퍼즐의 해답 자체가 발견의 가치가 되는 장소도 만든다.

등반 지점, 활공, 짧은 공명 도약, 탈것을 여정에 따라 얻는다. 특정 직업만 필수 통로를 통과할 수 있게 하지 않으며, 직업별 능력은 지름길과 다른 해결법을 제공한다. 빠른 이동은 발견한 거점끼리 연결하고, 첫 방문에서는 지역의 분위기와 동선을 경험하게 한다.

## 8 직업과 전직

다섯 직업을 모두 전체 게임의 핵심 콘텐츠로 포함한다. 초기 선택으로 영구적인 손해가 생기지 않도록, 성채에서 다른 직업을 배우고 장비 편성을 저장할 수 있다. 영웅 레벨은 직업별로 관리하고, 스토리 진행·탐험·동료 관계는 계정 내 공유한다. 처음부터 다섯 번 같은 본편을 반복하도록 요구하지 않는다.

| Mage | 원소 조합·광역 제어·순간 화력 | Elementalist 화염과 번개 연쇄 | Frostbinder 빙결과 방어적 제어 |
| Priest | 성광 공격·정화·피해 예방 | Dawnkeeper 보호와 회복 | Exorcist 낙인과 대언데드 공격 |

전문화는 레벨 20에 열고 레벨 40과 60에서 핵심 특성을 발전시킨다. 전직은 직업별 개인 서약 임무로 완성하며, 단순 메뉴 구매로 끝내지 않는다. 전투 밖에서 전문화와 특성 재설정을 허용해 실험을 장려한다.

각 직업은 기본 공격, 고유 방어·기동 행동, 선택 가능한 액티브 기술군, 궁극기, 지속 효과를 갖는다. 전투에는 액티브 3개와 궁극기 1개를 장착한다. 기술을 많이 수집하는 것과 화면에 많은 버튼을 놓는 것을 구분한다.

Knight의 차단은 적의 자세를 무너뜨리고, Elf의 약점 표시는 그 부위에 집중할 이유를 만든다. Dwarf는 방어를 부수며, Mage는 노출된 적에게 원소를 연계하고, Priest는 위험한 상태를 정화하면서 공격 기회를 유지한다. 모든 직업은 솔로용 피해와 회복 수단을 가지며 힐러 편성을 일반 모험의 입장 조건으로 삼지 않는다.

## 9 전투의 손맛과 전술

### 기본 전투

플레이어가 공격 방향과 타이밍을 판단하고, 피격 전에 대응할 수 있는 행동 중심 전투를 지향한다. 적의 큰 기술은 자세·소리·바닥 표시를 함께 사용해 알려 준다. 이펙트가 많아져도 위험 표시는 남아 있어야 한다.

기본 공격은 직업마다 연계와 타격 간격이 다르다. 근접 직업은 공격을 계속할지 방어할지 결정하고, 원거리 직업은 시야·거리·기동을 관리한다. 모바일은 표적 보정과 선택형 자동 기본 공격을 지원하되, 회피·중요 스킬·우선 표적 선택은 플레이어가 통제한다. 전투 전체를 자동 진행하는 기능은 기본 설계에 넣지 않는다.

공통 자원은 체력·회피용 스태미나·직업 자원이다. 이동 자체로 스태미나를 소모하지 않아 탐험이 느려지지 않게 한다. 회피를 연속 남발하면 위험하지만 적의 연타에는 방어·거리 확보·환경 엄폐로 대응할 수 있어야 한다.

### 적과 보스

일반 적도 돌진형·방패형·원거리형·지원형·매복형의 행동 차이를 가진다. 고블린은 측면을 노리고, 오우거는 느리지만 공간을 차지하며, 리치 계열은 소환 장치를 남긴다. 강한 적을 단순히 체력이 많은 적으로 만들지 않는다.

보스는 일반적으로 공격 학습, 전장 변화, 배운 행동의 결합으로 진행한다. 실패 원인이 읽혀야 하고 재도전 이동은 짧아야 한다. 이야기 보스의 솔로 버전은 한 사람이 동시에 두 지점에 서야 하는 기믹을 사용하지 않는다.

### 공명 연계

파티와 동료의 기술은 상태를 연결한다. 방패 반격으로 균형을 무너뜨린 적에게 약점 사격을 맞히거나, 젖은 지면에 번개를 연결하고, 성광 표식에 도끼를 맞혀 방어를 깨는 방식이다. 강력한 조합 한 가지만 모든 콘텐츠를 지배하지 않도록 서로 다른 적과 환경에 유효한 조합을 둔다.

연계 성공에는 짧은 소리와 시각 반응을 주지만 전체 화면을 멈추지 않는다. 다른 플레이어의 강한 이펙트는 줄일 수 있으며, 적의 공격 예고와 파티 위험 신호는 유지한다.

## 10 동료와 진영 지원

솔로에서는 이야기 동료 2명과 동행할 수 있다. 직접 조작은 주인공에 집중하고, 동료에게 공격 집중·집결·고유 기술 사용을 지시한다. 파티 플레이에서는 인원에 맞춰 AI 동료를 줄여 일반 모험의 전투 인원을 최대 4명으로 맞춘다. 솔로의 3인 구성과 4인 파티는 각각 별도의 밸런스 조건으로 검증한다.

동료는 장비 수치만 다른 자동 공격 유닛이 아니다. 전투 역할, 탐험 대화, 개인 이야기, 성채에서의 생활을 가진다. 전투 필수 능력을 특정 호감도 선택 뒤에 숨기지 않으며, 관계 발전은 연계 변형·개인 외형·대화와 전용 임무를 연다.

기존 타워의 정체성은 공성전과 왕좌 수호전의 지원 병력으로 발전시킨다. 병력 편성은 전투 전에 결정하고, 임무 중 얻는 지휘 자원으로 제한된 전술 지점에 궁수대·방패병·박격포·성광 지원 등을 요청한다. 모든 야외 전투에서 설치를 반복하도록 만들지 않는다.

플레이어는 전선에서 직접 싸우며 포탈을 닫고 적 지휘관을 노린다. 지원 병력은 길을 지키거나 공격 기회를 만드는 역할이다. 일반 임무에서 설치와 관리가 영웅의 행동 시간을 과도하게 차지하면 이 구조를 조정한다.

## 11 퀘스트와 선택의 결과

| 이야기 유형 | 설계 원칙 | 예시 |
| --- | --- | --- |
| 메인 스토리 | 각 장마다 독립 갈등과 해결, 전체 비밀의 진전 | 숲 복원과 첫 봉인핵의 진실 |
| 동료 이야기 | 동료가 스스로 판단하고 관계가 바뀐다 | 브란이 가문의 작업장을 공개하는 선택 |
| 지역 연속 퀘스트 | 주민과 장소의 변화가 누적된다 | 실종 광부 구조부터 광산 운영 재개까지 |
| 탐험 사건 | 짧지만 고유한 장면과 발견 | 소리가 나는 묘비를 따라 망자의 이름 찾기 |
| 진영 임무 | 문화와 갈등을 이해하며 선택한다 | 엘프 성역과 난민 정착지의 협약 |
| 반복 의뢰 | 이미 배운 시스템으로 짧은 목표를 수행한다 | 상단 호위·균열 정찰·강적 추적 |

대화 선택지는 성격 표현, 관계 변화, 지역 상태 변화로 구분한다. 결과가 같은 선택을 큰 분기처럼 연출하지 않는다. 중요한 선택은 실행 전에 상황을 이해할 수 있게 하되, 보상표만 보고 선택하도록 전체 결과를 노출하지는 않는다.

각 장의 큰 결말은 세계의 공통 진행으로 합류한다. 개인 선택은 개인 거점·NPC 대사·지원 방식에 반영한다. 파티에서는 호스트의 스토리 상태로 장면을 진행하고, 중요한 개인 결정은 각 플레이어가 자신의 후일담에 별도로 기록한다. 뒤처진 플레이어가 타인의 결말을 강제로 확정받지 않게 한다.

본편 장면과 보스는 회상 메뉴에서 다시 볼 수 있다. 중요한 선택의 원본 기록은 유지하고, 다른 결과는 회상용 분기로 체험하게 한다. 반복 파밍으로 매번 국가의 결말이 바뀌는 구조를 피한다.

## 12 장비와 성장

성장은 캐릭터 레벨, 전문화, 장비 조합, 동료 연계, 탐험 능력으로 나눈다. 각 축이 다른 경험을 바꿔야 하며 같은 공격력 증가를 여러 메뉴에 분산하지 않는다.

장비 슬롯은 무기·보조장비·방어구 4부위·장신구 2개·유물 1개를 기본안으로 한다. 무기는 공격 방식과 핵심 효과를, 방어구는 생존과 운영을, 유물은 조합의 중심을 맡는다. 외형 변경은 성능과 분리한다.

| 성장 요소 | 구체적 방향 |
| --- | --- |
| Hero Level | 기술·콘텐츠 접근과 기본 성장. 직업별 관리 |
| 전문화 | 서로 다른 운영 방식과 역할 |
| 장비 효과 | 도끼 회수 시 폭발, 완벽 차단 후 반격 변화 등 행동을 바꾸는 효과 |
| 룬 | 기술의 속성·범위·자원 사용을 조절. 무조건 상위인 룬보다 선택 관계 |
| 제작 | 원하는 종류의 장비를 목표로 획득하는 경로 |
| 동료 연계 | 관계와 개인 임무를 통해 전술의 선택지를 확장 |
| 탐험 능력 | 새로운 장소와 다른 이동 경로에 접근 |
| 명예 성장 | 만렙 이후 칭호·외형·거점 장식. 무한한 전투력 누적을 제한 |

드롭은 기대감을 주되 목표를 잃지 않게 한다. 보스 고유 무기는 완제품 드롭과 재료 제작을 병행한다. 예를 들어 5회 처치로 모이는 확정 재료로 기본형을 만들고, 추가 도전에서는 효과 조합을 추구할 수 있다. 5회는 초기 설계값이며 실제 소요 시간에 따라 조정한다.

강화는 실패로 장비가 파괴되거나 단계가 내려가는 구조를 쓰지 않는다. 재료를 모으면 확실히 강화되고, 최고 강화 한도와 효과 조합으로 성장 폭을 관리한다. 새 지역이 나올 때마다 이전의 고유 장비를 전부 버리게 하기보다, 재련과 효과 계승으로 애착을 이어가게 한다.

## 13 경제와 아이템 거래

새 RPG의 경제는 기존 Throne Defense와 별도로 설계한다. 기존 게임의 전투 Gold나 Diamonds 잔액을 자동으로 연결하지 않는다. 새 RPG 화면에서는 영속 일반 재화를 **Coins**, 임무 안에서 쓰는 병력 자원을 **Command Points**로 구분한다. 유료 외형 재화의 명칭과 지갑은 별도로 확정한다.

Coins는 퀘스트·전투·거래로 얻고 제작·재련·생활·거점 장식에 쓴다. 장비 수리는 초반 진행을 막는 세금으로 사용하지 않는다. 경제의 주된 소비처는 새로운 선택과 꾸미기다.

채집 재료와 일반 제작품은 거래할 수 있다. 이야기 핵심 아이템, 최고 난도 보스의 핵심 유물, 유료 외형은 거래 규칙을 각각 분리한다. 드롭 거래만으로 모든 최종 도전을 건너뛰는 구조는 피하며, 친구가 같은 전투에서 얻은 아이템을 짧은 시간 동안 나눌 수 있는 규칙을 검토한다.

거래소는 기본 재화·아이템의 수급이 안정된 뒤 전체 경제에 맞춰 도입한다. 등록 수수료, 품목별 공급, 비정상 거래, 반복 작업 계정의 영향을 운영 지표로 본다. 서버가 아이템 소유권·수량·거래 완료를 확정하며 복제와 중복 지급을 막는다.

## 14 생활과 거점

왕도 성채는 플레이어와 함께 회복되는 집이다. 동료가 돌아오고, 주민의 상점이 열리며, 지역에서 가져온 음악과 장식이 공간을 바꾼다. 메뉴만 나열된 로비를 넘어 다음 모험 전에 머물 이유를 만든다.

| 생활 콘텐츠 | 모험과 연결되는 이유 |
| --- | --- |
| 채광·벌목·약초 | 제작 재료, 지역 생태와 비밀 통로 발견 |
| 낚시 | 지역 도감, 요리, 희귀한 탐험 단서 |
| 요리 | 짧은 준비 버프와 동료 야영 대화 |
| 대장·연금·룬 제작 | 목표 장비와 소모품을 만드는 경로 |
| 개인 거처 | 전리품·동료 선물·업적을 전시하는 공간 |
| 성채 복원 | 구한 주민과 지역 재료가 실제 시설로 돌아옴 |
| 탈것·수집 | 세계 문화와 생물에 연결된 외형과 이동 경험 |

생활 콘텐츠의 버프는 고난도 도전의 준비를 돕지만, 특정 전문직을 강제로 반복해야 본편을 진행할 수 있게 하지 않는다. 전문직을 바꾸거나 부캐릭터를 키우는 부담을 줄이고, 계정 내 제작 기록을 공유한다.

## 15 협동과 길드

기본 파티는 친구 초대·파티 찾기·솔로 출발을 지원한다. 대기 인원을 채우지 않아도 출발할 수 있고, 도중 이탈에는 AI 대체와 재접속을 제공한다. 적 수·체력·행동 빈도·목표 수를 함께 조정해 인원이 늘었다는 이유만으로 전투가 길어지지 않게 한다.

플레이어 간 레벨 차이는 지역 콘텐츠에 맞춘 보정으로 줄인다. 고레벨은 기술 선택과 장비 효과의 정체성을 유지하되 저레벨 친구의 전투 기회를 빼앗지 않게 한다. 초행 파티, 이야기 감상, 빠른 반복, 고난도 연습 목적을 파티 찾기에서 구분한다.

길드는 전용 회관, 공동 장식, 길드 의뢰, 연습 보스, 함께 세우는 주간 목표를 제공한다. 출석하지 않으면 길드 전체가 손해 보는 강한 의무를 피한다. 길드 레이드에는 개인 기여와 무관하게 길드장이 전리품을 독점 배분하는 구조를 쓰지 않는다.

길드 콘텐츠의 장기 목표는 강제적인 일과보다 함께 만든 장소와 기록이다. 성채 방어 기록, 첫 보스 격파 기념물, 길드 탐험 도감, 사진 촬영 공간을 둔다.

## 16 던전과 최종 콘텐츠

본편의 마지막 전투로 이야기를 완결하고, 결말 이후에는 새 서약망이 아직 불안정한 지역을 안정시키는 활동으로 연결한다. 엔드게임에 들어가야 본편의 진짜 결말을 볼 수 있게 하지 않는다.

| 콘텐츠 | 구성 | 주요 보상과 목적 |
| --- | --- | --- |
| 지역 던전 | 1~4인, 탐험과 2~3회 주요 전투 | 장비 기반, 지역 이야기, 제작 재료 |
| 심층 던전 | 적 조합·경로·환경 변수가 바뀌는 원정 | 다양한 빌드와 반복 공략 |
| 균열 원정 | 여러 지역의 규칙이 섞이는 15~25분 임무 | 유물 변형과 서약망 복원 |
| 8인 레이드 | 3~4개 주요 전투와 협력 기믹 | 고유 외형·유물·칭호·협동 성취 |
| 왕좌 수호전 | 병력 편성·영웅 출격·포탈 차단 | 전술 조합과 길드 협력 |
| 보스 추적 | 필드 단서로 강적을 찾는 임무 | 목표 제작 재료와 몬스터 도감 |
| 수호자의 시험 | 솔로 전투·직업별 기량 도전 | 직업 외형과 숙련 증명 |
| 세계 이벤트 | 여러 플레이어가 지역 문제를 해결 | 지역 변화, 공동 장식, 탐험 보상 |

완성상은 주요 지역 던전 6개, 본편 이후 레이드 3개, 직업별 시험과 동료 이야기, 재구성 가능한 균열 원정을 포함한다. 각 던전은 전투 외에도 고유한 공간 경험을 갖는다.

첫 레이드 **The Hollow Cathedral**은 묘지와 성직자의 과거를 확장하며, 치유가 오염으로 바뀌는 장치를 해제한다. 두 번째 **Heart of the Caldera**는 거대 화산 생명체의 몸과 용광로 설비를 오가는 전투다. 세 번째 **The Starless Court**는 왕이 열어 둔 균열 너머의 존재와 마주하며 다음 장편 확장으로 이어진다.

보스전의 기본 도전에서는 연습과 학습을 지원하고, 최고 난도에서는 역할 전환·자원 관리·파티 연계를 요구한다. 높은 난도의 보상은 힘의 차이를 무한히 키우기보다 특수 조합·외형·명예를 강화한다.

## 17 선택형 대전

대전은 세계 탐험과 스토리의 필수 경로에서 분리한다. 결투장과 3대3 경기에서는 장비 능력치를 보정하고, 직업과 조작의 상성을 중심으로 겨룬다. PvE와 PvP의 기술 계수는 별도로 조정한다.

길드 간 성채 전술전은 확장 콘텐츠로 설계한다. 참여하지 않아도 지역 자원이나 본편 접근권을 잃지 않으며, 특정 길드가 일반 필드를 독점하거나 새 플레이어를 반복 처치하는 구조를 두지 않는다.

## 18 화면과 조작

전투 화면의 우선순위는 캐릭터와 위험 신호, 현재 목표, 생존 상태, 스킬과 동료 명령이다. 퀘스트 목록·보상 알림·수집 정보는 전투를 가리지 않는 위치와 빈도로 표시한다.

모바일은 이동 조이스틱, 기본 공격, 회피, 액티브 3개, 궁극기를 중심으로 구성한다. 동료 명령은 상황 버튼과 길게 누르는 선택 메뉴로 묶고, 탈것·상호작용·전리품 버튼은 상황에 따라 교체한다. 중요한 스킬 여러 개를 동시에 정밀 조준해야만 하는 직업 설계는 피한다.

PC·게임패드는 직접 조준과 표적 고정을 모두 지원한다. 입력 장치를 바꾸면 버튼 안내만 전환하고 현재 선택과 메뉴 상태는 보존한다. 자막, 대화 기록, 글자 크기, 색상 외 위험 표시, 카메라 흔들림 감소, 이펙트 강도, 반복 입력 완화 옵션을 제공한다.

장비 화면은 ‘현재보다 무엇이 달라지는가’를 먼저 보여준다. 공격력 수치만으로 실제 조합을 설명하지 않고, 기술 효과와 조건을 함께 비교한다. 퀘스트 화면은 지금의 목표와 관련 인물·장소를 연결하고, 원하면 상세 일지를 읽을 수 있게 한다.

## 19 미술과 음악

기존의 기사 은청, 엘프 녹색, 드워프 갈색·주황, 성녀 백금, 마법사의 원소색을 이어받는다. 캐릭터는 성인 비례와 역할이 읽히는 실루엣을 갖추고, 금속·천·목재·돌·마력의 재질을 구분한다.

분위기는 아름답지만 위험한 판타지다. 숲은 생명과 오염, 설원은 고요와 상실, 화산은 노동과 분노, 묘지는 공포와 애도, 부유 도시는 경이와 오만을 표현한다. 어둠을 보여주더라도 지나친 암부와 발광으로 이동 경로나 공격 예고를 숨기지 않는다.

왕좌의 음악 동기는 처음에는 장엄한 선율로 등장하고, 진실을 알아갈수록 불협화음과 빠진 음이 드러난다. 마지막에는 다섯 문명의 악기가 같은 동기를 나눠 연주한다. 동료별 짧은 주제와 성채의 단계별 편곡으로 관계와 세계의 변화를 들려준다.

보스의 큰 공격은 소리만으로도 대비할 수 있는 신호를 갖되, 음소거 상태에서도 시각적으로 읽을 수 있어야 한다. 대화 음성은 핵심 장면과 주요 동료를 우선하며, 모든 대사에는 읽기 가능한 자막과 기록을 제공한다.

## 20 운영과 수익 모델

수익 상품은 캐릭터·무기·탈것 외형, 거처와 길드 장식, 감정 표현, 사진 연출을 중심으로 설계한다. 가장 멋진 외형 중 일부는 이야기와 도전에서 얻어 세계 안의 성취가 보이게 한다.

직업·본편 결말·필수 전투 기술·최고 성능 장비·전투 도중의 유료 부활을 구매 압력으로 만들지 않는다. 확률형 유료 장비 뽑기는 기본안에 포함하지 않는다. 상품이 전투 읽기와 직업 실루엣을 해치지 않는지도 검토한다.

시즌은 선택형 지역 사건과 외형 목표를 제공한다. 주요 스토리는 기간 종료로 사라지지 않게 기록 보관소에 남긴다. 이전 시즌에 참여하지 않은 신규 플레이어도 본편과 현재 이야기의 관계를 이해할 수 있어야 한다.

대형 확장은 새 지역·갈등·던전·직업 전문화를 통해 세계를 넓힌다. 만렙과 장비 수치만 올리는 업데이트를 반복하지 않는다. 첫 확장 후보는 바다 건너 봉인되지 않은 문명을 다루는 **Beyond the Last Gate**다. 이들은 왕좌가 필요 없던 사회이며, 본편에서 세운 새 질서를 다른 관점으로 시험한다.

## 21 기술과 제작 원칙

새 RPG는 독립 프로젝트로 만든다. 기존 Throne Defense의 게시본·저장 데이터·성장·상품을 변경하는 작업으로 취급하지 않는다. 새 게임의 저장 스키마, 재화, 결제, 텔레포트, 복구 계약을 별도로 정의한다.

서버가 피해·회복·쿨다운·아이템 생성·장비 장착·보상·거래·구매를 검증한다. 클라이언트는 조작과 빠른 시각 반응을 제공하고, 서버 확정 상태에 맞춰 정합성을 유지한다. 희귀 아이템·퀘스트 완료·결제는 재접속과 중복 요청에도 한 번만 적용되게 설계한다.

지역은 스트리밍과 서버 이동을 고려해 구성하고, 던전과 레이드는 인스턴스로 분리한다. 동료·소환수·보스·다수 적이 동시에 움직이는 장면을 기준으로 AI와 이펙트 예산을 세운다. 목표는 선정한 모바일 기준 기기에서 일반 전투 30FPS 이상, PC 기준 환경에서 60FPS 이상이며 실제 기종·설정·부하별로 검증한다.

기존 모델은 외형 참고·재사용 후보로 분류한다. 캐릭터 리깅, 이동·피격·회피 애니메이션, 근접 카메라 품질, 충돌과 성능을 새 RPG 기준으로 검사한다. 새로 업로드하거나 재업로드하는 에셋은 사용자 개인 소유·비공개 원칙과 경험에 필요한 최소 권한을 따른다.

## 22 전체 제작 순서와 완료 기준

전체 이야기를 먼저 확정하고, 각 시스템이 최종 전투와 세계 경험에 어떻게 쓰이는지 설계한다. 제작 순서는 전체 완성상을 구현하기 위한 의존성에 따라 정한다. 아래 단계는 이야기나 최종 콘텐츠를 축소하는 목록이 아니다.

| 단계 | 주요 산출물 | 다음 단계로 넘어갈 조건 |
| --- | --- | --- |
| 세계와 서사 확정 | 전체 사건표, 인물 관계, 장별 임무, 선택 결과, 결말 | 동료·지역 갈등이 최종전에 연결되고 주요 설정 충돌이 해소됨 |
| 조작과 전투 확립 | 이동·공격·피격·방어·카메라·적 행동·파티 기본 구조 | 근접·원거리·지원 직업이 PC와 모바일에서 명확히 읽히고 조작됨 |
| 공통 RPG 기반 | 저장·장비·성장·퀘스트·동료·전리품·서버 이동 | 정상 진행과 실패·재접속·중복 요청의 정합성을 검증함 |
| 본편 전체 제작 | 프롤로그부터 에필로그까지 모든 지역과 장면 | 처음부터 결말까지 단절 없이 플레이하고 각 장의 고유 경험을 확인함 |
| 최종 콘텐츠 제작 | 던전·레이드·균열·길드·생활·직업 시험 | 보상과 경제가 연결되고 솔로·파티 각각의 도전이 성립함 |
| 통합 완성도 개선 | 미술·음향·조작·접근성·성능·밸런스 | 지정 기기와 실제 신규 플레이어의 전체 여정에서 출시 기준을 충족함 |
| 운영 준비 | 고객지원·복구·지표·업데이트·롤백 | 데이터와 상품의 복구 가능성 및 실제 운영 책임이 확인됨 |

PM은 세계와 시스템의 의존성과 수용조건을 관리한다. 시나리오·퀘스트 설계, 전투·성장 설계, UI 설계, 엔지니어링, 캐릭터·환경·애니메이션·음향, QA의 책임을 구분한다. 실제 제작 인력과 도구의 처리량을 확인한 뒤 일정을 산정한다.

## 23 품질을 판단할 기준

| 영역 | 플레이와 검증에서 확인할 것 |
| --- | --- |
| 첫 경험 | 도움 없이 이동·전투·회피·장비 변경·첫 구조 임무를 이해한다 |
| 이야기 | 각 장을 마친 플레이어가 지역의 문제와 자신이 한 선택을 설명할 수 있다 |
| 동료 | 능력치 외의 이유로 기억하고 함께 가고 싶은 동료가 생긴다 |
| 전투 | 보스에게 패배한 이유와 다음 시도에서 바꿀 행동을 말할 수 있다 |
| 성장 | 서로 다른 전문화와 장비 조합이 실제 플레이 방식을 바꾼다 |
| 탐험 | 퀘스트 표식을 따라가지 않는 자발적인 탐색과 발견이 발생한다 |
| 협력 | 친구와 함께할 때 개인 행동의 의미와 서로 도운 순간이 남는다 |
| 공정성 | 같은 조건의 플레이어가 구매 없이 본편과 도전 콘텐츠를 완주할 수 있다 |
| 조작과 성능 | 실제 기기에서 위험 표시·입력·카메라·목표 프레임이 유지된다 |
| 신뢰 | 저장·거래·보상·구매·재접속에서 유실과 중복이 없고 실패를 명확히 알린다 |

평가는 콘텐츠 개수와 자동 테스트 통과 수에만 의존하지 않는다. 실제 플레이에서 어디를 기억하는지, 왜 다시 시도하는지, 다음에 무엇을 하고 싶은지 관찰한다. 초반 이해도·장별 이탈·보스 재도전·직업 선택·장비 다양성·경제 흐름·친구 동행률을 함께 확인한다.

## 24 새 프로젝트로 가져갈 기획 패키지

이 기획안을 출발점으로 새 프로젝트에서 다음 상세 문서를 연결한다. 전체 스토리와 시스템의 기준을 한 문서에 끝없이 중복하지 않고 각 문서가 담당하는 결정을 명확히 한다.

1. 세계관 설정집: 연표, 지도, 세력, 종교, 마력과 포탈의 규칙, 고유명 사전.
2. 전체 시나리오: 장별 사건표, 컷신, 대사, 개인 선택과 후일담, 동료 이야기.
3. 전투 설계서: 조작, 판정, 적 AI, 기술·상태·직업별 역할, 솔로와 협동 규칙.
4. 성장과 경제 설계서: 레벨 곡선, 장비 효과, 드롭·제작·재련, 재화 유입과 소비.
5. 월드와 퀘스트 설계서: 지역 동선, 발견, 주민 생활권, 던전·보스·세계 이벤트.
