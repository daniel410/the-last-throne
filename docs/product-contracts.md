# 현재 제품 계약

2026-11-11 기준. 관련 분야를 변경할 때만 해당 항목을 읽는다. 최신 사용자 지시 → 이 계약과 결정표의 최신 결정 → 분야 상세 사양 → 과거 제안 순으로 적용한다.

## 최근 승인

- 스토리 통행 차단은 유리벽 대신 지역 장애물로 표현하고, 해제 시 형상과 충돌을 함께 제거한다. 확장 사건 이동 표지판은 저장된 다음 필수 목표로 연결한다. [구현/검증/미검증](evidence/story-obstacles-travel-20261111/README.md).

- 본편: Deepwood → Gloamwood → Frozen Vale → Ember Caldera → Haunted Graveyard. 35본편·12선택, 전투량/몬스터/보상을 유지하며 반복 웨이브를 이동 경로 교전으로 분산한다. [동선](production/campaign-combat-routes-2026-11-10.md), [맥락](production/campaign-context-review-2026-11-10.md).
- Dawnspire: TD 전투 맵의 분홍 크리스탈 왕좌 원본을 균일2배로 재사용한다. 로비300×300, HG07 완료 영웅만 심장을 개인 복원한다. 금색 의자 해석은 폐기했다. [증거](evidence/dawnspire-crystal-throne-20261111/README.md).
- 장비 부위 수치: 무기/방패/투구·장갑/신발·상의HP/로브MP 순서로 Tempered6/4/30, Veteran15/10/50, Sentinel30/20/80. Traveler·장신구·가격/레벨·강화·보유품 유지. [증거](evidence/equipment-values-20261110/README.md).
- 마법사 모자4계열의 기본 옵션은 최대 MP다. 사용자 지정 Traveler +10, Tempered +20, Veteran +30, Sentinel +60을 적용하며 강화3%/단계를 따른다. 지력·마법 공격력·방어력은 추가하지 않고 현재 MP를 회복하지 않는다. [검증](evidence/mage-hat-mp-20261111/README.md).
- 기본 옵션1개와 별도로 선택형 `specialEffects`를 허용한다. 서버 정의 기반 피해 증감·스킬 지정·합산 상한·영어 표시를 사용하며 기존 장비에 자동 배정하지 않는다. [계약](production/equipment-special-effects-2026-11-10.md).
- 전직은 Lv20/40/60/80·자기 클래스와 선택 계열의 순차 진행만 요구하며 모험/전투 중 선택 가능하다. 거점·처치 수·시험을 요구하지 않는다. 소유권/로드/저장/중복 검사는 유지한다.
- 새 영웅은 기본 무기와 Lv1 방어구/장신구 즉시 착용. 트레이닝 무기 신규 지급/상자 선택 중단, Lv5 투구는 가방 유지. 기존 보유품/편성 소급 변경 없음.
- Selene는 해금 및 지원권 보유 시 로비부터 무료 동행하고 메인 모험 지원 시작 시1스토리권 소비. 캠프 재초대·모험 내 자동 유료 갱신 없음. 영입·최초 무료 체험·중복 소비 방지 유지.
- 인간 정원4명, AI는1/2/3/4인에 최대2/2/1/1이며 Selene 포함. 4인+AI1의 실기기/밸런스 수용은 후속.
- Blender 비교: Standard / sRGB / Look None / Exposure0 / Gamma1 / Curves Off. 새 장면·가져오기·렌더 직전 재확인. 색 텍스처 sRGB, 데이터 Non-Color, 재질은 scene-linear 입력. AgX나 임의 채도 보상으로 색 일치를 판정하지 않는다. Roblox 조명 검증은 별도.

## 유지할 제품 계약

- 플레이어는 Knight, Elf Archer, Dwarf Axe Thrower, Mage의 4클래스다. 최초 클래스는 불변이다. Priestess/Selene는 NPC·선택형 지원이며 플레이어 전직/트리를 만들지 않는다.
- 클래스별 2계열, Lv20/40/60/80 전직을 유지한다. 강철기사 이외의 상위 전직 이름과 신규 영문 번역은 가칭으로 표시한다.
- STR/DEX/INT/VIT의 스탯 포인트는 `4 × (level - 1)`, Lv80 총316이다. 스킬포인트 기준안 `level - 1`, 총79와 별도다. 기본 능력치·파생 능력치·배분 포인트를 혼용하지 않는다.
- 2026-11-05 방어 리뷰 지시: STR 투자는 방어력을 올리지 않는다. 기사·드워프가 VIT에 많이 투자해 방어력이 커지는 방향은 허용하되, 엘프·마법사가 VIT 무투자 상태에서 장비만으로 과도한 방어력을 얻지 않도록 한다. 구체 장비 효율/방어 공식은 리뷰·수치 수용 후 적용하며 이 지시 기록만으로 런타임 조정 완료로 간주하지 않는다.
- Mage는 비전/바람 훈련과 기초 물 → Lv20 Pyro/Cryo → Lv40 Pyro 대지/Cryo 번개 → Lv60 대규모 광역 → Lv80 최강 주문의 성장 방향을 지킨다.
- 공격·블록·회피·스프린트는 네 영웅 공통 액션이며 Stamina를 소비하지 않는다. 기본 공격·회피는 별도 쿨다운이 없다. Stamina는 제거한다. 물리 스킬은 기술별 쿨다운, 마법 스킬은 MP와 기술별 쿨다운을 사용한다. 0.18.8 시험 런타임에서 Stamina를 제거했으며 정식 밸런스/실기기 수용은 후속이다. 엘프 마법궁수는 첫 전직 시 마법용 MP를 추가한다.
- 2026-11-05 최신 후속 지시로 HP 자연 회복은 제거하고 MP 자연 회복은 복구한다. MP는 시전 후1초부터 기본0.15%/초·Mage/마법궁수2배(0.30%/초), MP 없는 클래스에는 새 자원을 만들지 않는다. 물약·Selene/스킬 회복과 레벨업/최초 스폰 전회복은 별도다. 2026-11-06 최신 사용자 확인으로 무료 물약·추가 장비 키트·재료 보급은 영웅마다 최초 생성 때1회씩 지급하며 미수령 추가HP5개 지급은 중단한다. 후속 영웅의 기본 무기/기사 방패와 기존 보유 아이템·획득한 퀘스트 보상은 유지한다.
- 클래스별 선택 계열의 최신 설계는 기존 기본3개+Lv20 이전 새 공통3개·추가 계열 액티브12개·궁극기1개, 총19개다. 0.31.0 시험 구현은 Lv5/10/15에 새 공통 기술을 무료 해금하며 기존 편성은 덮어쓰지 않는다. 수치·상세 효과의 최종 밸런스/실기기 수용은 남아 있다. Lv15 궁극기는 없으며 Lv80 전직 완료 시 계열 궁극기1개를 해금한다. 궁극기는 일반 스킬1~5와 별도의 전용 버튼으로 사용한다. 0.31.0의 전용 입력은 T / D-Pad Up / 터치이며 Lv80 최종 전직으로 해금되기 전에는 버튼을 숨긴다. 최종 입력/위치 수용은 후속이다.
- 전투용 스킬 편성은 Lv1에3개, Lv5에4개, Lv10에5개다. 4/5번 슬롯은 전직과 무관하게 레벨로 개방한다. 스킬 학습·계열 자격과 슬롯 개방은 별개다. 스킬 키 1~5와 액션 Q/E/R 방향을 따르며 궁극기는 별도 전용 버튼을 추가하고 단축키·위치와 액션별 최종 배치는 미정이다. 0.12.0에서 이 최신 계약이 모두 구현됐다고 간주하지 않는다.
- 현재 기본 장착 무기는 기사 검·방패, 드워프 도끼, 엘프 활·화살, 마법사 지팡이다. 드워프는 Lv20 Gunner 전직 후 총·폭탄·포격 스킬을 사용한다. 총의 독립 장착 무기와 다른 무기 유형은 이후 확장 대상으로 남긴다.
- 첫 제작·전투 검증 지역은 Deepwood다. 첫 구현은 기사 K0 기본기다. Dawnspire는 프롤로그/거점이다.
- 프롤로그4구간과 에픽1~4의28스토리 보상 정본은 [story-reward-budget.json](../assets/balance/story-reward-budget.json)이다. 승인 XP를 목표에 맞춰 임의 재계산하지 않는다.
- 2026-11-07 최신 사용자 지시로 강화 시도 비용은 단계와 무관하게50Gold고정이다. 이전25Gold를 대체한다. 성공/실패 모두1회 소비하며 재료/확률/실패 시 단계 유지 계약을 보존한다. Gold 소비는 강화 재료 교환에도 연결한다. 2026-11-07 사용자 재확인으로 보석 구매는50Gold→1개로 확정, 마석보석5개+50Gold→1개는 기존 교환 유지이며 Diamonds와 구분한다.
- 2026-11-07 사용자 지시로 Soft Hide(담요처럼 보이는 가죽)는 신규 지급을 중단하고 기존 보유분도 계정 로드 시 전부 제거한다. 영웅 최초 Iron Ore 지급은24→10개로 줄이며 이미 보유한 광석/다른 아이템/재화는 유지한다. 과거 Soft Hide 보유품 보존 문구보다 이 삭제 지시가 우선한다.
- 장비는8슬롯이다. 최신 UX는 가방 진입 통합·모든 장비 슬롯 자동 지정·거점 창고·미수령 배지다. 2026-11-05 사용자 지시로 장신구1/2 선택을 제거한다. 동일 고유그룹 교체→빈 슬롯1/2→모두 찼으면1번 교체 순서로 자동 지정하고 교체 대상/능력치를 미리 보여 준다. 용량60/120·스택99/999는 제안이다.
- 스탯/스킬 리셋권과 실제 성능 장비 판매는 최신 사용자 요구다. 외형 전용 판매나 상시 무료 초기화로 되돌리지 않는다. 가격·성능·실상품ID·무료 획득 세부는 설계/검증 대상으로 구분한다.
- 일반 모험1~4인·솔로 본편 완결을 지향한다. 일반4인 파티에도 전투AI동료를 허용하며 현재 파티 전체 최대1명, 성녀도 동료 슬롯을 사용한다. 후반8인 레이드는 별도 성능/공략 게이트다.
- The Last Throne은 TD와 분리된 Roblox Experience다. TD의 기존 시작 Place·잔액·구매권·성장은 변경하지 않는다. 공통 Diamonds는 별도 서버 권위 지갑과 권리 조정이 검증되기 전까지 공유하지 않으며, TD Gold / RPG Gold(구 Coins) / 임무 Command Points는 항상 구분한다. 2026-10-30 사용자 지시로 RPG 계정 Gold·Diamonds와 로비 무기 상점을 도입하며 TD 잔액/권리는 자동 공유하지 않는다.

## 원본과 구현 상태

- **2026-11-01 UI 지시:** UI 구현과 미리보기에는 항상 승인된 TD 공통 룩앤필(원본 프레임·버튼·아이콘·영웅 초상)을 적용한다. 로비·배틀 기본 메뉴와 아이콘의 기존 이미지·배치·기능은 유지하며, 상세 메뉴 화면만 데스크톱/모바일 가로에 맞게 구분한다. 예외로 로비 왼쪽 아이콘의 크기는 TD 현재 소스의 실제 크기 규칙과 동일하게 맞춘다. 단순 와이어프레임을 최종 미리보기처럼 제시하지 않는다.
- UI는 [승인 v2](../assets/concepts/2026-10-27-shared-ui-v2/approved-baseline.json)의9개 파일을 비교 기준으로 쓴다. 생성 이미지의 글자/수치를 런타임 데이터나 최종 영어 문구로 추출하지 않는다.
- TD 원본은 [공유 레지스트리](../assets/shared/td-asset-registry.json)에서 찾고 현재 해시·버전·사용 권한·적합성을 확인한다. 게임 직업을 기존 타워 모델에 맞춰 변경하지 않는다.
- 영웅5·타워30·몬스터40은 카탈로그/후보 수다. RPG용 리그·애니메이션·AI가 완성된 수로 보고하지 않는다.
- 문서/JSON/SVG/HTML 컨셉, 정적 검사, Studio 실행, 게시된 테스트 클라이언트, 실기기, 사용자 관찰의 증거를 구분한다. 직접 확인하지 않은 항목은 미검증으로 남긴다.
- 현재 계획 작업은 TD 운영 코드·라이브 DataStore·상품·Place 게시를 변경하는 작업이 아니다. 구현 요청을 받으면 해당 범위와 기존 승인을 적용한다.
