# Deepwood 선택 이야기 DW-S3 · 붉은 전쟁터의 잔당

2026-10-29 · TLT-061 설계 초안 · [에픽 전체](epic-01-deepwood-story.md) · [지역 설계](deepwood-region-design.md)

## 이야기와 진입

DW-07 지역 결말을 마친 뒤 점령 유적에서 붉은 전쟁터로 이어지는 선택 의뢰가 열린다. 구조된 정찰병은 제단이 무너진 뒤에도 잔당의 지휘관이 부하를 모아 귀환로를 위협한다고 보고한다. Enraged Warlord는 DW-05에서 쓰러진 Orc Warlord와 **다른 인물**인 잔당 지휘관이다. 지역을 지배한 주술이 모두 사라졌거나 이 지휘관의 행동이 전부 주술 때문이라고 단정하지 않는다.

## 진행과 교전

안전 입구 → Orc Warrior 잔당과 정찰병 흔적 확인 → 위험 지역에서 주민 귀환로 확보 → 보스 전 안전 지점 → Enraged Warlord 대결 → 거점 보고. 주민을 공격받는 전장에 실시간 호위하지 않는다. 일반 군벌이 가르친 휘두르기와 돌진을 더 긴 연속 패턴으로 응용하되 공격 전후 안전한 회피/반격 창을 남긴다. 광폭 상태는 색상만이 아니라 몸짓·음향·아이콘으로 알린다. 체력 구간·속도·피해·지원 병력은 테스트 전 미확정이며 반복 증원/보상 파밍을 만들지 않는다.

제압 후 안전해진 귀환로와 잔당의 기록을 보고한다. 지역 결말에서 선택한 복원 결과는 보존하며 이 의뢰가 두 선택의 필수 성능 격차를 만들지 않는다. TD의 `warlord`/`enraged` 변형과 전용 시각 키를 후보로 확인하되 RPG용 모션과 적합성은 따로 검증한다.

## 완료 조건 · DW-Q4

- 시작: DW-07 지역 결말 후 정찰병 의뢰를 수락한다.
- 필수: 정찰병 흔적과 잔당 활동을 조사하고 **Enraged Warlord를 격파**한다. 이후 안전 지점에서 귀환로를 확인하고 DW-03 정찰병에게 보고하면 완료한다.
- 불필요: 모든 Orc Warrior 처치, 주민 실시간 호위, 시간 제한, 특정 클래스나 동료.
- 보스 승리 후 끊기면 재격파 없이 미완료 귀환로 확인 또는 보고부터 재개한다. 승리만으로 완료/보상을 확정하지 않는다.

## 공통 진행·보상·검증

이 의뢰는 메인 진행·봉인핵·전직·필수 장비의 선행 조건이 아니다. 네 클래스 솔로·동료 0과 1~4인으로 해결 가능하며 특정 원소·완벽 방어·동시 조작을 요구하지 않는다. 파티의 현장 목표와 개인 선행/완료/보상 자격을 분리한다. 완료된 구조·조사는 저장하고 전멸 시 미완료 교전만 초기화한다. 보스 승리 후 끊기면 미완료 필수 목표 또는 보고부터 이어간다. 보상 후보는 탐험 기록과 제작 재료이며 종류·수량·XP·Coins·반복 보상은 미정이다. 초회/반복/처치 수령을 구분하고 재접속·중복 요청으로 이중 지급하지 않는다. 기존 승인 32구간 XP·Coins와 필수 처치 예산에는 포함하지 않는다.

실제 적 리그·모션·AI·보상·저장은 구현 전이다. 원본 사용 권한·해시·모델 적합성, 보스 예고와 카메라, 솔로/4인, 재시도/접속 복구 및 중복 지급을 검증한다. 아래 행동과 이름은 RPG 제작 초안이며 TD 수치나 동작을 그대로 이식한다는 뜻이 아니다. 게임 목표와 대사는 별도 en-US 원문으로 작성한다.
