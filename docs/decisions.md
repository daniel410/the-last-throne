# 현재 기획 결정과 미확정 항목

기준일: 2026-10-28, America/Toronto · 문서 묶음 v0.25 · 상태: 기획·제작 준비

이 문서는 지금까지의 사용자 결정과 채택한 설계 방향을 정리한다. 상세 전투 수치나 가칭을 사용자 확정 사양으로 취급하지 않는다. 제품 전체는 [개발 기획안](game-design.md), 전체 이야기는 [통합 제안서](../the-last-throne-rpg-proposal.md)를 따른다.

| 드워프 계열 | 강철 / 화약 |

| 마법사 Lv20 | Pyromancer 화염술사 / Cryomancer 냉기술사 선택 |
| 마법사 Lv40 | Pyro는 대지 마법, Cryo는 번개 마법 추가 |

명궁은 속사뿐 아니라 저격·치명타·약점 공략을 포괄한다. 마법궁수는 활과 화살을 매개로 마법을 사용한다. 이 계열명과 속성 명칭은 다른 클래스의 기술 습득 권리를 뜻하지 않는다.

## 4. 아직 정하지 않은 항목

- 강철기사 이외의 상위 전직 명칭, 성녀/교단NPC의 기술 수치·합류 시점·지원AI 상세.
- 기본 스탯 초기값·스탯별 투자 상한·기본 성장 곡선·전투 능력치 계산식과 공통 MP/기존 클래스 자원의 통합 정책.
- 별도 캐릭터 슬롯 수와 RPG 캐릭터 사이의 스토리·제작 기록 공유 범위.
- 마법의 세부 주문명·소규모/대규모 범위·추가 속성·학파 심화 트리.
- 기사 일부 기술/노드는 실험값을 작성했으며 실제 밸런스는 미검증. 나머지 스킬 노드의 효과/계수, 장비/XP/드롭/Coins·Diamonds 수급 곡선.
- 실제 Experience/Place ID, 공통 데이터 키·버전, TD 기존 writer의 감사와 이관 절차.
- 공개 버전의 제공 콘텐츠·출시일·인력·일정·예산.

## 5. 용어와 문서 우선순위

| 용어 | 의미 |
| --- | --- |
| 기본 스탯 | 힘·민첩·지력·체력. 체력 VIT는 현재 생명력 HP와 구분 |
| 전투 능력치 | 기본 스탯·장비·트리·효과로 계산하는 공격력·방어력·공격속도 등 |
| 클래스 | 캐릭터의 고정 원형. 기사·엘프·드워프·마법사 |
| 전직 계열 | Lv20에 고르는 두 성장 방향. 명궁/마법궁수 같은 직업적 정체성 |
| 전직 단계 | 선택 계열 안의20/40/60/80레벨 성장 |
| 마법 속성 | 화염·빙결·물·바람·대지·번개 등 주문의 성질 |
| 학파 | 원소/비전처럼 마법을 분류하는 상위 체계 |
| 기술 형태 | 투사체·결계·장판·제어·이동 등 시전 방식 |
| 성녀/지원 동료 | 플레이어 클래스가 아닌 서사 인물·선택형AI동료·임무 지원 역할 |
| 타워 | TD의 기존 방어 유닛. RPG에서는 적합한 자산/인물/지원 용도로 활용 |

최신 사용자 결정이 먼저다. 문서에서는 이 결정표를 기준으로 충돌을 확인하고, 각 분야의 세부 사양은 담당 상세 문서에 모은다. 초기 원안·과거 변경 이력·외부 참고 자료는 현재 결정과 구분한다. 새 결정을 반영할 때에는 관련 상세 문서와 [변경 이력](CHANGELOG.md)을 함께 갱신한다.

## v0.17 Deepwood 시나리오 저장

사용자가 전체 에픽 줄거리 저장과 나머지6개 시나리오 작성을 승인했다. [에픽 제작 기준](epic-01-deepwood-story.md)에 일곱 주동선·봉인핵 기록·개인 복원 선택·Frozen Vale 연결을 보존한다. 스토리2~7의 지도/동선·몬스터·사건·성공·복구·보상·협동 상세안을 작성했다.

새 세부 대사·적/장치 수·레벨·보상은 검증 전 초안이다. 감시탑 후 에린 전용 신뢰 퀘스트 영입은 제안이며 확정 영입 시점이나 필수 소비 아이템으로 취급하지 않는다. 최종 포로 구조는 선택, 두 결말은 필수 성능 보상과 다음 에픽 진입에서 동등하다. 주동선 경험치만으로 다음 구간의 추천 하한에 도달하도록 후속 밸런스를 맞춘다.

사용자 요구로 Deepwood 스토리별 안전 스타트 포인트7개와 재시작/리조인 지원을 확정했다. [공간/복구 설계](deepwood-map-design.md#8-스토리-스타트-포인트--재시작리조인)에 처음부터/이어하기/파티 재합류를 구분한다. 구체 좌표·마당 크기·유예 시간·저장 구현은 검증 전이다.

## 2026-10-28 기존 TD 몬스터·Meshy 백업 우선 사용 재확인

사용자는 고블린·슬라임·오우거와 Meshy 원본 백업이 이미 있음을 지적했다. 기존 원본을 먼저 찾아 재사용하고 RPG의 판정·움직임 어댑터를 연결한다. 원본 리그가 다르다는 이유만으로 기본 도형의 신규 외형을 장기간 유지하지 않는다. 이번 채택 파일·해시·보존 위치는 [몬스터 원본 기록](evidence/k0/td-monster-sources.md)에 남긴다. 기존 K0 교전 대상은 Goblin/Ogre 두 종을 유지하며, Slime는 원본 보존·어댑터·로딩 검증까지 연결한다. 슬라임 분열 전투는 별도 구현이다.

같은 날 사용자가 오크 추가를 요청해 K0에 TD 원본 일반 **Orc Warrior**를 세 번째 교전 대상으로 연결했다. [오크 연결 기록](evidence/k0/orc-integration.md)의 값은 시험 프리셋이며, Orc Warlord 보스와 장갑·측후면 전용 전투를 완료한 것으로 취급하지 않는다. 위 두 종 범위는 이전 시점의 기록이다.

## 2026-10-28 플레이어 기본 무기·근접 기본 공격

사용자는 Knight에 TD Swordsman 철검·철방패, Dwarf Axe Thrower에 TD 도끼, Elf Archer에 TD 활을 요청했다. Mage의 입문 무기는 새 나무 지팡이로 제작한다. 원본의 해시·파생·실제 장착과 권한 검증을 구분한다.

사용자는 이어 **드워프와 마법사의 기본 공격을 손에 든 도끼와 지팡이를 직접 휘두르는 근접 공격**으로 지정했다. 도끼 투척·마법 사용은 별도 기술로 설계할 수 있지만 기본 공격으로 대체하지 않는다. 시험용 공격 수치와 당시 0.4.0의 Knight 중심 실행 범위는 사용자 승인된 최종 밸런스나 네 직업의 출시 완료를 뜻하지 않는다.

## 2026-10-28 네 영웅 시험 로비

사용자는 간단한 기본 로비, 네 영웅을 바탕으로 한 새 영웅 생성과 튜토리얼 시작 버튼을 요청했다. 네 직업을 시험할 수 있도록 한 세션에서 영웅을 생성·선택하고 로비로 돌아와 다른 영웅을 시험한다. 영웅별 최초 직업 불변 계약은 유지한다. 이번 시험판의 세션 전용 영웅과 직업당 1명 제한은 구현 범위이며, 정식 캐릭터 저장·계정 슬롯 정책의 확정이 아니다.


## 2026-10-28 튜토리얼 전투 피드백

사용자는 튜토리얼 슬라임, 오크보다 확실히 큰 오우거, 네 직업의 무기 동작과 공격 효과, TD를 참고한 작은 몬스터 머리 위 체력 바를 요청했다. 기사의 검은 칼끝이 앞으로 뻗어 휘둘러지고 방어 시 방패의 넓은 면이 정면을 향한다. 바는 적이 죽으면 사라진다. 마법사는 지팡이 근접 기본 공격을 유지하며 별도 시험용 Arcane Bolt를 사용한다. 수치·모션과 이 스킬은 정식 성장 트리의 확정이 아니며, 슬라임 분열은 별도다. [구현과 검증](evidence/k0/combat-feedback.md).


## 2026-10-28 원거리 표적과 기사 무기 가시성

사용자는 기사의 검·방패가 보이지 않는 문제, 엘프의 활 높이와 얼굴 앞 활시위 손 위치, 엘프와 마법사의 클릭 표적 발사를 요청했다. 원본 메시가 클라이언트에서 로드되지 않을 때는 로컬 대체 외형을 사용하고 원본이 로드되면 복원한다. 엘프는 적 클릭으로 선택·발사하고 마법사는 적 클릭 후 Q/마법 버튼으로 시전한다. 목표·사거리·장애물·피해는 서버가 검사한다. [검증](evidence/k0/targeted-combat.md).

2026-10-28 추가 요청: 엘프 활시위는 대기 중 풀고 왼손이 올라가는 준비 시간에 맞춰 당긴 뒤 발사 시 놓는다. 게임의 마법 사용 동작 용어는 **Cast**로 통일한다.

2026-10-28 추가 요청: 엘프는 활을 왼손에 들고 오른손으로 시위를 당긴다. 발사 동작의 손 배치와 시위 타이밍을 함께 검증한다.


## 2026-10-28 — 슬라임 분열·피격 인식과 엘프 발사 자세

사용자 요청에 따라 튜토리얼 슬라임은 처치 시 원본 크기의 절반, 부모 최대 체력의 4분의 1인 작은 슬라임 두 마리로 한 번 분열한다. 작은 슬라임이 모두 사라진 뒤 부모 재생성을 시작한다. 모든 적은 유효한 피격을 받으면 공격자를 즉시 인식하며 기존 귀환 범위는 유지한다. 엘프 발사 자세는 활을 잡은 왼팔을 높이고 시위를 당기는 오른손을 활시위 가운데 높이로 낮춘다. 세부 검증과 미검증은 [작업 기록](evidence/k0/slime-awareness-bow.md)을 따른다.
