# 현재 기획 결정과 미확정 항목

## 2026-10-30 — 지상 Deepwood·열린 길·밝은 낮

사용자는 맵 밖 낙하/바닥 아래 카메라와 공중 지형을 고치고 원경을 제한하도록 요청했다. 이어 좁은 다리의 벽과 어두운 안개를 거부했다. 최신 구현은 **중앙24/전체96studs의 열린 지상길·양옆 흙 경사·길 벽/난간0·밝은 낮·180~340studs 먼 배경만 옅은 하늘색 처리**다. 지역 외곽 자연 경계와 서버의 개인 선행/실제 지면 검사·안전 위치 복구를 유지한다. 기존6~18studs 줌에 살아 있는 모험 카메라의22~72도 기본 회전/충돌 보정을 추가한다. 복구로 HP/MP/보상을 변경하지 않는다. 수치/미술/성능은0.39.0 시험 구현이며 실제 전체 완주/실기기 수용과 구분한다. [조사](research/2026-10-30-grounded-deepwood.md) · [증거](evidence/deepwood/grounded-0390/README.md). 미게시다.

## 2026-10-30 — 전체 지도 시각 개선·Mage 마법/MP 회복 강화

사용자 첨부 화면과 요청을 근거로 지역명·스토리/개인 해금은 유지하고 전체 지도 표현과 탐색을 개선한다. 공격 주문 계수40%·MP 자연 회복50% 상향은 요청을 구체화한 **0.38.0 시험 수치**이며 최종 밸런스 수용과 구분한다. 기본 지팡이 공격·MP 비용/쿨다운·장벽량·HP 회복은 유지한다. 현재 공통 MP 설정으로 전직 엘프의 회복에도 적용된다. 지도는 정본 좌표의 2D 지형/랜드마크, 지역 상태·탐험률·이야기 목록, 확대/전체/내 위치를 제공한다. [조사/판단](research/2026-10-30-atlas-and-mage-balance.md) · [구현/검증](evidence/deepwood/atlas-0380/README.md). 게시된0.37.2는 변경하지 않았으며 새 게시·릴리스 태그는 별도다.

## 2026-10-30 — 0.37.2 두 RPG Place 비공개 게시

TLT-021/053/084. 사용자가 정확한 두 RPG Place에0.37.2 게시를 승인했다. 시작70829337938054는 Roblox 버전17, 전투129388473517823은 버전3으로 게시하고 Dashboard 게시 전용 이력과 Private 유지를 확인했다. 실제 클라이언트 Knight 생성→SOLO ADVENTURE→Deepwood 도착을 확인했다. 로비 전투 신호 대기 경고는 남아 있으며 영웅 생성/이동을 차단하지 않았다. 왕복·2~4인·타 로비/리조인·저장 장애·실기기 수용은 후속이다. [게시/해시/증거](evidence/release-0372/README.md). TD는 변경하지 않는다.


기준일: 2026-10-28, America/Toronto · 문서 묶음 v0.25 · 상태: 기획·제작 준비

이 문서는 지금까지의 사용자 결정과 채택한 설계 방향을 정리한다. 상세 전투 수치나 가칭을 사용자 확정 사양으로 취급하지 않는다. 제품 전체는 [개발 기획안](game-design.md), 전체 이야기는 [통합 제안서](../the-last-throne-rpg-proposal.md)를 따른다.

## 2026-10-30 — 새 RPG 전투 Place 생성과 연결

사용자는 The Last Throne에 포함 자산의 사용 권한 부여/진행을 명시적으로 승인했다. 직접 새 Place 저장 경로로 **The Last Throne Battles129388473517823**을 같은 Experience10773575153에 생성했다. 최대4명·Secure within Universe only를 저장/재확인하고0.37.2의 ExpeditionConfig에 연결했다. 임시 Studio API 접근은 OFF다. 로비20·전투4 빌드와 네이티브10/132/13개 통과를 실제 게시/클라이언트 수용과 구분한다. 두 Place 실제 게시 클릭이 자동 승인 검토에서 별도 명시적 승인 부족으로 거부되어 사용자에게 정확한 두 ID와 버전으로 승인을 요청했다. [과정/검증](evidence/battle-place-provisioning/README.md).

## 2026-10-30 — 전투 Place 생성의 일시 API 접근 승인

사용자는 Studio API 접근을 전투 Place 생성 동안만 켜고 생성 후 끄는 것을 승인했다. 이어 전체 Studio 강제 종료/재시작을 요청해 RPG 창 선택을 정상화했다. RPG에서 API 접근을 잠시 켜고 Run 서버로 재시도했으나 HTTP403으로 실패했고, 즉시 OFF 저장/재열기로 복구를 확인했다. 검증된 Battle0.37.1의 Save to Roblox As → The Last Throne → Add as a new place는 자산 사용 권한 부여 경고에서 대기 중이다. 자동 승인 검토가 Grant Permissions and Publish를 별도 사용자 승인 부족으로 거부해 사용자에게 정확한 대상 Experience10773575153에 대한 승인을 요청했다. 당시 대기 후 위 후속 결정처럼 자산 사용 권한 승인을 받아 생성/저장을 확인했다. 실제0.37.2 게시 승인만 남았으며 TD 설정/Place는 변경하지 않았다. [재시도·복구 증거](evidence/battle-place-provisioning/README.md).

## 2026-10-30 — 로비 컨셉의 세 시설 구현

사용자 요청으로 원정 포탈·훈련장·대장간을0.37.1에 월드 시설로 연결했다. 포탈은 원정 선택 메뉴를 열고, 훈련장은 로비에서 선택 영웅의 기존 전투 훈련에 입장하며, 대장간은 기존 무기 구매/매각을 제공한다. 간판은 영어이며 그림의 개발 코드를 노출하지 않는다. 대장간 제작/강화·컨셉 전체 왕성·새 전투 Place 배포까지 완료한 것은 아니다. [배치/원천](research/2026-10-30-dawnspire-facilities.md) · [검증/제한](evidence/lobby-landmarks-0370/README.md).

## 2026-10-30 — Gold/Diamonds·로비 무기 상점·원정 서버

사용자 요청으로 RPG 일반 재화 표시를 Gold로 바꾸고 기존 Coins 금액을 보존하며 계정 지갑·Diamonds·무기 구매/판매를 도입했다. TD와 분리한 지갑이며 공통 Diamonds 조정/실제 Robux 상품 계약을 대체하지 않는다. 솔로·2~4인·20명 로비·타 로비 합류·예약 전투·리조인 경로를0.36.1에 구현했다.15분 리조인·가격/2 Diamond 지급·lease/대기 시간은 시험값이다. [실행 계약](production/lobby-economy-and-expeditions.md) · [증거](evidence/lobby-0361/README.md). 로비 최대20명 저장 확인. 사용자 답변상 기존 전투 Place가 없고 새 Place 생성의 API403 재시도/접근 OFF 복구 후 자산 사용 권한 승인 대기 중이다. ID0·미게시·실제 게시 이동/저장/다인 수용 미완료다.

## 2. 업데이트 제안서에서 반영한 연동 방향

| 항목 | 채택한 방향 |
| --- | --- |
| 게임명 | The Last Throne / 최후의 왕좌 |
| Roblox 구성 | The Last Throne은 TD와 분리된 독립 Experience, 개발 소스도 별도 |
| 진입 | 각 Experience의 Start Place를 유지. TD↔RPG는 개인 Experience 간 이동으로만 연결하며 초기 단체 이동은 제외 |
| 공통 계정 | 공통 Diamonds·명시된 공통 업적/외형/이벤트는 외부 서버 권위 계약이 검증될 때만 제공. 그 전에는 분리 |
| 보존 | 기존 TD 잔액·확인된 구매/수령 권리·진행·복구 보존 |
| 장르별 데이터 | TD 성장/전투와 RPG 클래스/장비/스토리/Coins를 구분 |
| 일반 재화 | TD Gold / RPG Gold(종전 Coins) / 임무 내 Command Points를 별도 관리. RPG Diamonds도 TD와 공유 계약 검증 전까지 별도 |

2026-10-28 최신 사용자 결정으로 같은 Experience 방향을 독립 Experience로 대체했다. 기존 TD 제안서는 공유 세계관의 참고만으로 사용한다. 자세한 계약과 도입 조건은 [Experience·지갑 연동](experience-integration.md)을 따른다. 문서에 반영한 방향이며 새 Experience 생성·게시나 운영 데이터 연동을 수행했다는 의미는 아니다.

## v0.17 Deepwood 시나리오 저장

사용자가 전체 에픽 줄거리 저장과 나머지6개 시나리오 작성을 승인했다. [에픽 제작 기준](epic-01-deepwood-story.md)에 일곱 주동선·봉인핵 기록·개인 복원 선택·Frozen Vale 연결을 보존한다. 스토리2~7의 지도/동선·몬스터·사건·성공·복구·보상·협동 상세안을 작성했다.

새 세부 대사·적/장치 수·레벨·보상은 검증 전 초안이다. 감시탑 후 에린 전용 신뢰 퀘스트 영입은 제안이며 확정 영입 시점이나 필수 소비 아이템으로 취급하지 않는다. 최종 포로 구조는 선택, 두 결말은 필수 성능 보상과 다음 에픽 진입에서 동등하다. 주동선 경험치만으로 다음 구간의 추천 하한에 도달하도록 후속 밸런스를 맞춘다.

사용자 요구로 Deepwood 스토리별 안전 스타트 포인트7개와 재시작/리조인 지원을 확정했다. [공간/복구 설계](deepwood-map-design.md#8-스토리-스타트-포인트--재시작리조인)에 처음부터/이어하기/파티 재합류를 구분한다. 구체 좌표·마당 크기·유예 시간·저장 구현은 검증 전이다.
