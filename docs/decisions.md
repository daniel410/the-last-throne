[재시도·복구 증거](evidence/battle-place-provisioning/README.md).

## 2026-10-29 기사 스킬 역할과 도발 확장 검토

## 2026-10-29 Provoke 방어 약화

사용자 결정: 기존 Provoke의 도발을 유지하고 대상 방어 약화를 추가하며 두 기사 계열의 Provoke 뿌리 스킬트리를 해당 효과로 확장한다. 별도의 충격파·도전 표식을 기본 기술에 추가하는 이전 제안은 채택하지 않는다. 실제 방어력 계산·수치·중첩·보스별 면역은 후속 설계 대상이다. K0 시험 소스에는 적 방어력 공식이 없어 기존 도발 대상의 받는 피해를 4초간 10% 늘리는 서버 시험 대체값을 사용한다. 이는 방어력 10% 감소와 동의어가 아니며 실측·최종 수치가 아니다. 트리의 파생 기술은 설계안·미구현이다. TLT-005/013/027/042/052/058.
