## 퀘스트별 완료 조건

아래 조건은 각 퀘스트의 설계 초안이다. 주민 의뢰 경로와 현장 발견 경로는 **시작 방법만 다르고 완료 조건은 같다**. 보스 격파와 보고를 별도로 확정하며, 보스 승리만으로 전체 퀘스트가 완료되지는 않는다.

| 퀘스트·시작 경로 | 보스 처치 | 그 밖의 필수 완료 조건 | 선택 조건·불필요한 것 |
| --- | --- | --- | --- |
| DW-Q1 · 현장 상자 조사 | 없음 | 상자에서 방수 기록 회수 → DW-03 도착 후 구조 주민에게 전달 | Cave Slime 처치·DW-03 이전 보고 불필요 |
| DW-Q2 · 주민 의뢰 **또는** 자루·인장 조사 | **Goblin King 필수** | 포로를 안전 지점으로 안내 → 창고 확인·물자 회수 → DW-03 주민에게 보고 | 전달 기록 조사·모든 Goblin 처치·시간 제한 호위 불필요 |
| DW-Q3 · 주민 의뢰 **또는** 경사길 도구 조사 | **King Ogre 필수** | 채석장의 장치/자재 이송 흔적 확인 → 보스 격파 후 DW-03에 조사 결과 보고 | 별도 작업 기록 조사·Cave Slime 처치 불필요. 도구는 현장 시작 경로에서만 필요 |
| DW-Q4 · 정찰병 의뢰 | **Enraged Warlord 필수** | 정찰병 흔적과 잔당 활동 조사 → 보스 격파 후 귀환로 안전 확인 → DW-03 정찰병에게 보고 | 주민의 실시간 호위·모든 Orc Warrior 처치 불필요 |

자루·인장과 도구는 현장에서 시작할 때 조사하는 시작 단서다. 주민에게 이미 의뢰를 받았다면 각각 다시 조사할 필요가 없다. Q2의 **전달 기록**, Q3의 **작업 기록**은 시작 단서 및 Q3의 필수 장치/이송 흔적과 구분되는 선택 조사다. 발견한 추가 이야기를 읽지 않아도 퀘스트 완료에 영향이 없다. Q4의 귀환로 안전 확인은 보스 승리 뒤 안전 지점에서 공통 상호작용으로 확정하는 초안이며 별도 시간 제한 호위가 아니다.

## DW-Q1 상세

상자와 수레 표식을 조사해 퀘스트를 발견한다. 주변 Cave Slime은 서식지의 생물이며 고블린 병력이 아니다. 전투 없이 접근 가능한 길에서 방수 기록을 회수하고 전초기지의 구조 주민에게 돌려준다. DW-03 도착 전 발견·회수하면 상태를 보존하고 보고 가능 시점을 안내한다. DW-01 이후에도 발견할 수 있다. 기록은 생존자의 피신을 보완하며 DW-02의 필수 단서를 대신하지 않는다. 보상 후보는 보급대 후일담과 탐험 기록이며 XP·Coins·재료는 미정이다.

## 공통 발견·진행·보상

현장 단서로 시작하는 경로는 발견 전 지도/목록에 퀘스트 위치를 표시하지 않는다. 주민이 의뢰한 경로는 안내된 목적지를 표시한다. 일단 어느 경로로 시작하든 같은 퀘스트 ID·목표·완료·보상 기록을 사용한다. 현장 단서와 주민 의뢰를 양쪽에서 접해도 별도 완료나 중복 보상을 만들지 않는다. 놓친 선택 조사 단서가 보스 격파 후 사라지거나 의뢰를 막지 않게 한다. 관련 주민 대사와 기록은 상황에 맞게 보존한다.

퀘스트는 전부 선택이다. 메인·봉인핵·전직·필수 기술/장비·결말 선행이나 승인된 32구간 성장 예산에 포함하지 않는다. Q2~Q4의 보스는 해당 숨은 퀘스트의 완료 조건이며 본편에는 필수가 아니다. Q2/Q3의 조사 단서는 추가 배경이며 보스 격파나 의뢰 수락에 필수가 아니다. 모든 퀘스트는 네 클래스 솔로·동료 0 및 1~4인에서 가능하고 특정 원소·유료 기능·동시 조작을 요구하지 않는다.

발견·필수 목표·보스 승리·보고·수령을 개인 자격과 구분해 저장하고 재접속/중복 요청에 안전하게 처리한다. 파티원이 조사했다고 현장에 없는 사람의 자격을 자동 확정하지 않는다. 재플레이와 단서 추가 조사에 따른 반복 보상·참여 범위는 미정이다. 초회 수령을 두 경로에서 각각 지급하지 않는다. 보상 종류·수량·XP·Coins는 미정이며 정본 보상을 임의 수정하지 않는다.

기획은 영어 목표·대사와 보상을 확정한다. 디자인은 단서 가독성과 접근 경로를, 엔지니어는 서버 권위 개인 진행·수령을, QA는 양쪽 시작 순서·동시 요청·재접속·보스 후 단서 접근·솔로/4인을 검증한다. 실제 지도·NPC·퀘스트·저장·보상·플레이테스트는 구현 전이다.
