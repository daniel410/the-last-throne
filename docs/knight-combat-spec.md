# 기사 전투 상세 명세와 첫 전투 실험실

문서 묶음 v0.24 · 작성일: 2026-10-27, America/Toronto · 상태: 설계 초안, K0 원형 일부 구현·검증 중

상위 규칙은 [기획 결정](decisions.md), [클래스·전직·스킬트리](class-advancement-and-skill-trees.md), [전투 공통 기준](game-design.md#9-액션-전투의-기준)을 따른다. 이 문서는 기사 전투의 조작·수치·판정·제작 단위·검증을 담당한다. **이하 기술명·키 배치·수치·판정 형태는 실험 시작값이며 사용자 확정 사양이나 플레이테스트 결과가 아니다.**


> 최신 사용자 결정: 공통 스태미나와 기본 공격·회피의 별도 쿨다운을 제거한다. 아래의 과거 스태미나 비용·방어 붕괴·회피 쿨다운 수치는 폐기되었으며 기사 자원·방어 밸런스는 재설계 대상이다. 기술별 쿨다운은 유지한다. 최신 시험 구현은 [기술 작업 기록](evidence/k0/basic-skills-mana.md)을 따른다.

## 1. 목표와 구현 범위

기사는 검으로 틈을 공략하고 방패로 다음 공격 기회를 만드는 근접 클래스다. “공격 예고를 읽었다 → 방어하거나 피했다 → 검과 기술로 되갚았다”를 첫 전투에서 경험하게 한다. 기본 공격·방어·회피는 전직과 포인트 없이 제공한다.

| 구분 | 강철기사 | 성기사 |
| --- | --- | --- |
| 핵심 판단 | 공격을 받아 낼 방향과 반격 시점, 적 자세를 무너뜨릴 순서 | 검 표식을 쌓을 대상과 소비 시점, 보호할 위치 |
| 공격 순환 | 방어/기본 연계 → 반격 기회 → 파쇄 → 노출 중 검격 | 서약검 → 표식 유지 → 여명폭발, 보호 후 재진입 |
| 방어 표현 | 금속 충돌·검/방패 반격·전선 유지 | 성광 검술·방패/서약 인장·아군 보호 |
| 솔로 수단 | 기본 검격·일반 방어만으로도 공격과 자원 수급 가능 | 자기 보호·검 표식만으로 공격과 자원 수급 가능 |

캐릭터의 `baseClassId`는 `knight`로 유지한다. 강철기사 계보는 **기사 →20 강철기사 →40 중갑기사 →60 철벽기사 →80 강철의 수호자**다. 성기사 상위 명칭은 기존 문서의 가칭을 유지한다. 성기사는 플레이어 기사 계열로 유지하고 성녀는 NPC·지원 동료로 구분한다.

처음에는 K0의 공통 기본기와 고블린/오우거를 구현한다. 이어 K1에서 공통3액티브, K2에서 두 계열을 비교한다. Lv40~80 성장·궁극기·스킬트리 수치는 후속 통합 명세이며 K0 완료 조건에 포함하지 않는다. 전체 게임의 규모와 출시 범위는 [로드맵](production-roadmap.md)을 따른다.

## 2. 공통 실험 조건과 계산 단위

| 항목 | 시작값·정의 |
| --- | --- |
| 단위 | 거리 stud, 시간 초, 각도는 전체 부채꼴 각도. 반경은 캐릭터 중심의 수평 거리 |
| 비교 캐릭터 | 체력1,000·공격력 ATK100·방어율0·스태미나100·서약 최대100·궁극기 게이지 최대100 |
| 레벨 프리셋 | Lv10 공통 / Lv28 강철기사 / Lv28 성기사. 같은 공격력·체력·노드0·장비 효과0으로 비교 |
| 수치 의미 | ATK×계수는 방어 적용 전 피해. ATK100에서1.4배는140. 자세 피해는 별도 수치 |
| 이동 | 일반 이동16, 방패 유지8. 달리기에는 스태미나를 소모하지 않음. 공격 중 이동은 기본 이동의40% |
| 판정 원칙 | 한 공격의 한 타격 구간은 대상당1회. 벽·닫힌 문·높이 차이로 차단된 대상에게 피해/표식 없음 |
| 대상 제한 | 표의 최대 대상 수는 공격별 상한. 가까운 유효 대상 우선, 동률은 고정된 대상ID 순서 |
| 체험 상태 | 운영 저장과 분리한 실험 프리셋. 시험용 레벨·장비·기술은 실제 캐릭터에 지급하지 않음 |

체력 피해의 순서는 `ATK×계수 → 대상 방어율 → 기술 피해 감소 → 방패 방어 → 보호막 → 체력`이다. 실험 방어율은0이며, 방어율 상한60%를 가정한다. 같은 종류의 피해 감소는 가장 큰 값 하나만 적용하고, 서로 다른 기술의 감소를 곱하더라도 이 단계의 감소 상한은60%다. 방패의80% 경감은 그 뒤 별도로 적용하며, 무적과 완벽 방어도 별도 판정이다. 소수 계산 후 최종 체력 피해를 반올림하며 유효 적중의 최소 피해는1이다.

회피 무적이면 피해·자세 피해·피격 상태를 적용하지 않는다. 이어 방패 방향/공격 방어 가능 여부를 확인한다. 보호막은 남은 체력 피해만 흡수하며 방패의 스태미나 비용을 대신 내지 않는다. 자세 피해는 체력 방어율과 분리한다. 후속 장비·노드는 이 계산의 적용 단계와 상한을 명시해야 한다.

## 3. 입력·카메라·터치 조작

| 행동 | PC 기본 배치 제안 | 게임패드 제안 | 터치 |
| --- | --- | --- | --- |
| 이동·카메라 | WASD·마우스 | 왼쪽/오른쪽 스틱 | 왼쪽 이동·오른쪽 빈 공간 드래그 |
| 기본 공격 | 마우스 왼쪽, 홀드 연격 옵션 | RT, 홀드 옵션 | 큰 공격 버튼, 홀드 옵션 |
| 방패 | 마우스 오른쪽 홀드 | LT 홀드 | 방어 버튼 홀드 또는 설정에서 켜기/끄기 방식 |
| 회피 | Space | B / Circle | 방어와 분리한 회피 버튼 |
| 액티브1/2/3 | Q / E / R | RB+X / Y / B | 번호가 고정된3버튼 |
| 궁극기 | F | RB+A | 게이지가 찬 독립 버튼 |
| 표적 고정 | 마우스 가운데 | 오른쪽 스틱 누름 | 잠금 버튼, 다시 누르면 해제 |
| 상호작용 | C | X / Square | 대상이 가까울 때 상황 버튼 |

패드에서 RB를 누른 동안에는 보조 기술 입력만 판독해 회피/상호작용/점프의 중복 실행을 막는다. K0에서는 점프가 필요 없는 평면 전투장으로 검사하며, 일반 탐험의 점프 입력은 후속 이동 명세에서 확정한다. 조작 재지정과 왼손 배치 옵션을 후속 UI 사양에 포함한다.

표적 고정은20stud 안의 시야가 열린 적을 선택한다. 대상이 죽거나25stud 밖으로 나가면 해제하고, 엄폐로1초 이상 보이지 않으면 해제한다. 기본 공격의 자동 방향 보정은 시전 시작 시 최대30도, 준비 구간에서만 수행한다. 유효 판정이 시작되면 방향을 잠그며 적을 따라 순간 회전하지 않는다. 잠금 대상이 없어도 입력 방향으로 공격한다.

터치의 근접 기술은 탭으로 이동/바라보는 방향에 즉시 사용한다. 방향 지정 기술은 홀드로 범위를 미리 보고 드래그 후 놓으면 시전하며, 취소 구역에 놓으면 자원·쿨다운 없이 취소한다. 조준 중 피격·회피로 취소할 수도 있다. 준비/판정/회복이 시작된 뒤의 취소는 아래 전투 상태 규칙을 따른다.

폰 가로 화면을 최초 배치 기준으로 검사하고, 세로·태블릿·PC 작은 창은 별도 배치로 확인한다. 터치 버튼 유효 영역은짧은 변의8% 이상을 시작값으로 두되 화면을 가리면 크기·간격을 함께 조정한다. 적의 위험 표시와 방어/회피 버튼이 겹치지 않아야 한다. 잠금·버튼 색상만으로 사용 가능 여부를 전달하지 않는다.

## 4. 전투 상태·입력 버퍼·취소

`대기/이동 → 준비 → 유효 판정 → 회복 → 대기/이동`이 공격의 기본 흐름이다. 방어·회피·피격·방어 붕괴·사망은 별도 상태다. 아래 시간은 서버가 승인한 행동 시작을0으로 센다.

| 항목 | 실행 규칙 |
| --- | --- |
| 입력 버퍼 | 다음 행동1개를0.12초 보관. 같은 버튼 연타는 중복 큐를 만들지 않음 |
| 우선순위 | 사망/강제 피격 → 유효한 회피 → 방어 → 액티브/궁극기 → 기본 공격. 비용·쿨다운이 부족한 입력은 큐에 남겨 자동 발사하지 않음 |
| 공격 준비·유효 구간 | 회피/방어/다른 기술로 취소 불가. 조준 미리보기는 아직 이 상태가 아님 |
| 기본 공격 회복 | 회복 시작0.10초 후 회피 가능, 마지막0.10초에는 방어 가능. 다음 검격은 회복 종료 후 시작 |
| 액티브·궁극기 회복 | 회복 시간의 절반 이후 회피 가능. 방어/다음 공격은 회복 종료 후 가능 |
| 취소의 결과 | 남은 판정·후속 타격·후속 효과 취소. 이미 지불한 비용·시작한 쿨다운은 유지하고 이미 맞은 피해도 되돌리지 않음 |
| 방어 중 공격 | 공격 승인 시 방패를 내리고 준비 상태로 진입. 공격 중 방어 피해 감소를 유지하지 않음 |
| 피격 | 일반 피격 경직0.25초. 같은 공격의 중복 접촉으로 연장하지 않음. 적의 연속 공격 조합은 회피 가능한 틈을 남김 |
| 사망·리셋 | 진행 중 공격·반격 기회·표식·필드·보호막 정리, 이전 공격ID의 뒤늦은 적중 거부 |

준비·유효·회복은 애니메이션 재생 시간과 같은 기준표를 사용한다. 화면의 검 궤적이 판정보다 늦거나, 회복 중 다음 행동이 가능한 것처럼 보이면 모션 또는 판정표를 함께 고친다. 시각 타격 정지는 로컬 연출로만0.03~0.05초를 시험하며 서버·다른 플레이어·실제 입력 처리는 멈추지 않는다.

## 5. 검 3연격·방패·회피

### 5.1 기본 검격

기본 검격은 서약·스태미나를 쓰지 않는다. 표의 판정은 전방 부채꼴과 무기 궤적 안의 유효 대상 최대3명에 적용한다. 동일 적의 여러 신체 부위를 맞혀도 한 번이다.

| 공격ID | 준비/유효/회복 = 총시간 | 피해계수 | 자세 피해 | 사거리·각도 | 맞힌 뒤 서약 |
| --- | --- | --- | --- | --- | --- |
| `knight.basic.1` | 0.16/0.10/0.16 = 0.42 | 0.75 | 12 | 4.5·100도 | 6 |
| `knight.basic.2` | 0.18/0.10/0.18 = 0.46 | 0.90 | 14 | 4.5·110도 | 6 |
| `knight.basic.3` | 0.26/0.12/0.24 = 0.62 | 1.20 | 24 | 5.0·100도 | 10 |

3연격 전체는1.50초·피해계수2.85·자세 피해50이다. 적이 멈춰 있고 전타가 맞는 ATK100 조건의 방어 적용 전 기준은285/1.50=190DPS다. 실제 처치 시간 목표와 같다는 뜻은 아니다. 회피·피격·액티브 사용 시 연격은1타로 돌아가며, 다음 검격을0.60초 넘게 시작하지 않아도 초기화한다.

### 5.2 방패와 반격 기회

방패 올리기0.10초 뒤부터 정면120도를 방어한다. 후면·방어 불가 공격은 막지 못한다. 방향은 방패 앞에서 공격 발생점으로 향한 벡터로 판정하며, 범위 공격은 적 몸체가 아니라 해당 판정의 공격 원점을 쓴다. 방어 중 회전은 가능하지만 순간 반전 보정은 하지 않는다.

| 결과 | 체력·스태미나 | 공격 기회 |
| --- | --- | --- |
| 일반 방어 | 남은 체력 피해의80% 경감, 적 공격에 명시된 방어 비용 지불 | 1.5초 반격 기회1개, 서약4 획득은1초에 한 번 |
| 완벽 방어 | 방어가 활성화된 첫0.15초 안에 적중하면 피해/방어 비용0 | 1.5초 강화 반격 기회1개, 서약12 획득은0.60초에 한 번 |
| 방어 붕괴 | 필요한 방어 비용보다 스태미나가 적으면 스태미나0, 방패 경감 없이 피격·0.80초 경직 | 반격 기회 없음, 스태미나 회복 지연1.20초 |

방패 올리기 시작에 스태미나4를 소비한다. 올리기 시작 간격은 최소0.40초이며 새 완벽 방어 창도 이 간격을 따른다. 계속 들고 있어도 창이 반복되지 않는다. 공격별 비용이 남은 스태미나와 같으면 정상 방어 후0이 되고, 그보다 클 때 붕괴한다. 비용과 각도는 화면으로 예측 가능해야 한다.

반격 기회는 일반/강화 중 높은 것 하나만 보관하고 재획득 시1.5초로 갱신한다. 다음 기본 검격 또는 반격참의 유효 적중에 한 번 소비한다. 기본 검격의 추가 피해계수는 일반+0.25, 강화+0.50이며 다른 기본기에는 적용하지 않는다. 반격참의 전용 값은 기술 표를 따른다. 빗나가면 기회는 만료 전까지 남으며, 후속 공격이 기회를 만들지는 않는다.

일반 방어만으로도 반격 기회가 생긴다. 완벽 방어 성공은 일반 적의 공격 회복을0.40초 연장하고 보스에게는 자세 피해20을 준다. 보스의 확정 연속 패턴 전체를 강제 취소하지 않는다. 이 반응은 적당0.60초에 한 번만 적용한다.

### 5.3 회피와 회복

회피는 스태미나30, 전체0.65초, 이동 구간0.30초·최대7stud, 무적은 시작 후0.08~0.28초의0.20초다. 이동 입력이 없으면 뒤로 피한다. 벽·낭떠러지 안전 경계에서 이동을 자르고, 벽 반대편으로 통과시키지 않는다. 시작 후 다음 회피까지0.65초를 요구하며 후반 회복을 또 취소해 무적을 잇지 못한다.

스태미나는 마지막 소비 후0.80초부터 초당20 회복한다. 방패를 유지하거나 방어 붕괴 중이면 회복하지 않는다. 일반 공격·걷기 중에는 지연 조건을 만족하면 회복한다. 비용을 낼 수 없으면 회피가 시작되지 않으며 체력이 빠지는 대체 비용도 없다.

### 기본 스탯 연동

힘·민첩·지력·체력은 [기본 스탯 설계](character-stats.md)를 따른다. 기존 ATK/HP 고정 프리셋과 기술 계수는 전투 기준선으로 유지하고 K3 성장 통합에서 스탯 기반 파생 능력치를 연결한다. 성기사의 검격/성광 기술이 참조하는 능력치와 혼합 비중은 별도 정의한다. 민첩의 공격속도 효과를 연결할 때 서버 타격 시각과 모션을 함께 조정하되, 회피 무적·완벽 방어 창·비용·취소 규칙을 일괄 단축하지 않는다. 이번 스탯 도입만으로 아래 서약/스태미나 비용을 MP로 대체하지 않는다.

랭크 값은 누적 합이 아니라 해당 랭크의 최종 값이다. C4의 “다음 회피 비용”은 비용 보정 후 고정 감소를 적용하되 최소20으로 제한한다. 일반 전투의 학습 순서와 총79P/216노드 예산은 바꾸지 않는다. 시험 프리셋이 노드 선행/레벨 검증을 우회하는 공개 기능이 되지 않게 한다.

## 9. 첫 전투 실험실의 적·공간·시나리오

**첫 제작·전투 검증 맵은 Deepwood다.** Throne Defense의 Deepwood 지형·거목·석조 포탈·수정 왕좌·돌길·절벽/폭포를 참고하고 적합한 자산을 선별해 활용한다. 실제 확인한 원본과 RPG 전환 기준은 [공유 자산의 Deepwood 적용](shared-universe-and-assets.md#12-deepwood-첫-제작-맵-적용)을 따른다.

지역 전체의7지점·선택3구역과 몬스터10종 배치는 [Deepwood 지역 설계](deepwood-region-design.md)를 따른다. 성녀의NPC/선택 지원은 [동료 설계](companions-and-support.md)로 분리하며 기사 기본기 검증의 필수 조건으로 두지 않는다.

K0는 Deepwood 안의 평탄한 공터96×96stud를 검사 구역의 시작 예산으로 둔다. 이 수치는 Deepwood 전체 크기가 아니다. 검격 시험 구역, 적1명과의 결투 구역, 작은 엄폐물2개가 있는 다수전 구역을 분리한다. 숲의 색과 거목/포탈의 방향성을 보존하면서 낭떠러지는 안전 경계로 막고 리셋 지점은 전투 구역 밖에 둔다. 이동/카메라 테스트 후 경사와 좁은 통로를 추가한다.

TD의 타워 패드와 U턴 경로는 원형 참고로 두고, RPG에서는 자유 이동·회피/돌진·적 추적·카메라/공격 가림에 맞게 재구성한다. 기존 시각 메시와 별도 경사판의 물리/쿼리 설정을 RPG용으로 검증한다. Dawnspire 왕도 거점·프롤로그의 기존 서사 위치와 Deepwood를 먼저 제작하는 순서는 구분한다.

## 10. 자산과 애니메이션 제작 요구

기사 은청·검/방패 원형을 유지한다. 강철기사는 금속 충돌·낮은 파편·검 궤적, 성기사는 검날 주변 문양·짧은 성광으로 구별한다. 큰 오라로 적의 방어 불가 문양이나 표식 수를 가리지 않는다. Crusader/Paladin은 성기사 참고 자산이며 전직 레벨과 일대일로 배정하지 않는다.

| 제작 묶음 | 필요 항목 | TD 활용 후보·판단 |
| --- | --- | --- |
| K0 플레이어 | 대기/이동·검격3·방패 올림/유지/내림·방어 적중/완벽 방어·회피·피격/붕괴/사망 | Knight·Swordsman·Shieldbearer의 적합한 검/방패/의상 참고. 플레이어 리그와 근접 모션 신규/보수 판단 |
| K0 적 | 고블린1공격·오우거2공격, 준비/회복·피격·자세 붕괴 | 기존 몬스터 형상 후보, RPG 추적/공격·예고·피격은 별도 제작 |
| K1 공통 기술 | 접근 검격·방패강타·외침 동작과 범위/상태 표현 | 공통 리그 파생 동작, 기존 타워 자동 공격 코드 그대로 사용하지 않음 |

형상·피벗·리그·장착 손·검 궤적·방패 방향·판정체를 함께 확인한다. 특정 기존 모델 때문에 무기 운용이나 캐릭터 관절 품질을 줄이지 않는다. 자산의 실제 경로·해시·권한·채택 상태는 [공유 자산 문서](shared-universe-and-assets.md)의 등록 절차를 따른다. 이 표는 제작 요구이며 사용 가능한 애니메이션ID 목록이 아니다.

## 11. 구현 데이터와 서버 판정 계약

다음은 구현할 데이터 필드의 제안이다. 실제 코드 파일·원격 이벤트 이름·저장 키는 아직 생성하지 않았다. 기술과 애니메이션을 동일한 버전의 정의로 묶는다.

| 데이터 | 필수 필드 |
| --- | --- |
| 기술 정의 | `abilityId`, `definitionVersion`, 클래스/계열/레벨·시험 조건, 준비/유효/회복, 취소 구간, 비용·쿨다운, 판정 형상·원점·거리/각도·대상 상한, 피해/자세, 효과·태그 |
| 전투 상태 | 캐릭터/생명ID, 현재 행동·시작 시각, 연격 단계, 체력/스태미나/서약/게이지, 방패 방향·완벽 방어 창, 반격 기회, 효과 소유자·발생 기술ID/태그·잔량·만료, 쿨다운 |
| 클라이언트 의도 | 증가하는 입력 순번, 기술ID, 조준 방향, 보조 대상ID. 최종 피해·자원·자격은 요청받지 않음 |
| 서버 승인 | 요청 순번·공격ID·기술 정의 버전, 승인/거부 사유, 서버 시작 시각·현재 자원/쿨다운 |
| 적중 결과 | 공격ID·대상/생명ID·타격 구간ID, 적용 시각, 방어/무적/차단 결과, 피해·자세·상태·자원 변화 |
| 관측 기록 | 빌드/프리셋·기기·입력 방식·지연 조건, 입력/승인/판정 시각, 중단/거부 원인·피해 원인 |

처리는 `자격/생존/상태/쿨다운/비용 확인 → 행동ID 생성·비용/쿨다운 확정 → 서버의 시각과 위치로 판정 → 공격ID/대상/구간 중복 방지 → 자원/효과 변경 → 결과 통지` 순서다. 같은 입력의 재시도는 기존 결과를 돌려주고 두 번 소비하지 않는다. 거부 사유는 잠긴 기술·잘못된 계열·비용 부족·쿨다운·상태 불가·오래된 입력으로 구분한다.

클라이언트는 애니메이션과 조준을 빠르게 시작할 수 있으나 서버 거부 시 판정·이동 예측을 복구한다. 클라이언트 시각으로 완벽 방어 창을 무제한 소급하지 않는다. 첫 구현은 서버 시간의 판정을 기준으로 하고, 지연 보정 방식은80/150/250ms 관측 후 별도 설계한다. 지연 때문에 규칙을 넓힐 때에는 예고·피격·완벽 방어를 함께 평가하고 변경값을 기록한다.

기절/사망/전투 리셋과 이동 충돌은 동일한 서버 판정 순서에 포함한다. 앞서 취소된 공격의 늦은 콜백, 죽은 적의 표식, 실험 리셋 전 공격을 새 생명에 적용하지 않는다. 아직 없는 API나 저장 기능을 완료된 것으로 안내하지 않는다.

초기 수치 예로 오우거 내려치기220은 일반 방어로44체력/45스태미나를 잃는다. 외침20%가 먼저 적용되면176→방패 후35체력, 방어 비용은 별도45다. 여기에 철벽진이 있어도 피해 감소40%로 합산하지 않으며 방어 비용만45×0.70을 올린32가 된다. 완벽 방어는 이 체력/피격 비용을0으로 처리하되 방패 올리기의4비용은 이미 지급한 값이다.

새 이용자12명 이상을 PC/터치에 나눠 관찰하는 초기 기준을 제안한다.10명 이상이 직접 조작 안내 없이 일반 방어/회피 중 하나로 큰 공격에 대응하고, 다음 시도에서 바꿀 행동을 말할 수 있는지 기록한다. 두 계열 체험 후에는10명 이상이 차이와 선택 이유를 설명하는지 확인한다. 본편용 통과 기준은 [로드맵의 관찰 계획](production-roadmap.md#61-새-이용자-관찰)과 함께 관리한다.

같은 장비 예산·노드0·같은 오우거에서 계열별 두 편성의 솔로 처치 시간·받은 피해·방어/회피 성공·서약 고갈·기술 사용 빈도를 측정한다. 계열 사이 처치 시간 차이20%는 초기 조사선이며 자동 너프 규칙이 아니다. 빠른 처치만으로 보호 계열의 가치를 판단하지 않고 보호 기여와 조작 부담도 함께 본다.

성능은 K0의 솔로 전투부터 실제 기기·설정·빌드를 붙여 측정한다.4인+적24+보스1 부하와 모바일/PC P95 프레임 시간33.3/16.7ms는 후속 통합 목표다. 실험실의 적 몇 명이 원활하다는 결과를 전체 게임 성능 통과로 바꾸지 않는다.
