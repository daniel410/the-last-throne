# 에픽 귀환 후 로비 사이드 퀘스트 담당 NPC

2026-11-07 · TLT-028/031/041/050/052/057/061~065/084 · 기획 → 디자인/ENG → QA

상태: 사용자가 에픽 완료 후 로비 NPC의 미완료 사이드 퀘스트 제시·보상 역할 필요성을 제기했다. 아래는 구체화한 설계안이며 게임 적용·보상 수치 확정·수용 완료가 아니다.

## 역할과 플레이 흐름

기존 Dawnspire의 Expedition Guide **Tessa**에게 의뢰 접수·보고 역할을 추가하는 안을 추천한다. 기존 원정 안내 역할과 맞고 새 NPC/모델 제작 없이 연결할 수 있다. 담당 인물은 제안이며 확정 이름 변경은 없다.

에픽 완료 → 로비 귀환 → Tessa의 남은 의뢰 표시 → 해당 에픽 목록 → 의뢰 선택 → 현장 수행 또는 로비 보고 → 보상 결과 확인 흐름이다. 강제 대화창을 띄우지 않으며 다음 본편 Continue는 그대로 둔다. 다음 에픽을 먼저 진행해도 이전 지역 의뢰를 나중에 선택할 수 있다.

- 기본 목록은 선택 영웅이 본편을 완료한 에픽의 남은 사이드 퀘스트다. 지역 순서는 Deepwood → Gloamwood → Frozen Vale → Ember Caldera → Haunted Graveyard다.
- 상단에 보고 가능 의뢰를 우선 표시하고 미수락·진행 중 의뢰를 이어 표시한다. 완료 항목은 별도 완료 보기에서 확인한다.
- 각 행은 지역·제목·현재 상태·남은 목표·보상 미리보기·다음 행동을 보여 준다. NPC 머리 위 표식은 색과 기호/영어를 함께 사용한다.
- 의뢰 선택 시 기존 ADVENTURES의 해당 사이드 원정을 선택한다. 즉시 강제 이동하지 않고 기존 솔로/파티·난도·입장 자격 검사를 따른다.
- 현장 발견형은 위치와 짧은 소문을 제시한다. 로비 클릭으로 단서 발견·수락·조사 목표를 자동 달성하지 않는다. 일반 NPC 의뢰도 기존 수락 규칙을 유지하고 필요한 현장 인물을 안내한다.
- 현장 목표를 모두 마치고 보고만 남은 의뢰는 Tessa에게 보고할 수 있게 한다. 기존 현장 보고도 유지하며 두 경로는 같은 완료·보상 권리를 사용한다.

## 확인한 현재 구현과 변경 경계

`src/client/LobbyQuestJournal.luau`는 선택 영웅의 저장 진행을 읽는 조회 창이다. `src/shared/LobbyQuestText.luau`는 모험에서 수락/진행하라고 안내한다. `src/server/Lobby/NPCService.luau`는 상점·Selene를 제외한 주민에게 기본 인사만 표시한다. 현재 Tessa는 이 기본 인사 경로다.

`CampaignContent`의 실제 사이드 등록은 DW-Q1~Q4, FV-Q1~Q4, EC-Q1~Q4의12개다. Gloamwood/Haunted Graveyard 사이드는 새 콘텐츠를 작성하기 전까지 목록을 만들어 내지 않는다. 숫자형 본편 선행을 과거 순서에서 복사하지 않고 현재 CampaignContent/진입 규칙을 사용한다.

현재 사이드 고정 XP·Gold는0이며 처치/난도 재료 보상은 별도다. `DeepwoodProgress.apply`는 마지막 목표 완료에서 clears와 보상 결과를 함께 만든다. 따라서 완료된 퀘스트를 전부 ‘미수령’으로 재해석하면 안 된다. [기존 전수 리뷰](../evidence/side-quest-review-20261106/README.md)와 [비교 조사](../research/2026-11-07-lobby-side-quest-return.md)를 함께 참고한다.

## 보상 방향과 보존

사용자가 요구한 ‘수행 후 보상 체감’을 만족시키려면 현재0인 고정 완료 보상도 별도 설계해야 한다. **Gold + 실용 재료/소모품**을 1차 후보로 추천하며 종류·수량·XP 포함 여부는 경제 검토 후 확정한다. 메인 승인 XP·초회 Diamonds·반복 Gold·기존 처치/난도 보상을 자동 변경하지 않는다. Soft Hide와 트레이닝 무기는 새 보상 후보에서 제외한다.

첫 원형은 DW-Q1~Q4의 목록·현장 복귀·보고 동작을 검증하고, 보상 정의를 확정한 뒤 실제 지급을 연결한다. 보상0 상태의 화면을 보상 기능 완성으로 수용하지 않는다. 신규 보상을 과거 완료자에게 소급 지급할지는 별도 결정이며 현재 완료 기록만으로 새 지급 권리를 만들지 않는다.

## 적극 추천·표식 계약 — 2026-11-07 최신 요구

TLT-028/031/050/052/084. 사용자가 로비 NPC의 적극적인 사이드 퀘스트 추천과 느낌표/물음표 표시를 명시했다. 기존 Tessa를 안내/추천 창구로 사용한다. NPC 이름의 최종 변경은 요구하지 않는다. 플레이어가 저널을 먼저 열어야 알 수 있는 구조를 바꾼다.

### 적극 추천의 동작

- 로비 귀환/접속 시 저장 로드 후 추천 가능한 의뢰를 계산한다. 처음 해금된 의뢰 묶음 또는 새 보고 가능 상태가 있을 때 작은 안내를1회 보여 준다. 예: `Side quests are available. Talk to Tessa.` / `A quest is ready to report. Talk to Tessa.` 버튼은 `Find Tessa`, `Later`다. 강제 대화/강제 이동은 하지 않는다.
- Find Tessa는 로비 지도와 짧은 길 안내로 NPC를 찾게 한다. NPC 상호작용은 곧바로 사이드 추천 패널을 열며 일반 인사만 표시하고 닫히지 않는다. 주요 동선에서 NPC와 표식을 찾을 수 있도록 배치를 검토한다.
- 안내를 닫아도 `!`/`?`는 실제 자격이 남아 있는 동안 유지한다. 매 접속·영웅 왕복 선택으로 같은 안내를 반복하지 않도록 영웅+의뢰 묶음/상태에 대한 마지막 안내 식별자를 보관한다. 안내 기록은 완료/수령 권리와 분리한다. 저장 불명 때 새 팝업을 연속 생성하지 않는다.
- 추천 우선순위는 보고 가능 → 진행 중 이어하기 → 방금 완료한 에픽의 미수락 → 다른 입장 가능한 지역의 미수락이다. 같은 순위는 현재 레벨/원정 입장 자격에 맞는 의뢰를 우선하고 지역 순서·안정ID로 정렬한다. 임의 예상시간·보상 효율을 추천 근거로 표시하지 않는다.
- 첫 화면은 추천1개를 크게 보여 주고 지역·부탁 이유1문장·진행 상태·실제 XP/Gold/재료·다음 행동을 표시한다. `View All Requests`로 전체 목록을 연다. 구매/유료 지원 권유를 퀘스트 추천에 섞지 않는다.
- 이전 ‘완료한 에픽만’ 기본 목록은 **완료 에픽 우선·현재 실제 해금된 사이드도 안내**로 보완한다. 본편 진행 중 로비로 돌아와도 원래 사이드 선행을 충족했으면 추천할 수 있다. 미해금 에픽을 표시/선택 가능하게 만들지 않으며 기존 CampaignContent/입장/난도 규칙을 사용한다.
- 미발견 숨은 퀘스트는 부탁/소문과 탐색할 지역까지만 알려 준다. 상세 정답·모든 위치·완료 상태를 공개하거나 발견 플래그를 자동 부여하지 않는다. 현장 발견이 필요하다는 다음 행동을 분명히 표시한다.
- 다음 본편 Continue는 유지한다. 사이드 수행을 건너뛰어도 본편 결말·전직·다음 에픽에 새 제한을 만들지 않는다. 현재 사이드가 없는 GW/HG는 실제 새 콘텐츠 등록 전 `!`를 만들지 않는다.

### 추천/표식과 대리 보고를 나눈 제작 순서

1. **TLT-028/050/lobby-side-recommend / P1 / DES·ENG:** 실제 상태 투영·NPC 개인 표식·로비 지도·추천1개/전체 목록·귀환 알림·Find Tessa·기존 원정 선택을 먼저 만든다. 이 읽기/안내 기능은 대리 보고/새 콘텐츠 버전 구현을 기다릴 필요가 없다. 완료 효과나 보상 지급은 만들지 않는다.
2. **TLT-028/050/lobby-side-report / P1 / ENG·QA:** 기존12개 보고 허용표와 원정 정산을 검증한 뒤 로비 보고를 연결한다. 그 전 보고 완료 가능성을 과장하는 `?`는 표시하지 않고 현장 보고 안내를 사용한다. 기능이 연결된 후 표의 금색 `?` 상태를 활성화한다.
3. **TLT-084/lobby-side-discovery / QA:** 신규/본편 중간/에픽 귀환/기존 완료 계정·영웅 전환·로드 실패·재접속·여러 의뢰 동시 상태·PC/터치/패드를 검증한다. NPC를 직접 눌러야만 발견 가능한지, 표식과 패널 상태가 맞는지 확인한다.

사용자 관찰의 첫 목표는 PC4/터치4의 신규8명 중6명 이상이 외부 설명 없이 로비 입장 후30초 내 사이드 의뢰가 있음을 알고 Tessa의 추천을 여는 것이다. 이는 제안 수용 수치이며 미측정이다. 기능 회귀는 읽은 뒤 미수락 `!` 유지, 보고/완료 후 `?` 해제, 영웅별 표시 차이, 완료 의뢰 재추천0·중복 지급0·같은 상태 알림 반복0·미해금 입장0을 확인한다.

현재0.83.0 지급/누락분 복구를 보존하며 기존 본문의 보상0·소급 미정 문구는 과거 조사 이력이다. 추천 기능은 그 정본을 조회한다. 이번 후속은 계획 보강이며 런타임/Studio/빌드/게시 결과는 없다.
