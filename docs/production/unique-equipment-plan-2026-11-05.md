## 1. 기본 능력치와 착용 조건

유니크는 같은 세대 Common 환산 프로필×1.26을 기본치로 하고 고유 효과에 예산0.14를 예약한다. 상한1.40 안에서 **기본치와 효과를 교환**하는 시험안이다. Legendary의1.40을 그대로 쓰고 효과를 추가하지 않는다. 기존 Legendary 세트 조각에는0.97이 적용되므로 실제 개별품 기본치 비교는1.358 대1.26이고, 비세트는1.40 대1.26이다. 이 예산 예약이 피해/생존/MP의 실제 가치 교환을 증명하지는 않는다.

모든 표는 등급 비교를 위한 **Lv10 시험 세대**다. Unique 최소착용Lv10이나 후반 보스Lv10 보상을 확정하지 않는다. 보스·지역·난이도별 장비 세대/요구Lv가 고정되기 전 드롭은OFF다. 높은 난이도에서Unique를 더 자주, Easy에서는 희소하게 주는 방향을 유지하며 확률표/보장책은 기존 재리뷰의 수용 조건을 먼저 충족한다. 본편/전직에 특정Unique를 요구하지 않는다.

Unique는 모두 **비세트**다. 기존5부위 세트의 조각·97%차감·2/4/5부위 보너스를 받지 않는다. 장신구 uniqueGroup은 원래 품목 계열을 유지해 그 계열의 다른등급과도 중복 장착하지 않는다. 서로 다른Unique의 동시 장착은 허용하되 효과별 공유 제한을 적용한다. 기존 클래스4·8슬롯·검/방패·활·도끼·지팡이 유형을 보존한다. 이름/색만으로 기존품을 자동 승급하지 않는다.

## 2. 개별 아이템

Power / Armor / HP / MP 순서로 표시하며 수치는 소수3자리까지 표시 반올림한다. JSON은 기본치 소수4자리/+9 소수6자리까지 보존한다. +9는 세트/고유 효과를 제외한 기본치 결과다. Power는 공격/주문력에 대한 장비 퍼센트 보너스 포인트이며 고정피해가 아니다. 모든 이름·효과 수치·목표 보스는 시험안이다.

## 3. 효과의 공통 실행 계약

모든 효과는 실제 전투 중 살아 있는 소유자에게만 적용한다. 서버가 피해·블록·회피·적중·MP 소비를 확인해야 하며 안전 거점, 장비 교체, 무적 표적만으로 발동하지 않는다. 피격 계열은 적의 직접 공격만 센다. 아군·자가 피해·DoT·환경 피해·고유 효과에서 파생된 이벤트는 제외한다. 범위/다단 스킬은 적이나 펄스 수와 관계없이 시전당1회다. 기본 공격3회 조건도 공격당1씩만 세고, 8초 안에3회를 채우면 카운터를0으로 되돌린다.

| 효과 종류 | 중첩과 상한 | 영웅별 공유 재발동 |
| --- | --- | --- |
| 보호막 | 가장 큰 하나, 효과 적용 전 최대HP의6% 이하. 보호막끼리 더하지 않음 | 20초 |
| 직접 피해 감소 | Unique끼리는 가장 큰 하나, 최대6%. 기존 피해 계산 후 추가×(1−비율) | 20초 |
| 다음 기본 공격 | 가장 큰 충전1회, 최대+8%. 발동 이후 별도 공격의 첫 유효 대상만, 4초 만료 | 15초 |
| MP 회복 | 한 번에 최대6MP. 기존 풀의 부족MP까지만 회복 | 15초 |
| 자기 HP 회복 | 한 번에 최대HP의2%. 부족HP까지만 회복, 부활 효과 없음 | 20초 |

같은 이벤트에 여러 품목이 반응하면 종류별 가장 큰 효과값을 먼저 고른다. 동률은 definitionId 순으로 고정한다. 선택된 효과만 공유 타이머를 소비하고 나머지는 별도 예약 발동하지 않는다. 회복 결과가0이면 타이머를 소비하지 않는다. 이미 활성화된 더 강한 같은 종류의 버프를 작은 효과로 덮어쓰거나 지속시간을 늘리지 않는다. 기본 공격 보너스는 발동한 공격에 소급 적용하지 않으며 추가 피해가 새 발동을 만들지 않는다.

블록은 키 유지가 아닌 실제 적 공격 차단, 회피는 서버가 확정한 실제 적 공격 회피다. 기존 기본 공격/회피에 쿨다운이나Stamina를 추가하지 않는다. 효과 수치·범위·지속·재발동 시간은 강화로 늘지 않는다. 고유 효과가 기존 보스 기믹을 무시하거나 적에게 새 스턴/행동불가를 추가하지 않는다.

재장착·다른 등급 교체·사망·영웅 변경·재접속·원정 이동으로 공유 타이머를 초기화하지 않는다. 서버는 영웅+효과 종류별 nextEligibleAt을 장착 여부와 분리해 저장/이전한다. 해제·사망·원정 이동 시 버프·충전·3회 카운터는 삭제하고 남은 재발동 시간은 유지한다. 저장 불명·전송 실패 시 효과를 다시 주지 않는 복구가 필요하다. 계정 리스·장비 버전과 동시 서버 요청도 검증한다. 툴팁에는 공유 재발동/중첩 불가 조건까지 영어로 표시한다.

MP 효과는 Mage와 첫 전직을 완료한 magic_archer Elf의 기존 풀에만 적용한다. Knight/Dwarf/일반 Elf에게 새 풀을 만들지 않는다. 공통품의 HP/Armor는 정상 적용하고 MP 비적용을 비교창에 설명한다. MP10 소비 조건은 한 시전에서 실제로 차감한 값이며 장비 교체·물약은 포함하지 않는다.

## 4. 강화와 목표 보스

+9는 양수Power/Armor/HP에×1.27, MP에는×1을 유지한다. 순수MP인 Grovewell Pendant는 강화 불가·재료 차감0이다. Stillwater Ring은Armor만, Moonwell Charm은HP만 강화한다. 마법사 혼합품도MP와 고유 효과 수치는 그대로다. 성공률100/90/80/70/60/50/40/30/20%, 목표n의 보석2n·마석max(0,n−3), Gold0, 실패 재료 소모/단계 보존, 성공 투입분80%회수와 과거+10권리를 보존한다.

목표 보스는 현재 DeepwoodEncounterBalance의 bossKind와 대조했다. 같은 보스의 공통/클래스 품목 풀은 클래스·MP 자격·지역·세대·난이도별로 완성한다. 첫Unique 무기4종은 KingShaman을 표적으로 시험한다. 후반 보스 품목은 이름·모티프·목표 후보이며 Lv10 지급표가 아니다.

개인 추첨·참여/사망/단절·미수령·고정RNG·내구성 저널·보호 진도는 [보스 설계](boss-drop-reward-design-2026-11-04.md)를 따른다. Unique0.1/0.5/1.5/3% 및120점 보호는 수용 전 가설이므로 이번에 활성화하지 않는다. Gold/Diamonds/XP/재료·상자·상점 권리는 유지한다.
