## 1. Deepwood

실제 추가는 조사7/장치4/추적3/호위2/순서1/이동1이다. 낙오자/가족 호위는 실제 서버 이동이며 캠프 변화는 개인 소품/일부NPC 등장이다. 기존 전투/구조 배치와 외곽 조사 공간은 분리돼 있다. 첫 지역에서54단계가 전투 입문을 지연시키는지는 미측정이다. 우선 개선은 DW01~03의 약품→사람 치료→캠프 변화가 한 흐름으로 보이게 연결하고 구조자의 이동/도착을 더 명확히 하는 것이다.

## 2. Gloamwood

GW01 운반대와 정찰대 흔적 분리 → GW02 Tali 구출/등불 회수 → GW03 남은 정찰대 위치와 탈출 계획 → GW04 뿌리 길/피난처 연결 → GW05 사냥터 관찰/안전 난간 → GW06 마지막 정찰대 호위/Finn 선도/후위 방어 → GW07 여왕 둥지/설원행 옛길이다. 여왕을Veyr의 부하로 바꾸지 않았고, 단순 운반대 추적에서 동료 전원 구조로 중심을 바꾼 점은 유지할 가치가 있다.

Finn은 대사만 있는 인물이 아니라 실제 호위 actor로 이동한다. 다만 정찰대 전원 집단 이동·탈출 행렬을 구현한 것은 아니다. 안전 로프·표식도 정해진 지점 이동/상호작용이며 독자적인 우회 판단/정찰 시스템은 없다. GW06에 연속 호위2개가 배치돼 속도/반복감 확인이 필요하다. 우선 개선은 최소한 한 구간의 가려진 안전길/명확한 위험길과 마지막 탈출 장면을 지역 고유 경험으로 만드는 것이다.

## 3. Frozen Vale

FV01 조난 대상 탐색/호위 → FV02 두 마을 보급과 끊긴 봉화 파악 → FV03 협곡 구조/연결로 복구 → FV04 과거 기록으로 거짓 경보 확인/원래 신호 복구 → FV05 운반 기록과 공급 터널 → FV06 평온 신호 전달/수호수 진정 → FV07 거울 경보/여왕 진정/마을 재회/Caldera행 기록이다. 수호수를 죽여야 하는 악역으로 바꾸지 않고 경보 문제로 설명하는 구조가 명료하다.

실제 구현은 조난자 호위2개, 기록/순서 장치, 높이가 다른외곽 발판, FV07완료 뒤 개인 안개 완화다. FV03의Eastern Lift Walk는 신규 승강기나 움직이는 협곡 횡단 설비가 아니라 공통 연결로/3상호작용이며, 새 확장 공간에 두 마을을 잇는 전용 교량 네트워크는 없다. FV05터널도 별도 터널 공간을 전용 설계한 것이 아니다. 우선 개선은 FV03협곡을 건너는 하나의 명확한 공간 변화와 FV07두 마을의 신호/주민 재회가 실제로 보이는 전경이다.

## 4. Ember Caldera

EC01 운송 설비 정지/기어/도시 진입 → EC02 기술자와복구 순서 파악 → EC03 광부 구조/냉각 지도 → EC04 냉각 공급·회수 회로 → EC05 옛설계/안전 모형 시험 → EC06 시험장/고렘/보호 검증 → EC07 비상 냉각/해방/이미 반출된 심장의 침공 열쇠 가공 기록이다. 같은 물건을 되찾았다가 다시 잃는 전개 없이Veyr와 왕릉이라는 다음 목표를 확정한다.

냉각복구 완료 때 광선/소품을 바꾸는 것은 구현했다. 그러나 EC05의입구 파랑→회수 연결→보호 표시라는 단계별 회로 반응은 전용 시뮬레이션이나 모델 변화로 구현되지 않았다. 이번 추가에는 호위0개이며 Orik의 새등장은 정적 cameo다. 원래 광부 구조 활동과 이번 추가를 구분한다. 우선 개선은 실제 공급/회수/과압 해소가 보이는 모형 하나와 공장 재가동 전경이다. 도시 전체 가동 완료를 현재소품 반응과 동일시하면 안 된다.

## 5. Haunted Graveyard

HG01 정찰대/드워프의접근 표식 → HG02 동맹별작전 확인 → HG03 Lumi의납골 통로 → HG04 Brann의성문 장치/합류지 → HG05 왕좌 방어연결2개 → HG06 왕실기록/마지막안전지점 → HG07 Veyr/심장회수/침공문폐쇄/귀환이다. 이전지역에서 구한인물이 결전에 기여하고, 마지막에는 집으로 돌아오는 줄거리 구조가 좋다.

실제는 기록/표식/장치와 일부 정적 cameo이며 동맹이각 작업을 수행하는 독립행동 장면은 제한적이다. 기존 성문/봉인 연출이 있는 것과 신규구역의 동맹행동 구현은 구분한다. 최종완료뒤 로비 Eryn/Tali/Freya/Brann/Lumi5명과 대화할 수 있다. 계획의 왕좌 빛복원·4~6분후일담 전용연출은 구현하지 않았다. 우선 개선은 정찰대신호/드워프윈치/엘프우회 지원이 각 다른시각변화를 만들고HG07에서 함께회수되는 짧은 장면이다. 전투AI를 늘릴 필요는 없다.

## 확인된 결함·계획 차이와 우선순위

1. **높음 — 확장 사건의 완료 대사 82개가 성공 메시지에서 누락된다.** `CampaignExpansion.luau:60`은 `row.outcome`을 `g.text`로 넣지만 `DeepwoodService.luau:102`는 모든 `stepId`에 대해 `step.text`로 덮는다. 마지막 step3도 동일하며 확장 사건에는 별도 결과 발행 경로가 없다. 실제 메시지 블록을 추출해 최종 단계에 대입하니 **82/82가 사건 결과 대신 step3 문구를 반환했다.** 예를 들어 GW06 Finn의 후위 방어 안내가 “Every scout is beyond the nests edge.”로 바뀐다. 완료 확정 시 사건 결과를 전송하고 중간 단계·중복 재요청을 구분하는 회귀 검사가 필요하다.
2. **높음 — 같은 외곽 방과 세 지점 왕복이 지배한다.** `CampaignExpansion.luau:19`와 `:55`에서 확인된다. 적 배치·전투 총량 보존은 계약에 맞지만 모든 새 사건을 무전투 외곽에 놓는 방식은 계획의 전투/안전 조사 방 교차와 다르다. 기존 전투 수량을 유지하면서 대표 사건을 실제 진행 동선에 통합해야 한다. 지점 수 증가를 재미 증가로 보고하지 않는다.
3. **중간 — 복구 문장과 실제 공간 변화의 차이.** 신규 발판·경사로는 처음부터 생성되며 `CampaignExpansionPresentation`은 개인 시각을 바꾼다. 확인된 이동 권리 해금은 체크포인트·귀환이다. 신규 교량·승강·문이 단계별로 작동하는 것은 아니다. 등불·상자·광선만 바뀌는 사건을 지역 대표 기믹으로 보강할 필요가 있다. 공유 충돌을 무작정 끄면 개인 진행·파티 호환을 해칠 수 있으므로 서버 권한과 개인 연출을 유지해야 한다.
4. **중간 — EC05 회로 피드백은 문장에 비해 단순하다.** mechanism 모드는 정해진 순서의 상호작용 3회다. 새로운 잘못된 회로 선택·되돌리기·단계별 파랑 회로 표시가 없다. 기믹을 구현하거나 현재 동작에 맞게 문구를 정확히 해야 한다.
5. **수용 미충족 — 시간·재미·성능.** 0.85.0 격리 엔진 3,709검사·동선 1,312지점 충돌0은 물리 기반 검사다. 실제 물리 캐릭터·실계정·모바일·4인+AI·초회 285~410분·반복감 수용은 별도다. 전체 동시 생성 BasePart는 43,302→56,321(+30.1%). 객체 수만으로 FPS 저하 정도를 단정하지 않지만 성능 게이트를 닫을 수도 없다.

추가 UI 검토: 본편 저널은 현재 확장 사건의 세부 목표 3개를 표시한다(QuestBook:51). 신규 목표가 아예 보이지 않는 것은 아니다. 기존 phase 표에는 신규 사건이 편입되지 않아 phase 이름과 현재 사건의 맥락이 맞는지 실제 화면 검증이 필요하다. Chronicle은 기존 `chapter.quest.outcome`만 기록하므로 누락된 사건 대사의 대체 수단이 아니다.

## 검증·인계

이번 검토는 `lua /tmp/tlt-expansion-review.lua`로 실제 데이터 집계·메시지 발행 블록 추출 재현, `lua tests/campaign-expansion.spec.lua`로 진행·저장 회귀를 확인했다. 후자는 **7,688 PASS**다. 이전 [고정 빌드 증거](../evidence/campaign-expansion-20261108/README.md)는 이번 대사 누락을 검사하지 않았으며 통과 횟수로 서사 누락을 상쇄하지 않는다. 런타임·보상·버전·게시·Studio·기존 사용자 파일은 이번 리뷰에서 변경하지 않았다.

권장 순서는 **대사 누락 수정과 회귀 검사 → FV03 협곡·EC05 회로·HG04 동맹 대표 장면 보강 → DW/GW 도입·연속 호위의 반복감 조정 → 실제 솔로 시간·멀티·저사양 검증**이다. 이번 기록은 검토 결과이며 수정 완료나 부모 티켓 완료가 아니다.
