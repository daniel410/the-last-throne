# 영웅별 스킬 레벨업과 스킬트리 설계

2026-10-28 · TLT-004/013/014/015/027/042/052/054~056/058 · 기획 제안 · 담당 PLAN → ENG·DES·QA

## 1. 상태와 원칙

이 문서는 [0.18.7의 실제 세션 기술](../../src/shared/K0Config.luau)을 출발점으로 한 **정식 성장 설계안**이다. 수치·새 영문 기술명·변형·해금 순서와 빌드는 실험 전 제안이다. 정식 레벨·포인트·트리·전직·저장과 아래의 스킬 레벨업은 아직 구현되지 않았다. 현 프로토타입의 모든 기본 기술은 세션에서 즉시 사용 가능하며, 아래의 순차 학습은 정식 성장용 제안이다.

사용자 결정은 네 클래스와 각 3개 기본 스킬, 클래스별 두 계열과 Lv20/40/60/80 전직, 기본 3개·Lv20/40 전직 완료 후 각각 4/5개 전투 슬롯이다. 기본 공격·블록·회피·스프린트는 공통 액션으로 자원을 소비하지 않고 공격·회피에는 별도 쿨다운이 없다. 물리 스킬은 Stamina, 마법 스킬은 MP와 기술별 쿨다운을 사용한다. 원형 엘프는 MP가 없고 마법궁수 전직 완료 후 MP를 추가한다. 궁극기의 별도 슬롯 여부는 미결정이다.

기존 [전직 및 트리 설계](../class-advancement-and-skill-trees.md)의 Lv2~80 매 레벨 1SP·총 79SP, 노드당 3랭크·랭크당 1SP, 클래스당 공통 6개와 두 계열 각각 24개, 전체 216개 노드는 기존 **기준안**이다. 스탯 316P와 별도다. 각 기술 자체의 무료 습득과 포인트를 쓰는 강화는 구분한다. 아래는 우선 12개 기본 스킬의 강화와 8계열의 성장 방향을 구체화한 설계이며 216개 노드 전체의 효과가 완성됐다는 뜻은 아니다.

## 2. 스킬 레벨과 계산

- **기술 레벨**은 해당 기술의 대표 숙련 노드(C1~C3) 랭크를 가리킨다. 기본 습득 시 기술 레벨 1, 노드 랭크 1/2/3은 각각 기술 레벨 2/3/4다. 기술 습득에 SP를 소비하지 않는다. 초기 세 기술은 정식 게임에서 Lv1/5/10에 각각 훈련·습득하는 기존 제안을 따른다. 제공 시점과 튜토리얼 보상은 테스트 후 확정한다.
- 각 행의 `+x%/랭크`는 **해당 기술의 기본 피해 계수에 대한 합연산**이다. 예: 기본 1.40, 숙련 랭크 3의 +5%/랭크 → `1.40 × 1.15 = 1.61`. 다른 기술이나 기본 공격에는 적용하지 않는다. 숫자와 기간은 모두 실험값이다.
- `+x/랭크`는 명시된 대상·반경·초에 선형 합산한다. 달리 쓰지 않는 한 비용·쿨다운·대상 수는 0.18.7 기준을 유지하며 랭크가 자동으로 비용을 늘리거나 쿨다운을 줄이지 않는다. C4~C6의 효과는 아래 정의에 따르며 중복 적용 규칙은 구현 전에 확정한다.
- 스킬은 고유 ID와 같은 쿨다운을 유지한다. 장착 슬롯 교체·리셋·전직 변경으로 쿨다운을 초기화하지 않는다. 시전 성공 시 서버가 자원과 쿨다운을 확정하며 이미 발동한 스킬의 피해·자격은 해당 시전의 서버 스냅샷을 사용한다.
- CC는 일반 적에게만 정해진 효과를 적용한다. 보스·면역 적에 대한 자세 피해 전환량, 저항 및 파티 중복 규칙은 별도 밸런스 시험 전에는 확정하지 않는다. 도발은 보스 강제 타깃을 보장하지 않는다.

## 3. 각 영웅의 공통 스킬 성장

각 행의 효과는 대표 숙련 노드 랭크 1~3에 비례한다. 기술 레벨 4는 숙련 랭크 3이다. 잠긴 기술의 노드에는 투자할 수 없다. 효과가 없는 비용 절감·범위·지속 등은 자동으로 발생하지 않는다.

| Knight C2 | Whirlwind 피해 +4%/랭크 | 근접 다수 처리 |

### 공통 노드 C4~C6: 추가 선택

C4는 C1, C5는 C2, C6은 C3을 최소 1랭크 투자해야 한다. 각 행의 수치도 랭크당 증가하며 모든 효과는 해당 영웅의 지정 스킬에만 적용한다.

| Elf | Aimed Shot 준비 시간 −2%/랭크 | Rapid Fire Stamina 비용 −1/랭크 | Multi Shot 유효 거리 +1 stud/랭크 |

C4~C6은 공통 스킬 외 방어·자원·운용 중 하나를 담는 기존 예산에 맞춰 연결한 첫 실험안이다. 예전 문서의 서약·집중·열기는 신규 자원으로 자동 적용하지 않는다. 스킬별 계수와 기존 공통 노드 예시는 이 문서의 제안으로 재검토하되 사용자 승인을 받은 규칙으로 취급하지 않는다.

## 4. 전직 계열별 스킬트리 (이전 배치 · 재설계 필요)

2026-10-29 사용자 결정에 따라 모든 계열의 Lv20/40/60/80 전직 완료마다 신규 스킬이 필요하다. 아래 Lv24/28 및 상위 강화만의 배치는 이 결정에 맞지 않는 과거 제안이며 [재배치 리뷰](skill-tree-review-2026-10-29.md)를 따른다. 기술명과 상세 효과는 가칭이다.

아래 기술의 영어 표기는 **가칭**이고 액티브 3개와 궁극기 1개는 해당 계열의 기존 콘텐츠 예산에 포함한다. Lv20/24/28은 일반 계열의 제안된 학습 시점이며 해당 레벨과 전직 완료 조건이 둘 다 필요하다. Mage는 예외적으로 Lv20/40/60에 해당 주문을 배운다. Lv40/60/80의 노드·기술 강화는 제안이며 Lv40 전직 완료 시 다섯 번째 슬롯이 열린다. 기존 공통 3개는 어느 계열에서도 보존된다.

### 계열 층과 선행

기존 1계열 30노드·최대 90SP의 층별 예산을 사용한다. 해금은 캐릭터 레벨 **및 해당 단계 전직 완료**가 모두 필요하다. 기술 습득과 트리 층 개방은 별개다.

| 층 | 개방 | 노드·최대 투자 | 설계할 역할 |
| --- | --- | --- | --- |
| C 공통 | Lv2 및 해당 기술 습득 | 6개·18SP | 위 12개 기본 스킬의 강화와 공통 운용 |
| T 1차 | Lv20 전직 | 7개·21SP | 계열 액티브 3개 숙련, 자원·공격·방어·연계. 해당 기술을 습득해야 그 기술 노드 투자 가능 |
| V 2차 | Lv40 전직, 일부 Lv48/55 | 8개·24SP | 계열 기술 변형과 자원·연계, 상위 운용 |
| M 3차 | Lv60 전직 | 6개·18SP | 계열의 순환·보호·위치 선정 숙련 |
| A 각성 | Lv80 전직 | 3개·9SP | 해당 계열 궁극기·숙련·계열 완성 |

모든 계열의 T1/T2/T3은 해당 계열의 첫째/둘째/셋째 액티브를 요구한다. V1/V2/V3은 각각 해당 T1/T2/T3 1랭크와 기술 습득이 선행이다. Mage의 둘째/셋째 기술은 각각 Lv40/60까지 잠겨 있으므로 관련 T/V 노드도 그때까지 잠긴다. 다른 노드의 상세 선행과 각 랭크 값은 TLT-015에서 정의한다. 공통 기반을 전부 최대화할 의무는 없다.

| 드워프 강철 투척 | Overhead Smash·Axe Throw·Ground Slam·Armor Splitter·Returning Echo. C1/C2와 회수 경로 | Mountain Strike 미장착. |
| 드워프 화약 공성 | Axe Throw·Ground Slam·Bomb Toss·Scatter Shot·Field Mortar. 공성 및 안전 거리 우선 | Overhead Smash 미장착. |
| Mage Pyro 지형 | Mana Bolt·Gravity·Ember Lance·Earth Rise·Lava Eruption. 광역 유도·화염/대지 | Water Ball 미장착; Lv60 이후 예시. |
| Mage Cryo 제어 | Water Ball·Gravity·Frost Lance·Chain Lightning·Froststorm. 물·냉기·번개 | Mana Bolt 미장착; Lv60 이후 예시. |

### 79SP 예산 검산

Lv80에서 공통 C 18SP + T 19SP + V 21SP + M 15SP + A 6SP = **79SP**, 최대 90SP보다 11SP 적다. 각 층의 상한 18/21/24/18/9 이내다. 이는 예산 배분 예시이며 아직 세부 선행이 완성되지 않아 실제로 투자 가능한 구체 빌드로 인증한 것은 아니다. Lv1/2/20/40/60/80의 누적 획득량은 각각 0/1/19/39/59/79SP이고 전직 자격이 자동 완료된다는 뜻은 아니다. 스탯 포인트와 합산하지 않는다.

## 5. UI·저장·자원·검증 계약

- **관리 화면:** 기본/전직 층, 기술 아이콘, 현재/다음 레벨, 효과·자원·쿨다운, 남은 SP, 선행과 해금 이유를 표시한다. 수치는 서버가 승인한 실제 데이터에서 가져온다. 영문 예시: `Skill Level 2`, `Requires Level 20 and first advancement`, `Not enough skill points`.
- **장착:** 해금한 기술만 해당 캐릭터·계열에 맞게 서버가 검증한다. 동일 기술 중복 장착 금지, 빈 슬롯 허용, 전투 중 변경 제한은 기존 제안이다. 기존 연습용 5슬롯 전환을 실제 전직으로 간주하지 않는다. HUD 아이콘 위의 단축키와 남은 쿨다운을 유지한다.
- **영속성:** 서버가 레벨 기반 획득량, 투자 및 잔여 포인트를 검증하고 `투자 + 잔여 = 획득`을 보장한다. 중복 투자·다중 레벨 상승·잘못된 계열/선행·동시 요청·저장 실패·재접속·버전 마이그레이션을 처리한다. 실패한 로드를 빈 신규 프로필로 저장하지 않는다. 자원·쿨다운의 재접속 정책은 아직 미정이다.
- **리셋:** 기존 제안은 거점에서 확정한 전체 투자 초기화에 스킬 리셋권 1개를 소비하고 편성만 변경할 때는 무료다. 후손과 선행, 권리 소비와 포인트 반환은 실패 시 복구 가능해야 한다. 반대 계열 재선택 및 환급도 기존 제안이며 무제한 무료 초기화로 확정하지 않는다.
- **균형 검증:** 각 영웅 공통 3기술의 레벨 1~4에 대해 단일·다수·생존·자원 고갈과 공격 시간 대비 실제 피해를 비교한다. 8계열에서 서로 다른 2빌드씩 같은 79SP와 같은 장비로 솔로·1~4인 실전 비교한다. 명궁과 마법궁수의 자원 1종/2종 차이, 보스 제어 면역과 도발, 멀티샷 단일 중복 피해, 도끼 투척 소유권·회수, 마법궁수 MP 개방 경계를 우선 확인한다. 수치가 높다는 문서 계산만으로 실제 성능을 판정하지 않는다.
- **기술별 추가 정의:** 공격·타격 범위와 발사체, 선행·자격, 노드별 모든 랭크, 계열 기술 비용·쿨다운, MP/성기사 정책, 궁극기 슬롯, 제어 내성, 리셋/재접속 정책과 영문 설명은 별도 구현 전 확정한다. UI와 효과는 PC·터치·패드 및 다양한 체형에서 확인한다.
