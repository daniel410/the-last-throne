# 난이도별 캠페인 진행과 초회 보상

2026-11-15 사용자 지시 · TLT-050/061~065/084. Easy/Hard/Insane/Hell은 영웅별 독립 캠페인이다. 다른 모드를 완료했다는 이유로 퀘스트/에픽을 완료하거나 다음 지역을 개방하지 않는다. 추가 확인에 따라 초회 XP·Gold·아이템도 영웅·난이도·퀘스트별 1회다. Diamonds는 기존 3/5/7/10과 난이도별 영수증을 유지한다.

각 모드의 본편·선택 퀘스트·부분 목표·수집/대화 단계·에픽 선행·완료 상태를 분리한다. 선택 화면은 해당 모드의 완료/초회 수령/입장 상태를 표시하고 모드 버튼은 그 모드의 저장된 목적지를 선택한다. 모드 변경 후 원래 모드에 돌아오면 체크포인트와 확정 처치 기록을 복원한다. 본편의 비전투 스토리도 각 모드에서 출발/재개할 수 있어야 하므로 과거 상위 모드의 비전투 임무 차단은 제거한다. 프롤로그·훈련에 새 난이도 보상을 만들지는 않는다.

Hard는 Easy 완료 없이 첫 스토리부터 입장한다. Insane은 같은 임무 Hard 완료, Hell은 같은 임무 Insane 완료가 필요하며 현재 모드의 이야기 선행도 충족해야 한다. 솔로·파티·목적지 입장/재접속과 원정 내 다음 스토리 처리에 같은 서버 검사를 적용한다. 상위 모드 영웅 레벨 제한은 추가하지 않는다. 레벨·스탯·장비/아이템 소유·Gold/Diamonds 잔액·유료 권리와 지도 탐색의 기존 공유 범위는 유지한다.

저장은 기존 영웅 `expeditions`의 추가 필드를 사용한다.

| 필드 | 범위/용도 |
| --- | --- |
| `modeJournals[mode]` | 모드별 영속 퀘스트·에픽 저널 |
| `modeRewardClaims[mode][questId]` | 해당 모드의 초회 XP/Gold/아이템 수령 |
| `runsByMode[mode]` | 부분 목표·완료/원정 정보·처치 영수증을 보존하는 체크포인트 |
| `active.modeProgressVersion=1` | 독립 진도를 사용하는 현재 원정 |

초회 보상은 해당 퀘스트의 현행 정본과 고정 XP 규칙을 사용하며 반복 완료 Gold/XP를 겹쳐 지급하지 않는다. 전투 완주 재료·상자 진도와 기존 Diamonds 영수증은 유지한다. 아이템 지급ID에 난이도를 포함한다. 동일 이벤트/불명 응답/재시도는 저장된 목표와 수령 기록으로 무중복 처리한다. 이미 완료한 같은 난이도 재플레이는 기존 반복 보상을 받는다.

구 공통 `deepwood` 기록과 보유 자산은 삭제하지 않는다. 실제 난이도별 완료/영웅별 지급 영수증을 이용해 각 모드의 연속 본편 진도를 복원하고, 난이도를 확인할 수 없는 스토리 전용 기록은 기존 Easy 이력으로 보존한다. 완료 기록이 있다고 다른 난이도 전체를 복제하지 않는다. 아직 그 모드의 선행을 완료하지 않은 과거 상위 임무의 영수증은 유지하며 선행을 재생성하지 않는다. 이미 지급한 보상에 소급 차액을 추가 지급하지 않는다. 저장 저널이 손상됐거나 로드 결과가 불명인 경우 새 저널/0잔액으로 덮지 않는다.

신규 진행은 반드시 난이도 저널을 원천으로 읽는다. 기존 `deepwood`는 영웅의 과거 이력/공통 연동을 위한 합산 호환 기록으로 유지하며 새 모드의 진도나 초회 수령 판정에 사용하지 않는다. 검증·빌드·미검증과 다음 담당은 [작업 증거](../evidence/campaign-mode-progress-20261115/README.md)에 기록한다. [사례 비교와 해석](../research/2026-11-15-mode-campaign-progress.md).
