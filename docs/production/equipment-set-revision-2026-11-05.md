# 세트 완성 효과 조정

2026-11-05 · TLT-028/029/044/045/052/082/084 · PLAN/DES → ENG/QA

사용자의 “세트 완성 효과를 체감 가능하게 조정” 지시에 따라 기존 장비Power2% 중심의 세트 보상을 교체했다. **2부위는 최대HP5%, 4부위는 클래스별 강화, 5부위는 최종 직접 피해 Rare5%/Epic6%/Legendary8%**다. 세트12개/장비60개에 동일한 구조를 적용하고 현재160종 수치안을 v3로 갱신했다. 사용자 요청의 조정 방향을 반영한 시험 수치이며 실제 플레이 체감·최종 밸런스 수용은 남아 있다.

## 변경한 보상

| 단계 | 이전 | 조정 |
| --- | --- | --- |
| 2부위 | 세트 적용 전 최대HP의2% | **세트 적용 전 최대HP의5%** |
| 4부위 | 강화 장비Armor의2% | **아래 클래스별 강화** |
| 5부위 | 강화 장비Power의2% | **기본공격·스킬 최종 직접 피해 Rare+5% / Epic+6% / Legendary+8%** |

| 클래스 / 두 계열 공통 | 4부위 효과 | 역할과 자격 |
| --- | --- | --- |
| Knight | 블록한 적 직접 피해 추가10% 감소 | 일반 블록 후 남은 직접 피해를 줄인다. 완벽 블록의0피해를 회복/보호막으로 전환하지 않는다. |
| Elf Archer | 원거리 스킬 직접 피해5% 증가 | 서버가 ranged로 분류한 실제 스킬 타격. 물리/마법 모두 가능하며 특정 기본 스킬 편성을 강제하지 않는다. 기본공격에는 미적용. |
| Dwarf Axe Thrower | 물리 스킬 직접 피해5% 증가 | 서버가 비마법으로 분류한 실제 스킬 타격. Iron Axe/Gunner를 모두 포함하며 특정 무기 스킬을 강제하지 않는다. 기본공격에는 미적용. |
| Mage | 마법 스킬 MP 소모8% 감소 | 기존 MP 사용 자격 유지. 양수 비용은 `max(1, ceil(baseCost×0.92))`,0비용은0. 자연 회복/MP 회복을 추가하지 않는다. |

2·4·5부위 효과는 문턱별로 함께 적용된다. Elf/Dwarf의 해당 스킬은 완성 시 Rare `1.05×1.05=1.1025`, Epic `1.05×1.06=1.113`, Legendary `1.05×1.08=1.134` 배율이다. 즉 해당 직접 피해는 세트 없음 대비10.25/11.3/13.4% 증가한다. 기본공격은 모든 클래스에서5/6/8%다. 피해는 마지막에 반올림하므로 실제 정수 타격 증가율은 달라질 수 있다.

Mage의 예시는14MP→13MP,20MP→19MP,80MP→74MP다. 올림 때문에12MP는12MP로 남는다. “모든 주문이 최소1MP 절약된다”는 설명을 쓰지 않는다. 현재 HP·MP 자연 회복 제거 지시를 유지한다.

## 계산·발동 계약

1. 같은 setId·장비 세대·등급의 서로 다른 setPieceId만 센다. 대상은 weapon/head/body/hands/feet다. 오프핸드·장신구·Unique는 제외한다. 과거 `_t10_` ID 접미사로 착용레벨을 판정하지 않는다.
2. 서버가 소유·장착·클래스·레벨 자격을 검사한다. 같은 부위 복제·중복 instance·다른 등급을 섞어5개로 인정하지 않는다. 서로 다른 세트를2개씩 착용해도 같은 문턱 효과는 가장 강한 한 세트만 적용한다. 동률은setId 순으로 선택한다. 2부위HP5%를 두 번 합산하지 않는다.
3. 최대HP는 `(영웅최대HP+강화장비HP)×1.05`다. 세트 자신의 증가분을 다시 입력으로 사용하지 않는다. 장착/해제 시 현재HP·MP를 채우지 않고, 최대치가 낮아지면 현재값을 최대치로 제한한다. 버프 해제/재접속도 회복으로 사용하지 못하게 한다.
4. 5부위는 장비Power에 더하지 않는다. 대상 방어/저항까지 계산한 직접 피해에 자격을 갖춘4부위 배율과5부위 배율을 각각 한 번 곱하고 마지막에 반올림한다. 기본공격·액티브 스킬·궁극기와 저작된 후속펄스는 해당 타격마다1회만 적용한다.
5. 프로시저 보너스 피해·반사·자해·환경·지속피해는 새 세트 피해 배율 대상에서 제외한다. Unique와 혼합할 때 Unique 보너스 피해를 세트로 다시 증폭하지 않는다. 후속 엔진은 원래 직접 타격과 고유 보너스분을 구분해야 한다. 고유 효과 자체 수치/횟수/공유 쿨다운은 유지한다.
6. Knight4부위는 일반 블록과 고정Armor 처리 후, 보호막 흡수 전에 적용하고 최소피해 계약을 유지한다. 회피·완벽 블록·환경 피해에는 새 감소를 발동시키지 않는다. 새로운 범주 쿨다운이나 proc를 소비하지 않는 장착 조건부 배율이다.
7. 장비의 +0~+9로 세트 비율은 커지지 않는다. 강화된 장비HP는2부위 기준에 포함되지만 세트5% 자체를1.27배 하지 않는다. 계정/서버/원정/인간 인원/AI 수에 따라 세트 비율을 바꾸지 않는다.

## 체감 목표와 Unique 비교

Knight 전용8장비·+0의 계산 예시다. 이전 완성 세트의 피해 배율과 새 완성 세트의 피해 배율을 비교했으며 실제 전투/처치시간 결과는 아니다.

| 등급 | 이전5부위의 실제 피해 보너스 | 새5부위 보너스 | 이전 완성 세트 대비 새 기본공격 증가 |
| --- | ---: | ---: | ---: |
| Rare | 약0.5012% | 5% | 약4.4764% |
| Epic | 약0.5554% | 6% | 약5.4145% |
| Legendary | 약0.6378% | 8% | 약7.3156% |

160종 기본치·강화치·착용레벨·드롭 난이도·아이템ID를 모두 보존했다. Unique40종은 영문 설명과 효과까지 이전 값과 같다. 같은 세대의 Unique 기본치가 Legendary보다 높은 계약도 유지한다. 다만 완성 세트는 추가 배율이므로 **완성 Legendary와 효과 미발동 Unique의 전체 피해 순위까지 기본치 비교로 보장하지 않는다.** 이전의 “세트 장비스탯2%보다 Unique 단품 기본치가 높다” 검사는 새 효과의 전체 성능 비교를 대신할 수 없다.

후속 QA는 동일 레벨·강화·포인트·기술 편성에서 완성 세트/혼합/Unique 조합의 기본공격·스킬DPS·블록 생존·MP지속을 비교한다. Unique의 최상위 기본치+고유효과 가치를 유지하면서도 세트가 유효한 선택인지 판정한다. 세트 완성을 본편·전직 필수 조건으로 만들지 않는다.
