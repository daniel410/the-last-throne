# 골드 보상 감액 계약

2026-11-16 · TLT-045/027/029/044/050/084 · 사용자가 [보상 리뷰](../research/2026-11-16-gold-reward-review.md)의 권고안 적용을 요청했다. 같은 날 추가 확인에 따라 Studio 신규 시험 프로필의 초기 재화 지급도 제거한다.

## 신규 원정 규칙19

| 구분 | 신규 지급 | 계산 순서 |
| --- | --- | --- |
| 본편35·선택12 초회 Gold | 기존 고정액의70%, 소수점 내림 | 난이도별 초회 영수증과 한 계정 저장에서 확정 |

| 반복 완료 Gold | 규칙18 최종액의50%, 소수점 내림 | 기존 초회 예산·반복표/내림·20% 감액까지 계산한 뒤 절반. 초회 감액으로 반복 기준을 다시 줄이지 않음 |

공통 구현은 `GoldRewardTuning`이다. 본편·선택 보상 미리보기, 퀘스트 목록/책, 완료 카드와 서버 실제 지급에 같은 규칙을 사용한다. 진행 중인 원정의 버전은 모드 전환/재접속·재개 시 보존하고, 완료 후 새 재플레이는19를 사용한다.

XP·요구XP·레벨·재료·상자·장비·강화 확률·강화50Gold·상점 가격·Diamonds3/5/7/10·모드 Gold1/1.5/2/3배·환율1:50·회복은 변경하지 않는다. 프롤로그·훈련 보상은 이번 감액 대상이 아니다. TD 코드/권리는 변경하지 않는다.

## 과거 권리와 저장

- 기존 잔액과 영웅/모드별 수령·처치 영수증을 유지하며 소급 회수/차액 지급을 하지 않는다. 추가 완료 보상의 기존 영수증 버전도1로 유지한다.
- 저장된 규칙1~18의 초회·처치·반복 계약을 보존한다. 과거 완료 후 미지급된 추가 완료 보상을 복구하는 기존 경로도 원래 금액을 사용한다. 신규19 보상의 영수증이 있으면 로드 시 과거 금액으로 보충하지 않는다.
- 저널 `coins`는 과거의 검증 합계다. `CampaignContent.reward.coins`, `journalCoins`, 추가 완료 원본은 그대로 두고 서버 지급 단계에 별도 정책을 적용한다. 이 값을 신규 실제 수입으로 표시하지 않는다. 퀘스트 책에는 서버의 현재 지갑 잔액을 표시한다.
- `story-reward-budget.json`의 `quest_coins`/기존 처치 합계는 과거 기획·저장 호환 예산이다. 승인된 신규 금액은 `current_quest_gold`와 `gold_reward_rules`로 구분한다. 관련 지역 시나리오 JSON도 `current_quest_gold`/`gold_rules_version`을 가진다. XP 검증은 과거 계획 곡선을 그대로 검사하며 현재 캠페인 성장 곡선과 혼동하지 않는다.

## Studio 초기 재화

신규 Studio 세션의 계정 지갑은 운영 기본과 같은 Gold0/Diamonds0이다. 기존 프로필을0으로 덮거나 사용자의 기존 잔액을 회수하지 않는다. 이전의 Studio Lv10 영웅 시작·세션 전용 저장 방식은 유지한다. 특정 QA 테스트가 직접 설정한 고잔액 fixture는 일반 플레이의 초기 지급이 아니다.
