# 몬스터 움직임 후속 개선 계획

2026-11-07 · TLT-032/033/057/061~065/084/087 · 상태: 후속 계획, 제작 미착수

영웅 Mixamo 파일럿 이후 몬스터의 이동·공격·시전·피격·사망 전환을 종별로 개선한다. 인간형에는 Mixamo 리타깃을 시험하고, 사족·다족·비행·무정형은 Blender 전용 모션을 다듬는다. 기존 모델의 외형·리그·소켓과 서버 공격 시각을 먼저 보존한다. 이 계획은 미래 작업 목록이며 자동 실행 예약이 아니다.

## 박쥐 비행 높이 확정

2026-11-07 사용자 지시로 박쥐는 **공중에 떠서 이동하며 몸통 중심이 플레이어의 얼굴 높이**에 위치한다. 날개 끝이나 바닥으로부터 임의의 고정 높이를 기준으로 삼지 않는다. 추격·정지·공격 준비/회복에도 공중 자세를 유지한다. 사망은 기존 사망/낙하 처리와 구분한다.

구현안은 추격 대상 영웅의 `Head` 중심 높이를 기준으로 삼아 기사·드워프 등 체형 차이에 대응하는 것이다. 대상 변경·경사·계단에서 높이가 갑자기 튀지 않도록 보간한다. 점프 중 추종 방식·대상이 없을 때 기준 높이·상하 흔들림 폭은 표본 제작에서 결정하며, 흔들림으로 얼굴 높이에서 크게 벗어나지 않게 한다.

서버 이동/공격 원점과 보이는 박쥐의 위치를 함께 검토한다. 메시만 위로 올려 실제 공격/피격 위치가 발밑에 남는 결과를 수용하지 않는다. 비행 높이 변경은 이 지시의 명시적 구현 대상이며, 피해량·공격 주기·예고 시각 변경과 분리한다. 이번 작업은 지시를 계획에 기록한 것이며 게임 반영은 후속이다.

## 런타임 연결과 유지 계약

`src/client/K0EnemyMotion.luau`에서 기존 지역 클립·무기·시전자·Gloamwood 스킨 모션의 선택 경로를 먼저 확인한다. 코드에 남은 alias가 실제 스킨 모션을 대체하는지 bind 성공/실패 경로로 구분하고, 정상 적용된 종을 오래된 대체 포즈로 되돌리지 않는다.

`EnemyPatternPose.luau`, `GloamwoodMotion.luau`, `K0EnemyHitReaction.luau`와 본/관절을 쓰는 순서를 조사한다. 새 애니메이션과 기존 반응이 같은 관절을 이중으로 덮어쓰지 않도록 합성 규칙을 정한다.

- 서버 `windup/active/recovery`·실제 타격/pulse·예고·이동/충돌·피해·사거리·공격 주기·HP/보상은 유지한다. 동작을 구간별로 맞추며 애니메이션에서 피해를 새로 발생시키지 않는다.
- 이동 루트와 시각적 몸통 움직임을 분리한다. 추격/급회전/경직/공격/사망 전환 시 다리·몸통 포즈가 남지 않게 한다. 2026-11-07 박쥐 얼굴 높이 비행 지시에 필요한 이동 높이/공격 원점 정렬은 별도 구현하고, 나머지 비행/돌진의 기존 서버 이동 계약은 유지한다.
- 장시간 경직·노출·사망·전투 종료·스트리밍 해제/복귀·재등장에서 상태를 초기화한다. 기존 사망 연출과 보상/사체 수명 주기를 보존한다.
- 종별 리그/소켓·일반/보스 크기와 장식은 원형을 유지한다. 전용 리그나 관절 추가가 필요한 경우 기존 스킨으로 가능한 범위와 신규 제작 비용을 따로 기록한다.

## 산출물과 인계

향후 `assets/animations/monster-motion-v1/`에 원형/파생SHA·편집원본·리그 매핑·클립/공격 대응표·내보내기 명령/버전·채택/복구 참조를 둔다. 큰 원본은 LFS로 관리하고 기존 파일을 덮어쓰지 않는다. `docs/evidence/monster-motion-<실행일>/`에 기준/개선 영상·검사 로그·미통과 항목을 보존한다. 실제 자산 업로드·게임 빌드·게시의 결과는 각각 별도 기록한다.

다음 담당자는 ART·ENG이며 영웅 파일럿 인계 후 MM-00을 진행한다. 현재 완료 범위는 계획 작성과 로컬 링크/회귀 파일 존재 검사이며, 새 모션 제작·재생·Studio·실기기 검증은 미실행이다.
