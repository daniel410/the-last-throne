# 무기·장비 선택형 특수 효과

2026-11-10 · TLT-027/029/041/044/052/057/084 · 0.97.0 · ENG → PLAN/QA

사용자 승인: 무기 및 장비에 특수 효과도 추가할 수 있게 한다. 기존 단일 기본 옵션은 유지하며 별도 `specialEffects`를 허용한다. 프로젝트 제작 스킬을 적용했다. [직전 디아블로·WoW 조사](../research/2026-11-10-weapon-effects-points-vs-percent.md)의 가산/곱산 구분과 비교 가독성을 적용한다. 해당 조사를 재사용하며 최신 라이브 수치를 새로 조사했다고 주장하지 않는다.

## 현재 구현 범위

기본 공격력/방어력/HP/MP/DEX는 기존 포인트다. 특수 효과는 카탈로그 정의에 선택적으로 붙이며 무기·방패·방어구·장신구 모두 지원한다. 기존 활성 장비에 임의로 효과를 배정하지 않았다. 새 Epic 아이템/등급별 효과 목록·수치·가격·드롭·보상·랜덤 옵션/재련 UI를 만든 작업이 아니다. 현재 무효과 장비의 성능은 동일하다.

`src/shared/EquipmentEffects.luau`가 정의 검사·장착 집계·서버와 미리보기의 배율·영어 설명을 공유한다. 아이템 인스턴스/Remote/클라이언트가 주장하는 효과 값은 원천으로 사용하지 않는다. 저장 스키마/아이템ID/인스턴스/강화·영수증 이관이 필요 없다. 기본 옵션 강화 규칙은 그대로이며 특수 효과는 강화 단계에 따라 증폭되지 않는다.

| 효과 ID | 적용 |
| --- | --- |
| `damage` | 모든 일반 공격·공격 스킬 피해 |
| `physical_damage` | 물리 일반 공격·공격 스킬 피해 |
| `magic_damage` | 마법 일반 공격·공격 스킬 피해, Mage 일반 공격 포함 |
| `basic_damage` | 물리/마법 일반 공격만 |
| `skill_damage` | 물리/마법 공격 스킬만; 선택형 `skillId`로 특정 기술 지정 |
| `damage_reduction` | 받는 적 공격/스토리 위험 피해 감소 |

효과 정의 예시(실제 아이템에 배정한 수치가 아님):

```lua
specialEffects = {
    {id = 'skill_damage', skillId = 'knight.common.whirlwind', value = 0.15},
}
```

위 예시는 Whirlwind 피해 +15%이며 공격력 +15포인트가 아니다. `skillId`는 기존 Config의 기본/전직/궁극기 ID 중 하나여야 한다. 잘못된 ID·NaN/무한대·0/음수·허용 외 키·중복 범위·비배열·소모품 효과는 정의 검사에서 거부한다. 런타임에서도 잘못된 효과는 무효 처리한다. 삭제 장비는 효과가 없다. 범용 효과도 허용하지만 Epic 이상의 빌드 특화가 우선 추천 방향이며, 모든 등급에 자동 효과를 주지 않는다.

## 계산·중첩·수명

- 장착한 자기 영웅의 장비 정의만 집계한다. 가방/창고/미수령/다른 영웅 장비는 기여하지 않는다. 교체 미리보기는 실제 자동 슬롯 결정 후 해당 슬롯을 제거하고 새 정의를 한 번 추가한다.
- 한 피해에 맞는 피해 보너스들을 합산한다. 예: 물리 피해10% + 스킬 피해15% → 해당 물리 스킬 ×1.25. 일반 물리 공격은 ×1.10이다. 각각 ×1.10×1.15로 계산하지 않는다.
- 초기 시험 보호값: 아이템당 최대4효과·개별 비율0초과1이하, 합산 피해 보너스 최대+100%, 피해 감소 최대50%. 현재 장비에는 배정이 없어 현재 성능에 영향을 주지 않는다. 이 상한은 최종 밸런스 승인값이 아니며 실제 아이템 설계와 함께 재수용한다.
- 공격 시작/시전이 서버에서 승인될 때 장비 배율을 고정한다. 일반 공격·투사체·다단히트·광역/전직/궁극기 모두 같은 공격 객체와 피해 경로를 사용해 각 타격에 정확히 한 번 적용한다. 적별 노출/표식 등 기존 전투 배율과 곱한 뒤 기존 최종 반올림을 적용한다. 추가 발동·회복·스택/타이머를 만들지 않는다.
- 받는 피해 감소는 기존 블록/기술 배율과 곱하고 반올림한 뒤 기존 방어 포인트·보호막 순서를 유지한다. 구규칙1~8의 직접 스토리 위험 피해는 기존 방어 미적용 경로를 유지하면서 특수 효과 감소만 반영한다. STR 방어0/VIT 투자 방향·HP 자연 회복 제거·MP 회복 계약은 유지한다.
- `power` 자체에는 특수 효과 배율을 더하지 않는다. 특정 기술만 강화하는 옵션을 모든 공격력이 증가한 것처럼 표시하지 않는다. 기본 옵션 강화·아이템 교체는 기존대로 현재 HP/MP를 회복하지 않는다.

## 표시와 다음 단계

가방의 별도 SPECIAL EFFECTS 설명, 실제 교체 전/후 효과 %와 차이(percentage points), 상점 상품/교체 설명, 강화 설명의 효과와 강화 불변 안내를 연결했다. TextService로 장비 설명과 비교 높이를 계산하고 기존 TD 프레임/버튼/아이콘을 유지한다. 기본 옵션은 pts, 효과는 % 단위를 쓴다. 비교는 효과 범위별 합계를 보여 주며 여러 범위가 동시에 맞는 최종 피해 배율과 동일하지 않다. 피해/스킬 미리보기에는 최종 합산 상한을 적용한다.
