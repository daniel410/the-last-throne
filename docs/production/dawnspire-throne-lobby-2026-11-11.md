## 공간과 미술

기존 200×200 지면과 스폰을 유지하고, 북쪽에 상시 존재하는 수정 왕좌 성소를 배치한다. 원점 `(0,96,512)`, 스폰 로컬 `(0,.1,24)`, 왕좌 로컬 `(0,0,-76)`. 청색 행렬길·금색 테두리·원형 집결 광장·창백한 성벽/흉벽·북쪽 쌍탑·열린 성소 아치가 하나의 축을 만든다. 좌우 정원은 외곽으로 옮겨 시설 접근 시야를 비운다. 직업 깃발 네 개는 성소 좌우 날개에 배치한다.

왕좌는 계단식 석조 단상, 유리 수정 등받이/첨탑, 금색 팔걸이와 왕관, 비어 있는 심장 받침으로 구성한다. 성소 계단 높이는 .35stud씩 네 단이며 점프가 필수가 아니다. 전경의 세계 간판은 짧은 영어 문구를 사용하고, 기존 TD 프레임·메뉴·버튼·아이콘·영웅 초상은 기존 구현을 그대로 사용한다. 기존 시설 좌표/프롬프트/서버 서비스는 유지한다.

## 이야기와 구현 계약

공용 서버 왕좌에는 심장이 없다. 영어 간판은 `THE CRYSTAL THRONE` / `The Crownheart is missing. Bring our light home.`를 표시한다. 선택 영웅의 서버 스냅숏 `deepwood.clears['HG-07'] == true`일 때만 해당 클라이언트에 청록색 수정 심장·보호의 고리·따뜻한 귀환 문구를 만든다. 완료 간판은 `The Crownheart is home. Dawnspire shines again.`이다. HG07을 마치지 않은 영웅, 선택 해제, 불완전 저널은 복원 상태를 받지 않는다.

과거 남쪽에 별도 생성되던 완료 전용 임시 왕좌를 제거하고 같은 북쪽 왕좌의 받침을 복원한다. 영웅 교체 때 개인 심장을 정리하며 반복 스냅숏은 중복을 만들지 않는다. 왕좌 모델은 Atomic 단위로 스트리밍하고 스냅숏보다 늦게 도착/재유입하면 최신 스냅숏으로 다시 표시한다. 개인 심장의 모든 Part는 충돌/질의/터치가 없고, 서버 진행·보상·권리·저장에는 쓰지 않는다. 재회 NPC와 기존 사이드 귀환 장면은 유지한다.

신규 원본은 Roblox 네이티브 Part/CornerWedgePart 기반 코드다. 기존 왕좌 메시가 레지스트리에 확정되지 않아 외부 자산 업로드 없이 새 모델을 제작한다. TD 공유 자산/시설/무기는 기존 모듈에서 재사용하고 TD 소스는 수정하지 않는다. 승인된 Dawnspire 컨셉의 청색·금색·밝은 석재 방향을 참고하되 전체 고해상도 컨셉 미술과 같다고 선언하지 않는다. Blender 작업은 없으며 Roblox 실제 화면을 별도로 검토한다.
