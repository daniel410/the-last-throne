# 몬스터 이동·무기·마법 전투 사양

2026-11-15 · TLT-005/027/033/050/057/061~065/084 · ENG/ART → QA

사용자 요청에 따라 기존 50종·146공격을 종별 특성·무기·난이도에 맞춰 개선한다. 종별 정본은 `EnemyCombatProfiles.rows`, 공격 원형은 `EnemyPatterns.profiles`다. [공식 RPG 비교 조사](../research/2026-11-15-monster-combat-design.md)와 [검증·미검증](../evidence/monster-combat-20261115/README.md)을 연결한다. 수치는 로컬 시험값이며 재미·실기기 수용은 별도다.

## 종별 이동과 공격

| 역할 | 대표 몬스터 | 동작과 대응 |
| --- | --- | --- |
| Skirmisher | Goblin, Skeleton, VenomcoilCentipede | 측면 접근과 좁은 찌르기. 대기 중 짧게 각도를 바꾸며 옆으로 피할 공간 제공 |
| Bruiser | Orc, Ogre, IceBear, Zombie | 정면의 느린 정렬. 도끼의 넓은 베기와 둔기의 무거운 내려치기, 긴 회수 구분 |
| Pouncer | Slime, IceWolf, Gloambat, Ghoul, Hellhound, MagmaWorm | 접근과 준비를 분리. 일반 IceWolf는 근접 전용, 기존 돌진 보유 종만 예고된 직선 이동 |
| Guardian | Golem, IceGolem, SkeletonKnight, Hollowbark 계열, CalderaTitan | 작은 측면 이동과 무거운 선회. 기존 준비 중 전방 방어를 측후방·회수로 공략 |
| Caster | Shaman, KingShaman, VolcanoShaman, Lich | 18~20 stud 전후 선호. 압박 시 0.85초 후퇴 시도·5초 재시도 간격, 경계에서는 멈추고 전투 |
| Artillery | IceElf, QueenIceElf, Imp, MagmaImp | 18~22 stud에서 사격·측면 재배치 교대. 고정 발사선 사이로 접근 가능 |
| Controller / Commander | Silkweaver, WidowQueen, Mummy, LichSovereign / Warlord, DeathKnight, Veyr | 각각 순차 지역 봉쇄 / 근접·원거리 조합을 거리와 준비된 기술에 따라 선택 |

같은 측면을 수초간 유지하고 같은 교전 안에서만 몬스터 간격을 보정한다. 벽·중간 바닥·경사·높이·스폰 leash를 검사하며, 안전한 직선이 없으면 경로를 요청한다. 경로가 없거나 소진되면 현재 위치에서 기다린다. 공격 중 추격·자동 추적 회전은 중단한다. 유효 거리·쿨다운·직전 공격·보스 체력을 사용해 공격을 선택하며, 다른 공격이 준비되지 않았을 때 사용 가능한 기본기를 봉쇄하지 않는다. 기존 일반 적 시작 간격 0.24초·같은 교전 강공격 동시 1개 제한을 유지한다.

단검은 좁은 찌르기·연타, 도끼·대검은 넓은 베기, 둔기·주먹은 긴 준비와 회수로 구분한다. 일반 Goblin/Orc/Ogre/IceWolf/IceBear는 6 stud 이하 근접만 사용한다. SkeletonKnight 방패·지네 독침의 찌르기도 실제 근접 범위로 보정한다. IceElf·기존 마법형과 보스의 원거리 역할은 유지한다.

## 마법의 공간 특성

- 화염 원형 공격은 고정 지점에 0.7초 간격의 2~3회 폭발을 일으킨다. 얼음 고리는 0.65초 간격으로 반경이 확대되며 다음 경계를 미리 표시한다.
- 독·거미줄·영혼의 순차 지대와 탄환은 각기 다른 간격·속도·확산을 사용한다. 별도 Burn/Poison/Slow 상태이상은 추가하지 않는다.
- 준비 시작 때 방향·표적 지점·발사 원점을 고정한다. 실제 투사체와 부채탄은 동일한 발사선·벽 검사를 사용한다. 근접·돌진·탄환의 충돌 반경을 경고에 반영한다.
- 다단 공격은 한 번의 기존 정수 피해 예산을 정확히 나눈다. 같은 펄스의 부채탄 중복 피해를 막고 매 펄스마다 서버의 원정·생존·방어 검사를 반복한다. 지연된 과거 접촉은 재생하지 않는다.

## 난이도와 보스

| 모드 | 전술·주기 | 학습·반격 |
| --- | --- | --- |
| Easy | 재사용 간격 ×1.12, 약한 측면 압박 | 준비 +0.12초·회수 +0.1초 |
| Hard | 종별 기본 주기·거리 운용 | 무기 고유 준비·회수 유지 |
| Insane | 재사용 간격 ×0.94, 일부 시전자 후속 연사·화염/얼음 3펄스 | 예고·안전지대 유지 |
| Hell | 재사용 간격 ×0.88, 강한 측면 압박·후속 조합 | 준비 최소 1초·회수 최소 0.8초 |

보스 HP 50% 이하에서는 재사용 간격 추가 ×0.94와 기존 다발탄의 소폭 확산으로 2단계를 구성한다. 체력 복구·신규 증원·보상·무적을 만들지 않는다. 기존 보스 템포 보정은 유지하되 최종 회수는 일반 0.8초·강공격 1.1초 이상이다. 저장 규칙 1~8은 기존 공격 경로, 기존 패턴 사용 규칙 9 이상은 개선 경로를 사용한다. 성장·보상 규칙 버전은 이 변경으로 증가하지 않는다.

## 표현과 수용

서버 최종 정의를 `begin.definition`과 `K0PatternDefinition`으로 공유해 애니메이션·경고·마법 속도를 일치시키고 스트리밍 후에도 복원한다. 일반 리그·Gloamwood 스킨·지역 시전자는 실제 이동량에 따라 후진 보행·측면 기울기를 보정한다. 기존 원본 모델과 클립을 사용하며 새 업로드 자산은 없다.

QA는 고정 빌드의 각 지역·난이도 정상 전투, 네 클래스 솔로·1~4인+AI, 지연·재접속·중도 합류, PC/터치/패드, 작은 화면·성능과 사용자 난도·미술 수용을 확인한다. 격리 엔진 검사만으로 이 게이트를 닫지 않으며 부모 티켓은 진행 중이다.
