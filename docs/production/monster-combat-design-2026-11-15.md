# 몬스터 이동·무기·마법 전투 사양

2026-11-15 · TLT-005/027/033/050/057/061~065/084 · ENG/ART → QA

사용자 요청에 따라 기존 50종·146공격을 종별 특성·무기·난이도에 맞춰 개선한다. 종별 정본은 `EnemyCombatProfiles.rows`, 공격 원형은 `EnemyPatterns.profiles`다. [공식 RPG 비교 조사](../research/2026-11-15-monster-combat-design.md)와 [현재 확장 검증·미검증](../evidence/monster-encounter-depth-20261115/README.md)을 연결한다. 0.110.0 확장에서는 무리 협력·지원 중단·원소 실효과·3단계 공략을 추가한다. 수치는 로컬 시험값이며 재미·실기기 수용은 별도다.

## 상위 난이도 공격력과 추적 유지

후속 사용자 지시로 Hard/Insane/Hell의 몬스터 공격력을 상향한다. 규칙18의 일반·정예·보스 모드 공격 계수는 규칙17 대비 각각 **×1.25 / ×1.35 / ×1.50**이다. 최종 피해는 기존 정수 반올림·영웅 방어·블록·효과를 거친다. Easy·적 체력·레벨·보상·입장 조건은 보존한다. 구 규칙으로 진행 중인 원정은 해당 규칙을 유지하며 새 원정/재입장에18을 고정한다. 구체 비율은 시험 조정값이며 최종 체감 수용은 후속이다. [비교 근거](../research/2026-11-15-advanced-monster-damage.md)·[구현/엔진 증거](../evidence/advanced-monster-combat-20261115/README.md).

추적 중 영웅을 향해 선회한 직후에도 마지막으로 안전성이 확인된 이동점을 다시 명령한다. 경로 계산은 기존0.25초 주기를 유지한다. 공격 시작·기절·경로 차단·정지 시 저장 이동점을 버려 이전 추적이 재개되지 않게 한다.

## 종별 이동과 공격

| 역할 | 대표 몬스터 | 동작과 대응 |
| --- | --- | --- |
| Skirmisher | Goblin, Skeleton, VenomcoilCentipede | 측면 접근과 좁은 찌르기. 대기 중 짧게 각도를 바꾸며 옆으로 피할 공간 제공 |
| Bruiser | Orc, Ogre, IceBear, Zombie | 정면의 느린 정렬. 도끼의 넓은 베기와 둔기의 무거운 내려치기, 긴 회수 구분 |
| Pouncer | Slime, IceWolf, Gloambat, Ghoul, Hellhound, MagmaWorm | 접근과 준비를 분리. 일반 IceWolf는 근접 전용, 기존 돌진 보유 종만 예고된 직선 이동 |
| Guardian | Golem, IceGolem, SkeletonKnight, Hollowbark 계열, CalderaTitan | 작은 측면 이동과 무거운 선회. 기존 준비 중 전방 방어를 측후방·회수로 공략 |
| Caster | Shaman, KingShaman, VolcanoShaman, Lich | 18~20 stud 전후 선호. 압박 시 0.85초 후퇴 시도·5초 재시도 간격, 경계에서는 멈추고 전투 |
| Artillery | IceElf, QueenIceElf, Imp, MagmaImp | 18~22 stud에서 사격·측면 재배치 교대. 고정 발사선 사이로 접근 가능 |
| Controller / Commander | Silkweaver, WidowQueen, Mummy, LichSovereign / Warlord, DeathKnight, Veyr | 각각 순차 지역 봉쇄 / 근접·원거리 조합을 거리와 준비된 기술에 따라 선택 |

같은 측면을 수초간 유지하고 같은 교전 안에서만 몬스터 간격을 보정한다. 벽·중간 바닥·경사·높이·스폰 leash를 검사하며, 안전한 직선이 없으면 경로를 요청한다. 경로가 없거나 소진되면 현재 위치에서 기다린다. 공격 중 추격·자동 추적 회전은 중단한다. 유효 거리·쿨다운·직전 공격·보스 체력을 사용해 공격을 선택하며, 다른 공격이 준비되지 않았을 때 사용 가능한 기본기를 봉쇄하지 않는다. 기존 일반 적 시작 간격 0.24초·같은 교전 강공격 동시 1개 제한을 유지한다.

단검은 좁은 찌르기·연타, 도끼·대검은 넓은 베기, 둔기·주먹은 긴 준비와 회수로 구분한다. 일반 Goblin/Orc/Ogre/IceWolf/IceBear는 6 stud 이하 근접만 사용한다. SkeletonKnight 방패·지네 독침의 찌르기도 실제 근접 범위로 보정한다. IceElf·기존 마법형과 보스의 원거리 역할은 유지한다.

## 마법의 공간 특성

- 화염 원형 공격은 고정 지점에 0.7초 간격의 2~3회 폭발을 일으킨다. 얼음 고리는 0.65초 간격으로 반경이 확대되며 다음 경계를 미리 표시한다.
- 독·거미줄·영혼의 순차 지대와 탄환은 각기 다른 간격·속도·확산을 사용한다. 아래 원소 실효과를 실제 HP 손실 뒤에 적용한다.
- 준비 시작 때 방향·표적 지점·발사 원점을 고정한다. 실제 투사체와 부채탄은 동일한 발사선·벽 검사를 사용한다. 근접·돌진·탄환의 충돌 반경을 경고에 반영한다.
- 다단 공격은 한 번의 기존 정수 피해 예산을 정확히 나눈다. 같은 펄스의 부채탄 중복 피해를 막고 매 펄스마다 서버의 원정·생존·방어 검사를 반복한다. 지연된 과거 접촉은 재생하지 않는다.

## 난이도와 보스

| 모드 | 전술·주기 | 학습·반격 |
| --- | --- | --- |
| Easy | 재사용 간격 ×1.12, 약한 측면 압박 | 준비 +0.12초·회수 +0.1초 |
| Hard | 종별 기본 주기·거리 운용 | 무기 고유 준비·회수 유지 |
| Insane | 재사용 간격 ×0.94, 일부 시전자 후속 연사·화염/얼음 3펄스 | 예고·안전지대 유지 |
| Hell | 재사용 간격 ×0.88, 강한 측면 압박·후속 조합 | 준비 최소 1초·회수 최소 0.8초 |

보스는 HP 70%·35%를 경계로 3단계를 사용한다. 단계마다 `EnemyEncounterMechanics`의 공격 연결 순서와 공간 기하를 적용한다. 이전의 단순 쿨다운·확산 변경을 대체한다. 마지막 공격의 회수 1.6~2.8초에는 전 방향·후방·측면 중 지정된 방향에서 25% 추가 피해를 주는 반격 창을 연다. 같은 창을 중첩하지 않으며 기존 자세 붕괴·기술 판정과 구분한다. 최종 회수는 반격 창보다 짧지 않다.

대표적으로 Warlord는 교차 선과 세 갈래 압박, KingOgre는 외곽 고리→중앙 폭발→외곽 고리, QueenIceElf는 굴절 연사와 삼각 낙하, Veyr는 교차 베기·안팎 전환·엇갈린 관문으로 발전한다. 방향·지점은 시작 시 고정하며 **모든 후속 위험을 첫 준비부터 예고**한다. 원·선·고리와 회전·중심 이동은 서버/클라이언트 공통 `EnemyAttackFrame`으로 계산한다.



## 무리 협력과 우선 목표

Shaman·KingShaman·VolcanoShaman·KingVolcanoShaman·Silkweaver·WidowQueen·Mummy·Lich·LichSovereign·QueenIceElf는 근처 일반 동료 하나에게 Ward를 시전한다. Warlord·EnragedWarlord·DreadCommander·InfernoOverlord·Veyr는 최대 세 일반 동료에게 Rally를 시전한다. 혼자 남으면 지원 행동을 선택하지 않는다.

- 지원은 공격 두 번 이후부터 한 공격 차례를 대체한다. Ward 준비 1.8초·Rally 1.6초, 같은 교전의 동시 지원 하나, 거리 18 stud·지속 5초·재사용 12/14초다.
- Ward는 대상 최대 HP의 18%와 시전자 기본 피해 두 배 중 작은 유한 양을 흡수한다. 실제 HP를 복구하거나 서로 중첩하지 않는다. Rally는 동료의 다음 공격 재사용 시간을 15% 줄이며 피해량·체력·적 수를 늘리지 않는다.
- **모든 클래스의 실제 피해로 지원 준비를 끊을 수 있다.** 시전자는 짧은 경직과 2초 전 방향 반격 창을 갖고, 지연 프레임에서도 서버 승인 타격 시각이 시전 완료보다 앞이면 중단이 먼저다.
- 지원은 같은 원정·유효 시야·높이·거리의 동료만 연결한다. 시전자의 스턴·귀환·사망·삭제·서사 중단이나 연결 거리/시야 이탈은 남은 지원을 해제한다. 보스/무한 증원·공짜 재화·영속 권리를 만들지 않는다.
- 같은 영웅에 대한 동시 공격은 Easy 1개·상위 2개로 제한한다. 다른 유효 표적이 약간 가까워졌다는 이유만으로 공격 대상을 계속 바꾸지 않는다. 강공격 1개·시작 간격의 기존 제한도 유지한다.

## 실제 원소 효과

| 원소 | 명중 후 효과 | 공략·제한 |
| --- | --- | --- |
| Fire | 원시 피해 25%를 0.6초 간격 두 번의 Burn으로 분할 | 직접+지속 원시 예산은 기존 1회분. 반복 경직·스킬 중단 없음 |
| Venom | 원시 피해 30%를 같은 유한 지속 구간으로 분할 | 동일 독의 중첩·시간 갱신 없음 |
| Frost | 1.4초 동안 이동 배율 0.8 | 조작 봉쇄·빙결 없음 |
| Web | 1.2초 동안 이동 배율 0.75 | 냉기와 곱하지 않고 강한 감속만 적용, 감속 하한 0.7 |
| Shadow | 1.5초 동안 가하는 피해 배율 0.85 | 약화 중첩 없음, 원소 약화 하한 0.8 |
| Soul | 1.4초 동안 가하는 피해 배율 0.9 | 클래스별 자원 강탈·보스 회복 없음 |

실제 HP 손실이 있는 방어되지 않은 명중이고 보호막 흡수량도 0일 때만 적용한다. 방어·회피·완전 흡수·ForceField에는 효과가 없다. 지속 피해도 서버의 생존·원정·캐릭터/영웅 identity·방어/방어구·보호막을 다시 검사한다. 정상 공격 완료 후 남은 효과는 유지하지만 실제 소스 취소·귀환·사망·서사 중단에는 제거한다. 각 tick의 방어·반올림 때문에 최종 HP 손실이 원래 단타와 동일하다고 주장하지 않는다. 큐 128개·한 step 피해 호출 32개·지난 tick 허용 0.18초로 제한한다.

기존 일반 근접 전용 5종·IceElf 거리 역할·원정 규칙 1~8의 기존 공격 경로·승인 성장/보상과 TD 분리 계약은 유지한다. 새 효과는 기존 패턴을 사용하는 규칙 9 이상에 적용한다. [원소 설계 조사와 수명 계약](../research/2026-11-15-monster-encounter-depth.md)을 따른다.

## 표현과 수용

서버 최종 정의를 `begin.definition`과 `K0PatternDefinition`으로 공유해 애니메이션·경고·마법 속도를 일치시키고 스트리밍 후에도 복원한다. 일반 리그·Gloamwood 스킨·지역 시전자는 실제 이동량에 따라 후진 보행·측면 기울기를 보정한다. 기존 원본 모델과 클립을 사용하며 새 업로드 자산은 없다.

QA는 고정 빌드의 각 지역·난이도 정상 전투, 네 클래스 솔로·1~4인+AI, 지연·재접속·중도 합류, PC/터치/패드, 작은 화면·성능과 사용자 난도·미술 수용을 확인한다. 격리 엔진 검사만으로 이 게이트를 닫지 않으며 부모 티켓은 진행 중이다.
