# 장비 희귀도 외형 차별화 v2

2026-11-08 · TLT-028/029/032/041/052/073/082/084 · DES/ART → ENG → QA

사용자 요청: Rare/Epic/Legendary/Unique가 비슷해 보이며 **아이콘과 착용한 3D 장비 모두** 차이를 만든다. 현재 산출물은 외형 설계와 후드 4등급 비교 시안1장이다. 160개 아이콘 교체·3D 제작·게임 적용 완료가 아니다. 기존 아이콘/TD 원본·ID·수치·보유품은 유지한다. 전체적인 시안 방향은 사용자 긍정 평가를 받았으며, 에픽 꼭대기와 유니크 재질은 아래 r2로 수정했다. 수정본의 최종 수용은 후속이다.

## 현재 문제와 근거

[기존 비교 보드](../../assets/concepts/2026-11-04-equipment-icons/comparison.html)의 후드 네 PNG를 직접 열어 비교했다. Rare/Epic은 둥근 후드 윤곽·청록 안감·가죽 구성이 거의 같고 Epic은 주로 은색 입구 테두리를 추가한다. Legendary/Unique는 중앙 보석·금속 이마 장식·금색 테두리가 반복된다. 모든40계열을 육안 검수했다고 주장하지 않는다.

3D 소스 `src/server/Cosmetics/WeaponAppearance.luau`의 SPECS는 클래스별 기본 무기 템플릿을 선택한다. `KnightAppearance.luau`도 클래스 기반 부착을 호출한다. 따라서 아이콘을 바꾸는 것만으로 실제 착용 외형까지 바뀌지 않는다. 소스 열람 결과이며 실행 중인 Studio/게시 게임의 전수 검증은 아니다. 두 파일은 별도 진행 중 변경이 있어 이번 작업에서 편집하지 않았다.

## 네 등급의 조형 문법

| 등급 | 인상 | 실루엣·구조 | 재질·장식 |
| --- | --- | --- | --- |
| Rare | 숙련된 모험가의 실용 장비 | 간결한 둥근/직선 윤곽, 기능적인 부품 | 가죽·천·강철의 큰 면2~3개, 단순 체결, 무발광 |
| Epic | 클래스 정체성이 보이는 명품 | 낮고 둥근 꼭대기·겹판·보강 구조, 클래스 상징1개 | 대비되는 보강재, 작은 보석 선택1개, 정돈된 문양 |
| Legendary | 왕실·고대 영웅의 유물 | 왕관형 곡선·뚫린 공간·큰 상징 구조, Epic와 다른 균형 | 은/금 인레이·깊은 색 직물·중심 보석1개, 제한된 표면 발광 |
| Unique | 이름과 보스가 떠오르는 단 하나의 전리품 | 보스 특징을 구조로 바꾸는 전용 윤곽, 의도적인 비대칭 가능 | 단조 금속을 주재료로, 보스 소재는 보석·인레이·문양의 보조 요소로 표현 |

기존 Rare→Epic→Legendary→Unique 순서와 Unique 우위 계약은 유지한다. Unique의 위압감은 큰 주요 면과 뛰어난 제작 완성도로 표현한다. 모든 Unique를 금색 왕관+큰 보석으로 만들지 않는다. 색은 클래스/지역 정체성과 기존 희귀도 UI를 보조하며, 등급 구분의 첫 단서는 형태다. 상시 오라·입자 수를 늘려 등급을 표현하지 않는다.

## 후드 파일럿

[최신 비교 시안 r2](../../assets/concepts/2026-11-08-rarity-shapes-v2/hood-comparison-r2.png) · [수정 입력/출처](../../assets/concepts/2026-11-08-rarity-shapes-v2/manifest-r2.json) · [이전 시안 보존](../../assets/concepts/2026-11-08-rarity-shapes-v2/hood-comparison.png)

- Rare: 낮고 둥근 가죽 여행 후드.
- Epic: 사용자 피드백으로 뾰족한 꼭대기를 제거한 낮고 둥근 후드. 여러 겹 측면과 은색 이마 보강으로 Rare와 구분한다.
- Legendary: 빈 공간이 있는 왕관형 금속 아치와 왕실 직물.
- Unique Quarrykeeper Hood: 기존 KingOgre 연결/안정ID를 유지하는 후보. 사용자 피드백으로 돌 덩어리 외피를 단조한 짙은 강철 판금·청동/금색 체결부로 변경한다. 비대칭 금속 능선과 측면의 정교한 호박 보석 소켓으로 채석 군주 테마를 절제해 표현한다. 거친 암석·용암 균열은 제거한다. 이 조형은 KingOgre 실제 모델의 정확한 복제가 아니며 보스 원형과의 대응 수용은 후속이다.

시안은 단일 이미지 생성 도구의 컨셉 보드다. 개별 투명 아이콘·메시·게임 UI 화면이 아니며 Blender Standard 렌더를 했다고 보고하지 않는다. 같은 슬롯/비슷한 화면 점유율로 다시 제작하여 크기만으로 등급을 구분하지 않도록 한다.

## 아이콘과 3D를 맞추는 제작 규칙

1. 기존 familyId/definitionId별로 `아이콘 경로 + 3D 자산키 + 대표 윤곽 + 재질 + 원본 해시`를 연결한다. 동일 등급이라도 클래스를 지우지 않는다. 기사 검은 곧은 검, 엘프는 활, 드워프는 도끼, 마법사는 지팡이/천 후드 원형을 지킨다.
2. 대표4클래스 무기와 공통 후드의5계열×4등급=20변형을 먼저 제작·비교한다. 현재 생성된 것은 후드 보드1장뿐이다. 무기20개나 장비160개 완성을 뜻하지 않는다.
3. 승인 TD 원본 계보를 보존한 파생3D를 제작한다. 손잡이 피벗·Attachment·Motor6D 이름·그립 축·활 시위/화살 위치·도끼 날 방향·검 트레일 기준을 유지하고 장식은 판정과 분리한다. 방어구는 얼굴/손/관절과 겹치지 않게 한다.
4. **View Transform = Standard**, Display=sRGB, Look=None, Exposure=0, Gamma=1, Use Curves=Off를 새 장면/가져오기/렌더 직전에 확인한다. 색 텍스처=sRGB, 데이터 맵=Non-Color, 재질 숫자는 scene-linear 입력. AgX 화면/임의 채도 증가로 색을 맞추지 않는다.
5. 검증된3D에서 동일 카메라·조명·정규화된 여백으로 개별 투명 아이콘을 렌더해 두 표면의 주된 특징을 일치시킨다. 기존 TD 프레임·버튼·아이콘 배치·희귀도 표기를 유지한다. 반지/목걸이는 8슬롯 정책 안에서 표시하고 신규 외형 슬롯을 만들지 않는다.
6. 서버가 확정한 장착 definitionId를 검증된 외형키로 연결한다. 미지원 외형은 기존 클래스 기본 외형으로 명시적으로 대체하고 소유/장착/피해·능력치를 변경하지 않는다. 재장착·리스폰·영웅 변경 시 이전 외형을 정리한다. 실제 동기화 구현은 후속이다.

## 수용 조건과 인계

제안 시험: 48/64px·밝고 어두운 배경·회색조·검정 실루엣에서 라벨을 가린 네 등급을 구분한다. 사용자5명 이상에게 섞어서 제시해 전체 정답률90%를 목표로 측정하되 아직 측정값은 없다. 3D는 정면/측면/후면·전투 카메라에서 같은 특징을 확인하고 기본 공격/블록/회피/스킬 중 관절·시야·무기 궤적 간섭을 검사한다. 4인+AI1 모바일에서 기존 대비 렌더 비용을 측정하며 숫자 예산은 실측 후 정한다. Roblox 실제 조명 비교는 Standard 컨셉 렌더와 별도다.

검증: 후드 기존4PNG 육안 비교, 생성 보드1장 육안 확인(네 윤곽/등급 라벨/인물 없음), PNG/메타데이터·상대 링크·Git 공백 검사. 미검증: 흑백/48px 사용자 식별률, 나머지39계열, 전체 아이콘 개별 생성/등록, Blender 메시·리깅·장착·모션·Studio·실계정/기기 성능. 빌드/게시/릴리스 없음, VERSION 유지. 부모 티켓은 완료로 바꾸지 않는다.

다음 담당: DES/ART가 후드/무기20변형의 일관된 모델·개별 아이콘을 제작하고, ENG가 장착 정의별 외형 동기화, QA가 식별률·모션·실기기를 확인한다. [비교 리서치](../research/2026-11-08-equipment-rarity-visuals.md).

## 2026-11-08 사용자 리뷰 반영 r2

전체적인 차별화 시안은 긍정 평가를 받았다. 에픽은 너무 뾰족하다는 지적을 반영해 머리 곡선을 따르는 둥근 꼭대기로 수정했고, 유니크는 돌 위주라는 지적을 반영해 금속 판금 주재료로 수정했다. Rare/Legendary의 디자인·전체 배치·조명은 유지하도록 편집했다. 이미지 생성 스킬의 내장 도구를 사용했고 입력 원문은 `prompt-r2.txt`로 보존했다.

변경 범위: r2 비교 PNG·프롬프트·메타데이터와 이 명세. 검증: 생성 이미지 육안 확인(에픽 둥근 상단·유니크 금속 반사/판금·기존 두 등급 방향 유지), PNG 헤더/치수·SHA-256·상대 링크·Git 공백 검사. r2는 별도 파일로 저장하여 이전 시안을 보존한다. 수정본 수용·개별 투명 아이콘·3D 제작/Standard 렌더·게임 적용/실기기는 미검증이다. 빌드·VERSION·릴리스는 변경하지 않는다. 다음 담당은 DES/ART의 수정본 기준 후드/무기 파일럿 제작이며 부모 티켓은 미완료다.
