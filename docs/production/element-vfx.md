# 속성별 마법 VFX 기준

TLT-033/057 · 2026-11-12 사용자 지시: 불·물·바람·번개·얼음·땅은 각각의 속성이 확실히 드러나야 하며, 성속성은 금빛 효과를 사용한다. 색만 교체한 동일한 구형 효과로 속성 구별을 대신하지 않는다.

| 속성 | 주 형태·움직임 | 색·재질 | 구분 기준 |
| --- | --- | --- | --- |
| Fire | 뾰족하게 흐르는 화염, 명중 끝의 불꽃, 위로 올라가는 불티/불기둥 | 주황/적색 불꽃·호박색 중심 | 물보라/결정과 다른 상승·소멸 방향 |
| Water | 둥근 물방울, 퍼지는 물결과 기울어진 물마루·옅은 포말 | 청색 물·Glass 방울/물마루 | 얼음의 단단한 쐐기/파편과 다르게 매끈한 곡면·바깥으로 튀는 흐름 |
| Wind | 발사축을 감는 회전 기류·넓은 공기 리본·접촉 돌풍 | 옅은 민트/백색 | 불꽃/물기둥 대신 공기의 방향과 소용돌이가 보임 |
| Lightning | 꺾인 주 방전·옆 분기, 짧은 섬광 | 청색 외곽·밝은 중심 | 보라색 비전 마법과 구별. 반복 스트로브 대신 단발 방전과 짧은 소멸 |
| Ice | 뾰족한 얼음창·각진 파편·분리된 지면 결정 | 옅은 청색·Ice 재질 | 물과 공유하는 단색 원반을 사용하지 않음 |
| Earth | 거친 바위창·지면에서 솟는 바위·균열·무거운 파편 | 흙빛/갈색·Slate 재질 | 투명 마법 구체 대신 불투명한 암석의 면과 지면 상승 |
| Holy | 빛의 인장·상승 광선·금빛 검기/방패·명중 빛 | 주색RGB255/189/50, 하이라이트255/226/128 | 전방 방패/검기 모양을 유지해도 성속성 전체는 금빛. 공통 방패의 청색이 성속성을 덮지 않음 |

구현 위치: `HeroVFX`의 계열 형상/입자/장식, `AdvancedSkillVisual`의 기본 선/면, `PixelFXCatalog`의 속성 선택, `K0HitEffects`의 기존 명중 표현. 바람은 검증된 `WindLanceVisual` 전용 렌더러를 보존한다. 성속성13기술은 스킬/명중/강조빛까지 금빛으로 연결한다. 일반 물리 방패·비전 방어·Selene의 별도 지원 액션은 기술 정의의 속성과 구별해 취급한다.

서버 기술 정의의 속성/피해/상태/범위/MP/쿨다운/해금은 변경하지 않는다. 시각 장식은 실제 피해 경계의 정본이 아니며 기존 범위 정보·시전 순서·권위 이벤트를 유지한다. 물/불/얼음/땅의 투사체와 광역 기술이 동일 형상일 필요는 없지만 위 속성 단서를 공통으로 유지한다. Lava/Steam 같은 복합 표현은 기존 기술의 실제 속성과 효과를 보존하고 새 속성 판정을 만들지 않는다.

근거: [Diablo 및 RPG 조사](../research/2026-11-12-combat-vfx-game-references.md), [WoW의 직업 정체성/원형 보존 원칙](../research/2026-11-12-wow-vfx.md). 구체적 색·모양은 최신 사용자 요청을 반영한 우리 게임의 기준이며 참고 게임의 원본 자산을 복제하지 않는다.

검증: [속성별 전후·실제 엔진 검사](../evidence/element-vfx-20261112/README.md). 다음 ART/QA는 실제 영웅/장비, 밝고 어두운 지역, 다인 교전·터치 기기에서 색을 가리거나 흑백으로 보아도 형상/흐름이 구별되는지, 캐릭터와 위험 바닥이 가려지는지 확인한다. 격리 모형 캡처·수치 검사를 사용자 최종 미술 수용으로 보고하지 않는다.

검기·접촉의 시간 구성: 검기 면은 휘두르는 축을 따라 회전하고 화염은 가늘어지는 꼬리를 사용한다. 물/중력·대지/폭발 장식은 중앙이 열린 띠로 바닥을 노출한다. 명중 중심광은0.08초 안에 소멸하고 열린 압력파는0.23초 안에 끝난다. 이는 클라이언트 장식의 시간이며 서버 타격 시점·범위/예고를 변경하지 않는다. [Roblox RPG 비교 근거](../research/2026-11-13-roblox-rpg-vfx.md)·[전후/엔진 검증](../evidence/roblox-rpg-vfx-20261113/README.md).

번개 분기는 실제 꺾인 주 경로에 붙이고 선/면이 같은 점을 공유한다. 냉기 광역은 밑동이 지면에 고정된 높이가 다른 결정을 각각0.18초에 걸쳐 성장시킨다(장식 지연 최대0.024초). 우박/화살비의 본체와 잔광은 같은 가속 하강 궤적을 사용한다. 기존 확정 펄스 이후의 장식이며 서버 피해·피격·범위 시점을 새로 만들지 않는다.
