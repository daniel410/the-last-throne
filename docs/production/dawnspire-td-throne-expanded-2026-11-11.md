# TD 로비 왕좌 재사용과 Dawnspire 확장

2026-11-11 · TLT-001/028/031/050/052/057/084 · DES/ENG → QA · 0.100.2

사용자 피드백은 ‘TD의 왕좌와 너무 다르게 생겼다’, 추가 지시는 ‘로비 크기도 늘려 달라’다. 기존 청록 유리 의자를 제거하고 **TD 로비의 금색 프레임·청색 벨벳·높은 뾰족 등받이 왕좌**를 재사용한다. TD 전투 맵의 분홍 수정 왕좌와 구분한다. 왕좌 종류 질문에 추가 답변이 없는 상태에서 로비 맥락의 원본을 기준으로 진행했으며, 별도의 사용자 선택 승인을 주장하지 않는다.

## 왕좌 원본

`../throne-defense/src/Server/VisualFactoryLobby.lua`의 `ThroneDais`~`RoyalThroneFinial` 구간과 `VisualFactoryLobbyArchitecture.lua`의 beam/arch/crest 함수를 스냅숏한다. [추출 도구](../../tools/snapshot-td-lobby-throne.py)·[출처/현재 해시](../../assets/shared/td-lobby-throne/provenance.json)·[런타임 모듈](../../src/shared/TDLobbyThroneGeometry.luau). 형상을 다시 그리지 않고 TD의 원래 크기·위치 관계를 유지한다. 최종 Gold 패스의 본체 RGB240/175/50·반사0.18과 청색 Fabric RGB37/62/109를 사용한다. 별도 TD 금속 MaterialVariant/얇은 하이라이트 패스와 미게시 Blender 로비 메시까지 가져왔다는 뜻은 아니다.

RPG 어댑터는 왕좌 좌표를 평행이동해 새 북쪽 단상에 배치한다. 좌석12×2×8, 등받이11×21×2, 청색 방석/등받이, 양쪽 팔걸이·다리·26높이 장식 기둥·뾰족 왕관을 보존한다. 바깥 성소 아치는 높여 의자와 겹치지 않게 한다. 8단 진입 계단은 .225stud 간격으로 TD 단상 상면1.8stud까지 연결한다. 새 계단은 RPG 로비 보행용이다.

왕관의 심장 받침은 **의자 앞 별도 위치**에 둬 TD 좌석을 덮지 않는다. 기존 서버 HG07 완료 영웅만 개인 심장/빛을 표시한다. 미완료/선택 해제/불완전 저널·스트리밍 재유입 계약은 유지하고 저장·보상·지원권은 변경하지 않는다.

## 확장 배치

지면은 **200×200 →300×300stud**, 면적40,000→90,000으로 **2.25배(+125%)**다. 월드 원점/스폰은 유지한다. 안전 경계±148, 장식 성벽±146, 서버 로비 허용 크기도300으로 일치시킨다. 확장된 동서남북 영역의 바닥/닫힌 경계와 실제 보행을 검사한다.

중앙길은224stud로 연장하고 정원/직업 깃발/성벽·쌍탑도 넓어진 공간에 재배치한다. 준비 시설은 중심부에서 접근 가능한 범위로 배치하고 외곽은 이동/모임의 여유 공간으로 둔다. 시설 길은 공유 시설 좌표를 읽어 생성한다. `DawnspireDesign`의 바닥 크기와 Tessa 좌표를 서버 주민/클라이언트 안내 지도가 함께 사용하며, 실제 NPC가 로드되면 그 위치를 지도에 투영한다. 예전±50 위치 제한은 제거하고 지도 버튼 자체는 영역 안에 배치한다. TD 공통 UI 프레임/아이콘/초상은 기존 것을 유지한다.

## 근거와 검증

[기존 디아블로/Roblox 거점·스트리밍 조사](../research/2026-11-11-dawnspire-throne-lobby.md)의 준비 동선 유지·개인 진행 표시 원리를 재사용한다. 이번 미술 교정의 직접 비교 원천은 실제 TD 소스이며 새로운 인기/성능 주장을 추가하지 않는다. 네이티브 기하 원본을 재사용해 외부 메시 업로드/권한 변경이나 Blender 편집을 요구하지 않는다. TD 소스/게시 상태는 읽기 전용이다.

[검증 증거와 화면](../evidence/dawnspire-td-throne-expanded-20261111/README.md). 확대된 바닥·경계·시설/왕좌까지 .75stud 이하 보행 표본, TD 원본 비율/재질, 영웅별 심장/재유입, 실제 안내 지도/문구 배치를 검사한다. 서버 로컬 위치 검증을 실제 게시 Teleport/계정/PC·터치·패드·20인 FPS/사용자 미술 수용으로 해석하지 않는다. 다음 담당 QA는 TD 원본 대비 형태 수용과 넓어진 공간의 실제 이동감을 확인한다.
