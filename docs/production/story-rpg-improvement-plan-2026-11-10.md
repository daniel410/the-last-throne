# Roblox·Diablo·WoW 장점을 활용한 스토리 RPG 개선 계획

2026-11-10 · TLT-001/028/050/057/061~065/084 · DIR/RES → PLAN/DES/ENG/QA

상태: **사용자가 요청한 조사·개선 계획. 제안 수치와 새 기능은 미채택이며 구현·재미 수용 완료가 아니다.** [작품별 사실·출처·한계](../research/2026-11-10-story-rpg-reference.md). 이 문서는 기존 승인 시나리오를 대체하지 않는 후속 개선안이다.

## 1. 추천 방향과 현재 기준

우선순위는 **인물과 목적을 이해함 → 직접 해결함 → 변화와 도움을 확인함 → 다음 모험이 궁금해짐**이다. Diablo의 단서/행동 연결과 결과가 보이는 월드, WoW의 지역/인물 이야기와 솔로 접근, Roblox 작품의 짧고 기억할 만한 인물·보스 장면을 결합한다.

현재 본편은 Deepwood → Gloamwood → Frozen Vale → Ember Caldera → Haunted Graveyard다. [0.85.0](../evidence/campaign-expansion-20261108/README.md)의35본편/12사이드/82사건/246단계, [0.86.0](../evidence/campaign-expansion-review-fixes-20261108/README.md)의 지역별 장면/회로/동맹 보강, [0.88.1](../evidence/story-fun-20261108/README.md)의 인물·단서·회수를 기준으로 한다. GW06의 [Hollowbark Sovereign](../evidence/hollowbark-sovereign-20261110/README.md)도 반영한다.

현재 `src/shared/CampaignStoryBeats.luau`에는 약품→생존자→운전사, Finn의 등불 성장, FV 경보·수호수 관계, EC 기술자 협업, HG 동일 등불 회수가 이미 있다. **이 장면을 새로 만들었다고 중복 산정하지 않는다.** 현 단계의 공백은 실제 유저가 이를 보고 이해하는지, 전투/이동에 묻히지 않는지, 재접속 후에도 이해가 이어지는지에 대한 수용 증거다. 소스/엔진 통과와 재미 통과를 구분한다.

## 4. 스토리와 전투·장비·협동을 연결하는 후속 개선

스토리 요청의 연장으로, 다른 시스템을 대규모 개편하기보다 이야기와 만나는 지점을 우선한다.

1. **전투 학습:** 장치/전투 전에 짧은 위험 신호를 익히고 보스에서 같은 규칙을 읽게 한다. WoW NPC 학습 접근을 기존 안내/AI로 단순화한다. 첫 파일럿은 현재 공격 예고의 인지·회피 시도를 측정하며 피해/공격속도·적 수를 변경하지 않는다.
2. **장비의 의미:** 획득/교체 시 다음 행동에 어떤 도움이 되는지 기존 비교 UI로 설명한다. 현행 선택형 `specialEffects`의 설명 형식과 스킬 지정/합산 상한을 먼저 검토한다. Diablo식 거대한 옵션 풀·신규 드롭·효과 자동 배정은 별도 밸런스 후속이다. 이번 장면 파일럿에 포함하지 않는다.
3. **협동 성과:** Finn/Brann의 서사 기여는 장면 배우로 표현한다. 실제 전투 AI를 늘려 도움을 표현하지 않는다. 혼자도 순차 행동으로 해결하며 인간 여러 명 동시 스위치·특정 클래스·Selene 유료 지원을 본편 필수로 만들지 않는다.
4. **반복/복귀:** 기존 완료 저널에서 마지막 결과와 다음 이유를 바로 읽게 한다. 이미 본 연출은 생략/재확인할 수 있게 설계하되 최초 보상/영웅별 난이도 권리와 연결하지 않는다. 별도 반복 던전·일일 숙제·계정 공유 본편 도입은 보류한다.

## 6. 최소 실험·측정·수용 가설

다음 숫자는 외부 게임이 입증한 기준이 아닌 **제안 목표**다. 비교군/표본이 작으므로 통계적 우월성이나 유지율 향상을 선언하지 않는다. 동일 플레이어에게 같은 퍼즐을 두 번 풀려 생기는 학습 효과를 피하도록 기존/수정안을 서로 다른 신규 참가자에게 배정한다. 미성년 참가자의 모집·관찰 방식은 실제 테스트 준비 때 정한다.
