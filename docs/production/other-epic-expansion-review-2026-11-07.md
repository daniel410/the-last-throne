# 프로즌 베일 외 네 에픽 리뷰·확장 개선 총괄

2026-11-07 · TLT-001/050/057/061/063/064/065/084/087 · 계획 완료·런타임 미적용

사용자는 다른 에픽도 리뷰하고 확장 개선 계획을 만들도록 요청했다. Deepwood/Gloamwood/Ember Caldera/Haunted Graveyard의 현재 투영 콘텐츠·활동·기본 월드 생성·연결 원고를 검토하고28개 장의 확장안을 작성했다. Frozen Vale는 [기존 통합안](epic-story-map-expansion-2026-11-07.md)의7장 계획을 유지한다. 이번 계획은 추가 지역/보스/보상/시간의 사용자 확정이나 게임 적용을 뜻하지 않는다.

시간은 이전 통합안의 가설을 재사용한 것이며 아직 측정된 결과가 아니다. 빠른 완료를 막거나 처치/이동량을 강제로 늘리는 기준으로 쓰지 않는다. 기존8개 사이드 퀘스트(DW4/EC4)는 개선 계획, 신규4후보(GW2/HG2)는 선택 탐험 제안이다. 기존 보스의 필수/선택 지위를 바꾸지 않는다. 새 공간의 게임 내 이름은 영어 원고와 함께 추후 확정하며 한국어 작업명을 게임에 노출하지 않는다.

## 3. 실행 순서와 통합 담당

1. **QA·PLAN / 기준 측정:** 네 에픽의 현재 빌드를 동일 조건으로 완주하고 사건별 시간·반복감·길 찾기·목적 이해를 기록한다. 처음 가는 사람과 숙련자 기록을 분리한다.
2. **ENG·PLAN / 공통 저장 계약:** 콘텐츠 버전 고정, 기존 완료/활성 원정 이관, 새 사건 영수증, 보상 예산을 확정한다. 콘텐츠 배열부터 늘리지 않는다.
3. **DES·ENG / Frozen Vale 파일럿:** 기존 우선 제안을 유지한다. 공통 저장/지도/스트리밍 해결을 검증한 뒤 다른 지역에 적용한다.
4. **DES·ENG·PLAN / Gloamwood → Ember Caldera → Deepwood → Haunted Graveyard 파일럿:** 각각 GW-04~06, EC-04~05, DW-04/03 귀환, HG-02~04를 먼저 만든다. GW의 반복 구조와 적은 사건 수를 먼저 다루고, HG 후일담은 로비 완료 계약을 선행한다. 이는 제작 순서 제안이며 게임 진행 순서는 DW→GW→FV→EC→HG 그대로다.
5. **ART·ENG / 전체 장 확장:** 파일럿 수용 뒤 나머지 장과 선택 가지를 적용한다. 지역당 하나의 파일 담당이 콘텐츠/월드/원고 대응을 통합한다. TD 공통 원본 해시/사용권한/실제 모델 적합성을 확인한다.
6. **QA·DIR / 사용자 수용:** 네 클래스 솔로·구매0·동료0 및4인+전투AI1, PC/터치/패드, 신규/기존 완료/구버전 진행 중/재접속을 검증한다. 프레임/메모리/접속/동시 적은 기존 성능 예산과 비교한다. 미검증을 남긴 채 부모 티켓을 Done으로 바꾸지 않는다.

산정할 제작 단위는28개 장의 시나리오·공간 앵커, 기존8개 사이드 개선, 신규4개 선택 후보, 지역별 파일럿4묶음과 HG 귀환 후일담1묶음이다. 장별2~3개 소공간은 모듈 조합 목표이며 신규 맵 개수나 신규 모델 수로 합산하지 않는다. 일정/인력은 활동 엔진 재사용·기존 맵 앵커 이동·저장 이관의 실제 비용 검토 후 산정한다. 통합 담당은 DIR/PLAN, 다음 실행 담당은 QA/PLAN 및 ENG다.

## 4. 지역 전체에 적용할 수용 기준

- 현재 장/목표/보상ID·계정 완료·다음 에픽 입장·보유품·재화·전직·Selene 권리 유지. 새 콘텐츠 원정과 기존 활성 원정의 버전을 분리하고 구버전 완주/안전 이관을 실제 검증한다.
- 추가 전투의 처치XP/Gold/드롭을 포함해 수입을 계산한다. 장별 고정 보상 보존만으로 경제 보존을 선언하지 않는다. 적 총량 재배치를 먼저 시험한다.
- 대사/조사/호위가 같은 원인의 진행을 설명하고 완료 결과가 보인다. 플레이어가 다음 목적과 그 이유를 말할 수 있는지 관찰한다. 텍스트만 늘리거나 동일 스위치 반복으로 시간을 채우지 않는다.
- 선택 탐험0개·구매0·Selene0·특정 클래스 열쇠0 상태로 본편 완결. 전투AI 상한1과 인간 정원4를 유지하고 동맹 연출을 별도 전투AI 증원으로 취급하지 않는다.
- 사건 종료 전후 저장 실패/중복 요청/서버 재입장/파티원 이탈/더 진행한 파티원 합류를 시험한다. 개인 완료/보상과 원정 공용 상태를 구별하고 로드 실패를0진행으로 덮지 않는다.
- 길 개방·호위·스트리밍 복귀 때 안전 바닥과 목표를 재구성한다. 기존 보스의 유한 호위/재도전·원정 이어하기·지도7/7·구순서 영수증 회귀를 포함한다.
