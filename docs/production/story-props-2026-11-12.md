## 구현 계약

`StoryPropAssignments`가 기존 안정ID로 물품을 직접 지정한다. 새 목표를 추가하면 자동 책상 대체 대신 누락 검사가 실패한다. `StoryQuestGeometry`는 native 기하 정본이며 기존 TD 환경/원형 자산과 기존 소품 키트를 함께 사용한다. 새 데이터는 모델 형태/맥락이지 계정 소유 아이템이 아니다. 상호작용 앵커와 서버 권한·저장·전투·보상·스텝/정답/순서를 바꾸지 않는다.

새 native 모델55개는 기본 형태47개와 뿌리 문양 변형8개다. 문서들은 상황에 따라 봉인 명령서·작업판·야외 지도·게시 명단으로 분산된다. 전체 이야기에서 원본 `LedgerDesk`는 배치하지 않는다. 기존 키트의 책상 원본은 다른 자산/과거 증거를 파괴하지 않도록 보존한다.

확장 사건은 기존 `ExpansionStepEvent/Chapter/Index`와 원래 색을 보존해 개인 저장 단계 투영에 연결한다. 태그를 설정한 뒤 모델을 부모에 넣는다. 교체한 광산/용광로 손잡이는 개인 완료 표시 후 원래 색으로 복구한다. 무관한 상자/소품을 무작위로 추가하지 않는다.

5에픽44지역의 주변 생활 구성은 별도 기능이며 이번 물품 교체의 완료 수에 합산하지 않는다. 기하·정적 검증·Studio·게시 클라이언트·사용자 미술 수용을 구별하고 부모 티켓/G5/G7은 변경하지 않는다.
