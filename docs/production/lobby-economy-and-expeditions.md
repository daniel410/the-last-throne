## 재화와 무기

RPG 계정 지갑의 표시 재화는 **Gold / Diamonds**다. 종전 Coins/처치 Coins의 금액은 한 번 Gold로 이전하며 저널에는 누적 획득 기록을 보존한다. 승인 보상 JSON의 Coins 키와 XP·일반 재화 금액은 바꾸지 않는다. Gold는 TD 전투 Gold·임무 Command Points와 별개다. Diamonds도 TD 지갑·구매권·Robux 상품과 공유하지 않는다. 기존 Deepwood 본편 초회 완료당2 Diamonds를 계정당 한 번 주며 이전 완료도 한 번 반영한다. 가격·추가 Diamond 지급량은 시험값이다.

로비의 실물 무기 상인과 **ARMORY** 버튼으로 구매·판매한다. TD UI 원본과 실제 TD 무기 전시를 사용한다. 기본 클래스별 상위 무기250 Gold, Lv5 Veteran 무기600 Gold 또는10 Diamonds, 방패250 Gold다. 매각은50/120/50 Gold다. 다른 클래스 장비 구매는 허용하되 소유·클래스·레벨 장착 검사는 유지한다. 잠금·장착·기본 지급 장비는 팔 수 없으며 Diamonds로 샀어도 매각 대금은 Gold다. 두 번 클릭해 가격을 확인하고 확정한다.

아이템 지급/회수와 지갑 증감은 같은 RPG 계정 키의 UpdateAsync에서 처리한다. 요청ID·revision·요청 내용으로 중복 지급과 충돌을 막는다. 과거 요청 장부96건이 밀려나도 이전 revision은 새 구매가 되지 않는다. 저장 결과가 불명하면 동일 요청만 재시도한다. 로드 실패를0잔액으로 덮어쓰지 않는다. 실제 Robux 결제·상품ID·ProcessReceipt는 이번 구현에 포함하지 않는다.

## 솔로와 파티

**ADVENTURES**에서 Solo 또는2/3/4인 모집을 고른다. 전체 로비의 모집 목록을 공유하며, 다른 로비에서 합류하면 임시 자리를 확보하고 파티장 로비로 이동한다. 모두 도착·준비하고 같은 다음 본편을 진행해야 파티장이 출발할 수 있다. 개인 선택·스토리를 호스트 것으로 복사하지 않는다. 영웅 선택과 훈련은 출발 중 잠그며, 파티 소속 상태의 훈련은 거부한다. 훈련은 계속 로비에서만 가능하다.

20명 로비·최대4명 전투로 역할을 나눈다. `default.project.json`은 Lobby, `battle.project.json`은 Battle을 만든다. 게시 Lobby는 Deepwood를 구성하지 않고 Battle은 Dawnspire 로비를 구성하지 않는다. Studio Lobby는 동일 프로세스 미리보기이며 실제 서버 이동 수용이 아니다.

회원 인덱스·파티 키·원정 키·리조인 키는 MemoryStore에 두고 만료와 소유 토큰을 검사한다. 여러 키의 갱신을 다중 키 거래로 취급하지 않는다. 출발 전 전체 로컬 명단을 잠그고 최신 소유/영웅/진행/준비 상태를 재검사한다. 각 계정의 대기 지급을 마감하고 저장 lease를 해제한 뒤, 하나의 ReservedServerId와 각 인원 전용 입장 티켓으로 이동한다. 재화·아이템은 TeleportData에 싣지 않는다.

전투는 같은 Experience/허용 Place 출발·예약 서버·개인 티켓·유효 회원·목적 Place·원정 소유 lease를 확인한다. 도착한 인원 또는30초 대기 뒤 전투를 열고 lease 갱신이 불명하면 전투 입력을 잠근다. 제한 재시도3회는 목적지/티켓을 바꾸지 않는다. 일부 인원만 이동 실패하면 그 인원 계정만 재개하며, lease를 안전하게 다시 얻기 전에는 조작을 풀지 않는다.

## 복귀와 리조인

15분 안에 **REJOIN**으로 허가된 영웅/원정에 돌아간다. 원래 전투 서버가 남아 있으면 합류하고, 서버가 종료되어 소유 lease가 만료되면 같은 예약 목적지의 새 작업에서 저장된 개인 체크포인트를 재개한다. 적 HP나 모든 전투 상태의 영속 복원은 없다. 의도적인 로비 복귀는 해당 리조인 권한을 끝낸다. 복귀 이동이 실패하면 계정 재개 확인 후 권한을 복구한다. 출발 파티가 모험 후까지 계속 유지되는 UX는 후속이다.
