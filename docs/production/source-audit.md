# 원천 검토와 제작 계획 연결

2026-10-28 · v0.25 · 이번 계획 작성에 사용한 저장소 자료의 추적표다. SHA는 현재 파일 스냅샷의 앞12자리이며 승인 여부를 뜻하지 않는다. 기존 내용의 결정 상태는 결정표/각 원문을 따른다. 기획·디자인·3D·엔지니어·QA가 분야별 원천을 검토했고 총괄이 통합한다. 모든 이미지의 미술 수용·모든 TD writer/배포 서버 감사 완료를 의미하지 않는다.

## 5. 현재 TD 원본 조사에서 반영한 차이

- 모델링 조사: 현행 프로젝트 참조의 타워30템플릿·영웅무기4템플릿·몬스터43템플릿과 카탈로그40/보존3종을 구분했다. 메시·템플릿·원형·RPG 리그·애니메이션의 수는 다른 산정 단위다.
- 모델링 조사: 해당3개 XML에는 Motor6D/Bone이 없으므로 런타임 어댑터/파생 리그를 따로 확인한다. 변경17종 metadata를 전체30종 명세로 간주하지 않는다.
- 레지스트리 비교: `ui.mobile-battle`, `model.hero-weapon-adapter`의 현재 해시가 보존 스냅샷과 달라 TLT-002/028에서 재감사한다. 승인 컨셉 해시와 원본 소스의 최신성은 다른 검사다.
- 엔지니어 조사: TD에 DiamondWallet/ReceiptDispatcher 구현이 존재한다. 기존 코드가 있다는 사실을 모든 Place/서버가 호환 버전을 운영한다는 증거로 쓰지 않고 TLT-021에서 전체 writer/배포를 감사한다.

세부 파일/구조/근거는 [자산 제작 계획](asset-production-plan.md)과 [기술 제작 계획](engineering-plan.md)에 둔다. TD 파일·라이브 DataStore·상품·Place는 이번에 수정하지 않았다.

## 6. 공식 플랫폼 근거

- [Data stores](https://create.roblox.com/docs/cloud-services/data-stores): 같은 Experience의 접근 범위·서버 저장·테스트 환경 분리.
- [Teleport](https://create.roblox.com/docs/projects/teleport): 실제 게시된 테스트 클라이언트 수용.
- [Developer Products](https://create.roblox.com/docs/production/monetization/developer-products): 영수증 기반 구매 처리.
- [Client-server boundary](https://create.roblox.com/docs/scripting/security/client-server-boundary): 서버 자격/구조/값/빈도 검증.
- [OpenAI Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents): 역할 지침과 자동 발견용 커스텀 에이전트 설정의 구분.

확인일2026-10-28. 플랫폼 API/제약은 실제 구현 시 공식 문서의 해당 버전/환경을 다시 확인한다.
