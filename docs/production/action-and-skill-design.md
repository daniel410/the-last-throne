# 액션·스킬·자원 설계

2026-10-28 · 사용자 요청에 따른 제품 방향 · TLT-005/008/014/084 · 기획·디자인 → 엔지니어링·QA

## 제품 방향

모든 영웅이 사용하는 **액션(Action)**과 영웅의 직업 및 전직으로 배우고 장착하는 **스킬(Skill)**을 구분한다. 이번 문서는 사용자 결정과 구체적 구현 전 추천안을 분리한다. 0.18.9에는 아래 계약의 세션용 시험 구현이 있으며, 정식 성장과 전직은 별도다.

### 공통 액션

| 액션 | 규칙 | 외형·전투 표현 방향 |
| --- | --- | --- |
| Attack | 자원 비용과 별도 쿨다운 없음 | 기사 검, 엘프 활, 드워프 도끼, 마법사 지팡이의 기존 기본 공격 |
| Block | 전 영웅 공통 입력. 자원 비용 없음 | 기사 방패, 엘프 활, 드워프 도끼, 마법사 지팡이 등 무기에 맞는 방어 표현을 설계 |
| Dodge | 자원 비용과 별도 쿨다운 없음 | 현재 V/패드 B/터치 동작을 유지하는 방향. 동작·무적 구간과 충돌 판정은 존재 |
| Sprint | 전 영웅 공통 입력. 자원 비용 없음 | 이동용 달리기. 실제 속도·입력·동작 전환은 검증 대상 |

블록의 무기별 동작, 피해 감소·방향·방어 불가 공격·반격은 미정이다. 자원 비용이 없으므로 계속 막기와 반복 회피가 모든 공격의 정답이 되지 않도록 예고가 있는 방어 불가 공격, 위치/각도, 동작 후 빈틈 등을 실험한다. 새로운 블록 쿨다운을 사용자 결정으로 단정하지 않는다. 동작 지속 시간과 별도 스킬 쿨다운은 구분한다. 스프린트 키는 Roblox Shift Lock과 충돌할 수 있으므로 PC/패드/터치 실측과 설정 가능성 검토가 필요하다.

### 직업 스킬과 비용

| 대상 | 물리 스킬 | 마법 스킬 |
| --- | --- | --- |
| Knight | 해당 물리 스킬의 쿨다운 | 향후 성기사의 마법 분류 기술에 MP 적용 방식은 전직 설계와 연결해 검토 |
| Elf Archer / 명궁 | 해당 물리 스킬의 쿨다운 | 원형 엘프에 MP 막대를 미리 부여하지 않음 |
| Elf Archer / 마법궁수 | 물리 스킬은 해당 쿨다운 | 전직 자격이 생기면 MP를 추가하고 마법 화살 등 마법 스킬에 MP + 개별 쿨다운 |
| Dwarf | 해당 물리 스킬의 쿨다운 | 마법 스킬 추가 여부는 별도 결정 |
| Mage | 지팡이 기본 공격은 공통 액션으로 무료 | 모든 주문에 MP + 해당 주문의 쿨다운 |

최신 사용자 결정으로 **Stamina를 제거**한다. 물리 스킬은 개별 쿨다운을 쓰고 마법 스킬은 MP와 개별 쿨다운을 함께 쓴다. 공통 공격·블록·회피·스프린트는 자원을 쓰지 않으며 기본 공격·회피에 별도 쿨다운은 없다. 원형 클래스는 변하지 않고 엘프 마법궁수는 Lv20 첫 전직 완료 시 MP를 추가한다. MP 비용·최대량·회복 속도와 성장/장비 계수, 과거 서약·집중·열기 등의 처리와 마법/물리 간 균형은 미정이다. Stamina 제거는 0.18.8 세션 원형에 반영했으며 정식 성장과 실기기 수용은 남아 있다.

## PC 단축키 방향

사용자 요청에 따라 스킬은 숫자 **1~5**, 공통 액션은 **Q/E/R 등**의 문자 키로 구분한다. 기본 3개에서 Lv20/40 전직 완료마다 한 칸씩 열어 최대 5개를 장착한다. 궁극기 슬롯은 미정이다. 사용하지 않는 숫자 슬롯은 빈 상태로 둔다.

구체적인 액션별 기본 배치는 사용자 확정 전 추천안이다. Attack은 마우스 왼쪽, Block은 Q 또는 마우스 오른쪽, Sprint는 E, Dodge는 이전 결정인 V를 유지하고 R을 추가 입력 후보로 검토한다. Space는 점프, X는 현재 표적 해제다. Q/E/R 배치는 실제 이동과 동시 입력·기기/키보드 접근성 검증 후 조정하고 재지정 설정도 검토한다. 패드와 터치에는 각 기기에 맞는 별도 입력과 HUD를 제공한다.

## 스킬 관리와 전투 HUD

- 관리 화면에서 습득·자격을 확인하고 전투용 스킬을 기본 최대 **3개**, Lv20/40 전직 완료 후 각각 최대 **4/5개**까지 미리 배치한다. 슬롯별 아이콘, 기술명·효과·자원 비용·쿨다운·자격을 볼 수 있게 한다. 기술 교체 시 해금·전직·중복 장착을 서버가 확인한다.
- 전투 화면 하단에 장착한 스킬을 아이콘 위젯으로 표시한다. 아이콘에는 실제 사용 키/패드 버튼과 남은 쿨다운을 겹쳐 표시하고, 자원 부족·사거리 밖·준비 상태를 숫자/문구 등으로 구분한다. 색만으로 상태를 구분하지 않는다. 모바일은 같은 아이콘을 탭해 사용한다.
- **사용자 결정:** 기본 슬롯은 3개이며 Lv20/40 각 전직 완료 시 각각 4/5번 슬롯을 연다. 레벨 도달만으로는 열리지 않는다. 사용할 수 있는 기술이 부족하면 슬롯은 비워 두고 미개방 슬롯은 잠금 표시한다. 스킬 학습·계열 자격은 슬롯 개방과 별개다. 궁극기를 별도 슬롯으로 둘지는 미정이다.
- **추천:** 전투 중 스킬 교체는 막고 비전투 상태에서 관리한다. 편성을 바꿔도 진행 중인 개별 쿨다운이 초기화되지 않도록 설계한다. 정확한 전투 이탈 조건과 재접속/사망·기기별 동작은 별도 결정과 검증이 필요하다.
- UI·스킬명·오류 메시지는 영어로 작성한다. 디자인 문구는 개발용이며 최종 영문명과 아이콘은 검토 대상이다.

## 현재 구현과 다음 작업

0.13.0 당시 네 직업의 세션 기술 각 3개를 로비에서 미리 편성했다. 물리 기술의 당시 시험값은 Stamina 최대 100·초당 15 회복, Mage 마법은 MP 최대 100·초당 10 회복이었으며 각 기술별 쿨다운도 적용했다. Stamina 비용은 이후 0.18.8에서 제거했다. Q/오른쪽 클릭 Block, E 유지 Sprint, R/V Dodge, 왼쪽 클릭 Attack과 1~5 기술 키는 시험 배치이며 6번은 미할당이다. 하단에는 약어 기반 임시 아이콘과 슬롯 키·쿨다운을 표시한다.

첫 전직과 레벨 시스템은 아직 구현되지 않았다. 로비의 **PRACTICE ONLY** 전환은 실제 전직이나 저장이 아니며 5슬롯 UI 검증을 위해 열어준다. 세션에선 기술별 쿨다운이 편성 교체·로비 복귀·리스폰을 거쳐도 유지되지만 접속 종료 시 영웅·편성·쿨다운이 사라진다. 스킬은 세션에서만 3개를 지급하며 정식 습득·계열 자격 검증은 미구현이다. 4·5번에 새 기술이 생기는 것은 아니다. 패드·터치 지원은 코드에 있지만 실기기 검증 전이다.

무기별 블록 자세는 초기 표현이며 방어 판정과 전투 수치·모션의 사용자 수용, 정식 전직 시 3→4→5 자격과 마법궁수 MP, 성장과 저장/재접속, TD 스타일의 최종 스킬 아트 및 모바일/패드 UI는 후속 작업이다. [구현 및 검증](../evidence/k0/action-skill-prototype.md).

마법사의 세 기본 주문은 Mana Bolt·Water Ball·Gravity다. Gravity는 선택한 적 주변을 타격하는 광역기다. 기사의 기본 기술은 Shield Bash·Whirlwind·Provoke이며 Whirlwind는 기사 주변 광역 공격이다. 도발과 감속의 수치·범위는 시험용이다. [현재 구현](../evidence/k0/knight-gravity-area.md).

드워프 기본 기술은 Overhead Smash·Axe Throw·Ground Slam, 엘프 기본 기술은 Aimed Shot·Rapid Fire·Multi Shot이다. Ground Slam과 Multi Shot은 광역기이며, 범위·대상 수·연사 간격·피해 수치는 시험값이다. [구현](../evidence/k0/dwarf-elf-starter-skills.md).

0.17.0은 각 기본 스킬의 절차적 준비·발동 자세와 서버 확인 적중 효과를 제공한다. Rapid Fire의 재장전 동작은 실제 서버 화살 발사 시각에 맞춰 표시하며, Provoke는 피해 없는 도발 표식으로 구분한다. 사용자 시각 수용과 실기기/다인은 별도다. [기록](../evidence/k0/starter-skill-visuals.md).

### 0.18.5 회복 시험값

사용자의 회복 속도 조정에 따라 네 영웅 HP는 서버에서 최대 HP의 초당 0.2%씩 회복한다. 0.18.5 당시 물리 스킬 Stamina는 초당 6으로 줄이고 스킬 사용 후 1초 회복 지연을 유지했으나 0.18.8에서 Stamina를 제거했다. MP 회복과 무료 공통 액션 계약은 그대로다. 위의 0.13.0 수치는 당시 기록이다.

### 0.18.6~0.18.7 방어와 Overhead Smash

Dwarf·Elf·Mage는 현재 방어 위치에서 무기를 가로로 들고 반대 손으로 받친다. Overhead Smash는 0.65초 준비 동안 머리 위 한 바퀴 회전한 뒤 서버 타격하며 확대된 적중 효과를 표시한다. 사용자 Play와 다양한 체형의 미관·지연은 미검증이다. [방어](../evidence/k0/2026-10-28-horizontal-block-slime.md) · [Overhead](../evidence/k0/2026-10-28-overhead-smash.md).

### 0.18.8 Stamina 제거

물리 기술 비용·부족 오류·회복과 HUD의 Stamina 표시를 제거하고 개별 쿨다운을 유지했다. Mage MP와 기술별 쿨다운은 유지한다. 격리 Studio의 네 직업 기본3 기술 입력과 자원 표시 일부를 확인했으며 정식 성장·저장·마법궁수 전직과 실기기·다인 수용은 미검증이다. [구현·검증](../evidence/k0/2026-10-29-stamina-removal.md).

0.18.9는 로비의 전직 슬롯 안내를 Lv20 전직 완료 후 4번, Lv40 전직 완료 후 5번으로 고친다. 실제 자격 구현은 아니며 5칸 전환은 연습 전용이다.

## 아이템 퀵슬롯

스킬 왼쪽에 아이템 버튼 2개를 둔다. PC 기본키는 Z(첫 칸), C(둘째 칸)이며 터치 버튼을 제공한다. 정식 구현은 가방 소유 소모품 지정·수량·서버 소모·실패 안내와 저장/재접속을 연결한다. 수량0에도 등록은 유지하고 재획득 시 다시 표시한다. 창고/수령 대기 아이템은 전투에서 자동 소모하지 않는다. 허용 품목·소모품 쿨다운은 미정이다. 현재 소스 원형은 HP/MP 물약을 각 3개 제공하며 회복량 40은 시험값이다. 캐릭터 생성마다 초기화되므로 정식 인벤토리가 아니다. MP가 없는 영웅, 자원 최대, 수량 부족 시 소모하지 않는다. 패드 배치와 기기별 화면 수용은 미검증이다.
