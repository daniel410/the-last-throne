## 기존 문제와 새 흐름

기존75교전은 모든 무리를 한 전투 중심 주변에 생성했다. 현재 무리를 전멸시키면 같은 위치에 다음 무리가 즉시 생성되어, 유한 웨이브여도 몬스터가 되살아나는 것으로 보일 수 있었다. 새 원정14와 기존 확장 원정13은 **현재 무리 처치 → 확보한 길로 이동 → 다른 교전 지점 접근 → 다음 무리**로 바꾼다. 후속 무리는38stud 이내로 실제 생존 파티원이 접근할 때 생성한다. 관전자/다른 원정/쓰러진 영웅은 시작 권한이 없다. 한 번에 모든 몬스터를 월드에 활성화하지 않는다.

일반 적·보스·난이도별 능력치·파티별 총량과 기존 적 분할/안정 처치ID는 유지한다. 각 전투 목표의 보스는 여전히 마지막 무리에 한 번만 나온다. 각 목표 내부의 교전 위치를 최소80stud 떨어뜨려 같은 자리의 연속 전투를 제거했다. 모든 파티 크기의 편성을 수용하는 공간 계획은 총276지점이다. 이 숫자는 한 플레이어가 모든 지점을 싸운다는 뜻이 아니며 파티 크기별 기존 무리 수만큼만 사용한다.

## 실제 맵 확장과 제작 제약

44개 기본 구역의 실제 지원 지면 합계를 기존보다94.3% 확대했다. 이는 원래 기본 사각 바닥 면적의 합계 비교이며, 기존 사건 윙까지 포함한 전체 맵 면적 증가율이나 플레이 시간 증가율이 아니다. 구역별 목표 확장 폭을 주고 인접 지역 경계와 겹치지 않는 방향으로 확장했다. 기존 앵커/목표ID는 유지하며, 사건 윙은 확대된 바닥에 다시 안전하게 연결한다. DW-02처럼 양쪽 연결 구역에 끼인 구역은 기본 지면을 강제로 넓히지 않고 기존 공간 안의 서로 다른 위치를 사용한다. 전체 지도에 같은 배율을 일괄 적용하지 않는다.

새 지면은 서버가 인정하는 발판·지역 경계·지도와 일치한다. 기존 TD 지형/랜드마크 구성도 확대된 크기를 사용하고 교전 공간/통로를 먼저 예약한다. 길 폭24stud, 새 지점에서 기존 몬스터 반경13stud 배치는 현행 출발값이다. 절벽·기둥·수목으로 유효 폭이 줄어드는지는 실제 기하 검사로 확인한다. 전투 지점 간 연결은 굽은 길로 표시하며 기존 주요 구조물은 경로를 침범하면 조립체 단위로 옮긴다. 최종 건축으로 교체된 구형 얼음벽/기둥·배관 프록시는 숨긴 뒤 충돌도 퇴역시킨다. 보이는 최종 벽을 비충돌로 바꾸어 통과시키지 않는다.

## 진행·실패·복구

- 새 입장은 규칙14를 사용하고, 진행 중인 확장 원정13도 같은 공간 분산을 적용한다.13의 처치ID/보상/수치는 그대로여서 영수증을 이관하거나 초기화하지 않는다. 확장 이전1~12 원정은 기존 전투 라이프사이클을 유지한다. 지역 지형 확장은 공통 월드 변경이다.
- 서버가 무리 전멸과 다음 위치를 확정한다. 클라이언트는 현재/다음 위치를 받아 지도·화살표·목표 표식을 갱신하고 `Route n / total`과 이동 안내를 영어로 표시한다.
- 같은 원정원이 살아 있거나 쓰러져 있는 동안 이동·단서 읽기만으로 이미 정리한 구간을 초기화하지 않는다. 같은 서버의 사망 복귀는 마지막 정리 지점의 실제 SpawnLocation을 사용한다.
- 서버 재입장 시 기존 지급 확정 처치 영수증으로 완전히 정리한 무리의 접두 구간을 복구한다. 일부 처치만 확정된 무리는 다시 처리할 수 있고 기존 영수증이 보상 중복을 막는다. 저장 불명 상태를 완료로 간주하지 않는다. 파티원 중 미확정자가 있으면 그 권리를 건너뛰지 않는다.
- 현재 단서246단계의 ID·순서/선택·부분 저장 계약을 삭제하거나 자동 완료하지 않는다. 이번 핵심 개선은 모든 교전의 장소 분산이다. 단서 수 자체의 재편집이나 에픽 원고 전체 교체를 했다고 보고하지 않는다.

## 수용·인계

정적 적/보상 비교, 격리 엔진의 실제 서버 라이프사이클, 새 교전 지점/통로와 기존 사건 경로의 바닥·신체 충돌, 실제 지도 도면 재생성을 각각 기록한다. 실제 사용자 전투 시간·재미·길찾기·저사양 FPS/메모리·PC/터치/패드 입력·4인+AI 성능은 별도 수용이다. 부모 티켓은 이 검사만으로 Done으로 바꾸지 않는다.
