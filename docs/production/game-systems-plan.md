# 게임 시스템·서사 제작 계획

> **현재 본편: 어둠의 숲을 포함한 총 5에픽.** 10~15세 Roblox 플레이어가 쉽게 이해할 수 있도록 도움·우정·용기·회복을 중심으로 쓴다. Deepwood → Frozen Vale → Ember Caldera → 어둠의 숲(Gloamwood, 영문 가칭) → Haunted Graveyard. Dawnspire는 시작/귀환 거점이며 별도 에픽이 아니다. [쉬운 모험 줄거리](five-epic-adventure-story-2026-10-30.md)를 따른다.

v0.25 · 2026-10-28 · 문서 한국어 / 게임 영어 전용 · 상태: 구현 전 제작 실행안

**The Last Throne**은 Throne Defense의 세계관·자산·공통 UI 원본을 공유하는 1~4인 액션 RPG다. TD와 분리된 독립 Experience·별도 소스로 만들며, 기존 TD 진행/권리는 보존한다. 공통 Diamonds는 외부 서버 권위 계약 검증 전까지 분리한다. 전체 일정·게이트·정식 작업 의존은 [plan.md](../../plan.md)와 [backlog.md](../../backlog.md)를 따른다. 이 문서는 그 계획에 연결할 기획 계약과 32구간 추적표다.

## 1. 근거와 결정 상태

우선순위는 최신 사용자 지시 → [결정표](../decisions.md)의 사용자 결정 및 최신 변경 이력 → 현행 상세 명세 → [통합 제안서](../../the-last-throne-rpg-proposal.md) → 콘셉트/아카이브다. 문서·계산기 결과를 게임 구현·재미 수용의 증거로 쓰지 않는다.

| 상태 | 적용 범위 |
| --- | --- |
| 사용자 결정 | 고정4클래스·각2계열·20/40/60/80·STR/DEX/INT/VIT·316스탯P·성녀NPC·Deepwood 첫 제작·TD 공유 자산/UI·리셋권 및 실제 성능 장비 판매·영어 게임 |
| 반영된 기획 기준 | 정본 JSON의 고정 XP/Coins, 프롤로그+28스토리 성장 예산, DS-04 고블린2마리 순차 교전. 런타임/플레이 수용 전 |
| 상세 초안 | 스토리 적/장치/대사·기사 수치·스킬79P·36액티브/12궁극기/216노드·동료 AI 상한·장비/보관 동작 |
| 후속 상세 설계 | 5에픽 상세 시나리오·기존ID 대응·Lv1~80/전직/보상 재설계. 과거 AS/DC/FB/FC는 참고안 |
| 후속 확장 후보 | Beyond the Last Gate, 추가 마법 속성/소환, 거래소, 선택 PvP |

현재 사용자 요구는 게임 영어 전용이다. 기존 한영 초기언어안은 대체한다. 모든 이름·대사·퀘스트·튜토리얼·아이템·스킬·상점·가격/조건·오류/복구·자막을 en-US 키로 납품한다. 기존 영문 고유명사는 보존하고 한국어 원문만 있는 항목은 영어 번역 제안과 최종 검수 상태를 구분한다(TLT-025/026/085).

수익화는 [아이템 상세안](../items-and-monetization.md)과 결정표 v0.22가 반영한 최신 요청을 따른다. 옛 ‘외형 중심’ 요약으로 실제 성능 장비·스탯/스킬 리셋권 판매를 삭제하지 않는다. 가격·성능·무료 대응 장비 획득 시간·무료권 공급은 미확정이다.

## 2. 전체 서사와 상세 설계 경계

[승인된 5에픽 줄거리](five-epic-adventure-story-2026-10-30.md)를 반영한다. 대상은 10~15세이며, 지역 구조와 도둑 추적이 Veyr의 침공 저지로 이어진다.

| 구간 | 지역 | 현재 본편의 사건과 결과 |
| --- | --- | --- |
| 프롤로그 | Dawnspire | 왕관의 심장 탈취·포탈 침공·주민 구조 후 추적 시작 |
| 에픽1 | Deepwood | 보급대/주민 구조·King Shaman 격파·북쪽 운반 명령서 발견 |
| 에픽2 | Frozen Vale | 고립 주민 구조·얼음 수호수 진정·겨울 해제·화산 도시 추적 |
| 에픽3 | Ember Caldera | 광부 구조·냉각 복구·Inferno Overlord 격파·Veyr 계획 발견 |
| 에픽4 | Gloamwood | 원정대 구조·거미 여왕 격파·묘지 요새의 숨겨진 입구 확보 |
| 에픽5 | Haunted Graveyard | Veyr 최종전·왕관의 심장 회수·대형 포탈 폐쇄 |
| 귀환 | Dawnspire | 수정 왕좌 복구·구한 주민/동료와 재회·본편 완결 |

Gloamwood/Crownheart는 영문 가칭이다. 기존 DW/FV/EC/HG 안정ID와 승인32구간 보상은 변경하지 않는다. 아래 기존 구간 추적표와 지역별 상세안은 재사용 후보이며 충돌하는 서사는 승인 개요로 개정해야 한다. HG는 새 본편 에픽5다. 새 지역 ID·스토리 수·Lv1~80 성장 및 Lv20/40/60/80 전직 배치·XP/Gold는 후속 설계이며 과거 장별 레벨을 그대로 적용하지 않는다.

기존 AS/DC/FB/FC 8에픽 후반 원고는 참고로 보존하고 현재 본편 제작 범위에서 제외한다. Dawnspire는 거점이며 첫 제작·전투 검증 지역은 Deepwood다. 일반 본편은 솔로~4인으로 완결하며 레이드와 선택 보스를 결말의 필수 조건으로 두지 않는다. 상세 영어 대사·맵/몬스터·정상 성장·실기기/협동 수용은 후속이며 상위 티켓 완료를 뜻하지 않는다.

## 3. 프롤로그+28스토리 제작 추적표

**모든 행은 문서 있음 / Roblox 구현·수용 미완료**다. `Q`는 공통 납품: 안정 ID·버전·영어 키·목표/적/장치 정의·안전SP·처음/이어하기/재현/리조인·완료/실패/복구·개인 초회/반복/처치 수령·자산 요구·네 클래스 솔로/1~4인/재접속 QA 증거다. 마지막 열은Q에 추가할 구간별 수용이다. 상세 상태/배치는 각 원문을 따른다.

아래 영어 스토리명은 전부 **번역 제안**이다. 원문/JSON에 확정 영어 표시명은 없고 기존 한국어명/slug만 존재한다. 지역/인물/적의 기존 영문명과 지역 ID는 원문 그대로다. 완료Lv는 현재 산술 예측이며 실기기 결과가 아니다. 부모 티켓/지역ID를 함께 사용한다(예: `TLT-061/DW-01/quest`).

- 트리는 클래스당 C6+두계열×(T7+V8+M6+A3)=54, 전체216노드 예산이다. 선택경로30노드·최대90P중79P 선택. 전체 랭크/선행/계수는 미완성이다.
- 스탯 `투자합+잔량=4×(Lv−1)`; Lv1/2/20/40/60/80에0/4/76/156/236/316P. 스킬은 별도 `투자합+잔량=Lv−1`, 최대79P. 다중레벨/중복수령·리셋에도 예산 보존.
- 초기값·기본성장·방어곡선·공속/치명상한과 기존 클래스 자원과 마법 MP의 처리 및 Stamina 제거 후 물리/마법 밸런스는 TLT-027 미결정. STR/INT·DEX/INT 혼합은 정규화 합산/단일 유효 능력치를 비교하고 곱·동일피해 이중보상 금지. VIT와 현재 HP를 구분한다.
- 기사 HP1,000/ATK100·Lv10/Lv28은 비교용 실험값이며 출시 기본스탯이 아니다. 기존 Stamina/서약 비교안은 0.12.0 구현이나 확정 자원 수치가 아니며 최신 자원 계약에 맞춰 재설계한다. 공속으로 회피/방어창·취소규칙까지 임의 단축하지 않는다.

제작은 **TLT-025/026/029 데이터·영어→005~008 K0/기본원형→035 K1/K2 격리실험→009~012 대표던전→041/042 저장·성장→043~050 장비/경제/퀘스트→013~015/054~059 전직 전체→051/060~074 본편→075~083 후반** 순의 의존을 따른다. 원형 실험은 운영 저장과 분리한다. 상세 선행은 루트 백로그를 따른다.

## 6. 핸드오프·품질·미결정 처리

기획 데이터는 안정ID·정의버전·출처/상태·영어키·선행·해금/목표·효과/상한·완료/실패/복구·개인/공유·초회/반복/처치 권리를 갖는다. 엔지니어는 실제 스키마/서버검증/저장/거래/관측을 구체화하고 디자인은 조건/오류/가격과 목표를 기기별로 읽게 하며 모델링은 원본/파생/신규·리그/모션/판정요구를 산정한다. QA는 동일버전과 실기기 증거로 수용한다. 데이터필드 제안은 이미 존재하는 Luau/API로 보고하지 않는다(TLT-029).
