# Deepwood 리뷰·스토리·맵 확장 개선 계획

2026-11-07 · TLT-061/050/057/084/087 · PLAN/DES/RES → ENG/ART/QA · 상태: 계획 작성, 게임 미적용

확장 주제는 **구조한 사람들이 함께 숲을 되찾는 첫 모험**다. [통합 확장 기준](epic-story-map-expansion-2026-11-07.md)과 [네 에픽 리뷰 총괄](other-epic-expansion-review-2026-11-07.md)을 함께 적용한다. 기존 본편 순서·7장·안정ID·보상·완료 기록은 보존한다. 아래 공간/사건/영어 문구는 제작 제안이다.

## 현재 리뷰

근거: `DeepwoodContent · DeepwoodWorld · DeepwoodActivities`. 현재 본편7장/41목표/19전투 목표, 사이드4퀘스트다. 전투 목표는 적 목록이 있는 목표 수이며 웨이브·처치 수·시간이 아니다.

- 강점: 본편41목표에 조사·추적·호위·장치·전투가 이미 연결된다. DW-04에는 거점 지름길도 있다. 첫 전투와 Selene 만남을 다시 길게 설명할 필요는 없다.
- 개선1: DW-04의 서/동 장치, DW-06의 세 장치, DW-07의 서/동 장치가 연이어 나온다. 장치 수보다 각 장치가 막고 있는 주민/길의 문제와 해결 결과를 구별한다.
- 개선2: DW-05는7목표, DW-07은9목표로 후반에 사건이 몰린다. 구조된 인물이 거점과 후속 구간에 어떻게 기여하는지 연결하면 기존 분량의 의미를 높일 수 있다.
- 개선3: 선택4퀘스트는 이미 존재한다. 새 보스보다 습지·채석장·옛 전장의 발견 과정과 보고 왕복을 먼저 개선한다.
- 한계: 소스의 목표/활동 구성 리뷰이며 첫 사용자의 학습 속도나 실제 호위 대기시간은 미측정이다.

## 탐험 가지와 거점 연결

| 현재 ID 또는 신규 후보 | 개선안 |
| --- | --- |
| DW-Q1 | 습지의 방수 기록을 수레 작업자 흔적과 연결하고 동굴 입구의 물높이/발자국으로 발견하게 한다. 슬라임 생태 조사와 보고의 맥락을 강화한다. |
| DW-Q2 | 식량 자루의 흔적→고블린 야영지→포로/식량 회수로 연결한다. Goblin King은 선택으로 유지한다. |
| DW-Q3 | 폭포 뒤 채석장 입구를 소리 외에 물길/레일로도 안내한다. 운반 설비 조사로 거점에 돌아갈 경로를 보여 준다. King Ogre는 선택이다. |
| DW-Q4 | 사라진 정찰병 흔적을 옛 전장의 안전 통로와 연결한다. Enraged Warlord 격파 뒤 귀환길 확보를 눈으로 확인한다. |

선택 가지는 본편 목적을 보완한다. 필수 단서를 숨기거나 본편 진입을 막지 않는다. 신규 후보에는 아직 안정ID·보상·최종 영문명이 없다. 기존 Q-ID를 다른 퀘스트로 재사용하지 않는다. 보고 왕복은 현장 완료 확인과 열린 귀환길을 활용하되 개인 보상 확정은 서버가 처리한다.

주요 사건 공간은 입구/관찰/전투/해결/안전 출구의 앵커로 분리한다. 표의 공간은 새 거대 평지를 뜻하지 않으며 기존 환경 모듈과 회랑·우회로·실내 공간의 조합을 우선한다. 거점으로 돌아오는 지름길은 기존 진행을 확인해 열고 닫는다. 최종 충돌·카메라·경사·AI 경로는 블록아웃에서 검증한다.

## 저장·보상과 검증

기존 완료자의 다음 에픽 진입과7/7 표시는 유지한다. 새 단계는 신규 콘텐츠 버전에 배정하고 진행 중인 구버전 원정은 고정 버전 완주 또는 검증된 체크포인트 이관을 제공한다. 기존 단계 인덱스 사이에 무조건 삽입하지 않는다. 추가 처치XP/Gold/드롭의 총량 영향과 장별 고정 보상 영수증을 별도로 검증한다. 같은 예산 안의 재배치를 우선 시험하며 추가 고정보상·무료 보급·새 판매권리는 이번 계획에서 확정하지 않는다.

네 클래스 솔로/구매0/동료0, 인간4인+전투AI1, 신규/진행 중/기존 완료 계정, PC/터치/패드에서 다음 목적·단서·길 개방·회피 공간을 확인한다. 저장 실패/재요청/재접속/후반 구성원 합류·스트리밍 복귀도 포함한다. 이벤트 연출 NPC는 전투AI 추가 인원으로 구현하지 않는다. HP 자연 회복이나 무료 물약을 안전 지점의 숨은 전제로 삼지 않는다.

첫 구조와 Selene 해금이 늦어지지 않는지, 두 장치의 목적을 구별하는지, 포로/호위 대상의 재접속 위치가 안전한지 확인한다.
