# 영웅별 장비·세트·아이콘 제작 준비안

2026-11-04 · TLT-027/028/029/041/043/044/045/052/073/082/084 · PLAN/RESEARCH/ART → ENG/DES → QA

상태: 사용자 요청에 따른 제작 준비와 재리뷰. 장비 분류·수치·등급·착용Lv·세트는 추천 시험안이며 확정 제품/구현이 아니다. [보스 드롭](boss-drop-reward-design-2026-11-04.md), [보호 재리뷰](../research/2026-11-04-boss-loot-independent-review.md), [확률 강화](equipment-enhancement-v2-2026-11-03.md)를 연결한다. 기존 아이템 ID·수치·보유품·상품/승인 보상은 보존한다.

## 2. 등급별 정체성·효과

| 등급 | 신규 동일 세대 기본 예산 | 외형·게임 역할 |
| --- | ---: | --- |
| Common | 1.00 | 단순 가죽/철, 시작·교체용 |
| Uncommon | 1.08 | 손질된 금속/바느질, 초반 강화 체험 |
| Rare | 1.18 | 명확한 지역 문양, 무료 본편 주력, 첫 세트 후보 |
| Epic | 1.28 | 고유 실루엣·제한된 보석 장식, 반복 보스 수집 |
| Legendary | 1.40 | 큰 고유 실루엣·절제된 상징, 장기 파밍 |
| Unique | 최대1.40, 효과 예산 차감 | 보스 고유명·외형·고정 효과1개, 별도 무작위 옵션 없음 |

고정 능력치 프로필은 Power/Armor/Health만 우선 사용한다. 모든 전용 장비에 무조건 특수 효과를 붙이지 않는다. 공통품은 효율과 호환성, 전용품은 클래스별 프로필·외형이 장점이며 전용품이 자동 상위 티어가 아니다. 동일 레벨 Rare 공통품으로 본편을 끝낼 수 있어야 한다. Unique는 이름만 다른 Legendary가 되지 않도록 고정 효과를 명세하되 효과 미구현 품목은 미출시로 둔다.

Unique 특화 후보: 기사 Pendant의 블록 성공 후 제한 보호막, 엘프 Signet의 지정 조준 기술 적중 후 다음 단일 공격 보너스, 드워프 Vestments의 지정 충격 기술 후 짧은 피해 감소, 마법사 Staff의 지정 주문 적중 후 제한 MP 회복. 공통 Unique는 피격 후 제한 보호막 등 클래스 중립 후보로 시작한다. 각 효과는 수치/대상/지속/내부 재발동/중첩/보스/사망/재장착/MP 상한/계열 호환을 정의해야 한다. 스턴 상향·무한 MP·추가 포인트·기본 공격/회피 쿨다운·Stamina는 도입하지 않는다. 현재 런타임이 이러한 효과를 지원한다고 주장하지 않는다.

## 3. 영웅별 방어구·무기 세트

4클래스 각각 head/body/hands/feet/weapon의 **5부위**가 한 세트다. 기사 방패와 장신구는 세트 조각에서 제외해 다른 클래스와 부위 수를 맞춘다. Rare/Epic/Legendary 세트를 각각 제작 후보로 두며 Unique는 처음에는 개별 고유 장비로 두어 세트와 경쟁하게 한다. 4클래스×3등급=12세트 후보이며 동일 계열 5부위를 묶는다. 새 슬롯은 없다.

| 클래스 | 세트 가칭 | 2 / 4 / 5부위 효과 시험 후보 |
| --- | --- | --- |
| Knight | Oathguard Bastion | 최대HP +2% / 장비 Armor +2% / 장비 Power +2% |
| Elf Archer | Briarwatch Vigil | 최대HP +2% / 장비 Armor +2% / 장비 Power +2% |
| Dwarf Axe Thrower | Stonehearth Resolve | 최대HP +2% / 장비 Armor +2% / 장비 Power +2% |
| Mage | Aetherweave Constellation | 최대HP +2% / 장비 Armor +2% / 장비 Power +2% |

초기에는 같은 보너스 규칙으로 클래스별 과도한 격차를 줄이고, 실제 차이는 부위별 능력치 프로필과 무기/외형에서 준다. 클래스 특수 세트 효과는 위 단순 세트와 비교한 뒤 추가한다. 각 문턱 효과는 누적하되 배율끼리 곱하지 않는다. 세트 보너스는 강화·Unique 발동을 다시 강화하지 않으며 세트 소속 아이템의 개별 예산을 같은 등급 비세트의97%부터 비교한다. 3%차감과 2%보너스는 실험값이며 전체 생존/공격 가치의 단순 합산으로 동등성을 주장하지 않는다. 같은 setId·세대·등급의 서로 다른 5개 부위만 센다. Rare와 Epic 혼합으로 문턱을 달성하지 않으며 다른 세대도 합치지 않는다. 상위 등급으로 교체할 때 세트 상실을 비교창에서 표시한다. 여러 세트 효과 중복과 재장착 시 HP 회복 악용을 서버에서 막는다.

## 4. 착용 레벨과 난이도·성장

착용Lv와 희귀도·강화는 별개다. Common이라도 Lv80 장비가 있고 Unique도 Lv10 보스 품목이면 Lv10에 착용할 수 있다. Lv1/5는 기존 초반 품목 중심으로 두고 신규 상위 등급은 Lv10부터 설계한다. 제안 세대는 1/5/10/20/40/60/80이며, 10~20 간격이 길면 Lv15 또는 Lv30/50/70 중간 세대 필요성을 실제 교체 시간으로 판단한다. 모든 세대를 한 번에 생성하지 않는다.

| 보상 콘텐츠 | 신규 착용Lv 후보 | 출시 전 조건 |
| --- | --- | --- |
| Deepwood Easy | 5/10, 기존 Lv1 품목 보존 | 보스별 진행 시점과 정상 성장 대조 |
| Frozen Vale Easy | 10/20 | 진입Lv·중간 성장 및 기존 Lv10 장비와 비교 |
| Ember Caldera Easy | 20 | 본편 성장·처치시간 수용 |
| Gloamwood/HG Easy | 20/30 후보 | 고정 성장 예산 미완성; 40/60/80을 임의 강제하지 않음 |
| Hard | 20/40 후보 | 보스별 입장·진행과 무료 장비 확보; Lv20 첫 진입에 Lv40만 지급 금지 |
| Insane | 40/60 후보 | 첫 진입Lv40 사용 장비와 후속 교체 경로 |
| Hell | 80 | Lv80 무료 장비/적Lv80 이상 곡선 검증 |

각 임무/보스/난이도가 고정된 wearLevel·lootTableVersion을 참조한다. 원정 시작 후 영웅 레벨에 맞춰 결과가 달라지지 않는다. 미래 장비 획득과 착용을 구분하며 보관 가능하되 서버가 착용 자격을 확인한다. Easy로 Lv80에 도달하는 무료 성장 경로와 해당 시점의 장비는 PLAN 선행이며 이 표만으로 완성되지 않는다. 기존 Easy 후반 입장Lv27과 고정 보상 미승인 임시0 구간을 Lv80 콘텐츠라고 표시하지 않는다.

## 5. 강화 포함 예산과 재리뷰

현재 신규 강화 +9, 성공률100/90/80/70/60/50/40/30/20%, 목표n 비용 보석2n·마석max(0,n−3), 시도Gold0을 유지한다. 실패는 단계 보존·재료 소모, 성공 투입분80%회수이며 실패분은 반환하지 않는다. 모든 신규 등급/세트 부위/장신구의 Power/Armor/Health 양수에만 기본치×(1+0.03n)을 적용한다. Unique 효과·세트 보너스·MP 회복량은 강화하지 않는다. 과거+10 권리·원장은 보존한다.

같은 세대 Common 대비 Legendary+9는1.40×1.27=1.778이다. 다음 세대 Rare가 이전 Legendary+9보다 약해 강제 장기 강화가 되는지 비교한다. 산술 예시로 다음 세대 기본 예산을1.85배로 잡으면 Rare는2.183배라 이전 Legendary+9를 넘지만, 이는 실제 Lv별 스탯 승인이 아니다. Unique 효과와 세트·Armor 피해경감·HP·모드 전투를 함께 검증해야 한다. 다음 세대는 무조건 승리할 필요는 없지만 정상 교체 유인이 있어야 한다.

장비 하나 +9 기대 비용 보석244.37/마석67.43, 5부위 세트 약1221.87/337.14, 8슬롯 약1954.98/539.43이다. 기대값이며 보장 상한이 아니다. 낮은 세대에서 +9를 필수로 요구하지 않는다. 본편·전직·입장에 세트 또는 강화 문턱을 만들지 않는다. 전용 장비·세트·Unique 효과와+27%강화를 전부 합쳐 같은 세대 비세트 Rare를 얼마나 앞서는지 비교한다. 모든 출처의 동일 정의는 같은 성능/강화 규칙을 쓴다.

## 6. 보스 풀과 드롭 계획

보스마다 공통 방어구·공통 장신구와 각 클래스 유효 전용품을 함께 배치한다. 초기에는 서버가 선택 영웅의 호환 품목+공통품에서 추첨하는 안을 쓴다. 기존 타 클래스 획득 허용 상세와 차이는 드롭 정책 확정 때 결정한다. 먼저 등급을 기존 보스 드롭 시험표로 선택하고 그 등급의 유효 itemId 풀에서 균등 추첨한다. 따라서 등급확률/N이 실제 품목확률이며 희망 품목별 보호도 필요하다. 풀의 전용/공통 비중은 품목 수에 좌우되므로 실제 목록을 공개하고 전용 비중이 너무 희박하면 명시적 가중치 표로 대체한다.

King Ogre는 body/feet·생존 장신구, Goblin King은 hands/head·공격 장신구, King Shaman은 클래스 무기·기사 방패·대표 Unique의 목표 보스 후보다. Frozen/Ember/후반 보스는 지역 소재·다음 세대 동일 계열을 분담한다. 각 실제 보스 풀은 6등급/4클래스에 모두 유효해야 하며 고유 품목이 없는 등급을 임의 재추첨하지 않는다. 세트 조각을 여러 보스에 나눠도 특정 선택 퀘스트/유료/AI가 필수는 아니어야 한다. 개인 장비1개/보스, 중복 없는 영수증·죽은 참여자·지원 기여·만석/저장 불명 복구 및 보스별 목표 보호는 기존 설계를 따른다. 장비 세트/중복품/희망 보호를 합친 실제 획득시간은 미검증이다.

## 7. 아이콘 생성 준비와 수용

40개 SVG는 슬롯과 클래스 팔레트 확인용 **초안**이다. 승인 TD 아이콘이나 최종 메뉴 미리보기가 아니다. 기존 실루엣을 반복하는 등급은 최종 그림에서 재질·문양·실루엣을 차별화해야 한다. 표준 출력은 투명 1024 정사각 원본·여백12%·48px/64px 가독성·문자/수치/등급 프레임 없는 장비 한 개다. 등급 배지/프레임/+숫자/레벨은 런타임 TD 레이어로 합성해 재사용한다. Unique는 별도 실루엣을 제작하고 모든 등급을 색만 바꾸지 않는다.

실제 생성 직전 공유 레지스트리의 TD 장비/프레임/관련 영웅 원본을 눈으로 확인하고 현재 해시·권한·적합성·참조 경로를 기록한다. 이번에는 후보 레지스트리만 대조했으며 각 최종 참조의 재감사와 시각 비교는 후속이다. 원본이 있는 품목은 이를 파생하고, 없는 품목만 준비된 품목별 프롬프트로 신규 생성한다. 생성 이미지는 게임 정의/수치의 원천이 아니다. 승인 전 상태는 draft이며 원본/raster는 LFS에 기록한다. Roblox 자산 ID 연결은 별도 구현·검증이다.

제작 순서: (1) 공통 방어구4+장신구7와 무기4+방패1의16실루엣 확인 (2) 클래스별 방어구·장신구24 확장 (3) Lv10 Rare/Epic/Legendary 비교 원형 (4) 고유 효과가 확정된 Unique (5) 지역/세대 확대. manifest의 status와 각 최종 품목의 reference·prompt·output·hash·approval을 관리한다.

QA는 4클래스·8슬롯·클래스/레벨 제한·세트 혼합·장신구 uniqueGroup·무기 유형·스킬 계열·MP 보유 자격과 재장착·동시 저장·드롭/미수령을 확인한다. 네 모드, 1~4인·AI0/1, 무료 Rare 비세트/세트/Legendary/Unique, 강화0/5/9의 처치시간·사망·소비·보스별 품목/시간과 모바일 가독성을 비교한다. 이 계획은 생성 준비까지이며 실제 세트/효과/아이콘 런타임·실제 저장/기기/게임 밸런스 수용은 후속이다.

검증 기록: 40개 SVG XML 파싱, 고유 제안ID 240개, 세트 후보60조각(12세트×5), 상대 링크, 다음 세대 예산 산술 및 git diff --check PASS. SVG 육안 렌더·48px/64px 가독성은 미검증이며 로컬 CairoSVG가 없어 래스터 미리보기는 생성하지 않았다. 생성형 이미지·TD 원본 일치·업로드·게임 연결 검증도 후속이다. 게임 빌드를 만들지 않아 VERSION/릴리스 태그는 갱신하지 않는다.


## 2026-11-04 추가 — 공통 최대 마나 장신구

사용자 요청으로 Mana Ring / Arcane Reservoir Pendant / Wellspring Charm 세 계열을 추가한다. 공통 장신구는7종, 전체40계열·Lv10 여섯 등급240개 제안 레코드다. 이름/수치는 가칭·시험값이며 런타임 ItemCatalog 등록은 후속이다.

| 품목 | Lv10 Common 기본치 시험안 | 역할 |
| --- | --- | --- |
| Mana Ring | 최대MP +20 | 마나 확보용 반지 |
| Arcane Reservoir Pendant | 최대MP +30 | 마나 집중 목걸이 |
| Wellspring Charm | 최대MP +15, 최대HP +30 | 마나·생존 혼합 장신구 |

최대MP를 늘리며 즉시 회복/MP재생/마법 해금 효과는 없다. 공통품이라 모든 클래스가 보관·착용할 수 있지만 **기존 마나 풀이 있는 영웅에게만 MP 보너스를 적용**한다. Mage 및 Lv20 첫 전직을 완료한 magic_archer Elf가 대상이며 Knight/Dwarf/그 외 Elf에게 새 마나 풀을 만들지 않는다. 무효 MP 효과는 비교창에서 설명하고 혼합품의 HP는 정상 적용한다. 슬롯별 같은 uniqueGroup 중복 금지, 서로 다른 품목의 MP는 합산하는 시험안이다. 직업/계열 변경·해제 시 현재MP는 변경된 최대MP 이하로만 제한하며 장착으로 현재MP를 추가 충전하지 않아 교체 회복 악용을 막는다.

현재 강화는 Power/Armor/Health만 대상으로 하므로 **최대MP는 +9에서도 기본치 유지**다. MP 전용 반지/목걸이는 현 규칙상 강화 대상이 아니며 시도 시 재료를 소비하지 않도록 표시·검증해야 한다. HP 혼합품은 HP만 강화한다. 마나를 강화 대상으로 확대할지는 별도 경제/서버 검증이 필요한 제안이며 이번에 암묵적으로 확대하지 않는다. Rare 이상 동일 세대 MP 배분과 HP 혼합 예산, 보스 풀 내 마나 없는 클래스의 유효 보상 비중, 게임 표면 설명을 실제 카탈로그 작성 전에 검증한다. 표의 수치는 기존 등급 배율과 함께 무조건 자동 산출하는 최종 능력치가 아니다.

40개 SVG 구조·240개 고유 레코드·보드 참조를 정적으로 검증한다. 새로운 세 아이콘은 기존 실루엣 파생 초안이며 최종 TD 아트/렌더/게임 효과·장착/MP 보존·실기기 수용은 후속이다.
