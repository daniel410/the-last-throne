## 최신 사용자 결정

- **영웅과 성장:** 네 원형 클래스는 불변. 각 2계열의 첫 전직은 Lv20, 이후 Lv40/60/80. 성녀는 NPC·선택 지원이며 플레이어 클래스가 아니다. Mage는 비전/바람·기초 물 → Lv20 Pyro/Cryo → Lv40 대지/번개 → Lv60 광역 → Lv80 최강 주문.
- **액션:** Attack·Block·Dodge·Sprint는 모든 영웅의 공통 액션이고 Stamina를 소비하지 않는다. 기본 공격·회피에는 별도 쿨다운이 없지만 동작/무적 시간은 유지한다. 무기별 블록 연출·판정과 스프린트 속도는 설계·검증이 필요하다.
- **스킬 자원:** 영웅별 물리 스킬은 Stamina, 마법 스킬은 MP와 해당 기술의 독립 쿨다운을 사용한다. 원형 엘프는 물리 Stamina, 마법궁수 전직 시 마법용 MP를 추가한다. Mage의 지팡이 기본 공격은 무료 공통 액션이다. 스킬 비용·자원 수치·회복과 기존 서약/집중/열기 자원의 관계는 미정이다.
- **편성과 조작:** 전투용 스킬은 기본 3개, Lv20 첫 전직 **완료 후** 5개. 습득한 스킬이 부족하면 빈 슬롯으로 둔다. 스킬 관리 화면에서 미리 지정하고 하단 아이콘에 키·개별 쿨다운을 표시한다. PC 스킬 키는 1~6, 액션은 Q/E/R 등의 방향. 6번과 궁극기 슬롯의 관계 및 액션별 최종 키 배치는 미정이며, 기존 V 회피를 유지하고 R도 시험한다.
- **성장·세계·운영:** STR/DEX/INT/VIT 스탯 포인트는 `4 × (level - 1)`·Lv80 316, 스킬포인트 기준안은 별도 79. TD와 같은 Experience의 별도 RPG Place·공통 Diamonds 방향이며 TD Gold/RPG Coins/Command Points와 진행은 구분한다. 기존 TD 운영과 권리를 보존한다.
- **언어·제작 마감:** 개발 문서/보고는 한국어, 게임 콘텐츠는 영어(en-US). 완료 작업은 선별 커밋·원격 푸시, 빌드는 `MAJOR.MINOR.MICRO`, 실제 릴리스만 태그·푸시한다. 이미지/3D 원본과 자산 압축은 Git LFS 규칙을 따른다.

## 남은 제품 판단

궁극기 전용 슬롯과 6번 키의 관계, Q/E/R의 액션별 기본 배치/대체 키, 비용·최대치·회복 속도, 마법궁수/성기사의 자원 세부, 기존 클래스 자원 통합 여부, 스킬 교체 가능 조건과 재접속 중 쿨다운은 미정이다. 먼저 플레이 가능한 후보와 검증 결과를 만든 뒤 결정한다. 3→5 슬롯·공통 액션의 무료 사용·마법 MP 및 물리 스킬 Stamina는 이미 결정됐다.
