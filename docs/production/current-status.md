## 유지할 결정

- 네 원형 클래스는 불변이며 각 2계열의 첫 전직은 Lv20, 이후 Lv40/60/80. Priest/Selene는 NPC·선택 지원이다.
- Attack·Block·Dodge·Sprint는 공통 액션이며 Stamina를 소비하지 않는다. 기본 공격과 회피에는 별도 쿨다운이 없다. 물리 스킬은 기술별 쿨다운만, 마법 스킬은 MP와 스킬별 쿨다운을 사용한다. 0.18.8 세션 원형에서 Stamina를 제거했다. 0.24.1에서 마법궁수 첫 전직 완료 후 MP와 전직 시험을 구현했다. 정식 퀘스트·밸런스 수용은 별도다.
- 전투 스킬은 Lv1/5/10에3/4/5개까지 사전 편성한다. 습득·자격과 슬롯 개방은 별개다.0.31.0에서 궁극기는 일반1~5와 분리하고 Lv80 최종 전직 후에만 별도 버튼을 표시한다.
- 스탯 포인트는 `4 × (level - 1)`로 Lv80에 316, 스킬포인트 기준안 79는 별도다. The Last Throne은 TD와 독립 Experience이며 지갑·상품·진행은 검증된 연동 전까지 분리한다.
- 개발 문서·보고는 한국어, 게임 콘텐츠는 영어(en-US). 작업별 커밋·푸시, 빌드 버전, 실제 릴리스 태그와 LFS 규칙을 유지한다.
