# 강철기사: 기본 스킬에서 확장되는 공격 스킬트리

2026-10-29 · TLT-013/015/027/042/052/058 · PLAN → ENG·DES·ART·QA · 가칭 기획안, 구현/플레이 미검증

## 방향과 제약

사용자 정정: 강철기사를 방어 위주로 제한하지 않고 공격 스킬을 충분히 제공한다. 기존 기사 공통 3개 스킬을 각각 뿌리로 삼아 강화·분화·새 스킬로 성장시킨다. 이전 방어 중심 기술 목록은 이 초안으로 대체한다. 성기사 세부 트리는 별도 리뷰한다.

검·방패를 유지하고 물리 스킬은 Stamina와 기술별 쿨다운을 사용한다. 공통 공격·블록·회피·스프린트는 무자원이며 기본 공격·회피의 별도 쿨다운이 없다. 매 Lv20/40/60/80 전직 완료에 새로운 스킬을 최소 1개 해금하고 그 사이에도 새 액티브를 제안한다. 슬롯은 기본3, Lv20 완료 후4, Lv40 완료 후5, 최대5다. Lv80 궁극기 사용·슬롯은 미정이다. 영어명·기능·레벨은 가칭이다.

두 계열의 단일·광역·이동·표식·보호 역할과 Provoke 추가 효과는 [역할·도발 확장안](knight-taunt-and-skill-roles-2026-10-29.md)을 참조한다. 효과는 실험 제안이다.

## 뿌리와 성장

| 뿌리 | 기본 역할 | 성장 방향 |
| --- | --- | --- |
| Shield Bash | 전방 방패 타격·자세 피해 | 진입→방패 강타→돌진과 검격으로 단일 파쇄 |
| Whirlwind | 주변 광역 검격 | 전방 다수 검격→연속 회전→이동형 광역 공격 |
| Provoke | 주변 일반 적의 주의를 끌어 전선 정리 | 방어가 약화된 적을 파쇄→전방 베기→광역 압박. 보스 도발·약화 면역은 별도 정의 |

**학습과 장착의 차이:** 각 파생 액티브는 뿌리 스킬을 습득하고 해당 레벨·계열 전직을 완료해야 해금된다. 제안상 파생 액티브를 쓰기 위해 뿌리를 슬롯에 장착할 필요는 없다. 뿌리와 함께 장착하면 조건부 연계를 활용할 수 있다. 이전 단계 액티브를 먼저 장착하거나 특정 79P 투자량을 요구하지 않는다. 늦은 전직 완료 시 이미 도달한 중간 기술의 학습 자격을 빠짐없이 제공하고 중복 지급하지 않는다. 실제 학습 방식·SP 사용은 기존 무료 습득 제안에 따르되 최종 확정 전이다.

## 전직·레벨별 새 액티브 (가칭)

사용자 결정에 따라 기본 3스킬 외 계열 액티브는 12개다. 중복 역할을 고려해 Piercing Thrust·Weakpoint Cut·Iron Arc를 목록에서 제외하고, 세 뿌리 각각 4개로 정리한 실험안이다. 레벨·세부 효과는 미확정이다.

| 획득 | 뿌리 | 기술 | 독립적인 공격 역할과 연계 |
| --- | --- | --- | --- |
| Lv20 강철기사 전직 | Shield Bash | Counter Slash | 즉시 전방 검격. 직전 방어 성공 시 자세 피해 추가. 방어하지 않아도 기본 피해를 낸다. |
| Lv26 | Whirlwind | Steel Sweep | 전방 넓은 부채꼴을 베어 적을 밀어내는 검격. 제자리 주변을 베는 Whirlwind와 범위가 다르다. |
| Lv33 | Provoke | Challenging Strike | 방패로 전방을 공격하고 일반 적의 주의를 끈다. 도발 불가 보스에도 기본 피해와 자세 피해를 준다. |
| Lv40 중갑기사 전직 | Whirlwind | Twin Cyclone | 두 차례 연속 회전 공격. 첫 회전과 두 번째 회전 사이에 적의 공격을 받을 수 있는 틈을 조정한다. |
| Lv46 | Shield Bash | Shield Breaker | 방패를 크게 휘둘러 단일 대상의 자세를 강하게 압박한다. 보스에도 자세 피해. |
| Lv49 | Shield Bash | Guardian Counter | 방패로 전방을 쳐 피해를 주고 자신·가까운 아군을 짧게 보호한다. 아군 없이도 공격과 자기 보호가 가능하다. |
| Lv53 | Provoke | Rallying Slash | 근처 일반 적의 주의를 끈 뒤 전방을 벤다. 적을 끌어당기는 강제 이동은 확정하지 않는다. 솔로에서도 검격 사용 가능. |
| Lv60 철벽기사 전직 | Shield Bash | Breaker Charge | 방패를 들고 짧게 돌진해 부딪친 적을 타격하고 검으로 마무리한다. 지형·낙하 보호와 보스 자세 피해를 서버가 처리한다. |
| Lv63 | Provoke | Vanguard Strike | 짧게 전진해 방어 약화 중인 적을 베고 추가 자세 피해를 준다. 약화가 없어도 기본 타격을 한다. |
| Lv66 | Whirlwind | Blade Storm | 짧은 거리 이동하면서 연속 회전 공격. Whirlwind보다 이동 선택이 있으나 지속 중 방향과 피격 위험이 남는다. |
| Lv69 | Whirlwind | Sweeping Break | 낮게 검을 휘둘러 주변 일반 적을 잠깐 감속한다. 보스는 감속 면역일 수 있으나 기본 피해는 적용한다. |
| Lv73 | Provoke | Warcry Assault | 전방으로 함성을 질러 일반 적의 주의를 끌고 검으로 연속 공격한다. 도발 불가 보스에도 공격을 수행한다. |
| Lv80 강철의 수호자 전직 | 세 뿌리의 완성 | Unyielding Front (궁극기) | 전방으로 방패 돌진, 주변 검격, 짧은 자기·주변 아군 보호를 한 번에 수행한다. 신규 궁극기이며 방어만 주는 기술이 아니다. |

Lv20/40/60의 전직 기술은 서로 다른 공격 방식이다. 12개 모두 피해를 주는 액티브 후보이고, Provoke 계열은 공격과 도발을 결합한다. 제어 면역 적과 단독 플레이에서 피해를 주기 위한 수치·범위는 실제 밸런스 시험이 필요하다. 철벽의 보호 강점은 방패 행동, 해당 노드 및 궁극기에 남기고 별도의 방어-only 액티브를 강요하지 않는다.

## 궁극기 수량과 Lv80

기본3 + 추가12 + 궁극기1 = 현재 구성 총16개다. 기존 Lv15 공통 궁극기와 Lv80 새 계열 궁극기를 동시에 별도 기술로 유지하면 총17개이므로 충돌한다. Lv80 전직 완료 시 기존 공통 궁극기가 새 계열 궁극기로 교체되는 안을 제안한다. 새 기술의 이름·효과·ID와 기존 투자/재접속 복구 및 교체 과정은 미정이며, Lv80 전직 때 새로운 궁극기가 열리는 조건은 유지한다. 교체가 승인/구현됐다는 뜻은 아니다. 궁극기 슬롯·사용법도 미정이다.

## 성장 노드 예시

모든 노드는 별도 스킬 버튼을 추가하지 않는 강화다. 예시 선행은 뿌리 숙련 1랭크이며 투자 비용·랭크·서버 판정은 별도 설계한다. **새 액티브 해금과 강화 노드의 학습은 서로 다른 성장**이며, 예시 숫자는 확정하지 않는다.

| 뿌리 | 강화 A | 강화 B | 파생에 미치는 방향 |
| --- | --- | --- | --- |
| Shield Bash | 자세 피해 강화 | 전방 적중 안정성 강화 | Shield Breaker의 파쇄 또는 Breaker Charge의 마무리 선택 |
| Whirlwind | 주변 다수 공격 강화 | 회전 중 이동/범위 조정 | Twin Cyclone의 연속타 또는 Blade Storm의 이동형 공격 선택 |
| Provoke | 방어 약화 지속·대상 범위 개선 | 방어 약화 대상에 대한 자세 압박 강화 | Challenging Strike 단일 파쇄 / Rallying Slash 광역 / Warcry Assault 연속 타격 |

가지/선행 노드의 완전한 그래프와 상충 선택은 미확정이며 공통6·계열24의 기존 노드 예산 및 Lv80 79SP로 실제 성립하는지 재검증한다. 스탯316P와 분리한다. 같은 계열 내 세 뿌리 모두 접근 가능해야 하며 필수 빌드 하나를 강제하지 않는다.

## 5칸 편성 예시

- **단일 파쇄:** Shield Bash / Counter Slash / Shield Breaker / Breaker Charge / Whirlwind. 방패와 검의 공격을 연결한다.
- **다수 섬멸:** Whirlwind / Steel Sweep / Twin Cyclone / Blade Storm / Challenging Strike. 여러 방향과 이동형 광역을 섞는다.
- **전선 공격:** Provoke / Challenging Strike / Rallying Slash / Warcry Assault / Shield Breaker. 일반 적을 모으며 공격하고 보스에게도 공격 기술로 기능한다.

이 예시는 후보이며 각 기술의 동일 쿨다운·중복 피해·최적화는 정해지지 않았다. Lv20·40·60 단계에서 해당 기술을 모두 배우기 전에는 사용할 수 없다. 궁극기 편성 방법도 별도 결정이다.

## 범위와 검증

강철기사와 성기사 각각 기본 액티브3개 + 계열 액티브12개 + 궁극기1개 = 선택 계열당 총16개가 최신 목표다. 다른 세 클래스가 기존 액티브 예산을 유지한다면 전체 액티브 정의는 기존36에서54개다(기사 두 계열 각각3→12, 총18개 증가). 네 클래스 8계열 전체에 같은 구조를 적용하면 액티브 정의는108개(공통12 + 계열96)이며 타 클래스 개별 내용은 별도 설계한다. 궁극기 정의 예산은 공통과 계열 후보의 정리 방식에 따라 재산정이 필요하다. 전체 216노드·79SP는 기존 기준안으로 재검증한다. 기술·레벨·효과·제작비는 미검증이다.

QA: Lv20/40/60/80 전직 완료 후 새 기술, 전직 사이 다수 액티브, 뿌리 습득만으로 파생 자격과 뿌리 미장착 시 사용, 5칸 편성, 솔로 및 2/4인, 제어 면역 보스에 피해/자세 적용, 늦은 전직·재접속·저장 실패·중복 지급을 검증한다. 공격 타이밍·Stamina·개별 쿨다운·도발 확률/중첩·보스 자세 피해·돌진 벽/낙하 및 모바일 조준은 미정이며 서버와 애니메이션의 일치를 실기기에서 검증한다. 문서는 기획안이며 전직·기술·트리·저장은 구현되지 않았다.
