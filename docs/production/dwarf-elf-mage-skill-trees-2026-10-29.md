## 공통 계약

4개 클래스의 최초 클래스는 불변이고 각 2계열이다. 각 선택 계열은 기본 액티브3 + 계열 액티브12 + Lv80 계열 궁극기1 = **16개**를 목표로 한다. Lv15 궁극기는 없다. Lv20/40/60/80 각 전직 완료 시 새 스킬을 최소 하나 제공하고 각 전직 사이에도 여러 액티브를 배운다. 레벨 도달만으로 전직하지 않는다. 아래의 Lv20/26/33/36, Lv40/46/49/53, Lv60/63/69/73은 **실험용 배치**이며 각 뿌리별4개/계열12개다. 전직 레벨은 사용자 결정, 중간 레벨·이름·효과는 제안이다. 늦게 전직하면 해당 단계의 이미 도달한 중간 스킬 자격을 복구하되 중복 지급하지 않는다.

기본 슬롯3, Lv20 전직 완료 후4, Lv40 전직 완료 후5이며 최대5다. 궁극기의 슬롯/입력은 미정이고 Lv80 궁극기를 어떻게 즉시 편성하는지는 이 문서로 확정하지 않는다. 파생 액티브의 자격은 해당 뿌리 스킬 습득 + 제시 레벨 + 해당 전직 완료를 제안하며, 뿌리를 장착해야 할 필요는 없다. 전직 사이의 새 액티브는 단순 랭크 강화가 아니다. 스킬 습득과 SP 강화, 전투 편성은 별개이며 무료 습득은 기존 제안이다. 스킬 포인트 Lv2~80 총79P·스탯316P는 별도다. 리셋권 정책과 최초 클래스 불변을 바꾸지 않는다.

공통 공격·블록·회피·스프린트는 자원을 쓰지 않고 기본 공격·회피에 별도 쿨다운이 없다. 모든 물리 스킬은 Stamina, 모든 마법 스킬은 MP 및 각 스킬의 쿨다운을 쓴다. 드워프 폭탄은 기술이며 물리·Stamina로 분류하는 제안이다. 명궁 기술은 물리·Stamina, 마법궁수의 파생은 마법·MP이며 원형 기본3은 물리·Stamina다. 마법궁수 MP는 Lv20 첫 전직 완료 시 개방한다. Mage 계열 기술은 전부 마법·MP다. 모든 보호·이동도 활성 스킬이면 분류된 자원과 쿨다운을 갖는다. 비전/바람 입문과 기초 물, Pyro Lv20 화염/Lv40 대지, Cryo Lv20 냉기/Lv40 번개, Lv60 대규모 광역, Lv80 최강 주문을 지킨다. 이전에 해당 상위 원소를 주지 않는다.

각 표에는 최소 단일·광역·이동·표식/연계·보호/제어를 포함한다. 상태와 연계는 없을 때도 기본 효과가 있으며 보스에 무조건 속박/강제이동/연속 패턴 취소를 주지 않는다. 표식·보호막/투사체·설치물의 상태 및 피해는 서버가 확정한다. 선택지는 솔로에서 모두 쓰일 수 있고 일반4인에 전투 AI는0, 설치 무기나 스킬 이펙트는 자동 동료가 아니다. 모든 사거리·피해·비용·쿨다운·보스 효과·스택·지속은 아직 정량값 미정이다. 스킬명·상위 직업의 영문 번역은 모두 가칭이다.

## 학습·빌드·예산 리뷰

각 클래스는 공통 C1~C3에 각각 기본 기술 숙련, C4~C6에 대응 기술 운용 강화 제안이 있다. 각 계열은 뿌리별 4개 파생 액티브의 역할을 가지며, 계열 노드는 액티브가 아니라 강화/변형 선택이다. 이전 공통6+계열24·3랭크, 전체216 노드는 기준안이며 12개 파생 각각에 노드를 자동 생성하지 않는다. Lv80 최대79SP로 유효한 선택이 존재하는지 전체 그래프/비용·선행·선택 충돌을 재산정하기 전에는 완성된 스킬트리라고 판단하지 않는다. 스킬 획득·선행·저장·계열 재선택·리셋권 처리는 별도 서버 계약이 필요하다.

예시 편성(전부 해당 자격 습득 후, 각 5칸):

- 강철 드워프: Armor Splitter / Returning Echo / Ground Slam / Stonebound Leap / Shatter Blow — 단일 파쇄와 회수.
- 화약 드워프: Gunner Shot / Bomb Toss / Scatter Shot / Field Mortar / Ground Slam — 지정 구역과 이동. (Lv60 이후)
- 명궁: Weakpoint Shot / Moving Volley / Piercing Line / Mark Breaker / Arrow Rain — 단일 표식과 다수 공격. (Lv73 이후)
- 마법궁수: Elemental Arrow / Vine Trap / Storm Arrow / Gliding Shot / Spirit Rain — 표식과 제어. (Lv60 이후)
- Pyro: Ember Lance / Earth Rise / Ember Step / Searing Ward / Lava Eruption — 단일·이동·대규모 광역. (Lv60 이후)
- Cryo: Frost Lance / Chain Lightning / Frost Step / Ice Ward / Froststorm — 냉기·번개 연계. (Lv60 이후)

한 직업/선택 계열에서 기본3+계열12+궁극기1 =16. 전체 액티브 정의는 공통 4×3=12와 계열 8×12=96으로 **108**, 계열 궁극기8, 총 정의116이다. 현재 신규 상세안은 3클래스/6계열 액티브72개+궁극기6개이며 구현/승인 수가 아니다. 제작량은 모션·VFX·서버 판정·아이콘 재사용 가능성을 검증해 산정한다.

## 미확정과 수용

PLAN은 기술별 역할/뿌리/중복·MP/물리 구분과 표식 소유/소비를 상세화하고, ENG는 서버 전직·레벨·자원·쿨다운·피해·상태·설치 상한, 중복 지급·저장 실패·재접속을 설계한다. DES는 5칸 편성·잠금 사유·새 스킬 안내·터치 조준과 취소를 영어로 제공한다. ART는 원본 권리/해시·활 시위·도끼 회수·지팡이·화약 효과를 검증하며 장착 총 제작을 선행시키지 않는다. QA는 각 계열 전직20/40/60/80과 전직 사이 새 기술, 12개/뿌리4개 계산, 5칸·Lv80 궁극기 사용 미결정, solo/2인/4인·동료0, 보스 면역·사각/벽·폭탄 장치·다수 플레이어 표식 중첩, 실제 기기/네트워크를 검증한다. 기술별 재료/애니메이션·효과 수치·적응형 노드·정식 전직/저장은 모두 미구현·미검증이다.
