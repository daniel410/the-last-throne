# 대표 퀘스트의 공간·지물·결과 연결

2026-11-14 · TLT-061/062/063 · PLAN/DES/ENG → QA

사용자는 [조사](../research/2026-11-14-quest-terrain-props-and-items.md) 후 작업을 요청했다. 첫 구현 범위는 DW-01 흔적 추적, FV-03 양안 봉화, EC-01 화물 설비다. 다섯 에픽 전체 개편 또는 새 이동/생활 시스템 도입으로 확대하지 않는다.

`CampaignQuestSetpieces`는 지역별 생성·미술 배치가 끝난 후 한 번 생성한다. 원본은 `StoryProps`/`StoryQuestGeometry`의 기존 소품을 재사용한다. 새 모델 업로드·외부 자산·별도 인벤토리 도구는 없다. 새 추적 자국은 `CampaignIncidentRoute`와 `CampaignBounds`를 따라 서버가 인정하는 바닥에만 배치한다.

목표/단계ID·동선 좌표·정답·모드·전투량·보상·저장 스키마·요청 처리는 변경하지 않는다. 기존 `CampaignExpansionPresentation`과 `CampaignSceneState`로 확정 저널을 개인 투영한다. 클라이언트의 기어/운반대는 피해·진행·아이템 지급 권한을 갖지 않는다. 수리 요청이 저장되기 전에는 완료 장면을 보여주지 않는다.

운반대는 탑승형 이동 발판이 아니라 기존 승강장 옆의 화물 가동 장면이다. 고정 바닥과 원래 충돌은 유지한다. 개인 연출의 새 파트는 anchored/noncolliding/nontouch/nonquery이며 파티원 진도 차이로 통행을 변경하지 않는다. 물리적 지형 고저차·협곡 재굴착·새 등반/운반 조작은 이번 구현에 포함하지 않는다.

영문 입력 문구는 FV 봉화 `Light beacon`, EC 조작 `Fit gear and start lift`다. 기존 F/ButtonX/터치 공통 프롬프트 경로를 재사용한다. 새로운 안내판/설명 UI를 덧붙이지 않는다.

수용은 [작업 증거](../evidence/quest-setpieces-20261114/README.md)에 기록한다. 장면 생성/기하·개인 복원 검사는 재미·실기기·게시 수용과 구분한다. QA는 최초/부분/완료/영웅 전환·재접속/스트림 도착, 솔로~4인+허용 AI와 세 기기의 실제 가독성·통행·성능을 확인한다.
