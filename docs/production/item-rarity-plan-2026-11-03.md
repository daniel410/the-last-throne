# 아이템 등급 도입 계획

2026-11-03 · TLT-027/028/029/041/043/044/045/052/073/082/084 · RESEARCH/PLAN → ENG/DES/ART → QA

상태: **등급 도입은 사용자 요청, 아래 6단계·계수·획득량·고유 효과는 추천안**이다. 이번 산출물은 계획이며 게임 구현·가격 변경·게시 승인이 아니다. [조사](../research/2026-11-03-item-rarity.md), [강화](equipment-enhancement-plan-2026-11-02.md), [난이도·반복 보상](difficulty-rewards-and-entry-plan-2026-11-02.md), [상품](../items-and-monetization.md), [가방](../equipment-bag-and-storage.md)과 연결한다.

## 1. 플레이어 경험과 등급

추천 순서는 **일반 → 고급 → 레어 → 에픽 → 레전드 → 유니크**다. 게임에는 아래 영어를 쓴다. Unique는 이름·고유 효과가 고정된 최상위 수집 등급으로 제안한다. 모든 상황에서 다른 장비를 압도하는 장비로 만들지 않는다.

| 등급 / 저장 키·en-US | 표시색 후보 | 역할 | 획득 방향 |
| --- | --- | --- | --- |
| 일반 / `Common` | 회색 | 시작·기본 장비 | 시작 지급·기본 상점 |
| 고급 / `Uncommon` | 녹색 | 첫 교체·강화 체험 | 퀘스트·Gold 상점·선택 상자 |
| 레어 / `Rare` | 파랑 | 본편 진행의 주력 | Gold 상점·선택 상자·지역 보상 |
| 에픽 / `Epic` | 보라 | 반복 모험의 첫 수집 목표 | 지역 수집 진도·후속 보스 보상 |
| 레전드 / `Legendary` | 주황 | 높은 기본 능력치의 장기 목표 | 더 많은 지역 수집 진도 |
| 유니크 / `Unique` | 금색 | 보스/영웅의 이야기를 담은 이름·고유 효과 | 해당 에픽 완료 후 개인 수집 진도 |

색은 TD 원본 프레임을 보존한 테두리/배지에 적용하고 텍스트·서로 다른 문양을 함께 표시한다. 레전드/유니크도 색만으로 구별하지 않는다. 물약·재료의 기존 희귀도는 표시 분류로 유지하며, 높은 희귀도라고 회복량·재료 효과가 자동 증가하지 않는다. 새 성장 체계는 우선 **장비8슬롯**에 적용한다.

## 2. 등급·요구 레벨·강화의 관계

세 축을 분리한다. `Lv10 / Rare / +3`은 요구 레벨10, 레어 등급, 강화3단계다. 요구 레벨은 기본 장비 세대, 등급은 같은 세대 안의 품질/특성, 강화는 획득한 개별 장비에 들인 투자다. 등급 때문에 요구 레벨이나 강화 상한이 자동 상승하지 않는다. 시작부터 모든 등급을 Lv1 장비에 채워 넣지 않는다.

현재 [ItemCatalog](../../src/shared/ItemCatalog.luau)는 Common/Uncommon/Rare와 Lv1/5/10 장비를 갖고 있다. Rare Lv10 Dawnforge 무기의 `power=24` 등은 이미 정의된 기본치다. 새 등급 배율을 기존 수치에 일괄 곱하거나 기존 안정ID를 다른 등급으로 바꾸지 않는다. `uniqueGroup`은 장신구 중복 장착 제한이며 Unique 등급과 별개다.

같은 레벨·부위·능력치 프로필의 **신규 정의를 제작할 때** 다음 예산 비율을 비교 출발점으로 제안한다. power/armor/health의 양수 값에만 사용하며 STR/DEX/INT/VIT·MP회복·공속·쿨다운·군중제어 시간은 추가하지 않는다. 동일 부위라도 공격형/생존형의 각 능력치를 무조건 같게 만들지는 않는다.

| 등급 | 동일 세대 기본 예산 후보 | 예: Common power20에 대응 |
| --- | --- | --- |
| Common | 1.00 | 20 |
| Uncommon | 1.08 | 21.6 |
| Rare | 1.18 | 23.6 |
| Epic | 1.28 | 25.6 |
| Legendary | 1.40 | 28 |
| Unique | 1.40 이하 + 고유 효과1개 | 28 이하, 효과 예산에 따라 조정 |

표의20은 산술용 가상 프로필이며 기존 아이템 값이 아니다. 제작자가 등급을 반영해 고정한 `stats`가 런타임 기본치가 된다. 런타임은 **기본치 × (1 + 0.03 × enhancementLevel)**만 한 번 적용한다. 예시 Legendary power28의 +5는32.2다. 1.40을 다시 곱하지 않는다. 고유 효과의 수치·발동률·범위는 강화로 증가하지 않는다.

기존 요구 레벨별 강화 상한(+3/+5/+7/+9/+10), 성공100% 시험 규칙과 실제 투입 재료80% 회수 원장을 유지한다. 상위 등급 추가 요금·실패·파괴·등급 승급 합성·랜덤 옵션/재추첨은 첫 범위에 넣지 않는다. 재료 회수는 강화만0으로 돌리며 등급·고유 효과를 제거하지 않는다.

본편은 무료 Rare 중심 장비와 필요한 교체로 완결하도록 검증한다. Epic 이상·특정 Unique 효과를 본편/전직/난이도의 필수 자격으로 삼지 않는다. 다음 세대 Rare가 이전 세대 Legendary+상한보다 언제 유리해지는지는 Lv1/5/10/20/40/60/80 곡선에서 별도로 검증한다. 무조건 상위 등급이라는 이유로 장착을 권하지 않고 실제 능력치·요구 레벨·고유 효과를 비교한다.

## 3. 획득과 반복 모험

첫 구현은 **확정 선택과 수집 진도**를 추천한다. 기존 초회XP/Gold·트로피·상자 진도와 상자 내용은 보존한다. 기존 `equipment_cache_1/5/10`의 Rare 표시는 상자 자체의 희귀도이며 선택 결과를 Rare로 바꾸는 권리가 아니다.

| 획득 경로 | 첫 버전 제안 |
| --- | --- |
| 시작/본편 | 기존 지급 보존. 무료 Rare 경로의 부족 구간을 먼저 확인 |
| 기존 장비 선택 상자 | 현행 진도4당1개·선택 대상 유지. 새 등급 상자로 자동 전환하지 않음 |
| 신규 지역 수집 진도 | 전투 임무 전체 완료마다 Easy/Hard/Insane/Hell에1/2/3/4점 추가 |
| Epic 선택 | 수집 진도12점 소비, 해당 지역/장비 세대의 호환 장비1개 선택 |
| Legendary 선택 | 수집 진도36점 소비, 동일 범위 장비1개 선택 |
| Unique 선택 | 수집 진도72점 소비 + 해당 에픽 개인 완료, 해당 지역의 고정 Unique1개 선택 |

모든 진도·문턱은 **시험값**이다. 수집 진도는 기존 상자 진도와 별도이며 계정의 `regionId + equipmentTier + rulesVersion`별로 관리한다. 선택한 임무의 서버 고정 보상표가 지역·세대를 결정하고 영웅 현재 레벨만으로 상향하지 않는다. Deepwood 저레벨 Easy 반복으로 Lv80 장비를 얻을 수 없다. 상위 난이도에서 다른 세대를 제공하려면 그 무료 장비군/적 곡선을 먼저 제작하고 보상표에 명시한다.

Easy에서도 같은 지역/세대의 모든 등급을 얻을 수 있고 상위 모드는 수집 속도를 높인다. 에픽 완료가 요구하는 기본 이야기 자격 외에 Hell·레이드·유료 구매·특정 AI동료 조건은 추가하지 않는다. Hell은 횟수 제한 없이 새 원정 완주마다 진도를 지급한다. 같은 runId의 재접속/중복 요청은 추가 지급하지 않는다. 개인 유효 참여자에게 전액 지급하고 파티 인원으로 나누지 않는다. 지원·목표 기여도 인정한다.

이 안은 세 등급이 같은 진도를 소비하므로 Epic을 받으면 Legendary/Unique까지 남은 횟수가 늘어난다. UI에 소비 후 잔여와 목표까지 남은 점수를 표시한다. 임무1회5~8분이라는 **미측정 가정**이면 다음과 같다.

| 목표1개 | Easy 횟수 | Hard | Insane | Hell | Easy 가정 시간 / Hell 가정 시간 |
| --- | --- | --- | --- | --- | --- |
| Epic | 12 | 6 | 4 | 3 | 60~96분 / 15~24분 |
| Legendary | 36 | 18 | 12 | 9 | 180~288분 / 45~72분 |
| Unique | 72 | 36 | 24 | 18 | 360~576분 / 90~144분 |

표는 다른 선택에 점수를 쓰지 않을 때의 산술이며 실제 모드별 시간은 다를 수 있다. Unique의 Easy6~9.6시간은 장기 목표 가설이고 대상층에게 과한지는 관측 후 조정한다. 8슬롯 전부 Legendary는 Easy288회, 전부 Unique는576회이므로 전 슬롯 최상급 완성을 본편 목표로 두지 않는다. 첫 Epic의 실제 시간·중간 포기율을 보고 공통 진도 대신 등급별 진도로 나누는 대안도 비교한다. 첫 버전은 확률 드롭을 추가하지 않아 표의 확정 소요가 흐려지지 않게 한다. 후속 확률 드롭은 무료 보너스·확률 공개·중복 보호·기존 진도 보존을 별도 설계한다.

## 4. 유니크의 개성·제작량

Unique는 특정한 고유명/고정 능력치/효과1개를 갖는다. 첫 Unique군은 Deepwood의 **4클래스 무기4종**으로 제한해 같은 수집 비용과 동등한 효과 예산을 비교한다. 아래는 영어 가칭과 효과 방향이며 수치/효과 발동을 확정한 것이 아니다.

| 클래스 | 영어 이름 후보 | 고유 효과 방향 |
| --- | --- | --- |
| Knight | Rootwarden's Oath | Shield Bash 적중 후 짧은 자기 보호막 |
| Elf Archer | Thornsong | 조준 계열 공격 적중 후 다음 공격의 단일 대상 피해 보너스 |
| Dwarf Axe Thrower | Stonebreaker's Resolve | Ground Slam 적중 후 짧은 자기 피해 감소 |
| Mage | Groveheart Staff | Wind Lance 적중 후 제한된 MP 일부 회복 |

R2에서 클래스 기본 기술/계열 호환을 실제ID와 대조하고 효과마다 발동 조건·수치·지속/내부 재발동 간격·최대 중첩·보스/아군/사망/원정 경계·영어 설명을 고정한다. 엘프 조준 기술이 모든 계열에 유지되는지도 확인한다. 이 정의가 없으면 이름만 붙여 완성 장비로 출시하지 않는다. 새 기본 공격/회피 쿨다운이나 Stamina를 만들지 않는다. 기사의 기존 스턴 시간·마법사의 MP 비용/쿨다운을 덮어쓰지 않는다.

복수 Unique 장착은 허용하되 동일 `effectId`는 중첩하지 않는 안이다. 두 장신구의 `uniqueGroup` 제한도 별도로 유지한다. 재장착/리스폰/영웅 변경으로 보호막·회복을 즉시 반복 생성하지 못하도록 서버 발동 원장과 재발동 시간을 보존한다. 추가 피해는 자기 재발동을 일으키지 않고 소환체·복제 투사체·무한 연쇄는 첫 범위에서 제외한다.

Unique의 효과 포함 실전 기여는 같은 세대 Legendary 대비 평균10% 이내를 원형 가설로 둔다. 피해/생존/MP회복은 같은 수치로 단순 합산하지 않고 동일 전투의 완주 시간·피격/사망·물약·MP 고갈을 각각 비교한다. 효과가 기본치에 더해 과하면 Unique의 기본 예산을 낮춘다. 측정 전에는 표의1.40과 최대 효과를 동시에 보장하지 않는다.

첫 콘텐츠 묶음은 현재 Lv10 세대의 무기4클래스 × Epic/Legendary/Unique = **신규 정의12종**이다. 기존 Rare12종과 기존ID를 보존한다. 방어구/장신구·다음 지역/세대 확장은 원형 수용 후다. 효과 전용 새 무기 종류를 추가하지 않으며 TD 레지스트리의 검·활·도끼·지팡이를 감사 후 파생하고 신규 파일/권한/해시를 기록한다. 실루엣·소켓·클래스 동작을 유지하며 과한 상시 오라를 피한다. 이번 계획에는 새 이미지/3D 미리보기를 만들지 않는다.

## 5. 상점·가방·저장 계약

성능 장비와 리셋권 판매 방향을 유지한다. 첫 등급 확장은 무료 획득 경로부터 만들고 기존 Gold/Diamonds 상품의 가격·등급·권리를 변경하지 않는다. 후속 유료 Epic/Legendary/Unique를 검토한다면 같은 레벨/등급/효과의 무료 대응품과 동일 성능·동일 강화 상한의 **내용 고정 확정 상품**으로 설계한다. 최고 등급 판매 배제나 유료 전용 상위 성능을 이번 계획으로 확정하지 않는다. 새 ProductId·유료 확률 상자·등급 승급권은 만들지 않는다. TD 재화/권리는 공유하지 않는다.

가방·창고·대장간·상점·보상 카드·미수령에 같은 등급 텍스트/배지와 필터를 적용한다. 비교 창에는 요구Lv/클래스/등급/+단계, 실제 현재/교체 후 능력치, 고유 효과, 획득처, 귀속/잠금을 표시한다. 선택 상자에는 결과 등급·선택 내용·소비 진도를 먼저 보여 준다. Epic 이상 신규 획득은 기본 판매 잠금, 일괄 판매 기본 제외를 추천한다. 사용자가 명시적으로 잠금을 해제하고 개별 판매할 수 있고 기존 보유품의 잠금을 이관 중 몰래 변경하지 않는다. 승인 TD 프레임/아이콘·기본 메뉴 배치를 지키고 PC/모바일 가로/패드에서 상세 화면을 검증한다.

| 제안 문자열 키 | en-US |
| --- | --- |
| rarity.common / uncommon / rare | Common / Uncommon / Rare (각 키 분리) |
| rarity.epic / legendary / unique | Epic / Legendary / Unique (각 키 분리) |
| item.collectionProgress | Collection Progress: {current}/{required} |
| item.chooseReward | Choose {rarity} Equipment |
| item.epicRequired | Complete {epic} to unlock this item. |
| item.uniqueEffect | Unique Effect: {effect} |
| item.effectNoStack | Identical unique effects do not stack. |
| item.progressRequired | Earn {amount} more Collection Points by completing missions in {region}. |
| item.rewardChanged | This reward changed. Review your selection and try again. |
| item.claimPending | Your reward is being saved. Reconnect to check its status. |

`rarity`는 서버 카탈로그의 허용 enum이며 인스턴스는 `definitionId/instanceId/definitionVersion/enhancementLevel`로 참조한다. 고정 `effectId`는 정의에서 조회하고 클라이언트가 배율/희귀도/효과/결과 장비를 주장해 확정하지 않는다. 기존 인스턴스는 안정ID·능력치·강화 원장·잠금·귀속을 유지하며 알려지지 않은 정의/등급은 임의 Common/신규 아이템으로 바꾸지 않고 복구 대상으로 격리한다.

서버는 선택 요청의 계정/영웅 소유·개인 이야기 자격·지역/세대·현재 카탈로그 버전·진도·요구 클래스·가방 공간을 검사한다. 미래 장비의 요구 레벨 미달은 획득과 장착을 구분하며 UI에 명시한다. 서버 보상 결과·진도 차감·단일 인스턴스/미수령 권리·요청 결과를 하나의 복구 가능한 계정 거래로 확정한다. 공간 부족은 기존 미수령으로 보내고 진도 차감 후 유실되지 않게 한다. 여러 키면 단일 UpdateAsync를 원자 거래로 오해하지 않고 저널/복구 계약을 먼저 만든다.

같은 requestId+동일 내용은 같은 결과, 다른 내용 재사용은 거부한다. 보상 선택·판매·강화·회수·창고 이동이 겹치면 소유/버전/계정 직렬화로 통제한다. 저장 불명 응답에서는 새 아이템/효과/진도 차감을 다시 만들지 않고 원래 요청을 조회한다. 로드 실패의0잔액/신규 프로필 덮어쓰기를 금지한다. 반복 원정 완료 영수증에 새 진도도 연결하고 규칙 버전을 고정한다.
