## 수치와 실패 계약

+0은 미강화이며 +1~+9가9단계다. 각 목표 단계의 성공/실패 확률과 1회 보석/마석 비용은 JSON/설명 원고의 동일 표를 따른다. 실패 확률은 순서대로0/10/20/30/40/50/60/70/80%다. 단계당 기본 장비 power/armor/health 양수 값3%, +9 최대27% 가산이다. 기존 등급 예산은 카탈로그 기본치에 포함되므로 등급 배율을 다시 곱하지 않는다. 고유 효과·MP회복·공속·스턴은 강화 대상이 아니다.

실패하면 아이템과 단계는 유지하고 시도 재료를 소모한다. 실패/성공 모두 완료된 시도로 기록한다. 재료 부족·취소·검증 거부·저장 오류를 확률 실패로 처리하지 않는다. 첫 안에는 천장·실패 누적 보정·자동 연속 강화·확률 상품이 없다. 무료/유료와 모든 등급에 같은 확률을 적용한다. 보석은 Diamonds와 별도다. +9 장비와 기본 강화 스탯0 장비의 요청은 무소모 거부다.

회수80% 제안은 **성공한 강화에 실제 투입한 재료만** 대상으로 한다. 실패 소비를 회수 원장에 합산하지 않는다. 단계0 재료 재회수·원장 없는 선강화품·규칙 버전 변경으로 새 재료를 생성하지 않는다. 장비 회수 시 실패 이력/시도 영수증은 삭제하지 않고 기존 결과 재조회에 사용한다.

최소 보석90/마석21, 기대 비용은 보석244.373015…/마석67.428571…이며 기대 시도19.289682…다. 단계별 독립 성공 확률 p에 대한 기대 시도1/p를 사용하고 단계별 비용/p를 더했다. 확정 성공 횟수나 비용 상한이 아니다. +8→+9에서10연속 실패 확률은0.8^10≈10.73741824%다.

이전 성공100% 경제의 강화1~2임무 체험/+5 재료4~8회는 이번 실패 체계의 수용 증거가 아니다. 보석6/8/10/12·마석0/1/2/3, Easy 교환5보석+50Gold는 초기 비교값으로만 남긴다. 실패 부담·교체 시점·교환Gold·물약 소비를 함께 시뮬레이션하고 실제 무료 플레이 시간을 관측해 조정한다. Gold0은 강화 시도에 대한 안이며 교환료와 구분한다. 본편/전직/난이도 입장에 특정 강화 단계는 요구하지 않는다.

기존 광석/코어 아이템ID·수량·성공 강화 원장·과거 요청 결과를 보존한다. 보석/마석 신규 정의·버전별 원장·보상/교환 경로를 함께 이관한다. 이미 +10 또는 알려지지 않은 단계가 저장된 사례가 있으면 자동 +9 하향/삭제하지 않고 구버전 정의로 권리를 보존해 별도 이관 정책을 적용한다. 이번 계획으로 실제 프로필을 변경하지 않는다.

## 서버 판정과 복구

클라이언트는 requestId·heroId·instanceId·expectedItemVersion·예상 현재 단계·rulesVersion과 행동만 전송한다. 서버가 소유/세션·대장간/거점·대상·동시 판매/이동/회수·현재 단계·재료·정의/규칙 버전을 검사한다. 확률/비용/피해·결과는 클라이언트가 확정하지 않는다.

1. 같은 requestId의 기존 확정/대기 기록부터 조회한다. 동일 fingerprint는 기존 결과, 내용이 다르면 거부한다.
2. 유효 시도만 서버에서1회 표본을 만들고 동일 요청의 판정 후보로 고정한다. 정수0~9999 표본에 `roll < successPercent × 100`이면 성공이다. 100%는 항상 성공, 20%는0~1999만 성공이다.
3. 재료 차감·시도번호/규칙/고정 결과·성공 시 단계/버전·성공 투입 원장을 하나의 복구 가능한 거래로 저장한다. 실패도 장비 버전을 올려 동일 버전 경쟁 요청을 차단한다. 소비와 결과가 확정되기 전 성공/실패 효과를 보여 주지 않는다.
4. UpdateAsync 콜백 재실행/경합 재시도에서 재추첨하지 않는다. 프로세스 중단 후 이미 저장된 거래는 원래 결과로 복원하고, 확정 기록이 없으면 소비/단계 변화도 없어야 한다. 다중 키라면 단일 UpdateAsync로 원자성을 주장하지 않고 내구성 저널·적용/복구 상태를 설계한다.
5. 재접속/낡은 서버/타임아웃에는 원래 요청을 조회한다. 영수증 보관/만료 후에도 오래된 요청이 새 시도로 실행되지 않도록 단조 시도번호/프로필 버전과 연동한다. 로드 실패에 신규 프로필/0재료 덮어쓰기를 금지한다.
