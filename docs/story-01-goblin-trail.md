# 에픽1 Deepwood · 스토리1 고블린 숲길

문서 묶음 v0.24 · 2026-10-27, America/Toronto · 상태: 사용자 승인 시나리오 기준, 구현 전

상위 기준은 [Deepwood 지역](deepwood-region-design.md), [전체 줄거리](../the-last-throne-rpg-proposal.md), [동료·협동](companions-and-support.md)이다. 2026-10-27 사용자가 상세 시나리오를 기록해 이후 제작의 기준으로 사용하도록 요청했다. 이야기·동선·목표·협동 방향을 제작 기준으로 보존하며, 아래 몬스터 레벨·배치 수·시간·보상 수치는 테스트용 초안이다.

## 1. 이야기와 역할

Dawnspire로 들어오던 숲의 보급대가 연락을 끊는다. 플레이어는 원정 포탈로 Deepwood 입구에 도착해 끊어진 보급로를 조사한다. 처음에는 고블린의 약탈처럼 보이지만 식량과 약초가 일부 남아 있고, 수레바퀴 흔적이 숲 안쪽으로 이어지며, 고블린보다 큰 발자국이 발견된다. 첫 스토리는 원인을 다 밝히지 않고 “단순한 약탈이 아닌 것 같다”는 의문을 남긴다.

목표는 이동·공격·회피·여러 적 대응과 작은 선택 탐험을 배우고 다음 구역 DW-02 무너진 수레 공터로 이어지는 것이다. 고블린 전체를 절대적인 적으로 규정하지 않으며, 이후 주술사 세력과 난민을 구별하는 Deepwood 이야기로 연결한다.


선택 습지의 보급 상자를 조사하면 [선택 퀘스트 DW-Q1](deepwood-hidden-quests.md)을 발견할 수 있다. 슬라임 교전은 필수가 아니다.

## 2. 동선과 공간

```text
A 도착 포탈·안전 지점
        │
B 숲길 입구·첫 고블린 교전
        │
C 부서진 이정표·갈림길
   ┌────┴──────────┐
   │               │
D 보급품 공터 ← S 얕은 습지·선택 탐험
   │
E 끊어진 바퀴 자국·마지막 조사
   │
F 공터 앞 안전 체크포인트
   │
다음 구역: DW-02 무너진 수레 공터
```

위 그림은 구역 연결도이며 축척 지도나 최종 지형 배치가 아니다. 한 연결된 숲길에 주동선과 선택 탐험로를 두고 선택 경로도 앞으로 합류시킨다. 거목·감시탑이 원경에서 방향을 알려 준다. 도착/귀환에는 포탈을 활용하고 B~F는 직접 이동하는 현재 구성안이다. 에픽/스토리별 Place·빠른 이동 계약을 이 문서만으로 확정하지 않는다.

TD의 돌길·초지·이끼 바위·거목·폭포·보라 포탈을 공유한다. 승인된 영웅 외형, 현행 Goblin/Cave Slime 모델과 [공통 UI](shared-ui-and-look-and-feel.md)를 사용하며 새 몬스터 원형을 추가하지 않는다.

## 3. 몬스터·레벨·배치 초안

Deepwood 전체는 권장Lv5~12 기준안이며 이 첫 스토리는Lv5~6 입문 구간을 제안한다. 완료 시간은 동선/전투를 구현한 뒤 측정하며 고정 플레이 시간을 약속하지 않는다.

| 위치 | 몬스터 | 레벨 초안 | 솔로 배치 초안 | 학습 |
| --- | --- | --- | --- | --- |
| B와 주동선 | Goblin | 5 | 2마리씩 두 무리 | 방향·거리·공격·회피 |
| D 보급품 공터 | Goblin | 6 | 3마리 한 무리 | 여러 적 대응·위험 표적 판단 |
| S 선택 습지 | Cave Slime | 5 | 부모1마리 | 서식지 탐험·분열 뒤 표적 전환. 전투는 선택이며 이후 DW-S2에서도 만날 수 있음 |

주동선 고블린은 솔로 기준 총7마리다. Lv6 고블린도 기존 동일 종이며 신규 종족/모델이 아니다. 슬라임은 자식2기·자식 재분열 없음의 TD 원형을 참고하며 자식 수치·활성 상한·보상은 후속 조정한다. 이 스토리에는 보스를 넣지 않는다. 일반Ogre와의 첫 필수 교전은 스토리5 오크 점령지, Goblin King·Orc Warlord·King Shaman은 이후 구역에서 소개한다.

## 4. 플레이 순서와 성공 조건

| 단계 | 행동 | 진행 결과 |
| --- | --- | --- |
| 도착 | A에서 목표 확인 | 끊어진 보급로 조사 시작 |
| 첫 교전 | B의 길에서 고블린 상대 | 흩어진 보급품 흔적 발견 |
| 갈림길 | C에서 주동선 또는 습지 선택 | 탐험/슬라임 전투는 선택 |
| 공터 조사 | D의 보급상자 주변 위협을 해결하고 조사 | 약탈만으로 설명되지 않는 현장 확인 |
| 흔적 추적 | E의 정찰 기록·큰 발자국 확인 | 보급대가 안쪽으로 끌려갔다고 추정 |
| 마무리 | F의 안전 체크포인트 도착 | 스토리1 완료·다음 목표 개방 |

필수 조사와 보급품 공터의 위협을 해결하고 F에 도착하면 성공한다. 모든 고블린 처치·선택 습지·숨은 물자는 성공 필수 조건으로 삼지 않는다. 첫 스토리에 시간 제한이나 보급품 내구도 실패를 넣지 않는 방향이다.

마지막에는 멀리서 나무가 부러지는 소리와 무너진 수레를 보여 주고 “생존자를 찾아라”로 이어지는 장면을 제안한다. 다음 수레 공터에서는 흔적과 먼 실루엣만 보여 주고 실제 교전은 스토리5로 미룬다. 이후 제작에서는 조사·공터 위협 해제·완료·보상 상태를 구분하고 재접속/재처리 때 이미 완료한 보상을 중복 지급하지 않는다.

## 5. 보상 초안

| 구분 | 제안 |
| --- | --- |
| 첫 완료 | Coins150·현재 클래스에서 사용 가능한 입문 장비1개 |
| 퀘스트 경험치 | 초회 퀘스트XP140 · 반영된 성장 예산 기준 |
| 일반 전투 | 별도 처치XP·소량Coins·재료 |
| 선택 습지 | 약초·제작 재료·발견 기록 |
| 진행 | 다음 구역과 체크포인트 개방 |
| 재플레이 | 축소된XP/Coins·일반 전리품, 초회 장비 중복 지급 없음 |

경험치 곡선·고정 퀘스트XP·반복 보상량은 v0.21 공통 예산에 반영했고 장비 등급/옵션과 실제 플레이 수용은 미검증이다. 전투/탐험과 합쳐 다음 구간에서 자연스럽게 성장하도록 검증하고 첫 임무만으로 반드시 레벨업을 보장하지 않는다. 실제 레벨업에는 확정한 스탯4포인트와 별도 스킬1포인트를 지급한다. 보상은 개인 지급이며 선행·초회 수령 자격을 확인한다.

## 6. 실패·재도전·협동

전멸하면 가까운 체크포인트에서 무료 재도전한다. 파티에는 쓰러진 동료를 구할 기회를 제공하는 초안이며, 구체 부활 시간과 적/조사 상태의 복구 경계는 후속 전투 명세에서 정한다. 특정 지원NPC나 유료 재도전을 필수로 요구하지 않는다.

일반 모험1~4인과 솔로 완주를 지원한다. 한 명의 조사는 함께 참여 중인 파티에 진행을 공유하되 각자의 선행 자격·완료·보상은 개인 기록으로 관리한다. 개인 전리품을 다른 플레이어가 먼저 주워 독점하지 않게 한다. 힐러/탱커 필수 편성은 없다.

몬스터 레벨은 유지하고 무리 구성·수·체력·처리 시간을 조절한다. 솔로의2/2/3마리 배치를4인에서3/3/4로 시험할 수 있으나 체력만 인원수대로 곱하지 않는다. 고레벨 친구 지원에는 지역 보정과 초회 보상 중복 제한을 적용하고, 연결 끊김에는 복귀 유예/체크포인트 복구를 설계한다.

일반 전투AI동료는 솔로 최대2명·2인 파티 최대2명·3인 최대1명·4인0명이라는 현재 상한을 따른다. 이 첫 스토리는 동료 없이도 완료할 수 있어야 하며 에린·셀레네의 정식 동행을 필수로 두지 않는다. 동료 영입 방식/시점은 별도 설계 항목이다.

## 7. 후속 제작 산출물

축척/전투 여유가 있는 블록아웃, 조사 대상·상호작용·퀘스트 상태표, 적 스폰/활성/복구 규칙, 체크포인트/개인 진행·보상 계약, 짧은 대사/음향/카메라, 솔로/협동 테스트 기록을 작성한다. 먼저 [기사 K0](knight-combat-spec.md)의 검·방패 기본기를 확인하고 DW-01~02에 적용한다. 현재 완료는 시나리오 기록이며 실제 맵·전투·보상 구현이 아니다.
