- 승인된 TD 영웅 초상을 참조한 플레이어4종 전신, 성녀 지원NPC, 에픽1 Deepwood/스토리1 고블린 숲길, 스탯/스킬/전투HUD/영웅 선택의 신규 최종안11장 제작.
- Deepwood 현행 몬스터10종 개별PNG를 변경 없이 재사용하고 좀비가 남은 구 미리보기는 제외. 참고 이미지8개와 함께 원본 출처·SHA256 기록.
- 스킬 노드명/포인트 합계와 HUD 고블린의 추가 무기를 수정. 프롬프트·수정 이력·최종21개 목록·확대 가능한 로컬 갤러리 저장. UI 수치·전신 확장·지도 배치는 컨셉 초안으로 구분하고 실제 Studio 구현/업로드는 수행하지 않음.

### 스탯 포인트 결정

- 사용자 결정으로 Lv1은 기본 능력치로 시작하고 Lv2~80에 레벨업마다4포인트, 총316포인트를 지급하도록 확정.
- 힘·민첩·지력·체력에 자유 배분하며 한 번 받은4포인트를 한 스탯에 집중 가능. 기존 스킬트리79P와 별도 예산으로 관리.
- 스탯 총량을 미정에서 확정으로 전환하고 결정표·상세 스탯·GDD·통합 제안서·전직/스킬트리·README·로드맵을 동기화. 초기값·효과 계수·스탯별 상한·추천/재분배 상세는 검증할 설계 항목으로 유지.
- 누적 예산과 다중 레벨 상승·미배분 잔량·재접속/재처리 중복 지급 방지 검증 기준 추가. 문서 설계 반영이며 실제 코드 구현/플레이 검증은 수행하지 않음.
