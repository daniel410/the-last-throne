# 아이템 강화 UI 룩앤필 검토

2026-11-03 · TLT-028/029/052/084 · 디자인/QA · 정적 검토 완료, 시각 수용 보류

검토 소스: `070ba8cc1b9fcc23d48331a90f159d8f1ec355bd`, VERSION `0.63.1`.
범위는 강화 상세 화면의 승인 TD 공통 외형·정보 위계·반응형 배치다. 구현은 변경하지 않았다. 기존 미커밋 작업을 보존했다.

## 판정과 근거

TD 공통 외형을 일부 재사용하지만, 강화 화면의 최종 룩앤필 수용은 보류한다. 승인 보드의 남색 패널·은색 테두리·금색 장식·파란 보조 버튼 방향은 연결돼 있다. 다만 외곽 셸은 코드로 재현한 프레임이고, 주요 행동/선택 상태/모바일 정보 위계는 승인 기준에 미달한다.

직접 열어 본 비교 이미지는 [승인 공통 UI 보드](../../assets/concepts/2026-10-27-shared-ui-v2/ui/00-shared-ui-board.png)다. SHA-256이 approved-baseline.json의 `e2f5c90fefd39ed299b7e1882fb60b55e4fbfef7000613cd834e51374ec30a2a`와 일치했다. 컨셉에 남은 Stamina/슬롯 표기는 최신 제품 계약을 대체하지 않는다.

`src/shared/TDUI/StatusWindowArtAssets.luau`와 현재 TD `../throne-defense/src/Shared/StatusWindowArtAssets.lua`를 바이트 비교해 일치를 확인했다. SHA-256은 `c6927fe3f15902818046f72f9d902e6aacfb38e9c6c5bddce4578dac9238163a`다. UIIconAssets는 현재 TD와 바이트가 다르므로 전체 공통 아이콘 동기화까지 통과했다고 주장하지 않는다. 실제 이미지 접근 권한·로딩은 이번에 검증하지 않았다.

## 최신 강화 설계와의 차이

`AdventureText.luau:23`과 EnhancementView는 현재 `Success Rate: 100%`를 표시한다. 이는 현재 시험 런타임과 맞으며, 최신 +9 확률 강화 설계가 구현됐다는 증거가 아니다. 단계별 확률·실패 시 소모·단계/장비 보존·도움말·결과 표시는 [V2-3](../production/equipment-enhancement-v2-2026-11-03.md)에서 서버 계약과 함께 연결해야 한다. UI 문구만 확률형으로 바꾸지 않는다.

- 신규 기능/구현 변경 없이 기존 승인 기준을 대조한 리뷰다. 신규 외부 사례 조사·빌드·버전 증가·게시·릴리스 태그·상위 티켓 완료 처리는 하지 않았다.
