## 1. 확정 방향과 제안 범위

사용자 요구에 따라 **스탯 리셋/스킬 리셋은 아이템으로 수익화하고 무기·방어구·액세서리도 실제 장비 상품으로 판매**한다. 이전의 거점 무료 스탯/스킬 초기화 초안은 이 방향으로 대체한다. 외형만 파는 계획으로 축소하지 않는다. 포인트 자체·다른 클래스 변경·기본 스토리 진행 자격은 판매하지 않고 레벨업의 스탯4P/스킬1P를 유지한다.

이번 가격/등급/획득 경로/세부 사용 조건은 첫 출시 제안이며 실제 Roblox 상품 생성·ProductId·게시/결제·런타임 지급은 수행하지 않았다. 직접Robux 상품을 첫 출시안으로 사용하고 TD Diamonds/TD Gold/RPG Coins 잔액을 합치거나 임의 환전하지 않는다. 공통 Diamonds 판매상품 확장은 독립 Experience 외부 지갑·권리 조정 계약이 검증된 뒤에만 검토한다.

## 2. 아이템 분류와 장착

| 분류 | 용도 | 획득/판매 방향 |
| --- | --- | --- |
| 무기 | 클래스 기본 공격/전투 스타일 | 퀘스트·드롭·제작·확정 유료 장비 |
| 보조 | 방패/보조도구 등 클래스 호환 | 플레이 획득 먼저,유료 세부품은 후속 |
| 방어구4부위 | 머리·몸통·손·발의 생존/프로필 | 부위별 판매+세트 판매,플레이 획득 병행 |
| 액세서리2슬롯 | 공격/생존·빌드 보조 | 고정 효과 상품,동일 고유그룹 중복 장착 금지 |
| 소모품 | 스탯/스킬 리셋권,추후 회복 등 | 리셋권 유료,회복 상품은 별도 경제 검증 |
| 재료/인장 | 제작/강화 | 필드/보스 획득,현 카탈로그 직접 판매 없음 |
| 외형 | TD/RPG 캐릭터 정체성을 유지한 장식 | 기존 외형 상품 병행,히트박스/예고 불변 |

장비는8슬롯이며 외형 슬롯과 성능을 분리한다. 상점은 현재 클래스 상품을 우선 표시하며 다른 클래스 상품도 구입할 수 있다. 장착 시 서버가 클래스·레벨·슬롯 조건을 확인한다. 지급과 자동 장착은 분리한다. 낮은 레벨에 구매해 보관할 수 있지만 요구 레벨을 무시하지 않는다. 한 캐릭터의 구매가 다른 클래스 전직 권리를 주지 않는다. 공통 원본 모델에 재질/장식 파생을 연결하며 승인 캐릭터 체형을 바꾸지 않는다.

## 3. 리셋권 상품과 소비

| 상품 | 효과 | 기준 가격 제안 |
| --- | --- | --- |
| 스탯 리셋권1개 | 선택 캐릭터의 투자STR/DEX/INT/VIT를 회수해 미배분으로 반환 | 39Robux |
| 스킬 리셋권1개 | 선택 캐릭터의 투자 스킬P를 회수하고 해금/장착 상태 재검증 | 49Robux |
| 성장 재설계 묶음 | 위 두 권을 각1개 지급,자동 사용하지 않음 | 79Robux |

아이템은 계정 보관함에 쌓고 거점에서 사용할 RPG 캐릭터를 선택한다. 사용 미리보기에서 반환P/잔액·해제되는 기술·비활성 슬롯을 보여주고 ‘확인’ 성공 때 해당 권1개를 소모한다. 취소·서버 검증 실패·대상 투자0이면 소모하지 않는다. 포인트/아이템 저장과 결과 적용은 하나의 논리 거래로 처리하며 중복 요청/재접속으로 두 번 소모하거나 추가P를 만들지 않는다.

스탯은 원래 기본/레벨 자동 성장분을 유지하고 투자분만 되돌린다. 스킬은 실제 투자한 예산만 반환하며 미배분P를 중복 합산하지 않는다. 이후 포인트 재배분은 무료다. 매번 +버튼을 누를 때 아이템을 쓰지 않는다. 부분/노드별 유료 초기화는 첫 출시에서 제외하고 전체 초기화로 시작한다. 레벨업 신규P 배분,미리보기/되돌리기/확정 전 취소,스킬바 장착 변경/설명 재열기는 무료다.

전투/원정 중 사용은 막고 안전 거점에서만 처리한다. 초기화를 HP/자원/쿨다운 즉시 회복 수단으로 쓰지 않게 원정 상태와 자원 보존을 검증한다. 저장된 빌드를 불러와 확정 투자 분배를 바꾸는 경우에도 해당 리셋권을 요구하며 단순 장착 프리셋 교체는 무료다. 같은 클래스의 반대 계열 재선택은 기존 검토 항목이며 스킬 리셋권이 미해금 전직을 열거나 다른 클래스로 바꾸지 않는다.

무료권 상시 제공/첫 실수 보정/시즌 보상은 이번에 확정하지 않는다. 사용자 요구는 아이템 수익화이며 의무 무료 초기화를 약속하지 않는다. 초회 튜토리얼에서 확정 초기화는 리셋권 소비임을 먼저 설명하고 포인트 소비 자체를 강제하지 않는다.

## 4. 실제 장비 상품 초안

| 상품군 | 구성/요구 | 가격 제안 |
| --- | --- | --- |
| 기사 서약 수호검 | Lv5·기사 무기1 | 99Robux |
| 엘프 숲길 정찰궁 | Lv5·엘프 궁수 무기1 | 99Robux |
| 드워프 견습 대장장이 도끼 | Lv5·드워프 무기1 | 99Robux |
| 마법사 공명 수습지팡이 | Lv5·마법사 무기1 | 99Robux |
| 왕도 견습 방어구 | Lv5·투구/흉갑/장갑/장화 각1종 | 부위별49Robux |
| 왕도 견습 방어구 세트 | 위4부위 각1개 | 169Robux |
| 결의의 반지 | Lv5·생존/VIT·HP 지향 고정 프로필 | 79Robux |
| 집중의 목걸이 | Lv5·클래스 호환 공격 지향 고정 프로필 | 79Robux |

무기/방어구/장신구는 **성능이 있는 장비**다. 첫 상품은 일반 플레이에서 구할 수 있는 같은Lv5/고급등급 프로필과 동일한 성능을 돈으로 바로 얻는 확정 판매안이다. 희귀도명/ATK·DEF·HP·옵션 계수와 제작 재료/플레이 소요 시간은 장비 밸런스에서 확정한다. 카탈로그의 `power_template`는 대응하는 플레이 획득 장비를 가리키는 제안 키이며 존재하는 런타임 자산ID가 아니다.

구매 직전에는 고정 상품명·클래스·요구Lv·부위·고정 옵션·같은 장비의 플레이 획득 경로·가격을 표시해야 한다. 성능/가격이 미정인 현재 설계 표를 그대로 실제 판매창으로 게시하지 않는다. 상품은 자동으로 플레이어 레벨에 따라 무한 성장하지 않고 무료/유료 동일 강화 규칙을 따른다. 후속 에픽Lv10/20/30/40 상품군은 동일한 분류로 확장할 수 있지만 이번에 완성된SKU로 포함하지 않는다.

유료 상품만으로 최고 전직/스킬P/장비 수준 제한을 우회하지 않는다. 유료 장비를 사지 않아도 기존 퀘스트 기본 장비와 제작/드롭으로 본편을 완주하도록 검증한다. 유료 장비 때문에 필수XP/Coins 예산·기존 퀘스트 장비 보상을 줄이지 않는다. 출시 카탈로그는 내용이 고정된 확정 상품이고 랜덤 유료 상자/옵션 재추첨 상품은 포함하지 않는다. 플레이어 거래는 아직 없고 구매 장비는 계정 귀속 인벤토리에 보관해 호환 캐릭터에 장착하는 제안이다.

## 5. 상점/가방/튜토리얼 연결

Dawnspire/지역 거점 공통 상점에 ‘장비·성장권·외형’ 탭을 둔다. 구매 장비/재료/권은 기존 TD 아이템 카드/툴팁/비교/확인 셸을 공유한다. 스탯/스킬 화면의 초기화 버튼은 보유권/대상/소비 수량을 보여주고 보유권이 없으면 상품 정보를 여는 명시적 버튼을 제공한다. 첫 배분 실수 직후 강제 결제창을 자동으로 띄우지 않는다.

DS-02에서 무상 배분/미리보기와 확정 초기화의 차이를 설명한다. 프롤로그를 완료하는 데 구매/리셋권은 불필요하다. DS-04 후 Lv5 장비 카탈로그를 선택적으로 소개할 수 있으나 구매하지 않아도 Deepwood로 출발한다. 초반 장비/스킬이 과금 없이도 Ogre/숲길에 대응하는지 네 클래스별로 검사한다.

## 6. 결제/복구 설계

Robux 소모성 상품은 Developer Products를 기준으로 설계한다. 반복 구매 지원과 서버 영수증 처리/지급 방식은 [Roblox Developer Products 공식 문서](https://create.roblox.com/docs/production/monetization/developer-products)를 따른다. 실제 상품ID·라이브 가격은 생성 후 연결하고 표시 가격은 판매 시 Roblox 상품 정보와 일치시킨다.

TD와 RPG는 독립 Experience이므로 각 Experience가 자신의 영수증 처리 책임을 가진다. RPG 상품이라는 이유로 TD의 기존 영수증 콜백/상품을 덮어쓰지 않는다. 공통 권리가 필요하면 검증된 외부 권리 장부로 조정한다. 계정ID+구매ID+ProductId+상품 버전·지급 내역을 저장하고 구매 완료 팝업/클라이언트 신호만으로 지급하지 않는다. 영수증 재시도는 같은 아이템을 추가 생성하지 않는다. 상품 지급은 계정 보관함에 확정하므로 구매 당시 캐릭터가 로그아웃/변경됐더라도 잘못된 캐릭터로 자동 장착하지 않는다. 보관함 가득 참은 유료 구매 소실 대신 수령 대기/오버플로로 보존한다.

리셋권을 사는 거래와 사용하는 거래를 분리한다. 구매는 권을 지급하고 사용은 선택 캐릭터의 투자분을 초기화한다. 지급 직후 자동 소모하지 않는다. 실제 ProcessReceipt/저장 코드·운영 환불/중복 지급 감사는 구현 전 검증 항목이다.

## 7. 수익 검증과 출시 순서

첫 검증 상품은 스탯권/스킬권/두 권 묶음,클래스 무기4종,방어구4종/세트,액세서리2종이다. 카탈로그는 개별12종+묶음2종이다. 가격은 모두 제안이고 Roblox 실상품/매출/전환율을 측정한 값이 아니다. 다른 게임의 유사 판매가격을 근거로 확정하지 않았다.

측정은 상품 노출→상세 열기→구매 요청→영수증 지급→실제 장착/리셋 사용과7일 유지/재구매를 연결한다. 장비 구매 여부별 본편 완주/난도와 신규 이용자의 잘못된 배분/이탈을 함께 본다. 목표 전환율/ARPPU/월매출은 실제 데이터 전에는 보장값으로 쓰지 않는다. 먼저 무료 기본 성장과 장비 수용을 확인하고 실제 장비 계수·가격/획득 시간을 확정한 뒤 실상품을 생성한다.

## 장착/보관 상세 연결

[가방/계정 창고 기획](equipment-bag-and-storage.md)에 귀속/장착/보관/수령 대기를 정의했다. 계정 귀속 구매품은 같은 계정의 호환 영웅으로 이동 가능하며 구매 자동 장착은 없다. 공간 부족 시 이 카탈로그의 대기 구매품을 자동 만료하지 않는다. 잠금은 판매 방지이고 보관 이동은 가능하다. 용량 판매/실거래는 이번에 추가하지 않았다.

### 클래스 표시와 결제 복구

상점은 현재 영웅에 맞는 상품을 우선 표시하고, 다른 클래스 장비는 대상 클래스와 현재 영웅의 장착 불가를 구매 전에 영어로 명확하게 표시한다. 다른 클래스 장비 구매와 계정 창고 보관은 허용하며 귀속 규칙은 상품에 표시한다. 결제된 영수증은 재접속이나 영웅 변경으로 거부·소실하지 않고 상품과 지급 상태를 복구해 중복 없이 처리한다. 공용 상품은 클래스 제한이 없다. 실상품 출시 전 영수증·저장·복구 계약을 검증한다.
