# 2. 원천과 현재 준비 수준


기존 내용을 새 문서로 대체하지 않고 **제작 순서·담당·수용 기준**을 연결한다. [결정표](../decisions.md)가 사용자 결정을, 각 분야 상세 문서가 세부 사양을, 이 계획과 백로그가 실행 순서를 관리한다. [원천 검토표](../production/source-audit.md)에 기존 문서와 컨셉 묶음의 연결을 기록한다.

| 구분 | 현재 보유 | 아직 필요한 것 |
| --- | --- | --- |
| 전체 이야기 | [프롤로그·5에픽·귀환 제안서](../../the-last-throne-rpg-proposal.md), 승인된 모험 방향 | 5에픽 상세 시나리오·공간·Lv1~80/보상·영어 대사 |
| 상세 콘텐츠 | Dawnspire4구간 + Deepwood/Frozen Vale/Ember Caldera/Haunted Graveyard 각7스토리 | 32구간의 런타임 퀘스트/전투/저장·실제 플레이 수용 |
| 지도 | 5개 지도 보드·SVG·layout/scenario JSON, 총32개 시작 구간 | Studio 블록아웃·내비게이션·카메라·충돌·스트리밍·기기 측정 |
| 클래스/성장 | 4클래스·8계열·32전직 단계 방향, 스탯·기술·노드 예산 | 계수·자원 정책·전 데이터·리그/모션·전직 시험·유효 빌드 검증 |
| UI/외형 | 공통 UI v2 최종9장 승인, 영웅/환경/적 컨셉, 장비 UX v2 | 실제 공통 컴포넌트·영어 문자열·기기 입력·접근성·사용성 |

컨셉·HTML 동작 보드·정적 계산이 있다는 사실을 게임 기능 완료로 계산하지 않는다. 기존 모델은 메시 재사용 이점이 있지만 근접 액션용 리그·타격·AI까지 대체하지 않는다. 신규 계획 문서의 완성은 G0의 일부 입력이며 게임 게이트 통과가 아니다.

현재 0.22.2의 로비·네 영웅·전투/12개 시험 기술·장비8슬롯·가방/계정 창고와 미수령 원형, 최신 확정 규칙과 미구현 차이는 [현재 개발 상태](../production/current-status.md)를 따른다. Studio는 세션 보관이며 실제 게시 저장/재접속·정식 성장 수용은 별도다. [장비 구현 증거](../evidence/inventory/README.md)와 [영웅별 스킬 성장 설계](../production/hero-skill-progression-design.md)에 다음 검증과 제작 입력을 연결한다.
