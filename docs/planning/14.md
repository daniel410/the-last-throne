# 14. 운영과 변경 관리


빌드는 코드·콘텐츠/영문·자산·공통 UI·저장 스키마·상품 계약 버전을 함께 기록한다. 결제/보상 복구·아이템 조사·플레이 차단·패치/호환·문의 응답을 출시 전 리허설한다. 포탈/상품 기능 차단과 데이터 롤백을 구분하고, 구버전 writer로 최신 잔액을 덮어쓰지 않는다.

초기 관측은 접속→캐릭터→첫 전투→첫 원정→장비→전직→지역 이동→재접속의 흐름과 저장/결제/Teleport 오류다. 이후 균열·레이드·생활의 참여/반복 이유를 본다. 운영 개선은 진행 차단/유실·조작/가독성·계열/경제 불균형·새 콘텐츠 순으로 영향과 증거에 따라 정한다.

새 작업은 기존 TLT-001~024 ID를 보존하고 [backlog.md](../../backlog.md)에 추가한다. 사용자 결정 변경은 [결정표](../decisions.md), 관련 상세 사양, [변경 이력](../CHANGELOG.md)을 함께 갱신한다. 문서 계획의 성공을 게임 출시·결제·실기기 검증의 성공으로 보고하지 않는다.

2026-10-28 사용자 지시에 따라 작업 마감은 [Git·빌드 버전·릴리스·LFS 규칙](../development-workflow.md)을 따른다. 작업 완료마다 커밋/푸시, 빌드마다 세 자리 게임 버전, 실제 릴리스마다 해당 빌드 커밋의 태그/푸시를 기록한다. 이미지/3D/자산 압축본은 LFS로 관리하며 문서 버전과 게임 빌드 버전은 구분한다.

0.20.2: 사용자 요청으로 TD 배틀 프레임·공통 버튼 셸을 HUD에 연결하고 좁은/낮은 화면 재배치를 적용했다. 실제 기기 수용은 후속이며 [증거](../evidence/battle-hud/README.md)를 따른다.

TLT-013/014/015/027/042/052/054~056/058: [초반6스킬·19개 트리](../production/pre20-skill-tree-2026-10-29.md)를 최신 기획으로 적용한다. 네 클래스 각각 기존3개+새 공통3개, 선택 계열12개+Lv80 궁극기1개다. 신규 해금 Lv5/10/15는 제안, 슬롯은 Lv1/5/10에3/4/5칸으로 변경하며79SP는 유지한다. 액티브120·궁극기8 정의가 목표이며 기존16개/108개 문구를 대체한다. 문서 재구성만 완료했고 런타임·노드 이전·플레이 수용은 ENG·DES·ART→QA 후속이며 상위 티켓은 미완료다.
