# 훈련장 전투 조작 튜토리얼

2026-11-26 · TLT-005 / TLT-051 연계 · ENG·DES → QA · 후보 0.116.1

Dawnspire에서 영웅을 선택한 뒤 **Training**으로 들어간다. 안내 카드는 표식 도착, 기본 공격 적중, 영웅 스킬 적중, 회피를 한 단계씩 표시한다. 기본 공격과 스킬 단계에서는 주변 훈련 적에 금색 윤곽을 표시한다. 회피는 서버가 승인한 회피 동작으로 인정한다. 마지막 단계 뒤에는 자유 연습을 계속하거나 지도 메뉴에서 **Return to Hub**를 고를 수 있다. [참고 사례와 적용 범위](../../research/2026-11-26-lot-training.md)

## 검증

- **빌드** — Rojo로 입력 커밋 `61b32b60`을 패키징했다. 변경된 런타임 스크립트 8개를 RBXLX에서 읽고 입력 커밋과 일치함을 확인했다. 단일 Place 패키지의 역할·도착 로딩 검사 336건을 통과했다. [빌드 파일과 SHA-256](build.json)
- **정적 및 로컬 회귀** — 변경된 Luau와 Studio 검사 스크립트 9개를 컴파일했다. 서버 세션 157건, 입력 67건, 스폰 47건, 로비 재진입 33건, 파티 스토리 3,701건을 통과했다. 서버 세션 검사에 본편 행동 분리, 잘못된 높이, 공격 시작과 명중 구분, 먼저 성공한 스킬, 같은 영웅 재입장을 포함했다. `k0-rules.spec.lua`는 기준과 후보 모두 Lua에서 추출한 Luau 복합 대입문을 파싱하는 단계에서 중단됐다.
- **Studio 0.116.1** — 로컬 Studio 세션 프로필에서 엘프를 생성하고 서버의 훈련 입장 요청을 사용했다. 키보드로 표식을 밟고, 공격 버튼과 키 `1`로 Slime을 각각 명중시킨 뒤 `R`로 완료했다. 지도 메뉴의 허브 복귀 버튼으로 나갔고, 같은 엘프 재입장에는 완료 카드가, 새 기사의 첫 입장에는 표식이 표시됐다. 사망 확인 후 이전 단계 복구는 0.116.0 Studio에서 관찰했다.
- **휴대폰 에뮬레이터** — 0.116.1 iPhone 17 Pro 가로 화면의 750×381 뷰포트에서 첫 카드와 표식 배치를 확인했다. Touch 입력 뒤 이동 스틱 안내로 전환됐고 키보드가 다시 활성화되면 WASD 안내가 돌아왔다. [Roblox 입력 모드 API](https://create.roblox.com/docs/reference/engine/classes/UserInputService#PreferredInput)

다음 담당 QA는 모바일·게임패드 실기기에서 처음부터 완주하고, 게시 클라이언트와 여러 플레이어가 같은 훈련장에 있을 때의 가독성을 확인한다. TLT-051의 DS-01~04와 G3 수용은 진행 상태를 유지한다.

## 0.117.0 스킬·무기 강화 확장

TLT-005 / TLT-044 / TLT-051 연계 · ENG·DES → QA. 훈련장에서는 **Combat Basics**와 **Hero Skills**를 각 3단계로 표시한다. 스킬 시전 승인, 피해 적용, 스킬 명중 뒤 기본 공격의 피해 적용을 구별한다. 먼저 성공한 행동은 진행에 반영한다. **Blacksmith → Enhance → Practice +1**은 연습용 검 선택, +0→+1 미리보기, 한 번 확인, 결과 확인의 네 화면으로 진행한다. TLT 강화 규칙에서 읽은 현재 수치로 50 Gold, 2 Gems, 성공률 100%, 예시 공격력 100→103을 표시한다. [고정 빌드 0.117.0](build-0.117.0.json)

- 로컬 서버 세션 검사 160건에서 시전만 한 상태와 명중, 명중 전후 기본 공격을 구분했다. 기존 장비 강화 규칙 검사 8,792건과 확률 검사 2,869건, 패키지의 역할·로딩 검사 336건을 통과했다. 변경된 Luau와 Studio 검사 스크립트 10개가 컴파일됐다.
- Studio 데스크톱에서 엘프로 표식에 도달하고 기본 공격, `R` 회피, `1` 스킬 적중, 기본 공격 후속타를 순서대로 수행해 완료했다. 다른 세션에서는 표식 전에 수행한 공격과 회피가 인정되는 것도 확인했다.
- Studio 데스크톱에서 실제 대장간 메뉴를 열어 네 연습 화면을 버튼으로 진행했다. 시작 전후 서버가 보낸 인벤토리 스냅샷을 대조했다. 리비전, Gold 10000, Diamonds 5000, 아이템 12개의 ID·버전·수량·강화 단계가 일치했다. 결과에서 **Back to Enhance**가 일반 강화 화면을 다시 열었다.
- iPhone 17 Pro 가로 에뮬레이터에서 연습 결과의 스크롤과 버튼이 프레임 안에 들어오는 것을 확인했다. 터치로 전 과정을 완주하는 검증은 남아 있다. 다음 담당 QA는 모바일·패드 실기기와 게시 클라이언트에서 처음부터 완주한다.

## 0.117.5 대장간 연습 바로 이어하기

전투 완료 카드의 **Continue to +1 Practice**는 서버가 허브 복귀 요청을 승인하고 로비 준비 상태를 알린 뒤 대장간 연습의 첫 화면을 연다. 연결 요청 오류나 미응답은 기존 영웅 전환 오류 처리를 따른다. [고정 빌드 0.117.5](build-0.117.5.json)

- Studio 데스크톱에서 엘프로 전투를 완주했다. 첫 목표와 기본 공격 목표에는 이어하기 버튼이 숨겨졌고, 완료 카드에서 버튼을 한 번 누르자 Dawnspire로 돌아가 **Weapon Enhancement Practice 1 / 4**가 열렸다. 일반 **Return to Hub**는 대장간을 열지 않았다. 완료 카드를 다시 사용하면 이전에 2단계에 있던 연습이 1단계부터 열렸고 4단계까지 진행됐다.
- 변경 Luau 5개 컴파일과 영웅 세션 160건, 로비 재진입 33건, 패키지 역할·로딩 336건을 통과했다. 해당 이어하기의 전환 장애 주입, 게시 클라이언트와 모바일·패드 실기기는 후속 QA 범위다.
