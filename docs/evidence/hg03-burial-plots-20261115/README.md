Lumi Secret Passage의 관리 통로 주변 묘역 재구성. G5와 부모 티켓은 미완료다.

| 서사/문제 | 변경 | 보존 |

| 관리 통로 주변 일렬·무작위 무덤 반복 | 기존 grave 키트로 작은 묘역 최대4개/각3무덤, 낮은 석축3개 | 스토리·보상·저장·개방 상태·공유 TD 원본 |

소유 파일은 EpicWorldArt/HauntedBurialPlots, VERSION과 이 증거/리서치뿐이다. 사용자 미커밋 파일은 별도 작업트리로 보존한다. 신규 메시/텍스처/Blender 자산은 없다. EpicArchitecture.grave와 EpicEnvironmentKit.part를 재사용한다. HG03만 기존 흩어진 무덤을 생략하며 원래 RNG 호출 횟수는 유지한다. 새 군집은 원래 안전 예약 반경34, 경계, 군집간80, 바닥5지점 높이차0.65 제한을 통과한 후보에만 배치한다. 낮은 석축은 EpicDetailSolid로 실제 충돌을 유지한다.

[리서치/가설](../../research/2026-11-15-hg03-burial-plots.md). 최초0.110.17/f646f2e2/build.json은2묘역만 생성해 최소3묘역 검사 실패. 안전/접지 기준을 유지하고 후보 탐색 반경을56→140stud로 늘렸다. 0.110.18/e426ae28/build-18.json도2묘역으로 실패했다. 실제 CampaignContent의 투영 구역은 중심(283.15,180,-16309.4)/572×600이므로 최종은 반경280/64방향으로 구역 전체를 탐색한다. 동일 안전/접지/간격 기준을 유지한0.110.19/459bfefd15760fd666e5a62c68bdf66d62763a4d는 build-final.json과 verify.luau로 재현한다. verify.luau는 PlaceId0/플레이어0의 별도 Studio Edit에서만 실행한다.

결과는 results.json 참조. 실제 게시 클라이언트/실기기/다인 성능/스트리밍/사람 미술 수용은 미검증. 다음 QA는 실제 보행·회피·카메라를 확인하고, 환경 아트는 큰 평탄 지형 자체를 추가 검토한다. 소품 군집 변경으로 지형 조형 완료를 선언하지 않는다.
