# 네 영웅 이동 공격의 착지 자세와 잔상

2026-11-23 · TLT-033/057/059 · 기준 0.115.57 · 로컬 후보 0.115.58

| 영웅 | 기술 | 자세와 효과 |
| --- | --- | --- |
| Knight | Valiant Advance | 방패 쪽 팔꿈치를 접어 진입하고 앞무릎으로 타격 하중을 받는다. 발밑의 금빛 두 줄은 디딘 곳 쪽으로 모인다. |
| Dwarf Axe Thrower | Blast Step | 왼손 포격을 앞쪽으로 유지하면서 뒤쪽 다리에 반동을 싣는다. 바닥의 넓게 벌어지는 자국은 포격과 반대 방향으로 이어진다. |
| Elf Archer | Retreating Fire | 활을 겨눈 채 뒷발로 후퇴를 멈추고 시위를 놓은 팔꿈치를 거둔다. 가는 깃 모양 잔상으로 후퇴를 표시한다. |
| Mage | Ember Step | 지팡이를 몸 가까이 두고 빈손으로 뒤를 쓸어낸다. 이동에 따라 짧게 들리는 잔불을 표시하고, 공격 펄스의 화염 띠는 출발점에서 한 겹 솟는다. |

시전 승인 이벤트에 실제 이동 전 위치를 덧붙인다. 시전자가 움직였을 때 클라이언트는 도착 위치까지 0.22초짜리 Beam 두 개를 그린다. 벽 때문에 이동 거리가 줄면 자국도 짧아진다. 네 기술이 동일한 장식 예산을 쓰며 보호막, 명중 판정, 스킬 펄스는 기존 전투 경로를 사용한다. [공식 사례 조사](../../research/2026-11-23-hero-step-wakes.md)

## 검증

- 같은 R15 리그·무기·카메라·조명의 Studio Run 격리 장면에서 시전 시작 145ms 뒤를 비교했다. 후보의 네 잔상이 각각 도착 지점에 붙는 것을 확인했다. [R15 전후 화면](step-wakes-comparison.jpg)
- 고정 소스 `0477af38`에서 공용 로비·배틀 Place를 빌드했다. 빌드 SHA-256과 런타임 모듈 5개를 입력 커밋과 대조했다. [빌드 기록](build.json)
- 고정 후보의 Studio Edit 검사 8묶음 259,523건을 통과했다. 새 검사 335건은 네 기술의 개방 지면·벽에 의한 단축·벽에 의한 정지·낭떠러지, 확정 이동 방향과 두 Beam, 중복 시전 이벤트, 수명, 자세를 확인했다. Studio 회귀는 R6/R15의 128개 스킬, 직전 표식 부여, 아군 효과 예산, 보호와 준비 동작을 포함한다. [Studio 결과](studio-results.json) · [이동 잔상 재현 소스](../../../tests/hero-step-wakes-native.luau)
- Luau 구문 검사 7파일과 기존 CPU 검사 18,590건을 통과했다. 별도 모의 검사에서 기준은 171건 중 40건에서 새 판정 조건을 충족하지 못했고 후보는 1,327건을 통과했다. 후보에서 새 경로가 존재할 때만 곡선 좌표와 수명을 추가로 샘플링했다. 별도 기존 CPU 검사 4개는 양쪽 소스에서 동일한 규칙 버전 기대값, Lua/Luau 문법 또는 준비 스텁 문제로 중단됐다.

## 남은 수용

후보는 미게시 상태다. 전투 QA가 게시 시험의 로비→배틀 이동과 실제 4인 교전에서 적 예고와 이동 잔상을 구별할 수 있는지 확인한다. 저사양 터치 실기기 프레임 시간과 사용자 타격감 수용이 남아 있다.
