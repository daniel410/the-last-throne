# Easy 오크450·오우거600 적용

2026-11-04 · TLT-005/057/061/084 · ENG → QA

사용자 지정값을 앞서 비교한 DW-05 솔로Lv9 기준으로 반영했다. `Difficulty.stats`의 Easy v2 일반 적에만 Lv9 기준 목표HP를 오크450/오우거600으로 지정한다. 계산은 `목표HP × (100 + 실제레벨 ×25) / 325 × 기존파티배율`이며 마지막에 기존 정수 반올림을 수행한다. 따라서 모든 레벨의HP를450/600으로 고정하는 변경이 아니다.

| Lv9 솔로 | Easy 이전 | Easy 변경 | Hard 유지 |
| --- | --- | --- | --- |
| Orc | 358 | 450 | 924 |
| Ogre | 439 | 600 | 1134 |

Hard 이상·훈련장·규칙 없는 기존 스토리 경로·저장된v1 원정·공격력·보상·다른 적/보스는 변경하지 않는다. Easy v2는 서버 생성과 입장 미리보기가 사용하는 기존 공통 경로에 적용한다. 이미 생성된 적은 자동 갱신하지 않는다.

검증:

- `lua tests/difficulty-balance.spec.lua`:2637검사 PASS. 추가8검사는 두 종족의Easy 목표값, Hard 보존,4인HP배율2.5, v1 보존을 확인한다.
- `lua tests/deepwood-encounter-balance.spec.lua`:3111검사 PASS.
- `lua tests/k0-rules.spec.lua`:125검사 PASS.

직전 [원인 분석](orc-ogre-hp-revert-20261104.md)에서 확인한 본편/훈련장 수치 분리를 유지하는 사용자 지정 수치 조정이다. 기존 [파티 스케일 검토](../research/2026-10-31-party-enemy-scaling.md)의 처치시간 측정 항목을 후속QA에 적용한다. 외부 게임 수치를 새 목표값의 근거로 사용하지 않는다.

미검증: Studio 실제 전투·게시 클라이언트·실기기/4인+AI 처치시간·사용자 체감 수용. 빌드·게시·릴리스는 하지 않았고 VERSION0.69.6 유지. 다른 미커밋 변경은 제외하며 부모 티켓 상태는 유지한다. 다음 담당QA는 DW-05 동일 레벨/장비 솔로에서HP450/600과 처치시간을 확인한다.
