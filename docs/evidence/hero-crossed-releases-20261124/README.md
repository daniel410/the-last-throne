서버가 각 타격의 시점, 피해, 방향과 범위를 확정한다. 아군 화면에는 낮은 비용의 주 형상을 유지하고 검격 보조면과 얼음 파편을 줄인다. 효과 슬롯이 가득 차면 공용 범위·투사체 표시 경로를 사용한다. [Diablo IV·World of Warcraft·Lost Ark·Roblox 비교](../../research/2026-11-24-hero-crossed-releases.md)

## 검증

- Rojo 7.7.1로 소스 `02f74cf6`을 고정해 단일 Place를 빌드했다. 0.115.92와 0.115.94의 SHA-256과 각각의 클라이언트 모듈 6개를 원본 커밋과 대조했다. [빌드](build.json) · [패키지 대조](package-check.json)
- 격리 Studio 18묶음에서 253,823개 검사를 통과했다. 네 영웅의 128개 기술을 R6·R15에서 각각 재생했다. 집중 검사 42개는 베기의 높이, 도끼 복제본과 장착 무기의 교대, 두 발의 소켓과 엄폐 끝점, 파편의 이동을 확인했다. 같은 집중 검사에서 기준 후보는 42개 중 20개를 충족하지 않았다. [검사별 결과](studio-results.json) · [재현 스크립트](../../../tests/hero-crossed-releases-native.luau)
- 동일 R15 리그·무기·카메라에서 전후 16장을 비교했다. 첫 후보 0.115.93에서는 도끼가 손에 닿을 때 복제본과 장착 모델이 겹쳤다. 0.115.94는 회수 시 표시를 장착 무기로 넘겼다. 비교 장면의 첫 투척에서는 표적 몸에 도끼가 일부 가려져 발사 방향이 잔상으로 더 잘 읽힌다. [최종 전후 비교](comparison.jpg) · [첫 후보 빌드](build-first.json)
- 전직·스킬 렌더러·스탯 미리보기 CPU 검사 15,375개와 Place 역할·입장 정적 검사 336개를 통과했다. 별도 순수 Lua 자세·입력 취소 검사는 기준과 후보 모두 각각 Luau 문법과 `TargetAssistRules` 스텁 오류로 중단됐다. 자세는 Studio에서 확인했다.
