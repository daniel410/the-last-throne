# 모든 무기·장비 착용 레벨 제한 제거

2026-11-11 · TLT-029/041/043/044/084 · ENG → QA. 상태: 소스 구현/순수 Lua 검증 완료, 엔진/게시/기기 수용 대기. 상위 티켓과 게이트는 완료 처리하지 않는다.

## 변경·근거

사용자 요청 “현재 모든 무기및 장비에도 레벨제한없애줘”를 적용했다. `InventoryRules`의 수동/기본 착용과 저장 데이터 검증에서 레벨 조건을 제거하고, 구장비 이관 때 저레벨 착용품을 가방/미수령으로 내보내던 처리를 삭제했다. 가방의 요구 레벨·레벨로 인한 버튼 비활성/거부 문구, 상점의 Lv 표기·레벨 도달 후 착용 안내, 카탈로그 요구 레벨 설명도 제거했다.

대상은 무기4종·방패·머리·상의/로브·장갑·신발·장신구와 기존 비삭제 퇴역 장비다. 삭제된 아이템을 복원하거나 판매/보상으로 재활성화하지 않는다. 클래스·슬롯·소유/귀속·전투 안전·준비/저장·버전·중복 방지는 유지한다. 능력치·등급·가격·강화/특수효과·보상 상자 선택군·영웅 성장 조건도 유지한다. 내부 `level`은 보상 상자 구분/정렬/과거 강화 데이터 해석용이며 영웅 착용 제한으로 사용하지 않는다. 이미 가방/미수령으로 이동한 장비를 자동 장착하지 않고 직접 선택하도록 한다.

## 미검증·다음 담당

Studio 실제 가방/상점 렌더·더블클릭 조작, 게시 클라이언트·실계정 DataStore·실기기·낮은 레벨의 고성능 장비 전투 밸런스는 미검증이다. 빌드/Roblox 게시/VERSION 변경/릴리스 태그는 수행하지 않았다. QA는 다음 빌드에서 Lv1 영웅의 Veteran/Sentinel 구매→가방/더블클릭 착용→저장/재접속과 PC/터치 표시를 확인한다. 기존 미커밋 자산·전투 효과 작업은 스테이징하지 않는다.
