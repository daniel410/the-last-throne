# 선택 퀘스트를 남긴 다음 에픽 진행·사이드 지도 누락 교정

2026-11-06 · TLT-028/031/050/061~065/084 · ENG → QA · 0.78.10 · 로컬/미게시

사용자는 메인7스토리를 마치면 미완료 사이드 퀘스트를 남겨도 다음 에픽을 진행할 수 있어야 한다고 확인하고, 진행 중인 사이드 지역이 지도에서 검게 보이는 문제를 보고했다. 사이드는 선택이라는 기존 제품 계약에 맞추는 결함 수정이며 별도 게임성 정책/보상·해금 조건을 만들지 않는다. 프로젝트 제작 스킬/엔지니어 지침을 적용했다.

## 확인한 원인과 변경

- **서버의 다음 에픽 권한 자체는 이미 사이드 완료를 요구하지 않았다.** `Difficulty.allowed`는 메인 진행·레벨/난도 자격을 확인한다. 그러나 `AdventureRules.selection`이 마지막에 시작한 미완료 사이드 원정을 계속 로비 기본 선택으로 돌려줘 다음 본편으로 이어가기 어려웠다. 해당 사이드의 에픽이 이미 끝났고 아직 다음 본편이 있다면 영구 진행 기준 다음 메인/Easy를 기본 선택한다. 완료되지 않은 에픽의 사이드 기본 이어하기와5에픽 전체 완료 후 사이드 선택은 유지한다. 명시적인 모험/난도 선택·기존 레벨/난도 자격은 유지한다.
- 사이드 원정에서 퀘스트창 **MAIN STORY**를 누르면 원정 제한 때문에 다음 메인 목표가 유효하지 않아 사이드 목표로 돌아갔다. 이제 `CONTINUE MAIN STORY` 버튼/추적 안내로 로비에서 다음 지역·본편을 선택하도록 설명한다. 접근 불가능한 다음 에픽 목표를 현재 월드의 화살표/웨이포인트로 찍지 않는다. 사이드 자체를 계속 추적하면 기존 목표가 유지된다.
- **상세 지도 `CampaignMapScope.ids`가 에픽의 메인 지역7개만 포함했다.** 늪지/채석장 등 사이드 지역은 배경/이름/길이 만들어지지 않아 빈 검은 공간처럼 보였다. 해당 에픽의 모든 지역을 포함해 Deepwood/설원/화산은 각각10지역(메인7+사이드3), 숲/묘지는 각각7지역으로 그린다. 본편 JOURNEY/스토리 진행 분모는7을 유지한다. 로비 지도는 이미 모든 지역을 포함하므로 그 범위를 바꾸지 않는다.
- 사이드 지역에는 메인 스토리 번호가 없어 기존 상세 지도 배지 계산이 불가능했다. 번호 대신 기존 영어 `SIDE AREA`를 쓰도록 수정했다. TD 프레임/버튼/아이콘·지도 원본 스타일과 탐험 저장·지역 입장 권한은 유지한다. 검은 공간을 없애기 위해 미탐험 칸을 강제로 탐험 완료 처리하거나 잠금 지역을 열지 않는다.
- 첫 미완료 사이드를 중단하고 다음 본편에 입장했다가 다시 돌아와도 수락·완료한 목표가 영구 저널에서 보존된다. 사이드/메인 자동 완료·보상 재지급·잔액 수정은 없다. 원정은 기존처럼 로비에서 선택하며 플레이 중 자동 강제 이동하지 않는다.
