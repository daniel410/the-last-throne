`CampaignStoryText`를 확장/인물 원고 이후의 최종 교정 단계로 적용한다. 원래 저작 파일의 구순서 문구는 이력으로 보존하며 실제 `CampaignContent`와 서버/클라이언트가 보는 최종 원고를 검사했다. 단일 단계 목표는 상위 설명과 실제 대사를 일치시킨다.
