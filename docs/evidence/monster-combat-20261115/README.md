# 몬스터 이동·무기·마법 개선 검증

2026-11-15 · TLT-005/027/033/050/057/061~065/084 · ENG/ART → QA · 로컬 구현·엔진 통과, 미게시·부모 티켓 진행 중

## 변경·근거

사용자 요청과 [Diablo/WoW 공식 조사](../../research/2026-11-15-monster-combat-design.md)를 반영했다. [사양](../../production/monster-combat-design-2026-11-15.md)이 구현 범위와 시험 수치의 정본이다. 50종·146개 기존 공격을 무기·전술·난이도로 분화하고, 안전한 측면/후퇴·거리 유지, 보스 체력 단계, 화염 반복 지점·확대 얼음 고리·원소별 탄환을 연결했다. 기존 리그·스킨·원본 클립을 사용한다.

서버 최종 공격 정의를 경고·무기 접촉·마법 궤적과 공유하며 다단 총피해를 기존 정수 예산으로 제한한다. 원점·조준은 예고 시작에 고정하고 취소·원정 무효화·벽·프레임 지연을 검사한다. 독립 리뷰에서 후퇴 제한, 이동 중간 바닥, 소진된 경로 대기, 돌진 폭/끝점, 측면 지팡이 발사 원점의 경계를 보완했다. 승인된 성장·보상·TD 운영 데이터는 수정하지 않는다.

## 고정 빌드·마감

게임 **0.108.0**, 입력 소스 `8d10333a569fb78bb78b6761af21ca8995a74d70`. `python3 tools/build-game.py --source 8d10333a --record docs/evidence/monster-combat-20261115/build.json` 성공. [빌드 기록](build.json)의 단일 산출물은 `builds/0.108.0/TheLastThrone-0.108.0.rbxlx`(19,586,252 bytes), SHA-256 `9aa019e156a8dc655c3fbd3af97e26edec4f9d386f04854d4950c47fd8d90567`이다.

[고정 원문 대조](fixed-source-equality.json)에서 변경 전투 모듈 12개가 소스 커밋과 완전히 같음을 확인했다. 이 빌드에 같은 통합 probe를 실행해 [고정 빌드 엔진 검사](fixed-native.log) **218,929 + 3,747 + 14,214 + 149 = 237,039 PASS**, 37개 서비스 사례·프로세스 종료0·`ENEMY_COMBAT_ALL_PASS`를 확인했다. 초기 통합의 147검사와 최종 서비스/캐시 보완 뒤 149검사를 구분한다.

소스·검증 기록은 origin/main에 커밋·푸시한다. 동시 정상 푸시로 원격 참조 잠금 충돌이 한 번 발생했으나 원격이 로컬 조상인 것을 확인하고 일반 fast-forward 푸시 재시도로 성공했다. 이력을 재작성하지 않았다. 새 LFS 자산은 없고 기존 사용자 자산/미커밋 변경을 보존했다. Roblox 게시·릴리스 태그는 생성하지 않았다.

## 미검증·다음 담당

격리 모듈/기하·합성 서비스 검사이며 정상 입력의 전투 완주·실제 네트워크/저장/재접속·중도 합류·1~4인+AI·모바일/패드·실기기 성능·사용자 난도/자연스러움 수용은 미검증이다. 새 원본 Blender 애니메이션 50종 제작이나 상태이상 Burn/Poison/Slow 구현을 뜻하지 않는다. QA가 고정 빌드에서 각 지역 대표 일반/보스와 모든 모드를 실제로 관찰하고 결함·기기·성능을 기록한다. 부모 티켓/게이트는 완료 처리하지 않는다.
