# 반격·관통탄·뿌리·연쇄 번개의 방출

2026-11-25 · TLT-033/057/059 · 기준 0.115.114 · 후보 0.115.116

| 영웅 | 기술 | 동작과 효과 |
| --- | --- | --- |
| Knight | Guardian Counter | 방패 뒤에서 무릎을 굽혀 힘을 모은 뒤 앞발에 체중을 싣고 검을 어깨 위로 올린다. 짧은 방패 획에서 상승 검격으로 이어지며 서버가 확정한 파티 보호막은 수혜자에게 표시한다. |
| Dwarf | Piercing Round | 시선을 왼손 포구에 맞추고 뒷발로 한 발의 반동을 받는다. 한 줄이 포구와 서버의 엄폐 끝점을 연결한 뒤 끝점 쪽으로 사라진다. 엄폐가 포구보다 가까우면 시전자 쪽으로 시작점을 당긴다. |
| Elf | Rooting Fan | 시위를 몸쪽으로 당기고 앞발을 딛으며 낮게 회수한다. 시전자 화면에서는 다섯 뿌리, 아군 화면에서는 핵심 세 뿌리가 각 서버 엄폐 끝점 전에 자라고, 일부 끝에서 짧은 가지가 솟는다. |
| Mage | Chain Lightning | 빈손을 지팡이에 모은 뒤 팔꿈치를 펴며 연쇄를 유도한다. 지팡이 끝부터 서버가 확정한 표적 순서대로 연결이 20ms 간격으로 점등된다. 최대 네 연결이며 표적이 없으면 연결이 생기지 않는다. |

반격의 파티 보호막과 피해, 관통탄의 피해, 뿌리의 감속, 연쇄 번개의 피해와 적중 시점은 기존 서버 경로를 사용한다. Rooting Fan이 받는 엄폐 끝점은 시각 경로에 사용한다. [공식 자료 비교](../../research/2026-11-25-hero-guard-chain.md)
