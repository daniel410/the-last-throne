# 원정 지도 탐험 안개 재검토

2026-11-26 · TLT-028/084 · 0.117.10 후보 · ENG → 릴리스/QA

0.117.9에서는 지역 전체를 어둡게 표시하다가 첫 탐험 기록이 생기면 본래 12×12 격자 안에서만 안개를 그렸다. 이 때문에 촬영본 가장자리와 확장 지형이 아직 탐험 기록이 없는 상태에서도 밝아질 수 있었다. HUD 회귀 테스트는 실제 가림 여부 대신 셀 배경색을 비교했다.

- 탐험 안개를 각 지역 촬영본에 배치했다. 기존 서버 탐험 좌표와 같이 기본 격자 바깥은 가장자리 셀에 대응시켜 촬영본 전체를 덮는다. 지역 이동 안내, 이름과 위치·목표 마커는 촬영본 위에서 읽을 수 있다.
- 이미지 API를 쓸 수 없는 환경에서 지형을 어둡게 하는 처리는 지형 띠에만 적용한다. HUD 회귀에서는 방문한 칸의 안개가 사라지고 옆 칸의 안개가 남는지 불투명도로 확인한다.

[고정 빌드 기록](build.json). 격리 Studio에서 지형 렌더러 154검사, 지역 상세 420검사와 지형 3검사, 배틀 전체 지도 444검사, 로비 전체 지도 87검사, 지도 좌표·미니맵 6,617검사를 통과했다. 44개 촬영본의 안개 경계와 네 화면 크기에서 첫 탐험 뒤의 가장자리 안개를 확인했다. 다른 지도 테스트의 진행 상태가 유입되지 않는 별도 Studio 세션에서 HUD 22,444검사를 통과했다. 전체 소스 구문 컴파일을 통과했다.

릴리스/QA 담당의 게시 클라이언트와 모바일에서의 시각 확인은 남아 있다.
