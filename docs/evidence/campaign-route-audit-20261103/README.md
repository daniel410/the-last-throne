## 재현과 원본 결과

[검사 도구](../../../tools/audit-campaign-routes.luau), [전체 구간/후보/경로 원본](routes.json), [요약](summary.json).

Studio의 플레이어 없는 생성된 캠페인 장면에서 검사 도구를 임시 ModuleScript로 로드한다. `chapter(1..47)`, `edge(1..43)`, `returns()`를 순차 실행하며 도구 내부에서 구간마다 yield한다. 최초 반환 동선 BFS 경로 검사를 별도 명령으로 수행한 뒤 최종 도구의 `returns()`로 바닥/시각 후보까지 확장 검증했다. 스폰 Overlap 재검사와 카메라 확인은 원본 구간 검사에 추가한 조건이며 위에 각각 명시했다. 검사 뒤 임시 모듈을 삭제한다. 제품 인스턴스/저장/진행 상태는 변경하지 않는다.

`python3` 표준 JSON 파서로 원본 집계 및 [요약](summary.json) 재생성, `git diff --check` 통과. 실제 화면7개는 원본 Studio 캡처이며 LFS로 관리한다. 캡처 당시 장면 조명은 야간이고 실제 기기 화면이 아니다.
