# 상점 하단 여백·2열 상품 수정

2026-11-01 · TLT-028/043/061/084 · ENG → QA · 0.58.28

사용자 첨부 화면의 하단 빈 공간은 모바일 전용 공간이 아니라 `ArmoryView`가 빈 Notice에도 92px을 예약한 결함이었다. 안내문이 비어 있으면 목록을 하단16px까지 확장하며, 확인·저장·오류 문구가 있을 때만 실제 줄 높이로 공간을 확보한다. 일반적인 상세 창에서 상품은 한 줄2개로 표시한다. 짧은 모바일 가로 창은 별도 헤더/카드 높이를 사용하며 폭640px 미만은1열로 전환한다. TD 공통 카드·버튼·물약 원본을 재사용한다. 공유 상점 모듈을 쓰는 대장간·다이아 상점에도 적용된다. 가격·서버 거래·2회 확인 계약은 유지한다.

검증: 현재 Studio Play Client에 변경 모듈을 임시 복제하고 구매를 전송할 수 없는 fixture로 `tests/shop-layout-native.luau` 실행.1280×720 / 844×390 / 750×323 / 568×320에서167개 Pass.2열 위치,8개 물약,이름/설명 TextFits,버튼 겹침 없음,부족액 비활성,하단16px,확인문 표시·공간 반환,마지막 구매 버튼 스크롤 도달을 검사했다. fixture 크기는 실제 Roblox GUI 절대 크기이며 실기기 검증과 구분한다. 기존 사용자 Play는 중지하지 않고 임시 GUI/모듈만 제거한다.

미검증: 실제 휴대폰 터치·게시 클라이언트·독립 QA/사용자 시각 수용. 기존 사용자 Play의 원래 상점 컨트롤러는 교체하지 않았다. 다음 실행에는 새 빌드를 열어 확인한다. 기존 다른 변경은 빌드 입력과 커밋에서 제외한다. 다음 담당 QA는 대장간/다이아 상품 긴 설명과 거래 상태의 실제 조작을 추가 수용한다. 상위 티켓은 완료로 닫지 않는다. Roblox 미게시·릴리스 태그 없음.

고정 소스 빌드 결과·해시는 build.json을 따른다.
