피해·감속·표식·범위·타격 시점은 서버의 기존 계약을 따른다. 클라이언트의 공용 지면 투영은 적과 영웅의 충돌 리그를 건너뛰며 실제 지형과 충돌 표면에 바인딩한다. 효과 슬롯이 찼을 때 공용 범위 표시가 이어진다. [공식 사례와 적용 근거](../../research/2026-11-24-hero-ground-beats.md)

## 검증

- Rojo 7.7.1로 소스 `14c439b5`를 고정해 단일 Place를 빌드했다. 기준과 후보 파일의 SHA-256과 각 런타임 모듈 10개를 입력 커밋과 대조했다. [빌드](build.json) · [패키지 대조](package-check.json)
- 격리 Studio 22묶음에서 253,901개 검사를 통과했다. 신규 103개 검사는 세 타격의 높이·범위, 활의 한 번 발사, 적 아래 지면 배치, 아군과 예산 소진 시 범위 표시를 다뤘다. 기준은 같은 재현에서 실행된 99개 검사 중 80개가 새 기준을 충족하지 않았다. 기준과 후보 세부 획 수의 차이로 검사 개수가 다르다. 기존 전체 스킬 검사는 네 영웅의 R6·R15 128개 기술을 각각 재생했고, 적 붉은 예고선과 네 영웅 효과가 겹치는 장면도 검사했다. [검사별 결과](studio-results.json) · [신규 재현](../../../tests/hero-ground-beats-native.luau)
- 같은 R15 리그·무기·표적·기술별 고정 카메라에서 전후 16장을 비교했다. 첫 후보 0.115.90에서 표적 몸에 지면 탐색이 멈추는 모습을 재현했고, 0.115.91에서 발밑까지 내려가는 것을 확인했다. Shatter Blow의 뒤쪽 균열 일부는 표적과 겹치는 각도에서 가려진다. [전후 비교](comparison.jpg) · [첫 후보 빌드](build-rejected.json)
- CPU 18,296개 및 Place 역할과 입장 정적 336개 검사를 통과했다. WoW 계열 형태 검사는 Oath of Dawn 상승광이 마지막 타격에 나오는 현행 계약을 반영해 별도로 통과했다. 별도 기존 순수 Lua 자세 검사는 `K0MeleeMotion`의 Luau 복합 대입을 읽지 못했으며 같은 동작군을 Studio에서 확인했다.

```sh
run-in-roblox --place builds/0.115.91/TheLastThrone-0.115.91.rbxlx --script tests/hero-ground-beats-native.luau
```
