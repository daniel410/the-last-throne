## 구현과 경계

`DeepwoodConceptArt`가7본편+3공유 선택 구역에 길목 쉼터·구조 공간·거목 보급/지도 공간·단일 망루·점령 병영·뿌리숲 피난처·제단 주변 석축·식량 보관·채석 운반장·전쟁단 잔해를 배치한다. 기존의 반복 수도원/종탑/성채를 Deepwood에서만 교체한다. 대표 구성1개와 최대5개 보조 구성, 이끼/양치식물/석회암 갓길로 장소를 구별한다. 선택12스토리를 새12맵으로 계산하지 않으며 DW-Q1은 DW-01의 기존 습지를 공유한다.

- 실제 스폰·목표·교전 반경·이동/귀환로와 사건 윙/진입로를 예약하고, 구역 내부의 평탄한5점 지면·기존 물리 공간을 검사한다. 작은 선택 지역은 동일 키트를 축소한다. 안전한 자리가 없으면 생성을 생략한다. 전쟁터 일부 보조 구성은 이 이유로 생략한다.
- 목재/석축/상자/기둥에는 실제 충돌·쿼리를 적용하고 천/깃발/지면 마감은 비충돌이다. 모델/파트 표시 거리는230~700stud, 지역별 신규 장소 구성520파트 이하·길 마감 별도 상한이다. 새 상호작용/NPC/입자/Light/프레임 루프는 없다.
- 전투·보고·귀환 길의 기존 그림을 같은 색 체계로 마감한다. 주 이동로는 돌길, 귀환로는 좁은 흙길이다. 보고/계획 장소의 얇은 마감은 실제 바닥을 올리지 않는다. 실제 바닥·권한 경계·목표 좌표·진행·저장·전투 수치·보상은 유지한다.
- 대표 건물의 접근 시야를 가리는 일반 TD 수목은 원본 모델과 대응하는 단순 충돌체를 함께 제거한다. 거목 랜드마크/스토리 객체는 유지한다. 옛 TD 절벽 원본은 지면 속으로 내려 화분처럼 보이던 섬 형상을 없앤다. 원본 메시/텍스처는 다시 제작하거나 업로드하지 않는다.
- Deepwood 전용 따뜻한 색 보정과 완화한 안개를 사용한다. 다른 지역 조명과 원래 환경 복원은 유지한다. ArtVersion17으로 이전 미술 캐시를 교체한다.

## Blender MCP 조형 연결

초기0.104.17의 장소 배치는 Studio/native 기본형 단계다. 후속0.104.18에서는 실제 연결된 Blender5.2.0LTS의 새 `TLT_Deepwood_Architecture_20261112` 씬에서10종·691파트를 직접 조형했다. [Blender 원본 GLB·정확한 CFrame 데이터·실제 렌더](../../../assets/models/deepwood-architecture-blender-v1/README.md)를 남겼다. 목조 박공/널판 지붕·보강재·아치/모서리 석재·흉벽·창·병영 잔해·채석 운반 장치를 구별한다. 런타임은 같은 기본형/CFrame/색으로 대표 건축을 재구성한다. 외부 메시 업로드와 TD 원본 수정은 없다. 기존14개 Blender 씬은 보존했고 새 씬만 GLB로 내보냈다. Standard/sRGB/None/Exposure0/Gamma1/Curves Off를 확인했다. 보조 구성과 배치 안전 조건은 유지한다.

후보 첫 실행은 이전 ArtVersion16 캐시를 재사용해 새 Blender 원본 검사가 실패했다. ArtVersion17과 새 검수 월드에서 다시 검사한다. 고정 빌드 결과는 후속 검증 후 기록한다.

## 후보 검증과 수정

첫 후보에서는 일부 선택 지역에 대표 건축이 들어가지 않았다. 후보2/3에서 전체 구역 탐색과 작은 지역의 축소 키트를 적용했고, DW-S3은 성채가 아닌 작은 전쟁단 잔해로 만들었다. DW-07 길 마감1개가 기존 높은 바닥과 맞지 않아 실제 보이는 바닥을 추가 검사하도록 수정했다. 실패 후보 로그는 통과 증거로 합산하지 않는다.

`run-in-roblox`의 공유 플러그인/포트에 다른 검사가 간섭해 후보3 검수 세션이 종료됐다. 다른 작업/TD Studio를 수정하거나 종료하지 않았다. 이후 명시적으로 연 `TheLastThrone-Deepwood-Concept-Review.rbxlx` 로컬 사본에만 Studio MCP를 지정해 검증했다. 후보는 소스 주입 상태이며 불변 빌드 검증과 구별한다.

후보5는10대표/58구성·장소 구성1476파트/고체1110파트·길 포장378조각을 생성했고, 새 구성11040검사·기존 생활 구성/물리 충돌/전투 경로/환경 회귀를 통과했다. 이후 화면에서 확인한 일반 수목 시야/옛 절벽 접지 보정을 추가했으므로 최종 판단은 아래 고정 빌드 재검증을 따른다. 후보 경로 감사는 Deepwood 본편/선택/연결로와 기존 귀환로171구간(166 Success·5 SamePoint, NoPath0)이다.

정적 회귀: 원고1054·전투 경로77381·Deepwood 진행570·지도 안내99695, 합계178700 PASS. 원본은 `static-*.log`다. 각47스토리의 원고/전투/보상 계약과 길 안내를 유지하는 검사이며, 실제 사용자 이해·재미를 판정하지 않는다.

## 고정 빌드·화면·남은 수용

소스와 VERSION을 고정한 뒤0.104.17 단일 파일을 생성하고, 소스 일치·Luau 컴파일·새 구성/기존 물리·서사·전투·환경·길찾기를 재실행한다. 최종 결과·입력/이미지 해시는 검증 후 이곳에 기록한다.

미검증: 게시 클라이언트/실계정·PC/터치/패드 실조작·1~4인+AI 프레임 시간·전투 카메라 전체·최종 사용자 미술 수용. 현재 큰 평지 규모·일부 같은 수목/기본형 반복과 먼 곳의 지형 경계가 남는다. 모든 콘셉트의 나무집/절벽/높이차를 그대로 구현했다고 주장하지 않는다. 새 미술이 기존 TD 원본보다 완전한 최종 품질이라는 판정도 사용자 수용 전까지 유보한다. 부모 TLT-061/G5/G7은 완료 처리하지 않는다. Roblox 게시·릴리스 태그는 만들지 않는다.

다음 담당 QA/DES는 고정 빌드에서 이동·회피·목표 접근, 구역 식별·카메라 가림·성능을 검토하고 사용자는 실제 화면의 미술 방향을 확인한다.
