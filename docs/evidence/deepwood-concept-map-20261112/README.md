## 변경과 제작 근거

`DeepwoodConceptArt`가7본편+3공유 선택 구역에 길목 쉼터·구조 공간·거목 보급/지도 공간·단일 망루·점령 병영·뿌리숲 피난처·제단 주변 석축·식량 보관·채석 운반장·전쟁단 잔해를 배치한다. Deepwood의 반복 수도원/종탑/성채를 교체했다. 대표 구성1개와 최대5개 보조 구성, 이끼/양치식물/석회암 갓길로 장소를 구별한다. 선택12스토리를 새12맵으로 계산하지 않으며 DW-Q1은 DW-01의 기존 습지를 공유한다.

초기0.104.17은 Studio/native 기본형으로 공간을 개선한 단계다. 후속0.104.18에서는 **실제 Blender MCP**로 Blender5.2.0LTS의 새 `TLT_Deepwood_Architecture_20261112` 씬에10종·691파트를 직접 조형했다. 목조 박공/널판 지붕·보강재·아치/모서리 석재·흉벽·창·병영 잔해·채석 운반 장치를 구별한다. 기존14개 씬을 보존하고 새 씬만 GLB로 내보냈다. Standard/sRGB/None/Exposure0/Gamma1/Curves Off 실측은 `blender-session.json`, 메시 수·회전 직교 오차·원본 해시는 모델 폴더의 `validation.json`에 있다.

런타임 `DeepwoodArchitecture`는 Blender에서 추출한 같은 기본형/CFrame/크기/sRGB 색으로 대표 건축을 재구성한다. GLB 메시를 업로드한 방식은 아니며 원통/구형의 곡면 분할은 Blender 렌더와 Roblox에서 차이가 있다. `kit.json`과 생성된 `DeepwoodArchitectureTemplates`는10종·691파트가 대응한다. 외부 모델 생성기·외부 메시 업로드·TD 운영 파일 수정은 없다. 새 씬만 `.blend`로 저장하는 API는 Blender MCP 안전 모드에서 거부돼, 다른 씬을 함께 저장하는 대신 GLB·기하 JSON·재현 제작 코드를 편집 원본으로 보존했다.

## 배치와 게임 계약

- 실제 스폰·목표·교전 반경·이동/귀환로와 사건 윙/진입로를 예약한다. 구역 내부의 평탄한5점 지면·기존 물리 공간을 검사하고 작은 지역은 전체 비율을 유지해 축소한다. 안전한 자리가 없는 DW-S3의 보조2구성은 생략한다.
- 목재/석축/상자/기둥은 실제 충돌·쿼리를 적용하고 천/깃발/지면 마감은 비충돌이다. 표시 거리230~700stud, 구역당 장소 구성520파트 이하·길 마감84개 이하를 검사한다. 새 상호작용/NPC/입자/Light/프레임 루프는 없다.
- 기존 전투·보고·귀환 길 그림을 같은 색 체계로 마감한다. 주 이동로는 돌길, 귀환로는 좁은 흙길이다. 얇은 포장은 실제 바닥을 올리지 않는다. 실제 바닥·권한 경계·목표 좌표·진행·저장·전투 수치·보상은 유지한다.
- 대표 건물의 접근 시야를 가리는 일반 TD 수목은 원본 모델과 대응 충돌체를 함께 제거하고 거목/스토리 객체는 유지한다. 옛 TD 절벽은 지면 속으로 내려 화분 같은 섬 형상을 줄였다. 원본 메시/텍스처는 유지한다.
- Deepwood 전용 따뜻한 색 보정과 완화한 안개를 적용한다. 다른 지역 조명과 원래 환경 복원은 유지한다. ArtVersion17로 이전 미술 캐시를 교체한다.

## 실패 후보와 재현 경계

초기 후보의 선택 지역 배치 누락은 전체 구역 탐색/축소 키트와 작은 전쟁단 잔해로 수정했다. DW-07 길 마감1개는 기존 높은 바닥과 맞지 않아 실제 보이는 바닥을 추가 검사하도록 수정했다. 후보3은 `run-in-roblox` 공유 플러그인/포트에 다른 검사가 간섭해 세션이 종료됐다. 이후 명시적인 로컬 검수 사본/Studio ID만 사용했다. 다른 작업/TD Studio를 변경하거나 종료하지 않았다. 실패 로그는 통과 합계에 넣지 않는다.

Blender 연결 첫 후보는 이전 ArtVersion16 캐시를 재사용해 새 원본 검사가 실패했다. ArtVersion17과 새 월드로 재검사한 결과는 `blender-candidate-native.log`, 최종 판단은 고정0.104.18 결과를 따른다. 초기 시야 보정 전후는 `before-sightline.jpg`, `after-sightline-candidate.jpg`이며 최종 Blender 모델 화면과 구분한다.
