준비선은 공통 습득 후속 기술 11개와 전직 기술 104개에 적용했다. Wind Lance에는 전용 준비·발동 경로가 있다. 12개 시작 스킬은 기존 표현을 사용하며, 회귀 검사 범위는 총 128개다. 새 준비선은 무기나 보조 무기 소켓을 기준으로 움직이며, 소켓이 늦게 준비되면 캐릭터 전방을 쓴다. 발동 전 서버 시각에서만 표시하고 취소·새 회차·확정 발동 시 회수한다. 지면 예고의 남은 시간은 서버 시각을 기준으로 계산한다. 기존 장식 풀 안에서 기술당 Beam 2~6개, 동시 준비 효과 데스크톱 3개·터치 2개를 사용한다. 서버는 시작 시각을 시각 이벤트에 전달한다. 피해, 타깃, 범위, 펄스 간격과 이동은 서버 전투 계약을 따른다.

## 검증과 인계

- 0.114.16 기준과 0.114.18 후보의 R15 Studio 화면에서 Shield Verdict·Stonebound Leap·Heavy Draw·Frost Ring을 비교했다. 동일 기술 준비의 77%에서 같은 무기·장비·카메라를 사용했다. 화면은 수동 관절 평가를 사용한다.
- 0.114.17에서 Grand Volley에 Heavy Draw의 빠른 당김이 적용되는 회귀를 확인했다. 0.114.18에서 해당 보간을 Heavy Draw에 한정했고 같은 활 검사에서 재검증했다. [중간 빌드](build-0.114.17.json)
- 판정·권한과 분리된 Studio에서 준비선 소켓 추적·중복·역순·취소 및 도끼 회수를 확인했다. 고정 게임 빌드에서 10묶음 278,867건을 통과했다. R6/R15의 128개 스킬, 무기 소켓, Blender 기준 활·지팡이 포즈, 128개 VFX 형상과 장식 한도를 검사했다.
- 다음 담당은 전투 QA·아트다. 게시 테스트 클라이언트의 연속 전투, 아군 4인 효과와 적 예고의 가독성, 터치 실기기 프레임 시간, 사용자 미술 수용은 미검증이다. 로컬 빌드이며 게시 및 릴리스 태그는 없다.
