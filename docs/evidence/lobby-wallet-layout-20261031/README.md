# 로비 재화 표시 배치 수정

- 작업: 사용자 요청에 따른 로비 UI 겹침 수정 (별도 백로그 ID 없음).
- 변경: 로비 지갑을 상단 버튼 아래로 이동하고, 공유 지갑의 재화 이름을 왼쪽 정렬해 아이콘 옆에 배치했다. 영웅 선택창은 지갑 아래에 위치하도록 위쪽 여백을 늘렸다. 공유 지갑 정렬은 전투 미니맵 아래에도 적용된다.
- 검증: Studio의 로컬 0.43.2 로비 플레이 세션에 변경값을 임시 적용해 실제 화면을 확인했다. BAG과 지갑, 지갑과 영웅 선택창이 분리되며 각 아이콘과 글자 영역 간격은 6px이다. 해당 세션에서 지갑 아래 경계는 128px, 선택창 위 경계는 140px이었다.
- 제한: 다른 기기 크기와 전투 화면의 실제 시각 수용은 미검증이다. 별도 네이티브 픽스처 실행은 다른 작업이 포트 50312를 사용 중이어서 시작하지 못했다. 게임 빌드와 게시는 수행하지 않았다.
- 다음 담당: QA/사용자가 실기기 및 전투 화면 배치를 확인한다.
