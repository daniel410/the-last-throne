# 드워프 왼손 투척·사격과 포탄 연출

TLT-033/057/059 · 2026-11-20 · 후보 0.115.7

Bomb Toss의 기존 소품은 작고 손에 남아 있었다. 착탄 프레임에는 손에서 지점까지의 궤적과 카메라를 향한 폭발 이미지가 한꺼번에 그려졌다. 이번 후보는 오른손의 장착 도끼가 보이는 상태에서 왼손으로 Gunner 기술을 사용한다. 투척 준비, 발사 방향, 반동과 회수를 왼손에 맞췄다.

| 기술 | 동작과 효과 |
| --- | --- |
| Bomb Toss | 불붙은 심지가 달린 폭탄을 어깨 뒤로 당겼다가 왼손으로 던진다. 폭탄이 포물선을 그리며 날아가고, 확정 착탄 때 지면에서 파편과 짧은 연기가 퍼진다. |
| Shrapnel Toss | 각 펄스의 산개 좌표에 짧게 연속 투척한다. 착탄에서 작은 파편이 넓게 튄다. |
| Skipping Charge | 허리를 숙여 낮게 던진다. 폭탄은 지면에 한 번 닿고 다시 튀어 목표점에 내려온다. |
| Rolling Charge | 왼손으로 낮게 밀어 굴린다. 시전 시점의 서버 표적을 비행에 쓰고, 피해와 폭발 위치는 타격 시점에 서버가 다시 계산한다. |
| Shell Burst, Field Mortar, Siege Pattern, Siege Barrage | 왼손으로 포신을 들고 발사한다. 길쭉한 금속 포탄과 포신 반동을 사용하고, 포탄 길이에 맞춘 짧은 잔상이 하강을 보여 준다. |
| Blast Step | 포신을 전방으로 두고 뒤로 물러나며 짧은 부채꼴 충격을 낸다. |
| Gunner Shot, Quickfire, Scatter Shot, Piercing Round | 왼손 총구에서 기존 직사·연사·산탄·관통 동작을 수행한다. |

## 검증과 인계

- [Bomb Toss 전후와 Gunner 대표 장면](gunner-payloads.jpg)은 동일 R15 검토 리그의 준비·비행·착탄을 비교한다. 실시간 전투의 입력·성능 증거는 게시 테스트에서 수집한다.
- [Gunner 전용 검사](../../../tests/gunner-payload-native.luau) 180건에서 13개 기술의 R6·R15 왼손 소품, 오른손 도끼 표시, 폭탄 4종의 실제 비행과 확정 착탄, 사망·취소 정리, 포탄 하강, Rolling Charge의 타격 시점 재판정을 확인했다.
- 고정 단일 Place에서 Studio 27묶음 280,868건을 통과했다. 영웅 128개 스킬의 애니메이션과 VFX, 기존 오디오와 폭탄의 투척음 타이밍을 회귀 검사했다. [Studio 결과](studio-results.json) · [빌드 및 SHA-256](build.json)
- CPU 연출 검사 14,026건과 빌드의 Place 역할·입장 로딩 검사 336건을 통과했다. 후보는 미게시 상태다. 전투 QA는 실제 클라이언트에서 연속 투척과 착탄을 확인하고, 일반 전투 카메라와 터치 화면에서 심지 달린 폭탄과 금속 포탄을 구분할 수 있는지 확인한다.
