## 확인한 문제와 수정

기준 입력은 `c5016d7b` /0.106.1이다. 새로 재검토한 결과, 기존 계산은 무사망·선택/반복 제외 조건에서만 예상치와 맞았지만 Hell 회차별 XP 감액과6회 이후0XP가 있었다. 사망으로 단1XP를 잃어도5회 후 Lv98+2,524XP에 남았고6회 완주로도 성장하지 않았다.4인 Hell4/5회에는 각각63.9%/63.6%의 적이0XP였다. 낮은 모드 반복2회로99에 도달하는 보상/요구량 불균형도 있었다. [수정 전 계산과 실제 계정 reducer 재현](before.json).

후속 사용자 지시대로 완료 레벨은 **정상 XP 누적 시 예상치**로 해석하고, XP0으로 막는 구조를 수정했다. 현재 `CampaignXPRewards`는 목표 레벨·영웅 레벨·요구XP·회차에 의존하지 않는 고정 지급 정의다. 비전투5장도 고정 완료 XP를 지급한다. Hell은6회 이후에도 같은 보상을 주며 고레벨에서는 요구량이 증가한다. 새 원정17과 기존16의 남은 지급에 적용하며 원정ID/영수증·기존 레벨/레벨 내XP를 유지한다.

## 산출물·검증

- [수정 후](after.json)·[에픽별 누적](growth.csv): Easy10/17/23/27/30, Hard60, Insane80, Hell90/95/97/98/99. 완료 시 남은 레벨 내 XP도 기록한다. 기준 경로의 숫자이며 개별 플레이 결과를 강제하지 않는다.
