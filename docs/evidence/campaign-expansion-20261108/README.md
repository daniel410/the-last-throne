# 전체5에픽 확장 구현

2026-11-08 · TLT-001/028/031/050/057/061~065/084/087 · 0.85.0 · ENG/DES/RES → QA · 미게시

## 변경과 플레이 흐름

본편35장에 각2개, 기존 사이드12개에 각1개씩 사건82개·세부 목표246개를 추가했다. 원래 목표 사이에 원인 조사→다른 공간에서 행동→결과 확인을 연결한다. DW 보급/포로/운반 명령, GW 표식/정찰대/Finn의 실제 이동 호위/옛길, FV 경보/피난처/수호수/눈보라 완화, EC 설비/광부/침공 명령/왕릉 길, HG 친구들의 도움/성문/왕관의 심장 회수로 이어진다. 강제 최소 대기 타이머·추가 처치/적 HP/보스·XP/Gold/재료 증가는 없다.

기존44지역 정체성/좌표를 보존하고 바깥 사건 구역82곳을 연결했다. 구역끼리 겹치지 않는 배치·폭32 연결로·전망대 +10/지하 갤러리 등 −10 높이·점프를 요구하지 않는 경사로·안전 발판을 만든다. 기존 TD 나무 메시와 지역별 표식/대피소/설비/묘실 소품을 사용한다. 실제 지형과 같은 좌표로 지도/목적지/서버 경계를 확장하며, 경사 입구에 걸리던 기존 숲 경계/나무 충돌만 좁게 조정했다.

조사/추적/장치/순서/이동/호위는 기존 서버 활동 경로를 사용한다. 사건의 마지막 확정 단계는 지름길 체크포인트와 원래 길 귀환 위치를 해금한다. 마지막 저장 단계에서 사망/재접속을 재개하며 클라이언트 좌표/미확정 권리는 이동에 쓰지 않는다. 복구 전후 연출은 개인 확정 저널로 표시하며 스트리밍 재유입에도 다시 적용한다. FV07 완료 뒤 눈보라 시각 완화, HG07 뒤 Dawnspire 친구5명의 선택 대화를 제공한다. 후일담은 스킵 가능한 자유 대화이며 보상/완료 조건이나 별도4~6분 컷신은 아니다.

## 호환·보상 보존

새 입장 규칙13에서 확장 저널1을 활성화한다. 구원정1~12의 저장은 원래 필수 목표를 유지한다. 기존 영웅이 새 원정에 들어올 때 이미 통과한 원래 목표 앞의 추가 사건만 면제하며 원래 완료/선택/보상/보유품을 보존한다. 원정 재플레이·구순서 FV/EC 완료 후 GW 빈 구간·활성/영구 저널 정산·응답 유실 재요청을 검사했다. 추가 사건은 별도 지급이 없고 기존 원정 규칙12와 같은 보상을 준다. 현재 본편 성장 산술은 여전히 Lv44이며 Lv80 성장 완료로 보고하지 않는다.

기존12사이드도 추가 현장 사건을 마쳐야 로비 Tessa의 기존 보고 경로가 열린다. 원래 퀘스트/아이템/보상 ID와 NPC !/? 추천 기능을 유지한다. 신규 GW/HG 사이드4개는 기존 계획의2차 범위로 남긴다.
