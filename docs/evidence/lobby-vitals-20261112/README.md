# 로비 왕복 HP/MP 보존

작업: TLT-008/041/053 · 소프트웨어 엔지니어 · 소스 구현/정적 검증, 실제 이동 수용 대기.

2026-11-12 사용자가 로비에 갔다가 배틀에 재입장하면 HP/MP가 채워지는 문제를 보고하고 기존 수치 유지를 지시했다. 기존 `CombatService.setupCharacter`는 배틀 캐릭터 생성마다 현재 HP/MP를 최대치로 초기화했으며 이동 프로필에 해당 수치가 없었다. 명확한 결함 수정으로 별도 게임성 리서치는 생략했다.

## 변경과 저장 경계

- `HeroVitals`: 영웅의 절대 HP/MP와 측정 당시 레벨을 보존한다. 최초/기존 무기록 프로필·실제 사망·레벨 상승의 전회복은 유지한다. MP 0을 결측값으로 취급하지 않고, 장비 변경은 새 상한으로 제한한다. 로비 대기 시간을 MP 오프라인 회복으로 환산하지 않으며 기존 배틀 MP 자연회복 코드는 유지한다.
- `CombatService`: 서버 전투 상태에서만 체크포인트를 생성하고 재입장 초기화 때 복원한다. 현재 Character와 다른 이전 생명 상태는 저장에 사용하지 않는다.
- `InventoryRules/InventoryService`: 영웅별 `vitals`를 기존 RPG 단일 계정 키·세션 fence 안에서 검증/저장한다. TeleportData로 HP/MP를 받지 않는다. 이동 전 저장이 확인된 뒤 계정 lease를 해제한다. 저장 실패/응답 유실이면 이동을 시작하지 않으며 저장 불명 세션은 재접속하여 다시 읽는다. 로비의 기본 Humanoid는 영웅 체크포인트를 덮지 않는다. 정상 접속 종료/서버 종료에도 최종 체크포인트를 저장한다.
- `HeroSessionService`: 같은 서버의 Studio/훈련/스토리 재생성 경로도 체크포인트를 거친다. 실제 사망 후 새 생명에는 부활 회복을 허용한다. 계정 없는 시험 경로는 영웅별 세션 체크포인트를 사용한다.

기존 TD 운영 코드·데이터, 사용자 미커밋 변경은 작업 범위에서 제외했다. 게임 빌드·VERSION 변경·태그·Roblox 게시를 수행하지 않았다.
