# 파티 접근 관리 검증

2026-11-20 · TLT-053 / G3 · ENG → QA · [접근 계약](../../production/lobby-economy-and-expeditions.md#파티-접근-관리) · [비교 조사](../../research/2026-11-20-party-access.md)

- Lua 회귀 11개를 통과했다. 두 MemoryStore 어댑터로 공개/잠금 참가, 앞의 0, 잘못된 번호, 변경·해제, 계정 단위 시도 제한, 파티장 권한, 추방과 자리 해제, 이전 토큰 및 이동 거부, 재참가 제한 만료, 출발 예약 후 관리 요청 거부를 확인했다.
- 0.115.0 단일 Place 빌드를 로컬 Studio Edit에 열고 `tests/party-access-native.luau`를 실행해 26개 검사를 통과했다. 임시 MemoryStore와 가상 플레이어로 실제 요청 처리기·모집 응답·추방 안내를 검증하고, 실제 GUI 객체를 데스크톱과 667×375 레이아웃에 배치해 버튼 크기·겹침·비밀번호 입력 유지·관리 버튼 노출을 확인했다. [빌드 로그와 SHA-256](build.json).
- Studio 테스트의 첫 실행은 테스트용 시그널에 연결 객체가 없어 중단됐다. 연결 객체를 반환하도록 테스트를 수정하고 같은 빌드에서 재실행했다.
- 게시 클라이언트와 실기기 수용은 대기 중이다. QA는 서로 다른 두 로비에서 잠긴 방을 찾고 올바른 번호로 이동해 같은 명단이 보이는지 확인한다. 도착 전후 추방, 같은 방 재참가 거부, 다른 방 참가, 비밀번호 없이 공개방 참가를 실제 클라이언트에서 재현한다.
