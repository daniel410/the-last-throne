# Dawnspire·Deepwood 밝은 낮 환경

2026-10-31 · TLT-031/050/061/084 · DES/ENG → QA · 시험 구현

로비와 Deepwood에 각각 밝아진 낮 환경광·노출, 맑은 파란 낮 하늘과 하늘색 원거리, 채도 보정(+0.24)을 적용했다. Roblox 기본 하늘 텍스처를 사용하므로 새 외부 에셋 권한은 필요 없다. Deepwood의 먼 배경 안개 180~340과 지형 숨김 거리는 유지한다. Atmosphere는 엔진에서 거리 안개를 무시하게 하므로 적용하지 않는다. 로비 ↔ Deepwood 전환과 훈련 등 다른 상태에서는 기존 하늘·대기·조명 값을 복원한다. 다른 사용자의 미완료 VERSION·게임 파일은 포함하지 않았고 빌드는 만들지 않았다.

검증: `lua tests/daylight-atmosphere.spec.lua` 8개 통과(프로필 전환, 기본값/원본 하늘 복원, 색 보정 제거). 실행 중인 Studio 서버의 일시적 비부모 ModuleScript에서 Luau 구문 컴파일 통과. `git diff --check` 통과. 실제 로비/Deepwood 렌더 화면, 그래픽 품질별 하늘 색상·채도·피격 가독성, 실기기 및 최종 사용자 미술 수용은 미검증이다. 다음 QA/DES가 실제 클라이언트에서 각 상태와 전환을 확인한다.
