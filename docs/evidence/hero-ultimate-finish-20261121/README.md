앞선 박자의 대표 효과는 다음 타격 간격 안에 정리된다. 아군용 대표 형태는 중복 아이콘 획 없이 표시한다. 피해, 보호막, 쿨다운과 발동 순서는 서버 정의를 따른다.

## 전후 비교

- 같은 R15 리그, 장비, 카메라에서 마지막 타격 60ms 뒤 자세를 고정해 비교했다. [궁극기 마무리 자세](ultimate-finish-poses.jpg)
- Knight의 Oath of Dawn, Dwarf의 Mountain Collapse, Elf의 Spirit Arrowfall과 본인 Mage의 Eternal Tempest가 한 적에게 겹치는 상황을 재현했다. 서버 확정 이벤트를 소비하는 클라이언트 렌더러에 같은 타격 위치와 순서를 전달했다. [네 영웅 겹침](ultimate-finish-party.jpg)
- 겹침 장면의 HeroVFX Beam은 113→67개, 표면은 110→58개로 감소했다. 적의 붉은 예고선 16개와 피해 숫자 42의 표시 객체를 양쪽에서 확인했다. 격리한 궁극기 8개의 아군 마지막 타격 합계는 Beam 218→53개, 표면 229→30개였다.

## 검증 범위

`run-in-roblox --place builds/0.115.33/TheLastThrone-0.115.33.rbxlx --script tests/hero-ultimate-finish-native.luau`로 여덟 기술의 첫 효과 만료, 마지막 동작, R6/R15 자세, 본인·아군 효과 수, 활 소켓에서 시작하는 궤적과 예산 초과 시 대체 효과를 재현한다. [검사 소스](../../../tests/hero-ultimate-finish-native.luau)

신규 검사 88건 중 기준은 33건에 실패했고 후보는 모두 통과했다. 후보의 Studio 검사 12묶음 263,774건과 CPU 전직·형상·취소 검사 15,147건을 통과했다. 전체 128개 기술의 아이콘 효과와 피격도 검사했다. 고정 빌드의 SHA-256과 변경한 클라이언트 모듈 6개를 소스 커밋과 대조했다.

0.115.31에서 아군용 주 효과 위에 아이콘 장식이 겹쳤다. 0.115.32에서 중복 장식을 제거했다. 후속 R6 검사에서 방패 마무리가 기존 몸통의 이동값을 지워 두 번째 타격에 0.2스터드 단차가 생겼다. 0.115.33에서 이동값을 보존했고 R6/R15의 204개 타격 경계 회귀를 통과했다.
