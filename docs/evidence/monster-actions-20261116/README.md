# 일반 몬스터와 보스의 추격·공격 동작

2026-11-16 · TLT-005/027/057/084 · 개발·리서치 → QA·사용자

0.111.21은 다섯 지역의 몬스터 50종(일반 27, 보스 23)이 사용하는 146개 공격을 다룬다. 종별 원본 클립에 무기·체형별 준비, 접촉, 반동을 더했다. 기존 공격 데이터에 따라 13가지 자세를 공유하고 종별 원본 보행과 무기 소켓을 사용한다. 구형 전투 시계만 제공되는 원정은 준비 자세를 보강하고 원본 클립의 접촉 자세로 이어진다. [공식 RPG 사례·기존 동작 리뷰](../../research/2026-11-16-monster-actions.md)

| 기존 동작 | 달라진 동작 |
| --- | --- |
| 근접 유형 여러 개가 같은 몸통 회전을 사용했고 빈손의 추가 동작이 없었다. | 고블린은 단검 팔을 감아 찌르고, 오우거는 가슴과 무기를 높였다가 내려친다. 할퀴기와 방패 반격은 서로 다른 쪽으로 몸을 감는다. 늑대는 앞발로 버티며 목과 몸을 앞으로 보내고, 박쥐는 양쪽 날개를 펼쳐 기울인다. |
| 시전자의 후속 자세가 투사체 전체 비행 구간에 걸쳐 고정됐다. | 발사 시 지팡이와 몸이 정면을 향하고, 빈손은 주문을 펼친다. 마지막 탄을 보낸 뒤 팔이 먼저 회수된다. 다단 시전은 다음 발사 전에 다시 준비한다. |
| 스킨 리그는 추격 중 위치 차이가 없는 한 프레임에서 Idle로 전환했다. | 짧은 위치 갱신 간격에는 보행 클립을 유지하며 실제 이동량을 나누어 반영한다. 정지하면 Idle로 돌아가고 순간이동은 보폭에서 제외한다. 일반 관절 리그는 직전 추격 자세에서 공격 준비로 짧게 전환한다. |

## 검증

- 0.111.21 고정 빌드에서 모션 관련 5개 모듈이 작업 소스와 일치하는지 확인했다. 새 검사에서는 서버가 Hell·체력 30% 조건에서 결정한 전체 146개 공격의 285회 타격, 40개 장거리 발사 후 회수, 스킨 12종의 연속 보행·정지·순간이동을 확인했다. [빌드·해시](build.json) · [엔진 검사 원본](native.json)
- 기존 방향 검사에서는 네 난이도와 체력 세 구간의 1,752개 시전을 다뤘다. 30·60·144Hz에서 동작 방향과 판정 방향, 반복 타격 경계, 최종 복귀를 검사했다. 실제 50종 모델을 별도로 생성해 관절·Bone의 유한 변환, 서버 루트·HP 보존과 스킨 정리를 확인했다. 네 묶음 합계 821,057개 조건을 통과했다. Lua 패턴과 Deepwood 보스 회귀는 각각 3,717개와 96개 조건을 통과했다.
- 영상은 0.111.19와 0.111.21에서 같은 모델·공격·카메라로 촬영했다. 기술당 16개 시점을 원래 길이로 재생한다. 첫 촬영의 일부 프레임은 Studio 콘솔 전송 중 손상됐고 주술사의 카메라 구도가 잘못됐다. 최종본에서는 보이는 파트의 크기로 구도를 잡고 격리 복사본에서 루프백으로 받은 픽셀을 압축 해제해 검사했다.

- 별도의 원본 기반 회귀에서는 Deepwood 9,553개, Gloamwood 27,999개, 지역 시전자 4,269개, 좀비·구울 135,426개 조건을 통과했다. 전체 동작 검사는 8묶음 998,304개다. 0.111.20 후보에서 구울의 오른팔이 준비 자세 도중 0.00271스터드 바닥을 통과해, 최종 빌드에서는 낮은 두 리그의 기존 어깨 동작과 접지를 유지하면서 수평 체중 이동과 회전을 적용했다.
- 60Hz에서 위치를 세 프레임마다 0.15스터드씩 보냈을 때 Gloambat과 VolcanoShaman 모두 보행 상태였던 프레임이 각각 6/18에서 18/18로 늘었다. Cinder Bolt는 두 빌드 모두 클립 위상 0.62에서 발사했으며, 약 2.11초 비행 구간이 끝나기 0.1초 전의 위상은 0.78에서 1.00(회수 완료)으로 달라졌다.
- 별도 과거 보스 난이도 검사 `boss-pressure-boost.spec.lua` 75행은 이전 버전 소스에서도 같은 조건으로 실패한다. 이미 진행 중인 임무를 다시 시작하는 사례에서 현재 규칙으로 교체될 것을 기대하지만, 현재 원정 코드는 진행 중인 임무의 규칙을 보존한다. 이번 변경에는 원정·난이도 소스 수정이 없다.

- 고정 빌드 복사본의 로컬 Play에서 실제 R15 플레이어 1명과 Goblin, Gloambat, VolcanoShaman, Veyr를 차례로 교전시켰다. 전투 서비스가 대상을 선정하고 공격을 시작했다. 클라이언트에서 네 몬스터 모두 준비·발동·회수 및 관절 이동을 관측했고, 각각 서버 명중 1회와 시험 피해 3을 확인했다. 주술사·Veyr는 투사체 발사와 종료도 관측했다. 대상 클라이언트 스크립트 오류는 0건이다. 임시 영웅과 Hard 규칙 18의 시험 원정을 사용했고, 처음에 Studio 기본 바닥이 플레이어와 몬스터 사이를 막은 시도는 제외했다. ## 재현

1. 고정 빌드에서 `run-in-roblox --place builds/0.111.21/TheLastThrone-0.111.21.rbxlx --script tests/monster-action-phrasing-native.luau`를 실행한다. 같은 방식으로 `enemy-combat-presentation-native`, `enemy-direction-motion-native`, `enemy-attack-motion-native` 검사도 실행할 수 있다.
2. `python3 tools/collect-monster-actions.py PLACE.rbxlx OUTPUT.log`로 두 버전을 각각 촬영한다. 도구는 고정 빌드의 임시 복사본에서 로컬 수신기만 사용한다. 한 번에 한 Studio에서 실행한다.
3. `python3 tools/render-monster-action-review.py --before BEFORE.log --after AFTER.log --versions 0.111.19 0.111.21 --output /tmp/monster-actions`로 재생본을 만든다.

다음 담당은 QA와 사용자다. 게시 클라이언트, 실기기, 4인 동시 전투에서의 성능·예고 가독성과 사용자 수용은 미검증이다.
