# 영웅 공격의 자세 붕괴 연출

2026-11-23 · TLT-033/057/059 · 기준 0.115.58 · 고정 후보 0.115.60

| 영웅 | 기술 | 동작 |
| --- | --- | --- |
| Knight | Shield Breaker | 방패 팔꿈치를 접어 준비하고, 충격을 앞다리에 실은 뒤 방패를 가슴 쪽으로 되돌린다. |
| Dwarf Axe Thrower | Crag Cleave | 도끼를 옆으로 당기면서 반대쪽 어깨를 열고, 휘두른 무게를 앞무릎으로 받는다. |
| Elf Archer | Piercing Line | 고개를 활의 조준선에 맞춘 뒤 시위를 푼 팔꿈치를 뒤로 거두고 앞다리를 디딘다. |
| Mage | Stone Lance | 빈손을 낮춰 바위를 모은 뒤 앞으로 밀어내면서 앞다리로 반동을 받는다. |

서버가 적의 자세 수치가 양수에서 0으로 바뀐 공격을 확인하면 명중 이벤트에 붕괴를 표시한다. 피격면 가까이에서 영웅별 두 곡선이 벌어지고 적의 몸이 짧게 내려앉는다. HP가 줄었다면 피해 숫자는 한 번 표시된다. 같은 타격의 표식 부여나 소모는 공용 예산 안에서 함께 표시된다. 자세 계산, 피해, 범위와 기존 시전 박자는 서버의 기존 규칙을 따른다. [공식 사례 조사](../../research/2026-11-23-hero-posture-break.md)

## 검증

- 같은 R15 리그, 무기, 조명, 카메라의 Studio Run 격리 장면에서 시전 접촉 후 64ms 자세와 명중 획을 비교했다. 위치가 가까운 조건에서 0.115.59는 방패와 표적이 겹쳐 한쪽 획이 가려졌다. 0.115.60은 표적 가까이에서 두 획이 카메라 쪽으로 열리도록 보정했다. 비교 장면은 명중 형태 관찰을 위해 피해 숫자 레이어를 숨겼다. [네 기술 전후 화면](posture-break-comparison.jpg)
- 고정 커밋 `bf57145f`에서 공용 로비·배틀 Place를 빌드했다. Studio로 연 사본의 SHA-256과 변경 런타임 모듈 6개의 내용을 대조했다. Luau 7파일을 컴파일했다. [빌드 기록](build.json)
- Studio Edit 검사 13묶음 260,654건이 통과했다. R6·R15의 128개 기술, 표식과 이동기, 연속 피격, 피해 숫자와 적 예고 우선순위를 확인했다. 새 검사 187건은 서버의 전환, 면역·연속·중복·처치 상황, HP가 보호된 붕괴, 동시 표식, 획·수명·예산을 확인했다. 같은 검사에서 기준은 220건 중 22건이 새 조건을 충족하지 못했다. 이전 효과와 후보 효과의 인스턴스 수 차이로 검사 수가 달라졌다. ## 남은 수용

후보는 미게시 상태다. 전투 QA가 게시 시험의 로비→배틀 이동과 실제 4인 교전에서 적 예고와 자세 붕괴를 구별할 수 있는지 확인한다. 저사양 터치 실기기 프레임 시간과 사용자 타격감 수용이 남아 있다.
