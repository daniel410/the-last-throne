# 마법사·엘프 기본 공격속도 절반 조정

2026-11-02 · TLT-005/008/032/033/084 · ENG → QA

사용자 요청에 따라 `src/shared/K0Config.luau`의 마법사·엘프 기본 공격 준비/타격/복귀 시간을 각각2배로 늘렸다. 엘프는0.22/0.08/0.30초에서0.44/0.16/0.60초(전체1.20초), 마법사는0.16/0.10/0.16초에서0.32/0.20/0.32초(전체0.84초)다. 별도 기본 공격 쿨다운을 추가하지 않는다. 기사·드워프, 공격당 피해·사거리·대상 수, 기술 시전/쿨다운·MP는 유지한다.

서버 `CombatService`가 같은 프로필로 행동 종료와 타격 시점을 결정하며, 클라이언트 `K0BowMotion`·`K0MageMotion`도 해당 프로필의 구간 길이에 맞춰 기존 모션을 샘플링한다. 모션 원본을 변경하지 않는다. [기존 마법사·엘프 조사](../research/2026-10-31-mage-elf-balance.md)의 서버 권위·동일 조건 비교 원칙을 재사용했다. 이번 배율은 사용자 지정값이며 새 경쟁 게임 조사나 최종 밸런스 수용을 뜻하지 않는다.

검증 결과:

- `lua tests/skill-stat-preview.spec.lua`: 1,368개 통과.
- Lua로 HEAD의 기존 설정과 수정 설정을 재귀 비교: 4,020개 값 검사. 두 클래스의 기본 공격 시간6개만 정확히2배이며 다른 값/키는 동일하다. 전체 공격 주기1.20초/0.84초 확인.
- `git diff --check`: 통과.
- 서버/클라이언트의 공통 프로필 참조는 소스 확인이다. Studio 실행·실제 클라이언트·모바일/패드·멀티플레이·체감 밸런스는 미검증이다.

이번 작업은 소스 수정이며 빌드·게시·릴리스는 실행하지 않아 VERSION을 유지한다. 기존 미커밋 로비/이동 작업과 자산은 포함하지 않는다. 다음 담당 QA는 동일 레벨·장비에서 연속 기본 공격의 주기·타격·모션과 회피 입력을 확인한다. 롤백은 이번 기본 공격 시간6개를 이전 값으로 복원한다.
