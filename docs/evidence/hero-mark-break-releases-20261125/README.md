# 네 영웅의 표식 소모 공격

2026-11-25 · TLT-033/057/059 · 기준 0.115.103 · 후보 0.115.105

| 영웅 | 기술 | 준비, 방출과 일반 명중 |
| --- | --- | --- |
| Knight | Oath Challenge | 방패 뒤에서 몸을 낮춘 뒤 앞발을 디디며 가슴을 편다. 확정 방향에 금빛 왕관 파동을 내보내고, 일반 명중에는 양쪽으로 올라가는 금빛 획을 쓴다. |
| Dwarf | Breaker Throw | 도끼를 어깨 뒤로 감아 던지고 왼발로 제동한다. 짧은 잔상과 장착 도끼의 회전 복제본이 확정 지점에 닿는다. 연출이 끝나면 장착 도끼가 손에 다시 보인다. |
| Elf | Mark Breaker | 조준할 때 뒷무릎에 체중을 싣고, 방출 뒤 시위 손을 뺨 뒤로 당긴다. 화살 한 발과 한 줄의 잔상을 쓰고 일반 명중은 가는 관통 획으로 표시한다. |
| Mage | Magma Spear | 빈손으로 힘을 퍼 올린 뒤 지팡이를 뻗고 앞발로 버틴다. 어두운 암석과 용암 창날이 한 방향을 가리키며, 일반 명중은 위로 찢어지는 불꽃으로 표시한다. |

기술 범위, 피해, 표식 주인·소모와 자세 붕괴는 서버 결과를 사용한다. 표식을 실제로 소모하면 금빛 인장, 갑옷 균열, 약점 괄호 또는 불씨가 터진다. Breaker Throw에서 자세 붕괴와 표식 소모가 함께 확정되면 두 효과를 표시한다. [공식 비교 자료](../../research/2026-11-25-hero-mark-break-releases.md)

## 검증

- 기준 0.115.103 및 후보 0.115.105의 단일 Place 파일 SHA-256과 런타임 모듈 6개씩을 고정 Git 커밋과 대조했다. 후보 Rojo 버전은 7.7.1이다. [기준 빌드](../epic-third-chapter-rescue-routes-20261124/build.json) · [후보 빌드](build.json) · [패키지 대조](package-check.json)
- 동일 R15 리그·카메라·조명으로 준비·일반 명중·표식 소모 24장을 비교했다. 첫 후보 0.115.104에서 도끼가 표적 몸에 가리고 용암 창날이 가늘어 보였다. 0.115.105는 도끼가 닿기 직전의 회전과 용암 창날의 밝은 면을 더했다. 정면에 가까운 각도에서는 표적이 왕관 파동의 중앙이나 도끼가 닿는 순간의 일부를 가린다. [전후 화면](comparison.jpg)
- 네 영웅 동시 시전의 같은 Studio 장면에서 영웅 Beam은 98→9, 표면은 80→12, 보조 발광선은 22→0, 입자 요청은 12→0이었다. 적의 붉은 예고선 16개와 아군 명중 피해 숫자 42를 확인했다. 이 수치는 한 장면의 인스턴스 수다.
- 집중 검사 94개를 모두 통과했다. 기준에서는 같은 검사 중 60개가 미충족이었다. 엄폐가 소켓 앞에 있을 때의 발사선, 확정 방향과 왕관 범위, 투척 도끼의 복원, 일반 명중·잘못된 표식·확정 표식·자세 붕괴를 검사했다. [Studio 및 CPU 결과](studio-results.json)
- 최종 후보에서 Studio 18묶음 253,112개를 통과했다. 네 클래스 128개 기술의 R6·R15 재생과 표식 소모 22개 기술의 서버 명중 경로를 포함한다. CPU 검사 15,339개, 패키지 정적 검사 336개를 통과했다. 기존 순수 Lua 자세 검사는 양쪽 빌드에서 Luau 복합 대입을 해석하지 못해 Studio 자세 검사 결과를 사용했다.
