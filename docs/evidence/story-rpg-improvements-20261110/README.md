## 유지·호환

35본편/12기존 사이드·원정 규칙/저널 스키마/목표·세부 목표·선택ID·완료/고정 보상·영웅별 Diamonds·보유품·전투/성장/강화 수치는 변경하지 않았다. 구완료자가 새 보스를 처치했다고 기록하지 않으며 이관 면제 사건을 실제 목격 기록으로 만들지 않는다. 개인 장면은 확정 저널에서 재구성하고 공유 충돌·발판·피해 대상을 바꾸지 않는다. 추가 인물은 장식 배우이며 전투AI 슬롯/성능 계약과 별개다.

## QA 인계

Studio/별도 테스트 클라이언트에서 로컬 플레이어의 `TLTStoryObservationEnabled`를 명시적으로 true로 설정한 뒤 기존 FV01~03 파일럿→FV04 경보→GW Finn/HG 회수→EC05를 관찰한다. `require(PlayerScripts.Client.DeepwoodJournal).playtestSnapshot()`은 로컬 측정 사본만 돌려준다. 영웅/원정 변경 때 초기화하며 서버/외부로 전송하지 않는다. `unchangedTravel`은 진행 변화 없는 이동 거리 대용치로 불필요한 왕복의 확정 판정이 아니다. 근처 체류/읽기 시간도 행동 성공과 구분한다.

확인할 질문: 누구를 위해 무엇을 하는가, 왜 다음 지역으로 가는가, Finn은 어떻게 달라졌는가, 경보/회로 선택 이유는 무엇인가, 내가 구한 사람은 마지막에 어떻게 도왔는가. 원안/수정안 신규8명씩(PC4/터치4)·6/8 이해 목표는 아직 미측정이다. 참가자 모집·사용자 응답을 가공/추정하지 않았다.

미검증: 신규 유저 이해/재미/동선20% 감소, PC/터치/패드 실제 입력, 실계정 저장·네트워크/스트리밍, 저사양 성능·4인+AI, 게시 클라이언트 연속 완주. 코드의 순차 완주 검사는 실제 조작/전투 난도 수용이 아니다. 다음 담당 QA는 위 고정 조건으로 측정하고, 부모 티켓은 실제 수용 전 미완료로 유지한다.

Roblox 게시·릴리스 태그·live DataStore·TD 운영 변경은 이번 작업에 포함하지 않는다. 롤백은 이번 소스 변경을 되돌린 새 빌드로 수행하며 저장 스키마 이관은 필요 없다.
