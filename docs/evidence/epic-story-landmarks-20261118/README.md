# 다섯 에픽 대표 지형·지물 개선

2026-11-18 · TLT-061 / TLT-065(Gloamwood) / TLT-062 / TLT-063 / TLT-064 · 환경 아트, 환경 3D, 맵 구현 · G5 수용 진행 중.

[공식 RPG 사례와 본편 35개 장의 제작표](../../research/2026-11-18-epic-environment-landmarks.md)를 바탕으로 에픽마다 대표 구간 한 곳을 개선했다. [모델 소스](../../../src/server/World/EpicStoryLandmarks.luau)는 기존 지역 팔레트와 Roblox 기본 형상을 사용한다. GW의 노출 암층과 FV의 퇴설은 기존 지형 위에 배치한 조형이다. 배치는 기존 목표 앵커를 기준으로 안전 공간, 원본/Easy 이동 경로, 도로, 확장 구간, 지면 높이와 소품 점유를 검사한다. 기존 충돌 정책으로 구조 부재와 얇은 마감에 맞는 물리 설정을 적용한다.

| 스토리 | 반영한 조형 | 현행 사건 |
| --- | --- | --- |
| DW-02 | 구조 쉼터, 천 차양과 들것 | 생존자 호위 |
| GW-01 | 갈라진 고목과 노출 암층 | 정찰대 경로 수색 |
| FV-03 | 설원 방풍 울타리와 비대칭 퇴설 | 서쪽 봉화 접근 |
| EC-03 | 금속 선별 격자와 광석 잔해 | 갱도 지지대 보강과 광부 구조 |
| HG-03 | 묘역 측면의 석조 배수구 | Lumi의 관리 통로 |

## 고정 빌드와 Studio 검증

[0.113.10 빌드 기록](build.json)과 [Studio 결과](studio-results.json)를 각각 보존했다. PlaceId 0, 플레이어 0인 로컬 Studio에서 변경 모듈의 소스 일치와 전체 Luau 구문을 검사했다. `CampaignWorld.create(epic)` 단독 진입과 캠페인 전체 생성·캐시 호출 후의 실배치를 확인했다. 검사 범위는 바닥 지지, 부품의 충돌·쿼리·터치, Atomic 모델, 기존 원거리 표시 속성이다. Luau 541개, 모델 5개·부품 100개·충돌 부품 66개를 확인했다. 기준 빌드와 후보 Studio에서 기존 Ivo 텍스처 로딩 경고가 확인됐다.

이동 검사는 기준 빌드 0.113.9와 후보 빌드에서 동일한 [경로 스위트](../../../tests/epic-map-navigation-native.luau)를 사용했다. 다섯 에픽의 기존 배치와 Easy 배치를 모두 순회하고, 가이드 표본에서 바닥·몸체 겹침·서버 경계 보정을 검사했다. 원본 739목표·38,241표본, Easy 782목표·39,540표본에서 기준과 후보의 결과가 일치했다. 두 배치 모두 바닥 누락, 경계 보정, 경로 실패, 단차 검출은 0건이다. 기존 Deepwood 몸체 겹침 네 건은 양쪽 빌드에서 확인됐다. DW-02 생존자 쉼터 앞 나무 한 점, DW-Q1 보고 경로의 나무 한 점과 사건 입구 석조 두 점이다. 실기기 영웅 조작에서의 영향은 후속이다.

[비교판](comparison.jpg)은 고정 빌드의 동일 위치와 지역 조명에서 모델의 표시 상태만 바꾼 5쌍이다. 각 카메라는 접근 목표 쪽을 기준으로 모델 앞면을 담은 근접 구도다. 정찰대 수색 중 처음 보이는 시점이나 전투 카메라는 후속이다. 초기 비교에서 GW의 끊긴 단면이 조명에 묻히고 EC의 격자가 바닥과 합쳐져 보여 밝은 심재·엇갈린 암층과 돌출된 금속 격자로 수정했다.

재현 도구는 [Studio 스크립트 준비](prepare-studio.py)다. `python3 docs/evidence/epic-story-landmarks-20261118/prepare-studio.py --frames --output /tmp/tlt-landmarks.luau`를 실행하고 `run-in-roblox --place builds/0.113.10/TheLastThrone-0.113.10.rbxlx --script /tmp/tlt-landmarks.luau`로 검사한다. 0.113.9 동선 기준선은 같은 준비 명령에 `--frames` 대신 `--baseline`을 사용한다. 기준 파일 SHA-256은 `412d173e16692979d50489e6f8104a9cf4a48ed0ec54c5643e5bdbf48c0be3aa`다.
