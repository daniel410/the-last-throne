# 참고 이미지 기반 여행용 창고 상자

2026-11-01 · TLT-028/043/055/061/084 · ART/ENG → QA · 0.58.17 로컬 시험판·미게시

사용자 제공 이미지를 따라 기존 파란 본체/금색 띠 상자를 목재 판자·어두운 철제 보강대·리벳·가죽 끈/버클·V형 여행 하네스·측면 운반 손잡이·자물쇠/열쇠구멍으로 교체했다. 기존 모델은 선물 상자처럼 보인다는 구체적 외형 교정이며 사용자 참고를 새 자산 원천으로 보존한다. [원본/기하/GLB/미리보기](../../../assets/models/storage-travel-chest-v1/).

153개 네이티브 Part 중 충돌/쿼리는 본체1개만 사용하고 장식152개는 고정·충돌/쿼리/터치 비활성이다. 기존 StorageChest.create의 body/prompt 반환, 각 거점 위치 및 F/패드X·거리12 프롬프트, 실제 저장/소유권 코드는 유지한다. 공통 생성기를 쓰는 로비·Deepwood·Frozen Vale·Ember Caldera 창고에 같은 외형을 적용한다. 실제 Play 확인은 로비이며 다른 거점은 같은 API 생성4회만 확인했다.

Blender MCP로 별도 장면에 같은 기하를 제작하고352,396bytes GLB(153메시·5,336삼각형)와1200×900 PNG를 내보냈다. 기존 Blender 장면/파일은 삭제하거나 덮어쓰지 않았다. JSON/제작 Python이 편집 원본이며 GLB는 베벨이 포함된 보조 모델이다. Blender 절차 목재 결은 렌더 전용이며 GLB/Roblox에 베이크하지 않았다. 런타임은 Roblox Wood/Metal/Fabric 재질과 물리 판자/틈/상처를 쓴다. 참고 이미지의 사진 같은 세밀한 풍화 텍스처 재현이나 최종 미술 수용을 주장하지 않는다. 외부 자산 생성/업로드는 없다.

Blender 안전 모드가 exec/파일읽기 및 libraries.write를 차단해 해당 경로는 실행되지 않았다. 안전 모드를 유지하고 직접 전달한 기하 데이터와 허용된 GLB export/render 연산으로 완료했다. 기존 외부 .blend 로드는 하지 않았다.

Studio 로컬0.58.16의 관련 생성기/기하 모듈을 교체한 Play에서630개 검사 통과:153파트/1콜라이더·고정/쿼리·내장 코드 없음·주요 형상·금색 띠 제거·기존 위치/프롬프트·4개 호출 형태 반환 API. 실제 게임 화면과 Blender 렌더를 확인했다. 검증은 verify.luau/studio-result.json, 고정 빌드 소스·해시는 build.json을 따른다. 촬영용 카메라/GUI는 원복한다.

실제 창고 저장/아이템 이동 회귀·다른3거점 화면·실기기 성능·게시·사용자 최종 미술 수용은 미검증이다. 다음 담당 QA는 각 거점의 F 창고 열기/입출고와 모바일 성능을 검증한다. 다른 진행 중 파일은 빌드/커밋에서 제외한다.
