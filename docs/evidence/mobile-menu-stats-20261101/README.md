# 모바일 메뉴·상세 상태 개선

2026-11-01 · TLT-028/031/052/084 · DES/ENG → QA · 0.58.9 로컬 시험판

- 로비·배틀 메뉴: 모바일/짧은 화면에서 2열·52px 버튼, 키보드 H/B/J 힌트 생략, 화면 높이에 맞춘 위치. 배틀 메뉴와 48px 열기 버튼을 미니맵 UIScale 밖으로 옮겨 축소 방지. PC 크기로 복귀하면 원래 부모·크기·위치·문구 복구.
- 상세 상태: 모바일에서 COMBAT / POINTS / GEAR / EFFECTS로 분리하고 선택 영역만 생성한다. 작은 화면의 장비 초상 높이와 투자 행을 조정하고 +/-44px 유지. 성장창 제목·탭·닫기를 안전 영역 안에 배치하고 안내문에 12px/44px 영역 확보.
- 하위 탭을 바꿔도 스탯 초안과 장비 상세 펼침 상태 유지. 저장 중 중복 CONFIRM 차단·각 하위 영역의 RETRY SAVE 유지. 서버 피해/성장/투자 예산·장비 권한은 변경하지 않았다.

[조사·근거](../../research/2026-11-01-mobile-menu-stats.md). 기존 승인 v2의 프레임·아이콘을 재사용했다.

기존 메뉴 테스트의 고정 세로 행 가정은 모바일/PC 분기와 실제 영역 검증으로 수정했다. 초기 저장 대기 fixture가 CONFIRM 활성화를 기대한 테스트 오류를 바로잡았다. 짧은 성장창의 최소 콘텐츠 높이가 1px 부족한 구현은 상단 여백 2px 조정으로 고쳐 재검사했다.

검증은 합성 GUI 호스트의 엔진 생성·측정 결과다. 실제 렌더링 미술 검수·휴대폰/태블릿 터치·스크롤·노치·실제 회전 입력·게임패드·저장/네트워크·게시 클라이언트는 미검증이다. 실제 모바일 선택 기기와 대표 4클래스의 시각/조작 수용은 QA 후속이며 상위 티켓은 완료 처리하지 않는다. 이번 작업은 Roblox 게시나 릴리스 태그 생성을 포함하지 않는다.
