## 동작 리뷰와 수정

- **기사 기본기.** 내려베기는 검을 들 때 방패를 몸 쪽으로 당기고, 올려베기는 더 낮은 지점에서 반대 다리로 받는다. 마지막 가로베기는 하체와 방패가 측면 회전을 받아내며 검끝이 가슴 높이를 통과한다. 드워프는 빈손을 반대로 보내며 도끼의 무게를 받고, 되치기와 횡베기는 서로 반대 방향으로 몸을 감는다. 이동 중에는 하체를 보행 Animator에 맡긴다.
- **기사 스킬.** 찌르기는 기존 R6/R15 정면 찌르기 해를 복원해 팔 신전과 칼끝 방향을 함께 맞췄다. 반격은 먼저 몸을 가리고, 도발은 방패를 가슴 앞에서 머리 옆으로 들어 올린다. 교차 베기는 다음 타의 준비 자세로 이어지고, 다단 방패 공격은 팔을 다시 당겼다가 민다. 방패를 움직이는 관절의 병진 성분도 회수 보간에 포함했다.
- **드워프 스킬.** 강타·지면찍기·낮은 휘두르기·도끼 투척의 준비 높이와 빈손 반동을 구분했다. 소총은 짧게 견착하고, 박격포는 포신과 왼팔을 함께 들어 올린 뒤 더 큰 반동을 받는다. 폭탄은 뒤로 당겨 던진다. 서버의 투척 통지를 받으면 손에서 사라지고 연속 투척은 다음 준비 구간에 다시 나타난다.
- **전직·궁극기.** 첫 번째 전수 자세표에서 유사했던 기술 20종을 다시 조정했다. Unyielding Front는 방패를 몸 앞에 당겨 버티고 Oath of Dawn은 검을 높이 든다. Mountain Collapse는 도끼를 쐐기처럼 세우고, Siege Barrage는 포신 아래에서 반동을 받는다. 다단 기술의 자세는 각 서버 타격 시각에 맞춰 재장전·회수한다.

첫 후보에서 검끝 이동 상한을 넘고 3타의 수평 높이 편차가 커져 첫 타의 가슴 회전과 마지막 타의 수직 기울기를 줄였다. 느린 연속 포격에서 마지막 반동이 Idle에 남는 문제도 수정했다. 기존 검사 임계값을 유지했다. 카탈로그 캡처의 페이지 인덱스 오류와 다중 Studio 실행 시 테스트 플러그인이 다른 세션에 붙은 시도는 제외하고 고정 빌드에서 다시 실행했다. Play는 0.111.17 시험용 복사본에 0.111.18의 유일한 게임 소스 차이인 MeleeWeightShift 모듈을 적용한 세션이다. 스킬 트리 해금·로비·저장·적과의 실제 피해 교환은 이 Play 기록 범위 밖이다.

## 재현과 남은 수용

1. 저장소 루트에서 `python3 tools/prepare-melee-actions-review.py`를 실행한 뒤 `run-in-roblox --place builds/0.111.18/TheLastThrone-0.111.18.rbxlx --script /tmp/tlt-melee-actions-native.luau`를 실행한다. 마지막 출력은 `MELEE_ACTIONS_ALL_PASS`다.
2. `python3 tools/prepare-melee-actions-review.py --capture motion`을 실행한다. 같은 `/tmp/tlt-melee-actions-capture.luau`를 0.111.16과 0.111.18에서 각각 실행해 출력을 별도 로그에 저장한다. `--capture catalog`로 생성한 스크립트는 0.111.18에서 실행한다. 캡처는 한 번에 한 Studio에서 실행한다.
3. `python3 tools/render-melee-action-review.py --before BEFORE.log --after AFTER.log --catalog CATALOG.log --output /tmp/melee-review --versions 0.111.16 0.111.18`로 비교 영상과 자세표를 복원한다.

다음 담당 QA·사용자는 게시 테스트 클라이언트의 보통 카메라 거리에서 터치·패드 연속 입력, 이동 중 방패·도끼의 판독, 4인 이펙트가 겹칠 때의 타격감을 확인한다. 현재 빌드는 미게시이며 실기기 성능·네트워크 지연·사용자의 타격감 수용은 미검증이다.
