# 몬스터 마법 VFX 재질·흐름·충격 개선

2026-11-12 · TLT-005/027/032/033/057/061~065/084 · ENG/DES → QA · 로컬 구현·미게시, 최종 미술 수용 후속

사용자는0.104.10의 기하 아이콘 중심 품질을 거부했다. [Diablo IV·Last Epoch·LoL 비교 조사](../../research/2026-11-12-monster-spell-art-review.md)를 거쳐 외형 분류뿐 아니라 재질·시간 곡선·빛·잔상·접촉의 분리를 적용했다.

## 실제 변경

- `EnemySpellArt`: 곡선 Beam의 가는 중심과 넓고 희미한 광륜, 텍스처가 있는 원소 흐름, 크기/투명도 생애가 다른 유한 입자, 짧은 국소광을 별도 층으로 제작했다. 엔진 내장 smoke/fire/sparkle 텍스처를 사용하며 새 업로드나 타 게임 자산은 없다.
- 불은 휘는3가닥 꼬리·난류 화염·식는 연기, 얼음은 반투명 결정·얇고 긴 잔광·빙진, 비전은 독립 회전하는 나선, 영혼은3가닥 흐르는 빛줄기, 그림자는 어두운 틈/유색 가장자리, 독은 점성 있는 짧은 궤적, 거미줄은 가는 실로 구분했다.
- 시전은 안으로 모이는 흐름과 늦게 강해지는 발광을 사용한다. 투사체 전체를 같은 속도로 회전시키지 않으며 얼음 창은 전방을 유지한다. 명중은 기존 투사체를 통째로 늘리는 대신 짧은 섬광·곡선 충격파·방사/중력을 가진 파편·속성별 잔향으로 처리한다.
- 광역 공격은 빠르게 올라와 천천히 가라앉는 기하와 지면 충격파/균열/초승달 흐름을 합성한다. 고리 안전 중심을 비우고 실제 서버 판정·탄도·피해·보상/저장을 보존한다.
- 데스크톱 Beam192/예약 입자480/국소광6/광륜32, 터치 Beam96/입자240 상한을 둔다. 기존 기하/효과 예산과 별도이며 취소·죽음·새 행동·수명 종료 때 해제한다. 장식 예산보다 실제 비행체를 우선한다.
