# 몬스터 마법 VFX 재질·흐름·충격 개선

2026-11-12 · TLT-005/027/032/033/057/061~065/084 · ENG/DES → QA · 로컬 구현·미게시, 최종 미술 수용 후속

사용자는0.104.10의 기하 아이콘 중심 품질을 거부했다. [Diablo IV·Last Epoch·LoL 비교 조사](../../research/2026-11-12-monster-spell-art-review.md)를 거쳐 외형 분류뿐 아니라 재질·시간 곡선·빛·잔상·접촉의 분리를 적용했다.

## 실제 변경

- `EnemySpellArt`: 곡선 Beam의 가는 중심과 넓고 희미한 광륜, 텍스처가 있는 원소 흐름, 크기/투명도 생애가 다른 유한 입자, 짧은 국소광을 별도 층으로 제작했다. 엔진 내장 smoke/fire/sparkle 텍스처를 사용하며 새 업로드나 타 게임 자산은 없다.
- 불은 휘는3가닥 꼬리·난류 화염·식는 연기, 얼음은 반투명 결정·얇고 긴 잔광·빙진, 비전은 독립 회전하는 나선, 영혼은3가닥 흐르는 빛줄기, 그림자는 어두운 틈/유색 가장자리, 독은 점성 있는 짧은 궤적, 거미줄은 가는 실로 구분했다.
- 시전은 안으로 모이는 흐름과 늦게 강해지는 발광을 사용한다. 투사체 전체를 같은 속도로 회전시키지 않으며 얼음 창은 전방을 유지한다. 명중은 기존 투사체를 통째로 늘리는 대신 짧은 섬광·곡선 충격파·방사/중력을 가진 파편·속성별 잔향으로 처리한다.
- 광역 공격은 빠르게 올라와 천천히 가라앉는 기하와 지면 충격파/균열/초승달 흐름을 합성한다. 고리 안전 중심을 비우고 실제 서버 판정·탄도·피해·보상/저장을 보존한다.
- 데스크톱 Beam192/예약 입자480/국소광6/광륜32, 터치 Beam96/입자240 상한을 둔다. 기존 기하/효과 예산과 별도이며 취소·죽음·새 행동·수명 종료 때 해제한다. 장식 예산보다 실제 비행체를 우선한다.

## 검토·검증 기록

검사 통과를 미술 수용으로 대신하지 않는다. 아래 영상은 실제 프로덕션 몬스터와 단순 표적을 배치한 격리 Studio의 연속 재생이다. 정상 입력·네트워크 전투 영상은 아니다. 외부 게임 영상/에셋은 포함하지 않는다.

![화산 샤먼의 연속 재생](fire-live.gif)

[7초 MP4](fire-live.mp4). 화면의 Studio 뷰포트만 잘라 크기를 줄였으며 효과를 후합성하거나 속도를 바꾸지 않았다. GUI와 다른 앱이 포함된 녹화 원본은 저장소에 포함하지 않는다. 이후 OS가 추가 앱 데이터 접근을 요구해 외부 녹화 경로를 중단했고, 다른 원소/광역은 추가 권한 없는 Studio 내부 캡처로 검토한다.

미검증: 게시 클라이언트의 정상 입력 전투, 낮은 그래픽/터치·패드/작은 화면, 실제1~4인+AI의 성능·시야 가림, 사용자 최종 미술 수용. 다음 담당 QA는 동일 빌드에서 실제 전투의 원소 식별·시전/명중 시점·경고 가림과 저사양 예산을 관찰한다. Roblox 게시·릴리스 태그는 만들지 않는다.

고정 빌드 엔진 합계 **282,040개 assertion PASS**. 기존 Gloamwood MeshPart 다운로드 경고가 있어 해당 자산의 게시 권한 성공으로 간주하지 않는다. 서버72검사 PASS 뒤 Studio 내장 MaterialManager/Gen3d Scheduler 오류가 발생해 해당 CLI 종료는1이었다. 게임 검사 실패0과 구분하며 로그를 보존한다(행끝 공백만 정리). 새 내장 텍스처의 접점/발광은 실제 화염 표본에서 확인했으며 낮은 그래픽과 실기기 수용은 남아 있다.

검토 도구는 `tools/prepare-monster-spell-art-review.py`와 `tools/capture-monster-spell-art.luau`다. 자체 샘플 클록으로 실제 렌더러/몬스터 포즈를 연속 재생하며, 네트워크/HP 판정을 생성하지 않는다. 지면의 확장 광륜은 기존 즉시 판정과 별개의 장식이며 필수 예고와 전체 범위 접촉 기하를 유지한다. 영상/GIF는 LFS로 관리한다.

촬영 초기에는 빌드 fixture의20stud 두께 Baseplate가 바닥/배우를 가려 제거했다. 내부 전용 FastForward 호출은 권한 오류로 사용하지 않고 정상 Run/Heartbeat 재생을 사용한다. 별도 Studio 검사와 고정 포트를 공유해 실패한 실행은 통과로 합산하지 않았다. 한때 QA 전용 임시 실행기 사본의 포트만 분리했으나 전역 플러그인 간섭이 확인되어 최종 검사는 기본 실행기를 순차 사용했다. 설치된 실행기·사용자 게임·다른 검사 프로세스는 수정/종료하지 않았다. 최종 검증은 위 고정 빌드 로그만을 정본으로 삼는다.
