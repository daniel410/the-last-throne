# 엘프 동작·후드 착용·전체 VFX 수명 수정

2026-11-13 · TLT-032/054/055/057/084 · ENG/ART → QA. 사용자 신고4건과 전체 영웅/몬스터 VFX의 동일 결함 조사. 상위 티켓/사용자 미술 수용 완료가 아니다.

## 변경과 근거

- 현재 Play의 Idle 엘프에서 `QuiverCarriedArrow` 복제본8개 중1개가 보이는 상태를 관찰했다. 화살통 → 손 → 활 전달 구간에서만 손 화살을 만들고, 전달/중단/대기 시 제거한다. 새 렌더러 상태가 소유하지 않는 잔여 복제본도 정리한다. 현재 세션에서 잔여 가시 화살 제거를 확인했다. R6의 기존 활에 끼운 화살과 R15 화살통 동작은 유지한다.
- 활을 최대한 당겼을 때 접점을 활 좌표 기준 우측0.18/아래0.32stud로 보정했다. 화살 뒤끝·두 시위·손 IK가 동일한 변위를 사용한다. 팔꿈치 pole 높이는0.70→0.35다. 실제 사용자 아바타의 로컬 복제본을 Native IK로 평가한 손-타깃 오차는0.0137stud였다. [세션 검토 화면](elf-anchor-session.jpg). 후드/장갑과의 최종 미술 수용은 별도다.
- Traveler/Tempered 후드: 세로1.12·깊이1.08배, 아래0.12stud. Sentinel: 세로1.12·깊이1.08배, 아래0.02stud. 모두 실제 Head 비율로 적용하며 Hair는 확대/이동하지 않는다. Veteran은 비교 기준으로 유지한다. 원본 메시·텍스처·업로드 ID는 변경하지 않는다. 초기 Sentinel 아래0.08 후보는 R6 눈 가림을 검출해 기각했다([초기 실패](hood-initial-native.log), [대안 측정](hood-eye-clearance.log)). 최종 후보는 R6/R15 후드4종의 눈·입 표본을 통과했다.
- Axe Throw: 실제 날아가는 도끼의 짧은 잔상이 이미 있는데, 도착 후 `HeroVFX.skill`로 투척 궤적을 다시 만들고 있었다. 도착 시 두 번째 투척을 제거했다. 회전·곡선 비행·무기 복원은 유지한다.
- Mana Bolt/Water Ball: 도착 효과에 이전 시전자 위치를 넘겨 경로가 뒤늦게 재생될 수 있었다. 도착 효과의 시작/끝을 실제 도착점으로 제한했다. Gravity는 서버 영역 이벤트만 사용한다. 피해/명중/MP/쿨다운은 수정하지 않는다.
- 전체 고급 영웅 VFX: 같은 공격의 발사/펄스 뒤 도착한 준비0단계를 거부한다. Wind Lance의 직접 진입점도 같은 규칙을 적용한다. 중복/과거 펄스 거부는 유지한다.
- 몬스터: `projectileEnd`를 발사보다 먼저 받으면 종료를 기억하지 못해 늦은 발사가 비행을 되살릴 수 있었다. 공격 순번·펄스·shot별 종료를 기억하고, 이미 발사/종료/취소한 공격의 늦은 begin이 준비 효과를 되살리거나 비행을 지우지 못하게 했다. 새 공격의 경고·각 펄스는 유지한다.

## 빌드와 남은 수용

소스 `176e26d781dd8a18773286cbcb4c4d93c40c3f7d`를 origin/main에 푸시하고 원격 일치를 확인한 뒤 **0.104.27** 단일 빌드를 만들었다. [build.json](build.json)의 산출물은 `builds/0.104.27/TheLastThrone-0.104.27.rbxlx`, SHA256 `aa3e25c8a31cb92b542a4f6150a152f024475d314504ccf57a338c1157ac0392`다. 변경8모듈 원문 일치와 같은 산출물의14개 엔진 검사 **88,962개 통과**를 확인했다([원문](pinned-native.log), [결과](pinned-results.json), [입력 해시](pinned-inputs.json)). 4계열 무기700검사도 포함한다. 실제 산출물 역할10·도착 로딩283·프로젝트 호환 검사를 통과했다. Roblox 게시/릴리스 태그 없음.

재현 도구는 `tools/prepare-visual-lifecycle-tests.py --place <고정 rbxlx> --output <임시 폴더>`이며 입력 원문 일치와 SHA256을 기록한다. 검사 준비 도구는 Rojo의 string Source와 기존 ProtectedString Source를 모두 읽는다. 최종 검사 포트가 별도 작업에 점유된 동안 대기한 뒤 재실행해 `VISUAL_LIFECYCLE_ALL_PASS`를 확인했다.

현재 Play에는 화살 정리/접점·후드 착용·Axe Throw 늦은 재생 제거의 임시 표시 보정을 적용했다. Play 종료 시 사라지며 영구 소스/고정 빌드를 대신하지 않는다. 진단용 복제본·임시 모듈은 Play에만 존재했고 Play 종료 후 소멸했다. TD 운영/재화/권리 변경 없음. 게시 클라이언트·저FPS/지연 실기기·다인·사용자 최종 수용은 미검증이다. 다음 담당 QA/DES는 네 후드 교체·연속 사격·회피 취소와 영웅/몬스터 실제 전투를 새 빌드에서 확인한다.
