# 딥우드 개울의 청록색 블록 수정

2026-11-11 · TLT-031/061 · ENG → QA · 게시/사용자 수용 별도

사용자 스크린샷의 청록색 구조물은 `CampaignIncidentScenes`가 만드는 `CreekWater`다. 개울 폭8을 일반 빔 헬퍼에 전달해 높이도8이 됐다. 지면보다3.98stud 높은 장식이 캐릭터 몸과 안내선을 가렸다. `CanCollide=false`이므로 기존 통행/충돌 검사에서 검출되지 않았다.

## 변경·검증

- 개울의 높이를0.12로 줄였다. 기존 위치·회전·폭8·길이·재질·색·비충돌 속성과 디딤돌은 유지한다. 수면 상단은 지면+0.04다.
- `tests/deepwood-creek-surface-native.luau`는 실제 콘텐츠의 딥우드 개울3곳을 생성해 수면 높이·기존 수평 범위·디딤돌 노출·비충돌 속성을 확인한다. 격리된 Studio0.103.4 Edit에서 기존 모듈은 `creek conceals the hero and walking route`로 실패했고 수정 후보 모듈은 `{passed=true,creeks=3}`으로 통과했다. 후보 모듈/시험 장면은 검사 후 제거했다.
- 신고 화면과 연결된 실행 중0.103.5 서버의 개울3곳에도 높이만 즉시 수정했다. [전후 크기·좌표](active-session.json). 캐릭터·퀘스트·저장 데이터는 시험 코드로 변경하지 않았다.
- 같은 Play 클라이언트에서 카메라 `(-2070,12,-806)` → `(-2085.72,0,-833.45)`로 확인했다. 개울이 바닥 높이의 얇은 띠로 보이고 디딤돌이 드러난다. 화면 확인은 자동 정상 보행/전체 퀘스트 수용을 대신하지 않는다.

영구 소스 빌드는0.103.8이며 입력 커밋·해시·결과는 [빌드 기록](build.json)을 따른다. Roblox 게시·릴리스 태그·실기기·재접속·사용자 정상 조작 수용은 수행하지 않았다. 상위 티켓 전체는 완료로 바꾸지 않는다. 다음 QA는 새 빌드에서 DW-01 화물 회수 구역과 나머지 개울2곳을 정상 입력으로 확인한다.
