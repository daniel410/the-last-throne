# 로비 재화 표시를 MENU 아래로 이동

2026-11-01 · TLT-028/061/084 · ENG/DES → QA · 0.58.21 로컬 시험판·미게시

사용자 요청에 따라 로비 Gold/Diamonds를 오른쪽 MENU 버튼 아래로 옮겼다. 메뉴는 Y8/높이44, 재화는 Y60으로8px 간격을 둔다. 오른쪽 끝은 둘 다 안전 영역에서12px이며 재화의208×56 크기를 유지한다. 이전 좌측/메뉴 옆/좁은 화면 압축 규칙은 제거했다. 로비 메뉴가 열리면 기존 TLTLobbyTopMenuOpen 상태로 숨기고 닫히면 기존 로비 표시 조건 아래 복원한다. 재화 값·서버 권한·배틀 지갑은 변경하지 않는다. 기존 제작 스킬의 명확한 위치 교정 절차를 적용했다.

Studio Edit/CoreGui의 기존 상단 메뉴34개와 지갑19개 검사가 통과했다. 하단 배치/오른쪽 끝·메뉴 열기/닫기·영웅/가방·배틀 전환·실제0과 미로드 표시를 검사했다. 최초 소스 교체 후 도구 require 캐시가 이전 모듈을 반환해 위치 검사에 실패했으며 새 ModuleScript identity로 재실행해 통과했다. 임시 모듈은 제거했다. 지갑 fixture는 반환값 없이 마지막 assert까지 성공했다. 실제 Play에서는 MENU 정상 클릭으로 숨김/복원, 최종(1,-12,0,60) 위치와8px 간격을 확인했다. 처음 영웅창 닫힘 직후의 즉시 검사는 표시 상태 반영 전에 실패했고 상태가 반영된 뒤 정상 표시를 확인했다.

검증은 tests/lobby-top-menu-native.luau와 tests/lobby-wallet-native.luau, 도구 결과는 native-results.json을 따른다. 고정 빌드 소스/해시는 build.json에 기록한다. 실기기·게시·실제 저장/구매는 미검증이다. 다음 담당 QA는 모바일 가로/세로에서 MENU 아래 표시와 숨김/복원을 확인한다.
