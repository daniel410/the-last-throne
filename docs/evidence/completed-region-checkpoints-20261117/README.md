# 완료 지역 체크포인트 이동

TLT-028/050/061~065/084 · 빌드 0.113.3 · 원정 지도

원정에서 M을 눌러 지역을 선택하면 상세 목록 맨 위에 체크포인트 이동 버튼이 표시된다. 현재 영웅과 난이도에서 해당 지역 스토리를 완료한 경우 이전 에픽과 부가 스토리 전용 구역도 선택할 수 있다. 본편과 부가 임무가 같은 땅을 쓰면 본편 스토리의 완료를 기준으로 삼는다. 미완료 지역에는 잠금 이유를 표시하며 캠페인은 기존 진입로를 통해 진행한다.

서버는 현재 계정의 난이도별 영구 저널과 플레이 중인 영웅으로 대상 ID를 검증한다. 재도전의 가상 완료 기록, 다른 난이도나 파티원의 진도, 방문 기록, 부분 사건 완료로 이동을 열지 않는다. 새로운 에픽을 준비하는 동안에는 중복 요청을 막고 준비 후 영웅·생명·원정·자격·좌표를 재검증한다. 실제 이동은 서버 월드의 도착점을 사용한다. [고정 빌드](build.json)

## Studio Play 재현

고정 Place의 로컬 복사본에서 실제 지도·스토리 RemoteEvent·CheckpointTravelService·CombatService와 생성된 Deepwood 월드를 사용했다. 시험 영웅과 난이도 저널을 메모리에서 공급했다. 사용자 계정의 저장이나 게시 없이 한 명의 로컬 플레이어로 수행했다.

| 조작 | 관찰 결과 |
| --- | --- |
| DW-02 진행 중 상세 열기 | 이동 버튼이 입력·패드 선택을 거부하고 완료 조건을 표시했다. |
| 클라이언트에서 DW-02 이동 요청 직접 전송 | 서버가 거절했다. 캐릭터는 시작 좌표 (-1031.36, 10.15, -992.40)에 머물렀다. |
| 지도에서 뒤로 → 완료한 Goblin Forest Trail → Travel to checkpoint 클릭 | 지도가 닫히고 도착 알림을 받았다. 서버에서 712.79스터드 이동, DW-01 도착점과 실제 캐릭터 위치 오차 0스터드를 확인했다. |

## 검사 범위

- 체크포인트 규칙·서버 검사 8,349개 통과. 44개 지역의 완료/미완료, 난이도 분리, 이전 에픽, 재도전, 부분 사건, 미저장·전투 중 거절, 로딩 중 생명/원정 전환과 재시도를 포함한다.
- 고정 빌드의 지도 엔진 검사 10,476개 통과. 지역 상세 버튼 콜백·접근 가능 상태 갱신·지도 복귀·배치를 포함한다. 스토리 장애물·이동 검사 1,095개에서 진행 중인 본편의 사건 출구 70개를 통한 우회 요청 거부를 확인했다. 체크포인트 메뉴 배치 36개, 파티 지도 96개, Place 역할 10개·도착 로딩 291개도 통과했다. [검사 로그](checks.log)
- 기존 종합 검사 두 건은 변경 전 커밋과 수정 후 모두 같은 지점에서 중단됐다. campaign-expansion은 첫 본편 Gold 기대값, campaign-reorder는 구형 시험 프로필의 FV-07 입장 단계에서 발생한 StoryLocked다. 해당 종합 검사의 이후 항목은 미검증이다.
- 다음 담당은 QA다. 게시 서버의 실제 저장 데이터로 재접속한 영웅과 진도가 다른 파티원의 개별 이동, 모바일·패드 실기기 입력을 확인한다.
