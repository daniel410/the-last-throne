# 본편35스토리 자동 전개·네비 유지 · 0.69.6

2026-11-04 · TLT-057/061/062/063/064/065/084 · ENG → QA · 로컬 수정·미게시.

## 원인과 변경

사용자는 Roblox 앱에서 스토리 보상/리뷰 이후 로비 복귀 안내가 나오고 다음 스토리와 네비가 끊긴다고 보고했다. 기존 게시 동작에는 선택한 임무 이외의 목표를 막는 계약이 있었고,0.69.5 로컬 수정에도 Easy·초회·동일 에픽 제한이 남아 있었다. 사용자 최신 지시는 모든 본편 자동 전개이므로 그 제한을 제거했다. 현재 Roblox 게시본의 코드를 직접 읽거나 해당 앱 현상을 재현한 것은 아니다.

- 본편은 난이도·초회/재도전에 관계없이 원정 저널의 다음 스토리로 진행한다. 입장용 원래 임무ID/원정ID는 바꾸지 않아 재접속 티켓과 기존 계정 계약을 유지한다. 다음 스토리 건너뛰기/다른 원정 이벤트는 거부한다. 선택 퀘스트의 개별 임무와 최종35번째 본편 종료는 유지한다.
- 현재 스토리의 실제 영구 완료 기록으로 초회/반복을 판정한다. 재도전 입장→미완료 본편 진입에도 초회 진도/보상을 저장한다. 반복 보상·난이도 완료·강화 재료와 기존 정본 XP/Gold/아이템·Diamonds의 단일 지급 권리를 보존한다. 완료 카드 표시도 입장 임무의 초회 여부 대신 현재 스토리의 초회 여부를 쓴다.
- 서버 확정 메인 진도가 증가하거나 확정 완료 이벤트를 받으면 기존 선택 추적을 해제하고 메인 추적으로 전환한다. 완료 카드의 TRACK NEXT STORY/닫기 버튼에 의존하지 않으며, 저장 상태가 완료 이벤트보다 먼저 와도 네비 목표를 복원한다. 사용자 SETTINGS의 길잡이 표시 설정을 강제로 바꾸지는 않는다.
- 에픽 경계는 기존 지연 월드 생성기를 다음 스토리로 호출해 지역을 추가하고 완료한 영웅만 안전 시작 지점으로 이동한다. 이전 지역/다른 플레이어의 진행은 유지한다. 생성 중 영웅/원정이 바뀌면 이동하지 않는다. 생성 실패는 보상/진도를 되돌리지 않고 재접속 안내를 제공한다. 재접속의 목적지 해석도 저장된 다음 에픽을 생성할 수 있게 했다.
- 메인 완료 카드에서 개별 임무마다 로비로 돌아가라는 문구를 제거했다. 지원권은 현재 스토리마다 종료하고 다음 스토리 캠프에서 명시적으로 재초대하는 기존 계약을 유지한다.
- 프로젝트 제작 스킬 적용. 명확한 결함 수정과 사용자 전개 지시를 따르므로 별도 비교 리서치는 생략했다. 기존 무기/회피/원정 이동 미커밋 파일은 이번 소스/고정 빌드에서 제외한다.
