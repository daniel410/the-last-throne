- FrozenValeContent/FrozenValeWorld/CampaignContent/CampaignStoryText를 대조했다. FV 기본420×380구역과 목표 밀집을 확인했으며 번호/레벨/문구는 현재 Campaign 투영을 우선했다. 최종 월드 전체 면적이나 체감 시간은 측정하지 않았다.
- 공식 Diablo II Act II 퀘스트/맵, Diablo III 2.4.3 패치, Diablo IV 2023년 출시 발표, Roblox 스트리밍 문서를 웹에서 확인했다. 작품/시점/사실/적용 가설을 분리해 리서치에 출처를 남겼다.
- 새 설계/리서치/증거의 상대 링크 존재 검사와 `git diff --check`를 수행했다. 문서 변경에 맞춰 검증했으며 런타임 테스트·빌드는 실행하지 않았다.
