## 검증

- Rojo 7.7.1로 커밋 `b98d06f3`을 고정했다. 단일 Place의 SHA-256과 런타임 모듈 5개의 소스를 빌드 안에서 대조했다. [빌드 기록](build.json)
- Studio 14묶음 253,282건을 통과했다. R6·R15에서 각각 128개 기술, 연속 타격 검사 219건, 네 영웅 효과가 겹친 장면의 붉은 예고선 16개와 피해 숫자를 포함한다. 접촉 방향·귀환 손·마지막 화염 높이·접근 범위를 확인했다. 터치 효과 예산은 Studio의 입력 스텁으로 검증했다. [검사별 결과](studio-results.json)
- 동일한 Studio R15 리그, 카메라와 타격 시점으로 네 기술의 기준과 후보 첫·마지막 타격 16장을 찍었다. 화살 잔광 차이는 같은 거리에서 작게 보이며, 끝점·곡률·두께를 엔진 검사로 확인했다. [전후 비교](comparison.jpg)
- CPU 검사 14,234건을 통과했다. 별도의 순수 Lua 자세 검사와 취소 검사는 두 소스에서 각각 Luau 복합 대입 구문과 누락된 `TargetAssistRules` 스텁에서 중단됐다.
- 별도 적 패턴 묶음은 Edit 모드의 보스 명중 효과 만료 검사에서 중단됐다. Run 모드 재시험은 Studio 연결 시간 초과로 시작하지 못했다. 이 결과는 통과 수에 포함하지 않았다.

후보는 미게시다. QA·ART에서 게시 시험 로비→배틀 이동과 실제 4인 교전의 연속 타격 및 적 예고 판독, 저사양 터치 실기기의 프레임 시간과 사용자 타격감 수용을 확인해야 한다. 상위 티켓은 열린 상태다.
