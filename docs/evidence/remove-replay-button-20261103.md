# 전투 완료 재플레이 버튼 제거

작업: TLT-028/061/084 · ENG · 2026-11-03

사용자 스크린샷의 `PLAY AGAIN · RETURN TO LOBBY` 버튼 제거 요청을 적용했다. `AdventureReplay.luau`에서 버튼 생성·완료 상태 구독·클릭 요청·재시도 타이머를 제거하고 `AdventureText.luau`에서 사용하지 않는 문구를 삭제했다. 서버의 재플레이 요청 속성에 따른 로비 모험창 연결은 보존한다. 기존 MENU의 로비 복귀 버튼은 수정하지 않았다. 원인이 명확한 UI 제거이므로 별도 사례 조사는 생략한다.

검증:

- `lua`에서 실제 모듈을 모의 Players/속성 신호/모험창 브리지로 로드: 전투 중 열림0회, 재플레이 요청 후 로비 진입 시1회, 반복 신호에도 추가 열림0회 PASS. 문자열 모듈 문법 로드 PASS.
- Studio `TheLastThrone-Lobby-0.67.4.rbxlx`의 실행 중 Client에서 `PlayAgain` GuiButton1개를 제거한 뒤 남은 동일 버튼0개 확인. 현재 세션 UI 제거이며 저장된 Place 수정이나 새 빌드 적용을 의미하지 않는다.
- `git diff --check` PASS. 관련 변경만 선별 커밋·푸시한다.

새 게임 빌드는 수행하지 않아 VERSION은 변경하지 않는다. 게시·릴리스 태그 없음. 다음 담당: QA — 다음 빌드의 실제 전투 완료 화면·MENU 복귀·실기기 입력 확인. 게시 클라이언트와 실기기는 미검증이며 상위 티켓은 완료로 변경하지 않는다.
