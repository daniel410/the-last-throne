# TD 원본 기반 왼쪽 로비 메뉴 통일

2026-11-01 · TLT-028/061/084 · DES/ENG → QA · 0.58.18 로컬 시험판·미게시

사용자는0.58.15의 글씨 교정 후에도 TD와 다른 외형을 지적하며 최대한 같게 만들라고 요청했다. 최신 지시에 따라 기존 RPG 전용 은색 사각/네 귀퉁이 보석 프레임을 교체한다. 영웅·퀘스트·지도·다이아몬드 상점은 현재 TD의 실제 원본ID/body crop을 사용한다. TD의 최신 구조는 그림 viewport(.01,0)/(.98,.72)와 동일한 Maps 이름표(.01,.70)/(.98,.30)를 별도 표시한다. 이 구조·자르기·원본 이름표를7개 모두에 적용했다.

포션·대장간·로그인 보상은 TD hero 원본을 참조한 투명 imagegen 아틀라스3개를 제작했다. 새 원본은 은색 상단/금색 하단 프레임이며 runtime에서는 본문만 잘라 TD 공통 이름표를 덧댄다. 생성 글자를 사용하지 않고 기존 en-US 캡션을 실제 TextLabel로 표시한다. 기존 메뉴7개의 순서·아이콘별 기능/안정ID·색상 상호작용을 유지하며 TD 운영 소스는 변경하지 않았다.

글꼴은 TD와 같은 GothamBlack/흰색/검은 외곽선, 하단30% 이름표를 쓴다. 기존 크기 공식에 TD의 기본 x/y 정렬도 적용하되 RPG7번째 행이 화면 아래를 넘지 않게 제한했다. 작은 화면의 긴 상점/보상 캡션은 POTIONS/DIAMONDS/REWARDS로 축약하며 상세창 전체 이름과 기능은 유지한다.

소스/자산 해시는 assets/ui/lobby-navigation-td-v2/manifest.json을 따른다. 실제 업로드 이미지96946740539077은 Image 유형1·사용자9156786071 소유·isPublicDomain=false를 MarketplaceService로 확인했다. ContentProvider에서 신규 이미지/기존 TD 공통 이미지4종 모두 Success, 실제 로비 화면에서 로드 확인. Restricted/협업자/Experience 권한 세부는 독립 확인하지 않았으며 게시 게임 사용 권한 수용은 후속이다.

Studio 로컬0.58.16의 관련 모듈을 이번 소스로 교체해 검증했다. Edit의 기존 아이콘 검사33개,1280×800/750×323/529×323/530×323/390×317 배치 검사285개 통과. 메뉴 순서·TD 셀 크기·전체 제목 수용/최소10px·공통 이름표·그림/이름표 좌표·보상 느낌표·화면 내 배치와 원본ID를 확인했다. 실제 Play에서도 상단 그림과 하단 이름표가 서로 가리지 않으며 일곱 아이콘이 같은 형식임을 확인했다. 최종 소스/VERSION을 고정한 Lobby/Battle 빌드·해시는 build.json을 따른다.
