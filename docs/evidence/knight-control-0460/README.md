# 기사 방패 계열5초 스턴과 몬스터 피격·제어 효과

2026-10-31 · TLT-005/031/032/033/050/057/061/084 · 로컬 시험 구현. 게시/실기기 수용 아님.

사용자 추가 지시로 Shield Bash와 기반 기술에 초기5초 스턴을 적용한다. 기반 범위는 기존 트리의 root1과 명시적 requiresShield 공통 기술이다. Shield Bash1 + 두 계열 파생8 + Driving Thrust/Guarded Strike2 =11개다. 다른 기사 기술·궁극기에 임의로 스턴을 추가하지 않는다. 기존 장착/자격/MP/쿨다운 규칙은 유지한다. 드워프 Ground Slam 계열10개도 유지한다.

실제 피해가 적용된 서버 타격만 스턴을 준다. 보스에도5초, 재타격은 최근 타격+5초 갱신, 동일 타격 중복은 갱신하지 않는다. 준비/활성 공격과 경로 작업을 취소하고 만료/리셋/사망 때 지운다. 기사는 푸른색, 드워프는 금색 별3개가 몬스터 머리 주위를 회전하며 서버 만료 시각에 사라진다. Blender에서 제작한 몬스터 스턴 자세와 카운트다운을 함께 사용한다. 별은 로컬 Attachment/Billboard의 기본 도형 문자로 제작해 별도 업로드/새 외부 자산이 필요하지 않다.

서버의 기존 확정 피해 이벤트에 들어 있는 기술ID로 기사/드워프64개 기술의 피격 효과를 계열별로 연결한다. 방패는 푸른 충격, 내려찍기/지면 강타는 주황 충격·파편, 투척/포격은 해당 계열 형태를 쓴다. 효과는 피해·스턴을 결정하지 않는다. 도발/공격 약화/취약 카운트다운과 기존 도발 강조도 유지하며, 상태 문구는 체력바 위에서 보이도록 높이를 조정한다.

[원천/적용 조사](../../research/2026-10-31-deepwood-monster-motion.md)의 경고·피격 가독성 원칙을 재사용한다. 이 수치/색/범위는 해당 게임의 실제 자산을 복제한 것이 아니라 사용자 요구와 이 프로젝트의 파생 트리로 정한 구현이다.

## 0.46.1 스트리밍 수정

원인은 EnemyVisual의30/10초 일회성 대기와 최초 빈/부분 리그 바인딩이었다. 로비에서 오래 머물거나 멀리 있는 몬스터가 늦게 스트리밍되면 관찰자가 연결되지 않았다. 컨테이너 출현 관찰·하위 파츠 추가 시 재시도·스트림 아웃 시 모터/이펙트 연결 정리를 추가했다. 몬스터가 다시 로드되면 자동 연결한다.

`tests/enemy-streaming-presentation-native.luau`는 늦은 폴더/빈 모델→파츠 도착→표식·곡선 적용→스트림 아웃 정리→재진입을2회 검증해10개 통과했다. 최초 fixture는 카메라를 대상에서260stud 밖에 두어 의도된 거리 생략으로 실패했고, 검토 대상 가까이에 카메라를 놓아 수정했다(최초 로그 보존). 거리 제한을 완화하지 않았다.

메뉴가 열린 실제 [첫 화면](client-stats-first.jpg)에서 render가 제목을 HERO STATS로 되돌리고 지갑이 메뉴 위를 덮는 문제도 확인했다. 최종 제목을 STATS & SKILLS / GEAR & BAG으로 유지하고 두 메뉴에서 외부 지갑을 숨긴다. 최종 키 H/T/B는 유지한다.0.46.0 결과물을 덮어쓰지 않고0.46.1을 별도로 빌드한다. 최종 Client 증거는 후속 절에 기록한다.
