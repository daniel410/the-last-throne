## 변경과 근거

사용자의 에픽 콘셉트·RPG 참고 품질 개선 및 Studio/Blender MCP 사용 지시를 적용했다. Diablo IV 환경 미술과 Guild Wars 2 랜드마크/접근성 설계를 참조하고 승인 Deepwood·Gloamwood·TD snow/volcano/cemetery 보드를 직접 대조했다. [입력 경로·해시](source-references.json).

- Blender MCP의 별도 장면에서 숲 유적, 뿌리·고치, 빙하 군집, 주상절리, 기념묘와 각 지역 지면 소품 등 **10모델·246기본 파츠**를 제작했다. 기존 Hollowbark 장면은 유지했다. Standard/sRGB/Look None/Exposure0/Gamma1/Curves Off, 재질의 sRGB→scene-linear 변환을 적용했다. GLB·제작 스크립트·제작값 JSON·렌더를 보존했다.
- 같은 기하/색/회전을 Roblox 기본 Part/WedgePart로 재현해 외부 메시 업로드 없이44지역에 배치한다. 낮은 식생·돌/얼음·지면 재질 변화, 높이가 다른 TD 원경 실루엣을 추가했다. 최종 디테일 그룹9,511파츠 중2,642개는 실제 충돌을 갖는다. 모델 수와 생성 인스턴스 수는 다르다. 최종 전체 월드 파츠61,573개는 성능 수용 수치가 아니다.
- 신규 지면 패치는 낮은 비발광 장식이다. 큰 조형물은 충돌·쿼리와 기존 경로 재배치에 포함한다. 원경 지형 받침은 전체 지역·사건 구역·연결로의 실제 범위를 피한 곳에만 생성한다. 원래44개 주연 랜드마크·스토리/적/보상/스폰·TD 운영은 유지했다.
- Voxel→ShadowMap, 숲 오후광·지역별 대기 깊이를 조정했다. 첫 후보의 과한 새벽 안개를 폐기하고 밤 지역은 야간 시간대를 유지했다. 새 per-frame 루프/입자/광원을 추가하지 않고 기존 거리 예산을 사용한다.
- Studio 캡처에서 기존 화산 대문이 공중에 떠 있는 결함을 발견했다. 재배치 ray가 `world.terrain` 안의 대문 자신의 상단을 밟는 원인이었다. 실제 보행 바닥/지형만 조회하고, 경사면 양쪽 기둥의 낮은 지면에 맞춰 배치한다. 새16기둥 접지 검사가 이를 확인한다.

## 미검증·다음 담당

이는 실제 맵의 환경 보강이며 콘셉트 그림과 같은 최종 미술 완성을 의미하지 않는다. 넓은 수평 전투장·반복 건축·일부 지역 사이 단면과 기본형 소품은 남아 있다. 스크린샷은 편집 시점이며 실제 전투 UI/VFX·영웅 카메라 조작·실기기 저사양·4인+AI 프레임 시간·게시 자산 권한·사용자 미술 수용은 미검증이다. 기존 일반 이동 감사4물체/2앵커도 후속으로 남긴다. 다음 담당은 QA/사용자의 실제 조작 시점 미술·길찾기·성능 수용이다. 부모 작업/G5/G7은 완료로 바꾸지 않는다.

Roblox 게시·릴리스 태그 없음. 게임 빌드와 별도로 생성 월드가 담긴 편집 검수용 장면을 저장해 Studio에 열어 둔다. 기존 사용자 미커밋 모델/삭제 파일은 스테이징하지 않았다.

최종 일반 이동 감사는 엔진 내 계산을 끝냈으나 MCP 응답이300초 제한으로 시간 초과했다. 로그의 완료 요약과 별도 Studio `_G.TLTPolishTraversalSummary` 읽기를 대조해 위 결과를 확인했다. [캡처·검수 장면 해시/전송 한계](capture-manifest.json).
