# 0.40.4 검·도끼 움직임 2차 개선

2026-10-31 · TLT-005/032/033/055/057/084 부분 구현 · [실제 영상 비교](../../research/2026-10-31-sword-axe-motion-video-review.md)

타격 키포즈마다 멈추던 보간을 기울기를 공유하는 곡선으로 바꾸고, 회복 중 연속 공격은 이전 자세·속도를 이어받는다. 기사 방패/드워프 빈손을 든 전투 준비 자세, 왼쪽 팔꿈치와 머리 보조 회전을 추가했다. 서버/밸런스·원본 모델은 이번 변경에 포함하지 않는다.

## 시각 검토와 재현

`python3 docs/evidence/melee-motion-0404/build-comparison.py`로 `/private/tmp/tlt-melee-comparison-v3.rbxlx`를 생성한다. 기준은0.40.3 커밋 `4d24560`이며 같은 Studio Player의 적용 외형을 복제한 R15 네 명에 실제 TD 검·방패·도끼와 생산용 장착 코드를 사용한다. 아바타 외형 위에 현재 클래스 색을 적용한 장면이며 별도 완성 영웅 갑옷/드워프 체형을 새로 만들지 않았다. 비교 UI는 게임 빌드에 포함하지 않는다.

Studio Play에서 반복 공격과 준비/접촉/회복 자세, 전후 카메라를 확인했다. 수정판의 무기가 타격 뒤 전투 준비 자세로 남고, 드워프 빈손이 들린 상태로 몸통과 함께 회전하는 차이를 확인했다. 키1/2/3/4/5는 준비/접촉 전/접촉/접촉 후/회복, C는 기사 타수, V는 카메라, F는0.65/1배, Space는 재생이다. 입력은 실제 전투 대신 동일한 합성 서버 상태를 양쪽에 공급한다. 정상 게임의 이동·판정·입력 수용과 구분한다.

초기 장면은 LocalScript 옆 Folder가 PlayerScripts에 복사되지 않아 시작에 실패했다. 모듈을 LocalScript 자식으로 옮겨 재생을 확인했고 생성기도 수정했다. 기존 원본의 `203785492` 자산 유형 경고는 남아 있다. 정면 카메라는 네 캐릭터가 들어오도록 중앙 위치로 보정했다.

전방 운동학 검사는 실제 Roblox 관절·원본 무기/방패를 사용하지만 GPU/정상 Player 입력 검사가 아니다. 검날 중심선과 방패 OBB 검사는 모든 메시 삼각형 사이의 비관통을 보증하지 않는다. 원본 자산 유형 경고는 로그에 보존했다. 새 서버 전투 변경은 없으며 이전0.40.3의933개 전투 서비스 검사를 이번 결과로 다시 세지 않는다. 0.40.4는 로컬 미게시 빌드이며 릴리스 태그는 만들지 않았다.
