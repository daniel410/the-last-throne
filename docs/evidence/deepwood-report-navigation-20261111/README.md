# Eryn 보고 복귀 스턱 수정

2026-11-11 · TLT-031/050/057/061/084 · ENG → QA · 0.102.9 · 미게시

사용자는 모바일 화면에서 `MAIN STORY 7 / 7 · REPORT TO ERYN` 상태의 추가 스턱을 보고했다. 정확한 좌표·실행 버전·튕김 여부는 제공되지 않았다. 최신 게시 버전0.102.8을 격리 호스트로 삼아 같은 보고 단계의 결함을 재현했다. 현재 게시 클라이언트에는 `M → ERYN → TRAVEL`의 기존 서버 승인 이동이 임시 우회로다. [조건/재현 좌표](baseline.json).

## 이전 검수의 빈틈과 원인

[이전171경로 검사](../deepwood-boundary-stuck-20261111/README.md)는 `PathfindingService`가 찾은 독립 경로를 검사했다. 실제 금색 화살표의 경로와 `DeepwoodRegionAccess`를 함께 실행하지 않았다. 이를 전체 플레이 통과로 해석할 수 없다.

- 이전 클라이언트는 사건 공간의 연결 경사로만 우회했다. 다른 일반 구역의 NPC로 보고할 때에는 직선을 가리켰다. DW-07의 `separate` 마지막 위치에서 Eryn까지2점 직선의201표본 중70개가 서버의 통행 영역 밖이었다.
- 맵 확장 후에도 `DeepwoodGroundedWorld`의 옛 연결 바닥/경사로가 남았다. 실제 바닥50.67205와 서버 기준52.69521이 어긋난 위치에서는 루트 높이를3으로 둬도 서버의 최소53.69521보다 낮아 되돌림이 발생했다.
- 새 경로를 실제 R15로 걸으면 연결로 끝을 비껴 지난 좌표에서 화살표가 끊겼다. 구역 경계만으로는 분류하지 못하는 연결로 끝부분을 포함해야 했다.
- 모바일 HUD의 긴 보고 안내가 잘려 지도 이동 방법이 보이지 않았다.

## 변경

`CampaignNavigationRoute`는 같은 에픽의 실제 구역 연결망과 `CampaignBounds.ends`를 따른다. 구역 안의 사건 경사로 안내는 유지하고, 연결로 중간/끝에서 진행 방향이 뒤집히거나 끊기지 않게 한다. 에픽 간 이동을 육로 지름길로 만들지 않는다. 길의 바닥이 스트리밍되지 않았을 때의 첫 화살표도 최종 NPC 직선 대신 다음 연결 지점을 가리킨다.

실제 월드도 같은 경계 좌표로 `JourneyPass` 영구 바닥을 생성한다. 대체된 옛 경사로/바닥은 물리·쿼리·외형을 함께 정리한다. 지역 간 보고 경로10개의 실제 안내 선분을 `RegionalReturnTrail`로 표시하고 Terrain·기존 나무·새 미술 배치에서 공간을 예약한다. 나무는 외형과 충돌체를 함께 이동한다. 서버 통행 제한·접근 조건은 완화하지 않는다.

모바일 보고 안내는 `Open MAP [M] and travel to ERYN, or follow the gold trail back.`로 줄였다. 보고 목표·진행 조건·보상·저장·클래스/장비·TD 운영은 바꾸지 않았다.

## 빌드·중간 실패·남은 수용

최종0.102.9 입력 `d88ca008c7ab3cca47e8cd079062ae90267349b8`, SHA256 `4e28670a0a5901b9086a7cbae5dbdf844da162b2b483ec8b43de1781206e2f59`. [빌드](build.json)·[역할10/도착 로딩192/산출물 검사](artifact.log). 같은 단일 파일을 사용하는 로비/배틀 계약을 유지한다. Roblox 게시·릴리스 태그는 만들지 않았다.

초기 경로/경사로·나무·연결로 끝의 물리 보행 실패는 각 `preview*.log`에 보존했다. 연결로 시험에서는 마지막 선택 구역에 main6으로 진입해 정상적으로 접근이 거부된 조건과, 표시된16stud 길 밖의±12stud 지점까지 검사한 결과를 구분했다. 최종 해금 조건/보행 폭을 적용하고 기존 몸체 검사 기준인 지면 위3.7의 중심을 사용했다. 실제 점프 없는 물리 보행을 별도로 추가해 표본 겹침만으로 보행 가능을 선언하지 않는다.

하네스의 Unicode 이스케이프와 반환값 없는 기존 미술 검사 처리 오류도 중간 로그에 보존했다. 게임 결함과 구분해 UTF-8 문자열 생성/반환형 검사로 수정했다. 단축된 안내에 맞춰 기존 HUD 문구 검사의 기대 의미도 지도와 ERYN 대상 안내로 갱신했다. PlaceId0 시험의 자산 요청 경고는 시각/권한 수용 통과로 간주하지 않는다.

모바일 터치·실계정 저장/재접속·게시된 새 서버에서의 정상 전투/보고 완료는 미검증이다. 시험용 R15는 실제 계정/장착 영웅의 실기기 수용을 대체하지 않는다. 이전 다른 지역의 잔여 진단도 이번 기하 회귀로 닫지 않는다. 다음 QA는 게시 후 새 세션에서 같은 보고 단계의 화살표·도보 복귀·M/포탈 이동·Eryn 보고와 다음 모험 연결을 확인한다. 상위 티켓 전체를 Done으로 바꾸지 않는다.
