# 안전한 필드 스킬 장착·직선 방향 안내

2026-10-31 · TLT-013/028/042/052/054~056/061/084 부분 수정 · ENG → QA

## 원인과 변경

사용자는 새 스킬이4번째 슬롯에 장착되지 않고 도로 경유 네비게이션이 돌아가도록 안내한다고 보고했다.

- Lv5/10의4/5슬롯 개방 및 Lv5/10/15 신규 공통 기술 학습 자체는 정상이다. HeroSkillTree와 InventoryService/InventoryRules가 스킬 편성을 거점 전용으로 제한해 모험 중 새 기술을 장착하지 못했다.
- 스킬 장착을 기존 포인트 투자와 같은 서버 안전 판정에 포함했다. 적 근접/최근 전투 상태에서는 거부하며 안전한 필드에서 장착할 수 있다. UI도 같은 snapshot.canInvest를 따른다. 실제 저장 시 영웅/생명 세대·안전을 다시 확인하는 기존 서비스 계약을 유지한다.
- 전직은 계속 거점 전용이다. 스킬 레벨·계열·궁극기 전용 버튼·중복 편성 방지·쿨다운·SP 계약은 변경하지 않았다. 영어 안내도 필드 장착 허용에 맞게 수정했다.
- 네비게이션의 지역 중심 그래프/다리 경유점을 제거했다. 현재 위치→실제 목표의2점 직선이며 매 프레임 갱신한다. 지면 투영 화살표·목표 도착 표시·설정 ON/OFF·사망/훈련 중 숨김은 유지한다. 직선은 목표 방향을 뜻하며 장애물 회피 경로를 보장하지 않는다.
- 지면 목록은 지형 추가/제거 시 갱신한다. 플레이어 이동 때마다 전체 지형을 재탐색하던 처리는 제거했다.

요청한 두 결함의 구체적인 재현/수정이며 별도 게임 기능·밸런스 리서치는 추가하지 않았다. 다른 진행 중 Blender/근접 모션 작업은 편집/커밋/검증 입력에서 제외했다.

```text
run-in-roblox --place builds/0.41.1/TheLastThrone-Battle-0.41.1.rbxlx --script /private/tmp/tlt-skill-nav-native.luau
run-in-roblox --place builds/0.41.1/TheLastThrone-Battle-0.41.1.rbxlx --script /private/tmp/tlt-direct-nav-toggle-native.luau
```

원시 결과: [native.log](native.log), [navigation.log](navigation.log). 기존203785492 자산 유형 경고를 보존했다. 최초 안내 검사는 지도 버튼 높이를44px로 가정한 오래된 검사가 실제40px에서 실패했다. 안내 방향/표시 검사는 이미 통과한 상태였으며 제품 버튼을 변경하지 않고 검사를 현재40px 이상 기준에 맞췄다. [최초 실패](navigation-first-failed.log).

[sources.json](sources.json)은 최종 수정 소스 해시다. 네이티브 검사 후 WaitForLobby의 영어 문구만 거점 복귀/영웅 선택으로 명확히 했으며 동작 코드는 추가 변경하지 않았다.

## 미검증과 다음 담당

Player/안전 상태·저장소는 검사별 대역이며 실제 계정의 저장/재접속, 게시 클라이언트, 모바일/패드 조작, 사용자 직선 안내 수용은 후속이다. 다음 QA는 Lv5 이상 영웅으로 전투 종료 후 HERO→SKILLS에서 새 기술→4번 슬롯을 선택해 저장/실제4번 입력 사용과 재접속 유지를 확인한다. 전투 중 변경 차단, 이동 중 목표 직선 갱신, 고저차/바위 뒤 목표의 방향 가독성도 확인한다. 상위 티켓은 미완료로 유지한다.
