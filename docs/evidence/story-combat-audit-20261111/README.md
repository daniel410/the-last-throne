# 다섯 Epic 스토리 전투량 검사

2026-11-11 · TLT-061~065/combat-audit · ENG/QA · 정적 검사 완료, 플레이 수용 미검증

사용자 요청: Gloamwood 스토리1의 전투바 누락 확인, Deepwood와 전투량 비교, 다른 Epic 검사.

## 범위와 재현

최종 런타임 `CampaignContent`의35본편/12선택 전부를 읽고 서버와 같은 `EncounterPopulation.encounterWaves`로 솔로/4인 편성을 집계했다. [검사 도구](../../../tools/audit-story-combat.lua), [47장 원자료](census.tsv). 실행은 저장소 루트에서 `lua tools/audit-story-combat.lua`다. 게임 콘텐츠·UI·보상·저장·VERSION·게시 상태는 변경하지 않았다. 신규 기능/밸런스 설계가 아닌 현황 검사이므로 외부 게임성 조사는 수행하지 않았다.

`battle_goals`는 적이 있는 목표 수, `solo_packs`는 솔로 실제 무리 수다. 기존 동선 문서의 ‘교전 위치 최대’는 파티별 최대 수용 공간으로 솔로 실제 교전 수와 다르다. `activity_steps`는 적 없는 목표의 단계 수(단계 배열이 없으면1)이며, 플레이 시간·버튼 입력 수·필수 단계만의 수는 아니다. 선택 분기와 단계별 거리를 시간으로 환산하지 않았다. 적 수는 일반/보스와 서버가 추가하는 호위병을 포함한 기본 유한 편성이며 별도 보스 HP 이벤트 소환 수는 제외한다. 기존 동선 문서와 같은 집계 기준이다.

## 확인 결과

각 Epic 본편7장만 비교했다. 선택 퀘스트의 적을 본편 수치에 합산하지 않았다.

| Epic | 전투 목표 | 솔로 무리 | 솔로 적 | Deepwood 대비 적 수 | 비전투 단계 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Deepwood | 19 | 61 | 284 | 100% | 103 |
| Gloamwood | 10 | 19 | 154 | 54.2% | 58 |
| Frozen Vale | 12 | 37 | 200 | 70.4% | 62 |
| Ember Caldera | 11 | 32 | 206 | 72.5% | 64 |
| Haunted Graveyard | 12 | 21 | 160 | 56.3% | 57 |

**Gloamwood의 전투 부족은 데이터로 확인된다.** 적 수는 Deepwood보다45.8%, 솔로 무리 수는68.9% 적다. 특히 GW-01/02는 전투 목표가 각각1개뿐이고, 둘 다 초반 전투18마리/2무리 후 비전투8단계를 마치고 끝난다. GW-03은 구조/거점 장으로 전투가 없어, 초반3장의 전투 합계는36마리/4무리다. 같은 Deepwood 초반3장은54마리/20무리다. GW-01의 진행 순서는 다음과 같다.

`maeve(대화1) → trail(전투18/2무리) → exp_1(조사3) → marks(조사1) → exp_2(이동3) → lantern(상호작용1)`

비교 DW-01은 `전투12 → 비전투6단계 → 전투18 → 비전투7단계`이고 총12무리다. Deepwood는 더 작은 무리로 자주 교전한다. 따라서 ‘적이 조금 적다’ 외에도 **교전 빈도와 장 후반 배치 차이**가 체감 원인으로 추정된다. 시간/재미를 실측해 확정한 것은 아니다.

다른 Epic 검사 결과:

- **Haunted Graveyard:** 본편 적160/21무리로 Gloamwood와 비슷하게 적다. HG-04~06은 각각3무리이며 HG-06은 보스/호위 포함19마리다. 최종 지역 전투 강도/플레이 시간 별도 검토가 필요하다.
- **Ember Caldera:** EC-05는 전투18마리/2무리 직후 비전투9단계로 끝나 GW-01/02와 같은 배치 문제가 있다. EC-03도 마지막 전투 후 비전투9단계다.
- **Frozen Vale:** 본편200마리/37무리로 상대적으로 빈도가 높다. FV-06은 전투 사이 비전투8단계가 있다. 지역 전체의 전투가 누락된 상태는 아니다.
- **Deepwood:** 전투량 기준선이지만 DW-04/06/07도 마지막 전투 뒤 각각11/10/14단계가 남는다. 후반 공백은 다른 Epic만의 문제가 아니다.
- **거점/비전투 장:** DW-03, GW-03, FV-02, EC-02, HG-02와 선택 FV-Q1/EC-Q1은 적0이다. 기존 거점/서사 역할이며 전투 스폰 실패로 판정하지 않는다.
- **선택 콘텐츠:** Deepwood4장은 합계183마리인 반면 FV/EC는 각각21마리다. GW/HG에는 현행 선택 장이 없다. 본편 외까지 비교하면 전투량 격차가 더 크다. 미구현 선택 후보를 실제 콘텐츠로 세지 않았다.

## 전투바 표시 검사

`src/client/BattleController.luau`의 `updateSessionView`는 `K0SessionPhase`가 `Tutorial` 또는 `Respawning`이면 HUD를 활성화한다. `src/client/K0Hud.luau`의 `setVisible`은 하단 액션 GUI와 상단 HUD를 함께 켠다. Gloamwood/Epic/현재 목표가 비전투라는 이유로 하단 전투바를 숨기는 조건은 없다. 따라서 **이동/대화 단계이므로 전투바가 없어도 정상이라는 설명은 코드와 맞지 않는다.**

두 연결 Studio가 모두 `Place is not open`이어서 실제 사용자 화면·세션 phase·GUI 생존 여부·다른 화면의 가림·클라이언트 오류·게시 빌드 일치를 확인할 수 없었다. 전투바 누락의 실제 원인은 미확정이며, 소스 검토만으로 수정 완료라고 보고하지 않는다. 사용자 플레이를 중단하거나 다른 Place를 열지 않았다.
