## 변경·근거

[사용자 결정](../../decisions/2026-11-14.md)과 [영상·Diablo/WoW 비교](../../research/2026-11-14-dwarf-three-hit-basic.md)에 따라 기본 공격을 내려베기→되받아베기→넓은 마무리 베기의3타로 구성했다. 기존 TLT 소유 Mixamo 파생 클립을 재사용하며 공통 기술 클립/원본은 수정하지 않는다. 후속 타격만 얕은 복사한 클립 메타데이터로 전방 몸통 회전을 보정한다. R6/R15 체형별 보정과 준비/복귀 곡선을 적용하며 기존 손 소켓/서버 루트는 유지한다.

서버의 기존 공통 콤보 처리가1→2→3→1을 승인한다.0.6초 이탈 초기화·입력 버퍼·동작 시간 제한·DEX공속·타격당 중복 방지·거리/높이/벽 검사는 유지한다.0.80/0.68/0.92초, 합계2.40초로 기존 평균0.80초를 유지하고 각 시간에 비례한 피해로 기존 지속 피해 예산을 보존한다. 기본 자세 피해는12/10/14, 합계36으로 기존3회 예산과 동일하다. 모두 기존 사거리5.5·각도100·최대3대상·높이7이다. 기사의 기본 공격과 공통 기술의 시간/피해는 변경하지 않는다.
