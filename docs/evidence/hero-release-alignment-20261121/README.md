# 네 영웅의 공격 방향과 방출 자세

TLT-033/057/059 · 2026-11-21 · 기준 0.115.35 · 후보 0.115.37 · ENG·ART → 전투 QA

[공식 사례 조사](../../research/2026-11-21-hero-release-alignment.md) · [고정 빌드](build.json) · [검사 결과](studio-results.json) · [R15 Studio 전후 화면](release-comparison.jpg)

| 영웅 | 기술과 변화 |
| --- | --- |
| Knight | **Crescent Cut**은 방패 쪽에 무게를 모은 뒤 몸통을 회전한다. 한 줄의 검호가 좌우로 퍼지며 높이가 낮아진다. 부채꼴 경계와 검호가 같은 공격 방향을 사용한다. |
| Dwarf | **Braced Throw**는 오른쪽 무릎을 접어 버틴 뒤 반대쪽 다리로 무게를 옮긴다. 도끼 잔상이 무기에서 좁은 직선으로 뻗고 기존 도끼가 끝에서 회전한다. |
| Elf | **Retreating Shot**은 뒤쪽 다리로 후퇴 반동을 받아 내고 당기던 손을 바깥으로 푼다. 활에서 확정된 끝점까지 잔상 한 줄을 쓰며 화살 모양을 유지한다. |
| Mage | **Thunder Spear**는 지팡이를 뒤로 감았다가 유도 팔을 펴며 방출한다. 전격은 지팡이 끝에서 출발하고 끝부분의 돌기가 창 형태로 모인다. |

부채꼴·근접 효과는 각 펄스의 서버 방향을 받는다. 폭발을 동반하지 않는 직선 기술의 시각 종점은 서버에서 펄스 원점과 사거리로 계산하고 벽이 있으면 앞에서 멈춘다. 원래의 판정 대상, 피해 적용 순서와 시점을 따른다. 짧은 거리나 소켓 로드가 늦은 경우 기존 원점과 대체 형상을 사용한다.

## 검증

- 기준 0.115.35에서 방향·벽·무기 소켓·자세 검사 26건 중 18건이 실패했다. [첫 후보 0.115.36](build-0.115.36.json)에서는 네 건이 남았다. 기존 베기 회전을 줄이는 보정의 방향을 바꾸고 투척 준비의 오른쪽 무릎을 더 굽혔다. 최종 0.115.37에서 26건을 모두 통과했다.
- 동일한 R15 리그·TD 장비·조명·카메라에서 기술별 방출 직후 자세와 효과를 비교했다. 주황색 바닥 표식은 동일한 종점 또는 선택 표적을 표시한다. 장면을 멈춰 윤곽을 비교했으며 실제 프레임 시간 측정은 실기기 수용 항목이다. [전후 화면](release-comparison.jpg)
- Studio 13묶음 259,271건을 통과했다. 128개 기술의 R6/R15 동작과 이펙트, 아군 피격이 몰릴 때의 우선순위, 여덟 궁극기와 기존 확정 타격을 포함했다. CPU 15,147건을 통과했고 고정 빌드의 SHA-256과 변경 모듈 8개를 입력 커밋과 대조했다. [묶음별 결과](studio-results.json)
