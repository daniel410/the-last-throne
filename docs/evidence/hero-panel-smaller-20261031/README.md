# 영웅 선택창 추가 축소

- 작업: 사용자 요청에 따른 로비 UI 조정 (별도 백로그 ID 없음).
- 변경: 영웅 선택창 최대 크기를 1100×660에서 900×560으로 줄이고 작은 화면의 좌우 여백을 늘렸다. 기존 카드 스크롤과 지갑 상단 여백을 유지한다.
- 검증: Studio의 로컬 0.43.2 로비 플레이 세션에 변경값을 임시 적용해 네 영웅 카드, 선택 버튼과 지갑이 보이는 화면을 확인했다. 해당 세션의 선택창 크기는 900×560이었다.
- 제한: 다른 화면 크기와 실기기 시각 수용은 미검증이다. 게임 빌드와 게시는 수행하지 않았다.
- 다음 담당: QA/사용자가 실기기에서 배치를 확인한다.
