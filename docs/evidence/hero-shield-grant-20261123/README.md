2026-11-23 · TLT-033/057/059 · 기준 0.115.53 · 최종 후보 0.115.55

| 영웅과 기술 | 준비·회수와 명중 |
| --- | --- |

보호막 기술 13개는 시전 승인 시 실제 수혜자에게 방패·성광·돌·깃·잎·얼음·불·비전 중 해당 형상의 곡선 두 개를 표시한다. 파티 보호막 6개는 서버가 거리와 시야 조건을 통과시켜 적용한 영웅을 전송한다. 같은 수혜자에게 새 보호 표시가 겹치면 새 곡선으로 교체한다. 본인 효과는 0.40초, 타인 효과는 0.30초이고 양쪽 모두 기존 효과 예산을 사용한다. 공격 명중 때 시전자 발밑에 생기던 공통 보호막 원은 제거했다. Arcane Ward의 지속 보호막과 서버의 피해·보호량·지속·기존 수혜 조건은 유지한다. [공식 사례 조사](../../research/2026-11-23-hero-shield-grant.md)

## 검증

- 0.115.53과 0.115.54의 고정 Place에서 같은 R15 검토 리그와 카메라로 보호 부여 한 장면과 네 기술의 명중을 비교했다. 시전자와 실제 수혜자에게만 보호 획이 나타났다. 뒤쪽에서 본 일부 명중 획이 본체에 묻혀 0.115.55에서 적의 피격면 앞으로 옮기고 폭과 곡률을 올렸다. [0.115.53과 0.115.54 화면](hero-shield-comparison.jpg)
- Studio에서 생산용 기술 시작 함수의 이벤트를 실제 클라이언트 렌더러에 넘겼다. 벽·거리·사망·자기 보호·다중 보호·시전 재시도·지연·수혜 모델 제거 및 R6/R15 관련 자세를 확인했다. 기준은 139건 중 72건 실패, 0.115.54는 139건 통과했다. 128개 모션·명중, 파티 VFX 우선순위와 Gunner 타이밍을 포함해 0.115.54 Studio 14묶음 246,607건을 통과했다. [재현 검사](../../../tests/hero-shield-grant-native.luau) · [실행 결과](studio-results.json)
- 0.115.55는 고정 소스에서 단일 Place를 빌드하고 변경 모듈 5개를 소스와 바이트 단위로 대조했다. Luau 6파일을 구문 검사했고, 최종 명중 형상 4종은 Luau에서 획당 5시점의 선폭·곡선·피격면 쪽 좌표를 확인했다. CPU 전직·스킬 효과·Place 역할 14,077건이 통과했다. [고정 빌드 및 해시](build.json)

## 남은 수용

0.115.55의 전체 Studio 재시험은 실행기 연결에서 지연 또는 시간 초과가 발생했다. 화면 캡처 재시도는 로컬 자산 로드에서 멈췄으며, 별도 Studio 4클라이언트 시험은 시뮬레이션 시작 전에 실행기가 시간 초과됐다. 후보는 미게시다. 전투 QA가 최종 후보의 동일 카메라를 재확인한 뒤 게시 테스트에서 로비→배틀, 4인 연속 교전의 적 예고·보호 판독, 저사양 터치 장치의 프레임 시간과 사용자 타격감 수용을 확인한다.
