# Hard 개방·보상 리뷰

2026-11-13 · TLT-027/028/050/084 · ENG/PLAN → QA. 소스 구현·순수 Lua 검증, 미게시. 상위 티켓/게이트 완료로 처리하지 않는다.

## 변경과 근거

사용자 지시로 Hard의 같은 임무 Easy 완료 조건을 제거한다. 공통 Difficulty.allowed를 쓰는 솔로·파티·도착/재접속에 적용한다. 이야기 선행·비전투 임무 제한·영웅 소유/준비·원정 검증은 유지한다. Insane은 같은 임무 Hard 완료, Hell은 Insane 완료가 필요하다. 레벨 제한 없음·적/보상 배율·저장된 전투 규칙1~14는 유지한다. 현재 입장 조건만 변경하므로 규칙 버전은14 그대로다.

Hard를 처음 선택할 수 있게 되면서 확인한 결함도 수정했다. 기존 AdventureRules의 첫 이야기 완료는 Economy.story에서 Easy 몫3 Diamonds를 지급하고, 원정 완료에서 Hard 몫3개를 추가 지급했다. 변경 전 순수 Lua 재현: `Hard first clear: Diamonds=6, Easy receipt=true, Hard receipt=true`. 서버 원정 난이도를 첫 이야기 지급에 전달해 실제 완료 모드에만 지급한다. 재로드 보충 로직도 Hard 원정 완료를 Easy 완료로 추정하지 않도록 한다. 일반 이야기 호출은 기본 Easy를 유지하고, 이전 계정 영수증/보유 잔액은 보존한다.

## 보상 리뷰

## 검증·다음 담당

[실행 로그](tests.log)는 순수 Lua 검사다. Hard 선행 없음·전 전투 임무·스토리 거부·비전투 제한, Insane/Hell 선행 유지,4인 투영·버전1~14 재접속·출발·전투/보상 회귀를 확인한다. 추가 회귀는 Easy 미완료 영웅의 Hard 최초 완주3 Diamonds, 재시도/재로드/반복 무중복, 나중 Easy 완료의 별도3 Diamonds와 계정 유효성을 확인한다.

검사 결과: hard-unlock 56, difficulty-level-free 633, expedition-presentation 24, expedition-departure 42, difficulty-balance 2,665, difficulty-diamonds 3,180, all-epic-diamonds 1,099로 **7,699건 통과**. `git diff --check` 통과. 추가 quest-completion-rewards는84행의 `D.version==13` 단정에서 실패했다(현행14). 변경 전 HEAD의 네 런타임 모듈을 /tmp로 추출해 같은 실패를 재현했다. 이 종합 검사의 전체 통과를 주장하지 않는다.
