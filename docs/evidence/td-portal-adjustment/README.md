# TD 포탈 조정 · TLT-060/084

TD 관문의 직사각형 면을 석조 원형 프레임, 금색 테두리와 중첩된 보라/파랑 발광 면으로 교체했다. 기존 F / ButtonX / 터치 입력과 서버 이동 경로를 유지한다. 공통 프롬프트는 기존에도 키 코드 이름을 출력하고 글자 자동 현지화를 껐으며, 이번에 BillboardGui에도 자동 현지화 비활성을 명시했다. 기존 소스에서 한글 키 표시 재현은 확인하지 못했다.

검증: `git diff --check` 및 소스 구조 확인. `tests/lobby-landmarks-native.luau`에 TD 관문의 키·수직 원형 면·프레임·접근 검사를 추가했으나 실행하지 못했다. 현재 Studio는 기존 0.58.4 플레이 세션이므로 중단하거나 변경하지 않았다. 새 빌드·Studio 시각 확인·한국어 입력기 실제 표시·터치/패드·기기 성능 및 게시된 Experience 이동은 미검증이다. QA 담당자가 격리 빌드와 실제 클라이언트에서 확인한다.
