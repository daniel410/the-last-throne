# 고해상도 로비 아이콘 그림·이름판 간격 수정

작업: TLT-028/031/052/084 · ENG · 2026-11-03

사용자 스크린샷의 고해상도 로비 아이콘 분리 현상을 수정했다. TD `LobbyHomeUI.navigationMetrics`의 고해상도 세로 확장과 현재 RPG의 동일 크기 규칙을 대조했다. 그림(.72 높이)과 이름판(.30 높이)이 각각 `ScaleType.Fit` 중앙 정렬로 그려져, 세로로 긴 셀에서 두 영역의 내부 여백이 합쳐졌다. 원인이 명확한 레이아웃 결함이므로 별도 사례 조사는 생략했다. 프로젝트 제작 스킬과 기존 공통 UI 계약을 적용한다.

변경:

- `LobbyNavigationArt.layout`에서 원본 크롭 비율로 그림 높이를 맞추고 그림 영역의 하단에 붙인다. 이름판도 원본 비율로 높이를 맞추고 기존 Y=.70 시작점에 붙인다. 두 영역의 기존 .02 겹침은 유지한다.
- 캡션을 실제 이름판 높이에 맞추고 버튼 크기 변경 시 재배치한다. 파괴 시 크기 구독을 해제한다.
- TD 원본 이미지·버튼 크기·열/행 간격·순서·문구·기능은 유지한다. 기존 미커밋 작업과 VERSION은 편집하지 않았다.

검증:

- `tests/lobby-navigation-grid-native.luau`에 3840×2160, 2560×1440, 1920×1080, 1500×900, 1499×900을 추가했다. 기존1280×800 및 모바일4조건까지10조건을 검사한다.
- Studio `tlt-epic-art-candidate.rbxlx` Edit / PlaceId0·플레이어0에서 Client 모듈 복제본으로 실행했다. 수정 전 첫4K 조건에서 `Heroes picture has no bottom fit padding` 실패를 재현했다. 수정 소스 주입 후 그림·이름판 접합/내부 맞춤 여백/캡션 위치·높이와 기존 크기·경계·문구·원본·순서 검사 **880 PASS**. 시험 GUI와 복제본은 정리했다.
- 실행 중 `TheLastThrone-Lobby-0.67.4.rbxlx` Client의 기존 로비 아이콘에도 동일 배치 함수를 적용했다. Heroes 그림 하단131.12 / 이름판 상단127.70으로3.42px 겹침, 캡션/이름판 높이34px 일치. 당시 전투 화면이 표시되고 로비 UI는 숨겨져 있어 이를 로비 화면 육안 수용으로 보고하지 않는다. 이 적용은 현재 세션만의 변경이다.
- `git diff --check` PASS. 관련 파일만 선별 커밋·푸시한다.
