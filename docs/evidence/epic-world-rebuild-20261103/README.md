기존 Part 콜라이더·목표/NPC·스폰·보상·안정ID·전투 동작은 유지한다. Terrain은 전투/스폰/프롬프트/연결로와 실제 기존 전망대/램프 발판 주변을 비운다. 모든 새 장식 Part는 비충돌·비쿼리·비터치다. HG 포털은 원래 TD ForestKit의 실제 메시를 사용하며 기존 캐리어/서버 저널키는 유지한다. 포털/심장 시각 모델의 모든 Part에도 숨김 키를 붙여 늦은 스트리밍과 개인 진행 전환을 따른다. Gloamwood 몬스터 임시 모델은 기존 사용자 지시대로 교체 대상으로 남는다.
