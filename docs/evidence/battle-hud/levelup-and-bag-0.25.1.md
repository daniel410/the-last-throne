# 가방·물약·레벨/XP·마나 회복·레벨업 효과

2026-10-29 · ENG/QA · TLT-004/028/043/052/084 부분 범위 · 최종 로컬0.25.1

## 변경과 최신 계약

- Hero Bag의 `Search Items` 생성/검색 필터를 제거했다. Sort는 기존 Organize 동작/표시 위치를 유지하고 Name↔Level로 전환한다.
- Small HP/MP 원본 이미지는 그대로 두고 아틀라스 여백을 줄여 약14% 확대했다. HP crop은 `(16,832,224,208)`, MP는 `(16,1072,224,232)`이며 이웃 셀/그림을 자르지 않는다. 대체 도형의 Small만0.46→0.53으로 확대했다. 글자 배경 투명·가운데 정렬, 다른 크기/회복량/수량은 유지한다.
- HP 패널 헤더에 `LV 1   xp 10/1000` 형식으로 표시한다. 값은 서버의 현재 XP/다음 레벨 필요 XP이며 예시1000으로 곡선을 바꾸지 않았다. 최고 레벨은 `xp MAX`다. 0.25.0 실제 화면에서 하단 XP와 자원 테두리 겹침을 발견해0.25.1에서 y19의 헤더 안쪽으로 옮겼다.
- MP는 HP와 같은 **최대치의 초당0.1%**다. MP100이면0.1/초,80이면0.08/초다. 시전 후1초 지연·사망/생명 검증·최대치 clamp·프레임당 dt상한0.25초를 유지한다. 물약 회복량은 바꾸지 않았다.
- **확정 성장의 레벨이 실제 상승할 때만 HP와 사용 가능한 MP를 새 최대치까지 채운다.** 같은 레벨 장비/스탯/저장 재조회는 회복/효과를 반복하지 않는다. 한 번에 여러 레벨이 올라도 한 효과로 합친다. 죽은 생명을 부활시키지 않으며 다음 정상 소환은 기존처럼 최대 자원으로 시작한다.

## TD 원본 재사용

TD 로컬 `EffectsFactory.towerUpgrade` 함수와 `TOWER_UPGRADE_EFFECT` 튜닝을 확인하고 RPG `HeroLevelUpEffect.play`로 부분 재사용했다. 금색 상승 링8개·흰색 chevron 막대4개,0.22초 Highlight,28개 기본 sparkle입자,1.3초 유지 및 최대 동시4개다. 캐릭터 제거/중복 효과 교체/시간 만료 시 정리하며 전투 충돌·쿼리·게임플레이 권한은 없다. 서버가 확인한 레벨 증가 뒤 호출한다.

[원본 SHA·현재 TD HEAD·변형 범위](../../../assets/shared/td-level-up-effect/manifest.json), [공유 레지스트리](../../../assets/shared/td-asset-registry.json)에 기록했다. TD 원본은 읽기만 했고 수정/게시하지 않았다. 로컬 작업 파일이 배포 TD와 같다고 주장하지 않는다. 새 이미지·외부 업로드 없이 기존 내장 particle texture를 사용한다.
