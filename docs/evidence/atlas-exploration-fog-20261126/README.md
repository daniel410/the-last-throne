# 원정 지도 미탐험 표시

2026-11-26 · TLT-028/084 · 0.117.9 후보 · ENG → 릴리스/QA

Gloamwood를 비롯한 전체 지도와 지역 상세에서 기존 미탐험 셀의 불투명도가 3~7%라 촬영본 정보가 거의 그대로 보였다. 영웅별 탐험 셀, 잠금 구분과 길 안내를 유지하는 [기존 결정](../../decisions/2026-10-29.md#2026-10-29-성장-투자확장-스토리지역-잠금탐험-지도거리-처리)에 맞춰 표시 대비를 높였다.

- 탐험 기록이 없는 지역은 촬영본 전체를 어둡게 표시한다. 잠긴 미방문 지역은 더 어둡게 표시한다. 원본 텍스처와 기본 보안 설정의 그라데이션 렌더러 모두 적용된다.
- 일부를 탐험한 지역에서는 기존 12×12 탐험 격자에 안개를 표시하고 기록된 칸을 원본색으로 드러낸다. 촬영본 여백과 격자 밖은 별도 탐험 칸으로 추적하지 않는다. 위치·목표·지역 라벨은 기존 레이어를 사용한다.
- 지도 표시는 저장된 영웅별 탐험 기록을 사용한다. 로비 전체 지도, 배틀 전체 지도와 지역 상세에 적용한다.

고정 후보 [빌드 기록](build.json). Studio에서 지도 렌더러 153검사, 지역 상세 332검사와 지형 3검사, 배틀 전체 지도 440검사, 로비 전체 지도 87검사가 통과했다. 네 화면 크기에서 미방문과 잠금 대비, 방문 기록 반영과 복원, 마커 레이어를 확인했다. 렌더링 회귀에서는 기본 보안 설정의 대체 지형에도 색이 적용되고 해제되는지 확인했다.
