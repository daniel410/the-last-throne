# 파티 공유 스토리와 마지막 보스 웨이브

2026-11-04 · TLT-016/050/061/084 · ENG → QA · 소스 구현, 실제 다인 수용 미완료

사용자 요청으로 보스와 증원의 등장 순서를 변경한다. 보스 체력으로 호출하던 유한 증원도 미리 편성해 일반 적 웨이브를 모두 처치한 뒤 마지막 웨이브에 보스1명만 생성한다. King Shaman 방어막/기둥·보스 단계/위험 지대는 유지한다. 현재 공통 웨이브 생성기를 사용하는 다른 에픽에도 같은 순서를 적용한다. 기존에 보스 단독 목표만 있던 후반 목표에 새 일반 적을 임의로 추가하지 않는다.

같은 서버의 검증된 원정 runId를 기준으로 조사·대화/선택·호위 체크포인트·목표/전투 완료를 공유한다. 가장 먼저 서버가 검증한 선택을 해당 원정의 공통 선택으로 고정한다. 각 영웅의 기존 저장/보상 계약을 사용하며 다른 원정·훈련·개인 Selene 구매/동행 설정은 공유하지 않는다. 파티원이 떨어져 있거나 쓰러져도 같은 원정으로 참여 중이면 전투 보상/완료를 받는다. 이전 원정 큐는 실행 직전 runId를 다시 대조한다.

서버 메모리의 유한 이벤트 기록을 재전달하므로 같은 서버에 늦게 도착한 파티원과 저장 지연/재접속은 순서대로 따라잡는다. 기록은 해당 원정 인원이 없는 상태15분 뒤 정리한다. **서버 자체가 종료됐을 때 미저장 파티 이벤트를 복원하는 별도 영속 원장은 추가하지 않았다.** 기존 각 영웅의 확정 저장 체크포인트에서 재개한다. 보스 체력 등은 전투 시작 인원 기준이며 전투 중 새 입장자에 대한 소급 재산정은 하지 않는다.

AI는 인간 인원에 포함하지 않는다. 보스는 복제하지 않고 개인 처치XP/Gold 총량과 고정 스토리 보상을 보존한다. 입장 상세의 몬스터 수/능력치 미리보기에도 같은 계획을 사용한다. [조사와 시험 근거](../../research/2026-11-04-party-shared-story.md).
