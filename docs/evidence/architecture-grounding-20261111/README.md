# 5에픽 건축 접지·공중 지물·나무 충돌·스토리3 봉쇄·포로 구출 수정

2026-11-11 · TLT-057/061~065/084 · ENG/DES → QA. 사용자 스크린샷6건과 실행 중 로컬0.103.5 인스턴스를 대조했다. 상위 티켓/G5/G7 수용 완료가 아니다.

## 원인과 변경

- 건축물은 지역 중심 Y로 생성되고 길을 막아 이동할 때에만 접지를 계산했다. 중심/장식 경계상자는 실제 벽·기둥 받침과 달랐다. `ArchitectureGrounding`은 건축물 받침5점의 실제 Terrain/승인 바닥을 조회해 노출된 하단을 돌 기초로 지면까지 연결한다. 건물 전체를 낮춰 경사면에 묻는 초기 후보는 폐기했다. 배치 후보에서도 기초를 재생성하고 몸체 통과 검사를 수행한다. 화산 첫 제련소는 EC-Q1 연결로를 피하도록 동쪽으로200stud 옮기고 동쪽 길을 막던 오른쪽 날개/굴뚝을 제거했다.
- `TDWaterfallGorge`는 분리된 수평 물/땅 조각을 포함한 융합 메시였다. 사용자 허용에 따라 DW-03/DW-S2의 해당 장식과 전용 깊은 지형 절삭을 제거했다. 원본 TD 파일은 보존한다.
- 길게 떠 있는 판은 `ReliefAwning`이다. 사건 구역 폭에 따라100stud 이상 늘어난 평면과 양쪽 가는 기둥을 모든 구호 장면에서 제거했다. 목표/배우/보상은 유지한다.
- Eryn 앞 `TDElderTree`는 줄기43stud·뿌리60stud에 비해 숨은 충돌체가 약10stud뿐이었다. 줄기/뿌리 원본 메시의 실제 충돌을 켜고 큰 나무를 거점 판자/대화 접근로에서 떨어뜨렸다. 새 미술 루트의 뿌리에도 물리를 적용한다. 잎은 장식으로 유지한다.
- 봉쇄물은 구역 중심의 중간점에 놓여 DW-03 서쪽 사건 구역과 DW-S2 길이 겹쳤다. 단순히 실제 연결로 중간으로 옮긴 후보도 스토리3 복귀 검사에서 실패했다. 최종은 실제 연결로의 **잠긴 목적지 경계 안쪽20stud**에 배치한다. 스토리3 사건의 모든 단계→Eryn 안내선에4×5×4 몸체 Blockcast를 수행한다. 서버 접근 자격을 완화하지 않는다.

- 화면의 빈 케이지2개는 목표와 연결되지 않은 공용 장식이었다. 이를 제거하고 기존 DW-04 숲 친구·DW-05 작업자·DW-07 포로의 실제 구조 목표 위치에 개인 케이지/승인 NPC 원형을 표시한다. 기존 서버 검증 호위를 시작하면 앞문이110도 열리고 실제 서버 NPC가 문앞7stud를 통과한 뒤 기존 호위 경로를 따른다. 저장된 단계/완료 상태는 열린 문과 구출된 NPC 위치를 복원한다. 영웅별 상태·훈련장/거점 제거·템플릿 지연 복제를 처리하며, 서버 목표 자격/보상/저장은 기존 경로를 유지한다.

## 실행 중 세션·미검증·다음 담당

사용자가 플레이하던0.103.5 로컬 세션에서도 공중 천막/폭포를 제거했고, Eryn 앞 큰 나무를 이동해 줄기/뿌리2메시 충돌을 켰다. 개인 봉쇄는 서버의 실제 `DeepwoodState`를 구독하는 최신 투영으로 교체했다. 무관한 공용 케이지2개를 제거하고 개인 구조 장면을 실제 스냅샷에 연결했다. 클라이언트 화면에서 구조 완료 케이지의 열린 문을 확인했다. 새 문앞 퇴장 경로와 건축 기초는 영구 소스 빌드에 적용하며 실행 중 옛 서버 로직을 교체했다고 주장하지 않는다. 캐릭터·진행·재화·저장 데이터를 시험으로 변경하지 않았다.

게시 클라이언트·모바일/실기기·다중 사용자·저사양 성능·사용자 미술 수용은 미검증이다. 후속 QA는 새 빌드에서5에픽 보행·건축 기초 실루엣·카메라·Eryn 접근과3곳 구조 정상 입력을 확인한다. Roblox 게시/릴리스 태그는 생성하지 않는다. 기존 사용자 Blender 수정/자산 삭제는 이번 커밋에서 제외한다.
