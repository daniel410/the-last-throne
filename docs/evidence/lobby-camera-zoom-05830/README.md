# 로비 최대 줌 아웃 확대

2026-11-01 · TLT-028/061/084 · ENG → QA · 0.58.30

사용자 요청에 따라 AdventureCamera.lobbyMax를18→22studs(약22% 확대)로 조정했다. 최소6studs,배틀 최대22studs,모험 지형 충돌/회전 보정은 유지한다. 기존 카메라 모듈의 상태 갱신 경로를 그대로 사용한다.

검증: 수정된 소스를 현재 Studio Play Client에 임시 모듈로 복제하여 `tests/adventure-camera-zoom-native.luau`의 격리 가드/모듈 경로만 Client fixture에 맞춰 실행했다. 실제 Roblox 벡터·충돌 검사10개 Pass(상태별 최대 거리,최소 거리,가까운 줌,구체 충돌,수직 회전). 검사용 지형은 플레이 영역에서 멀리 떨어진 임시 폴더이며 종료 후 제거했다. 현재 실행 중인0.58.28 로비에서 모듈 테이블 변경을 시도했지만 실제 CameraMaxZoomDistance는18로 되돌아왔다. 따라서 기존 Play에 즉시 반영됐다고 판단하지 않으며 새0.58.30 빌드 재실행이 필요하다. Play는 유지한다. live DataStore/서버/게시에는 변경이 없다.

미검증: 실제 기기 핀치/마우스 휠 끝점의 시각 수용·건물 차폐·독립 QA. 다음 담당 QA는 새0.58.30 빌드에서 확대 범위와 가림을 사용자와 확인한다. 상위 티켓은 닫지 않는다. 고정 소스 Lobby/Battle 빌드 결과와 해시는 build.json을 따른다. 다른 미커밋 작업은 포함하지 않는다. Roblox 미게시·릴리스 태그 없음.
