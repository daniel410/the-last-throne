# 대장간 무기·장비 아이콘 확대

2026-11-09 · TLT-028/029/052/057/084 · 0.93.3 · ENG→QA

사용자 요청: 대장간에서 무기·장비를 자세히 볼 수 있도록 아이콘을 키운다. 작은62×66/54×54 표시 영역이 원인인 가독성 조정으로, 기존 승인 TD 자산과 공통 UI를 그대로 재사용했다.

- `ArmoryView`: 대장간 구매·판매 아이콘62×66→**128×128px**. 이름은 오른쪽, 설명은 아이콘 아래로 이동한다. 카드 높이는 PC244→320px, 짧은 화면224→300px로 늘려 기존 설명 높이와44px 거래 버튼 공간을 유지한다. 물약/다이아 상점은 원래 크기를 유지한다.
- `EnhancementView`: 장비 아이콘54×54→**128×128px**. 재료 아이콘은54px 유지. 강화 카드314→390px로 늘리고 이름/설명을 조정해 두 행동 버튼과 겹치지 않게 했다.
- 원본 PNG·개별 장비ID·희귀도·가격·능력치·확인/거래/강화 명령은 변경하지 않는다.

검증: 격리 candidate Studio(Edit, PlaceId0, 플레이어0)에 두 UI 모듈을 적용하고 실제 CoreGui/ArmoryView로1280×720,844×390,568×320,390×844 치수의 Frame을 생성했다. 기존 영웅 최초 장비와 판매 가능한 카탈로그 장비 fixture를 이용해 구매/판매3분류와 강화, 총28경우를 렌더했다. **5,236검사 통과**: 128px 실제 AbsoluteSize, 이름/설명 TextFits, 그림/이름/설명/행동 버튼의 비중첩,44px 터치 높이, 거래 전송0회. [결과](layout.json). 기기 자체 해상도를 바꾼 검증이나 게시 클라이언트 증거는 아니다.

실제 TLT Studio(place70829337938054)의 StarterPlayerScripts.Client 두 모듈에도 적용했다. 기존 Play 세션의 PlayerScripts 복사본은 새 플레이 때 갱신된다. 다른 Studio의 실행 중 Play 세션은 중단하지 않았다. Roblox Place 게시·실제 구매·저장 변경은 하지 않았다.

`git diff --check` 및 소스 고정 단일 빌드 결과는 마감 기록에 연결한다. 다음 담당: QA의 실제 PC/모바일 가로 화면 확대 체감·스크롤 사용성 수용. 부모 티켓은 완료 처리하지 않는다.
