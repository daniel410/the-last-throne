# TLT-028/031/052/061/084 — 로비 선택 영웅 식별 개선

2026-11-02 · ENG → QA · 로컬 개선본, 미게시.

사용자 요청에 따라 기존 TD 프레임/초상/배치를 유지하고 선택 카드에5px 금색 테두리, SELECTED 띠, 금색 이름표를 추가한다. 나머지 초상은 약하게 감광한다. 하단은 `Knight Hero Lv.9` 형식으로 클래스와 레벨을 함께 표시하며 XP를 아래 줄로 분리해 모바일 가로에서도 이름 공간을 확보한다. 기존 작은 체크는 보조 표시로 유지한다.

로비에서는 K0ClassId를 nil로 두어 무기 외형을 만들지 않던 원인을 수정했다. HeroSessionService.changed가 서버 소유 선택 영웅과 실제 장착 상태를 캐릭터 외형에 전달한다. 생성/선택/프로필 로드/장비 변경/로비 귀환 시 갱신하며 전투 권한은 기존 getCombatContext의 Tutorial 생명 검증으로 유지한다. 무기를 해제했다면 표시하지 않는다. 기존 클래스별 무기 외형을 사용하며 장비별 새 스킨은 추가하지 않는다.

## 검증

- `lua tests/k0-hero-session.spec.lua`: 기존 미커밋 시험 변경을 보존한 채104검사 통과.
- 네이티브 HUD/생명주기 검증 결과와 고정 커밋 빌드는 별도 로그/JSON 참조.
- 구형 make_k0_source_probe 실행은 전체 runner가 Studio Source 200,000자 제한을 넘어 실행하지 못했다. 실제 빌드와 짧은 시험 스크립트를 직접 사용해 재검증한다.

실제 사용자 로비 화면, 게시 클라이언트, 터치/패드·실기기, 최종 미술 수용은 후속이다. 현재 열려 있던 게시 Battle 문서에는 변경하지 않았다. 다음 담당 QA: 네 클래스 선택·장비 해제/재장착·귀환·재접속, 모바일 가로 식별성 수용.
