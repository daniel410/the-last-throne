# TD 기준 로비 메뉴 글씨 교정

2026-11-01 · TLT-028/061/084 · ENG/DES → QA · 0.58.15 로컬 시험판·미게시

사용자 비교 확인 후 TD와 같이 변경 요청. 기존 제작 스킬/공통 UI 계약을 적용한다. TD LobbyHomeUI.caption/layout과 LobbyHomeArt의 실제 소스·직전 Studio Client 측정에서 확인한 GothamBlack·순백색·검은 TextStroke 불투명, 이미지별 하단 제목 좌표를 RPG 메뉴에 반영한다. TD 원본은 읽기만 했다.

기존 메뉴7개·순서·아이콘/원본ID·셀 크기·클릭 기능은 유지한다. 데스크톱 제목을 그림 하단으로 내리고 자동 줄바꿈/자동 축소를 해제한다. TD보다 긴 RPG 영문 이름은 한 줄 너비에 맞춰 생성 시 글꼴 크기를 계산한다. 짧은 모바일은 기존 긴 제목의 줄바꿈/최소9px 맞춤을 유지하며 동일한 굵은 흰 글씨/검은 외곽선을 적용한다. Diamond Shop의 잘라내던 하단 원본을 복원하고 원본 captionY/H를 사용한다. 로그인 보상 표시 변경 시 크기를 다시 맞춘다.

빌드와 엔진 확인은 build.json/studio-result.json을 따른다. 실기기·게시·사용자 최종 시각 수용은 미검증이다. 다음 담당 QA는 PC/모바일의 모든 메뉴 글씨·보상 느낌표 및 기존 메뉴 클릭을 확인한다.
