# 마법사 기본 주문 범위 정정과 Gravity 강화

2026-10-31 · TLT-008/015/042/052/056/084 · ENG → QA

사용자가 직전 요청을 정정했다. 초기 기본 마법 Mana Bolt·Water Ball·Gravity의 기존 피해만 2배로 유지하고, 지팡이 기본 공격과 Lv5/10/15 이후 공통 기술·Pyro/Cryo 전직 기술·궁극기는 2배 변경 전 수치로 복원했다. 기존 주문 보정 1.4는 유지한다. 마법사·엘프의 직전 MP 회복 2배는 유지한다. 예: Lv1 기본 주문 예상 피해는 280 / 238 / 196이며 장비·숙련·최종 반올림에 따라 달라진다. 서버와 미리보기의 공통 기술 계수를 이용한다.

Gravity의 기존 감속은 이동속도 50% 감소였다. 감속량 2배를 100% 감소로 해석해 이동을 멈춘다. 이는 기절이 아니므로 적의 공격을 중단하지 않는다. 대상 중심 반경 6→10 스터드, 기본 지속 3→10초로 늘리고 기존 숙련당 +0.2초를 유지한다. 기존 최대 대상 8·장애물·높이 검사와 적용 대상은 유지한다. 효과 원형의 반경도 서버의 기술 설정과 동일하게 표시하고, 스킬 설명에 실제 감속량과 숙련 반영 지속시간을 표기한다. 보스도 기존 Gravity 대상이므로 별도 면역은 추가하지 않았다. [기존 전투 조사](../../research/2026-10-31-mage-elf-balance.md)의 서버 권위와 기기 비교 원칙을 이어간다.
