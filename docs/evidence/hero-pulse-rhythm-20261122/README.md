# 네 영웅의 연속 공격 타이밍과 궤적

TLT-033/057/059 · 2026-11-22 · 기준 0.115.47 · 후보 0.115.48

[공식 사례 조사](../../research/2026-11-22-hero-pulse-rhythm.md) · [고정 빌드](build.json) · [검사 결과](studio-results.json)

| 기술 | 구현 |
| --- | --- |
| Knight · Oathblade | 첫 금빛 검격을 위에서 아래로 내리고, 두 번째 검격을 반대 방향으로 높여 길게 돌려 벤다. 첫 타의 뒷다리와 후속타의 앞다리가 하중을 받는다. |
| Dwarf · Quickfire | 오른손 도끼를 든 채 낮은 자세에서 왼팔로 세 번 반동을 받는다. 각 발사에서 총구부터 서버가 보낸 끝점까지 가는 선 하나가 짧게 남는다. |
| Elf · Echo Arrows | 기울인 활의 시위를 세 번 놓고 마지막에 당기는 팔을 더 멀리 뻗는다. 화살마다 궤적 하나와 각도를 달리한 잎 잔상 하나를 표시한다. |
| Mage · Molten Line | 지팡이를 든 손을 몸 가까이에 두고 다른 손과 앞무릎으로 각 방출을 받아 낸다. 용암 심이 각 펄스에서 약 90ms 동안 발밑에서 확정 끝점까지 순서대로 밝아진다. |

아군 화면의 핵심 획은 유지하면서 검격 면, 잎, 현무암 바탕을 줄였다. 연출은 기존 서버 펄스와 확정 방향·끝점을 받는다. 네 기술의 피해, 상태 효과, 판정 범위, 발동 시각은 기존 서버 구현을 따른다.

## 검증

- 같은 Studio Run 장면의 R15 리그, 장착 무기, 조명, 기술별 카메라에서 찍었다. Oathblade의 1·2타는 각각 52ms, Quickfire 2발째는 26ms, Echo Arrows 3발째는 48ms, Molten Line 3번째는 62ms 뒤다. 화면 비교는 자세와 주요 월드 효과를 포함한다. [전후 5장 비교](pulse-comparison.jpg)
- `run-in-roblox --place builds/0.115.48/TheLastThrone-0.115.48.rbxlx --script tests/hero-pulse-rhythm-native.luau`에서 R6/R15 자세, 검격의 서버 방향, 총구·활에서 끝점까지 연결된 단일 궤적, 지면 발화 순서, 짧아진 끝점과 이동 거리 0을 검사했다. 후보 85건 전부 통과. 기준은 실행된 77건 중 57건에 실패했다. 기준에 발화 전면이 없어 후속 발화 순서 검사의 일부가 생략됐다. [재현 소스](../../../tests/hero-pulse-rhythm-native.luau)
- Studio 11묶음에서 246,387건을 통과했다. 128개 기술의 두 리그 자세와 명중, 아군 효과 우선순위, 엘프 지연 발사, 투사체 시각을 포함한다. Gunner 투척 fixture는 첫 실행에서 Studio가 짧은 발사 창을 지나쳤다. Run 전환 후 750ms 준비를 추가해 최종 후보와 기준에서 각각 180건을 통과했다.
- CPU 전직과 효과는 15,075건을 통과했다. 별도 CPU 자세 검사는 양쪽에서 기존 `K0MeleeMotion.luau:142`의 Luau 복합 대입을 Lua가 읽지 못해 중단했다. 같은 자세 경로는 Studio 회귀 검사에서 통과했다.
- 후보 빌드 SHA-256과 변경된 런타임 모듈 7개를 입력 커밋과 대조했다. 소스와 증거를 원격 `main`에 반영했다.

## 남은 수용

후보는 미게시다. 전투 QA의 다음 검증은 게시 테스트의 로비→배틀 이동, 네 명이 겹쳐 공격할 때의 적 예고 판독, 저사양 터치 기기 프레임 시간, 사용자 타격감 수용이다.
