본편 35장의 확장 사건에 필요한 방문·조작은 194회에서 168회로 줄었다. 13개 사건에는 9개의 현장 조작과 4개의 본선 도착을 연결했다. 에픽 완료 화면의 해당 장 결과, 지역에 남은 변화, 다음 목적은 서로 다른 정보를 주도록 영어 문구를 수정했다.

서버는 기존 선행·거리 검사와 목표 저장을 사용한다. 완료 한 번이 기존 단계 3개를 기록하므로 이전 중간 저장과 완료 상태를 읽을 수 있다. 본선으로 옮긴 네 사건에는 예전 우회지의 체크포인트를 표시하지 않으며, 현장 조작의 이동 목적지는 실제 조작 위치를 사용한다.
