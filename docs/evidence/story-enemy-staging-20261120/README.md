# 다음 스토리와 페이즈 몬스터 선행 생성

2026-11-20 · TLT-040/087 · ENG → QA · [전투 활성화 계약](../../production/engineering-plan.md#7-퀘스트체크포인트보상) · [이전 개선](../monster-phase-loading-20261120/README.md)

사용자는 스토리를 진행하는 동안 다음 스토리와 페이즈의 몬스터를 미리 만들어 달라고 요청했다. 서버는 현재 스토리에서 완료되지 않은 첫 두 교전 목표와 다음 메인 스토리 첫 교전만 준비 범위에 넣는다. 진행 중인 교전은 현재 웨이브 대신 이어지는 웨이브를 준비한다. 격리된 복제 작업은 웨이브당 필요한 모델을 프레임 사이에 나눠 만든다. 클라이언트도 해당 무리의 외형 파일을 기존 비동기 경로로 요청한다. [Roblox Instance 복제 및 Parent](https://create.roblox.com/docs/reference/engine/classes/Instance#Clone).

준비된 개체는 서버 월드 밖에 있으며 등록, 피해, 보상은 정상 활성화에서 시작한다. 원정·목표·웨이브가 맞는 개체를 한 번 꺼내 쓴다. 준비가 끝나기 전에 교전이 열리거나 실제 무리 구성이 달라진 경우 필요한 개체는 즉시 복제한다. 사용하지 않은 개체는 원정에서 더 이상 참조하지 않으면 해제한다.

## 검증 범위

Studio에서 저장 대기 및 지역/접근 잠금, 동일 개체 재사용, 다른 원정의 격리, 첫 웨이브 진행 중 후속 웨이브 선행 복제, 미사용 개체 해제와 클라이언트 외형 요청을 비교한다. 게시 클라이언트의 외형 표시 시간, 실제 4인 서버와 실기기 성능 및 사용자 수용은 QA 확인 대상으로 남긴다.
