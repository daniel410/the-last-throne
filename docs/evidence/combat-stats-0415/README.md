# 0.41.5 영웅 전투 능력치·장비 기여도

2026-10-31 · TLT-028/043/046/052/084 부분 구현 · ENG → QA

H→STATS의 새 COMBAT STATS에 물리/마법 공격력·방어력·MaxHP/MP 현재 총합, Hero+Gear 기여도를 표시한다. SHOW GEAR BONUSES로 실제 장착된 아이템별 보너스를 펼친다. Power의% 단위와 Armor의고정 수치를 분리하며 DRAFT는 미확정 전후/차이로 표시한다. 미구현 능력치·전투밸런스·저장 계약은 추가/변경하지 않았다. [공식 게임 비교 조사와 적용 판단](../../research/2026-10-31-hero-combat-stat-breakdown.md).

앞선4/5슬롯 Lv5/10 개방·안전한 필드 장착, 누적XP·직선 안내·증가한 몬스터/레벨 표시를 보존한다.0.41.4에 다른 작업이 드워프 모션 빌드를 완료했으므로 이번 시험 버전은0.41.5로 예약한다.
