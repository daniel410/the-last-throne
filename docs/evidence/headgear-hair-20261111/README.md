2026-11-11 · TLT-028/032/057/084 · 제작: modeling_artist/software_engineer/QA 역할 적용.

사용자 요청에 따라 마법사 모자, 기사·드워프 헬멧, 엘프 후드의 네 계열에 머리카락을 함께 착용하도록 연결했다. 엘프는 TD Elf Archer 실제3D 머리 메시를 기준으로 앞머리를 보완했다. [원본·파생·자산 ID](../../../assets/models/headgear-hair-td-v1/README.md). 이전 로브 두께·모자 높이·눈 가림 보정도 유지한다.

정적 검증은3종15,748삼각형, 원본/파생 SHA256, 승인3자산, 네이티브144점 대응을 통과했다. Studio 제작 미리보기는 [마법사](mage-front.png), [엘프](elf-front.png), [기사/드워프 공통 목덜미](helmet-back.png)다. 미리보기 마네킹은 고립된 높이700의 진단용으로 실제 플레이어를 변경하지 않았다.

고정 소스 `b8f2e4922a4bd48f18db4da4ce7a5cf2f06de5f8`의 **0.102.5** 단일 빌드를 생성했다. [build.json](build.json), [엔진 JSON](native.json), [원문](native.log).

- 머리카락:274검사, R6/R15 ×4클래스 ×4계열=32조합 통과. 실제3Mesh 로드 성공, 색상·소켓·교체·멱등성·파손 복구·실패 원자성·원래 Hair 복구 확인.
- 착용:81검사 통과. 네 계열 ×R6/R15에서 기사/드워프/마법사/엘프 Hair가 양쪽 눈의18개 샘플을 가리지 않는다. 투구 눈 가림0, 로브 깊이/모자 접합 보정 유지.
- 기존 방어구6,062검사·무기700·방패199 통과. 기존 콘텐츠 경고는 출력됐지만 PreloadAsync 최종 상태는 모두 Success다.
- 실제 빌드 역할/로딩202검사와 정적 자산 검증 통과. Studio에서0.102.5를 열고 visualVersion3·정확한3Mesh ID를 재확인했다. 기존0.102.0/0.102.3 Play 세션은 보존했다.

초기 테스트는 Roblox float 투명도 `.3`의 정확 동등 비교 때문에 실패했다. 실제 복원값의 오차 허용 비교로 테스트만 보정하고 동일 빌드에서 전체 재실행했다([초기 로그](native-fixture-float.log)). 실행 중 다른 작업의 run-in-roblox 포트 점유는 대기 후 해결했다.
