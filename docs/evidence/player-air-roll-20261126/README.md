# TLT-AIR-ROLL-20261126 · 더블 점프 검증

관련 작업은 TLT-005의 플레이어 입력 후속이다. 원본은 인접 Throne Defense 저장소의 `PLAYER-AIR-ROLL-20261120` 검증 기록과 `src/Client/PlayerAirRoll.lua`(Git blob `a8837bb5f129bfe13867a91bd5d70e90e9a2a2d8`)다. [조작 비교 자료](../../research/2026-11-26-player-air-roll.md)

- 두 프로젝트가 공유하는 StarterPlayerScripts에서 같은 점프 로직을 로드한다. RPG의 로비 패널과 원정·체크포인트 이동 잠금 중에는 공중 점프 입력을 차단한다.
- 서버는 요청한 플레이어의 현재 캐릭터, 생존 및 공중 상태를 확인하고 짧은 반복 요청을 제한한 뒤 회전 시작 시각을 전달한다. 이동의 수직 임펄스는 캐릭터를 조작하는 클라이언트에서 적용한다. 서버 이벤트는 관전자 회전 표시용이다.

| Studio 격리 검증, 모의 입력·리그·네트워크 | 실제 소스에 신호를 넣어 Space 홀드와 세 번째 입력 차단, 43 studs/s 상승과 수평 속도 유지, 착지·리스폰 후 재사용, 발판에서 걸어 떨어진 상태 차단, 터치/패드 분기, 메뉴·이동 잠금 및 서버의 지상·중복 요청 차단과 관전자 포즈 복귀를 확인했다. |
