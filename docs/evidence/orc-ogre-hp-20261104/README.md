# 오크·오우거 HP 상향

2026-11-04 · TLT-005/057/061/084 · ENG → QA

사용자 요청: 오크와 오우거의 HP가 너무 적으므로 늘린다. 이번 조정은 기존 HP의 약2배를 시험값으로 적용한다. 정수 반올림 때문에 본편 일부 값은 이전 표시 HP의 정확한2배와1 차이 날 수 있다.

| 경로 | 오크 | 오우거 |
| --- | --- | --- |
| 난이도 규칙v2 종족 HP 배율 | 1.1 → 2.2 | 1.35 → 2.7 |
| Easy Lv5 솔로 예시 | 248 → 495 | 304 → 608 |
| 훈련장 고정 HP | 900 → 1800 | 6000 → 12000 |
| 원정 규칙 없는 스토리 경로 | 기존 계산 HP ×2 | 기존 계산 HP ×2 |

공격력·레벨·공격/이동 속도·자세·스폰 수·보상·보스는 보존한다. 저장된v1 원정의 능력치도 유지한다. v2 원정은 다음 몬스터 생성부터 조정값을 사용하며 이미 생성된 적의 HP를 실시간 변경하지 않는다. `DeepwoodService.applyBalance` → `StoryHealth` → `CombatService`의 서버 연결을 소스로 확인했다. 입장 미리보기도 같은 `Balance.unitStats` 경로를 사용한다.
