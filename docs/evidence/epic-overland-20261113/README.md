# 다섯 에픽 도보 연결

2026-11-13 · TLT-061/062/063/064/065/overland · ENG/QA · 로컬 구현·미게시

## 변경과 근거

[최신 사용자 결정](../../decisions/2026-11-13.md)과 [비교 조사](../../research/2026-11-13-epic-overland.md)에 따라 Deepwood → Gloamwood → Frozen Vale → Ember Caldera → Haunted Graveyard 전체를 인접 배치했다. Deepwood는 고정하고 각 다음 에픽의 전체 좌표를 이동한다. 지역 내부의 본편·선택 사건·전투 배치·NPC·원본 미술의 상대 위치, 안정ID·보상·저장 조건을 보존한다. 모든 점 좌표는 중복 참조를 고려해 한 번만 옮긴다.

이전 에픽 마지막 지역과 다음 에픽 첫 지역을 96stud 폭의 실제 길로 잇는다. 길의 기초·지형·기존 TD 환경 미술을 함께 만들고 네 경계 모두 금빛 안내를 왕복 연결한다. 스토리 완료의 저장 확인 뒤 다음 에픽을 준비하지만 캐릭터를 이동시키지 않는다. 선행 미완료는 기존 지역 바위 장애물과 서버 접근 검사로 제한하며 완료 시 형상·충돌을 제거한다. 재입장 시 현재 에픽과 이전 지역들을 생성해 뒤로 걸어가는 길도 유지한다.

기존 Eryn 귀환·선택형 빠른 이동과 사건 안의 이동 장치는 이번 요청의 에픽 전환과 별도다. TD 운영 Experience·계정 지갑·소유권·보상·난이도·몬스터 수치는 변경하지 않았다. 기존 사용자/다른 작업의 미커밋 파일을 선별 커밋에서 제외한다.

## 검증

- [후보 엔진 로그](candidate-native.log): 별도 PlaceId=0 Studio에서 전체 Luau 컴파일, 네 길의 중복 생성 방지, R15 실제 왕복8방향 통과. 각 이전 마지막 구역 중심에서 다음 첫 구역 중심까지 WalkSpeed32로 보행하며 점프/서버 위치 보정0회다.
- 실제 서버 저장 큐에 불명 저장 응답을 주입해 재시도 전에 지역 준비/이동이 없고, 저장 확인 후 다음 목표가 유지됨을 확인했다. 지역 준비 오류에도 위치 변경0회다. 미완료 경계 서버 차단·완료 뒤 통행·현재 에픽과 바로 다음 경계만 바위 투영·해제 시 충돌 제거까지112검사 통과.
- 이동된 GW/FV/EC/HG의36스토리·496목표·30지역 연결로를 실제 엔진 바닥/충돌/서버 권위와 대조했다. 바닥 실패·몸체 차단·서버 보정·경로 실패0. 기존 EC 경사 끝의 약1.30stud 낮은 단차6건은 별도 수치로 기록하며 몸체 차단이 아니다.
- 후보에서 FV 출구의 지형 턱과 확장 연결로가 지역 경계 밖까지 이어질 때 안내가 출구로 되돌아가는 진동을 발견했다. 지형을 걷어내는 범위와 기초의 겹침을 보강하고 출구 평면을 지난 안내가 되돌아가지 않게 수정한 후8방향 모두 통과했다.

[빌드 기록](build.json)의 산출물은 `builds/0.105.0/TheLastThrone-0.105.0.rbxlx`, SHA256 `3b8de70b6151a468d7069805a7cae4a0d2cb8d22b6520bee9a3f77fc178cb55a`다.
