# Roblox 검격·마법 조사 후 전체 전투 VFX 개선

TLT-033/057/059 · 2026-11-15 · ART/ENG · 소스/격리 엔진/로컬 빌드 검증. 게시·실기기·사용자 최종 미술 수용과 전체 G4는 미완료다.

후속 품질 질문에 대한 판단: 현재 빌드를 최상급 RPG 미술 완성도로 수용하지 않는다. [상용 RPG 공식 시연의 직접 관찰과 구체적인 격차](../../research/2026-11-15-rpg-vfx-quality-comparison.md)를 별도로 기록했다. 검사 통과·새 P0 회귀 없음과 높은 미술 완성도는 다르다.

사용자는 Roblox의 칼·마법 VFX를 충분히 조사하고 모든 효과를 다시 개선하도록 요청했다. Diablo IV/WoW의 기존 전투 가독성·정체성 원칙을 재확인하고, Creator Hub의 Beam/Trail/입자/성능 자료와 제작자8건의 실제 이미지·영상 표본을 확인했다. [공식 근거·채택/보류·비용](../../research/2026-11-15-roblox-vfx-production.md)·[독립 ART의 사례별 직접 관찰/12원칙](../../research/2026-11-15-roblox-vfx-artist-observations.md).

공통 곡선/Trail/입자 처리만 `CombatVFXStyle`로 묶고 각 렌더러의 예산·수명·기존 정리 경로를 재사용한다. 런타임 변경은 클라이언트10모듈이다. 서버 피해·보호·범위·시각 이벤트 시점·성장·저장·TD Experience와 승인 아이콘/원본 자산은 바꾸지 않았다. 신규 외부 모델·플러그인·PNG/메시 설치/업로드는 없다.

곡선 Beam 수와 전체 상한은 유지하지만 분할과 일부 주면 Part 수는 늘었다. Hero의 Beam240/터치144·면160/80·입자192/96, 적의640Part·64record 및 ART별 Beam/입자/빛 상한은 그대로다. 이것을 GPU 성능 개선으로 해석하지 않는다. 실제 빌드의 포화 장면 Lua update P95는 약0.955ms이며 이 로컬 Studio 표본에만 해당한다.

## 독립 아트 검수와 화면

[최종 ART 관측/잔여 과제](art-review.md)·[구조화 판정](art-review.json). 실제 아이콘과 기술 의미를 유지하면서 곡선·굵은 면·잔광·Trail을 다시 검토한다. 최종128정지 화면에서 새 주 형상 누락/뒤틀림을 발견하지 못했으며, 이 판단은 게시/실전/사용자 수용과 다르다.

유효 전후는 영웅48+적/Wind/지원22+Imp1+무기2=73쌍이다. 기하 캡처는 생성 후 yield하기 전에 지정 상대 시점의 실제 렌더러를 step하고 복제한다. 입자는 동결 후 재방출하므로 입자의 원래 연속 운동/정확한 프레임 시간은 이 화면으로 수용하지 않는다. 모형 전후의 낮/밤은 각각0.055/0.18초에 결합돼 있어 시간 감쇠의 단독 근거는 엔진 시간 검사다. 범위선은 원래 판정 정보이며 장식보다 우선한다.

각 단계의 `*-provenance.json`은 고정 baseline `11c0a9cf`, 명시된 후보 덮기, 원본/검사/fixture SHA를 기록한다. 초기 중간 캡처와 최종 면 조정의 입력은 다르다. 최종10쌍·128전수·무기 최종·Imp 재촬영의 런타임10모듈은 실제 빌드와 바이트가 모두 같다.
