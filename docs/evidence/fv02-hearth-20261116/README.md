# TLT-062 · FV-02 연결된 피난처 난로

빌드0.111.8 / 소스 b36a845b1bbe54c35870330632c1fafb33342b23. 미게시·태그 없음·G5 미완료. [제작표/조사](../../research/2026-11-16-fv02-hearth.md).

FV-02 약품 전달/피난 생활 맥락에 따라 HearthLonghouse 기존 굴뚝 아래 난로 받침·그을음 배면·양쪽 벽·선반·연도·장작·잔불11파트를 추가했다. 기존 건물 footprint 안, 전부 anchored/비충돌/비쿼리/비접촉이다. 고정 화로2개는 장옥 내부 겹침 때문에 FV-02에서 제외했다. 지형·서버 바닥·저장·보상·TD 원본은 변경하지 않았다. 새 광원/입자/루프 없음. 실제 성능 향상은 주장하지 않는다.

## 검증

고정 빌드의 BaseScript만 Disabled로 만든 UTF-8 로컬 XML fixture를 Studio Edit에서 열고 CampaignWorld.create(3)를 실행했다. 전체528개 구문 통과. 두 변경 모듈 Source가 커밋 원문과 정확히 같음을 확인했다. 실제 배치 장옥1개/scale1.3/추가11파트·충돌 플래그와 AuthoredVista의 Brazier 제거 확인. results.json 참조.

기존 tests/epic-map-navigation-native.luau의 world 생성만 기존 _G.HearthWorld로 바꾸고 for epic=2,5를3,3으로 제한했다. 기존 points 11장/9연결/142목표/6177표본, worldPoints143목표/6218표본에서 차단·바닥·보정·안내·단차0. 실제 Humanoid 이동은 아니다. 최초 범위 제한 문자열이 실제 소스와 달라 타 지역 nil spawn 오류가 났으며 수정 후 양쪽 통과했다. 제품 오류로 분류하지 않는다.

초기0.111.7은 구문·추가11파트 통과 후 화면에서 기존 고정 화로와 겹침을 발견해 채택하지 않았다. 후보 build.json을 보존했다. 최종0.111.8에서 화로 대체를 검증했다.
