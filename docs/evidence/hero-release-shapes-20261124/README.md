세 부채꼴 기술의 서버 펄스는 기존 엄폐 필터로 표시 경로 다섯 개를 구한다. 각 경로는 벽 앞에서 끝나며 열린 경로는 기술 사거리에 닿는다. 주 효과가 예산에서 밀려나면 같은 끝점으로 가벼운 발사선을 그린다. 피해 위치 목록과 표시 경로는 별도 필드로 전달한다. [공식 비교 연구](../../research/2026-11-24-hero-release-shapes.md)

## 검증

- Rojo 7.7.1 단일 Place 두 개의 SHA-256을 확인하고, 바뀐 런타임 모듈 9개의 빌드 내 소스를 입력 커밋과 대조했다. 후보 소스는 `58094acd`다. 패키지 역할·로딩 정적 검사 336건과 스킬·전직·몬스터 CPU 검사 75,552건을 통과했다. [고정 빌드 기록](build.json)
- 같은 R15 리그·무기, 카메라, 조명과 엄폐물로 발동 직후를 비교했다. 화면 비교 중 피해 숫자를 숨겼다. 첫 0.115.71에서 획이 총구와 활 끝에서 일찍 떨어져 보였다. 0.115.72에서 초기 45ms(산탄)·60ms(화살)는 발사 원점과 연결하고 그 뒤 빠르게 줄인다. 증기 가장자리도 넓혀 상승하는 획과 구분했다. [Studio 전후 화면](comparison.jpg)
- 신규 엔진 검사는 188건을 통과했다. 기준 빌드는 실행된 160개 조건 중 63개를 충족하지 않았다. 양쪽 화면, 막힌 중앙·열린 옆 경로, 가까운 엄폐와 무기 끝 순서, 예산 초과 시 대체 발사선, 피해 대상·방향, 정리와 자세를 확인했다. [재현 코드](../../../tests/hero-release-shapes-native.luau)
- Studio 묶음 16개를 실행했다. 12묶음 273,287건이 통과했고, 같은 실행 세션에서 실패한 세 묶음은 개별 재실행에서 양쪽 빌드 189건을 각각 통과했다. 128개 기술의 R6·R15, 파티 효과 예산과 적 예고, 엘프 확정 발사, 몬스터 584개 공격, 전직 화면을 포함한다. 기존 `hero-vfx-native`는 두 빌드에서 Mountain Sweep의 일반 명중 색상이 카탈로그와 같아야 한다는 조건에서 멈췄다. 현재 효과는 기존 스킬별 흙색을 사용한다.
