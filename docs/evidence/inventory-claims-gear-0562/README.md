- 작업 ID: TLT-005/021/026/032/084 부분 개선. 전투 중 미수령 창과 아이템 상세에 로비로 돌아가 수령하라는 안내를 표시하고 서버에도 전용 오류를 추가했다. 로비 위치 변경 시 같은 인벤토리 버전이어도 수령 버튼을 갱신한다. 불확실한 저장의 동일 요청 재시도 버튼은 미수령 팝업에 표시한다.
