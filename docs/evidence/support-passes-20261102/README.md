## 설명과 구현

`SupporterText`의en-US 키에서 가격·효력·시작/종료·재동행·미사용 보관·자동 갱신 없음을 관리한다. TD 프레임·버튼·nun 초상 상세창에 가격 버튼3개, 잔여 credits, 현재 story, 계정 Gold를 표시한다. 핵심 약관은 스크롤과 별도로 버튼 위에 고정한다. 소지 Gold 부족/확인 중/저장 중은 구매를 비활성화하고 알려준다. 계정 로드 실패를0 Gold로 표시하지 않는다. 로비Selene와 모험G/패드R3/터치 상세 진입은 기존 경로다.

가격/차감/권리는 서버 `SupportPassRules` + 기존 AccountStore 단일 키 트랜잭션으로 확정한다. 기존 작업 영수증과 동일한96개 보관 정책이며 구매 재시도에는 같은ID를 쓴다. 저장 결과가 불명확하면 기존 account fence를 유지하고 같은 요청을 재확인한다. 초대와 팔로우 선택도 한 저장에 반영한다. 파티 동료 슬롯이 이미 차 있으면 새 초대 차감 전에 거절하며 동시 초대에 임시 슬롯 소유를 둔다. 기존 무료 팔로우 플래그만으로 유료 지원을 부여하지 않는다. TD 지갑·보상 정본·회복 수치·파티AI 상한은 변경하지 않았다.
