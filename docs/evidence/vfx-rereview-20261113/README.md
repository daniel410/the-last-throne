## 수정이 필요한 코드 결함

### VFX-R01 · P1 · 돌진 예고가 실제 충돌 검사보다 먼저 끝남

- 근거: [예고 수명](../../../src/client/EnemyPatternEffects.luau#L219)은 `windup + (pulses-1)*interval + .22`. 돌진11공격은 모두1펄스다. [서버 돌진](../../../src/server/Combat/EnemyPatternRuntime.luau#L79)은 `windup`부터 `windup+.45`까지 이동과 선분 충돌 피해를 검사한다.
- 영향: MagmaWorm.2, Gloambat.2, Zombie.2, Ghoul.2, Hellhound.2, Warlord.3, GoblinKing.3, EnragedWarlord.3, KingIceBear.3, MagmaImp.3, VenomcoilKing.2.
- 정적 재현: 벽/절벽 없이 유효한 바닥과 leash 안에서 돌진을 실행하고 `age=windup+.30`을 평가한다. 클라이언트의 warning은false지만 서버 돌진 분기는true다. 예고가 끝난 뒤에도 약0.23초간 충돌 판정 구간이 남는다. 실제 표시 종료는20Hz draw 갱신에 따라 달라진다.
- 조치: 돌진의 실제 활성 구간을 예고 수명에 반영한다. 피해/돌진 속도나 서버 판정 시간을 미술 수정에 맞춰 단축하지 않는다.
- 수용: QA가11공격 각각에서 준비→돌진 끝까지 예고를 관찰하고, 벽 충돌/취소/사망 시 즉시 정리 및 일반 공격 수명 회귀를 확인한다. **정적 경로 확인, 엔진/화면 재현 Not Run.**

### VFX-R02 · P2 · 공격 범위 OFF가 패턴 예고에 적용되지 않음

- 근거: [설정 영어 문구](../../../src/shared/SettingsText.luau#L8)는 `Enemy Attack Ranges`, 설명은 공격 전/중의 바닥 윤곽 표시다. [기존 예고](../../../src/client/K0Telegraphs.luau#L139)는 `Settings.enabled(player,'attacks')`를 확인한다. `EnemyPatternEffects`의 draw/render에는 설정 조회가 없고 경고 폴더를 계속 생성한다.
- 재현 조건: Settings에서 Enemy Attack Ranges를OFF한 뒤 Goblin.1 또는 Shaman.2 패턴을 시작한다. 예전 K0 예고/위험 표시는 숨지만 `EnemyPatternWarning/WarningEdge` 생성 경로는 그대로 실행된다. 공격 중 토글해도 새 경로에는 반영되지 않는다.
- 조치: 패턴의 바닥 예고에 같은 설정을 적용한다. 몬스터 실제 투사체·확정 피격·지원 효과까지 함께 감추지 않는다.
- 수용: OFF로 시작/공격 중OFF/다시ON/리스폰/스트림 재진입에서 기본·패턴 예고가 일관되어야 한다. **정적 경로 확인, 엔진/화면 재현 Not Run.**

## 성능·수명 검토

- HeroVFX는 동시 레코드 PC12/터치8, Beam240/144, Glow96/48, 입자192/96, 파편48, 표면160/80 상한이 있다. PixelFX24레코드 및 Curated 입자 예약은 별도다. WindLance도 별도 수명을 관리하면서 표면 예산을 공유한다.
- EnemySpellVFX는640파트/64레코드, 투사체 우선 회수 정책이 있다. EnemySpellArt의 Beam192/96·입자480/240·Light6·Flare32 상한은 별도다. 이 수들을 단일 프레임 비용이나 실제 GPU 측정치로 해석하지 않는다.
- 예고 WarningEdge에는 위640파트 상한이 적용되지 않는다. 장거리 경계는3stud 이하로 세분화하며 동시 몬스터 수에 비례한다. **부하 위험 후보**이며 FPS 저하/누수가 재현됐다는 뜻은 아니다. 장식 예산 때문에 위험 정보를 삭제하는 해결은 피한다.
- 영웅/적의 늦은 준비·중복 펄스·종료 후 발사 부활 차단은 [수명 수정](../visual-lifecycle-fit-20261113/README.md)의 구현과 현재 코드가 연결된다. 기존 엔진 PASS 수는 과거 실행 결과이며 이번 재실행 결과가 아니다.
- 거리/예산 상한은 생성 시 또는 효과별로 다르게 적용된다. 따라서 모듈별 상한만으로4인+AI에서 위험 바닥이 잘 읽히거나 저사양 GPU가 충분하다고 승인할 수 없다.
