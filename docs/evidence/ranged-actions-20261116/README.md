# 엘프·마법사 공격 애니메이션 리뷰

2026-11-16 · TLT-005/084 · 개발·리서치 → QA·사용자

0.111.19에서 엘프 기본 활 사격과 마법사 기본 지팡이 타격, 직업별 스킬 32종을 수정했다. 각 직업에는 시작 기술 3개, 추가 공통 기술 3개, 전직 두 계열의 기술이 각 13개씩 있다. 같은 사격·주문 계열은 기존 원본 클립을 공유하며, 기술의 역할에 맞춰 체중 이동·무기 기울기·빈손의 경로와 회수 시간을 더했다. [RPG 사례와 적용 근거](../../research/2026-11-16-ranged-actions.md)

## 동작

- 엘프는 기본 사격에서 화살통으로 손을 보내는 기존 R15 동작에 어깨 감기와 무릎 지지를 연결했다. Heavy Draw는 깊게 감아 당기고, Retreating Shot은 물러나는 방향으로 상체를 기울인다. 부채꼴 사격에서는 활을 옆으로 기울이고, 곡사에서는 상체를 열어 활을 들어 올린다. Rapid Fire는 발사 후 손이 뺨 뒤를 지나 다음 당김으로 돌아간다. 반복 사격이 확인되기 전에는 반동을 재생하지 않는다.
- 마법사는 물구체를 모을 때 빈손을 안으로 당기고, 직선 주문은 지팡이 끝을 전방으로 내민다. 화염창·냉기창·번개창은 준비할 때 가슴과 양팔이 서로 다른 방향으로 움직인다. Caldera's Judgment는 몸을 낮췄다가 손바닥을 들어 올리고, Eternal Tempest는 먼저 양팔을 높게 들어 폭풍을 펼친다. 반복 시전은 발동과 재준비 사이를 부드러운 호로 연결했다.
- 서 있을 때는 무릎과 골반을 쓰고, 이동 중에는 기존 보행 관절을 따른다. 기본 공격 속도·마나·피해·사거리·서버 판정 코드는 이번 변경 범위 밖이다.

## 검증

[고정 빌드 기록](build.json) · [Studio 검사별 측정값](native.json) · [로컬 Play 동작별 결과](play.json)

- 고정 빌드의 네 클라이언트 모듈이 검토 소스와 일치하는지 확인했다. Studio 검사 10묶음에서 269,466개 조건을 통과했다. 양 리그의 66개 동작 적용, 활시위·화살통·활 손잡이·지팡이 소켓, 속도별 서버 발사 시각, 취소·중복 발사, 전 직업 스킬 회귀를 포함한다.
- R6·R15에서 Rapid Fire 발사 40ms 후의 재장전 경계 앞뒤 10μs를 표본으로 잡았다. 같은 발사 상태로 두 고정 빌드를 비교했다. 당기는 쪽 어깨의 각도 벡터 차이는 13.421도에서 0.01031도로, 활의 차이는 20.000도에서 0.00038도로 줄었다. 마법사 전방 투사체 발동 시 지팡이 축과 정면의 내적 최솟값은 0.97136이었다. 원소창 세 종류와 두 궁극기의 준비 자세 차이도 실제 캐릭터 렌더 경로에서 검사했다.
- 지팡이 소켓 검사 한 건은 과거의 발사 위치 기준을 사용하고 있었다. 현재 전투는 서버 조준선에 지팡이 끝을 수평 투영하고 실제 끝 높이를 유지한다. 해당 검사는 같은 0.002스터드 허용 오차로 그 위치를 검증하도록 수정했다. 기존 별도 마법 직사 검사도 함께 통과했다.
- 전후 비교는 같은 카메라·R15·Traveler 장비로 직업당 5동작을 12개 시각에 캡처했다. 재생 시간은 각 공격의 설정 길이와 같다. 전 스킬 자세표는 발동을 기준으로 전·중·후 3시점씩 총 192장이다. 관절을 고정해 촬영했으며 위 캡처의 발사·다단 신호는 검토용으로 설정했다.

- 고정 빌드의 격리 복사본에서 실제 R15 플레이어로 직업별 기본 공격 1회와 스킬 5회씩 입력했다. K0Action을 통한 서버 승인, 클라이언트 어깨 움직임, Idle 복귀를 12회 모두 관측했다. Rapid Fire 1회에서 화살 발사와 사격 횟수 변경이 각각 3번 발생했고, 마법사의 시작 주문 3개도 각각 발사 신호가 1번 발생했다. 검사 대상 클라이언트 스크립트 오류는 0건이었다. 시험 영웅·장비·편성을 준비하고 실제 전투 서비스와 시각 모듈을 구동했다.

다음 담당은 QA와 사용자다. 게시 클라이언트·실기기에서 실제 적과 교전할 때의 가독성과 조작감을 확인해야 한다. 궁극기는 격리 리그와 자세표에서 검증했으며, 위 12회 Play 입력에는 포함하지 않았다. 현재 로컬 빌드이고 사용자 수용은 대기 중이다.

## 재현

1. 저장소 루트에서 `python3 tools/prepare-melee-actions-review.py --ranged`를 실행한다. 고정 빌드에서 `run-in-roblox --place builds/0.111.19/TheLastThrone-0.111.19.rbxlx --script /tmp/tlt-ranged-native.luau`를 실행해 마지막 출력 `RANGED_ACTIONS_ALL_PASS`를 확인한다.
2. `python3 tools/prepare-melee-actions-review.py --ranged --capture motion`으로 만든 `/tmp/tlt-melee-actions-capture.luau`를 0.111.18과 0.111.19에서 각각 실행한다. 같은 명령의 `--capture catalog` 출력은 0.111.19에서 실행한다. 캡처마다 Studio를 한 개씩 사용하고 각 출력을 따로 저장한다.
3. `python3 tools/render-melee-action-review.py --ranged --before BEFORE.log --after AFTER.log --catalog CATALOG.log --output /tmp/ranged-review --versions 0.111.18 0.111.19`로 재생본과 자세표를 복원한다.
