# 복귀 저장·파티 출발 취소 장애 복구

2026-11-26 · TLT-016/041/053/057 · ENG → QA · [P1 리뷰](../../reviews/repository-review-2026-11-26.md)

복귀 직전 저장이 불명하면 서버가 캡처한 영웅의 HP/MP를 유지하고 계정 임대 갱신에서 동일한 소유 토큰과 세대로 재시도한다. 접속 종료 중에도 보류된 수치를 먼저 확인하고 계정 소유권을 반납한다. 이미 반영된 체크포인트의 재시도는 계정 리비전을 다시 올리지 않는다. 소유권이 교체되면 이전 서버의 저장과 재열기를 거절한다.

파티 출발이 취소되거나 로비 복귀 준비가 중단되면 기존 이동 복구 경로에서 계정을 다시 연다. 일시적인 재열기 실패는 2초 간격으로 재시도한다. 출발 전 계정 소유권 반납 자체의 결과가 불명하면 정기 계정 갱신에서 재열기를 이어 간다. 로비·배틀 게시 안내는 검증된 단일 파일을 두 Place에 게시하는 현행 절차와 실제 클라이언트 수용 조건을 연결한다. [로비·원정 실행 계약](../../production/lobby-economy-and-expeditions.md#배포와-다음-수용)

| 검증 | 조건과 결과 |

이번 수용 범위는 로컬 장애 주입과 정적 검사다. 다음 담당 QA는 게시된 테스트 Experience에서 복귀 저장, 두 멤버의 출발 취소와 같은 연결에서 재시도, 로비·배틀 실제 왕복을 확인한다. 실계정 저장·실기기 수용은 후속이다. 이번 변경은 소스와 문서 검증 범위로 마감했다.
