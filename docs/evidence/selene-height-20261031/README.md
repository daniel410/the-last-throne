# 셀레네 크기 조정

2026-10-31 · TLT-016/057/061/084 · ART/ENG → QA

사용자 모바일 화면에서 셀레네가 플레이어보다 크게 보이는 문제를 확인했다. 공통 `SeleneVisual`의 TD 원본 외형 높이를 6.5에서 4.8 스터드로 축소하고 이름표도 머리 위로 옮겼다. 같은 생성자를 쓰는 야영지·동료·로비의 새 모델에 적용된다. 모델 메시·텍스처, 바닥 앵커·상호작용·동행과 치유 로직은 변경하지 않았다. 기존 자산 원본은 보존한다.

## 검증

0.58.5 Battle 빌드에 수정 모듈만 교체한 임시 격리 Studio fixture:

- `tests/selene-size-native.luau`: 17개 통과. 원본 TD 메시의 높이 4.8, 기본 R6 5.0 및 R15 약 5.46 스터드와 비교했고 바닥 접촉, 앵커, 이름표, 축척 옵션을 확인했다. 각각 기본 모델 대비 약 96%와 88%다. 실제 아바타의 체형·모자 등은 다를 수 있다.
- `tests/selene-support-native.luau`: 33개 통과. 야영지 원본 메시, 영입·동행·이동·지원·파티 상한 회귀 확인.

실제 모바일의 카메라 원근·다양한 아바타·사용자 시각 수용은 미검증이다. 게시된 게임에는 아직 반영되지 않았다. 다음 담당은 QA/DES다.
