# 네 영웅 강타의 자세와 명중 전후 비교

TLT-033/057/059 · 2026-11-21 · 기준 0.115.24 · 후보 0.115.27

[공식 사례 조사](../../research/2026-11-21-hero-force-feedback.md) · [고정 빌드](build.json) · [Studio와 CPU 결과](studio-results.json)

| 영웅 | 기술 | 공격 동작과 확정 명중 |
| --- | --- | --- |
| Knight | Vanguard Strike | 방패를 올려 상체를 감았다가 검을 전진시키고 앞무릎으로 제동한다. 두 가는 획이 찌르기 방향으로 모인다. |
| Dwarf | Stonebound Leap | 도약 정점에서 양 무릎을 접고 착지 충격을 몸통과 양 무릎으로 받는다. 명중점 아래에서 두 파열선이 올라온다. |
| Elf | Fan Break | 앞다리로 버티고 시위를 놓은 손을 크게 열어 준다. 궤적이 적의 바깥쪽으로 벌어져 산개와 밀어내기를 보여 준다. |
| Mage | Stone Lance | 지팡이로 모으고 반대 팔을 펴 돌창을 밀어낸다. 명중점에서 두 파편이 전방 아래쪽으로 퍼진다. |

같은 적에게 약타가 이어지면 강타의 피격 자세를 정점에 도달하는 시간과 20ms의 여유 동안 우선한다. 그 뒤 들어오는 타격은 현재 자세에서 보간한다. 피해 숫자, 서버 시점, 물리 루트와 적 공격 상태는 기존 전투 계약을 따른다. 적의 Windup/Active와 보스 보정도 적용한다. 기본 VFX 예산 안에서 본인과 아군에 같은 두 획을 사용하며, 해당 두 획이 생성되면 겹치던 발광 구형 효과를 생략한다.

## 전후 장면과 재현

- 격리 Studio의 같은 R15 리그, 무기, 바닥, 카메라와 기술 시각으로 전후를 고정했다. Knight는 준비 55%, Dwarf는 도약 61%, Elf는 확정 발사 50ms 뒤, Mage는 시전 60ms 뒤다. [공격 자세](hero-force-poses.jpg)
- 피격 효과는 같은 위치와 방향에 피해 42를 입력하고 45ms 시점으로 고정했다. hit 이벤트 소비자의 효과를 비교하는 정지 화면이다. [명중 형상](hero-force-contacts.jpg)
- `run-in-roblox --place builds/0.115.27/TheLastThrone-0.115.27.rbxlx --script tests/hero-force-feedback-native.luau`로 네 기술의 강타, 0~8ms 겹침, 80ms 후 후속타 전환, R6/R15 관절, 본인·아군 효과 예산, 피해 숫자를 재현한다. 전체 128개 기술 명중과 네 영웅의 연속 명중·조준·발사·리그를 별도 검사했다. [재현 소스](../../../tests/hero-force-feedback-native.luau)

새 검사 81건 중 기준은 53건에 실패했고 후보는 모두 통과했다. 후보의 Studio 10묶음은 247,541건, CPU 전직과 형상·취소 두 묶음은 15,147건을 통과했다. 조준 검사의 첫 시도는 로컬 포트 충돌로 시작하지 못했고 같은 빌드에서 단독 재시도해 통과했다. 고정 빌드의 SHA-256과 클라이언트 모듈 4개를 입력 커밋과 대조했다.

0.115.25에서 이전 시각으로 교체하는 검사 입력에도 강타 유지가 걸려 Spirit Arrowfall 마지막 피격 회귀가 실패했다. 0.115.26에서 두 타격 사이 시각이 0 이상일 때만 우선순위를 적용했다. 앞선 정지 화면에서 대상 몸에 묻히는 명중선을 확인해 0.115.27에서 화면에 보이는 앞쪽 분량을 늘리고 중앙 구형 섬광을 제거했다.

CPU의 `skill-presentation.spec.lua`는 기준과 후보 모두 기존 `K0MeleeMotion.luau`의 Luau 복합 연산자를 Lua에서 읽는 단계에 실패했다. 두 빌드에서 동일하게 발생했으며 통과 집계에서 제외했다.

## 남은 수용

후보는 미게시다. 전투 QA는 게시 테스트에서 실제 4인이 같은 적을 공격할 때 적 예고와 기술별 명중 방향을 구분할 수 있는지 확인한다. 저사양 터치 실기기의 연속 교전 프레임 시간과 사용자 타격감 수용은 후속이다.
