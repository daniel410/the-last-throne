# 스토리 내비게이션 연속 표시 · 0.57.2

- 작업 ID: TLT-028/050/061/084. 기존 내비게이션의 지면 투영이 스토리 지형의 영구 바닥을 누락하거나 목표의 고도를 따라가며 지면을 놓쳐 잠깐 숨겨질 수 있었다. 영구 지지면을 포함하고 현재 위치의 높이에서 바닥을 찾으며, 주변 지형이 아직 없으면 캐릭터 가까이에 목표 방향을 임시 표시한다.
- 기존 SETTINGS의 Navigation Trail은 기본 ON이며 OFF 시 일반 표시와 임시 표시를 모두 숨긴다. 유효한 목표가 없거나 훈련·사망 상태일 때는 표시하지 않는다. 클라이언트 시각 보정이며 서버 이동·목표·보상은 변경하지 않는다. 기존 [표시 설정 조사](../../research/2026-10-31-display-guides-settings.md)를 따른다.
- 검증: 격리 Studio Edit `tests/navigation-always-on-native.luau` 통과(거리·직선 방향·스토리 지지면·고도 차이·미로드 대체 표시·설정 ON/OFF·사망/훈련). 별도 새 Studio의 `tests/display-guides-native.luau` 50개 검사 통과. 같은 테스트 세션에 앞선 테스트 잔여 객체가 있을 때 해당 검사가 실패했으므로 독립 세션으로 재검증했다.
- 미검증: 게시된 다인 클라이언트의 실제 스트리밍·Story 4 전 구간과 모바일 성능/가독성. 다음 담당: 전투 UI/QA.
