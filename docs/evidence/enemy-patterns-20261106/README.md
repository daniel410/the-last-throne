## 실제 변경

- 실제49종에 일반2개·보스4개씩 **142개 서버 공격**을 연결했다. GoblinKing의 Orc fallback·왕3종의 같은 원형을 분리했다. 조건/사거리·순환·개별 쿨다운·반복 제한을 사용하고 일반 적의 시작 간격0.24초·같은 교전 강공격1개 제한을 적용한다. 원거리형은 가까운 거리/쿨다운 중 유효 바닥을 확인한 짧은 후퇴를 제한적으로 선택한다.
- cone/line/circle/ring/projectile/trail의 독립 판정과 실제 직선 마법탄·부채탄·유한 연타·돌진을 구현했다. 마지막 형상인trail은 이번에 순차 지점 공격이며 지속 피해 장판을 뜻하지 않는다. 서버가 대상·방향/지점·시각·피해를 고정하고 실제 벽/지면/높이/leash와 동일 펄스 중복을 검사한다. 직격 피해를 탄 수만큼 중첩하지 않는다. 다단 총 피해는 기존1타 예산을 나누며 정수 반올림 차이는 최대3이다.
- 얼음·불·거미줄·독·영혼·그림자·비전/물리 접점, 시전 응집·실제 비행·타격/파편·공간 공격 예고·상황별 타격음을 연결했다. 기존 무료 Creator Store 음원 카탈로그를 재사용하고 새 음원을 업로드하지 않았다. 경고 기하는 입자 품질과 독립이다. 접촉효과24묶음·투사체48개·이 층의 동시음원8개 상한/거리100stud와 정리를 둔다. 플레이어 영웅 음원의 기존 층과는 별도다.
- 서버의 실제 결과로 명중/블록/완벽 블록/보호막 전부·일부 흡수/회피/ForceField를 구분한다. 실제 HP감소 때 기존 약한 붉은 화면/신음을 유지하며 원소 접점·짧은 윤곽·공격 방향 표시·방향별 상체 반응을 더한다. 구 공통enemy 접촉을 억제하고 서버 공격/펄스/실제target Instance별 결과를 중복 제거한다.0HP손실은 hurt/신음 없음. 시각 효과로 서버 스턴/루트/스킬 취소 시간을 늘리지 않는다.
- 새 규칙의 기존 바닥 위험도 공통 방어·장비·보호막·회피/피격 결과 경로를 사용하며 완료/사망 후 지연 피해를 막는다. 신규 패턴은 서사 pause/진정·스턴·자세 붕괴·죽음·복귀 시 취소된다.
- Golem/SkeletonKnight의 준비 중 전방30% 피해 경감과 측후방 공략을 추가했다. 완전 면역은 아니며 기본 공격으로 일반 적 준비를 끊는 기존 규칙을 유지한다. 보스 강공격에는 보정 후 최소1.1초 회수, 그 외에는 최소0.45초 회수를 둔다. 기존 보스 공격/이동 보정 자체는 유지한다.
- **원정 규칙9**에서 신규 공격을 사용하고1~8의 공격/저장 자격을 보존한다.9의 기존 HP/공격력/레벨/보상은8과 같다. 보스 단독 최종 웨이브·기둥 순차 조작·설원10%진정·진행/보상 ID·동료 상한을 유지한다. 새 피해 대상은 현재 같은 교전의 영웅/원정 자격을 서버에서 검사한다.

## 3D·모션

Gloamwood8종은 기존 임시 블록 모델의 분절·타원 몸통/복부·테이퍼 꼬리·쐐기 송곳니/날개/왕관·원통 나무 몸통/뿌리·수관으로 다듬었다. 기존 모터/원형색·종족을 유지한다. TD 원형의 일부 중량형/보스에는 겹친 어깨 갑옷·능선/왕좌 문장, 시전자에는 초점 구체·지지대와 시전 소켓을 추가했다. 원래TD 메시/텍스처/공유 원본 파일은 수정하지 않았다. 모든 추가 기하는 massless·비충돌·비쿼리다.

긴 다단 공격을 기존 한 번의 스윙에 늘려 재생하지 않고, 서버 공격 시계의 각 타격/시전 유지·회수에 맞춰 기존 클립을 샘플링한다. 베기·내려찍기·시전·돌진·도약에 몸 준비 강조를 합성한다. 기존 지역 시전자 뼈와 일반 리그에 함께 연결했다.49종의 모든 모션을 별도 Blender 애니메이션으로 새로 만든 것은 아니다.

## 미검증·남은 범위·인계

아직 미게시다. 정상 Roblox 전투 완주/실제 다인·늦은 합류/리스폰·4인+AI 성능/네트워크·터치/패드·음소거/작은 화면·최종 미술/음향/난도·10~15세 관찰은 후속 QA다. 원정1~8과9를 혼동하지 않는다. 기존 전직·경제 작업과 사용자의 드워프 미커밋 파일을 이 작업에 포함하지 않는다.

계획의 모든 고급 특성을 구현 완료로 처리하지 않는다. Shaman 아군 연결 지원, 지속 Burn/Poison/Slow, 실제 땅속 잠복/무적, 분절별 개별 충돌/약점·반사/유도탄, 보스별 단계 전용 추가 조합·최종 컨셉 메시 교체는 후속이다. 현재 독/거미줄은 공격/원소 표현이며 새 상태 이상을 뜻하지 않는다. 첫 시험에서는 읽을 수 있는 공간 공격·피격 결과·반격 기회를 우선했다.

다음 QA는 고정 빌드의 신규 원정에서 Deepwood7대표→설원/화산/숲/묘지의 정상 전투를 관찰하고, PLAN/ART는 각 종의 피해 분배/클립·소켓·경고 크기와 위 후속 특성을 보완한다. 부모 티켓과 전체 계획 게이트는 In Progress로 유지한다. 빌드 입력/해시/결과는 `build.json`에 추가하며 실제 게시·릴리스 태그는 만들지 않는다.
