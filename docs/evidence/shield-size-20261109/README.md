# 방패 크기 확대 · 0.95.1

TLT-028/029/032/041/052/073/082/084 · 사용자 요청: 방패가 너무 작으니 키운다.

Traveler/Tempered/Veteran/Sentinel의 실제 착용 메시를 뒷면 손잡이 원점 기준 **1.30배**로 확대한다. 높이1.88→2.444studs, 폭약1.32→1.72studs로 늘며 두께도 동일비율로 유지한다. Grip/왼손 용접 위치는 보존하고 메시 중심 이동량도1.3배로 맞춘다. 원본 GLB/RBXM·UV/색/아이콘·다른 방패·수치/블록 판정은 유지한다. 새 자산 업로드는 필요 없다.

FourFamilyShieldVisuals 버전2 visualScale1.3과 WeaponAppearance에 연결한다. ShieldVisualScale이 다른 기존 투영은 다음 동기화 때 교체하므로 이전 작은 부품을 그대로 재사용하지 않는다. 올바른 새 크기는 중복 생성하지 않는다. 단순 승인 자산의 크기 수정이며 기존 제작 절차/등급 미술 조사를 재사용한다.

## 검증/마감

원본 자산 검증·고정 빌드·R6/R15 실제 크기/중심/교체·강타 방향·기존 방패 회귀 결과는 소스 고정 뒤 기록한다. 게시 클라이언트·실기기 조작·사용자 최종 크기 수용은 후속이다.
