# 몬스터 생성과 스토리 페이즈 전환 개선

2026-11-18 · TLT-040/087 · ENG → QA/릴리스 · 0.113.14 후보

- 목표 저장이 확인되면 서버가 현재 영웅의 근처 교전을 확인한다. 이미 접근 범위 안인 새 교전은 0.2초 주기의 다음 갱신을 기다리지 않는다. 기존 진도, 접근 거리, 지역 준비, 원정 소속을 검사한다.
- 에픽 완료와 보상을 먼저 전달하고 다음 지역 준비를 이어간다. 다음 지역 접근은 준비 완료 뒤 열리며, 다른 원정으로 바뀐 영웅에게 이전 원정의 준비 알림을 보내지 않는다.
- 스토리 몬스터는 종마다 최초 1회 리그를 조립하고 다음 개체부터 복제한다. 위치와 처치ID·난이도·보상 속성을 적용한 뒤 생성한다. 준비 지역의 길 연결, 경로 지면 정렬과 표면 처리는 실제 캠페인에 합친 뒤 한 번 실행한다. [선행 저장 개선](../monster-spawn-latency-20261118/README.md).

## 검증

- 격리 Studio의 [스토리 페이즈 시험](../../../tests/story-phase-speed-native.luau) 270검사 통과. 저장 대기 중 교전 생성 차단, 확인 직후 교전 활성화, 다음 지역 준비 전에 에픽 완료 통지, 원정 교체 뒤 알림 억제, 실제 몬스터 50종의 외형·조인트·위치·템플릿 상태 분리를 확인했다. 0.113.13에서는 주기 갱신이 없으면 다음 무리가 생기지 않았고, 다음 지역의 준비를 풀기 전까지 에픽 완료 통지가 대기했다.
- Studio 교전 경로 912검사, 지역 생성·실패·재시도 20검사를 통과했다. 다섯 지역의 NPC 32명, 지역 연결로 4개와 준비 실패 시 이미 활성화된 교전의 보존을 확인했다. 격리 Place에서 자산 콘텐츠 표현 경고 1건을 관찰했으며 실제 게시 클라이언트 외형 다운로드는 미검증이다.
- 실제 리그 7종을 섞은 50개 생성 작업을 교대로 5회 측정했다. 리그 조립·이동·해제 중앙값 6.14ms에서 기존 리그 복제·이동·해제 5.11ms로 약 17% 줄었다. 서버 모델 준비만 측정했다.
- 0.113.13과 0.113.14의 격리 Studio에서 동일 순서로 1회 측정했다. 새 Deepwood 생성은 10.69초 → 10.58초, DW-07 진입 후 다음 지역 준비는 4.06초 → 3.93초였다. 준비당 표면·경로 마감은 각각 2회 → 1회였고 두 시점의 인스턴스 수는 각각 27,046개와 39,583개로 일치했다.
- Lua 저장 지연 58검사, 경로 77,381검사, 부활 688검사, 난이도별 진행 4,621검사와 파티·지역 생성·스트리밍·체크포인트 회귀를 통과했다. 소스 546개를 컴파일했고 빌드 내부의 변경 런타임 소스 3개 및 파일 해시를 확인했다. [고정 빌드](build.json).

QA/릴리스는 0.113.14 게시 후 실제 Roblox 클라이언트에서 입장 직후 첫 무리, 마지막 처치 뒤 다음 페이즈, 에픽 경계의 완료 알림과 접근을 각각 확인한다. 새 Deepwood의 초기 생성은 격리 시험에서 약 10.6초가 남았다. 운영 서버 DataStore, 클라이언트 스트리밍·실기기·4인 P95와 사용자 수용은 미검증이다.
