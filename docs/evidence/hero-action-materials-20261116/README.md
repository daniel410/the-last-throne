## 영웅별 변경

| 영웅 | 기본 공격과 스킬 |
| --- | --- |
| 기사 | 기본 3타의 내려베기·올려베기·가로베기에 서로 다른 곡선을 쓴다. Whirlwind는 허리 높이에서 열린 호를 돌리고 밝은 부분이 검날을 따라 이동한다. Twin Cyclone은 두 기울어진 궤도를 유지한다. |
| 드워프 | 도끼는 세로로 떨어지는 넓은 날과 방향이 바뀌는 횡베기를 쓴다. 파쇄·포화·낙하탄은 지면에서 갈라지거나 위에서 떨어지는 잔상을 쓴다. 되돌아오는 도끼는 실제 무기 모델로 비행한다. |
| 엘프 | 시위에 건 화살에서 갈라지는 가는 기류와 부채꼴·낙하 화살을 구별한다. 명중 방향을 따라 관통 흔적을 남기고, 확정된 화살 끝점 뒤로 이어진 광선은 꼬리부터 걷힌다. |
| 마법사 | 기본 지팡이는 보랏빛 횡베기다. 물 구체는 어두운 유리 몸체·국소 하이라이트와 후방 물방울, 냉기 폭풍은 폭이 변하는 흐린 기류, 칼데라는 높이가 다른 불기둥을 사용한다. 발광 계열은 짧은 색광이 주변 표면에 닿는다. |

기존 128개 스킬의 고유 형상과 아이콘 대응을 바탕으로 발동·명중 장식을 교체했다. 13가지 곡선에 기술별 폭·원소·펄스·궁극기 여부를 적용한다. Bomb Toss, Frost Ring, Spirit Rain은 기존 승인 전용 발동 재질을 우선하며 이 세 기술도 새 명중 경로를 탄다. 원본 TD 무기와 기존 승인·엔진 재질을 사용했다.

피해, 공격 대상과 사거리는 기존 서버 판정으로 결정한다. 영웅 잔상은 기존 장식 24레코드·거리 80스터드 한도와 취소·회수 경로를 사용한다. 추가 반사광은 그림자를 끄고 0.18초에 소멸한다. 동시 할당 상한은 데스크톱 3개, 터치 1개다. 기존 투사체·스태프 광원은 별개다.

기본 공격 4쌍과 스킬 6쌍은 기준 소스 bb884293과 같은 카메라·조명·R15 자세·표본 시점으로 촬영했다. 궤적은 엔진에서 계산한 뒤 캡처를 위해 동결하고 입자는 다시 방출한다. 장비 텍스처 로딩과 입자 표본은 두 촬영에서 달라질 수 있다. 움직이는 비교 자료는 자세를 고정하고 기술별 0.015초부터 0.295초까지 0.04초 간격으로 잔상을 보여 준다. 재생은 2.5배 느리며 마지막 표본에서 잠시 멈춘다.

초안에서 활 잔상이 전투 거리에서 희미했고 물 몸체가 단색으로 뭉쳤다. 활 끝선을 분리하고 유리 몸체와 물방울의 명도·배치를 조정했다. 검격의 밝은 부분은 인접 구간 끝 폭을 맞춰 경계가 튀는 현상을 줄였다.

## 검증과 인계

[고정 소스 빌드](build.json) · [게임 빌드·검증 Place·Git 소스의 변경 모듈 9개 일치](integrity.json) · [Studio 검사](native.json)

검증 Place와 동일 빌드 파일에서 각각 24묶음 118,983개 검사를 통과했다. 로컬 Studio에서 4영웅 8기본 동작·128스킬·199스킬 펄스, 취소·거리 제한·과포화·회수, 다중 화살 끝점, 도끼/주문의 중복 도착 방지를 검사한다. R6/R15 투사체 수명 검사는 두 거리와 30/144Hz 수동 스텝을 사용한다. 터치 한도 모의 검사는 실기기 GPU 측정을 대체하지 않는다.

다음 담당은 전투 QA·아트다. 게시 테스트 클라이언트에서 4인 연속 전투와 저사양 터치 프레임 시간, 카메라 방향별 검끝·명중점 일치, 사용자 미술 수용을 확인한다. 이번 빌드는 로컬 검토용이며 Roblox 게시·릴리스 태그는 없다.
