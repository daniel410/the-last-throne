# 사망 XP 안내창 수정

- 작업: 사용자 요청 / TLT-052 관련 / UI 결함 수정. 불투명 패널과 장식을 제거하고 영어 `OK` 버튼으로 닫도록 변경했다. 최종 안내도 확인 전까지 유지하며 저장 상태가 이후 변경되면 새 결과를 표시한다. 화면 크기 변경만으로 닫힌 안내를 다시 열지 않는다.
- 검증: 소스에서 투명 배경, 버튼 연결, 상태 변경과 크기 변경 경로를 확인하고 `git diff --check` 통과. Studio Play 실제 화면·버튼 입력 및 모바일 실기기는 미검증. 다음 담당: QA. 빌드·게시 없음.
