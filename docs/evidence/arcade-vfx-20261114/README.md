# D&D 아케이드 참고 VFX 개선

2026-11-14 · TLT-033/057 · ENG/ART · 소스/격리 엔진 검증, 미게시

## 변경과 근거

사용자 제공 [D&D 아케이드 영상](https://www.youtube.com/watch?v=xUhOca48eLQ)의6:06~6:11 명중점에 모이는 짧고 뾰족한 접촉광을 참고했다. [관찰 표본·Diablo IV/WoW 비교·채택 판단](../../research/2026-11-14-arcade-contact-vfx.md).

- `HeroVFX`: 물리 명중에 카메라 평면의 별 모양 섬광·밝은 중심을 제작했다. 기사/도끼와 화살/총탄의 관통 형상을 나누고0.13초에 소멸시킨다. 물리 접촉의 부드러운 halo를 제거하고 검격은 옅은 면/밝은 날을 나눠0.22초 이내 회수한다.
- `K0HitEffects`: 확정 명중에서 별 모양이 생성될 때 중복 선을 생략하고 기존3개 파편을 확정 공격 방향으로 보낸다. 피해 숫자·Slime 방울·장식이 생략될 때의 최소 접촉광은 유지한다.
- 서버 기술·범위·피해·저장·보상·무적·TD는 변경하지 않았다. 영상 자산을 추출/복제하지 않았고 새 외부 자산/업로드 의존성은 없다. 사용자 미커밋 모션·자산은 작업 스테이징에서 제외했다.

## 검증

- 격리 Studio 엔진 **18묶음·96,242검사 PASS**. [원시 결과](native.log)·[요약](validation.json)·[입력 해시](inputs.json)·[소스/후보/fixture 출처](provenance.json).
- 기존 영웅128기술·몬스터50종146공격, 원소 팔레트/금빛 성속성·전용 바람·예산/정리 회귀를 포함한다.
- 신규585검사: 정면/측면/상단 카메라의 접촉 평면·크기·물리 비참여,0.13초 소멸, 확정 명중 이벤트 함수의 피해 숫자/방향성 파편/중복 선 제거,50연속 접촉의 전역 예산과 정리. 실제 RemoteEvent 전송·게시 클라이언트 수용을 대신하지 않는다.
- Python 준비 도구 문법·후보 소스 해시·Git 공백 검사를 확인했다. Lua update 비용은 기존 격리 검사값이며 GPU/실기기 성능을 뜻하지 않는다.
