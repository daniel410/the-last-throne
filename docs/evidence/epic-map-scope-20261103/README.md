# 상세맵을 에픽별7스토리로 제한

2026-11-03 · TLT-028/061/084 · DES/ENG → QA · 로컬 구현, 미게시

사용자가 첨부한 상세맵은44지역을 한 번에 투영해 각 에픽이 지나치게 작고, 오른쪽에는35개 스토리가 함께 표시됐다. `CampaignMapScope`가 선택 에픽의 본편7지역만 필터링하고 `DeepwoodMap`의 지도·목록·진행률·번호01~07·FIT 범위를 함께 전환한다. 처음 열 때 현재 위치의 에픽을 선택한다. 다른 에픽은 상단 가로 스크롤의5개 TD 버튼으로 열람하고 `YOU`는 현재 영웅의 에픽으로 돌아간다. 기본 화면은7지역을 모두 맞춘다. 선택 지역의 실제 선행 조건·탐험 상태·서버 진행은 기존 계약을 읽는다.
