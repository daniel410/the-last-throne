# 드워프 도끼 투척 자세 연속성

2026-10-31 · TLT-005/014/032/055/084 부분 개선 · ART/ENG → QA/DES

투척체가 생성된 뒤 첫 갱신에서 손에 쥔 도끼의 회전을 버리고 비행 방향의 고정 자세로 바뀌던 동작을 고쳤다. 생성 시 실제 무기의 월드 회전을 보존하고 비행 방향의 가로축을 중심으로 회전시킨다. 피해·사거리·서버 시간·기술 조건은 변경하지 않는다. 기존 무기 모델의 손 소켓과 날 정렬도 변경하지 않았다. 투척 모형은 종전처럼 장식이며 손의 무기는 남는다.

[PlayStation 공식 전투 가이드](https://www.playstation.com/en-us/games/god-of-war-ragnarok/god-of-war-combat-refresher-course/)에서 일반 공격과 투척의 시각적 구분을 2026-10-31 확인했다. 기존 [영상 조사](../../research/2026-10-31-sword-axe-motion-video-review.md)의 후속 동작 관찰을 참고한 적용 판단이며 원본 동작 복제는 아니다. [Roblox 애니메이션 이벤트 문서](https://create.roblox.com/docs/animation/events)의 타임라인 이벤트도 확인했으나, 이 구현은 기존 서버 시각/속성 기반 연출을 유지한다.

## 검증과 한계

- `run-in-roblox`에서 0.58.4 Battle의 `K0SwordVisual`만 작업 소스로 치환한 임시 격리 fixture를 사용했다. `tests/k0-player-weapons-native.luau`의 투척 사례만 실행해 12개 검사 통과(해당 사례 8개). 원본 무기 방향 유지, 장식 투척체 생성, 물리 연결 제거, 캐릭터 루트 불변을 확인했다. 이는 정식 빌드가 아니다.
- 전체 오래된 무기 fixture를 먼저 실행했을 때 983개 확인 중 24개 사례가 현재 자산 ID·크기·수명주기 기대와 달라 실패했다. 투척 사례 자체는 통과했다. 전체 회귀 통과로 보고하지 않는다.
- GPU에서의 회전 방향·날 궤적, 각 아바타 비율, 네트워크와 실제 기기 조작, 사용자 미술 수용은 미검증이다. 다음 QA/DES는 실제 플레이에서 이 부분을 검토한다. 상위 티켓은 계속 진행 중이다.
