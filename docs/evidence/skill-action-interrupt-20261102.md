# 다른 액션 중 스킬 입력 누락 수정

2026-11-02 · TLT-005/008/028/032/033/050/084 · ENG → QA

사용자 요청: 다른 액션 중 누른 스킬이 사라지지 않고 바로 발동하도록 수정한다. 원인은 서버의 Idle 전용 스킬 검사, 같은 프레임에 소비된 예약 액션에 의한 입력 반환, 클라이언트의 누르고 있는 일반 액션 재전송이었다. 원인이 명확한 결함 수정으로 별도 경쟁 게임 조사는 생략했다.

일반 기술1~5·궁극기·기존 Mage CastArcane은 사용 조건을 만족하면 Idle/Attack/Block/Dodge에서 현재 행동을 취소하고 즉시 시작한다. 다른 기술로도 전환할 수 있다. 쿨다운·MP·해금/슬롯·무기/방패·창고 잠금·사망/기절 제한은 유지하며, 조건 거절 시 서버의 현재 액션과 자원을 보존한다. 승인 시 이전 공격/방어/회피·예약 입력을 정리하고 회피 무적/서버 소유권을 해제한다. braced 기술에서 전환할 때도 새 이동속도를 적용한다. 이미 판정된 피해와 이전 기술의 MP/쿨다운은 되돌리지 않는다.

클라이언트는 기술 요청 시 누르고 있는 공격 입력 집합과 공격/방어/달리기 재전송을 종료한다. 방어/달리기 버튼 해제 처리는 보존한다. 일반 액션 재개에는 버튼을 놓고 다시 누른다. 기술 거절 시에도 재전송은 종료되지만 서버의 현재 액션과 버튼 해제 경로는 남는다.

## 검증

- `lua tests/skill-action-interrupt.spec.lua`: **1,221개 통과**. 실제 서버 함수/RemoteEvent 콜백과 클라이언트 발송 함수를 추출해 실행하고 엔진 경계를 stub으로 대체한다. 4클래스×4상태×5슬롯, 궁극기/기존 마법 경로, 회피 소유권·무적 해제, 예약 입력 정리, MP/쿨다운 단일 차감, 거절 시 행동 보존, 같은 프레임 예약 회피와 스킬 입력, 누르고 있는 입력을 검사한다. 성장/해금 경계는 stub이며 실제 자격 수용을 뜻하지 않는다.
- 수정 전 HEAD 서버를 `/tmp/tlt-skill-interrupt-before.luau`로 추출해 `TLT_COMBAT_SOURCE=/tmp/tlt-skill-interrupt-before.luau lua tests/skill-action-interrupt.spec.lua` 실행: `knight Attack slot1 starts immediately`에서 실패해 기존 결함 재현.
- `lua tests/k0-rules.spec.lua`: **125개 통과**.
- `lua tests/skill-stat-preview.spec.lua`: **1,368개 통과**.
- 열린 Battle Studio의 Edit 환경에서 수정 서버/클라이언트 전체 소스를 각각 `loadstring`으로 컴파일 성공. 함수를 실행하거나 열린 게임 소스/상태를 변경하지 않았고 Play를 시작하지 않았다.
- `git diff --check`: 통과.

실제 RemoteEvent 전송·클라이언트 모션·PC/터치/패드 조작·다인·체감 밸런스는 미검증이다. Lua 격리 회귀/Studio 컴파일을 엔진 전투 실행으로 보고하지 않는다. 빌드·게시·릴리스는 실행하지 않아 VERSION을 유지한다. 기존 미커밋 로비/이동 작업과 자산은 보존한다. 다음 QA는 공격·방어·회피/다른 스킬 중 기술/궁극기 즉시 전환과 MP 부족·쿨다운 거절 시 행동/버튼 해제를 실제 입력으로 확인한다.
