## 권한 오류의 실제 원인과 정정

처음에는 PlaceId=0인 로컬 파일에서 업로드를 호출해 `asset:read` 미부여 오류를 받았다. 전체 Studio 재시작 후에도 같은 로컬 문맥에서는 같았다. 이 오류를 단순히 사용자가 권한을 켜지 않은 문제로 안내한 것은 잘못이었다.

사용자의 웹 확인 요청으로 [Roblox 공식 MCP Open Cloud 문서](https://create.roblox.com/docs/studio/mcp-open-cloud)를 확인했다. **권한은 게시된 게임별로 저장되며 미게시 로컬 파일에서는 사용할 수 없다.** 기존 RPG Battles(Place129388473517823, Universe10773575153)를 공식 CLI로 열고 `asset:read`와 `asset:write`를 각각 GET으로 확인한 결과 둘 다200이었다. 현재 두 권한은 이미 허용되어 있어 추가 활성화 요청이 필요하지 않았다.

같은 계정9156786071/같은 GLB 경로에서 업로드가 성공했다. API 키·쿠키·다른 자격증명·디렉터리 이동으로 권한을 우회하지 않았다. 게시된 Place에서는 읽기/업로드 권한 문맥만 사용했고 인스턴스 편집·저장·Experience 게시·실행·DataStore 호출을 하지 않았다. 자산 삽입/교정/월드 검수는 로컬 사본에서 수행했다. 이전 실패/재시작은 `upload-block.json`, `restart-retry.json`의 역사적 기록이며 현재 차단 상태가 아니다.
