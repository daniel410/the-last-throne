# 상점 버튼 높이 조정

2026-11-01 · TLT-028/043/061/084 · ENG/DES → QA · 0.58.13 로컬 시험판·미게시

사용자 후속 요청에 따라 Potion Shop/Blacksmith 데스크톱 BUY/SELL을 Y82→37로45px 올리고, 분류 행도 Y132→87로45px 올렸다. 상품 목록도 같은 만큼 올라가 표시 공간이 늘어난다. BUY/SELL의 기존 가로 중앙 정렬과 분류 순서를 유지하며, 잔액 영역을 왼쪽에 확보해 버튼과 겹치지 않게 한다. 짧은 모바일 창과 Diamond Shop 배치는 유지한다. 원인이 명확한 배치 수정으로 기존 제작 스킬/공통 UI 계약을 적용한다.

고정 소스·빌드/해시는 build.json, Studio 검증 결과는 studio-result.json을 따른다. 실제 게시·실기기·거래 회귀는 미검증이다. 다음 담당 QA는 실제 데스크톱에서 잔액·버튼 비중첩과 분류/상품 영역을 확인한다.
