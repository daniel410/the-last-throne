# 영웅 공격의 감속 상태 연출

2026-11-23 · TLT-033/057/059 · 기준 0.115.60 · 고정 후보 0.115.62

| 영웅 | 기술 | 동작과 피격 효과 |
| --- | --- | --- |
| Knight | Sweeping Break | 검 쪽 어깨를 낮춘 뒤 앞다리로 회전을 받는다. 적 하체에 얇은 강철 궤적을 남긴다. |
| Dwarf Axe Thrower | Low Sweep | 낮게 벤 뒤 팔꿈치를 당겨 한손 도끼를 거둔다. 발 가까이에 흙 획이 생기고 머리 위 기절 표시는 함께 유지된다. |
| Elf Archer | Vine Trap | 활을 낮게 들어 함정을 발사하고 시위를 푼 손을 내린다. 감속된 적의 다리 옆에서 덩굴 획이 솟는다. |
| Mage | Tidal Ring | 빈손을 몸 쪽으로 모았다가 옆으로 연다. 감속된 적의 하체를 낮은 청록 물결이 감싼다. |

서버가 적에게 감속을 적용할 때 기존 만료 시각과 함께 효과 형태를 기록한다. 피해량, 감속 배율·시간, 면역과 기절 규칙은 기존 서버 경로를 따른다. 일반 감속은 부착 곡선 두 개로 표시하고, 최초 0.22초 동안 굵은 획을 얇게 줄인다. 같은 유형의 갱신은 부착점을 재사용한다. 효과는 적을 따라가며 사망·초기화·만료 또는 카메라와 95스터드 넘게 떨어질 때 정리된다. 기본 Gravity는 보라색 윤곽을 유지한다. [공식 사례 조사](../../research/2026-11-23-hero-slow-presentation.md)

## 검증

- Rojo 고정 빌드에서 Studio 사본의 SHA-256과 런타임 모듈 6개를 입력 커밋 `d60d23b9`에 대조했다. [빌드 기록](build.json)
- 같은 R15 리그·카메라·조명에서 접촉 후 64ms의 자세와 감속 초기 효과를 비교했다. 0.115.61에서 도끼 뒤로 흙 획이 가려졌고 Vine Trap의 활이 높았다. 0.115.62에서 흙 획을 낮고 넓게 옮겼으며 발사 자세의 활 각도를 25도에서 12도로 낮췄다. 격리 장면에서 기준 빌드의 전신 강조 코드와 후보 빌드의 감속 렌더러를 각각 실행했고, 형태 확인을 위해 피해 숫자 레이어를 숨겼다. [전후 화면](slow-effects-comparison.jpg)

- Studio Edit 검사 14묶음 260,713건을 통과했다. R6/R15의 128개 기술, 표식, 자세 붕괴, 피해 숫자, 기절, 아군 효과 우선순위와 엘프 발사 시점을 점검했다. 신규 감속 검사는 후보 157건을 통과했고 기준은 공통 50건 중 18건이 새 조건을 충족하지 못했다. 기존 기사 기절 검사는 스킬별 곡선도 명중으로 인정하도록 수정한 뒤 기준과 후보에서 각각 296건을 통과했다. [검사 결과](studio-results.json) · [감속 재현 코드](../../../tests/hero-slow-presentation-native.luau)
- 전직·스킬 형상·Place 역할 CPU 검사 14,077건을 통과했다. 별도 난이도 CPU 검사는 기존 rules18 버전 기대값에서 중단됐으며, 해당 검사와 입력의 Git 내용은 기준과 후보가 일치했다.
