# 스킬 상세의 계열 전환 수정

2026-11-01 · TLT-028/031/050/052/084 · ENG → QA · 로컬 수정·미게시

Steel Knight/Paladin 버튼을 눌러도 선택 노드를 공통1번으로 되돌려 같은 상세가 보이던 결함을 수정했다. 공통 기술을 보고 있다가 계열을 누르면 해당 계열 첫 전직 기술(Counter Slash/Oathblade)이 표시된다. 전직 기술을 비교 중이면 상대 계열 같은 순번으로 제목·효과·타격수·수치·쿨다운·자격을 전환한다. 다른3클래스도 같은 규칙이다.

상세에는 선택 계열 미리보기 또는 양 계열 공통 기술임을 영어로 표시한다. 공통 기술은 직접 선택하면 원래 효과를 유지한다. 저장된 계열·성장·스킬 편성·서버 자격은 변경하지 않으며 Lv1 전직 기술은 잠긴 미리보기다. 승인 TD 프레임·아이콘·버튼은 그대로 쓴다. 원인이 명확한 UI 결함으로 제작 스킬의 조사 생략 조건을 적용했다.

변경: HeroSkillTree, SkillStatText, 기존 skill-stat-ui-native 회귀 검사. 4클래스×양 계열×첫/중간/궁극기 전환 후 실제 생성된 상세 제목·계열 표시·잠금·훈련 금지·저장 상태 보존을 검사한다. 기존 전체 스킬/스탯 UI 검사도 실행한다.

고정 소스 빌드·엔진 검사 결과는 build.json과 skill-stat-ui-native.log에 기록한다. 네이티브 GUI 생성/텍스트 검사는 실제 버튼 클릭·렌더 화면/실기기·게시 클라이언트 수용과 구분한다. 후자는 미검증이며 상위 티켓은 진행 중이다. 다음 QA는 데스크톱/모바일 가로에서 계열 버튼을 실제 눌러 수용한다. Roblox 게시/릴리스 태그 없음.
