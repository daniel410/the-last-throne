# 난이도 캠페인 이관·재플레이 수정 검증

2026-11-15 · TLT-050/061~065/084 · ENG → QA/사용자 수용. **0.109.4 로컬 구현·고정 빌드·격리 Studio Edit 검증 완료**. 일반 입력 완주·실계정 저장·게시·실기기·다인 수용은 미검증이다.

## 변경과 근거

구 계정의 미완료 선택 퀘스트/부분 목표가 이관에서 빠지는 문제, 다른 난이도의 활성 원정 때문에 Easy 부분 진도의 소유를 잘못 판단하는 문제, 과거 FV/EC 이력과 새 GW 완료의 합산 진도가 검증에서 막히는 문제, 재플레이용 임시 선행 완료가 영속 진도로 들어가는 문제를 수정했다. 완료한 Hard 원정의 다음 장은 실제 이벤트가 있을 때만 Hard 부분 기록으로 귀속한다. 구 확장 저장은 공통·활성 저널의 이관용 복사본을 전투 단계 규칙에 맞게 정상화해 완료/부분 목표 로드 차단을 해소했다.

`CampaignModeProgress`는 장별 이관과 실제 완료 집합의 연속 위치를 계산한다. `AdventureRules`는 재플레이 체크포인트와 영속 진도 저장을 구분하며, `InventoryRules`는 실제 처리한 장만 모드 저널·공통 이력에 합친다. 새 회귀 검사2개와 Native 준비 도구를 추가/확장했다. 난이도별 초회 수령·공유 성장/지갑/보유품 계약은 [현재 사양](../../production/campaign-mode-progress-2026-11-15.md)을 따른다. 최초 구현의 [0.109.0 증거](../campaign-mode-progress-20261115/README.md)는 보존한다.

소스 검사는 합계 **13,720건**이다. 구 순서21장 완료 계정은 실제 GW 미완료 때문에 새 HG 입장이 계속 잠긴다. 별도의 구 순서28장 완료 계정은 재플레이 이후 HG-01 최초 XP/Gold/Diamonds와 수령 기록을 함께 저장하고, 기존 장비 및 GW 목표·선택·이관 면제를 재지급/변조하지 않는 것을 확인했다. AccountStore 재접속 검사는 메모리 adapter를 사용한다.

정확한 **0.109.4 산출물**을 연 격리 Studio Edit DataModel(`PlaceId=0`, 플레이어0)에서 관련10개 Source 고정과 전체 소스 컴파일을 선행했다. 위 캠페인/이관/재플레이8,432건과 교전·네비 수명823건, **합계9,255건 통과**. [실제 엔진 출력](native-fixed-build.json). 대표4모드 계정 JSON은115,144 bytes이며 최악 저장량이나 실기기 성능의 보장 수치가 아니다. 소스 검사와 엔진 검사는 서로 다른 검증 층으로 구분한다.

## 미검증·다음 담당

이번 빌드의 Play 일반 입력 완주, live DataStore 저장/재접속, Roblox 게시, 실기기, 다인 플레이와 사용자 수용은 수행하지 않았다. 게시·릴리스 태그도 만들지 않았다. QA/사용자는 **0.109.4**에서 일반 입력으로 Hard 첫 목표의 몬스터/상호작용과 다음 스토리 진행, 구 계정의 선택 퀘스트 보고·부분 목표 복원, 모드 왕복·재플레이 이후 신규 장의 초회/반복 보상을 확인한다. 게시 테스트 Experience 이동과 실계정/기기·파티 수용은 해당 단계에서 별도 기록하며 상위 티켓 수용 게이트는 유지한다.
