TLT-033/057/059 · 2026-11-22 · 기준 0.115.49 · 후보 0.115.52

| --- | --- |

서버는 적마다 스킬 사용자의 표식 소유권, 종류와 만료를 확인한다. 해당 명중에 적용한 표식 종류를 기존 확정 피해 이벤트에 실어 보내고, 클라이언트는 소모 기술의 정의와 일치할 때 짧은 곡선 두 개를 그린다. 여섯 표식은 벌어지는 곡선과 색으로 구분한다. 아군 표시 수명은 0.16초다. 효과 슬롯이 포화돼도 피해 숫자를 표시한다. 피해 배율, 자세 피해, 판정 범위와 발동 시각은 기존 기술 정의를 따른다. [공식 사례 조사](../../research/2026-11-22-hero-mark-impact.md)

## 검증

- 0.115.49와 0.115.52의 고정 Place에서 같은 R15 검토 리그, 무기, 조명, 카메라를 사용했다. 두 번째 Sunward Cross와 세 기술의 명중 후 52~67ms를 정지해 비교했다. 0.115.50 화면에서 강화타의 두 직선이 약하게 보여 폭과 굽힘을 조정했다. 0.115.51 경로에는 다른 입력으로 만든 산출물이 이미 있어 보존하고, 후보 입력은 0.115.52로 빌드했다. [전후 화면](mark-impact-comparison.jpg)
- Studio는 표식 소모 기술 22개의 정상·강화·타인 소유·만료·불일치·중복·후속타를 비교했다. 피해량, 자세 피해, 적 처치 시 위치 스냅샷, 두 획, 시각 예산 포화의 피해 숫자와 네 기술의 자세를 함께 점검했다. 기준에서 341건 중 113건이 실패했고 후보는 341건을 모두 통과했다. [재현 검사](../../../tests/hero-mark-impact-native.luau)
- 128개 기술의 R6/R15 자세와 명중·발사·아군 VFX를 포함해 Studio 13묶음 246,468건을 통과했다. CPU 전직·스킬 효과 15,075건을 통과했다. 로컬 빌드의 런타임 모듈 6개를 소스 커밋과 바이트 단위로 대조했다. [검사 결과](studio-results.json) · [고정 빌드와 모듈 해시](build.json)
