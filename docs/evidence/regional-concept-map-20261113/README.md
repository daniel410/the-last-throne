## 변경

나머지4에픽의 본편28·선택8·에픽 대표4장을 각각 내장 ImageGen으로 생성했다. 사용자 정정으로 초기 Gloamwood의 Deepwood형 목조 마을 초안은 제외하고 기존 `gloamwood-environment.png`를 직접 참조한 푸른 밤숲·굵은 은백색 거미줄·뿌리 침식 석조 감시성채·작은 호박색 피난처로 교정했다. 이미지별 원본·참조 해시·실제 사용 프롬프트는 콘셉트 폴더의 manifest/prompts가 정본이다.

실제 Blender MCP로 별도 `TLT_Regional_Story_Architecture_20261113` 장면에서34종·1480파트를 직접 조형했다. 기존 사용자 Blender 장면을 보존하고 Standard/sRGB/None/Exposure0/Gamma1/Curves Off를 확인했다. GLB·원본 JSON·재현 제작 소스·Blender 렌더4장을 보존한다. 런타임은 새 외부 메시 업로드 대신 실제 Blender에서 추출한 기본형/CFrame/색/고체 계약으로 같은 구조물을 재구성한다. `.blend` 전체 사용자 파일을 덮어쓰지 않았다.

`RegionalConceptArt`가 기존 반복 대표 건물을 대체해 실제34구역에 각1개 대표와 보조3개, 낮은 재료 군집·길 마감을 배치한다. FV-Q1/EC-Q1은 본편 첫 구역을 공유하며36스토리를36별도 맵으로 늘리지 않는다. Gloamwood7곳은 감시성채/구조 마당/뿌리 피난처/뿌리 보루/석조 로프 받침/정찰대 탈출벽/여왕 감시성채, FV10곳은 구조소/피난처/봉화/기록고/썰매/잠금 성문/거울 정자와 선택3곳, EC10곳은 승강기/작업장/보강 광산/쌍펌프/설계고/시험로/용광로와 선택3곳, HG7곳은 관리인 문/동맹 쉼터/지하 통로/권양기 문/쌍장치/왕릉/빈 결속대다.

전투·목표·NPC·사건 윙/연결로·실제 꺾인 보행 경로·물리 점유·5점 지면을 예약한다. 작은 구역에서는 같은 구조물 비율을 축소하며 충돌을 끄거나 목표를 옮겨 배치하지 않는다. 건축/실체 있는 바위는 고체, 거미줄/천/길 마감은 비충돌이며 추가 스크립트·입자·Light·프롬프트·프레임 루프가 없다. 지역당 새 장소520파트·포장56개 이하를 검사한다. Deepwood·보상·몬스터 수·계정 저장·도보 에픽 연결은 보존한다.
