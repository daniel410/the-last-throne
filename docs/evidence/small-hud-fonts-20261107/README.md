# 로비·배틀 작은 글씨 확대

2026-11-07 · TLT-028/057/084 · ENG/DES → QA · 0.83.3 · 미게시.

사용자 요청으로 로비·배틀 기본 화면의 가장 작은 글씨를 약1px 확대한다. 배틀 스킬명8→9, 물약명9→10, 상태/자원/입력 힌트10~11→11~12, 미니맵 지역9→10·방향/현재 위치10→11, 로비 선택 배지10→11을 적용한다. 축소형 메뉴의 글자 제한9~13→10~14. 로비 TD 이름표는 작은 크기 목표14/16→15/17과 기존 이름표 내부 여백 조정으로 확대하며 원본 그림/타일 크기/동작은 유지한다. 큰 제목과 본문은 유지한다. 공통 테마나 상세 메뉴 전체의 글자 크기는 변경하지 않는다.

명확한 가독성 보정이므로 제작 스킬의 결함 수정 예외를 적용한다. 변경 범위는 클라이언트5개 파일·VERSION·이 증거 폴더이며 기존 미커밋 모델/이미지/증거 변경은 제외한다. 서버 전투/저장/재화 계약은 변경하지 않는다.

검증 예정: 고정 소스 단일 빌드, 기존 모바일 UI 엔진 검사, 로비 이름표/배틀 작은 글씨 실제 엔진 크기 확인. 게시 클라이언트·실기기·사용자 시각 수용은 미검증이며 다음 담당 QA가 확인한다. 부모 티켓 상태는 유지하고 게시/릴리스 태그는 만들지 않는다.
