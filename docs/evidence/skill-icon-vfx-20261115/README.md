# 아이콘 기반 전체 스킬 VFX 개선

TLT-033/057/059 · 2026-11-15 · ART/ENG · 구현/격리 엔진 검증, 미게시. 전체 G4와 사용자 미술 수용은 미완료.

## 변경·원천

사용자 요청에 따라 신규 영웅 스킬 아이콘128개를 직접 대조하고 각 기술의 실제 형상/원소/공격 방식과 연결했다. [조사와 채택 판단](../../research/2026-11-15-skill-icon-vfx.md)·[아이콘 해시/의미/개별 대응128개](../../../assets/effects/skill-icon-vfx-v1/manifest.json).

- 기사: 각진 방패, 반격/보호, 서약 보석, 도발·돌진과 검격의 방향을 보강했다. Oath of Dawn은 새 아이콘에 맞춰 큰 빛 검을 금빛 새벽 문장과 동료 방패3개로 교체했다.
- 드워프: 파쇄 균열·파편, 도끼 경로와 총구/산탄, 폭탄의 포물선/튐/구름, 공성탄 궤적을 구별했다.
- 엘프: 화살 깃·조준/관통·교차·후퇴, 자연 잎·꽃잎·보호와 정령 잔상을 보강했다. 부채꼴은 확정 발사점/기존 부채꼴 방향을 따른다.
- 마법사: 비전/얼음/암석의 결정 면, 물방울·증기, 중력의 수렴 궤도, 용암 직선의 이음/펄스와 방어 보석을 추가했다. Wind Lance는 기존 전용 렌더러에서 두 열린 면을 앞쪽으로 가늘게 만들었다.

`SkillIconVFXProfiles`/`SkillIconVFX`와 기존 `HeroVFX`/`SkillVFXProfiles`/`WindLanceVisual`만 클라이언트 표현을 변경한다. 새 텍스처 업로드는 없다. 기존 원소 팔레트·서버 기술/피해/범위/시간/MP/상태·성장·소유권·저장·TD Experience는 변경하지 않는다.

주 형상을 먼저 만들고 남는 개별 예산에 아이콘 장식을 넣는다. 기존 개별 최대 Beam48, 일부 마법 방어/성속성24와 전역 Beam240/터치144·면160/터치80·입자192/터치96·동시12/터치8 상한을 유지한다. 포화 시 일부 장식은 생략된다. 빈 Chain Lightning에는 새 방전/명중 대상을 생성하지 않는다.

## 검증·재현

실제 Studio 엔진에서 계정/플레이어/저장 없는 별도 PlaceId0 fixture로 검사한다. 게임 입력·실제 Player·RemoteEvent 전송·게시 테스트의 증거는 아니다.

```bash
python3 tools/author-skill-icon-vfx.py
python3 tools/prepare-skill-icon-vfx-review.py --source <기준 커밋> --output /tmp/tlt-icon-vfx-tests
run-in-roblox --place /tmp/tlt-icon-vfx-tests/qa.rbxlx --script /tmp/tlt-icon-vfx-tests/probe.luau
```

고정 커밋의 `src`만 추출하고 이 작업의 VFX5모듈을 명시적으로 덮는다. 다른 미커밋 변경은 fixture에서 제외한다. 최종 [15개 검사 묶음·30,439검사 PASS](native.json)·[정확한 소스/검사/fixture 해시](native-provenance.json). 새 검사는128기술·199구간, 추가 장식 누락0건, 개별 Beam 최대48을 확인했다. 기존 회귀14묶음도 통과했다.

새 전수 검사는128기술의199개 확정 반복 구간에서 아이콘 장식의 실제 생성·유한 좌표·프레임 이력 독립성·수명/예산 반환, 새 궁극기의 완전한 방패3개, 빈 연쇄 대상과 전역 포화를 검사한다. 기존 원소/움직임/개별 기술/명중/수명/예산 회귀도 함께 실행한다.

초기 시도는 장식 추가 후 개별 예산 초과, 빠른 Quickfire의 소멸 시점 뒤로 되감으려는 검사 오류, 예산이 가득 찬 Arcane Ward의 장식 누락을 발견했다. 주 효과 우선/잔여 예산, 생존 시점 내 프레임 비교, 방어 궤도 세분 수 재분배로 수정했다. 새 DawnAegis의 방패/상승광도 기존 마법/개별 예산 안에서 확인한다. 실패한 초기 시도는 통과 수에 포함하지 않는다.
