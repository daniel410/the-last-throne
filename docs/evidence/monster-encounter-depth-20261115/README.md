# 몬스터 무리 협력·원소 실효과·보스 공략 확장

2026-11-15 · TLT-005/027/033/050/057/061~065/084 · ENG/ART → QA · 로컬 구현/격리 엔진 통과, 미게시·부모 티켓 진행 중

## 변경과 근거

사용자가 앞선 개선만으로 최고 수준 RPG라는 목표에 부족하다고 지적한 후속 작업이다. [현행 사양](../../production/monster-combat-design-2026-11-15.md)과 [공식 Diablo/WoW 조사·원소 수명 계약](../../research/2026-11-15-monster-encounter-depth.md)을 기준으로 공략 선택을 추가했다. 이전 [0.108.0 증거](../monster-combat-20261115/README.md)는 당시 범위로 보존한다.

- 50종 개별 signature와 23보스의 HP70/35% 3단계: 단계별 연결 순서, 교차·삼각·안팎 공간 공격과 방향별 반격 창. 안팎 공격의 영구 안전띠를 제거하고 최저 이동속도에서도 다음 안전지대로 이동할 여유를 검사했다.
- 10종 Ward·5종 Rally: 근처 일반 동료에 대한 유한 지원, 어떤 클래스의 실제 타격으로도 시전 중단, 짧은 경직과 2초 반격 기회. 같은 원정/시야·높이·거리/생존·서사 조건과 시전자 중단으로 링크를 관리한다.
- Fire/Venom의 기존 원시 피해 내 지속 분배, Frost/Web의 짧은 감속, Shadow/Soul의 짧은 비중첩 약화. 실제 HP 손실 뒤에만 적용하고 보호·방어·회피 결과와 원정/생명 변경을 다시 검사한다. 지속 피해는 경직·입력 취소를 반복하지 않는다.
- 같은 영웅을 압박하는 동시 공격을 Easy1·상위2로 제한하고 공격 대상의 잦은 교체를 줄였다. 성장·보상·TD 운영 데이터·무한 증원은 변경하지 않는다.
- 공유 공격 프레임으로 모든 후속 위험·발사 원점·회전·중심 이동을 일치시켰다. 실제 펄스별 몸/무기 방향을 30/60/144Hz에서 연속 보간하고 기존 스킨·그립·서버 root를 보존한다. 지원·6상태·반격 방향·보스 단계의 영어 표시는 실제 서버 상태를 따른다.

독립 리뷰에서 귀환/지원 중단의 남은 효과 정리와 지연 프레임의 실제 타격 시각 우선을 보완했다. 원형 경고의 다각형 현이 피해 반경 안쪽에 놓이는 경계도 보수적으로 보정했다. 새 이미지·메시·음원 업로드는 없다.

통합 native **608590 PASS**, 프로세스 종료0·`ENEMY_COMBAT_ALL_PASS`. 순수 검사의 실제 출력은 [lua-results.json](lua-results.json)에 보존했다. 기존 difficulty-balance의 v1 완료 보상 기대와 monster-damage-tuning의 구형 규칙 버전 기대 2개는 착수 원본에서도 같은 assertion으로 실패했다([변경 전 대조](baseline-comparison.json)). 이 작업에서 성공으로 바꾸거나 기대를 덮어쓰지 않았다. 다른 기존 패턴·파티·보스·피해 예산 회귀는 통과했다.

초기 번들 변환의 토큰 공백 누락([기록](native-bundler-initial.log))과 새 WalkSpeed 검사의 32bit float 직접 비교([기록](native-float-fixture.log))를 수정했다. 큰 원형 경고 검사에서 드러난 현의 안쪽 경계는 [실패 기록](native-circle-boundary-initial.log) 뒤 외곽을 외접·안전 구멍을 내접시켜 실제 위험을 경고 밖에 숨기지 않도록 고쳤다. 최종 로그는 이 보완 뒤 결과다.

## 고정 빌드와 원격 마감

최신 main을 통합한 소스 **`89edc83de72c057f9bcf5b4ae7a00fdd9794e785` / 0.110.0**을 origin/main에 푸시한 뒤 표준 단일 빌드를 생성했다. [빌드 기록](build.json)의 산출물은 `builds/0.110.0/TheLastThrone-0.110.0.rbxlx`(19,670,549 bytes), SHA-256 `5ed4000ddd5fcd7fb92d8bdbdcaac5bbfabf7e92594ab338890dcbf725fd9c7f`다.

[고정 원문 대조](fixed-source-equality.json)에서 변경 전투 모듈 14개가 입력 커밋과 완전히 일치했다. **같은 고정 빌드**에 통합 probe를 실행해 [고정 빌드 엔진 기록](fixed-native.log)의 608,590검사·1,320개 공격 실행·50개 실제 서비스 사례·방향 모션/예고 검사를 재확인했다. 프로세스 종료0·`ENEMY_COMBAT_ALL_PASS`다. 원시 피해 예산과 실제 HP 손실·네이티브 기하와 정상 플레이 수용을 구분한다.

별도 작업 트리에서 구현해 기존 미커밋 자산을 보존했고, 일반 fast-forward로 main에 통합했다. VERSION 충돌은 0.110.0 예약을 유지하고 최신 0.109.4 변경을 함께 보존해 해소했다. 소스와 최종 기록을 origin/main에 커밋·푸시하고 원격 커밋 일치를 확인한다. 새 LFS 자산·Roblox 게시·릴리스 태그는 생성하지 않았다.

## 미검증·다음 담당

합성 신원·시계/실제 엔진 모듈 검사다. 실제 입력 전투 완주·네트워크·재접속·늦은 합류·1~4인+AI·모바일/패드·실기기 성능·최종 난도/미술·사용자 재미 수용은 미검증이다. 모든 몬스터의 새 Blender 원본 애니메이션 제작이나 실기기 최종 품질을 주장하지 않는다. QA는 Shaman 지원 중단→Warlord 무리→지역 원소/안팎 공격→Veyr 3단계 순으로 네 클래스의 대응과 기기별 시인성·성능을 관찰한다. 부모 티켓과 게이트는 완료 처리하지 않는다.
