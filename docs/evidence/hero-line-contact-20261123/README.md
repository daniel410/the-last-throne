기존 서버 피해 이벤트의 피격 위치와 방향에서 기술마다 Beam 두 개를 그린다. 아군 화면도 주 형상 두 개를 사용한다. 각 기술의 모션은 기존 발동 시각에 맞추고, 피해 숫자는 기존 경로에서 표시한다. 표식과 자세 붕괴가 겹칠 때는 해당 상태 표현이 우선한다. [공식 사례 조사](../../research/2026-11-23-hero-line-contact.md)

## 검증

- Rojo 7.7.1로 생성한 단일 Place의 SHA-256과 변경 런타임 모듈 3개의 XML 소스를 입력 커밋에 대조했다. Studio에서 실행기 표식만 추가한 로컬 사본을 열었다. [고정 빌드 기록](build.json)
- 같은 R15 검토 리그와 카메라에서 네 기술의 접촉 후 약 64ms 자세와 초기 명중 효과를 비교했다. 형태를 비교하는 동안 피해 숫자 레이어를 숨겼다. 첫 후보 0.115.64에서는 번개 갈래가 가늘었다. 0.115.65에서 획을 넓히고 각을 살렸으며 0.115.66에서 두 획의 높이를 달리해 옆에서 볼 때도 갈래가 보이게 했다. [전후 화면](line-contact-comparison.jpg)
- 격리 Studio 검사 13묶음 246,159건을 통과했다. 신규 158건은 각 기술의 두 방향, 아군·시전자 화면, 두 Beam 예산, 피해 숫자, 회수 자세를 확인한다. 기준은 실행된 90건 중 53건에서 새 연출 조건을 충족하지 못했다. 전체 회귀에 R6/R15의 128개 기술과 적 예고·아군 효과 겹침 표본, 엘프 발사 확인이 포함된다. [검사 결과](studio-results.json) · [재현 코드](../../../tests/hero-line-contact-native.luau)
- 전직과 스킬 효과 CPU 14,067건, 고정 빌드 역할·로딩 정적 검사 336건을 통과했다. 별도 순수 Lua 자세 검사는 기준과 후보에서 동일한 `K0MeleeMotion`의 Luau 복합 대입 문법 때문에 실행을 중단했다. 같은 기능군을 엔진 자세 검사의 R6/R15 조건에서 실행했다.

## 남은 수용

후보는 미게시 상태다. 전투 QA가 게시 시험의 로비→배틀 이동, 실제 4인 교전에서 적 예고와 네 공격의 판독, 저사양 터치 기기의 프레임 시간, 사용자 타격감 수용을 확인한다.
