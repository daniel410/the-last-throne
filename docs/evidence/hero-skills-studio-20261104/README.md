## 실제 관찰과 변경

네 영웅 각각32기술을 준비·접촉·회수 시점으로 배치했다. 실제 Roblox R15 리그/TD 장착 메시·기사 원본 방패/영웅 색을 사용하고, 수식이나 기본 도형을 최종 미술처럼 제시하지 않았다. 기본 아바타 몸체는 최종 영웅 외형이 아니다. Edit에서는 관절 FK를 먼저 적용한 뒤 무기 FK를 평가해야 활/찌르기의 월드 방향이 정확하다. 처음 검토 도구의 이 순서를 교정한 뒤 기준/수정본32장 모두 다시 촬영했다. 캡처는 원본 JPEG이며 갤러리만 CSS로 기술 행을 보여준다. Work의 로컬 브라우저 사용이 비활성화되어 HTML 페이지의 실제 브라우저 레이아웃 검토는 미실행이며,128개 행/32개 이미지/로컬 링크·해시는 구조 검사했다.

`AdvancedSkillMotion`은 새로 임의 관절 각도를 대량 생성하던 방식을 줄이고 기존 저작 곡선을 재사용한다. 기본기·피해/MP/쿨다운/해금·서버 권위·보상·TD 권리는 바꾸지 않았다. 진행 중인 사용자의 도끼 기본기/그립20도·회피/로비/원정 변경은 보존하며 이번 커밋/고정 빌드에 섞지 않는다. 최종 도끼 화면도 기존 채택 그립/이번 작업 소스 조합으로 재촬영했다.

## 실행과 증거

1. `tools/review-hero-skills-studio.luau`: 격리 PlaceId0에서 저작 리그/무기를 구성하고 기술별3시점의 실제 FK/소켓을 촬영한다. 소스 교체 시 별도 ModuleScript 이름을 사용해 require 캐시를 분리했다. 최종 사용 모듈은 작업 범위 소스와 일치하며 임시 모듈/검토 장면은 게임 프로젝트에 추가하지 않는다.
2. 검토용 서버/클라이언트 스크립트 `tools/hero-skill-play-review.*.luau`: 기존 서버/클라이언트 초기화를 **해당 미저장 격리 세션에서만** 비활성화하고, 준비된4NPC 모델과 별도 예고/효과 RemoteEvent로32기술씩 순차 재생했다. 기존 저장·상품·진행/계정 권한을 호출하지 않는다. 검토 배너는 개발 전용이며 게임 UI가 아니다.
3. 최종 Play에서128개 시전 완료·클라이언트 렌더10,909프레임 중 오류0·종료 후 기본 화살/마법 투사체0개를 확인했다. 이는 해당 데스크톱 로컬 시험이며4인 플레이어+AI 기기 성능 측정이 아니다. 원문은 `session-final.json` / `play-console.log`.
4. Play 접촉 시 실제 총구 전방 일치도0.9892, 찌르기 검 축 전방 일치도0.9979/검 끝 높이+0.4264stud를 측정했다. 추가 R6/R15 네이티브 소켓 fixture는 총신0.9948, 검 축 약1.0, 검 끝+0.1315/+0.5196stud로12검사 PASS.
5. 최종 작업 범위 모듈로 `tests/hero-skills-native.luau`: R6/R15×128=256기술, 실제 관절/무기·엘프 draw/release·추가 효과/취소239,912검사 PASS. CPU 대응/곡선/범위367,906, 효과11,977, 기존 스킬1,435·전투125검사 PASS. 원본 로그·컴파일은 이 폴더에 보존한다. CPU CFrame 모의 객체는 실제 회전/물리 검증을 대신하지 않으며 네이티브 검사를 별도로 실행했다.
6. 고정 소스의 Lobby/Battle 빌드 버전·커밋·명령·SHA256은 `build.json`. 기존0.69.1 결과물은 덮어쓰지 않는다. 실제 게시/릴리스 태그는 수행하지 않는다.

검토 도구 첫 Play는 서버에서 아바타 생성/사전 로딩을 기다리며 시작하지 못했다. Edit에서 준비한 모델을 복제하는 방식으로 고쳤다. 첫 성공 실행의 기본 투사체가 멈춰 있어, 검토 클라이언트에 실제 `Visual.start()`의 이동/수명 루프를 연결하고 전128개를 다시 실행했다. 마지막에는 렌더 오류0과 잔류 투사체0을 확인했다. 기존 `rbxassetid://203785492` 자산 유형 경고는 남는다. 이 실패/수정은 게임 결함과 검토 도구 결함을 구분한 기록이다.

## 남은 수용과 인계

전체128개를 개별 정적 자세로 검토하고4영웅 순차 재생 fixture를 실행했다. 실제 플레이어가 일반 전투 입력으로128개를 전부 시험한 결과·독립 QA·모바일/패드·벽/경사·실제4인+AI 성능·사용자 미술 수용은 아니다. 천/손가락/전신 독립 신규 애니메이션 제작도 아니다. 총/폭탄은 TD 색에 맞춘 임시 조합이며 최종 전용3D 메시/총 독립 장착은 후속이다.

QA/DES/ART는 갤러리의 각 기술ID를 기준으로 정상 훈련장/전투에서 카메라 거리·손/무기 접촉·실제 적중/피격·이동·방어/회피 취소·다인 효과 겹침을 확인한다. 최종 품질 수용 전까지 부모 티켓 Done/최고 품질 완성으로 선언하지 않는다. 자체 테스트 Studio 세션은 증거 보존 후 미저장 장면을 버리고 종료한다.
