# 상세 UI 기기별 배치·기본 메뉴 보존

2026-11-01 · TLT-028/031/052/084 · DES/ENG → QA · 0.58.11 로컬 시험판

## 최신 사용자 범위

로비와 배틀의 기본 메뉴·아이콘은 기존 UI를 유지한다. 상세 상태·성장 메뉴에서만 데스크톱과 모바일 가로 배치를 구분한다. 예외로 로비 왼쪽 아이콘 크기는 TD의 현재 실제 규칙에 맞춘다. 모든 구현과 미리보기에서 승인된 TD 공통 프레임·버튼·아이콘·영웅 초상을 적용한다. 이 지속 지시를 루트 AGENTS.md에 기록했다.

## 변경

- 0.58.9의 기본 메뉴 2열화·미니맵에서 메뉴/열기 버튼 분리를 취소했다. `LobbyTopMenu`, `BattleMinimap`, `K0Hud`는 변경 전 `042a567`과 바이트가 같다. 기본 아이콘 그림·입력·메뉴 순서·위치·HUD 배율을 보존하며 `MobileActionMenu`는 제거했다.
- 모바일 가로 상세 상태는 승인된 영웅 초상을 왼쪽에 두고 오른쪽에 고정 COMBAT / POINTS / GEAR / EFFECTS 탭과 별도 상세 스크롤을 제공한다. 포인트는 2열×2행, +/- 각각44px, CONFIRM/CANCEL DRAFT/RETRY SAVE는 고정 하단에 둔다. 저장 중에는 같은 요청만 재시도하고 중복 확정은 차단한다. 모바일 창의 빈 메시지 영역을 회수해 낮은 높이에서도 4개 배분 행을 초기 화면에 보인다.
- 데스크톱 상세 상태는 기존 큰 초상·8장비·전체 능력치/스킬 효과 구성을 유지한다. 스탯·장비 기여와 미확정 초안, 스킬 실제 효과 수식은 같은 공통 모듈을 쓴다. 기존 스킬·전직 화면은 그 화면의 적응형 배치를 유지한다.
- 로비 왼쪽7개 아이콘은 기존 이미지·순서·기능을 보존하고 TD `LobbyHomeUI.navigationMetrics`의 셀 크기·간격 계산을 재사용한다. 크기 비교는 기기 해상도가 아니라 같은 안전 영역(root.AbsoluteSize) 기준이다. 가로 모바일64×48, 데스크톱 safe root1280×662는102×102다. 큰 화면은 TD와 동일하게 비례한다. 긴 영어 캡션은 같은 크기 상한 안에서 축소한다. TD 파일은 읽기만 했다.

출처 함수·정확한 파일 해시·입력별 기대값은 [TD 크기 근거](td-navigation-size-source.json)를 따른다. 새로운 그림은 생성하지 않았고 기존 Restricted TD 자산을 기존 ID로 연결한다. HTML 시안을 실제 게임 적용 결과로 보고하지 않는다.

## 검증·빌드

QA가 별도 Studio의 실제 Play client와 Device Simulator에서 데스크톱1280×720, 모바일750×323 / iPhone13 가로844×390을 검사한다. 0.58.9 기준선에서 확인한 세로 쌓기 결함과 후속 수용 결과를 [독립 QA 기록](../mobile-desktop-studio-qa-20261101/README.md)에 구분했다.

소스와 VERSION을 먼저 커밋한 후 `python3 docs/evidence/detail-ui-layout-20261101/build.py`로 고정 소스 Lobby/Battle을 빌드한다. 실제 성공/실패·입력 커밋·산출물 해시는 build.json을 따른다. 새 릴리스 태그·Roblox 게시·TD 운영 코드·live DataStore 변경은 포함하지 않는다. 실기기·공식 서버 저장/멀티플레이 수용은 별도다.
