# 마법사 모자 최대 MP 옵션

2026-11-11 · TLT-029/041/052 · ENG · 소스 구현/회귀 검증 완료, 엔진 수용 대기

사용자 최종 지정: Traveler 최대MP+10, Tempered +20, Veteran +30, Sentinel +60. 모자는 기본 옵션1개로 최대MP만 제공한다. 직전 지력안을 대체해 마법 공격력/INT 증가는 제거했다. 기존 로브 MP20/30/50/80과 합산하고 강화3%/단계를 적용한다. 현재 MP를 회복하지 않으며 MP 없는 영웅에게 자원을 만들지 않는다. 기존 아이템ID/가격/레벨·획득/착용 자격·잠금/소유·강화는 유지한다. 기존 보유 모자도 정의에서 재계산한다.

변경: EquipmentFamilies의 전용 hatMana 수치와 ItemCatalog의 mana 옵션, 모자/계열/기본 장비 회귀 기대값. 이전 작업의 미사용 INT 서버/성장/강화/UI 연결을 제거하고 기존 최대MP 집계/영문 표시/장비 비교 경로를 사용한다. [판단 근거](../../research/2026-11-11-mage-hats.md).

## 검증

- 계열492·기본 장비206·상점487·강화8,792·인벤토리274·경제38·DEX130·장비 비교52·특수 효과281·성장3,711·스킬 미리보기1,392검사 통과.

이 결과는 로컬 순수 규칙/공유 계산 검증이며 실제 DataStore·동시 서버·게시 클라이언트 증거가 아니다. 새 빌드/Studio/엔진·실기기·사용자 수용은 미검증이다. VERSION0.101.0 유지, Roblox 게시/릴리스 태그 없음. 기존0.101.0 PNG/메뉴 엔진 증거를 최신 MP 변경 검증으로 간주하지 않는다.
