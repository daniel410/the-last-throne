# 영웅 기본공격·스킬 VFX 개선

작업 TLT-033/057 · 2026-11-11 · 구현/로컬 엔진 검사. G1/G4 전체 완료 또는 미술 수용으로 처리하지 않는다. [리서치와 MCP 확인 한계](../../research/2026-11-11-hero-combat-vfx.md).

## 변경과 근거

- `HeroVFX`에 동작/원소별 절차형 리본·파편을 추가했다. 찌르기·수직 베기·원호·방패·도끼·탄도·낙하·대지 균열·물/증기·불·얼음·번개·뿌리·중력을 구분한다. 상위/궁극기 강도는 폭·수명으로 보강하고 기존 실제 범위선은 유지한다.
- 116개 advanced 기술은 실제 `AdvancedSkillVisual.play` 경로에 연결했다. 기존 Wind Lance 전용 구현은 그대로 사용한다. 공통 근접 기술은 서버의 기술 시작/공격 속성, Gravity는 기존 서버 확정 영역, 모든 기술·기본 타격 장식은 확정 피해 경로에 연결했다.
- 기사/드워프 기본 무기 잔상을 테이퍼 처리하고 드워프 잔상을 짧게 했다. 엘프 기본/정밀/속사/다중 화살의 폭·수명·색을 구분하고 화살/마법탄 잔상을 비행축에 수직으로 배치했다. 물구체의 기존 물방울·TD 도끼/화살 메시를 보존했다.
- 추가 장식은 100stud 거리 제한, PC12/터치8개 효과, PC240/터치144개 Beam, 파편48개 상한이다. 유휴 프레임 연결 해제·만료 정리·Debris 보조 정리를 적용했다. 수치/피해/판정/저장/TD 운영은 변경하지 않았다.
- advanced 효과의 동일 시퀀스/펄스 중복과 오래된 이벤트를 차단했다. 클라이언트 복제 속성 도착보다 앞선 정상 서버 이벤트는 현재 시퀀스 불일치만으로 거부하지 않는다.

## 검증

재현: `python3 tools/prepare-hero-vfx-native.py` 후 출력된 `run-in-roblox` 명령 실행. 생성 Place는 Shared/Client만 포함하며 저장·상품·실계정·TD 운영 서비스를 실행하지 않는다. 실제 제출 소스 해시는 [입력 목록](native-inputs.json)으로 고정했으며352개 항목 모두 빌드 입력 커밋과 일치함을 확인했다.

## 빌드·남은 수용

게임 버전 **0.104.0**, 소스 커밋 `535447767195edd932705ea9eb9ebc98511af721`의 로컬 게임 빌드가 통과했다. [빌드 결과·명령·SHA-256](build.json). 산출물은 `builds/0.104.0/TheLastThrone-0.104.0.rbxlx`이며 게시/릴리스 태그는 만들지 않았다.

Studio 앱과 로컬 파일 열기 명령은 성공했으나 MCP는 `Place is not open`, CUA는 timeout을 반환했다. 따라서 화면을 실제 확인했다거나 MCP 성능/장면 분석 스킬을 실행했다고 주장하지 않는다. 사용자 요청으로 조사한 MCP 스킬의 용도와 제한은 리서치 문서에 남겼다.

다음 담당 QA/사용자: 실제 Studio/게시 테스트 클라이언트에서 네 영웅·8계열 전 기술의 모션 접점, 저/고 그래픽 품질, 적 예고 가림, 1~4인+AI 및 터치 실기기의 P95 프레임 비용을 확인한다. 서버/저장/경제가 변경되지 않은 것을 소스 범위로 확인했으며 전체 시스템 수용은 별도다.
