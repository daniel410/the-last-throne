# 다른4에픽 통행·안내 전수 검사

2026-11-11 · TLT-031/050/057/061~065/084 · ENG → QA · **0.102.10 · 미게시**

사용자의 다른 에픽 맵 검사 요청으로 Gloamwood·Frozen Vale·Ember Caldera·Haunted Graveyard를 확인했다. 0.102.9를 기준으로 현재 클라이언트 `Navigation.route`와 서버 `DeepwoodRegionAccess`를 함께 실행하고, 발견 결함을 수정한 고정0.102.10에서 재검사했다. 독립적인 Pathfinding 경로만으로 통과시키지 않는다.

## 발견과 변경

- Frozen Vale `FV-Q1:report`와 Ember Caldera `EC-Q1:report`에서 사건 입구를 다시 향하는 안내 반복을 재현했다. 연결 공간이 본 구역과 겹치는 위치에서 둘 다 본 구역에 있는 출발/목적지를 사건 경사로로 잘못 우회하지 않게 한다. 같은 X/Z의 수직 중복 지점도 정리하되 목표 도착 화살표는 유지한다.
- Gloamwood·Frozen Vale의 새 나무, Ember Caldera의 바위/광산 지지대/열탑/문기둥이 실제 안내 선분에 겹쳤다. 새 미술 배치와 기존 오브젝트 이동이 실제 전투/단계 안내 선분을 예약하게 했다. 문기둥 두 개와 상단은 하나의 모델로 함께 이동한다. 보이는 물체를 비충돌로 숨겨 통과시키지 않는다.
- 사건 입구의 대각선 복귀 접근이 문받침에 닿는 위치를 확인해 입구 폭64→80으로 넓혔다. 상호작용 주변의 이동 오차까지 고려하도록 미술 배치 여유도 확보했다.
- Haunted Graveyard의 끝 구역→거점 실제 보행에서 기본 퀘스트 검사만으로 발견하지 못한 중간 정체가 있었다. 퀘스트가 지나지 않는 구역 중계 선분도 실제 길/지형/배치 예약에 포함한다.
- 같은 보행에서 루트X `879.9626`이 경계X `880`보다 약0.0374 바깥에 있는 채 경계선을 따라 진행해 서버가 되돌리는 현상을 재현했다. 연결로 통과 후 구역 안쪽12stud 지점을 경유하게 하며, 매 프레임 재계산이 안쪽 지점으로 되돌아가는 새 반복을 만들지 않게 했다. 서버의 통행 영역/접근 제한은 넓히지 않았다.

기준 버전의 실제 활성 목표 검사에서 경로/물체 겹침36건이 보고됐다. 이 중6건은 같은 두 연결로의 바닥/기초 파츠가 약1.30stud 높은 턱으로 겹친 중복 보고였다. 나머지30건과 반복 안내2건을 수정 대상으로 삼았다. 이는 고유한 오브젝트30개라는 뜻이 아니다. [실제 활성 목표 기준 로그](baseline-active.log)·[JSON](baseline-active.json).

## 검수 조건

본편28장·선택8장, 전투 지점/활동 단계449개와 수락 위치8개, 총457목표를 검사했다. 전투의 현재 지점 → 활동 단계 → 대표 목표 순서의 실제 안내 대상을 사용한다. NPC/작업대 중심 안으로 들어가려는 가짜 결함을 만들지 않도록 목표8stud 이내까지 접근하며4×5×4 몸체를 지면 위3.7에 둔다.

각 목표의 `minMain`과 수락 위치의 실제 지역 조건을 만족시키는 가상 저널을 사용한다. FV-Q1/EC-Q1 보고는 기존의 메인15/22 조건 이후 검사하며 최종 선택 구역도 실제 해금 후 검사한다. 미해금 단계에서 정상적으로 거부된 결과를 결함으로 간주하지 않고, 계정의 실제 진도를 조작하지 않는다.
