# 전투 HUD 정사각형 슬롯

2026-11-26 · TLT-028/084 · ENG → QA · 0.117.2

물약·스킬·궁극기의 TD 프레임을 64×64로 맞췄다. 48×48 그림을 중앙에 배치하고 물약의 기존 자르기 영역을 사용한다. 프레임 위에 단축키·수량·쿨다운을, 아래에 어두운 배경의 이름을 배치했다. 짧은 게임패드 배지에 방향 입력을 ←, →, ↑로 표시한다. 일곱 슬롯을 한 줄에 두고 슬롯의 버튼 안에서 그림과 글자를 눌러 조작할 수 있게 했다.

- 격리 Studio Edit에서 모바일 가로·세로 화면 크기 7종의 레이아웃 검사 3,637개 조건을 통과했다. 게임패드 입력으로 설정한 844×390·1280×720·1920×1080에서 641개 조건을 통과했다. 프레임 비율, 그림 크기, 글자·장식 경계, 렌더링된 글자 영역과 버튼 배치를 검사했다.
- 별도의 격리 Studio Edit 세션에서 HUD 상태·자원 UI 검사 28,780개 조건을 통과했다. 물약 재할당, 스킬 잠금·쿨다운 갱신, 궁극기 표시를 포함한다.
- 패키지 검증에서 프로젝트 마운트, Place 역할 10개와 도착 로딩 326개 조건을 통과했다.
