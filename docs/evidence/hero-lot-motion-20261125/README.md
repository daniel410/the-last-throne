LoT 0.21.6의 클립과 슬롯별 동작 선택을 참고해 TLT의 기존 R6·R15 자세에 적용했다. TLT의 서버 접촉 일정과 발사 확인을 시간 기준으로 사용했다. 피해, 범위, 재사용 시간, 무기 장착 소켓과 성장 데이터는 기존 정의를 따른다. [원본 관찰과 RPG 비교](../../research/2026-11-25-lot-hero-motion.md)

## 검증

- 0.115.133, 0.115.134, 0.115.135의 RBXLX SHA-256을 기록하고 변경된 4개 런타임 모듈의 패키지 소스를 각각 입력 커밋과 대조했다. 0.115.135의 단일 빌드 검사 336건, Advanced Skills 검사 1,435건, 변경 Luau 5파일 컴파일을 통과했다. [후보 빌드](build.json) · [첫 후보](preview-build.json) · [패키지 대조](package-check.json)
- 패키지에서 읽은 모션 모듈을 Lune 0.10.5에서 실행했다. R6·R15 분기마다 기본 공격 8타와 스킬 128종을 각 41개 시점에서 샘플링했다. 유한한 자세값과 근접 공격 204개 접촉 시점의 팔·몸통·무기·시각 루트 오프셋을 검사했다. 근접 회귀 2,147건과 엘프 발사 지연 43건도 통과했다. 첫 후보에서 준비 자세 차이가 작아진 Shield Breaker와 Shield Verdict는 최종 후보에서 고유 팔 동작을 복구했다. [샘플링과 회귀 결과](pose-results.json)
- R15 기준 예시에서 기본 활 준비 중 오른팔은 12.95°, 지팡이 기본 타격 55ms 뒤 빈손 쪽 팔은 21.59°, Shield Bash 준비 중 왼무릎은 10.65° 달라졌다. 새 지연 검사 네 건 중 기준 빌드에서 세 건이 실패했고 최종 후보에서는 모두 통과했다. [전후 관절 비교](pose-results.json)
- 기존 Lua 검사 세 묶음은 기준과 최종에서 같은 지점에 중단됐다. `advanced-mode-damage`는 rules18 조건, `skill-action-interrupt`는 미정의 `TargetAssistRules`, `skill-presentation`은 Lua에서 Luau 대입 연산을 읽는 단계다.

Luau 샘플링은 패키지 모듈과 Roblox 호환 자료형을 사용하고 서비스와 서버 시계는 모의했다. 로컬 Studio 자동화는 새 창이 로그인 화면에서 멈춰 연결하지 못했다. 관절의 실제 렌더링, 보행·경사에서의 접지, 게시 클라이언트, 4인 교전, 터치 실기기와 사용자 수용은 미검증이다. 다음 담당 QA·ART가 0.115.135에서 네 영웅의 기본 연격과 대표 기술을 같은 카메라로 비교한다.
