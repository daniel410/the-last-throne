환경 3D가 해빙로의 현무암 노두를 만들고, 맵 구현에서 한쪽을 앞당기고 대면을 낮췄다. 다른 세 경계에는 노출 뿌리, 압설, 묘지 관리로 절단석을 배치했다. 네 경계의 길어깨는 기존 48부품에서 72부품으로 늘었다. 새 장식에는 충돌, 쿼리, 터치를 사용하지 않는다.

## 검증 조건

기준은 0.115.0 로컬 고정 빌드다. 기준 SHA-256은 `20d8c5141f16f3335420ab2da2e27f43da9c3e1a97d0fe2efb1e2f8070a3e7b2`다. 후보는 0.115.1 고정 빌드다. 두 빌드를 격리 Studio Place에서 실행해 동일 카메라를 사용하며, 기존 96스터드 도로 바닥과 R15 왕복 경로를 대조한다. 비교판은 Gloamwood 진입, Frozen Vale 진입, Ember Caldera 진입 세 시점, Haunted Graveyard 진입으로 구성했다.

## 결과

- 기준과 후보에서 네 도로의 변환과 크기가 일치했다. 재호출에도 도로 수는 4개였다. R15 정방향·역방향 8개는 두 빌드 모두 도착했고 점프와 서버 위치 보정은 0회였다.
- 후보 길어깨 72부품의 중앙 이격은 최소 32.48스터드이고 최대 노출 높이는 5.53스터드다. 하부 66부품의 바닥 매입은 0.2스터드를 넘고 현무암 절단면 6개는 기저 암석과 0.09스터드 겹쳤다.
- 세부 접근 화면에서 Deepwood의 뿌리 노출은 작게 보인다. Windgap 밤에는 압설이 셰일과 구분되고 Haunted Graveyard 진입 전에는 관리로의 밝은 절단면이 보였다.
- 중간 접근에서 먼저 배치한 노두의 윤곽을 확인했고, 반대 방향에서도 낮은 노두가 보였다. 설원 쪽 먼 카메라에서는 전경의 해빙 암반이 먼저 보이고 노두의 절단면 대비는 약하다.

Lua 내비게이션 105,907건 및 8,791건, 이야기 소품 문맥 4,264건, 전투 경로 77,381건을 통과했다.
