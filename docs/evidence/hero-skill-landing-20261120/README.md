낙하형 10개 기술은 서버 승인 시각과 기존 펄스 간격으로 마지막 0.19~0.25초의 하강을 표현한다. 늦게 받은 시전은 남은 구간에서 시작하고, 착탄이 25ms 미만으로 남았거나 예산이 찼으면 하강을 생략한다. 취소·사망·새 시퀀스에서 대기 중인 다음 펄스의 하강을 제거한다. 착탄과 피해 표시는 서버 이벤트를 따르며 피해·범위·펄스·상태이상 값은 기존 값이다.
