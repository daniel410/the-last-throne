# 늦은 발사 확인의 활시위 동작 전후 검증

TLT-033/057/059 · 2026-11-21 · 기준 0.115.37 · 후보 0.115.39

[조사 근거](../../research/2026-11-21-elf-late-shot-motion.md) · [고정 빌드](build.json) · [검사 결과](studio-results.json)

이미 당긴 활을 보여 준 상태에서 발사 확인을 50ms 이상 늦게 받으면, 클라이언트에서 시위를 놓고 뒤따르는 동작을 짧게 재생한다. 기본 속도에서 시위가 앞으로 튀는 구간은 40ms이며, 이어서 25~50ms 동안 원래 동작 시각에 합류한다. 다음 화살이나 기술 종료까지 여유가 부족하면 기존 시각을 사용한다. 처음 화면에 들어온 영웅과 이미 처리한 발사도 기존 시각을 따른다. 피해, 투사체 경로, 탄착 시점, 연사 간격과 발사 횟수는 서버 확정값을 따른다.

## 전후 검증

- 발사 확인을 85ms 늦게 입력했다. 기본 사격, Aimed Shot, Heavy Draw, Rapid Fire, Crossfire, Grand Volley는 확인 직후 시위를 놓고 20ms 시점에 활시위가 앞으로 진행됐다. 95ms 시점에는 모두 기존 동작 시각과 일치했다.
- 같은 R15 리그·활·카메라에서 Heavy Draw와 Rapid Fire의 확인 직후, 20ms 뒤, 95ms 뒤를 비교했다. [활시위와 자세 전후](elf-late-shot-comparison.jpg)
- `run-in-roblox --place builds/0.115.39/TheLastThrone-0.115.39.rbxlx --script tests/elf-late-shot-motion-native.luau`는 85ms 지연, 다음 화살이 가까운 확인, 새로 보이는 영웅, 속성이 나중에 복제되는 경우와 회피 취소를 검증한다. [재현 소스](../../../tests/elf-late-shot-motion-native.luau)

신규 39검사 중 기준은 12건에 실패했고 후보는 모두 통과했다. 고정 후보의 Studio 12묶음에서 251,178건을 통과했다. 이 집계에는 R6/R15의 활·시위 접점, 네 클래스의 128개 스킬 자세, 발사축과 연속 명중을 포함한다. CPU 전직과 형상·취소 15,147건을 통과했다. 디스크 부족으로 일부 검사가 중단됐으며 임시 산출물 정리 후 같은 빌드에서 재실행했다.

0.115.38은 일반적인 발사 확인에도 보간을 시작해 Crossfire의 다음 조준과 Rapid Fire의 시위 회귀에 실패했다. 0.115.39는 실제 확인이 늦었고 그동안 활을 당긴 모습을 최근 프레임에서 본 경우에만 보간한다.

## 남은 수용

후보는 미게시다. 전투 QA가 실제 다인 교전과 터치 실기기에서 발사음·화살·시위가 함께 읽히는지, 입력 지연이 큰 조건에서 다음 화살 준비가 자연스러운지 확인한다.
