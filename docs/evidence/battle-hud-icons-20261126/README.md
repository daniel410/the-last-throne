# 전투 HUD 물약·스킬 아이콘 확대

2026-11-26 · TLT-028/084 · ENG → QA · 0.116.3

사용자 스크린샷에서 물약 병과 스킬 그림이 슬롯보다 작고, 병 위의 크기 글자가 그림보다 두드러졌다. 배틀 HUD의 물약·스킬·궁극기 아이콘 영역을 26×26에서 48×48로 키웠다. 일곱 슬롯은 한 줄에 두고, 단축키·수량·쿨다운은 그림 위에, 이름은 아래에 배치했다. 물약 8종은 기존 아틀라스에서 병 주변을 좁게 잘라 표시한다. 배틀에서는 슬롯 이름에 물약 크기를 표기한다.

- 기준 0.116.0은 격리 Studio 모바일 검사에서 새 아이콘 크기 조건을 28회 위반했다.
- 0.116.3의 모듈을 로컬 Studio Edit에서 검증했다. 모바일 화면 크기 7종에서 3,224개 조건, 키보드 입력으로 설정한 844×390·1280×720·1920×1080에서 전투 HUD 464개 조건을 통과했다. 그림과 글자 영역, 슬롯과 다른 전투 버튼의 겹침을 검사했다. 터치 목표 크기는 모바일 조건에 포함했다. 기존 물약 아틀라스 텍스처는 Studio에서 8종 모두 로드됐다.
- 원본 PNG에서 알파가 128을 넘는 병 실루엣이 새 자르기 영역에 포함되는지 8종을 확인했다. 확대·잘라내기를 함께 적용한 기본 배율에서 Small HP 병의 추정 높이는 약 17에서 41픽셀, Medium HP는 약 21에서 43픽셀이다.
- 패키지 검증에서 프로젝트 마운트, Place 역할 10개, 도착 로딩 326개 조건을 통과했다.
