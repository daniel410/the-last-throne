아군 발동 효과는 기술의 범위와 궤적을 표시한다. 기본 형상이 그려진 경우 범용 발동 섬광과 일부 보조 잔광을 줄였다. 형상이 렌더링 예산을 넘으면 해당 기술의 발동 대체 효과를 쓴다. 확정 피해 숫자와 몬스터 예고는 각각 기존 경로에서 그린다.

[0.115.15 첫 빌드](build-0.115.15.json)의 화면에서는 공통 명중 막대와 섬광이 고유 형상을 덮었고, 전직 방패 기술이 기본 Shield Bash 원형 효과를 함께 재생했다. 최종 후보는 네 기술의 명중 획이 생성된 경우에만 공통 효과를 생략하며, 전직 방패 기술의 발동 형태를 서버 이벤트에 맞춰 표시한다. 0.115.16은 먼저 원격에 올라간 지도 작업이 사용해 통합 후보를 0.115.17로 만들었다.

## 검증과 인계

- 고정 Place에서 Studio 검사 30묶음 280,856건을 통과했다. 128개 기술을 다룬 명중 묶음은 761건으로, 네 가지 타격 방향, 피해 숫자, 방패 발동 경로, 아군 효과 상한과 대체 표현을 확인했다.
- 일괄 실행에서 Gunner의 Shrapnel Toss 비행을 제시간에 샘플링하지 못했다. 같은 후보의 Run 모드에서 단독 실행해 180건을 통과했다. 팔레트 검사는 생략된 공통 명중 막대를 전제하고 있어, 실제 명중 획의 Beam 색을 검사하도록 갱신한 뒤 같은 빌드에서 562건을 통과했다.
- 고정 소스의 CPU 검사에서 전직 데이터 1,435건, 스킬 형상과 취소 14,026건, Place 역할과 입장 336건을 통과했다.

증거는 격리 Studio의 스크립트 실행과 장면 캡처다. 게시 Roblox 클라이언트의 실제 4인 연속전, 저사양 터치 기기의 프레임 시간, 미술·타격감 사용자 수용은 미검증이다. 다음 담당은 전투 QA이며 일반 플레이 카메라에서 몬스터 예고 인지와 입력 후 명중을 함께 측정한다.
