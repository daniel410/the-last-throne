# 몬스터 체력 추가10% 상향

2026-11-05 · TLT-027/050/057/061~065/084 · ENG/PLAN → QA · 로컬 구현·미게시, 부모 티켓 In Progress.

사용자의 체력을 조금 더 높여 달라는 후속 요청을0.75.9 대비10% 상향으로 구현했다. 5에픽 일반/보스·4난이도·1~4인·무난이도 로컬 모험에 적용한다. 앞서 추가20% 높인 공격력·레벨·정예·보상·출현 수·공격 주기는 유지한다. 고정 K0 훈련장은 변경하지 않는다. [기존 조사·실전 수용 조건](../../research/2026-11-05-epic-monster-progression.md)을 재사용하며10%는 요청을 해석한 로컬 시험값이다.

에픽1~5 체력 보정1/1.35/1.75/2.2/2.7을1.1/1.485/1.925/2.42/2.97로 변경한다. 정수 반올림/정예 보정에 따라 실제 전후 비율은 약간 다를 수 있다. 체력 보정 뒤 기존 정예 보정을 적용하며 추가10%를 중복 적용하지 않는다. 공격력 보정1.2/1.44/1.74/2.04/2.4는 유지한다.

새 원정은 Difficulty 규칙6으로 저장한다. 규칙1~5의 기존 저장·재접속은 이전 체력/공격력을 유지한다. 입장 미리보기와 실제 교전이 같은 unitStats를 사용한다. 후속 게시 시 Lobby/Battle을 함께 갱신해야 한다.
