# 네 영웅 기술의 조준 전환과 연쇄 경로

TLT-033/057/059 · 2026-11-21 · 기준 0.115.18 · 후보 0.115.20

[공식 사례 조사](../../research/2026-11-21-hero-skill-direction.md) · [고정 빌드](build.json) · [검증 결과](studio-results.json)

| 영웅 | 동작과 VFX |
| --- | --- |
| Knight | **Counter Slash**는 앞무릎을 접고 방패를 가슴까지 올린다. 낮은 곳에서 위로 그은 검호가 방패 앞을 지나간다. |
| Dwarf | **Crosscut Axe**는 두 번째 방향에서 돌아온 도끼를 오른손으로 받으며 무릎을 굽힌다. 기존 도끼 모델과 회수 잔광이 같은 75ms 구간을 따라간다. |
| Elf | **Crossfire**는 첫 화살을 발사한 뒤 시위를 다시 당기면서 활을 두 번째 방향으로 돌린다. 두 발의 잔상은 각 펄스의 원점에서 실제 발사 방향을 따라간다. |
| Mage | **Chain Lightning**은 유도 손을 안쪽으로 모았다가 가슴 앞을 가로질러 펼친다. 지팡이 끝에서 첫 표적으로 이어지며, 뒤쪽 링크의 폭은 점차 좁아진다. |

두 교차 기술의 각 펄스는 해당 방향의 벽에서 잔상이 끊긴다. 서버의 공격 시간, 사거리, 피격 방향과 표적 순서는 기존 판정에서 정한다. Chain Lightning은 확인된 표적 목록만 연결한다. 아군 번개도 모든 표적을 연결하며 보조 면을 줄였다.

[0.115.19 첫 후보](build-0.115.19.json)의 Studio 비교에서 기존 아이콘 보조선이 Crosscut Axe와 Crossfire의 확정 경로에 겹치는 것을 발견했다. 0.115.20은 주 궤적을 아이콘 표현으로 사용하고, Crosscut Axe의 도끼 모델과 회수 잔광을 같은 오른손 좌표에 맞췄다.

## 전후 화면

- [준비·회수 자세](hero-direction-poses.jpg) · 동일한 TD 무기와 R15 검토 리그, 카메라 및 조명. 영웅별 준비, 도끼 회수, 재장전, 방출 후 유도 손을 비교했다.
- [공격 경로](hero-direction-effects.jpg) · 검호와 도끼의 회수, Crossfire의 두 발, Chain Lightning의 세 링크를 비교했다. Crossfire 두 펄스는 두 방향을 한 화면에서 비교하기 위해 겹쳐 표시했다.
- [아군 효과 겹침](party-overlap.jpg) · iPhone 17 Pro 가로 Studio에서 본인 한 명과 아군 세 명의 효과를 몬스터 예고와 함께 겹쳤다. 아군 번개의 중복 선분은 18→0, 삼각 면을 그리는 Part는 36→0이었다. 확정 표적 세 개에 이어지는 Beam 12개, 적 예고 16선분, 피해 숫자 42를 확인했다.

## 검증과 인계

- `run-in-roblox --place builds/0.115.20/TheLastThrone-0.115.20.rbxlx --script tests/hero-skill-direction-native.luau`로 31건을 통과했다. 기준 빌드에서는 시전과 펄스 사이 원점이 달라지는 Crossfire 장면을 재현했고, 발사축을 기대값과 비교하는 첫 검사에서 실패했다.
- 같은 후보에서 Studio 31묶음 281,519건을 통과했다. 네 영웅의 128개 기술을 R6/R15에서 검토하고 명중·아이콘 경로를 재검사했다. 일괄 실행에서 산개 포격의 두 번째 비행과 일부 범위선을 놓쳐 두 묶음을 단독 재실행했다. Gunner의 투척 검사도 Run 모드 준비 뒤 다시 실행했다. 최초 실패와 재시험 결과를 함께 기록했다. [묶음별 결과](studio-results.json)
- CPU 검사에서 전직 데이터 1,435건, 116개 후속·전직 기술의 형상 및 취소 14,000건, Place 역할 10건을 통과했다.
- 별도 Lua `skill-presentation.spec.lua`는 기준과 후보에 공통인 Luau `*=` 변환 누락으로 실행이 중단됐다. 기술 동작은 위 Studio 검증 범위에서 확인했다.

격리 Studio에서 장면과 스크립트를 검증했다. 게시된 Roblox 클라이언트의 실제 4인 연속전, 저사양 터치 실기기의 프레임 시간, 사용자 타격감 수용은 미검증이다. 다음 담당은 전투 QA이며 실제 전투 카메라에서 두 번째 발사축의 식별, 적 예고 인지, 터치 기기의 프레임 시간을 측정한다.
