## 착탄 준비선

Shrapnel Toss 등 산개 기술은 다음 착탄점 한 곳을 보여 준다. 서버가 앞 타격을 확정하면 다음 좌표로 넘어간다. 회피·피격 취소·사망·다음 행동은 남은 준비선을 정리한다. 착탄 뒤 표시되는 확정 효과와 적의 붉은 예고는 각 렌더러에서 계속 그린다.

- 본인 Shrapnel Toss의 시작·첫 명중 직후 준비선은 각각 72→24선분이었다. 회피 직후에는 72→0선분이었다. 첫 착탄과 다음 두 착탄의 좌표, 중복 확정, 취소 뒤 수신, Froststorm 시전 중 사망도 검사했다.
- 같은 카메라와 R15 리그에서 아군 Shrapnel Toss에 Counter Slash, Crossfire, Chain Lightning을 겹쳤다. 아군 준비선은 36→12선분이었다. 적의 붉은 예고 16선분과 번개 Beam 12개, 피해 표시 42가 양쪽 화면에 표시됐다. 데스크톱 Studio 정지 화면이다. [전후 화면](party-scatter.jpg)

## 재현과 인계

`run-in-roblox --place builds/0.115.23/TheLastThrone-0.115.23.rbxlx --script tests/hero-skill-beats-native.luau`로 75건을 통과했다. 0.115.22에서 같은 75건 중 31건에 실패했다. 후보에서 네 영웅의 총 12타가 정지와 회수를 시작했다. 128개 기술의 피격 표현과 네 영웅 R6/R15 자세, 투사체, Gunner 및 적 예고 회귀를 함께 확인했다.

Gunner는 Edit 모드 첫 검사에서 타이머가 착탄 전에 깨어나지 않아 실패했다. Run 모드를 미리 시작한 같은 빌드에서 180건을 통과했다. 실제 리그 검사 또한 첫 실행에서 31건을 통과한 뒤 Studio 기본 플러그인 오류로 프로세스가 실패했고, Run 모드 재실행에서는 정상 종료했다. [묶음별 조건과 결과](studio-results.json)

Studio 12묶음에서 247,799건, CPU 두 묶음에서 15,147건을 통과했다. 별도 K0 입력·회피 검사에서는 전후 빌드가 동일한 14개 시나리오에 실패했다. 이 검사는 통과 건수에서 제외했다. [실패 시나리오 ID](studio-results.json)

후보는 미게시다. 다음 담당은 전투 QA이며 게시 테스트의 실제 4인 연속전, 저사양 터치 실기기의 프레임 시간과 적 예고 인지, 사용자의 타격감 수용을 확인한다.
