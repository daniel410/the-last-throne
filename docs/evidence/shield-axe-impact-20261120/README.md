## 증거

- [빌드 기록과 SHA-256](build.json). 소스 `95211dc71f2c071c30a44f21ff7dc93ec005349b`에서 단일 미게시 Place를 생성했다. 이전 커밋과 비교해 서버 전투 정의와 리그, 무기 자산, TD 운영 파일은 동일하다.
- [Studio 엔진 로그](native.log). 고정 Place 파일을 열어 `run-in-roblox`로 11묶음 통과를 확인했다. 기사·드워프 R6/R15 동작 140개 및 접촉 경계 204개, 준비 자세 차이와 종료 복귀, 전체 기술 128종 VFX, 방패 면과 외곽선의 동시 전진, 적중 지점의 기술별 충격선과 예산 회수를 검사했다.
- [야간 전후 비교](night-review.png). PlaceId 0의 검토 무대에서 동일 카메라와 조명(20:00)으로 첫 펄스 0.10초 후 발동 VFX를 정지했다. 왼쪽은 부모 커밋의 HeroVFX, 오른쪽은 0.114.14 빌드 모듈을 사용했다. 캐릭터는 거리 기준용 마네킹이며 애니메이션과 실제 적중 연출은 위 엔진 검사에서 확인했다. 화면에서 방패 두 기술의 새 전방 외곽선이 갈리고, Armor Splitter의 검흔은 더 좁고 가파르게 보인다.
