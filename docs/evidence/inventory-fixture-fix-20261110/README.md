# 인벤토리 회귀 검사 실패 수정

2026-11-10 · TLT-029/041/052/057/084 · ENG → QA

사용자는 직전 특수 효과 작업에서 보고한 기존 실패도 수정하도록 지시했다. `tests/inventory.spec.lua`가 최신 장비 계약 이전의 방어 합계와 시작 무기를 가정한 문제를 수정했다. 게임 수치를 낮추거나 검사를 제거하지 않았다.

- Traveler 방패3+투구3+신발2의 방어 합계를5→8로 바로잡고, 장갑 공격2·상의/Charm HP50과 함께 Copper Ring DEX3·MP0·기존 시작장비 특수효과0을 명시적으로 검사한다.
- 장착 교체 검사는 더 이상 기본 지급되지 않는 Tempered를 명시적인 소유 테스트 아이템으로 준비한다. 기존 교체·용량·중복 요청·다른 영웅 귀속 검사는 유지한다.
- 후속 Mage의 소유권 검사와 실제 신규 계정 저장 어댑터의 장착 해제·응답 유실·재접속 검사는 현재 지급되는 Traveler 무기로 실행한다.
- 첫 실패를 고친 뒤 드러난 미지급 Tempered 의존까지 모두 해결하고 전체 파일을 끝까지 실행했다.
