# 네 영웅의 이동 공격 자세와 효과 검증

TLT-033/057/059 · 2026-11-22 · 기준 0.115.43 · 후보 0.115.46

[공식 사례 조사](../../research/2026-11-22-hero-movement-skills.md) · [고정 빌드](build.json) · [Studio 결과](studio-results.json)

| 기술 | 자세와 공격 효과 |
| --- | --- |
| Knight · Breaker Charge | 앞무릎을 굽혀 첫 타를 낮게 밀고 두 번째 타에서 방패를 높이 들어 올린다. 각 펄스의 전방에 낮고 좁은 쐐기와 높고 넓은 쐐기를 그린다. |
| Dwarf · Iron Shoulder | 오른손 도끼를 몸 쪽에 두고 왼팔을 접어 어깨로 치고 나간다. 왼쪽 어깨에서 시작하는 짧은 압력 획 뒤에 앞무릎을 깊게 굽혀 버틴다. |
| Elf · Gliding Shot | 뒷다리를 펴고 활을 비스듬히 당긴 뒤, 앞발을 딛으며 시위를 놓는다. 활 소켓과 확정 끝점을 잇는 한 줄에 기존 화살을 표시한다. |
| Mage · Frost Step | 지팡이를 몸에 가깝게 두고 빈손으로 뒤를 쓸어낸다. 출발점에는 낮은 서리 파편이 솟고, 이동한 거리만큼 발밑의 서리 자국이 이어진다. |

네 기술의 명중은 서버가 확정한 방향으로 두 획을 보여 준다. 아군 화면도 두 획을 유지하고 방패와 어깨의 보조 면은 시전자 화면에서만 보인다. 서버 판정과 피해 숫자의 근거는 기존 전투 경로에 있다.

## 재현과 결과

- 같은 R15 리그·기존 무기·카메라에서 Breaker Charge 두 번째 타격 45ms 뒤, Iron Shoulder 50ms 뒤, Gliding Shot 준비 중간, Frost Step 방출 62ms 뒤를 비교했다. 공격 효과는 각 기술의 방출 45ms 뒤 Studio Run의 격리 장면이다. Frost Step은 서리 자국을 볼 수 있도록 두 빌드를 같은 측면에서 촬영했다. [자세 전후](movement-skill-poses.jpg) · [공격 효과 전후](movement-skill-effects.jpg)
- `run-in-roblox --place builds/0.115.46/TheLastThrone-0.115.46.rbxlx --script tests/hero-movement-skills-native.luau`로 R6/R15 자세, 서버 방향, 중복 효과 억제, 아군 효과 예산, 피해 숫자를 확인했다. Frost Step은 서버가 보고한 3.2스터드 이동과 0스터드 이동의 위치를 각각 재현했다. 새 검사 67건 중 기준은 43건에 실패했고 후보는 전부 통과했다. [재현 소스](../../../tests/hero-movement-skills-native.luau)
- 최종 Studio 10묶음 246,042건은 128개 기술의 R6/R15 자세·명중, 아군 효과 우선순위, 엘프 지연 발사와 개별 VFX를 포함한다. 원소 팔레트 검사는 기준과 후보에서 모두 Oathbreaker Strike의 사라진 범용 `ContactVolume`을 읽다가 중단됐다. 해당 기술의 실제 명중 Beam 색을 확인하도록 고친 뒤 양쪽 모두 84건을 통과했다.
- CPU 전직 및 스킬 효과에서 15,147건을 통과했다. 별도 CPU 자세 검사는 기준과 후보 모두 동일한 기존 Luau 복합 대입문에서 Lua 구문 오류로 중단됐다. 두 고정 빌드의 SHA-256과 변경된 클라이언트 모듈 5개를 각 입력 커밋과 대조했다.

## 남은 수용

후보는 미게시다. 전투 QA는 게시 테스트 4인 교전에서 연속 공격과 적 예고를 확인하고, 저사양 터치 실기기의 프레임 시간 및 사용자 타격감을 검증한다.
