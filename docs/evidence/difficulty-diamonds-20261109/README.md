# 난이도별 Diamonds 보상 · 0.91.0

2026-11-09 · TLT-027/041/050/052/057/084 · ENG → QA · 로컬 구현·미게시.

## 최신 사용자 결정과 변경

사용자는 Easy 재수령을 막되 Hard/Insane/Hell 최초 완료도 보상하도록 지시했다. 이후 다른 영웅의 중복 제한을 질문하고 선택지에서 **계정당 난이도별1회 유지**를 명시했다. 영웅별 지급을 적용하지 않는다.

계정·메인 스토리ID·난이도마다3 Diamonds다. 다섯 에픽35스토리×Easy/Hard/Insane/Hell4개=신규 계정 총420개, 난이도당105개다. 같은 난이도의 다른 영웅·같은/새 원정·저장 재시도·사이드 추가0. 기존 Gold/XP/재료/장비/가격/입장 레벨/TD 지갑을 보존한다. 비전투 허브5개의 로비 상위난이도 직접 출발 제한은 유지하며, 본편 연속 진행으로 해당 난이도 완료 기록과 보상을 얻는다.

기존 `wallet.claims`를 Easy 영수증으로 그대로 유지하고 `wallet.difficultyClaims[storyId][mode]`에 Hard/Insane/Hell만 기록한다. 저장된 영웅별 `expeditions.clears`를 계정 전체에서 합쳐 미수령 난이도만 복구한다. 저널만으로 상위 난이도 완료를 추정하지 않는다. 기존 DW2개 수령분·무지갑 DW이관2개 보충 없음. 잔액 상한이면 새 영수증을 소비하지 않고 소비 후 계정 재로드에서 복구한다.

원정 완료 이벤트의 계정 변환에 보상을 연결해 완료/영수증/잔액이 동일 저장에서 확정된다. 퀘스트/잔액부족 문구와 모험 상세의 선택 난이도 초회 Diamonds 안내를 영어로 갱신했다. 원본 TD UI 구성·버튼/메뉴 계약 유지. [비교·경제 영향](../../research/2026-11-09-difficulty-diamonds.md).
