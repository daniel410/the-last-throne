[환경 아트 제작표](../../research/2026-11-18-epic-route-landmarks.md)는 0.113.10의 다섯 대표 지물, 현행 원고와 도보 경로, 공식 RPG 환경 사례를 대조했다. 기존 TD 원본 두 묶음의 후보를 확인하고, 이 장면에 필요한 작은 단면은 기존 팔레트와 Roblox 기본 형태로 제작했다. [숲·묘역 소스](../../../src/server/World/ForestAndGraveyardLandmarks.luau) · [기록고·수로 소스](../../../src/server/World/ArchiveAndCanalLandmarks.luau)

[배치 코드](../../../src/server/World/EpicStoryLandmarks.luau)는 목표를 기준으로 원본/Easy 이동선과 길 바닥, 인접 구역과 확장 구역, 기존 물체와 접지를 검사한다. 첫 Studio 시안은 일부 모델이 목표에서 멀고 FV 모형 하나가 생성되지 않았다. 낮은 시각 전용 모델의 탐색 간격과 기존 물체의 회전 판정을 조정해 일곱 곳에 배치했다. 최종 배치에서 FV 동쪽 도관은 목표로부터 약 110스터드 떨어진 기록고 외곽에 놓였다. 중계기 옆에서 함께 읽히는지는 후속 검토가 필요하다. 신호와 냉각의 변화는 기존 상호작용이 담당한다.

## 로컬 빌드와 재현

[빌드 기록](build.json)의 버전은 0.113.11, 입력은 `6973958ad64c79e818c80404c0cf6251095de1bf`다. PlaceId 0, 플레이어 0인 로컬 Studio에서 확인했다.

```sh
python3 docs/evidence/epic-route-landmarks-20261118/prepare-studio.py --frames --output /tmp/tlt-epic-route-review.luau
run-in-roblox --place builds/0.113.11/TheLastThrone-0.113.11.rbxlx --script /tmp/tlt-epic-route-review.luau > /tmp/tlt-epic-route-review.log 2>&1
python3 docs/evidence/epic-route-landmarks-20261118/summarize-studio.py /tmp/tlt-epic-route-review.log
```

기준선은 [0.113.10 빌드 기록](../epic-story-landmarks-20261118/build.json)의 Place 파일이다. SHA-256은 `323d4d4a38b74fba33209d3c8a93042041339c16c909174f9623586aa7b22efd`다. 준비 스크립트의 `--baseline`은 기준 Place에서 경로와 R15를 다시 실행한다. `--side-frames`는 후보 Place에서 DW·GW·FV 동쪽·HG의 반대 측면을 촬영한다. 각 로그를 요약 스크립트의 `--baseline-log`와 `--side-log`로 전달하면 최종 기록과 비교판을 재현할 수 있다.

## 결과

- 변경 모듈 4개의 빌드 내 소스 일치와 Luau 543개의 구문을 확인했다. 다섯 에픽을 각각 생성한 뒤 전체 캠페인 생성과 캐시를 검사했다. 두 환경에서 일곱 모델·92부품의 접지와 시각 전용 설정을 확인했다. 다섯 점에서 검사한 바닥 높이는 모델 기준면과 0.13스터드 이내였다.
- 0.113.10과 0.113.11에서 원본 739목표·38,241표본, Easy 782목표·39,540표본의 결과가 일치했다. 양쪽 빌드에서 바닥 누락·경계 보정·경로 실패는 0건이고 기존 Deepwood 몸체 겹침 4건이 관찰됐다.
- 로컬 R15가 신규 모델의 일곱 스토리 목표에 마지막 64스터드 이내 안내 구간을 따라 접근하고 출발점으로 돌아왔다. 기존 DW-02 쉼터의 접촉점은 두 빌드 모두 통과했다. DW-Q1 보고 경로는 두 빌드 모두 `(-1516.53, 3.27, -1133.88)`의 기존 나무 옆에서 정방향 보행이 멈췄다. 해당 시험의 귀환은 정지 지점에서 시작했으며 뒤의 석조 접촉 두 곳까지 진행하는 별도 보행은 미검증이다. [Studio 측정 결과](studio-results.json)
- 비교판의 각 쌍은 후보 Place에서 지물의 표시 상태만 바꾼 근접 비교다. 지역 조명 아래 FV의 청회색 턱과 EC의 좁은 여과망·넓은 회수 단면을 구별할 수 있었다. DW는 첫 구도에서 기존 나무가 버팀 일부를 가렸고 반대 측면에서 석축과 목재를 함께 확인했다. GW는 두 구도 모두 야간의 낮은 명도 때문에 뿌리와 암층 경계가 약했다. 반대 측면에서 FV 동쪽 도관 뒤로 기록고가, HG 기단 옆으로 기존 등불이 보였다. 총 11쌍을 기록했다. [전후 비교판](comparison.jpg)

맵 구현·QA 다음 작업은 DW-Q1 나무와 석조 입구를 통과하는 보고 경로다. 환경 아트는 GW의 야간 재질과 FV 동쪽 도관이 중계기에서 읽히는 거리를 다룬다. 플레이어가 직접 조작하는 전투·회피·시야, 상태가 다른 멀티플레이어, 스트리밍, 실기기·게시 클라이언트, 사용자 미술 수용과 G5는 확인이 남아 있다.
