# 마법사 마법 공격력·MP 자연 회복 2배

2026-10-31 · TLT-008/015/042/052/056/084 · ENG → QA

마법사 마법 공격력의 기본·레벨·INT 기여를 기존의 2배로 계산한다. 장비 공격력 퍼센트 적용도 같은 비율을 유지하며, 기존 마법 주문의 1.4배 계수와 스킬 숙련을 보존한다. 기존 서버 구현에서 지팡이 기본 공격도 마법 공격력을 참조하므로 함께 2배가 된다. Pyro/Cryo 양 계열과 Lv80 궁극기 등 모든 마법 기술은 이 공통 능력치를 사용한다. 마법 공격력이 없는 방어막의 양은 바뀌지 않는다. 사용자 화면의 마법 공격력·피해 예상과 INT 안내도 같은 계산을 쓴다. 피해는 기존 서버가 최종 확정하며 반올림으로 최종 정수는 정확히 2배에서 1 차이 날 수 있다.

마법사의 MP 자연 회복은 초당 최대 MP의 0.15%→0.30%, MP100 기준 0.15→0.30이다. 시전 후 기존 1초 대기와 최대치·시간 스텝 상한, MP 비용·쿨다운은 유지한다. 엘프의 마법 공격력과 마법 궁수 회복은 기존 값을 유지한다. [기존/비교 근거](../../research/2026-10-31-mage-elf-balance.md).
