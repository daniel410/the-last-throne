# 골드 보상 감액·초기 지급 제거 검증

2026-11-16 · TLT-045/027/029/044/050/084 · ENG/PLAN → QA/사용자. [현재 계약](../../production/gold-rewards-2026-11-16.md)과 [변경 전 조사](../../research/2026-11-16-gold-reward-review.md)를 따른다. 정적 구현·검증 완료, 고정 빌드/Studio 검증 진행 중이다. 게시·실기기·일반 입력 플레이 수용은 미검증이다.

## 적용

신규 원정19에서 초회 고정 Gold30%·처치 원본 기본 Gold25%·반복 완료 최종 Gold50%를 감액했다. 추가 완료 보상의 반복 기준은 변경 전 값으로 계산하므로 이중 감액하지 않는다. 원정 시작 시 서버가 버전을 고정하고 옛 미완료 원정은 모드 전환·재입장에도 그 버전을 유지한다. 완료 후 새 재플레이는19다.

초회·반복 미리보기, 로비/필드 퀘스트 안내와 완료 보상 표시를 실제 지급 정책에 연결했다. 퀘스트 책의 과거 저널 합계 `Gold earned` 표시는 서버가 제공하는 실제 `Gold balance`로 교체했다. Studio 신규 계정은0Gold/0Diamonds로 시작하고 기존 재화·영웅/모드별 지급 이력은 유지한다. Studio Lv10·세션 전용 저장은 유지한다.

원본 `reward.coins`/`journalCoins`는 저장 검증 및 옛 원정 기준으로 보존한다. 신규 실제 금액은 별도 정책을 사용하며 정본/지역 시나리오 JSON의 `current_quest_gold`와 대조한다. XP/성장·재료·장비·확률·가격·Diamonds·승인 모드 배율·TD는 변경하지 않았다.

## 빌드·Studio·미검증

VERSION0.111.13으로 단일 고정 빌드를 준비한다. 빌드/엔진의 실제 결과는 후속 증거로 기록하며 성공 전 통과로 처리하지 않는다.

게시 클라이언트/운영 저장/실제 동시 서버, PC·터치·패드 일반 입력 완주·파티/AI 소비·사용자 밸런스 수용은 미검증이다. 실제 Roblox 게시나 릴리스 태그는 이 작업에서 만들지 않는다. 다음 담당은 QA/사용자로, 무구매 첫 영웅의 물약·지원 비용과 후반 반복 순잔액을 측정한다. 전체 TLT-045/G3/G7는 완료 처리하지 않는다.

롤백은 소스 되돌림으로 수행하고 지급된 잔액/권리는 삭제하지 않는다. 진행 중인 규칙19를 유지해야 하는 롤백에서는19 읽기/지급 경로를 남겨야 하며, 과거18 전용 writer를 그대로 재배포해19 프로필을 거부하게 하지 않는다.
