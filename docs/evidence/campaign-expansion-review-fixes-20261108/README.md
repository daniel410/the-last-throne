## 호환·물리 경계

새 회로 선택과 연출이 추가돼 MINOR를 올려0.86.0으로 빌드한다. 원정 규칙13·확장 저널1·82사건/246단계 ID·기존 규칙1~12·보상/성장·보유품은 그대로다. 기존 확장 저장의 단계 수/선택 없는 옛 진행도 읽으며 좌표는 새 안전 발판으로 재투영한다. 새 회로에 이미 통과한 단계를 다시 요구하지 않는다.

장면 이동은 서버가 확정한 활동/목표/챕터 상태로부터 개인 클라이언트가 재구성한다. 교량·성문 등 **연출용 모델의 위치/모습은 움직이며 공유 발판/충돌은 안전하게 유지**한다. 타인의 진행으로 바닥이 사라지거나 클라이언트의 장치 이동이 서버 진행 권한이 되지 않는다. 스트리밍 재유입/재접속은 저장된 최종 자세를 즉시 복원하고 새 확정 변화에만 짧게 보간한다. 장면 NPC는 실제 위치가 변하는 장식 배우이며 추가 전투AI/독립 군중AI가 아니다.

기존 전투 사이의 사건 공간 구조는 유지하되 지역별 공간/기계/동맹 반응과 접근 동선을 보강했다. 기존 전투를 새 방으로 재배치하거나 추가 전투·독자적인 군중 시뮬레이션을 만든 것은 아니다. 따라서 전투/이동 비율과 반복감의 최종 판단은 실제 플레이 수용에 남긴다.
