# Veyr와 무장 몬스터의 검 손

2026-11-16 · TLT-005/027/057/084 · 개발 → QA·사용자

| 몬스터 | 무기의 소유 관절과 공격 |
| --- | --- |
| Veyr · Dread Commander | 같은 TD 원본에서 대검, 손잡이를 감싼 손, 팔뚝을 함께 분리했다. 오른쪽 어깨를 축으로 기본 베기는 검을 몸 옆으로 높이 감았다가 앞을 가르고, 내려치기는 위에서 떨어진다. 시전은 칼끝을 전방으로 내민다. |
| Death Knight | 오른 주먹과 수직으로 든 대검을 한 파트로 연결했다. 몸통과 양다리는 각자의 관절을 따라간다. |
| Enraged Warlord | 두 주먹의 칼날을 각각의 팔에 연결했다. 오른팔이 주 공격을 이끌고 왼팔은 시차를 두고 따라간다. |
| Skeleton | 기존 오른손 검의 교대 기본 공격에서 체중을 앞으로 싣도록 조정했다. 구형 공격 시계의 준비 자세에서 접촉까지 칼끝이 전진한 거리는 0.019에서 0.186스터드로 늘었다. |

## 자산과 전투 연결

분리한 세 GLB를 Roblox Studio의 File → Import로 등록했다. 각 파트의 이름, 크기, 원본 기준 위치를 대조해 등록된 MeshId와 기존 TD 텍스처를 로컬 RPG 템플릿에 연결했다. 소켓은 각 칼끝의 실제 정점과 날 안쪽에 둔다. 런타임은 완성된 MeshPart를 복제한다. [원본 해시·파트별 크기·메시 ID](../../../assets/shared/commander-weapon-rigs/geometry.json)

## 검증

- 고정 빌드 0.111.27에서 네 몬스터의 기본 공격 4개와 패턴 14개를 재생했다. 공격 준비, 서버 타격 시점, 반복 타격, 회수 때의 어깨 회전·칼끝 위치를 측정하고 무기 손의 용접, 실제 메시 정점과 소켓의 일치, 서버 루트와 체력을 검사했다. Veyr의 Throne Cleave는 준비에서 첫 타격까지 오른쪽 어깨가 76.8도 회전하고 칼끝이 키의 1.05배를 이동했다. [관절과 칼끝 측정](native.json)
- 두 비교 영상은 0.111.21과 0.111.27에서 같은 Hard 공격과 카메라를 사용했다. 준비, 첫 타격, 뒤따르는 동작, 회수에서 16장을 뽑았다. 칼날을 비교할 수 있도록 첫 타격 프레임을 천천히 재생한다. 초기 촬영에서는 일부 모델의 첫 장에 몸통이 늦게 표시되어 카메라를 고정한 후 모델을 먼저 렌더링하고 다시 촬영했다. [Veyr 대검 전후](veyr.webp) · [다른 무장 몬스터 전후](armed-monsters.webp)
- 실제 R15 플레이어 한 명과의 격리 Studio Play에서 전투 서비스가 몬스터를 생성·구동하도록 했다. 네 몬스터에서 공격 손의 관절과 몸통 기준 칼끝의 이동, 준비·발동·회수, 서버 명중을 기록했다. Veyr의 칼끝은 몸통 기준 시작 위치에서 최대 9.85스터드 떨어졌다. 시험 캐릭터는 네 교전에서 각각 서버 피해 3을 받았고, 대상 클라이언트 스크립트 오류는 0건이었다. [로컬 교전 결과](play.json)
- 기존 동작 회귀 검사에서 50종·146개 공격·285회 타격, 묘지 몬스터 동작 371,796개 검사, 기존 오우거·워로드 무기 연결 108개 검사를 통과했다. 새 템플릿 3종의 등록 메시 9개와 텍스처를 빌드에서 대조했고 GLB 3개와 런타임 파일의 Git LFS 해시를 확인했다.
- QA는 게시 클라이언트의 자산 접근과 실기기에서의 가독성을 확인한다. 미술 수용은 사용자 검토 후 판정한다. [미게시 빌드와 소스 커밋](build.json)

촬영은 두 빌드에 각각 `tools/collect-monster-actions.py --weapon-hands PLACE LOG`를 실행한다. 두 로그를 `tools/render-monster-action-review.py --weapon-hands --before OLD_LOG --after NEW_LOG --versions 0.111.21 0.111.27 --output DIR`로 조합한다.
