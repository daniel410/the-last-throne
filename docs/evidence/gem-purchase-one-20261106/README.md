# 보석 구매 수량1개로 변경

사용자 지시로 기존50Gold→보석5개 교환을 제거하고 **50Gold→보석1개 구매**로 대체했다. 공유 규칙의 수량을1로 변경하여 서버 지급·버튼·재료 설명·영어 도움말에 같은 값을 연결한다. Ore1+50Gold→보석1·보석5+50Gold→마석1·강화25Gold·Diamonds무차감은 유지한다.
