# 스킬 참조 스탯·투자 전후 미리보기

2026-10-29 · TLT-014/015/027/042/052/054~056 · ENG/DES/리서치 → QA.

## 변경과 근거

사용자 요청에 따라 스킬 상세에 STR/DEX/INT 또는 받는 사람의 최대 HP를 표시한다. 스탯 화면의 장착 스킬·해금된 전용 궁극기에는 현재→투자 초안의1회 피해·다단 합계·자기 보호막 변화와 차이를 표시한다. 아군 보호막은 각 아군의 HP기준이라고 안내한다. 장비·숙련을 적용하며 현재 저장/카탈로그를 수정하지 않는다. 적 취약·표식·반격 등의 상황 보정은 제외했다고 설명한다.

공격력을 중간에 반올림하지 않고 서버처럼 최종 타격에서 반올림한다. 예를 들어 Lv2기사·Power장비+5%·숙련0 Shield Bash는87이다. 중간 공격력을 반올림하면86으로 틀리는 조건을 회귀 검사한다.

현재 Gunner·성기사의 피해는STR, 물리 엘프는DEX, 마법궁수 계열·Mage는INT다. DEX공속/치명타·혼합 가중 합산을 새로 구현한 것으로 안내하지 않는다. [타 RPG 조사·동일 예산18조건 비교](../../research/2026-10-29-skill-stat-relationship.md), [영문 가이드](../../player-guides/class-stat-guide.en-US.md).
