# Veyr의 오른손 대검 베기

2026-11-16 · TLT-005/027/057/084 · 개발 → QA·사용자

0.111.27에서는 오른손과 칼이 함께 움직였지만 Throne Cleave의 검끝이 타격 직후에도 Veyr의 오른쪽에 머물렀다. 0.111.28은 대기·추격에서 검을 들어 받치고, 오른손을 어깨 위로 올려 준비한다. 몸통의 과도한 회전을 줄이고, 손이 먼저 움직여 대검이 정면을 가로질러 왼쪽까지 지나가도록 했다. 기본 공격과 스킬 네 가지에 적용했다. 내려치기는 더 수직으로, 투사체 시전은 바깥쪽으로 더 길게 벤다. 연속 공격에서는 검을 아래로 감아 다음 베기를 준비한다.

[Throne Cleave 전후 영상](veyr-swing.webp)은 같은 Hard 공격, 같은 카메라로 각각 54장을 일정 간격으로 촬영했다. 두 버전 모두 공격 시간 2.22초로 재생한다. 그림자 주문의 준비 효과는 오른손 칼날에 붙고, 잔상은 검이 타격을 통과하는 동안만 나타난다.

## 검증

- 고정 빌드의 실제 무기 메시와 어깨 관절을 사용했다. Hell 조건의 Throne Cleave에서 준비부터 타격 0.13초 후까지 검끝의 좌우 이동 폭을 신장으로 나눈 값은 기존 0.38에서 0.82가 됐다. 검끝의 마지막 위치는 몸 중앙에서 오른쪽으로 키의 0.41배이던 것이 왼쪽으로 키의 0.26배가 됐다. 같은 공격에서 준비 때 오른 주먹은 어깨 위로 키의 0.17배 올라갔다. [이전·현재 측정값](native.json)
- 기본 공격 및 스킬 4종에서 손이 올라가는지, 검끝이 양쪽을 가로지르는지, 접촉 전후 20ms 동안 같은 방향으로 계속 베는지 검사했다. 무장 몬스터 4종 18개 공격, 34회 타격, 전체 몬스터 50종 146개 패턴과 묘지 몬스터 회귀 검사도 통과했다. 서버의 피해 판정과 투사체 원점은 기존 전투 규칙을 사용한다.
- 로컬 Studio Play에서 실제 R15 플레이어와 교전했다. 오른 주먹은 어깨보다 키의 0.16배 높이까지 올라갔고 칼끝은 몸 중심에서 오른쪽 0.70배부터 왼쪽 0.69배까지 움직였다. 서버 명중 1회와 시험 피해 3을 확인했다. [교전 측정](play.json)
- 게시 클라이언트·실기기·사용자 미술 수용은 후속이다. [미게시 빌드](build.json)

재현 시 두 빌드에 각각 `tools/collect-monster-actions.py --veyr-swing PLACE LOG`를 실행한 뒤 `tools/render-monster-action-review.py --veyr-swing --before OLD_LOG --after NEW_LOG --versions 0.111.27 0.111.28 --output DIR`로 비교 영상을 만든다.
