# 강화25Gold고정·보석 교환

2026-11-06 · TLT-027/028/029/041/043/044/045/052/084 · ENG/PLAN → QA · 0.77.0 로컬 구현·미게시.

사용자는 Gold 소비를 재료 교환에 연결하고 이어 강화 비용을25Gold로 명시했다. 이전25n시험안/Gold0 대신 **모든 지원 장비의 모든 단계에 시도당25Gold고정**을 적용한다. 실패도25Gold와 재료를 소모하고 단계/아이템은 유지한다. 기존 강화 확률·효과·+9상한·보상/레벨/물약/MP·성공 재료80%회수는 보존한다. [디아블로 제작경제 비교/실패 예산 조사](../../research/2026-11-06-weapon-enhancement-gold-review.md)를 재사용한다.

## 교환과 강화 계약

| 동작 | Gold | 재료 | 결과 |
| --- | ---: | --- | --- |
| 보석 교환 |50 |없음 |보석5개를 현재 영웅 가방에 지급 |
| 마석 교환 |50 |보석5개 |마석1개, 기존 교환 유지 |
| 강화1회 |25 |기존 단계별 보석/마석 |성공/실패 결과 저장·실패 시 단계 유지 |

25Gold는 사용자 확정 고정비다. **보석50Gold→5개는 초기 구현 시험 가격**으로 후속 실전 소비/재료 수급에 따라 검토한다. 마석의 기존비율·과거 광석/코어1:1 변환은 변경하지 않았다. Diamonds 잔액은 어느 동작에서도 차감하지 않는다. 재료의 모험 보상 획득 경로도 유지한다. 지원 장비의 무기/방어구/장신구에 같은 고정비를 적용하며 기본 수치0으로 강화 불가인 Training 무기에는 비용을 받지 않는다.

보석 구매는 가방 공간이 없으면 전체 거래를 거부한다. 부분 스택에 들어갈 공간이 있으면 합치되 새 스택 공간까지 부족하면 Gold/스택 변경을 모두 취소한다. 잠긴 스택·다른 영웅/창고/미수령에는 구매 재료를 임의로 합치지 않는다. 기존 마석 교환/변환의 overflow 계약은 보존한다.

Gold 차감·재료 지급/소비·시도 결과/영수증은 기존 단일 계정 거래로 확정한다. 강화규칙은2→3이며 이전 Gold0 클라이언트 확인은 새 시도를 거부하고 재확인을 요구한다. 기존 규칙2의 완료 영수증 재조회는 원래 결과를 돌려주고 소급25Gold를 청구하지 않는다. 새 영수증은 Gold 소비량을 포함한다. UI는 신규/기존 영수증의 실제 Gold값(기존 누락은0)을 표시한다. Gold 수수료/재료 교환료는 RECOVER로 환급하지 않는다.

신규 보석 교환에는 별도 견적 버전1을 검사하고 재요청 fingerprint·InventoryService의 저장 대기 비교에 포함한다. 원래 요청ID/버전으로 재조회해 이중 지급을 막는다. 기존 마석 교환의 버전 없는 저장 요청은50Gold/보석5개 계약 그대로 재현한다. 클라이언트가 보낸 가격/수량은 무시한다.
