# 지역 생성과 교전 반복 작업 최적화

2026-11-18 · TLT-040/087 · ENG → QA/릴리스 · 0.113.15 후보

새 Deepwood 생성에서 시간이 많이 걸린 월드 아트와 길목 충돌 검사를 조사했다. 동일 좌표·경로의 검사와 귀환로 목록 수집을 묶고, 길이 막혔음이 확인되면 남은 표본 검사를 생략한다. 가벼운 장식 배치는 같은 프레임에서 처리하고 비용이 누적되면 양보한다. 지형 복셀 대조가 달라진 절삭 호출 생략 실험은 후보에서 제외했다.

스토리 몬스터의 공격 대상, 파티 지도, 교전 접근·재개 검사에서 같은 원정인지 판단할 때 기존 ID 전용 조회를 사용한다. 처치 복구와 보상 계산처럼 기록이 필요한 경로에는 전체 데이터를 사용한다.

## 검증

동일한 격리 Studio에서 각 고정 빌드의 새 Deepwood 생성 1회씩을 측정했다. 서버의 지역 생성 구간이며 계정 읽기·Teleport·클라이언트 로딩은 별도다. [계측 스크립트](profile-native.luau) · [원본 계측값](measurements.json).

- 두 생성 결과는 전체 인스턴스 27,046개, 파트 18,241개의 경로·좌표·크기 및 충돌/조회/접촉 설정 해시, 이동한 지물 159개, 지형 표본 47,145개의 재질·점유율 해시가 일치했다.
- 실제 소스를 사용한 Studio 페이즈 270검사, 교전 913검사를 통과했다. 교전 투영이 ID 전용 조회를 사용하는 조건도 검사했다.
- Studio 지역 생성 실패·재시도 20검사를 통과했다. 다섯 에픽의 준비 결과에서 기존 교전 경로 검사 6,333개를 실행해 바닥 실패 0건, 충돌 장애물 0건을 확인했다.
- Lua 경로 77,381개, 길 안내 8,791개, 부활 688개와 저장·파티·지역 준비·체크포인트 회귀를 통과했다. 소스 Luau 546개를 컴파일했고 빌드에 들어간 변경 런타임 소스 4개와 파일 해시를 대조했다. [고정 빌드](build.json).

차기 QA는 게시 서버에서 입장과 경계 진입을 반복 측정하고 4인 근접 교전 중 서버 프레임 간격과 실제 클라이언트의 첫 몬스터 표시를 확인한다. 새 Deepwood의 초기 생성과 1초 이상 서버 프레임은 격리 시험에도 남아 있다. 후보 미게시. 게시 클라이언트·실기기·부하 P95 및 사용자 수용은 미검증이다.
