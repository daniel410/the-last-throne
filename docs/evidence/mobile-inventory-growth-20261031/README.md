# 모바일 장비·성장 화면 개선

2026-10-31 · TLT-028/031/043/052/061/084 · ENG/DES → QA

사용자가 제공한 가로 화면에서 GEAR & BAG과 STATS & SKILLS의 제목·버튼·여백이 대부분의 높이를 차지해 목록과 스탯이 거의 보이지 않았다. 높이 400 미만의 짧은 화면에 별도 배치를 적용했다. 화면 폭이 충분하면 제목과 주요 동작을 한 줄에 두고, 좁으면 두 줄로 배치한다. 장비 목록은 더 작은 여러 열의 스크롤 그리드를 사용한다. 장착 보기는 8슬롯을 두 줄로 배치하고, 장착 및 아이템 상세에서는 필터를 감춰 내용을 넓힌다. 상세의 장착·잠금·버리기 버튼은 한 줄에 남긴다. 창고·수령함·필터·정렬·서버 권위 처리는 유지한다.

성장창은 제목·세 탭을 압축해 스크롤 영역을 늘린다. 짧은 화면에서 스탯 투자는 큰 초상보다 먼저 나오고, 폭이 충분하면 스킬 트리와 선택 스킬 상세를 나란히 표시한다. 정해진 장착·스탯·스킬 규칙과 데이터는 변경하지 않았다. 기존 큰 화면 구성은 유지한다.

기존 [로비 조사](../../research/2026-10-31-lobby-panels-affordability.md)를 참고하고 2026-10-31 [Roblox 적응형 설계](https://create.roblox.com/docs/production/publishing/adaptive-design)와 [스크롤 프레임](https://create.roblox.com/docs/ui/scrolling-frames)을 재확인했다. 공식 문서는 화면 크기별 재배치·가독성과 스크롤 가능한 목록을 설명한다. 이번 배치는 사용자 화면에 대한 적용 가설이며 실기기 수용을 대신하지 않는다.

## 검증

0.58.5 로비 빌드에 작업 모듈을 교체한 임시 격리 Studio fixture 사용:

- `tests/lobby-panel-size-native.luau`: 100개 통과. 750×323 포함 세 화면의 목록·탭 영역과 기존 창 크기 회귀.
- `tests/inventory-mobile-layout-native.luau`: 13개 통과. 750×323에서 장비 8칸과 아이템 상세·버튼 위치.
- `tests/skill-stat-ui-native.luau`: 3,000개 통과. 전 직업/계열의 기존 수치·텍스트 및 짧은 화면의 스탯 순서와 스킬 상세 위치.
- `tests/inventory-claims-gear-native.luau`: 12개 통과. 기존 장비·수령 자격 상태 회귀. 마지막 필터 표시 조정 직전의 같은 로직으로 실행했다.

검사는 합성 GUI 호스트의 엔진 결과이며 실제 휴대폰 화면, 터치·스크롤, 노치·가로세로 전환, 게임패드, 네트워크/저장과 사용자 시각 수용은 미검증이다. 기존 `203785492` 자산 유형 경고가 남는다. 게시된 0.58.5에는 반영되지 않았다. 다음 담당은 QA다.
