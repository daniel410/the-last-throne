# 난이도별 스토리 접근로의 나무·작업대 차단 수정

2026-11-15 · TLT-063/064/065 · 맵 구현/환경 배치 → QA · 로컬 구현·미게시

이전 [협곡 작업의 전 지역 sweep](../fv03-glacial-landforms-20261115/results.json)에서 확인한 GW-01/EC-05 차단2건의 후속이다. 작업ID의 G5 전체 완료와 구별한다. 소스 입력 `ea52a7785062f1b904cd52e0814bf6ce584b56fe`, 빌드 **0.107.12**. [고정 빌드·LFS 확인](build.json).

## 원인과 변경

| 스토리/원천 | 기대와 실제 | 수정 |
| --- | --- | --- |
| Gloamwood / GW-01 `lantern_patrol`→`exp_2:step1`, `CampaignContent`와 `CampaignCombatRoutes` | 마지막 교전→확장 구조 지점으로 걸어가야 한다. 기존 교전의 끝은 `(-672.85,54,-3946.4)`, Easy 추가 교전 뒤 끝은 `(-580.85,54,-3946.4)`다. 서로 다른 접근로인데 Easy의 `worldPoints`만 배치 예약에 사용해 기존 접근로에 `ForestTree.trunk_geom`이 남았다. | 두 교전 배열마다 스폰부터 다음 활동까지의 연속 경로를 독립 예약한다. 기존 나무 전체 모델을 다른 안전 지점으로 배치한다. |
| EmberCaldera / EC-05 `vault_patrol`→`exp_2:step1` | 기존 끝은 `(281.15,156,-13569.4)`, Easy 끝은 `(189.15,156,-13569.4)`다. 접근 중 고체 `BlueprintTable`이 몸체를 막았다. | 단일 파트 소품의 탐지/이동 목적지 검사에도 두 경로를 모두 포함한다. 작업대의 크기·재질·고체 충돌을 유지한다. |

`CampaignSceneryPlacement`와 `CampaignRouteClearance`의 예약 생성 및 정적 묘지 소품 모델의 재배치 대상만 변경했다. `worldPoints`와 `points`를 합쳐 하나의 교전 순서로 만들지 않고 각각 스폰부터 추적하므로, Easy 마지막 교전 뒤 경로와 원래 마지막 교전 뒤 경로가 모두 보호된다. 나무의 잎/줄기를 따로 이동하지 않는다. 기존 공유 원본·정적 바닥·게임 콘텐츠·영문 문구·보상·계정/퀘스트 저장을 수정하지 않는다. 실제 이동을 막는 기존 결함이므로 별도 게임성 리서치는 추가하지 않았다.

첫0.107.11 고정 빌드는 기존 경로 차단2건을 해소했지만 새로 확대한 Easy sweep에서 HG-03 묘비1개와 HG-06 석관의 뚜껑/몸체2파트가 막혔다. [첫 시도](0.107.11-attempt.log)·[해당 빌드](0.107.11-build.json)를 보존한다. [변경 전0.107.10 Easy 재현](baseline-easy.log)과 [정확한 비교](baseline-easy-comparison.json)에서 같은 물체/목표/접촉 좌표3건을 확인했다. `GroundAndPaths`의 고체 묘지 모델들이 기존 재배치 그룹 목록에서 빠져 있던 결함이다. 전체 묘비/석관 모델을 기존 안전 배치 절차에 포함했다. 흙/포장처럼 모델이 아닌 바닥 조각은 이동하지 않는다. 이로 인해 최종 수정 범위에 HG-03/06을 포함했고0.107.12로 다시 동결했다. 첫 시도를 전체 통과로 합산하지 않는다.

검사기는 변경된2모듈의 바이트 일치와 전체 Luau 컴파일을 확인한 뒤 실행한다. 고정 빌드에 소스를 주입하지 않는다. GW/FV/EC/HG4지역 교전/목표·단계 접근 sweep을 기존 `points`와 Easy `worldPoints` 각각으로 실행하며 두 결과 모두 차단/바닥/보정/안내 실패0을 요구한다. 실제 R15는 GW-01/EC-05의 마지막 교전→확장 구조/정비 지점까지 두 경로, 총4조건에서 점프 없이 이동한다. 맵 밖 임의 시작점이나 서버 위치 보정으로 성공시키지 않는다.

[정적 기록](static.log)은 현재 원고/진행·전투·안내 계약 검사다. 이전 기준 차단 위치는 앞선 작업의 실제 엔진 결과를 재사용했고, [이번 변경 전 장면](before-native.log)도0.107.10으로 별도 생성했다. 최종 결과는 [고정 엔진 로그](fixed-native.log)와 [구조화 결과](results.json), 실행 입력은 [해시 기록](fixed-inputs.json)에 기록한다. 다섯 에픽 전체 기기/조작 수용을 검사 수로 대체하지 않는다.

최종 고정 빌드에서 기존/ Easy 각 경로의 GW·FV·EC·HG4지역 이동 검사 모두 차단/바닥/보정/안내 실패0이었다. 기존 경로는496목표·24,518표본, Easy 경로는529목표·25,427표본이었다. 실제 R15 보행4조건은 모두 도착했으며 점프0·서버 위치 보정0, 도착 거리4.41~6.93stud였다. 고체 scenery28,942검사에서9188고체 파트·각 지역 나무/벽/암석/아치의 실제 몸체 충돌도 유지했다. FV-03 지형1,523검사, 대표 건축/생활 구성·교전 바닥·조명/길 마감 회귀도 통과했다.
