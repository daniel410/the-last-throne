# 여섯 HP/MP 물약과 빠른 슬롯 아이콘

작업: TLT-053/028/084 일부(기존 장비·인벤토리 및 HUD 확장),2026-10-29,엔지니어/QA.

HP·MP 각각 Small/Medium/Large 여섯 정의를 추가한다. 기존 health_potion/mana_potion은 Small로 이름을 붙이고 ID·회복40·저장 definitionVersion1은 유지한다. 기존 저장을 다시 지급/초기화하지 않으며 새 시험 영웅의 시작 가방에는 각 타입 Small3/Medium2/Large1을 준다. 새 획득/상점/스토리 보상은 연결하지 않았다.

회복량은 시험값: HP40/120/300, MP40/80/160, 각각 서버 최대치까지 회복한다. MP가 없는 영웅의 MP 사용은 거부한다. 여섯 물약 모두 스택99·잠금·창고·빠른 슬롯 Z/C의 기존 서버 소유/원자 갱신/중복 방지 계약을 따른다.

TD 공유 아이콘/배틀 아틀라스와 레지스트리 조사에서 재사용할 물약 그림을 찾지 못했다. PotionIcon.luau는 외부 업로드 없이 실제 Roblox 네이티브 UI 도형으로 여섯 그림을 그린다. TD의 은빛 유리/금빛 마개, 붉은 HP·푸른 MP, 작은 둥근 병/중간 병/큰 금띠 병, S/M/L로 구별한다. 가방 카드·상세·빠른 슬롯에서 같은 렌더러를 쓴다. 빠른 슬롯은 실제 등록 definitionId를 복제 상태에서 읽어 그림과 크기/유형 캡션·x수량을 갱신하며,0개가 되어도 등록 그림과x0을 유지한다. 색만으로 구분하지 않는다.

추가 사용자 요청: Sprint x92/폭56은 고정. Attack x76/폭88로 두 버튼 가로 중심120을 일치시켰다. 이전x102에서26px 더 왼쪽이며 높이/크기는 유지한다.
