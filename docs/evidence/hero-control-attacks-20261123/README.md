| 기술 | 움직임과 명중 |
| --- | --- |

서버가 전달하는 실제 피해의 위치와 방향으로 명중 효과를 그린다. 기술별 주요 Beam 두 개는 기존 시간·거리·동시 효과 예산을 쓴다. 이 경로가 그려지면 범용 충돌 구체와 섬광을 줄인다. 피해 숫자는 독립 경로로 표시한다. [조사 근거](../../research/2026-11-23-hero-control-attacks.md)

## 검증 결과

- 커밋 `c39a6ee8`에서 로비·배틀 공용 Place를 생성했다. 파일 SHA-256과 변경된 클라이언트 모듈 세 개를 입력 커밋에 대조했다. [고정 빌드 기록](build.json)
- Luau 컴파일러로 변경 모듈 세 개와 Studio용 재현 스크립트의 구문을 확인했다. Lua CPU 검사에서 전직 및 장착 1,435건, 116개 전직·공통 기술의 효과·형상·예산·취소 12,632건, Place 역할 10건이 통과했다.
- Luau에서 네 기술의 관절 가산값과 두 명중 곡선을 검사했다. 직전 소스는 공통 자세를 쓰고 신규 획이 없어 16건 중 13건이 실패했다. 후보는 108건이 통과했다. 곡선당 5시점의 위치를 확인했으며, 후보의 양 끝점과 중점은 공격이 들어오는 면에 머물렀다. 이 검사는 Roblox 뷰포트의 결과를 측정하지 않는다.
- 두 빌드에서 `run-in-roblox` 실행기 연결이 검사 시작 전 시간 초과됐다. 로컬 사본을 여는 별도 시도에서도 해당 Place가 도구의 Studio 목록에 나타나지 않았다. [R6/R15와 본인·아군 렌더러 재현 스크립트](../../../tests/hero-control-attacks-native.luau)

## 남은 수용
