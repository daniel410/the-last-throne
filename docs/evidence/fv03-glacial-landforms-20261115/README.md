# FV-03 빙하 지형 대표 개선

2026-11-15 · TLT-062 · 맵 구현/환경 아트/환경 모델링 → QA/DES · 로컬 구현·미게시

대표 구간의 빈 가장자리에 지형의 높이와 재질 차를 추가했다. 기존 양안 봉화·횡단로 복구 이야기는 그대로 사용한다. 다섯 에픽 전체 재구현이나 G5 완료를 선언하지 않는다. 빌드 **0.107.10**, 입력 커밋 `98e194a3554fb644b2e22f3b6d42410a1fea601b`. [고정 빌드·LFS 검증](build.json) · [조사와 선택 근거](../../research/2026-11-15-frozen-ravine-landforms.md).

옛 문서 좌표를 새 정본으로 적용하지 않는다. 현재 런타임 중심은 `(277.15,92,-8781.65)`, 바닥 크기는 `552×556.5`이며 북쪽 구조 윙/동쪽 횡단로 윙을 포함한다. 처음 검토한 연속 양안 설벽은 다른 스토리 구역·확장 사건과 겹쳐 기각했다. 안전 예약을 통과한 지형만 배치하므로 양옆 모두 큰 절벽으로 둘렀다고 보고하지 않는다.

`FrozenRavineLandforms`는 `NewNativeTerrain` 원천이다. TD 공유 모델·원본 텍스처·Blender 파일·지역 건축 템플릿은 변경하지 않았다. 기존 일반 절벽 링을 해당 구간에서 대체하며 다른 구역의 지형 생성 분기는 유지한다. 모든 지형 쓰기는 전체 회전 형상 반경+복셀 여유로 인접 본편/선택/확장 구역·연결로를 피한다. 내부 돌출부는 기존 전투/NPC/목표/활동/귀환로 예약도 통과한다. 기반 바닥을 빼거나 구멍을 뚫지 않는다.

신규 BasePart·메시·텍스처·조명·입자·프레임 갱신·프롬프트가 없다. 1개 형상당 3회 Terrain 쓰기 후 yield한다. 높이·재질·생성 수의 실제 측정과 최종 검증은 `fixed-native.log`를 기준으로 한다. 복셀 비용이 0이라는 뜻은 아니며 기기별 성능 예산은 아직 측정하지 않았다.

## 재현과 검증

```bash
python3 tools/build-game.py --source 98e194a3 --record /tmp/fv03-build.json
python3 tools/prepare-frozen-ravine-native.py --review
run-in-roblox --place builds/0.107.10/TheLastThrone-0.107.10.rbxlx --script /tmp/tlt-frozen-ravine-native.luau
```

실행기는 신규 지형 모듈/통합 모듈 바이트 일치와 전체 Luau 컴파일을 먼저 검사한다. 고정 빌드에 소스를 주입하지 않는다. [정적 검사](static.log)는 원고/진행 계약1,054·전투 동선77,381·이동 안내106,051검사를 포함한다. 이 결과를 엔진·실제 조작·사용자 수용과 구별한다.

최종 [고정 엔진 로그](fixed-native.log)·[구조화 결과/기준 비교](results.json)·[검사 입력 해시](fixed-inputs.json)에서 지형6개(외곽1/돌출부5), 추가 BasePart0, 지형 쓰기18회를 확인했다. 신규 지형1,523검사에서 실제 높이21.52~113.71stud와 눈/노출 얼음·신호선 시야를 통과했다. Frozen Vale11스토리·142목표·6,177이동 표본에서 차단/바닥/보정/안내 실패0이었다. 대표 건축·생활 구성·물리 충돌·315교전 지점·지역 조명/길 마감 회귀도 통과했다. 실제 R15 에픽 경계 왕복8방향의 점프/서버 위치 보정은0이었다. 전 지역 이동 차단2건과 작은 단차6건은 기준 빌드와 동일함을 구조화 결과로 대조했다.

초기 [후보 회귀](candidate-native.log)는 전 지역 이동 sweep의 GW-01 나무/EC-05 작업대 차단 2건으로 전체 통과에 실패했다. 변경 전 **0.107.9**의 [독립 재현](baseline-navigation.log)에서 같은 두 물체·같은 목표·같은 접촉 좌표를 확인했다. [기준 소스 일치](baseline-source.json)는 기준 빌드의 지형/맵/배치/콘텐츠 4모듈이 변경 전 커밋과 같음을 확인한다. 이 결함을 숨기거나 검사에서 전 지역 통과로 바꾸지 않는다. 전용 실행기는 변경된 Frozen Vale 통과를 별도 판정하고 나머지 결과 전체를 출력하며 기준 결과와 비교한다.

고정 빌드 첫 [검사 시도](fixed-attempt-1.log)는 실제 R15 검사의 `Run:Stop()` 이후 다른 장면 검사를 이어 실행해, 편집 상태 복원 뒤의 블록아웃 충돌까지 집계했다. 이를 정상 장면의 신규 지형 결함으로 해석하지 않았다. 실행기를 기존 장면 참조를 사용하는 정적/기하 검사→Run/Stop 실제 이동→화면 확인 순서로 수정했으며, 런타임 지형 소스는 바꾸지 않고 동일 빌드로 재검증했다. 첫 실패를 최종 통과 검사 수에 합산하지 않는다.

기존 EC 연결 경사 끝의 약1.30stud 단차6건도 별도로 남는다. PlaceId=0 격리 시험에서 Roblox 내장 자산 hash 로딩 경고가 출력된다. 실제 계정/게시 자산 권한 검증을 이 격리 결과로 대체하지 않는다.
