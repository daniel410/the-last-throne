2026-11-16. 맵 구현·환경 아트·환경 모델링·리서치 순차 수행. 게임 맵 변경 없이, 반복 미술 후보의 판정을 막던 촬영 문제를 분리했다. G5 미완료. 본 브랜치는 검증 도구와 증거만 포함한다.

## 조건·결과

기존 후보 소스 778b70d4 / 0.111.23의 `/tmp/tlt-ec03-working-face-final-qa.rbxlx`를 자체 Studio PID60802, Edit, PlaceId0에서 열었다. 기존 파일은 BaseScript Disabled만 적용한 QA 파일이다. CampaignWorld.create(4)로 생성, 게임 소스 주입 없음. 카메라 (345.99094,170.41486,-12556.67578) → (404.52621,149.41486,-12538.74219), FOV70, 기본 조명, 같은 스토리 상태.

1. 카메라를 원점으로 복귀한 뒤 screen_capture의 일시적 카메라 인자로 촬영: [transient.png](transient.png). 큰 삼각 능선과 평탄한 지면 표시를 재현했다.
2. CFrame/Focus를 목표 위치에 유지하고 후속 호출에서 카메라 인자 없이 촬영: [held.png](held.png). 같은 형상의 암반이 세밀해지고 발밑 굴곡이 나타난다.
3. 1을 다시 재현하고 저장한 도구로 카메라 고정 후 촬영: [held-repeat.png](held-repeat.png). 안정된 형상을 재확인했다. 장면 geometry/material/조명/진행 상태는 변경하지 않았다.

이는 임시 카메라 이동과 즉시 캡처에서 Terrain 세부 단계가 충분히 갱신되지 않는 현상과 일치한다. Roblox 내부 LOD 스케줄러를 직접 측정한 것은 아니다. 기존 거대 삼각형을 모두 실제 메시 결함이라고 판정하거나, 그 캡처만으로 지형 후보를 기각해서는 안 된다. 반대로 안정된 장면에도 광산 대표물이 암반에서 떨어져 있고 둥근 외곽과 채굴면·짧은 철로의 공간 연결이 부족하다. 미술 통과는 여전히 보류한다.

기존 카메라→새 암반 높이75% 지점 raycast: East4 거리515.49, Terrain Basalt 최초 적중460.18; East5 거리414.79, Terrain Basalt 최초 적중364.82. 그 광선에는 앞선 쿼리 가능 메시 가림이 없었다. CanQuery=false 장식의 시각 가림까지 부정하는 검사가 아니다. 화면 중심 기준 각도 East4 수평-16.65°/수직22.00°, East5 수평0.93°/수직21.98°이므로 단순 프레임 밖 배치로 단정할 수도 없다.

## 재사용 절차

[카메라 도구](../../../tools/qa/hold-ec03-review-camera.luau)를 격리된 Edit QA에서 실행하고 `_G.EC03ReviewCamera.status`가 ready인지 확인한다. 이후 screen_capture에서 camera_position/look_at_position을 생략한다. datamodel_type=Edit를 전달한다. 3초는 최소 대기이며 렌더 완료 보장은 아니다. 연속 프레임의 지형 형태가 안정됐는지 직접 확인한다. 최초 엄격 CFrame 동등 비교가 미세한 부동소수점 차이로 camera-moved를 잘못 표시해 위치0.01stud/방향 dot .99999 허용치로 수정했다.

실제 영웅 카메라·보행·회피·구조전투·게시 클라이언트·실기기·스트리밍·다인 성능·사용자 미술 수용은 미검증이다. 이동/충돌 회귀를 이번에 재실행하지 않았다. 게임 빌드/버전/태그/게시 없음. 사용자의 기존 Studio와 미커밋 자산은 보존한다. 자체 Studio만 종료한다.

첫 전체 worktree 생성은 디스크 부족으로 실패했고 Git이 생성 경로를 정리했다. 자산을 지우지 않고 --no-checkout 및 sparse checkout으로 별도 작업트리를 구성했다.
