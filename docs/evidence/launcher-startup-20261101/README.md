# 로비 시작 시 독립 메뉴 깜빡임 수정

2026-11-01 · TLT-028/031/061/084 · ENG → QA · 0.58.29

사용자는 접속 초기에 오른쪽 상단의 예전 상점/가방/스탯 버튼이 잠깐 나타난다고 보고했다. 현재 소스와0.58.28 Play의 인스턴스를 확인한 결과 `InventoryGui.OpenBag`, `HeroGrowthGui.OpenHero`, `GameSettings.OpenSettings`라는 독립 버튼 생성 코드가 남아 있다. 평상시 로비와 배틀에서는 숨기고 기존 MENU/미니맵 메뉴에서 상세 화면을 연다. 독립 버튼은 기본 Visible=true로 생성되고, 생성 함수가 끝나야 숨김이 적용된다. 그 사이 원격 객체 대기 등으로 양보하면 화면에 노출될 수 있다. 또 기존 부정 조건은 미복제 nil 및 LoadingLobby/ReturningLobby를 표시 대상으로 잘못 분류한다.

세 생성 함수에서 버튼 생성 직후 Visible=false를 적용하고, nil/LoadingLobby/ReturningLobby에서도 숨기도록 수정했다. SpawnFailed 상태의 기존 독립 버튼 폴백과 상세 메뉴 열림 시 숨김은 유지한다. 로비 기본 메뉴·아이콘·위치와 TD 공통 룩앤필은 변경하지 않는다. 현재 소스와 Play에서 별도의 오른쪽 상단 다이아 상점 버튼은 발견하지 못했다. 현재 다이아 상점 버튼은 왼쪽 로비 레일에만 있으며, 사용자가 본 세부 글자는 별도 화면 녹화로 추가 확인할 수 있다.

검증: `tests/launcher-startup-native.luau`. 현재 Studio Play Client에 원본 소스의 생성 함수 앞부분을 임시 복제해 가짜 플레이어/PlayerGui로 실행하고, 콜백 등록·계정 요청 전에 종료했다. 생성 중150ms 지연을 넣은 원본은 첫 검사에서 Visible=true로 실패하여 결함을 재현했다. 수정본은 생성 중 숨김,미복제 상태 및6상태 숨김,SpawnFailed 폴백,다른 상세 메뉴에 의한 숨김 등30개 Pass. fixture와 테스트용 global을 제거했으며 사용자의 기존 Play는 유지했다. 결과는 native.json에 기록한다.

미검증: 실제 재접속 전체 영상·게시 클라이언트·느린 기기의 최초 렌더·독립 QA/사용자 관찰. 검사 범위는 실제 Roblox GUI 속성과 생성 순서이며 전체 로그인 완주나 실기기 수용을 대신하지 않는다. 다음 담당 QA는 새 빌드에서 최초 접속/로비 복귀를 시각 재검증한다. 상위 티켓은 닫지 않는다. Roblox 미게시·릴리스 태그 없음. 다른 미커밋 작업은 보존하고 고정 소스 빌드에서 제외한다. 빌드 결과와 해시는 build.json을 따른다.
