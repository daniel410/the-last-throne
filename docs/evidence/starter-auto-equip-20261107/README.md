# 영웅 생성 시 기본 장비 자동 착용·트레이닝 무기 중단

2026-11-07 · TLT-027/029/041/052/057/084 · ENG/DES → QA · 0.79.9 · 미게시, 부모 티켓 In Progress.

사용자 지시: 처음 영웅을 생성할 때 기본 무기·장비를 모두 착용하고 트레이닝용 무기를 없앤다. 기존 생성 경로가 트레이닝 무기를 장착하고 실제 기본 세트를 가방에 넣던 문제를 수정한다. 명확한 초기 지급/배치 교정이므로 별도 사례 리서치 예외를 적용한다.

- 신규 영웅은 클래스별 Tempered 무기·Traveler 후드/코트/장갑/신발·Copper Ring·Amber Charm을 즉시 착용한다. Knight는 기존0방어 기본 방패를 유지하고 영어 이름을 Dawnspire Shield로 정리한다. 장신구는 공통 자동 슬롯 규칙을 따른다. Knight8슬롯·나머지7슬롯을 채우며 비기사에게 방패를 만들지 않는다.
- Lv5 Veteran's Hood는 기존 레벨 제한을 유지하고 가방에 지급한다. 같은 머리 슬롯의 Lv1 후드를 덮어쓰지 않는다. 무강화 기본 장비 합계 공격력5%·HP50·방어5와 물약/재료 수량은 유지한다.
- 트레이닝 무기4종의 신규 영웅 지급을 제거하고 retired/cacheEligible=false로 새 일반 지급·상자 선택을 차단한다. 이미 저장된 인스턴스와 안정ID/강화·권리는 파괴하지 않으며 기존 프로필을 읽기 위한 정의만 남긴다. 기존 영웅의 장비 편성을 소급 변경하거나 장비/보급을 재지급하지 않는다. 신규 생성에는 트레이닝 무기가 없고 Tempered 무기는1개만 지급한다.
- 같은 계정 갱신에서 아이템 위치와 영웅별 최초 보급 수령표시를 저장한다. 기존 클래스/ID 중복 방지·서버 소유권·로드 실패/저장불명 처리는 유지한다. 사용자 Blender/컨셉 삭제·미추적 파일은 이번 커밋에서 제외한다.
