# 영웅 히트스톱·넉백 안전성·본인 효과음 우선권

2026-11-08 · TLT-005/013/014/015/027/032/054/055/057/084 · ENG → QA/DES · 0.87.0 · Studio 적용·미게시

사용자가 [공격 피드백 검토안](../../research/2026-11-08-hero-hit-feedback-review.md)의 구현을 요청했다. 근접 타격감·기존 밀기 기술의 안전성·파티 음원 우선권을 구현했다. 통합 기준은 직전0.86.5의 기사 평균0.70초/드워프0.80초다. 이번 작업은 그 공격 주기/피해·DEX·자세 피해·쿨다운·기존 경직/기절·저장/보상을 변경하지 않는다. 전체 티켓의 최종 밸런스/실기기 수용은 남아 있다.

## 변경

### 히트스톱

- `K0HitStop`은 서버가 실제 HP 감소를 확정한 뒤 전송하는 공격자·seq·시작 시각·표본 확정 시각을 검사한다. 본인 캐릭터의 현재 공격과 일치할 때만 적용한다. 타인·이전 생명/공격·180ms 초과 지연·미래 이벤트·회피/사망/새 행동은 정지를 만들지 않는다. 메타데이터는 기존 명중 이벤트 마지막 인자로 추가해 앞선7인자를 보존한다.
- 평타는 기사30ms/마지막45ms·드워프50ms·마법사 지팡이25ms다. 근접 단발 스킬은 기사45ms·드워프65ms, 적격 근접 다단은 첫 유효 접촉30ms다. 엘프·투사체/던지기·원거리/마법 기술에는 적용하지 않는다. 강타·단발/다단의 시험값이며 사용자 체감 최종 수용은 별도다.
- 광역/다단의 같은 공격에서는 한 번만 작동한다. 팔·몸통·손에 든 무기가 같은 포즈 시계를 공유하고, 정지 후 두 배 길이의 회복 구간에서 기존 시간축으로 합류한다. 남은 행동 시간이 부족하면 정지를 줄이거나 생략한다. 이동·물리 루트·회피 입력·서버 시계와 판정은 멈추지 않는다. 발동음/투사체/명중 이펙트의 이벤트 시계는 원래 서버 시간을 따른다.
- 서버 속성이 명중 이벤트보다 늦게 도착해 신원이 일치하지 않으면 해당 정지는 생략한다. 잘못된 새 공격을 멈추는 대신 보수적으로 처리하며, 지연 시점으로 모션을 되감지 않는다.

### 넉백

- 기존 Steel Sweep2/Mountain Sweep2/Fan Break3stud만 `EnemyKnockback`에 연결했다. 평타의 실제 넉백0은 유지한다. 기존 순간 `PivotTo`를0.12초 분할 이동으로 바꾸고, 프레임이 건너뛰어도 최대0.35stud씩 몸체 Blockcast·중앙/발판 네 모서리 지면을 검사한다.
- StoryBoss/Ogre/명시적 KnockbackImmune는 고정한다. 최대3stud·0.20초 재밀기 면역으로 동시 파티 공격의 거리 누적을 막는다. 깊은 낙차·수면·발판 이탈·급경사·몸체 벽·스폰 추적 범위를 넘는 이동은 중단한다. 작은 높이 차는 지면을 따라 이동한다. 수평 관성은 제거하고 수직 속도는 보존한다.
- 기존 추격 경로를 폐기하고 이동 종료 뒤 기존 AI 루프로 돌아간다. 사망·적 리셋·스토리 일시정지에서는 보류 이동을 폐기한다. 보스 기절/자세붕괴 정책은 이 넉백 면역과 별도로 유지한다.

### 효과음

- 중복 억제를 원음/8stud 셀/공격자별70ms로 분리했다. 같은 원음을 쓰는 동료의 명중이 본인 접촉음을 지우지 않는다. 같은 공격자의 광역 접촉은 계속 합친다.
- 발동8/명중8 상한 안에서 타인 소리를 먼저 교체하고, 타인 소리가 본인 소리를 밀어내지 않게 했다. 본인 소리로 꽉 찬 경우 새 본인 소리가 오래된 본인 소리를 교체한다. 음량·피치·음원ID·거리·정리/프리로드는 유지한다.
- 사용자 복구 지시인 기사 평타 착지음/마법사 기술 물소리·고정속도·신규 발동음 없음은 그대로다. 도끼/화살 등의 새 녹음 선정이나 음량 증가는 하지 않았다. 청취 전 자산 교체보다 확인 가능한 라우팅 개선을 우선했다.
