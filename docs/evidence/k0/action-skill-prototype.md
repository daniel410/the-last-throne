# 공통 액션·스킬 편성 시험 구현

2026-10-28 · TLT-005/008/014/028/032/084 · 엔지니어링·QA · 부분 원형

## 구현

- 네 영웅에게 무료 Attack·Block·Dodge·Sprint를 제공한다. PC 시험 조작은 왼쪽 클릭, Q/오른쪽 클릭 유지, R/V, E 유지다. Space는 점프, X는 표적 해제다. 패드와 터치 경로도 구현했으나 실기기 확인 전이다. Sprint는 서버가 유지 신호·속도 및 이동 허용량을 검증하고 입력이 끊기면 정지한다. Block의 기존 방향·완벽 방어·피해 감소는 전 직업에 임시 적용했다. 무기별 방어 자세는 초기 표현이다.
- 각 물리 기술은 Stamina, Mage 주문은 MP와 기술별 독립 쿨다운을 서버에서 검증한다. 임시 최대값은 각 100, 초당 회복 Stamina 15/MP 10이며 사용 후 1초가 지나 회복한다. Stamina 비용은 기술별 15~30, MP는 12~20이다. 기본 액션은 비용이 없다. 원형 엘프에게 MP를 주지 않는다.
- 로비에서 세션 영웅의 기술 3개를 슬롯에 지정·교환·비울 수 있으며 서버가 소유·로비 상태·슬롯과 중복을 검증한다. 4·5번은 처음에 잠긴다. 실제 전직·레벨과 저장은 없으므로 로비의 `PRACTICE ONLY` 버튼으로만 5슬롯을 시험한다. 더 많은 기술을 자동으로 지급하지 않는다. 키 6과 궁극기 슬롯은 미결정이다.
- 전투 화면 하단에 장착 기술의 약어 기반 임시 아이콘, 이름, 키, 개별 남은 쿨다운을 표시한다. 자원 부족 메시지는 영어로 제공한다. 세션 동안 기술별 쿨다운은 편성 변경·로비 복귀·리스폰을 거쳐 유지된다. 영웅·편성·쿨다운은 접속 종료 시 초기화된다.
