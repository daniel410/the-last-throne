# 튜토리얼 전투 피드백 원형

작업: TLT-005/006/007/032/033 일부 · 2026-10-28 · 담당 ENG/ART/QA, 통합 DIR. 사용자 요청을 반영한 시험판이며 티켓 전체 수용은 아니다.

- TD 원본 Slime을 전투 대상에 추가했다. 기본 접근·공격·체력/자세·재생성만 있으며 분열과 보상은 구현하지 않았다. TD 원본 Orc/Ogre를 그대로 재사용하고 오우거의 시각 높이를 9.18 studs로 확대했다. 오크는 4.60 studs다. 체구에 맞게 오우거 경로 탐색 크기도 조정했다.
- Knight는 전방으로 기울인 검, 측면에 든 방패, 팔·검의 전방 공격과 방어 팔 동작을 사용한다. 방어 중 방패 면이 앞을 향하며 머리 앞쪽까지 올라간다. Elf는 활을 내렸다가 양팔과 활을 들어 원본 활시위·화살을 당긴 뒤 발사한다. Dwarf는 TD 도끼 방향을 바로잡아 앞으로 기울여 들고 근접 공격한다. Mage는 나무 지팡이를 기울여 들고 근접 공격하거나 지팡이를 내미는 시험용 Arcane Bolt를 쓴다.
- 검·도끼·지팡이 궤적, 화살·마법 발사체와 착탄 효과는 시각 전용이다. Arcane Bolt는 마법사 전용이며 PC Q, 패드 Y 또는 HUD로 사용한다. 사거리·장애물·재사용 시간·피해와 자원은 서버가 결정한다. 기존의 근접 기본 공격을 대체하지 않는다.
- 몬스터 머리 위에 기존보다 0.35 studs 높인 96×30px 표시에는 이름과 현재/최대 HP가 나타난다. TD `EnemyHpBar.lua`의 초록/노랑/빨강 비율 경계(50%, 25%)를 참조했다. 서버 Humanoid 값으로 갱신하고 사망 시 숨기며 재생성 때 다시 만든다.

## 검증과 한계

- Lua 규칙 122, 영웅 세션 77, 스폰 생명주기, 외형 생명주기와 TD 자산 134개 정적 검사를 통과했다. TD 원본 파일의 해시와 원본 바이트 동일성도 확인했다.
- [서버 전투 native 로그](combat-spell-native.log)는 슬라임 근접 타격, 마법 피해/사거리/장애물/재사용 제한과 중복 방지를 포함한 137개 검사를 통과했다. [무기 native 로그](combat-visual-final.log)는 R6/R15 무기와 활시위, 시각 효과, 팔 동작 등의 2,149개 검사를 통과했다.
- [최종 소스 Studio smoke 로그](combat-feedback-final-source-smoke.log)는 원본 MeshPart 로딩, 네 몬스터와 재생성, 체력 수치/색상/사망 시 표시 등을 검사한다. 이 소스 fixture는 실제 게임 빌드가 아니다.
- 격리 Studio의 실제 R15 플레이에서 검 활성 구간의 칼끝 전방 내적 평균 약 0.75와 검 궤적, 방어 중 방패 정면 내적 0.95 및 머리 높이(방패 중심 1.14, 머리 중심 1.21 studs)를 측정했다. Elf 활 당김과 화살, Dwarf 팔/도끼와 궤적, Mage Q 입력과 시전/발사체를 확인했다. 실제 사용자 아바타별 시각 품질·R6 플레이·터치/패드·다인 환경·게시된 테스트 클라이언트 및 모바일 가독성은 추가 검증이 필요하다. 원본 방패 Mesh ID의 게시 대상 Experience 권한도 별도 확인이 필요하다.
