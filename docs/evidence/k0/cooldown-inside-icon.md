# 스킬 쿨다운 아이콘 내부 표시

2026-10-28 · TLT-028/084 · UI·QA · 부분 원형

쿨다운 중인 스킬은 아이콘 약어 대신 남은 시간을 아이콘 내부에 표시한다. 단축키와 스킬명은 계속 보이며, 준비가 되면 시간은 사라지고 약어가 복원된다. 서버의 쿨다운 판정과 스킬 입력은 변경하지 않았다.

빌드 전 격리 Studio R15 Player에서 Knight의 Whirlwind를 사용해 `7.8s`가 아이콘 경계 안에 표시되고, 단축키·스킬명과 겹치지 않는 것을 GUI 절대 좌표로 확인했다. 시간이 끝난 뒤 표시가 사라지고 약어가 복원되는 것도 확인했다. 이는 단일 Studio 화면의 확인이며 모바일·패드·다양한 화면 크기와 사용자 시각 수용은 미검증이다. 다음 담당: QA(다양한 화면 크기와 입력 기기).
