# 근접 표적 공격과 도끼 높이

2026-10-28 · TLT-008 · 엔지니어링 → QA

- 기사·드워프·마법사도 몬스터 클릭으로 표적을 선택하고 기본 공격을 시작한다. 터치는 몬스터를 탭해 선택하고 Attack 버튼으로 공격한다. X는 PC 표적 해제다.
- 서버가 공격 시작 시 살아 있는 등록 표적의 현재 위치로 캐릭터와 공격 방향을 맞추고 한 번의 휘두르기 동안 방향을 고정한다. 사거리·높이·각도·장애물을 서버에서 검증하고 표적을 우선 타격한다. 표적이 유효하지 않거나 닿지 않으면 다른 적을 대신 맞히지 않는다. 표적이 없으면 기존 전방 공격을 유지한다. 자동 이동이나 사거리 확장은 없다.
- 마법사 지팡이 기본 공격 궤적을 조금 더 낮췄다. 마법 Cast 동작은 별도다. 드워프 도끼를 더 높이 들어 머리 위에서 다리 쪽으로 내려친다.
- 소스 fixture 서버 256개 검사에서 세 직업의 측면 표적 회전·명중, 사거리 밖·장애물·사망 표적, 미등록 요청, 공격 중 방향 고정·예약 공격, 다중 타격 우선순위 및 AutoRotate 복원을 확인했다. 타이밍 기존 121개 검사도 통과했다. 격리 Studio Play의 R15 기사에서 실제 마우스 클릭으로 표적 표시, 측면 표적 방향 전환과 Goblin HP 300→150을 확인했다. 이 Play는 도끼 높이를 추가 조정하기 전 동일 표적 코드로 수행했다.
- 격리 소스의 R6/R15 관절 순운동학 검사는 실제 플레이어·화면 렌더링을 대체하지 않는다. 여러 아바타 체형, 실제 사용자의 동작 수용, 모바일·패드·다인·게시 클라이언트는 미검증이다.
- 회피 키 검토는 [비교 문서](../../production/dodge-key-research.md)에 기록했다. 키 배치 변경은 아직 적용하지 않았다.
