# 드워프·엘프 기본 스킬

2026-10-28 · TLT-008/014/032/084 · 엔지니어링·QA · 세션 시험 원형

사용자 요청으로 드워프와 엘프의 기본 스킬을 각 3개로 교체했다. 모두 물리 스킬이며 서버가 Stamina 비용·개별 쿨다운·피해·대상·거리·장애물을 검사한다. 기본 도끼 휘두르기와 활 공격은 비용 없는 공통 Attack으로 유지한다.

| 영웅 / 슬롯 | 스킬 | 시험 동작 | Stamina / 쿨다운 |
| --- | --- | --- | --- |
| Dwarf 1 | Overhead Smash | 단일 대상 머리 위 내려찍기. 공격력 140% | 20 / 6초 |
| Dwarf 2 | Axe Throw | 단일 대상 도끼 투척. 사거리 32, 공격력 110% | 20 / 7초 |
| Dwarf 3 | Ground Slam | 자기 중심 반경 6·360도, 최대 8명. 공격력 120% | 30 / 10초 |
| Elf 1 | Aimed Shot | 단일 대상 정밀 사격. 사거리 55, 공격력 140% | 20 / 6초 |
| Elf 2 | Rapid Fire | 0.18초 간격 3발, 각 발당 공격력 55%, 매 발마다 대상·거리·벽 확인 | 25 / 8초 |
| Elf 3 | Multi Shot | 정면 70도·사거리 50, 최대 5명에게 각 화살. 대상당 공격력 75% | 30 / 10초 |

Ground Slam은 선택 대상이 멀더라도 자신의 주변에 판정한다. Multi Shot은 선택하거나 전방에서 찾아낸 유효한 첫 대상을 중심으로 전방 부채꼴에서 다른 적을 찾고, 적마다 벽을 검사한다. 유효한 첫 대상이 없으면 추가 공격은 없다. Rapid Fire는 각 화살에 독립 타격 창을 사용하며 중단되거나 지나치게 늦은 발사는 실행하지 않는다. 다중 화살과 Ground Slam의 광역 원형 효과는 시각 전용이다.

수치·범위·대상 수·발사 간격은 시험값이다. Axe Throw는 현재 손에 장착된 도끼를 유지하면서 투척 모델을 시각적으로 복제한다. 실제 무기 이동·회수와 영구 장비 상태는 미구현이다. 세션 기술은 시작 시 지급되며 정식 학습·전직·저장은 아직 없다.
