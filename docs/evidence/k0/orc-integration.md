# Deepwood K0 오크 추가

2026-10-28 · `TLT-002/005/006/007/032/033` 일부 · 총괄/3D/엔지니어/QA

## 구현 범위

사용자 요청에 따라 TD에서 사용 중인 일반 `orc` 모델을 K0의 세 번째 전투 적 **Orc Warrior**로 추가한다. `Orc Warlord` 보스와 다른 일반 적이다. TD의 Meshy 원본과 런타임 메시·텍스처, 각 부위 및 해시는 [오크 원본 기록](orc-source.md)에 추적한다.

- TD 오크 메시 5부위와 기존 고블린/오우거의 동작 어댑터를 사용한다. 도끼는 TD의 `ArmR`에 포함되며 RPG에서 무기 쪽 어깨에 연결된다. 외형은 서버 충돌·공격 판정과 분리한다.
- 훈련장 초기 위치는 `(42, 0, 17)`이다. 기존 Spawn, Goblin, Ogre와 초기 감지 범위를 분리한다. 경로·재생성은 다른 적과 같은 서버 상태를 사용한다.
- 실험값은 HP900, 자세100, 이동속도8.5, 감지25, 이탈36, 기본 공격5stud/90도, 예고0.85초, 피해125, 방어 스태미나25, 5초 후 재생성이다. 이 수치는 플레이 테스트용이며 정식 밸런스 확정이 아니다.
- 오크 공격은 고블린 전용 공격 간격 타이머를 갱신하지 않는다. 장갑·측후면별 피해는 기획 방향이며 아직 구현하지 않았다. 슬라임 전투·분열도 별도다.
