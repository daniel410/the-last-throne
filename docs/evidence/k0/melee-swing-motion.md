# 세 직업 근접 공격 동작 조정

2026-10-28 · TLT-033 부분 원형 · ENG/ART/QA

사용자 요청에 따라 기사는 칼끝을 앞으로 뻗은 채 몸 앞에서 좌우로 크게 베며, 두 번째 연격은 반대 방향으로 움직인다. 드워프는 도끼를 위로 들어 몸 앞에서 아래로 내려친다. 마법사는 기본 공격에서 지팡이를 오른쪽 위에서 왼쪽 아래로 대각선으로 크게 휘두른다. 마법사의 Cast는 기존 자세를 유지한다. R6와 R15의 어깨 관절 기준축 차이를 보정하며 기존 무기 원본·서버 피해 및 타격 판정·공격 시간은 변경하지 않았다.

## 검증과 한계

- `tests/k0-melee-motion-native.luau`: 실제 R6/R15 리그와 무기 소켓, 프로덕션 동작 및 60Hz 보간을 사용한 순운동학 검사 28개 통과. 기사 3연격의 수평 왕복, 드워프의 하강, 마법사의 대각 하강을 확인했다. [로그](melee-swing-motion-native.log). 관절 계산은 실제 물리나 화면을 대신하지 않는다.
- 동일 소스의 격리된 Studio Play에서 실제 R15 플레이어로 영웅을 각각 만들고 튜토리얼에 진입해 서버 공격 Remote를 실행했다. 준비/공격 구간 마지막 샘플 기준 무기 끝의 캐릭터 로컬 좌표(스터드)는 기사 X 약 -3.68 → 5.13, 드워프 Y 약 2.09 → 0.77, 마법사 X 약 2.33 → -1.71 및 Y 약 2.71 → 0.53이었다. 수치는 움직이는 실제 리그의 단일 측정이며 시각적 수용을 의미하지 않는다.
- `tests/k0-player-weapons-native.luau`: 기존 무기·방패·활·Cast 및 자산 회귀 검사 2,177개 통과. [로그](melee-swing-weapons-native.log)
- 실제 사용자 시각 평가, 다양한 체형, R6 실제 Play, 다인·모바일·게시 환경은 미검증이다. 다음 담당은 QA·디자인이며 TLT-033 전체 수용은 계속 진행 중이다.
