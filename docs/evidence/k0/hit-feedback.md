# 명중 피드백 원형

2026-10-28 · TLT-033/034 부분 원형 · ENG/DES/QA

서버가 검증된 공격으로 실제 체력을 감소시킨 순간 `K0HitEffect`로 대상·피해·직업·종류·위치를 알린다. 피해 수치는 남은 체력을 초과하지 않으며, 빗나감·ForceField로 막힌 피해에는 명중 효과를 보내지 않는다. 서버가 피해와 체력을 계속 확정하고 이벤트는 연출에만 사용한다.

네 직업의 명중 색·입자·타격음과 짧은 섬광, 적 모델의 짧은 색 반응, 체력 바 위로 떠오르는 피해 숫자를 추가했다. 슬라임은 젤 방울, 오우거는 조금 큰 섬광을 쓴다. 로컬 이펙트는 최대 24개, 사운드는 0.07초 간격으로 제한하며 자동 정리된다. 음향은 기존 TD의 Roblox 기본 음원 경로를 참고한 임시 프로필이며 완성된 신규 음원은 아니다. 원거리 피해는 기존 서버 판정 시점에 확정되므로, 원거리 투사체의 시각적 도착 시점과 실제 피해·명중 피드백 사이에 차이가 있을 수 있다.

## 검증 및 한계

- `tests/k0-basic-attacks-native.luau`: 192개 통과. 실제 서버 코드와 모의 플레이어 fixture에서 명중·실제 체력 감소·처치·중복·방어막·빗나감 및 기존 네 직업 전투를 검증했다. [로그](hit-feedback-server.log)
- `tests/k0-hit-effects-native.luau`: 64개 통과. 네 직업 이펙트, 피해 숫자, 체력 바 위 배치, 슬라임 젤 입자, 효과 수 제한과 정리를 검증했다. [로그](hit-feedback-native.log)
- 동일 소스의 격리 Studio R15 플레이에서 드워프가 슬라임을 맞힐 때 서버 이벤트 `75`, 피해 숫자 `75`, 젤 5개, 색 반응, 기본 타격음의 로드와 재생 상태를 확인했다. 마법사의 고블린 기본 공격에서도 서버 이벤트·피해 숫자 `75`, 마법 프로필 음원의 로드와 재생 상태를 확인했다. 이후 피해 숫자 높이 계산을 체력 바 기준으로 수정하고 네이티브 fixture로 검증했다.
- 사용자 시각·청각 수용, 다른 체형과 R6 실제 플레이, 다인·모바일·게시 환경과 장거리 투사체의 체감 동기화는 미검증이다. 다음 담당은 QA·디자인이며 TLT-033/034의 전체 수용은 진행 중이다.
