사용자 제공 10초 영상 `media-generation-one-handed-axe-strike-single-h-0-33a89aa5-7d16-4c71-bc22-0f27678866c9.mp4`(SHA-256 `c181aa157e413e5bb8d0c0d6a703952860d88fc0acd3dd75381831a2424a9f87`)을 구간별 프레임으로 확인했다. 한 손으로 도끼를 들어 올리며 팔꿈치를 굽히고, 머리 위에서 팔을 펴 내려치면서 상체를 앞으로 숙인 후 도끼를 앞에 유지하는 동작을 참고했다. 영상의 움직임을 현재 게임의 짧은 공격 시간에 맞춰 해석한 절차식 애니메이션이며 모션 캡처나 원본 리그가 아니다. 원본 영상은 사용자 Downloads에 그대로 두었고 저장소에 복사하지 않았다.
