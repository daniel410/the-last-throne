# 슬라임 분열·피격 인식·엘프 발사 자세

2026-10-28 · TLT-007/033 부분 원형 · ENG/ART/QA

- 슬라임 사망 시 TD 원본 외형과 리그를 50%로 축소한 `Small Slime` 두 마리를 생성한다. 각각의 최대 체력은 부모 최대 체력의 25%다. 현재 부모 220, 자식 55다. 자식은 다시 분열하지 않으며 둘 다 사라진 후 부모의 기존 5초 재생성 타이머를 시작한다. 전멸 시 자식은 정리된다. 보상 시스템은 아직 연결하지 않았다.
- 서버에서 유효한 피해를 확정할 때 모든 직업의 공격자를 즉시 기록하고 6초간 인식한다. 적의 원래 위치 기준 귀환 범위는 유지한다. 작은 슬라임도 부모에게 마지막 피해를 준 살아 있는 플레이어를 인식한다.
- 엘프는 발사 준비·발사 중 활을 든 왼팔을 높이고, R15 오른팔 IK 목표를 조정해 시위를 당기는 오른손을 내린다. 격리 Studio의 실제 R15 플레이에서 관절을 수동으로 조정해 발사 준비 마지막 시점에 오른손과 시위 중심의 높이 차 약 -0.04 스터드, 중심 간 거리 약 0.35 스터드를 측정했다. 발사 준비 중 왼손 높이는 이전 자세보다 약 0.7 스터드 올라갔다. 이는 해당 아바타·순간의 관측이며 모든 아바타의 시각적 수용을 의미하지 않는다.
