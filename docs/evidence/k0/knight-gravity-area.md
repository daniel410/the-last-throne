# 기사 기본 기술과 Gravity 광역

2026-10-28 · TLT-008/014/032/084 · 엔지니어링·QA · 세션 시험 원형

사용자 결정으로 기사 기본 세 스킬을 Shield Bash, Whirlwind, Provoke로 교체하고 Mage의 Gravity를 광역기로 변경했다. 세션에서 기본 슬롯 1/2/3으로 지급하며 로비에서 재배치할 수 있다. Stamina/MP 소모와 개별 쿨다운은 서버가 관리한다.

| 기술 | 시험 동작 | 자원 / 쿨다운 |
| --- | --- | --- |
| Shield Bash | 방패로 전방 타격·자세 피해. 일반 적의 시전 중단, Ogre 시전 중단 면역 | Stamina 25 / 10초 |
| Whirlwind | 기사 중심 반경 7, 360도, 최대 8개 적을 한 번 공격. 벽 차단 | Stamina 30 / 8초 |
| Provoke | 기사 중심 반경 12, 최대 8개 적을 4초간 도발. 피해 없음, 벽과 적의 원래 추적 범위 적용 | Stamina 20 / 12초 |
| Gravity | 유효 표적 중심 반경 6, 최대 8개 적에게 피해와 3초간 이동 속도 50% 감소. 대상 주변 벽 차단 | MP 20 / 8초 |

Gravity는 기존 표적 조준 및 시야·사거리 검증을 통과한 적을 중심으로 발동한다. 무효·차단된 표적의 주변을 타격하지 않는다. 도발 중 다른 플레이어의 공격으로 목표가 바뀌지 않으며 도발 종료, 도발자의 사망/세션 변경 또는 적 추적 범위 이탈 시 기존 표적 규칙으로 돌아간다. 도발은 진행 중인 적의 공격을 강제로 취소하지 않는다. 광역 표시와 각 스킬의 동작은 초기 표현이며 반경·대상 수·피해·비용·지속 시간·보스 저항은 플레이 평가용이다.

## 검증

- `lua tests/k0-rules.spec.lua`: 122개 통과, `lua tests/k0-hero-session.spec.lua`: 89개 통과.
- 격리 Studio의 서버 fixture `tests/k0-basic-attacks-native.luau` 351개 통과. 전후방 Whirlwind·범위 밖·중복 타격, Gravity 다중 대상·범위 밖·벽·감속 해제, Provoke 우선순위·아군 피격 후 유지·지속 만료와 소모 비용을 확인했다. [로그](knight-gravity-0150-server.log).
- 빌드 전 같은 소스의 격리 Studio R15 Player에서 Knight 생성 후 스킬 관리 화면의 세 이름·비용·쿨다운과 전투 화면 숫자 1/2/3 발동, Stamina 감소 및 각각의 쿨다운을 확인했다. 기존 `203785492` 자산 유형 경고 외 콘솔 오류는 관찰되지 않았다.

실제 플레이의 다중 적 명중·도발 변경과 광역 표시의 사용자 시각 수용, 사용자 기기·다인·게시 클라이언트, 정식 레벨/전직/스킬트리 및 밸런스는 미검증이다. 다음 담당: 기획(보스 도발 저항·수치), 디자인(광역 모션/표시), 엔지니어링(정식 성장 자격), QA(다인·실기기).
