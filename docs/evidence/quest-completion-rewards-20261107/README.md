# 보상 없는 퀘스트 수정

2026-11-07 · TLT-027/028/041/050/052/057/061~065/084 · 0.83.0 · ENG/QA → 실계정/기기 QA · 미게시

사용자가 “보상이 없는 퀘스트는 말이 안 된다”고 지시했다. 사이드12개 외에 Gloamwood 본편7개에도 고정 완료XP/Gold가0임을 확인해19개에 확정 완료 보상을 추가했다. 현재 CampaignContent47개 모두 완료XP·Gold가 양수다. 구체 수치는 사용자 지정이 없어 기존 본편 규모/강화50Gold·광석/보석 경제에 맞춰 정한 초기 조정값이며 최종 밸런스 수용과 구분한다.

## 변경과 보상

사이드 합계2,320XP·3,100Gold·Iron Ore16·Enhancement Gem10, Gloamwood 합계1,720XP·2,600Gold다. 퀘스트당 초회권리는 영웅별1회다. 전투 사이드의 기존 난도 재료/장비상자 진행은 별도로 지급한다. 비전투 사이드도 초회 보상과 신규 반복XP·Gold를 받는다. 새로운 Diamonds 보상·Soft Hide·트레이닝 무기는 추가하지 않았다.

신규 규칙12 원정의 이19개 반복 보상은 초회XP의25% 내림, Gold의30% 내림 후 기존 난도/레벨 밴드·반복Gold20%감소를 적용한다. 규칙1~11로 고정된 기존 원정은 기존 반복 보상을 유지한다. 기존 영점 거점 스토리의 반복0 규칙은 그대로이며 해당 스토리의 초회XP/Gold는 원래부터 양수다.

## 저장과 누락분 복구

`completionRewardClaims[questId]=1`과 지급을 같은 계정 저장에 기록한다. 이미 완료한19개도 계정 로드 시 미지급 권리를 확인해 XP·Gold·재료를1회 보충한다. 기존 수령분을 추측해 되돌리거나 원래 퀘스트 완료 기록을 초기화하지 않는다. 지급 후 Gold를 쓰거나 재료를 팔아도 영수증이 남아 다시 지급하지 않는다. Lv80은 XP 상한만 적용하며 Gold/재료 권리는 유지한다. Gold 상한에 걸린 누락분은 허위 수령표시 없이 다음 로드에서 재확인한다.

구 저널의 coins는 기존 고정Gold 합계 검증값이다. 새 보상을 이 값에 섞으면 기존 계정의 선검증이 실패하므로 `journalCoins`로 역사적 합계를 보존하고 새 보상은 계정 지갑과 영수증에 저장한다. 신규/구 저장·원정 재현 모두 같은 규칙을 따른다. 기존 본편 Gold 합계16,570은 저널에 유지되고 새 본편 지급 합계는19,170이다. 계정Store의 lease·UpdateAsync·저장 실패/응답불명 경로를 그대로 사용한다.

## UI와 범위

기존 TD 룩앤필을 유지하며 모험 선택의 초회/반복 미리보기, 로비 퀘스트 목록, 배틀 퀘스트북, 완료창에 실제 지급XP/Gold·추가 재료를 표시한다. 로비 목록의 보상 높이는 실제 글자 크기로 계산해 작은 화면에서 잘리지 않게 했다. 게임 문구는 영어다.

이번 구현은 **퀘스트 완료 보상과 기존 완료자의 누락분 지급**이다. 이전 [Tessa 의뢰/대리 보고 설계](../../production/lobby-side-quest-npc-2026-11-07.md)의 NPC 대화·로비 보고 버튼·새 현장 보고 어댑터는 구현하지 않았다. 현재 보상은 기존 현장 퀘스트 보고 경로에서 지급한다.
