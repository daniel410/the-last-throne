| 기사 | Shield Verdict 직후 몸통이 뒤로 반동하고 앞 무릎이 충격을 받는다. 적 리그는 방패에 밀리는 방향으로 짧게 기울고 금빛 두 갈래 효과가 퍼진다. |

| 엘프 | Heavy Draw의 팔·몸통 반동을 길게 유지하고 연사 반동은 빠르게 회수한다. 곡사에서는 몸통을 위로 열고, 관통 명중은 사격 방향을 따라 가늘고 짧게 남는다. |
| 마법사 | Cinder Ring의 유도 손은 위로 힘을 밀어내고 Frost Ring은 팔을 바깥으로 펼친다. 명중에는 상승하는 불티·냉기 쐐기·번개 분기·하향 대지 균열을 사용한다. Gravity에 맞은 적은 주문 쪽으로 당겨지는 자세를 취한다. |

연속 명중은 이전 리그 자세에서 이어진다. 보스와 공격 예고 중인 적은 흔들림 폭을 줄인다. 클라이언트의 시각 리그에 적용했으며 실제 좌표·피해·상태이상·펄스 시각은 기존 서버 판정을 따른다. 다른 영웅의 공격에서는 스킬 형상과 명중 순간, 피해 숫자, 공간 음향을 유지하면서 보조 잔광·입자·피격 강조를 줄인다.

## 검증과 인계

- 커밋에 고정한 게임 빌드에서 Studio 검사 16묶음, 어설션 282,153건을 통과했다. R6/R15 각 128개 스킬의 관절·무기 소켓, Blender 기준 활·지팡이 포즈, 128개 스킬의 자기·아군 명중, 기존 원소·타격 정지·VFX 한도를 확인했다. 활과 지팡이의 기준 샘플 누락으로 첫 실행에서 해당 두 묶음이 중단됐고, Blender 기준 데이터를 포함해 같은 빌드에서 재실행했다.
- 격리 장면에서 네 영웅의 스킬을 동일 시야에 배치했다. 적의 붉은 예고선 16개, 아군 명중 피해 숫자, 배치 예산 포화 후 자기 명중 슬롯을 확인했다. 별도 화면 비교 장면에서 Cinder Ring·Bomb Toss·Storm Arrow·Shield Verdict와 아군 명중을 겹쳤다. 이때 HeroVFX의 입자 요청 수는 74→18, 잔광 Beam은 48→24, 채움 조각은 160→127이었다. 판정용 고정 장면의 인스턴스 계수이며 실제 기기의 프레임 시간은 별도 측정 대상이다.
- 다음 담당은 전투 QA·아트다. 실제 4인 연결에서 적 예고 인지와 명중 타이밍을 확인하고 저사양 터치 기기에서 프레임 시간을 측정한다. 게시 테스트 클라이언트, 실기기, 사용자 미술 수용은 미검증이다. Roblox 게시와 릴리스 태그는 없다.
