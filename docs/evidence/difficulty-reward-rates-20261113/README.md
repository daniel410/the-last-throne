# 난이도별 보상 수치 적용

2026-11-13 · TLT-027/028/041/050/084 · ENG/PLAN → QA. 소스 구현·순수 Lua 검증 완료, Studio/게시 수용 대기. 상위 티켓 완료 처리 없음.

## 확정 수치와 적용 범위

최신 사용자 지시를 적용한다. Hell Diamonds는 중간19에서 최종10으로 정정됐다.

| 모드 | 최초 Diamonds | Gold 모드 배율 | XP 모드 배율 |
| --- | --- | --- | --- |
| Easy | 3 | 1 | 1 |
| Hard | 5 | 1.5 | 1.5 |
| Insane | 7 | 2 | 2 |
| Hell | 10 | 3 | 3 |

Diamonds는 영웅·본편ID·난이도별 최초1회다. 35본편 전체는105/175/245/350, 합계875개/영웅이며4영웅은3,500개다. 기존 수령 영수증·보유/사용 잔액을 보존하고 차액 소급은 하지 않는다. 이미 완료했으나 수령 영수증이 없는 권리는 기존 복구 경로에서 새 금액으로 지급된다. 사이드/반복 추가 Diamonds는0이다. Easy 미완료 Hard 최초 지급과 이후 Easy의 별도 권리도 유지한다.

Gold 배율은 기존1/2/3/5에서1/1.5/2/3으로 변경한다. XP는 이미1/1.5/2/3이므로 그대로다. 처치·반복 완주 계산에 적용하며, 보상 레벨 구간/내림·반복 완주 Gold20% 감액·임무 초회 고정 XP/Gold는 유지한다. 따라서 최종 Gold가 같은 임무 Easy의 정확히1.5/2/3배가 되는 것은 아니다. 재료·장비·적 능력치·입장 조건·TD 코드는 변경하지 않는다.

EconomyCatalog8의 모드별 표를 서버 지급과 원정 미리보기·퀘스트/로비 영어 안내에 연결했다. 새 원정은 Difficulty 규칙15를 고정하며, 저장된1~14의 Gold/XP/전투 규칙은 보존한다. 게임 VERSION은 빌드하지 않았으므로 변경하지 않았다.
