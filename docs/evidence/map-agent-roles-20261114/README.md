# 맵 전문 에이전트 역할 추가 검증

작업: TLT-100/map-agent-roles · 문서 범위 완료 · 2026-11-14

## 변경과 근거

사용자 요청에 따라 맵 구현·환경 아트·환경 3D 모델링 역할을 추가했다. 첫 목표는 에픽별 줄거리·스토리·특성을 반영한 지형과 소품 개선이다. [역할/공통 수용 기준](../../../agent.md#맵-제작-호출과-공통-수용-기준)과 [제작 스킬](../../../skills/the-last-throne-production/SKILL.md)에 호출·역할 경계·스토리별 제작표·전후 비교·플레이 검증을 연결했다. 기존 역할을 보존하며 범용 디자인/3D와 환경 제작의 담당 범위를 구분했다.

변경 범위는 `agent.md`, 신규 역할 지침3개, 제작 스킬, 해당 백로그의 증거 링크와 이 기록이다. 게임 소스·자산·빌드 버전은 이 작업에서 변경하지 않았다. 역할 파일 경로로 호출하는 저장소 운영 방식이며, 자동 발견 설정이나 상시 실행 에이전트를 설치한 것은 아니다.

## 검증 조건과 결과

- 역할 지침3개가 역할표에 등록되고 제작 스킬에서 연결됨: 확인.
- 역할표·제작 스킬·신규 지침의 로컬 링크57개: 경로 존재 확인 통과.
- 첫 목표·서사 원천/배치 근거·역할별 단일 편집 담당·서버 진행 계약·도보 연결·Blender Standard·공유 원본/LFS·단계별 검증 구분: 문서 검토 확인.
- `git diff --check` 및 작업 파일의 `git diff --cached --check`: 통과.

## 미검증과 다음 담당

실제 맵 제작·에이전트 실행·Studio·게시 클라이언트·실기기 성능·사용자 미술 수용은 미수행이다. 상위 TLT-100이나 지역 구현 티켓을 완료 처리하지 않는다. 다음 담당은 디렉터/맵 구현이며, 대상 에픽·스토리와 지역 부모 작업ID를 정하고 세 역할의 소유 파일을 나눠 대표 구간 지형·소품 개선을 수행한다.
