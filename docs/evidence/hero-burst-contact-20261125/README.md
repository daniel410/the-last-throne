# 네 영웅의 방출과 명중 구분

2026-11-25 · TLT-033/057/059 · 기준 0.115.109 · 후보 0.115.113

| 영웅 | 기술 | 동작과 효과 |
| --- | --- | --- |
| Knight | Dawn Burst | 방패 안에서 힘을 모으고 검을 내리며 앞발을 디딘다. 낮은 금빛이 중심에서 퍼지고 사거리 경계는 기존 경로로 그린다. 보호막은 서버가 확인한 수혜자에게 붙는다. |
| Dwarf | Shell Burst | 왼손 포구를 들어 올리고 뒷발로 반동을 받은 뒤 포구를 낮춘다. 한 발의 금속탄이 좌표에 닿으면 불기둥과 지면 충격 두 줄이 열린다. 파편은 시전자 화면에 표시한다. |
| Elf | Bloom Shot | 시위를 놓은 오른팔을 어깨 위에서 열고 활은 조준을 유지한다. 잔상 하나가 승인된 끝점으로 이어진다. 시전자가 부여한 Nature 표식이 실제 소비되면 피격 위치에서 잎 다섯 장이 벌어진다. 아군은 한 장과 표식 두 획을 본다. |
| Mage | Ice Shard | 지팡이 옆에서 빙편을 모아 빈손으로 낮게 던진다. 짧고 넓은 단일 빙편이 손에서 서버 확정 끝점으로 이어진다. 근접 엄폐에서 손이 끝점보다 앞서면 궤적을 시전자 쪽으로 당긴다. |

외곽선과 피해 숫자는 기존 표시 경로를 사용한다. 피해·범위·시전/적중 시간·보호와 표식 처리는 서버에서 계산한다. [공식 비교 자료](../../research/2026-11-25-hero-burst-contact.md)

## 검증

- Rojo 7.7.1 단일 Place의 SHA-256과 관련 클라이언트 모듈 여섯 개가 각 고정 Git 소스와 일치했다. [기준 빌드](../epic-fourth-chapter-maintenance-profiles-20261125/build.json) · [후보 빌드](build.json) · [패키지 대조](package-check.json)
- 동일 조명과 카메라의 R15 비교 장면에서 준비, 방출 뒤 41ms와 98ms의 전후 화면 24장을 확인했다. Bloom Shot은 41ms 장면에 일반 명중, 98ms 장면에 시전자의 Nature 소모를 넣었다. 비교 각도에서 Shell Burst 불기둥의 측면이 드러나며 중심 일부는 표적 몸에 가려진다. [전후 화면](comparison.jpg)
- 0.115.110 비교에서 빙편 폭·길이 비율과 Bloom Shot의 꽃잎 수에 기존 아트 기준을 적용했다. 0.115.111과 0.115.112의 Shell Burst에서 불기둥이 표적 몸에 가리는 각도를 확인했다. 0.115.113은 착탄점을 불기둥의 시작에 두고 끝이 화면에서 표적 옆으로 펼쳐지게 했다.
- 집중 56건 통과. 기준은 실행된 집중 검사 52건 중 38건에서 개선 조건을 충족하지 못했다. 검사 수는 효과가 그려진 경우의 움직임 확인에 따라 달라진다. 같은 네 방출의 Beam은 시전자 화면 99→11, 아군 화면 84→9, 표면 인스턴스는 96→18 / 96→16이었다. 시전자 입자 요청은 36→0, 보조광은 15→0이었다. 이 수치는 명중 효과를 제외한 격리된 방출 장면에서 계측했다.
