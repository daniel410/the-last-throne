# 네 영웅의 공격 자세와 겹치는 명중 전후 검증

TLT-033/057/059 · 2026-11-21 (EST) · 기준 0.115.40 · 후보 0.115.43

[공식 사례 조사](../../research/2026-11-21-hero-contact-weight.md) · [고정 빌드](build.json) · [Studio 결과](studio-results.json)

| 기술 | 공격 자세 | 확정 명중 |
| --- | --- | --- |
| Knight · Oathbreaker Strike | 검을 올릴 때 몸통을 감고 내리찍은 뒤 앞무릎으로 하중을 받는다. | 황금빛 두 획이 아래로 갈라지며 적의 몸이 짧게 내려앉는다. |
| Dwarf · Piercing Round | 오른손 도끼를 든 채 왼손 총을 쏘고 무릎과 몸통으로 반동을 받는다. | 짧고 폭이 좁은 두 줄이 진행 방향으로 스친다. 표적이 같은 축으로 짧게 젖혀진다. |
| Elf · Elemental Pierce | 시위를 당길 때 활을 비스듬히 눕혀 일반 관통 사격과 다른 실루엣을 만든다. | 두 녹색 획이 명중점을 교차하며 사선 너머로 이어진다. |
| Mage · Glacial Spike | 지팡이를 내린 상태에서 효과를 모으고 발사할 때 유도 팔을 위로 편다. | 얼음 획이 명중점에서 위로 갈라진다. 시전자 화면에 짧게 커졌다 사라지는 얼음 면을 더했다. |

같은 적에 비슷한 타격이 연이어 들어오면 첫 피격 자세가 최고점에 도달하고 20ms가 지날 때까지 유지한다. 이 구간에도 변위 기준으로 15% 넘게 강한 타격이 도착하면 현재 자세에서 먼저 전환한다. 각 타격의 명중 이펙트와 피해 숫자는 별도로 재생한다. 적 준비·공격 중과 보스에는 기존 피격 자세 감쇠를 적용한다. 피해, 발사 시각, 기술 범위, 물리 루트와 서버 상태는 기존 전투 계약을 따른다.

## 전후 장면과 재현

- 격리 Studio에서 같은 R15 리그, 무기, 조명과 카메라를 사용했다. Oathbreaker Strike 적중 55ms 뒤, Piercing Round 발사 45ms 뒤, Elemental Pierce 준비 55% 시점, Glacial Spike 시전 62ms 뒤를 고정했다. [공격 자세 전후](hero-contact-weight-poses.jpg)
- 같은 고정 표적, 피해 42 및 진행 방향으로 `K0HitEffects.show`를 실행해 적중 35ms 뒤를 비교했다. 표적과 겹치는 면에서 각 방향의 획을 확인했다. [명중 효과 전후](hero-contact-weight-contacts.jpg)
- `run-in-roblox --place builds/0.115.43/TheLastThrone-0.115.43.rbxlx --script tests/hero-contact-weight-native.luau`로 비슷한 강도의 후속타, 강타의 조기 전환, 회복 이후 보간, 본인·아군 Beam 상한, 피해 표시와 리그 관절을 재현한다. [재현 소스](../../../tests/hero-contact-weight-native.luau)

새 검사 53건에서 기준은 43건에 실패했고 최종 후보는 전부 통과했다. 최종 후보의 Studio 15묶음 257,294건에는 128개 스킬의 자세·명중, 무기 소켓, 엘프 지연 발사, 피격 자세·피해 숫자와 파티 효과 우선순위가 포함된다. Gunner는 첫 두 시도에서 Shrapnel Toss의 비행 시각 검사에 실패했다. Run 모드 진입 뒤 750ms를 기다리고 재시험하니 기준과 후보 모두 180건을 통과했다.

CPU 전직·스킬 형상·취소 검사는 15,147건을 통과했다. 별도의 입력 취소 CPU 검사는 양쪽 모두 `TargetAssistRules`가 빠진 테스트 환경에서 중단됐다. 두 빌드의 SHA-256과 변경 클라이언트 모듈 네 개를 각각의 입력 커밋과 대조했다.

## 빌드 이력과 남은 수용

0.115.41 비교 화면에서 Glacial Spike의 얼음 질감이 가는 획에 묻혔다. 후속 빌드는 시전자 효과에 기존 표면 예산을 사용하는 얼음 면을 추가했다. 0.115.42 빌드는 디스크 공간 부족으로 중단됐고 재생성 가능한 자동화의 임시 빌드 입력 폴더를 정리한 뒤 0.115.43을 만들었다. [중단 기록](failed-build.json)

후보는 미게시다. 전투 QA는 게시 테스트 실제 4인 교전에서 같은 적에 몰리는 타격과 적의 위험 예고를 판독하고 저사양 터치 실기기의 연속 교전 프레임 시간 및 사용자 타격감을 확인한다. 이 수용 항목은 미검증이다.
