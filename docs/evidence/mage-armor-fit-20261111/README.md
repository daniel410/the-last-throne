# 마법사 로브/모자·투구 눈높이 보정

2026-11-11 · TLT-028/032/057/084 · ART·ENG · 고정 빌드 검증 진행 중.

사용자 측면/정면 스크린샷에서 로브의 납작한 몸통, 떠 있는 Mage Hat, Knight/Dwarf 투구의 눈 가림을 확인했다. 전 작업은 정면/관절/소유 장비 연결 위주의 검증으로 이 미술 결함을 놓쳤다. 이번에는 측면 볼륨과 얼굴 눈 영역을 별도로 검증한다.

## 원본과 변경

TD 현재 프로젝트가 마운트하는 `blender-mcp-rapid-v2/runtime.rbxmx`의 Arcanist Body 비율(깊이/폭 약0.687)과 TD Arcanist v10 실제 Blender 모델/렌더를 읽기 전용으로 참조했다. v10의 몸통 깊이0.58·머리 깊이0.64, 챙 높이2.71~2.79·머리 상단2.78에서 몸통 볼륨과 머리에 겹쳐 앉는 챙을 확인했다. 현재 마운트 모델과 v10 편집 원본을 같은 파일로 주장하지 않는다. [정확한 경로·커밋·해시·치수](td-reference.json). TD 운영 파일은 수정하지 않았다.

- 로브4종은 앞뒤 축1.85배. 부품 크기뿐 아니라 소켓 상대 위치도 같은 비율로 변환해 몸통·허리·치맛자락·소매의 볼륨과 연결을 유지한다. 기존 전체 로브 깊이/폭0.325에서 약0.602로 보정한다.
- Mage Hat4종은 머리 비율에 맞춰0.25stud 내리고 원래 Hair 액세서리를 유지한다. 원래 Hat은 중복 방지를 위해 계속 숨기며 해제 시 원래 투명도를 복원한다.
- Knight/Dwarf 헬멧4종은 머리 비율에 맞춰0.32stud 올려 이마 장식 아래에 눈 영역을 확보한다. 후드와 다른 부위의 크기/위치는 유지한다.
- 착용 보정 버전을2로 올려 이전 버전의 착용 복제본이 재사용되지 않게 한다. 원본/준비본/런타임 템플릿·Roblox 자산 ID·MP/방어력·소유권·무기/방패는 유지한다. 신규 업로드가 필요 없는 착용 변환이다.

## 검증 범위

`armor-fit-native.luau`는 R6/R15의4계열에서 실제 EditableMesh 삼각형과 양쪽 눈 영역18개 광선을 대조한다. 기존 위치의 눈 가림 재현과 보정 후 가림0을 비교하며, Dwarf 선택·로브 깊이의 신체 대비 여유·머리 크기에 따른 모자 하강/챙 접합을 검사한다. 기존 방어구 전체 회귀는 장착/교체/해제·머리카락 보존과 원래 투명도 복원을 함께 확인한다.

Studio의 별도 미리보기 모델에서 정면·측면을 확인한다. 실제 사용자 Play 세션이나 계정 프로필은 수정하지 않는다. 게시 클라이언트·실기기·모든 UGC 얼굴/머리카락·최종 사용자 미술 수용은 후속이다. 다음 담당은 QA/사용자 미술 수용이다.

마법사/투구 정면의 왼쪽부터 Sentinel·Veteran·Tempered·Traveler다. 편집용 격리 마네킹·보조광이며 실제 계정/게시 조명 검증과 구분한다.
