# NPC 관절·보행·소품 개선

2026-11-02 · TLT-031/057/061/084 · ART/ENG → QA · 로컬 구현, 미게시

Selene 제외29명의 기존 블록형 모델에 어깨·팔꿈치·손목·골반·무릎·발의 rest-space 그룹을 추가했다. 얼굴/머릿결/복장 색상과 NPC 안정ID·상점/퀘스트 판정은 보존한다. [조사/대안/근거](../../research/2026-11-02-npc-articulated-motion.md).

- 대기: 호흡·작은 팔 움직임·정면16stud 이내 플레이어를 향한 제한된 머리 회전. 인물별 위상을 달리한다.
- 이동: 서버 위치 사이 표시 보간·실제 표시 이동 거리 기반 교차 보행·2관절 다리 계산과 수평 발바닥. 순간이동은 달리기로 해석하지 않는다.
- 소품: 망치·책·열쇠·등불·지팡이·도구를 손 그룹에 부착한다. 책/지도는 팔꿈치를 굽히고 Nia는 왕관을 양손으로 받친다. 옷/가방/화살통은 몸통을 따른다.
- 로비·실제 배치·후속 지역 생성 모델에 전용 태그로 연결한다. Selene의 기존 TD 메시/치유 애니메이션 경로는 유지한다. 고정NPC의 이동AI는 추가하지 않는다.
- 100stud 밖/숨겨진 모델은 원형 자세로 복원하고 갱신을 멈춘다. 스트림 인·아웃/태그 제거 시 연결·정리한다. 추가 물리 파트·Humanoid·상품·게임 문자열·외부 업로드는 없다.

변경 범위: `NPCVisual`, `NPCArticulation`, `NPCMotion`, `NPCMotionPresentation`, 클라이언트 시작 연결 및 전용 엔진 검사/미리보기. 다른 진행 중 로비·원정 이동 변경은 포함하지 않는다. 기존 v4 머리/얼굴·메시 자산은 수정하지 않았다. Blender/FBX/R15 스키닝 리그나 새로운 얼굴 모델을 제작한 작업으로 보고하지 않는다.

검증 명령/결과·고정 소스·빌드 해시는 `build.json`과 로그에 기록한다. 초기 격리 검사에서29명183,944개를 통과했고, 실제 엔진 미리보기에서 발견한 왕관 부착을 보정했다. 왕관 추가 검사는 손 중심과 왕관 끝의 일치가 아닌 실제 손 너비 안의 접촉으로 바로잡았다. 중간 실패 로그도 보존한다. 최종 수치는 최종 로그를 기준으로 한다.

미검증: 게시 클라이언트의 실제 호위·경사 지면/문·실제 플레이어 입력에서 시선/개인 숨김·스트리밍 재진입·모바일 성능·4인+AI·최종 사용자 미술 수용. 평지2관절 발 보정은 경사 지형 레이캐스트IK가 아니다. 기존 TD자산 `203785492` 유형 경고는 범위 밖이다. 작업 중 열린 사용자 Battle Studio는 변경하지 않고 격리 runner 세션만 사용한다. QA/ART가 위 조건을 후속 수용하며 상위 티켓은 완료로 바꾸지 않는다. Roblox 게시·릴리스 태그는 수행하지 않는다.

최종 고정 빌드 검증: NPC29명183,948개, 전체30명 캐스트9,855개(Deepwood8배치), 중복 역할42개, 기존Selene317개, Lobby 시작156개, Battle 시작148개 통과. 기존 캐스트 검사의 Selene3메시 기대를 현재 정본6메시 파생본 비교로 수정했으며 제품 빌드 입력은 변경하지 않았다. [격리 엔진 자세 미리보기](walk-review.png)는 런타임과 동일한 자세 계산을 정적으로 샘플링한 것으로 실제 플레이 캡처와 구분한다. runner 세션은 모두 자동 종료됐고 기존 사용자 Battle Studio만 남은 것을 확인했다.
