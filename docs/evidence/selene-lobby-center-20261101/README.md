# 로비 Selene를 두 포탈 중앙으로 이전

2026-11-01 · TLT-016/031/061/084 · ENG/DES → QA · 0.58.16 로컬 시험판·미게시

사용자 요청에 따라 로비 Selene를 상대좌표(25,0,20)에서 두 포탈 좌표의 평균(-4,0,-30)으로 옮겼다. 두 포탈 사이 중앙이며 실제 월드 좌표는(-4,96,482)다. 포탈 위치가 바뀌면 같은 중간 지점 계산을 따른다. TD 원본 외형·Priestess 표기·동행/해금·F 대화 프롬프트는 유지한다. 원인이 명확한 배치 수정으로 기존 제작 스킬의 접근 수용 기준을 적용했다.

로컬0.58.15 Studio의 LobbyResidents만 이번 소스로 교체한 Play에서26개 검사 통과: 실제 새 위치·두 포탈 중간점·주민 중복 없음·기존 대화 F/거리10·중앙 접근 바닥/통행 raycast. 실제 화면에서도 두 포탈 사이 배치를 확인하고 촬영용 카메라/GUI는 원복했다. 재현은 verify.luau, 실제 도구 출력은 studio-result.json을 따른다. 고정 빌드 소스/해시는 build.json에 기록한다.

실제 대화 조작·실기기·게시·동행 회귀는 미검증이다. 다음 담당 QA는 로비 중앙에서 Selene F 대화와 기존 해금 상태를 확인한다. 다른 미커밋 작업은 포함하지 않는다.
