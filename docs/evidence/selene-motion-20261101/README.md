# Selene 자연스러운 동행과 치유 효과

2026-11-01 · TLT-016/057/061/072/084 · ART/ENG → QA · 로컬 개선본

사용자 요청으로 TD 성녀의 얼굴·복장·등불을 유지하면서 몸체를 머리·로브·양발로 나눈6메시 파생본을 적용했다. 원래 TD3메시 파일은 불변이다. 파생 자산ID·원본해시·교정행렬은 [segments.json](../../../assets/shared/td-selene-articulated/segments.json), 재생성 도구는 [build-selene-articulated.py](../../../tools/build-selene-articulated.py)다. [조사/적용 근거](../../research/2026-11-01-selene-follow-and-healing.md).

전투의 느린 상태 갱신(0.2초)과 이동 Heartbeat를 분리해 위치가 덩어리로 뛰는 현상을 줄였다. 서버는 지면 높이·가감속·완만한 회전·정지/재출발 간격·이동 방향에 따른 후방 대형을 계산한다. 제자리 방향 전환으로 동료가 주위를 도는 현상을 줄인다. 위험/시전 중 이동을 먼저 멈추고, 벽/낙차/오래된 웨이포인트를 통과하지 않게 한다. 클라이언트는 매 프레임 위치를 보간하고 어깨 회전·교차 보행·발 들기·호흡·머리·시전 자세를 표시한다. **무릎·발목까지 스키닝한 전신 R15 리그는 아니다.**

서버가 성공한 지원에 수혜자·종류·실제 회복량·시각을 붙여 전송한다. 치유는 손 초점·연결 광선·초록빛 입자·발밑 원·`+N HP`, 보호는 금빛 보호막/`PROTECTED`, 정화는 푸른 입자/`CLEANSED`로 구분한다. 클라이언트는 HP를 지급하지 않는다. 늦게 스트리밍된 과거 이벤트를 재생하지 않고 반복 이벤트도 중복 생성하지 않는다. 12초 쿨다운/기존 회복량과4인+AI1·무료 해금·편성 저장 계약은 유지한다.

[보행 자세](walk.png) · [치유 연출](healing.png)는 연결된 RPG Battle Studio의 **Edit 모드 격리 미리보기**다. 단순 수혜자 테스트 리그를 사용했으며 실제 플레이 캡처나 실계정 HP 변경 증거로 해석하지 않는다. 보행/치유 코드의 동일 수학·실제 MeshPart와 Beam을 사용했다. 새 파생 메시/텍스처는 로컬 엔진 Preload 성공을 확인한다.

검증 결과와 고정 빌드 정보는 `results.json`/`build.json`에 기록한다. 초기 벽 검사에서 Spherecast가 시작 중첩을 검출하지 않는 경우가 나타나 도착 부피 검사도 추가했다. 미리보기에서 모델 피벗에 따른 방향 반전도 발견해 `WorldPivot`을 명시하고 방향 회귀 검사를 추가했다. 실패한 중간 로그도 보존한다.

미검증: 게시된 클라이언트의 새 자산 권한, 실제 입력을 사용한 장시간 전투/복잡한 모든 경사·다리·문, 모바일 성능/네트워크·4인+AI, 사용자 최종 미술 수용. 기존 `203785492` 자산 유형 경고는 이번 범위 밖이며 로그에 남긴다. Roblox 게시/릴리스 태그는 수행하지 않는다. 다음 담당 QA/ART는 실제 게임 플레이의 발 미끄러짐·분할 경계·추종 지연·치유 가독성을 수용한다.
