## 검증 실행

- 커밋 대상 소스의 Lua/Luau 파일 538개가 `luau-compile --null`을 통과했다. 로비와 전투 Rojo 프로젝트에서 소스맵을 생성했다.
- 핵심 Lua 회귀 검사는 `tests/hero-vitals-service.spec.lua`, `last-selected-hero.spec.lua`, `equipment-lobby-refresh.spec.lua`, `expedition-store.spec.lua`, `expedition-backend.spec.lua`, `expedition-departure.spec.lua`, `expedition-outage.spec.lua`, `party-story.spec.lua`, `merchant-throttle.spec.lua`다. 저장소 루트에서 각 파일을 `lua tests/<파일명>`으로 실행했다.
- 커밋 대상 소스로 격리된 로컬 Place를 만들고 Studio 편집 모드에서 `tests/party-launch-native.luau`의 223개 검사, `tests/field-storage-quest-native.luau`의 창고·퀘스트 시나리오, `tests/support-pass-service-native.luau`의 18개 검사를 통과했다. 파티 검사는 실제 요청 처리기와 저장 모듈에 시험용 플레이어와 전송 어댑터를 연결했다.
- 작업 폴더에서 전체 Lua 검사 156개 중 116개, Python 검사 13개 중 12개가 통과했다. 실패한 41개는 수정 전에도 실패했다. 그중 전투 규칙 버전 기대값과 피격 표시 호출 위치를 확인하는 검사가 포함된다.
