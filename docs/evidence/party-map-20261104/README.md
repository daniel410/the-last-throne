# 파티원 전체 지도·미니맵 표시

2026-11-04 · TLT-028/031/050/057/061/084 · ENG/DES → QA · 0.73.0 구현, 게시/실기기 수용 전

사용자 지시로 같은 원정의 인간 파티원을 전체 지도와 미니맵에 표시한다. 내 기존 청록색 삼각형과 구분되는 초록색 번호 원을 쓰며, 전체 지도에는 DisplayName을 함께 표시한다. 미니맵은 번호만 표시한다. 쓰러진 동료는 주황색+로 나타내고, 지도/원형 미니맵 바깥의 동료는 가장자리에 방향 표시를 붙인다. 전체 지도는 `OUT OF VIEW`, 쓰러짐은 `DOWN`을 이름 옆에 표시한다. DisplayName은 사용자 생성 이름으로 게임 저작 문자열과 구별한다.

서버 `PartyMapRoster`가 검증된 영웅의 원정 runId·현재 모험 세션으로 자격을 정한다. 자기 자신·다른 원정·훈련·로비 인원은 제외하고 최대3명을 전달한다. 캐릭터 재생성 중에는 번호/신원만 유지하고 좌표를 생략한다. 원정ID·티켓·다른 영웅ID는 전송하지 않는다. 위치는 서버가 읽은 좌표/상태이며 클라이언트가 입력하는 위치 원격은 추가하지 않는다.

`DeepwoodPartyState`는0.5초마다 최대3개 표시 정보를 전달한다. 클라이언트는 영웅 일치·모험/훈련 상태를 다시 확인하고 마지막 수신 이후2초가 지나면 마커를 숨긴다. 새 스냅샷에서 빠진 사람/재생성 중인 사람은 해당 마커/이름을 제거한다. 현재 위치 전송은 별도 소형 메시지여서 전체 퀘스트/인벤토리 스냅샷 주기를 늘리지 않는다. 같은 서버의 모험 파티가 범위이며 서버를 떠난 동료의 다른 서버 위치를 추적하지 않는다. Selene AI 위치 표시는 이번 요청 범위에 포함하지 않았다.

기존 TD 프레임·지도 배치/내 위치·목표/적·체크포인트 아이콘은 유지한다. 새 의미 마커는 native 원·텍스트·윤곽선으로 그려 자산 생성/업로드를 추가하지 않는다. 두 지도는 같은 `PartyMapMarkers`/좌표 투영을 사용한다. 작은 미니맵에는 이름을 생략하며 원형 가장자리에 방향 화살표 공간을 확보한다. 기존 플레이어 UserId 순번으로 같은 스냅샷의 파티 번호를 일관되게 부여한다. [조사/적용 근거](../../research/2026-11-04-party-map.md).
