# 인물·단서·성과가 이어지는 스토리 개선

## 요청과 적용

사용자가 [스토리 재미 리서치](../../research/2026-11-08-story-fun-and-player-agency.md)에 대해 “개선해줘”라고 지시해 기존 확장에 인물의 변화·환경 단서·앞선 구조의 회수와 짧은 유머를 구현했다. **24개 사건의 대사/목표·8개 요청 설명·3개 사이드 결과**를 새로 연결했다. 기존82사건/246단계와 본편35장/사이드12개를 유지하며 새 필수 목표·보상·전투 수량을 추가하지 않는다.

## 기존 사이드의 작은 후일담

DW-Q2 식량 보고 뒤 Liora의 캠프 식사와 짧은 농담, FV-Q1 배지 보고 뒤 **Nell**의 이름/재회, EC-Q1 노동자 표식 보고 뒤 **Miner Jori**의 작업 복귀를 추가했다. Nell/Jori는 기존 NPC 시각을 재사용하는 소규모 서사 배우이며 플레이어 클래스/새 전투 동료가 아니다. 필드와 로비에서 개인의 확정 보고/기존 완료 권리로 보이며, 조사만 마친 상태에서는 나타나지 않는다. 선택 영웅 전환/스트리밍 재유입 때 같은 저널로 다시 표시한다.

Tessa의 기존 !/? 추천·발견/수락·대리 보고·보상/영수증 경로는 유지한다. 새 보고서/아이템/재화/무료 지원을 지급하지 않는다. 세 사이드와 기존 나머지 사이드 모두 본편의 필수 조건이 아니다.

## 진행·원본 보존과 함께 수정한 문제

- `CampaignStoryBeats`는 안정된 챕터/목표/세부 목표 ID에 영어 원문을 연결한다. 저장 스키마/원정 규칙13/구규칙1~12·기존 선택 ID/보상·처치·성장·장비·지원권은 유지한다. Cart Driver는 표시 역할명 보강이며 기존 활동 저장 키는 그대로다.
- 실물 조작부도 기존 단계 ID와 정답 ID를 사용한다. 실제 서버 바인딩→거리/영웅/선행 검사→기존 활동 저장 경로로 처리하며 대화 선택과 별도 보상을 만들지 않는다. 기존 중간 회로 저장을 이어할 수 있다.
- Deepwood의 지형 제작기는 보관된 원본 데이터를 사용하므로, 생성된 노드의 이야기 메타데이터를 현재 CampaignContent 정본으로 재연결했다. 현장/저널/Tessa의 새 결과와 확장 선행 조건이 일치하며, 원래 좌표·적·실제 지급은 바꾸지 않는다. 이 연결 없이 원래 목표가 확장 선행을 먼저 통과한 것처럼 노출될 수 있던 경로도 검사했다.
- 기본 순서의 마지막 행동에서 복구 결과가 너무 멀리 떨어지지 않게 배치했다. 전체82사건의 실제 결과 표식이 해당 마지막 목표에서40stud 이내임을 엔진에서 검사했다. 자유 순서 조사에서 어느 지점을 마지막으로 읽든 모두 같은 거리라는 뜻은 아니다.
- 자유 순서 조사에서 단서3만 모아도 단서1이 완료 색으로 칠해지던 문제를 수정했다. 실제 수집한 단서 키를 우선한다.
- NPC/기계 이동은 개인의 확정 저널을 시각적으로 표현한다. 공유 발판/충돌과 전투AI 상한은 유지한다. 마을 여행자의8초 도착 동작은 배경 연출이며 완료/보상/다음 이동을 기다리게 하는 타이머가 아니다. 새 강제 컷신·카메라 잠금·음성 녹음은 없다.

## 빌드·미검증·인계

새 기능으로 VERSION0.87.0→0.88.0을 올리고 소스 커밋을 먼저 푸시해 고정한 뒤 단일 파일을 만든다. [build.json](build.json)에 실제 소스·산출물 해시/성공을 기록한다. 조회 시 연결된 사용자 Studio가0개여서 사용자 Place 적용은 하지 않았다. 격리 엔진 시험과 사용자의 Studio 적용을 구분하며 Roblox 게시/live DataStore/릴리스 태그는 변경하지 않는다.

실계정 저장/서버 이동·실제 키보드/터치/패드 조작·일반1~4인+AI·저사양 성능·스크린샷/최종 미술·사용자의 이해/인물 기억/재미·실제 플레이 시간은 미검증이다. 리서치의 큰 진행 분기/대규모 동맹AI를 제작한 것으로 보고하지 않는다. 다음 QA는 DW02 치료→운전사, GW02/06→HG04 등불 회수, FV04 경보 관찰, EC05 현장 선택, 세 사이드 보고/영웅 전환을 실제 플레이에서 확인한다. 부모 티켓은 미완료다.
