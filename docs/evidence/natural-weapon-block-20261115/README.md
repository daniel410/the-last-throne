# 엘프·드워프·마법사 양손 방어 자세

2026-11-15 · TLT-005/032/033/084 · ENG/ART/RES → QA · 격리 Studio 후보 통과, 미게시

## 변경·근거

[사용자 결정](../../decisions/2026-11-15.md#엘프드워프마법사-방어-자세)과 [공식 자료·제작 선택](../../research/2026-11-15-natural-weapon-block.md)에 따라 세 클래스의 공통112도 팔 들기를 무기별 양손 지지 자세로 교체했다. 이전의 보조 어깨 누적 회전/이동 추적은 제거한다. 무기는 턱 아래 상체 전방에 두고 도끼 약5.7도·활6.8도·지팡이10.2도의 완만한 가로 기울기와1.2stud 지지 접점을 사용한다. 엘프는 왼손으로 활을 쥐고 오른손으로 받치며, 드워프·마법사는 기존 오른손 소유와 왼손 지지를 유지한다.

`K0BlockMotion`은 실제 C0/C1 관절 길이로 R15 양팔의 두 마디 풀이와 중립 손목을 계산한다. R6는 두 강체 팔의 도달 구면 교점으로 양손 위치를 정한다. 팔 관절 이동/길이 늘이기·손목 꺾임 없이 실제 손바닥을 손잡이에 맞추고 주손의 기존 무기 소켓을 보존한다. 무기/팔은 현재 자세에서0.18초 곡선으로 진입/해제하며, 보조 접점은 해제·무기 교체·클래스 변경·회피·사망 시 제거한다. 엘프는 방어와 해제 전환 중 화살을 숨겨 손·시위와 겹치지 않게 한다.

Config·CombatService·WeaponAppearance 원문은 기준 커밋 `eda125e7b447502422a5b552df8d666fa2e280dc`와 동일하다. 서버 방어 활성/완벽 방어/피해/방향 판정·이동 속도·공격/기술·기존 소유 손/C0/C1·물리 루트는 유지한다. 기사 Block과 이전 기사3연타 변경을 보존한다. TD·Blender·원본 자산을 변경하지 않는다.

## 후보·실제 엔진 검증

PlaceId=0·플레이어0인 로컬0.110.14 호스트에 후보2모듈만 주입했다. [후보 로그](candidate-native.log)·[입력 해시](candidate-inputs.json).

- 양손 방어 실제 관절 FK23,312검사: R6/R15×3클래스×30/144Hz,0.06/0.12/0.18/0.24/0.5/2초 전환,20초 유지·35도 회전, 입력 해제/재진입·회피·사망·무기 교체·클래스 전환·죽음 낙하의 접점 정리를 통과했다. 손 접점<0.1stud·손 간격≥1stud·팔다리 Transform 이동0·손목 중립·팔꿈치 굽힘135도미만·양손바닥의 머리/몸통 내부 비침투와 grip→보조 접점 손잡이 구간의 머리 비침투·소켓/루트 불변을 검사했다. 전투 이력이 없는3클래스 기본공격과 기사 Block의248샘플은 기준과 위치/방향 basis 차이0이다.
- 격리 호스트의 실행 Script/LocalScript4개만 비활성화한 뒤 Run/실제 PreSimulation에서6리그의 유지·45도 회전·해제를 검사했다. 수학 FK 결과를 실제 부품에 되먹이지 않았다. 실제 손바닥 CFrame→접점 오차 최대0.00003350stud, 소켓 거리0·팔다리 이동0·루트 불변·엘프 화살/당김 IK/해제 정리를 포함한906검사를 통과했다. 플레이어 입력이나 서버 복제/실기기를 실행했다고 세지 않는다.

합계131,473검사 통과. CFrame 상대 역행렬의 `ToAxisAngle`은 동일 행렬에도 최대0.0009765625rad를 반환해, 비Block 불변 검사는 원래 허용값을 유지하면서 Right/Up/Look 원본 basis와 위치를 직접 비교한다. [진단 로그](candidate-native.log)의 `nonBlockErrors`에서 실제 위치/basis 차이는0이다. 실패를 숨기기 위해 허용값을 늘리지 않았다.

기존 `tests/k0-block-guard-native.luau`의 완전 수평/손 중심 조건은 이전 연출에 대한 기록으로 보존한다. 이번 변경은 무기별 완만한 기울기·손바닥 접점·팔꿈치/손목·머리/몸통 여유·정리/전환/실제 엔진을 검사하는 독립 테스트로 수용했다.

## 시각 비교

실제 R15·승인 원본 무기·Traveler 방어구를 사용한 정지 FK 비교다. [Elf](elf-before-after.png)·[Dwarf](dwarf-before-after.png)·[Mage](mage-before-after.png)는 왼쪽부터 **Before Front / Before Side / After Front / After Side**다. [입력·자세·이미지 해시](capture-r15.json). 기존 얼굴 앞의 지나친 팔 들기보다 낮은 양손 지지와 굽힌 팔꿈치/중립 손목을 확인했다. 정지사진은 실시간 타이밍·사용자 미술 수용을 대신하지 않는다. 캡처용 호스트의 Traveler Coat 텍스처 로드 경고가 있는 경우 갑옷 표면 수용과 구분한다. R6 갑옷 외형·비기본 체형의 미술 수용은 남겨 둔다.
