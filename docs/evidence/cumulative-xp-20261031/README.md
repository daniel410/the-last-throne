# 영웅 누적 XP 표시

2026-10-31 · TLT-015/028/052/084 부분 수정 · ENG → QA

사용자 요청: XP가 레벨업마다 초기화되는 것처럼 보이므로 총경험치를 표시한다.

영웅 창과 전투 HUD를 모두 `TOTAL XP 현재누적 / 다음레벨누적`으로 변경했다. Lv1 99/100 → Lv2 100/225, 여러 레벨을 오른 뒤240/375처럼 표시한다. Lv80은84925 (MAX)다. 기존 레벨별 잔여XP 저장값과 현재 레벨의 누적 시작 임계값을 더해 계산하므로 저장 스키마/기존 계정 이관 없이 적용된다. 최대 레벨 도달 후 XP 초과분을 버리는 기존 성장 계약과 승인 보상·레벨 곡선·포인트 지급은 변경하지 않았다.

영문 문구는 K0Text의 TotalXP/TotalXPMax/LevelXP 키로 관리한다. UI 위치·크기·글꼴은 유지했다. 기존 다른 모션 작업의 미커밋 파일은 변경/검증 입력/커밋에서 제외했다.

## 검증

- `lua tests/hero-progression.spec.lua`: **656개 통과**. Lv1~80 전체 경계에서 누적XP가 감소/초기화되지 않음, 다음 누적 목표, 다중 레벨 보상과 불명 저장 재시도의 중복 방지.
- `lua tests/advanced-skills.spec.lua`: **1,435개 통과**. 성장·학습·슬롯·궁극기 회귀.
- `tests/k0-resource-ui-native.luau`: **4,804개 통과**. 실제 영웅 창과 HUD 생성자로0/99/100/240/84925 누적 표시 일치, HUD 텍스트 실측 폭220px 이내, 기존 상태·자원·모바일 배치 회귀. [원시 로그](native.log).

명령: `run-in-roblox --place builds/0.41.1/TheLastThrone-Battle-0.41.1.rbxlx --script /private/tmp/tlt-cumulative-xp-native.luau`

기존0.41.1의 별도 로컬 Studio 엔진 세션에 이번4개 게임 소스와 직전 승인된 HeroSkillTree를 주입했다. [수정 소스 해시](sources.json). 기존203785492 자산 유형 경고는 검사를 차단하지 않았다. 새 빌드/버전/게시/릴리스 태그는 생성하지 않았다.

실제 게시 클라이언트·기기 화면·저장 계정 재접속 수용은 미검증이다. 다음 QA는 실제 영웅의 레벨업 전후 두 화면의 총XP 증가와 다음 목표 갱신을 확인한다. 상위 티켓은 미완료로 유지한다.
