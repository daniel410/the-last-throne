# 로비 카메라 거리 조정

- 작업: TLT-005 후속 / ENG / 소스 수정·Studio 후보 확인, 게시·실기기 수용 대기.
- 근거: 2026-11-14 사용자 화면에서 PLAY 버튼이 영웅 몸통을 가림. 승인 HUD 배치는 유지하고 카메라 거리만 조정한다. 명확한 가독성 결함 수정으로 별도 게임성 조사는 생략했다.
- 변경: `src/client/AdventureCamera.luau`의 로비 최소 줌을 24 studs로 지정한다. 기존 기본 시점 약 12.5 studs보다 멀어지며 24~32 범위의 회전·줌을 유지한다. Lobby 외 상태는 최소6/최대32를 유지한다. 기존 캐릭터 생성·상태 전환·줌 속성 변경 콜백이 같은 규칙을 재적용한다.
- 비교: 연결된 TD 8.10.0 클라이언트에서 현재 거리36, 최소12/최대48, FOV68을 읽기 전용 확인했다. TD는 수정하지 않았다. RPG FOV70과 HUD 원본은 유지한다.
- Studio: 실행 중인 `TheLastThrone-0.107.3.rbxlx` 로비에서 24 studs 후보 시점을 확인했다. `lobby-camera-24` 화면 캡처에서 전신이 PLAY 버튼 위에 보였다. 이는 기존 실행 세션의 시점 후보이며 새 빌드 전체 검증을 뜻하지 않는다.
- 소스 엔진 확인: 수정본을 임시 ModuleScript로 로드해 Lobby=24, Tutorial/Respawning/nil=6, Lobby/Tutorial 최대32의6개 조건을 통과했다. 임시 모듈은 제거했다.
- 미검증: 새 소스의 시작부터 재접속·영웅 교체·상태 전환 전체 흐름, 다른 창 크기·카메라 각도, 모바일/실기기, 게시 클라이언트. 모든 시야에서 HUD 비겹침을 보장하는 자동 프레이밍은 이번 범위에 포함하지 않는다.
- 빌드·게시: 실행하지 않았다. VERSION·릴리스 태그 변경 없음.
- 다음 담당: QA가 새 빌드에서 로비 진입·영웅 교체·전투 왕복과 데스크톱/모바일 가로 시야를 확인하고 사용자가 거리감을 수용한다.
