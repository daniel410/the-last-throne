# 엘프 이동 시 표적 해제

작업: TLT-005/006/032/033 · 2026-11-03 · ENG → QA. 사용자 요청의 소스 수정이며 상위 티켓 수용 완료는 아니다.

엘프가 화살을 발사하면서 이동할 때 선택 타겟을 계속 유지하던 클라이언트 경로를 수정했다. `BattleController`에서 Humanoid의 MoveDirection 크기가 0.01을 넘으면 기존 clearTarget 경로로 표적·노란 Highlight·대상 이벤트 연결을 정리하고 기존 영어 TargetCleared 피드백을 한 번 표시한다. 키보드/패드/터치의 공통 이동 의도를 사용한다. 이동 중 선택 직후와 공격 요청 직전에도 같은 조건을 검사해 연속 공격 요청이 이전 표적을 다시 참조하거나 표적 방향으로 회전하지 않게 한다. 캐릭터 연결은 기존 생명주기 정리 경로에 등록한다.

다른 클래스의 이동 시 선택 유지, 서버의 발사/피해 검증, 이미 발사된 화살의 판정은 기존 동작을 따른다. 표적 해제 후 공격 입력은 기존 전방 조준으로 처리한다. 기존 표적 처리의 누락 조건을 보완하는 결함 수정으로 제작 스킬의 별도 리서치 예외를 적용했다.

변경 파일: `src/client/BattleController.luau`, `tests/elf-movement-target.spec.lua`, 결정표와 본 기록. 기존 미커밋 전투 모션·회피·로비·원정 변경은 포함하지 않는다.
