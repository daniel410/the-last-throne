# 실제 월드 도면 기반 상세 지도·미니맵 개선

2026-11-07 · TLT-028/031/050/057/061~065/084 · ENG/DES → QA · 0.83.1 · 미게시

사용자 지시: 상세 지도와 미니맵이 실제 맵의 특징을 더 충분히 나타내도록 개선한다. [프로젝트 제작 스킬](../../../skills/the-last-throne-production/SKILL.md)을 적용했고 [공식 사례 조사와 설계 판단](../../research/2026-11-07-map-cartography.md)을 연결했다.

## 변경과 원천

기존 지도는 거의 모든 지역에 같은 숲 타원·나무 배열·직선 길을 반복했다. Frozen Vale/Ember Caldera 외의 지역 차이가 약했고, compact 모드에서 랜드마크를 생략했다. 체크포인트는 실제 스폰 위치와 다른 공통 비율을 사용했다. 로비 지도는 구 캠페인 순서도 별도로 보유했다.

- 실제 `CampaignWorld.create()`로 생성한 **44개 지역**을 오프라인에서 북쪽 위 방향으로 수직 투영했다. 실제 숲·바위/고지·건축물·물/냉각 수로·용암의 큰 형태를40×40격자로 분류하고 같은 종류를 병합했다. 최종 **2,077개 지형 사각형**, 실제 `WornCurvedRoute`/`ReturnLoop`의 **2,745개 도로 선분**을 공통 도면에 저장한다. 세부 분포와 추출 데이터 해시는 [survey.json](survey.json)에 있다. 런타임 월드 복제·주기적 지형 스캔·외부 이미지 업로드를 추가하지 않는다.
- 상세 지도·로비 지도·미니맵이 `CampaignCartography`를 공유한다. 설원·화산·어두운 숲·왕릉의 지도 팔레트와 실제 건축/식생 배치를 구분한다. 격자 도로 그림 대신 실제 곡선 도로의 끝점과 폭을 투영한다. 연결로는 `CampaignBounds.ends`의 출입구를 연결하며, Experience 이동에 해당하는 에픽 간 연결을 지면 도로처럼 그리지 않는다.
- 실제 월드 `Landmark` 속성의 이름을 큰 지도/선택 설명에 넣고, 체크포인트를 실제 SpawnLocation에 맞춘다. 체크포인트 발견 판정도 그 좌표의 기존12×12탐험 칸을 사용한다. 작은 화면/FIT에서는 이름의 중첩을 줄이고 선택 설명을 유지한다.
- 미니맵도 건축물과 곡선 길을 유지한다. 원형 경계에는 사각형과 도로를 명시적으로 잘라낸다. 플레이어/적 표식은 공통 지도 투영과 실제 내부 여백 크기에서 변환하며 목표가 범위를 벗어나면 가장자리에 표시한다. 지역 사이 연결로에서 훈련장 지도로 바뀌지 않도록 이전 지역의 도면을 유지한다. 도로 길이를 Scale 좌표로 계산해 HUD UIScale에 두 번 축소되지 않게 하며, 미니맵 정리 후 지연된 메뉴 배치 콜백은 중단한다.
- 로비 에픽 목록은 `CampaignContent.epics`를 사용해 Deepwood → Gloamwood → Frozen Vale → Ember Caldera → Haunted Graveyard 순서를 따른다. 별도 구순서 표를 제거한다. TD 프레임/버튼/아이콘·개인 탐험/잠금·체크포인트 이동 자격·목표/파티/적 정보 계약은 기존 것을 사용한다.

rojo build default.project.json -o /tmp/tlt-cartography-bake.rbxlx

python3 tools/compile-cartography.py --log /tmp/tlt-cartography-bake.log

최초 추출 출력은 단일 로그 행의 크기 제한으로 잘렸고, 지역별 출력으로 바꿔44개 지역/완료 마커를 검사하도록 수정했다. 이후 수목 메시의 부모 이름과 고지/수면 분류를 보완해 최종 도면을 다시 추출했다. 각 지역의 모든 격자 칸을 덮는지 검사하며 누락된 추출로 생성하지 않는다. Studio의 기존203785492 asset-type 경고는 검사 결과에 영향이 없었다.

기존 순수 Lua `checkpoint-map-layout.spec.lua`는 최근 compact toolbar에 추가된 `epicPicker` 대역이 없어 실패했다. 이번 변경 이전부터 존재하는 시험 fixture 누락이며 해당 파일은 수정하지 않았다. 동일 화면의 실제 엔진 검사25개와 전체 지도416개는 통과했다. GUI 도구의 edit-time viewport 캡처는 CoreGui 지도 화면을 포함하지 않았으므로 사람의 시각 수용 증거로 사용하지 않는다.

## 한계와 다음 담당

정적40×40도면은 큰 지형의 안내용 요약이며 정밀 충돌/실시간 소품 상태/지하 구조를 표시하지 않는다. 월드 기하가 바뀌면 위 도구로 재생성한다. 임의로 랜드마크를 그려 넣거나 탐험 저장을 변경하지 않았다. 기존 월드 원본/진행·보상·전투 수치는 유지한다.

실제 기기 프레임 시간·게시 테스트 클라이언트·사람이 보는 지도 미술/가독성·4인 이동은 미검증이다. 실제 로비/배틀 Studio 장면에 일부 모듈을 혼합 적용하거나 Place 게시/릴리스 태그를 만들지 않았다. 다음 담당은 QA/사용자의 PC·모바일 가로에서 대표 다섯 지역 길찾기와 시각 수용이다. 부모 티켓은 In Progress 유지한다. 다른 작업 중 파일은 커밋 범위에서 제외한다.
