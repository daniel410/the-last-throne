# 로비 캡션 및 해상도별 아이콘 접합 교정

2026-11-03 · TLT-028/061/084 · ENG → QA · 0.67.7 로컬 수정·미게시

사용자 요청으로 왼쪽 아이콘만 POTIONS / DIAMONDS / REWARDS로 정정했다. 과거 PORTION / DIAMOND / REWORDS 지시보다 이번 정정이 우선한다. 상세창 제목/간판·TD 원본 이미지/자르기·셀 크기 공식·두 열 순서·기능은 유지한다. 기존 제작 스킬과 승인 공통 UI를 적용했으며 원인이 명확한 결함 교정이므로 별도 기능 사례 조사는 생략했다. TD 원본은 읽기만 했고 현재 로컬 원본 해시는 source-hashes.json에 남겼다.

기존 구현은 그림/이름판 각각의 Fit 여백 및 높이 제한과 셀 기준 텍스트 맞춤을 혼용했다. 짧은 화면에서 이름판 안의 실제 이미지 영역과 텍스트 영역이 달라지고, 그리드가 크기를 반영하기 전에 계산된 글자 크기가 남을 수 있었다. 이제 이름판은 셀 안의 실제 원본 비율로 맞추고, 남은 높이에 그림을 원본 비율로 맞춰 접합부를 겹친다. 텍스트 영역을 이름판과 일치시키고 실제 버튼 AbsoluteSize 변경 때 글자 크기도 다시 계산한다. 그림 전체를 같은 폭으로 축소하던 초기 후보는 모바일 DIAMONDS 최소 글씨 크기 검증에서 실패했으므로 채택하지 않았다. 최종본은 이름판 너비를 유지해 BLACKSMITH 최소8px·다른 이름 최소10px 검사도 보존한다.
