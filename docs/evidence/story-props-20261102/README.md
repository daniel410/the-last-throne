# TLT-031/057/061/062/063/084 · 스토리 소품 개선

2026-11-02 · ART/ENG · 로컬 구현, 미게시. 사용자: 막대·구체 중심의 스토리 물건을 의미 있고 더 실제 같은3D로 개선.

신규13종과 지역별 재료 색을 제작했다. 수레의 바퀴살/차축/파손 바퀴, 감옥의 창살/경첩/자물쇠, 장부의 책등/페이지/잉크/나침반, 윈치의 래칫/드럼/케이블, 냉각 밸브의 플랜지/압력계/핸드휠, 랜턴의 프레임/지붕/유리를 구분한다. Deepwood 조사·기구·수레·감옥·폐허 일부, Frozen Vale 경로 랜턴/조사 소품, Ember Caldera 냉각 장치/경로 랜턴에 연결했다. 보상·진행ID·프롬프트·전투 판정·기존 충돌체를 유지했다. 완료한 냉각 장치 핸들은 기존 개인 저장 상태에 따라 청록색이 된다.

Blender GLB13개는 동일 기하 원본의 검토/후속 병합 자산이고 현재 게임은 native multipart 모델을 사용한다. GLB 업로드나 새 원격 메시 의존은 없다. 실제 게임에 없는 추가 고해상도 모델을 게임 적용본으로 제시하지 않았다. 검토는 사용자의 열린 기존 Studio에서 격리된8종 갤러리로 수행하고 이후 리뷰 폴더/모델을 제거했다. 기존 게임 ModuleScript는 덮어쓰지 않았다.

검증: `python3 tools/author-story-props.py`, GLB별 native 부품 수/노드 수 일치, `tests/story-props-native.luau`11,456검사 통과. 전체3에픽351모델/9,306장식 부품, 위치·단계ID·장식 물리·원자적 스트리밍·중복 생성 방지·밸브 상태 표시를 검사했다. 최종 고정 소스 빌드/회귀 결과는 `build.json`/`results.json`/`frozen-native.log`를 따른다. 기존 자산 `203785492`의 자산 종류 불일치 경고는 신규 소품과 무관하며 새 소품은 원격 에셋을 요구하지 않는다.

미검증: 실제 플레이어의 정상 완주·모바일/4인+AI 성능·최종 미술 수용. 현재3에픽의 소품/일부 장소 개선이며 모든 지형·건물 교체나 Gloamwood/Haunted Graveyard 맵 구현은 아니다. 상위 티켓을 최종 완료로 바꾸지 않는다. 다음 ART/DES는 실제 전투 거리에서 사용자 미술 검토, QA는 모바일 성능/스트리밍을 확인한다. Roblox 게시/릴리스 태그 없음.
