## 검증

- Rojo 7.7.1로 소스 `8b327a23`의 단일 Place를 빌드했다. 기준과 후보의 SHA-256 및 각 런타임 연출 모듈 7개를 각각의 입력 커밋과 대조했다. [빌드 기록](build.json) · [패키지 대조](package-check.json)
- 격리 Studio에서 R6·R15의 128개 기술, 적 예고·아군 표시 예산, 타격과 표식, 궁극기 회귀를 포함해 18묶음 253,197건을 통과했다. 신규 148건은 확정 좌표, 화면별 형상, 중복 및 대체 표시, 효과 수명과 준비·회수 동작을 확인한다. 기준에서 같은 검사 516건 중 77건이 미충족이었다. 기준의 이전 함성 획이 많아 검사한 끝점 수도 늘었다. [검사별 결과](studio-results.json) · [신규 엔진 재현](../../../tests/hero-cast-shapes-native.luau)
- 같은 R15 리그·무기·표적·기술별 고정 카메라로 연속기 첫·마지막 또는 시전 준비·명중을 비교했다. 0.115.85에서 함성 마지막 잔파동과 도끼 재장전 보강이 필요했고, 0.115.86에서 Storm Arrow의 단일 낙뢰가 옅게 보여 0.115.87에서 높이와 대비를 조정했다. [전후 비교 16장](comparison.jpg)
- Lua 3묶음 14,237건 및 실제 패키지 정적 336건을 통과했다. 별도 기존 순수 Lua 자세 검사는 `K0MeleeMotion`의 Luau 복합 대입에서, 난이도 모드 검사는 rules18 기대값에서 중단됐다.

신규 검사는 저장과 네트워크 플레이를 시작하지 않는 Place에서 재현할 수 있다.

```sh

```
