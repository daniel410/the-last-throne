# 0.40.3 기사·드워프 기본 공격 모션

2026-10-31 · TLT-005/032/033/055/057/084 부분 구현 · ART/ENG → QA/DES · [원본 조사와 적용 판단](../../research/2026-10-31-sword-axe-motion.md).

## 변경

기존 공격은 단계별 고정 자세를 따라가며 기사1/3타가 같고 도끼가 과하게 수직 왕복했다. `K0MeleeMotion`에 기사 사선베기·되베기·내려베기와 도끼 사선 내려찍기의 준비/타격/잔여 회전/복귀를 작성했다. 몸통이 먼저 움직이고 팔꿈치·손목이 뒤따르며 모든 관절이 기존 서버 타격 시각에 도달한다. 검·도끼는 각각의 기존 TD 소켓 축을 사용한다. 추가 모션·권한 자산 업로드는 없다.

서버가 승인한 기본 공격에 `K0AttackStartedAt`을 게시하고 종료/취소 시 지운다. 스킬은 기존 시작 시각과 같은 값을 사용하지만 기본 곡선에 진입하지 않는다. 클라이언트는 기존 windup/active/hitDelay/recovery로 절대 시각을 샘플링한다. 관절과 무기를 별도 프레임 필터로 늦추지 않아30/144Hz 타격 자세가 같다. 걷거나 공중에 있을 때는 하체 애니메이션을 덮지 않으며 서 있을 때만 작은 체중 이동을 사용한다. Trail은 실제 베기 구간에만 보인다.

피해·사거리·속도·적 판정·보상·Stamina/MP·소유/저장과 기존 TD 원본은 변경하지 않았다. 전문 모션캡처나 모든 계열 스킬 모션을 새로 제작한 결과와 구분한다.

네이티브 모션 검사는 실제 Roblox CFrame/관절과 원본 무기/방패를 사용한 전방 운동학이다. GPU·네트워크·실제 Player 입력 테스트가 아니다. 방패 OBB 검사는 검날 중심선과 경계 상자의 교차 검사이며 전체 메시의 모든 삼각형 간 충돌을 증명하지 않는다. 기본 R6/R15 체형을 검사했고 모든 UGC 아바타 비율을 보증하지 않는다.

초기 후보에서 검의 과속/측면 타격을 발견해 방향과 준비 시간을 조정했다. 최종 최대 샘플 간 이동은 기본 공격당121시점 계측으로 기록했다. 이 수치를 FPS 성능 결과로 해석하지 않는다. 추가 서버 시각 검사의 첫 시도는 테스트가 샘플 판정만 부르고 종료 Heartbeat를 부르지 않아 실패했으며, 실제 `stepPlayer` 종료 처리까지 호출한 뒤 통과했다.

## 실제 Studio 시각 검토

`python3 docs/evidence/melee-motion-0403/build-preview.py`는 `/private/tmp/tlt-melee-preview.rbxlx`에 **게임 빌드와 분리된 검토 전용 장면**을 만든다. 실제 TD 검/도끼와 기본 R15 마네킹2개·고정 카메라를 사용한다. 해당 파일에서 F5로 재생하고1/2/3/4로 준비/타격/후속/중립 시각을 고정하며 C로 기사 타수를 바꿀 수 있다. 정식 게임에 이 검토 UI나 마네킹을 포함하지 않는다.

macOS Studio Play에서 두 원본 메시의 표시와 준비/타격 자세를 화면으로 확인했다. 도끼는 머리 위 준비에서 몸 앞 아래쪽으로 내려오며, 기사는 칼을 몸 앞에 내밀어 베는 자세를 확인했다. 확인 장면은 최종 관절 키포즈와 같고 이후 시간 보간에 몸통 선행/손목 후행을 추가했다. 최종 시간 보간은 위 엔진 검사로 검증했다. 시각 확인은 중립 마네킹·검토 카메라이고 정식 영웅 외형/방패 착용·정상 전투·게시 클라이언트 수용이 아니다. 검토 Play는 종료했다. 기존 `203785492` 자산 유형 경고는 원시 로그에 남긴다.

## 빌드·남은 수용

게임 버전0.40.3을 예약했으며 고정 입력 커밋에서 Lobby/Battle을 빌드한 결과는 [빌드 기록](build.json)에 추가한다. 비공개 게시판은0.40.2이며 이 작업은 Roblox 게시/릴리스 태그를 수행하지 않는다.

QA/DES의 다음 확인은 정식 영웅 외형을 착용한 정상 기본 공격3연격·이동 중 베기·방어/회피 취소, 모바일/패드, 실제 서버 지연·4인 관전자, 다양한 아바타 비율과 최종 사용자 미술 수용이다. 전체 모션/리그 티켓은 In Progress를 유지한다. 복구는 해당 소스 커밋의 변경을 되돌려 기존 단계별 포즈 경로로 복귀할 수 있다.
