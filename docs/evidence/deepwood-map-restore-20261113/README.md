# DW-03 최근 거목 수정 철회

2026-11-13 · TLT-061 · ENG/QA · 로컬 구현·미게시

## 범위와 기준

사용자의 최종 지시는 최근 거목 관련 수정만 취소하는 것이다. 거목 메시 연결 커밋 `756d8f9d` 직전 `4f3be928`의 맵 구성을 복구했다. Deepwood 전용 건축10종·기존 콘셉트 배치·길·안개를 유지하며, DW-03의 새 거목/뿌리/천막 메시와 그 전용 지형 정리·추가 길·옛 거목 교체만 제거했다. 해당 모듈2개와 ServerStorage 템플릿 연결을 제거하고 배치·충돌·테스트를 직전 상태로 맞췄다. 원본 모델/이미지와 당시 검증 증거는 비실행 참고 자산으로 보존한다.

관련11파일의 기준 커밋 바이트/해시는 `restoration.json`이다. 이후 VFX·게임 진행·보상·저장 및 다른 사용자 미커밋 변경은 유지한다. 앞선 넓은 복구는 빌드/푸시 전에 사용자 정정에 따라 취소했으며 이 최종 범위로 대체한다.

## 검증과 빌드

0.104.23에 최종 범위를 고정한다. 빌드 및 실제 검수 결과는 이 폴더에 기록한다. Roblox 게임 게시·원격 모델 삭제·릴리스 태그는 수행하지 않는다.

## 미검증과 다음 담당

게시 클라이언트·실기기·사용자 화면 수용은 별도다. QA는 실제 조작/기기 검증, 사용자는 DW-03 복구 화면을 확인한다. 부모 TLT-061 미술 게이트를 완료 처리하지 않는다.
