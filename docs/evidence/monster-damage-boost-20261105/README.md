# 몬스터 공격력 추가20% 상향

사용자 후속 요청에 따라 0.75.8의 에픽별 공격력에 추가1.2배를 적용한다. 에픽1~5의 일반/보스·4난이도·1~4인·무난이도 로컬 모험에 적용하며 체력·레벨·정예·보상·출현 수·공격 주기는 유지한다. 별도 고정 바닥 피해와 훈련장 K0는 변경하지 않는다. [이전 조사·선택·실전 수용 조건](../../research/2026-11-05-epic-monster-progression.md)을 재사용한다. 이번 추가20%는 사용자 요청을 구현하기 위해 선택한 시험값이며 최종 난도 수용과 구분한다.

새 원정은 Difficulty 규칙5를 저장한다. 기존 규칙1~4의 재접속/피해·보상은 보존한다. 따라서 기존 원정을 이어 하면 공격력이 바뀌지 않는다. 입장 미리보기와 실제 교전은 동일 unitStats를 사용한다. 후속 게시 시 Lobby/Battle을 함께 갱신해야 한다.
