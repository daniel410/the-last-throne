# 셀렌느 상세창·재동행 안내 · 0.60.0

2026-11-02 · TLT-016/028/061/072/084 · ENG/DIR → QA · 로컬 개선본·미게시.

## 변경

- 로비의 셀렌느 상호작용을 TD 서포터 상세창으로 연결한다. 영웅 프로필을 읽어 해금/선택 상태를 보여주고 로드 전에는 Unknown으로 남긴다. 신규 영웅의 저널 미생성은 실제 신규 미해금 상태로 표시한다.
- 모험 야영지/동행 셀렌느에는 View supporter details(G/패드Y/터치)를 추가한다. 서버가 영웅·생명 문맥과 NPC 거리14스터드를 검사한다. 읽기 전용 요청으로 해금/동행/통화/HP를 변경하지 않는다.
- TD 패널·버튼·nun 초상을 사용하고 데스크톱/모바일 가로에서 스크롤한다. 닫기/Escape/패드B·세션/캐릭터 교체 정리, 상세창이 열린 동안 전투 입력 차단을 연결한다. 같은 상태의2초 저널 갱신은 내용을 재생성하지 않아 읽던 스크롤을 유지한다.
- 상세창은 무료·기간 제한 없음·DW-03 구조 보고 해금·스토리4 이후 지속·능력/쿨다운·Elder Tree/Refuge/Forge City 재초대·영웅별 선택 저장·현재 파티 전체1명 제한을 설명한다.
- 휴식/모험 종료와 슬롯·거리·시야·주변 적·리스폰으로 인한 일시 중단을 나눠 다음 행동과 재개를 안내한다. 일반 안내는 상태 변경 시에만4초 간격으로 제한하며 명시적 휴식 종료는 즉시 안내한다. 기존 지원 수치와 구매/저장 계약은 바꾸지 않는다.
- 다른 서포터 고용·로비 구매·상품 가격·기간제는 구현하지 않았다. 현재 선택 가능한 전투 서포터는 셀렌느다.

## 중간 검증

`lua tests/supporter-info.spec.lua`:39개, `lua tests/selene-recruitment.spec.lua`:23개 통과. 0.59.1 로컬 Lobby에 변경 소스만 주입한 격리 시험에서 상세UI721·서포트40·NPC역할51개 통과(`source-native.log`). 기존 자산203785492의 유형 불일치 경고는 남는다. 이후 종료/중복/리스폰 추가 검사와 고정0.60.0 빌드를 검증한다.
