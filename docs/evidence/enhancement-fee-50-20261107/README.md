2026-11-07 · TLT-027/028/029/041/043/044/045/052/057/084 · ENG/QA → QA · 사용자 확정 구현·미게시.

사용자 지시로 지원 장비의 강화 시도 수수료를25→50 RPG Gold 고정으로 변경했다. 성공/실패 모두1회50Gold를 소비하고 강화 단계별 재료·성공률·효과·+9 상한·실패 시 단계 유지·회수 규칙은 그대로다. 기존 [강화/Gold 경제 조사](../../research/2026-11-06-weapon-enhancement-gold-review.md)를 재사용한다. 지정 가격 조정이므로 별도 비교 조사를 반복하지 않았다.

- 공유 `Enhancement.cost` 변경으로 서버 차감·강화 카드/도움말·구매 가능 판정이50Gold를 함께 사용한다. 강화규칙3→4로 이전25Gold 견적은 새 시도 전에 재확인을 요구한다.
- 기존 규칙3의25Gold 및 규칙2의 무료 완료 영수증은 원래 결과를 반환하며 추가 차감하지 않는다. 결과 UI는 이미 저장된 `outcome.gold`를 표시하므로 과거 결과도 실제 금액을 보존한다. 실패/저장 불명 재요청에서 수수료가 반복 소비되지 않는다.
- 보석 구매50Gold→1개·마석보석5+50Gold→1개·광석 전환 비용과 각각의 견적 버전은 변경하지 않았다. Diamonds·아이템 보유/강화 이력·모험/반복 보상·스킬/리셋 가격도 보존했다.
- 기존 검사 데이터의 ‘Tempered 무기는 가방’ 가정을 현재 신규 영웅 자동 장착 상태에 맞췄다. Lv80 구형 +10 검증품은 낮은 레벨 영웅의 가방에 두도록 수정했다. 반복Gold 기대값은 현재 `Difficulty.completion` 계약을 사용하고 구형 보석5개 버튼 기대값은 현재1개 구매 문구로 정정했다. 이 시험 수정으로 게임 장비/보상/교환 규칙을 바꾸지 않았다.
