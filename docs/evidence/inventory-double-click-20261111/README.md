# TLT-043 · Gear/Bag 더블 클릭 착용

2026-11-11 · 엔지니어 · 소스 구현/로컬 검사 통과, 실제 입력 수용 대기. 상위 티켓/G3 완료로 처리하지 않는다.

## 변경과 근거

최신 사용자 요청에 따라 Gear/Bag 가방 장비의 같은 아이템을0.35초 이내 왼쪽 더블 클릭하면 기존 Equip 명령을 실행한다. 한 번 클릭은 상세 선택이며 착용품 더블 클릭은 해제하지 않는다. 기존 버튼의 활성/착용 자격을 재사용하고 서버 소유권·버전·슬롯 확정 경로를 유지한다. 화면/영웅/revision이 바뀌거나 다른 입력이 끼면 이전 클릭을 착용에 사용하지 않는다. [조사·대안](../../research/2026-11-11-inventory-double-click.md).

변경: `src/client/InventoryGui.luau`, `tests/inventory-double-click.spec.lua`, 장비 UX 사양과 본 증거/조사. 기존 미커밋 장비 warmup 변경은 보존하고 이번 커밋에서 제외했다.
