# 다른 세 지역의 겹친 바닥 렌더 정리

2026-11-15 · TLT-063/064/065 · 맵 구현/환경 아트/ENG → QA · 로컬 구현·미게시

[Frozen Vale 수정](../fv-surface-20261115/README.md) 다음으로 Gloamwood·Ember Caldera·Haunted Graveyard의 동일 결함을 감사했다. 실제 엔진에서 GW-01 높이54, EC-05 높이156, HG-03 높이180에 기초/옛 표면/대표 보행면이 같은 폭·깊이·높이로 겹침을 확인했다. [변경 전 속성](before-surfaces.json). 예를 들어 EC 기초RGB48/47/54와 대표면78/66/70, HG 기초108/115/131과 대표면89/105/98이 겹쳐 있었다. 명확한 렌더 결함 후속이므로 별도 게임성 리서치는 추가하지 않았다.

## 변경과 보존

`CampaignSurfaceUnderlays`가 세 지역의 새48면(GW14/EC20/HG14)과 기존 FV20면을 공통 처리한다. Frozen Vale의 기존 호출 경로/속성 이름은 `FrozenSurfaceUnderlays`의 얇은 어댑터로 보존했고 이전 검사를 그대로 실행한다. Deepwood는 일부 표면 높이/바닥 구조가 달라 이번 대상에서 제외했다.

확인된 이름/부모 유형의 기초·옛 표면이 불투명하고 고체인 `JourneyGround`에 완전히 덮이고 회전·윗면 높이가 맞을 때만 렌더를 숨긴다. Transparency/그림자 외에 크기·높이·충돌·쿼리·터치·색/재질을 변경하지 않는다. 다음 적용 시 덮는 바닥의 크기 부족·투명화·회전 불일치를 발견하면 원래 표시를 복원한다. 프레임마다 감시하는 새 루프는 없다.

에픽별 기존 스토리·보상·진행·저장·봉쇄/연결·TD 원본·지역 조명·네이티브 Terrain은 보존한다. 신규 파트/외부 자산/메시/텍스처도 없다. 기존 Terrain과 대표면의 색/재질 차이나 넓은 평지·실제 각진 외곽까지 모두 해결했다고 보고하지 않는다. 특히 GW의 어두운 전투 바닥은 기존 지역 팔레트이며 이번 수정으로 밝히지 않았다.

## 고정 빌드와 재현

빌드 **0.109.3**, 입력 `aebf58f84e00931d740635031a810ae8e7d0c677`. [빌드/LFS](build.json) · [정적 검사](static.log) · [전체 엔진 로그](native.log) · [구조화 결과](results.json) · [입력 해시](inputs.json).

```bash
python3 tools/build-game.py --source aebf58f8 --record /tmp/regional-underlays-build.json
python3 tools/prepare-regional-underlays-native.py
```

생성된 `/tmp/tlt-regional-underlays-native.luau`를 고정 빌드의 격리 Studio에서 실행한다. 실제 검증은 고유 파일명 복사본을 `RobloxStudio -localPlaceFile ... -task EditFile`로 직접 열고 Studio ID를 명시해 수행했다. 변경3모듈 바이트 일치·전체 Luau 컴파일부터 검사하며 최종 빌드에 소스를 주입하지 않는다. 긴 MCP 응답은 타임아웃이더라도 엔진 작업이 끝난 뒤 마지막 통과 마커와 `_G.SurfaceMessages` 원문을 회수해 판정한다.

검사는 기존 FV20면 복구/호환, 새 세 지역별 크기 부족·투명/회전 불일치 복구, 반복 적용과 전 맵 물리 속성 불변을 포함한다. GW/FV/EC/HG의 기존/Easy 경로는 차단·바닥·보정·안내·단차0을 요구한다. 실제 R15는 GW-01/EC-05/HG-03/HG-06의 마지막 교전→다음 구조/봉인 접근을 두 경로별 총8조건으로 이동한다. 지역 건축/양수 고체 충돌/교전·FV지형·식생 회귀도 유지한다. 물리 Run/Stop은 모든 기하 검사 뒤에 실행한다.

미검증은 게시 클라이언트/실제 스트리밍·실계정·PC/터치/패드 전투/회피/카메라·1~4인+AI 성능·사용자 미술 수용이다. 다음 QA/DES는 실제 클라이언트에서 표면 깜박임과 지역 색/재질 연결을 확인한다. 겹침 정리를 다른 지역의 새 환경 제작 완료로 간주하지 않는다. G5는 닫지 않으며 Roblox 게시·릴리스 태그도 없다. 별도 작업 트리에서 작업 파일만 커밋한다.

최종 결과는 총68면·61,234파트에서 신규122,566검사 통과, 기존 FV검사도20면 처리와 복구를 유지했다. 두 경로 sweep의 차단/바닥/보정/안내/단차는0이며 실제 R15보행8조건도 전부 도착·점프0/보정0이었다. 새48면 처리와 기존20면 재검증을 합산해 신규68면으로 보고하지 않는다.
