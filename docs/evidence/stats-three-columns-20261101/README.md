# 스탯 상세3열 배치와 가용 포인트 상단 표시

2026-11-01 · TLT-028/031/052/084 · ENG → QA · 로컬 수정·미게시

사용자는 Available Stat 정보를 위로 옮기고 영웅 장비 이미지를 줄여 장비/Combat Stats/스탯 배분3정보를 함께 보도록 요청했다. 데스크톱 상세 폭960px 이상에서 장비24%·전투 능력치35%·포인트 배분 나머지3열을 같은 높이로 배치한다. 장비 초상/슬롯을 축소하고 배분 행 간격을 줄인다. 배분 +/-는44px, 저장/취소 동작을 유지한다. 가용 포인트는 TD 원본 plaque로 화면 맨 위에 표시하며 초안에서 사용한 포인트를 차감한다.

좁은 화면의 기존 반응형 배치/모바일 상세 탭은 유지한다. 모바일 세로·좁은 화면에도 상단 POINTS 탭에 남은 포인트를 표시해 가로 모바일 기존 동작과 맞췄다. 모바일에서3열을 강제하지 않는다. 게임 문자열은 영어 키로 관리하며 서버 배분/저장 계약은 유지한다.

변경: HeroStatsView, CombatStatText, skill-stat-ui-native. 기존 스킬 계열 전환 수정도 회귀 검사한다. 고정 소스 Lobby/Battle 빌드와 네이티브 GUI/텍스트 검증 결과는 build.json과 로그에 기록한다. 실제 렌더·게시 클라이언트·실기기 수용은 별도 미검증이다. 다음 QA가 실제 데스크톱/모바일 화면을 수용한다. Roblox 게시/릴리스 태그 없음.
