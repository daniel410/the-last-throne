## 범위와 근거

승인 영웅4종 컨셉 이미지를 직접 비교하고, 현재 `TheLastThrone-0.103.4.rbxlx`의 기존 무기/방어구를 R15 마네킹4개에 착용시켰다. 검·도끼·활·지팡이와 각 클래스의 Traveler 머리/몸/장갑/신발이 연결되는 것을 확인했다. 계정/인벤토리/TD 운영 상태는 변경하지 않았다. 높이700의 임시 마네킹은 캡처 후 제거했다. [실제 Studio 수정 전](studio-equipped-before.png).

| 영웅 | 관찰 | 로컬 수정 |
| --- | --- | --- |
| Elf | 컨셉의 갈라진 갈색 앞머리에 비해 기존 후드 앞머리가 거의 보이지 않음 | 옆가르마에서 좌우로 쓸리는 넓은 앞머리. 둥근 다발을 납작한 능선과 사선 끝으로 교체 |
| Mage | 기존 옆머리가 긴 판으로 읽힘. 계열별 녹색/청색 머리색은 영웅 컨셉에서 확인되지 않음 | 긴 옆머리·앞머리 제거. 정수리·뒤통수 전체와 짧은 목덜미 유지 |
| Knight | 컨셉은 얼굴 노출과 닫힌 투구가 중심 | 눈 앞머리를 만들지 않고 짧은 목덜미로 제한 |
| Dwarf | 기사와 공유한 머리 때문에 적갈색 머리·수염 정체성이 없음 | 바깥으로 뻗는 납작한 뒷머리. 최신 사용자 지시로 수염·콧수염·구레나룻 전부 제거 |

무기와 방어구 본체는 유지했다. Studio 기준 화면에서 일반 상의의 상완은 여전히 아바타 부품으로 드러난다. 이 부분과 컨셉의 정교한 방어구 장식 차이는 머리카락 변경으로 해결했다고 보고하지 않는다. Blender 몸체는 분할된 방어구만 표시하므로 로브의 어깨 접합 빈 공간은 실제 아바타 팔/리그 포함 검증과 구분한다.

최신 사용자 지시로 네 영웅 모두 가려지는 윗머리·뒤통수도 완전한 닫힌 머리캡으로 제작하고, 모자를 숨긴 `*-hair-only.png`로 확인한다. 드워프 수염은 없다.

최신 사용자 수정: 이전 후보는 컨셉과 다른 둥근 다발 형태라는 이유로 거부됐다. 이번 후보는 그 형태를 교체하며, 수치 검사 통과를 미술 수용으로 처리하지 않는다.

## 산출물·검증

[Blender 및 GLB4종](../../../assets/models/headgear-hair-concept-v2/README.md), [검증 JSON](geometry-validation.json), [원본 컨셉 대조](concept-comparison.jpg), [영웅별 비교](comparison.jpg), [16계열 비교](families.jpg).

- Blender5.2.0 별도 백그라운드 프로세스. 사용자의 열려 있는 환경 장면을 교체하거나 저장하지 않음.
- Standard/sRGB/None/Exposure0/Gamma1/CurvesOff, 원본 방어구 텍스처 유지.
- GLB는 스타일마다 머리 메시1개만 수출. 닫힌 표면/삼각형 수/파일 SHA256 및 컨셉 SHA256 검사. 수치 정본은 검증 JSON.
- 기준 Head 크기1.159×1.182×1.161에서 양쪽 눈18점 ×4영웅=72개 광선의 머리 메시 차폐 검사. 실제 R6/R15 엔진 검증은 아님.
- Traveler 정면·사선·뒤12렌더와 4영웅×4장비계열 정면16렌더. 둥근 블록 Head 프록시이므로 원본 후드의 좁은 측후면에서 프록시 피부가 노출되는 부분은 실제 Head 재검증 필요. 장비/머리의 의도된 안쪽 겹침을 모두 충돌 오류로 계산하지 않음.

## 차단·미검증·다음 담당

Studio Open Cloud의 읽기 전용 권한 probe에서 `asset:read`, `asset:write` 모두 **has not been granted**를 반환했다. 업로드/게임 연결/빌드/게시는 수행하지 않았으며 기존 v1 런타임을 유지했다. 권한 우회 없음.

다음 담당: 사용자에게 Studio Assistant Settings → MCP Permissions → Publish & manage assets의 두 권한 및 이 자산 폴더 업로드 허용을 요청한다. 사용자 계정9156786071로 새 Model4개를 생성하는 범위다. 이후 제작 담당이 업로드/승인 상태 확인 → 실제 메시48점/개 대응 → 영웅별 템플릿·색/후드 추가 오프셋 제거 → R6/R15×4계열, 교체/해제/실패 복구·눈 차폐·공격/회피 포즈를 검증한다.
