2026-11-14 · TLT-005/084 · ENG/RES → QA · 소스/후보 Studio 통과, 미게시

## 변경·근거

[최종 사용자 지정](../../decisions/2026-11-14.md#기사-기본3타-지정-구간)에 따라 [영상2:25~2:27의 프레임](../../research/2026-11-14-knight-reference-combo.md)만 동작 참고로 사용한다. 새 기본기는 **내려베기→올려베기→정면 찌르기**다. 기존 소유 내려베기에서 접촉을 보존하며 첫 두 타를 재저작하고, 마지막 찌르기는 실제 R6/R15 관절·검 소켓으로 푼다. 첫 두 타는 다음 준비로 연결하고, 입력 중단 시 실제 마지막 자세에서 방어/대기 자세로 이어진다. 원본 자산과 기술별 변형은 유지하며 서버 루트를 이동하지 않는다.

서버 코드를 변경하지 않는다. 기존0.588/0.644/0.868초(평균0.70), 피해1.05/1.26/1.68, 자세12/14/24, 사거리5.5/5.5/6, 각도100/110/100, 최대3대상·높이7·0.12초 입력 버퍼·0.6초 콤보 초기화·DEX 공속을 유지한다. 새 다단 피해·넉백·점프/돌진·로컬 피해 판정은 없다.
