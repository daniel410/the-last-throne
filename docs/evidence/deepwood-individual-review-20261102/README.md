종별 Idle/Walk/Attack/AttackAlt/Heavy/HeavyAlt/Stunned를 실제 TD 메시·현재 Ogre/Warlord 손 소유권으로 추출했다. native `Motor6D`의 이번 프레임 행렬을 합성해 Blender에 옮겼으며 걷기4자세/공격3자세를 각 모델마다 직접 검토했다. 나머지 공격 변주는 엔진에서 전체 시간과 30/60/144Hz 접촉을 검사했다. 추출/검토 스크립트의 초기 JSON 출력 길이와 Blender 회전 모드 문제는 렌더 전에 고쳐 재추출했다. 다른 Blender 작업이 병행되므로 각 작업은 별도 씬에서 수행하며 `.blend` 전체를 덮어쓰거나 저장소에 타 작업을 복사하지 않았다.

공통 수정: 실제 보폭과60% 지지 구간을 맞추고 팔이 같은 쪽 다리와 함께 흔들리던 위상을 교정했다. 거리 샘플에 다시 포즈 보간을 걸어 발이 늦던 현상을 Deepwood 프로필에 한해 제거했다. 공격/스턴/노출 때 남아 있던 보행 발 들기를 제거한다. 서버 판정 시점 .62, 공격 예고/활성/회복 시간, 루트·HP·피해·보상은 유지한다. Frozen Vale/Ember Caldera 곡선은 변경하지 않는다.

네 종의 메시 후보는 원래 Body에 걸쳐 있던 무기 조각을 ArmR에 재배분하고 UV/원래 표면적을 보존했다. Blender에서 경계를 닫고 별도 GLB8개(전체 검토4개 + 변경 Body/ArmR 가져오기4개)를 만들었다. 현재 게임에는 이 새 메시를 연결하지 않았다. 컴퓨터 사용 도구의 파일 업로드 확인 규칙에 따라 현재 로그인 Roblox 계정에 새 메시8개/텍스처를 올리고 로컬 연결하는 승인을 요청한 상태다. 기존 Ogre/Warlord 업로드 승인은 그 두 모델 범위이므로 추가4종의 업로드 승인으로 확대하지 않았다.

검증 명령: `python3 tools/prepare-deepwood-motion-v3.py` → Blender MCP `tools/author-deepwood-motion-v3.py` → `python3 tools/export-deepwood-v3.py`. 파생 메시: `python3 tools/repair-deepwood-caster-seams.py` → Blender MCP `tools/close-deepwood-v3-seams-blender.py`. 실제 리그 추출: `run-in-roblox --place <Battle fixture> --script tools/capture-deepwood-review.luau`. 이미지는 `tools/review-deepwood-model-blender.py`, 조립은 번들 Python/Pillow의 `tools/assemble-deepwood-review.py`를 사용한다. authoring-keys JSON은 입력이고 clips JSON은 실제 Blender F-curve 평가 결과다.

미검증/남은 일:4종 새 메시 Roblox 업로드·정규화·런타임 연결/소켓 재추출·엔진 재검증. 경사 지형 IK, 실제 플레이어 정상 교전·모바일/4인+AI 성능, 최종 사용자 미술 수용. EnragedWarlord 일체형 몸체와 로브형 보스의 무릎/팔꿈치 부재는 남아 있다. 현재 결과를10종 전신 리그 완성이나 새 메시 게임 적용 완료로 보고하지 않는다. 다음 ART/ENG는 승인 뒤4종을 연결하고 QA/DES가 게임 거리에서 재검토한다. 상위 티켓 최종 완료/Place 게시/릴리스 태그 없음.
