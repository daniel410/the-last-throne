## 구현과 결정 적용

[초반6스킬 재설계](../../production/pre20-skill-tree-2026-10-29.md)와 최신 궁극기 결정, 사용자의 구현 요청을 적용했다. 신규 해금5/10/15·영문명·수치·MP·지속·효과는 **런타임 시험값**이며 최종 밸런스 승인으로 보고하지 않는다. 기사/엘프/드워프는 물리 쿨다운만, Mage는 MP와 쿨다운을 사용한다. Lv5/10의4/5번 슬롯과 학습은 별개이며 새 기술이 기존 편성을 덮어쓰지 않는다.

기존 공통12 + 신규 공통12 + 계열96 + 궁극기8 = **128개 정의**, 클래스별 목록32개 중 선택 경로 **공통6+계열12+궁극기1=19개**다. 기존104개 계열 정의는 유지하면서 새 공통 기술도 서버가 대상·거리·장애물·중복·MP·쿨다운을 판단하는 전투 경로에 연결했다. 후퇴 이동은 음수 거리를 정방향 거리/반대 벡터로 바꿔 벽과 낙하 검사에 적용한다. 신규 감속은 StoryBoss와 Ogre에 적용하지 않으며 기본 피해는 남긴다.

궁극기는 **Lv80 선택 계열 최종 전직 완료 후에만** 전용 버튼이 보인다. 레벨80만 도달하거나 다른 영웅으로 바꾸면 숨긴다. 일반1~5에는 궁극기를 편성할 수 없다. 현재 전용 입력은 PC T / 패드 D-Pad Up / 터치 전용 버튼의 시험 배치다. 일반 슬롯을 늘리거나 미해금 잠금 버튼을 노출하지 않는다.

3뿌리 트리에 새 공통3개를 추가해19노드를 표시한다. 기술명·효과·MP·쿨다운·자격·숙련과5칸 편성 정보를 갱신했다. 보호막을 피해/도발로 표시하지 않으며 궁극기 노드 선택 중 일반 슬롯 편성은 비활성화한다. 레벨5/10/15를 넘으면 영어 새 기술 안내를 제공한다.

## 저장·권한·이전

성장 스키마3은 기존1/2를 읽는다. 기존1~29 스킬 인덱스·안정 ID·숙련·일반 편성을 유지하고 새 기술은30~32에 추가했다. 버전2가 쓰던 궁극기 일반 슬롯만 비우고, 같은 해금 궁극기를 전용 버튼에서 제공한다. 기존 궁극기 숙련과 SP는 보존하며 이전은 멱등이다. 실제 저장 기록이 없는 C4~C6 설계 노드에 임의로 새 의미를 부여하지 않았다. 투자316 스탯P/79SP는 그대로다.

실패한 로드는 신규/0 프로필로 덮어쓰지 않는다. 기존 거래·불명 응답 복구 검사와 함께 이전을 검사했다. 런타임 쿨다운은 안정 ID로 생명/영웅 전환 중 재사용하며, 저장/편성 갱신 때 슬롯 및 현재 쿨다운을 다시 투영한다. **서버 재접속을 넘는 쿨다운 영속 저장은 기존에도 없었으며 이번에 구현하지 않았다.** 실제 게시 저장/재접속·계정 경합 수용과 구분한다.

## 방패 동작

사용자의 방패 액션 확대 요청으로 Shield Bash·Guarded Strike 및 방패/반격/보호 관련 기사 계열 기술의 준비 자세, 방패 전방 이동, 상체 회전, 발 디딤을 키웠다. 기본 Provoke의 들어 올리기도 확대했다. 실제 방패 MeshPart 원본 크기·서버 사거리·피해 판정은 이 시각 변경으로 확대하지 않았다. 서버가 승인한 스킬/페이즈로 R6/R15 관절과 충격파를 움직인다. 최종 애니메이션 클립·미술·실기기 시각 수용은 남아 있다.

## Provoke 디버프 후속 (0.31.1)

사용자의 “Provoke도 상대 디버프 또는 영웅 버프” 요청을 적 공격 약화로 구현했다. 기존 도발·받는 피해10% 증가와 함께 범위 내 적의 일반 전투 공격 피해를15% 줄이는 디버프를4초 적용한다. 자기 HP/MP 회복이나 직접 피해는 없으며 여러 기사가 사용해도15%가 곱셈 중첩되지 않는다. 재시전은 지속을 새로 적용한다. 수치/지속은 시험값이다. 서버가 실제 적 타격 때 감소를 계산하며 만료 시 일반 피해로 복구하고 리셋/재생성에는 제거한다. 적 머리 위에 ▼ ATK -15% / ▲ DAMAGE TAKEN +10%와 각각 남은 초를 표시하고 만료/사망 시 없앤다. UI는 실제 방어 스탯 -10%로 오해시키지 않는다.

0.31.1 고정 빌드의 [전투 native873개](0.31.1-combat.log) 통과는 실제 감소 피해·만료 뒤 원래 피해·서버/표시 상태 초기화를 포함한다. [GUI native295개](0.31.1-ui.log)도 통과했으며 공격15% 감소·받는 피해10% 증가 표기와 만료 제거를 확인했다.0.31.0의 R6/R15 동작61개는 동작 소스가 같아 재사용하며 새로 실행한 검사와 구분한다.

MCP 원본 Studio의 편집 모드에 Provoke 관련4개 파일을 동기화하고 Play를 재시작했다. Client가 읽은 설정의 공격 배율0.85·지속4초·받는 피해 배율1.10과 새 공통 스킬 목록32개를 확인했다. 최신 후속의 실제 적 교전/디버프 시각 수용은 native 검사와 구분해 미검증으로 남긴다.
