## 공격력 검토

## 생존성 판단

영웅 레벨은 각 임무의 현행 요구 레벨과 난이도 하한 중 높은 값(최대80), 무장비·무회복·한 적의 같은 공격만 연속 명중으로 계산했다. VIT0의 마법사는 모든 난이도의 일부 보스에서2타 사망이며 단일 공격1타 사망 조건은 없었다. 파티4인은 기존 피해1.3배로 위험이 증가한다. VIT에 전체 배분 예산의25%(level−1포인트)를 쓰면 마법사의 최소 타수는 솔로 Easy2/Hard3/Insane4/Hell4,4인 Easy2/Hard2/Insane3/Hell3이다. 실제 방어/회피·동료/장비/자연회복·다중 적 중첩은 포함하지 않았다. 공격력이25% 올라도 방어의 고정 차감 때문에 실제 받는 피해 증가율이나 체감 난이도가 정확히25%가 되는 것은 아니다.

판단:25% 적용으로 비교하되 보스 추가 상향은 보류한다. 몬스터 수가 이미 많은 상태이므로 한 적 공격력만으로4인/모바일 사망률을 수용하지 않는다. 후반 진입Lv27 임시 기준·Lv41~80 본편 성장/최종 장비 밸런스 수용이 남아 있어 무장비 타수는 민감도 참고값이다.

## 구현·호환·검증

Difficulty 규칙을3으로 올리고2의 모드 행을 복사 보존했다. 새 원정/메뉴는3의25% 인상을 사용하고 저장된1·2 원정의 재접속/피해/보상을 유지한다. 새 규칙3을 모르는 구버전 서버로는 안전하게 롤백/혼합 운영할 수 없으므로 향후 Lobby/Battle을 함께 갱신해야 한다. 무난이도 로컬 모험 경로도 기존 일반1.5/보스1.25 배율에서1.875/1.5625로 조정한다. 이 경로의 HP·보상은 유지한다. 현재 원정 Easy와 이 과거 로컬 경로의 절대 수치 차이는 그대로이며 서로 같은 기준으로 혼동하지 않는다.
