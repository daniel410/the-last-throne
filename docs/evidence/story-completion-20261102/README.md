# 스토리 완료 연출·다음 스토리 안내

2026-11-02 · TLT-016/027/028/050/061/065/072/084 · ENG → QA

사용자 요청에 따라8초 보상 알림을 TD 스타일 완료 카드로 교체했다. 금색 강조선과0.28초 확대 등장 후 사용자가 읽고 닫을 때까지 유지한다. 기존 TD 프레임·버튼을 재사용하며 로비/배틀 기본 메뉴의 이미지·위치를 바꾸지 않는다. [사례 조사/근거](../../research/2026-11-02-story-completion-handoff.md).

## 표시·동작

- STORY COMPLETE / SIDE QUEST COMPLETE / EPIC COMPLETE로 종료 유형을 구별한다. 완료 제목·서사 결과·서버 확정XP/Gold와 가방/미수령 보상을 안내한다.
- NEXT에 실제 저장 진행 기준 다음 스토리명·지역·스토리 번호·첫 목표를 표시한다. TRACK NEXT STORY는 선택형 퀘스트 추적을 해제하고 기존 메인 길잡이/금색 표식으로 연결한다. 스토리 수락·진행·보상·순간이동은 클라이언트가 확정하지 않는다.
- Deepwood7→Frozen Vale1과 Frozen Vale7→Ember Caldera1은 지역명을 명시한다. 현재 플레이 가능한21스토리 종료 후 미구현4/5에픽으로 이동 가능하다고 표시하지 않는다. 완료 카드의 REVIEW QUESTS로 저널을 확인한다.
- 원정완료 상태가 포함된 별도 임무 경로에는 자동 다음 임무 시작 대신 Return to Lobby→모험지도에서 다음 스토리 선택→시작을 안내한다. 이 호환 분기는 현재 다른 작업의 미완료 난이도/원정 코드를 이번 커밋에 포함한다는 뜻이 아니다.
- 해당 메인스토리의 유료 Selene 지원을 확인했으면 지원 종료·안전 캠프에서1 credit 재초대·부족 시 로비 구매·자동 갱신 없음을 함께 표시한다. 같은 영웅의 지원 스토리를 기억해 상태 갱신이 완료 이벤트보다 먼저 와도 안내를 유지한다. 선택형 퀘스트 완료로 지원 종료를 안내하지 않는다.
- 닫기/ESC/패드B, 계속 버튼을 제공한다. 움직임·공격·카메라를 잠그지 않는다. 패드는 선택 가능한 버튼에 포커스를 제공하고 닫으면 이전 선택을 복원한다. 영웅 변경/모험 이탈 시 카드를 닫는다. 동일 영웅·스토리·원정ID의 완료 알림은 세션 중 중복 표시하지 않는다.
