# 광석 변환50Gold 추가

2026-11-06 · TLT-029/041/043/052/084 · ENG → QA · 0.78.11 로컬 구현·미게시.

사용자 지정 비용을 적용해 **Ore1개 +50Gold → Gem1개**로 변경했다. 기존 무료 Ore변환 계약을 대체한다. Core변환·Gold50→Gem5·Gem5+Gold50→Stone1·강화25Gold는 유지한다. Diamonds는 소비하지 않는다.

서버는 현재 교환 견적 버전 확인 후 Gold와 광석을 검사하고 동일 계정 거래에서 차감/지급한다. 이전 버전 없는 무료 견적은 ExchangeChanged로 재확인하며 이미 완료된 무료 변환 영수증은 재조회만 수행하고 소급 청구하지 않는다. UI는 공유 비용값으로 영어 버튼/확인 안내를 표시하며50Gold미만이면 비활성화한다. 신규 이미지/TD프레임 변경 없음.

기존 [제작경제 조사](../../research/2026-11-06-weapon-enhancement-gold-review.md)의 재료+Gold 소비 원칙을 재사용한다. 이번50Gold는 사용자 지정이며 비교작 가격이나 새 밸런스 추천으로 해석하지 않는다.

검증: `tests.log`에 Lua 재료교환180·재료보상41·강화확률2869(90000경계 포함)·인벤토리271·난이도2661·강화125 총6147검사 PASS를 기록한다.50Gold정확/49부족·광석부족·가짜가격·중복·저장응답 유실/콜백 재실행/재접속·이전 무료영수증·Core무료 유지 검사 포함. 기존 재료보상 테스트의 오래된 강화규칙2 fixture를 현재 공유 버전으로 정렬했다. 기존 Studio 시나리오의 Ore변환 요청에도 견적 버전을 추가했다.

빌드 입력 커밋/산출물 해시는 `build.json`에 기록한다. 실제 Studio UI조작·게시 클라이언트·실기기/경제 수용·live DataStore는 미검증이며 게시/릴리스하지 않는다. 다음 담당 QA는50Gold이상/미만의 실제 버튼 표시와 교환/재접속을 확인한다. 상위 티켓 완료 상태는 변경하지 않는다.
