## 검토 범위와 실제 변경

`K0Config`의 네 영웅 각각32개, 총128개 ID를 하나씩 `SkillPresentation`의 명시적인 동작/효과와 대조했다. [개별 검토표](skill-review.tsv)는 해당 기술의 이름·형태·연타·채택 동작·효과·보존/수정과 화면 수용 미실행을 기록한다. 기본3개×4는 기존 저작 모션/효과를 보존하고, 공통 추가12+계열104=116개 기술의 상위 효과를 개선한다. 128개의 독립 신규 애니메이션/최종 미술 완성을 뜻하지 않는다. [조사와 적용 근거](../../research/2026-11-04-hero-skill-presentation.md).

`AdvancedSkillMotion`은 신규 **절차적** 동작이다. 기존 Blender 원본을 수정하거나 신규 Action을 업로드하지 않았다. 이동 중 발은 기존 Animator를 유지하며 물리 루트는 움직이지 않는다. 기존 K0SwordVisual의 팔/무기 경로에 동일 샘플러를 연결했다. 후속 사용자 도끼/회피·로비/원정 미커밋 변경은 작업 커밋과 고정 빌드에서 제외한다.

`AdvancedSkillVisual`은 서버 RemoteEvent만 소비한다. 지면 Raycast로 표식 높이를 찾고 ground는 radius, area는 range, cone/melee는 실제 angle/range로 표시한다. 원판을 없애고 얇은 외곽/궤적으로 중앙 시야를 남긴다. Crosscut 두 번째 궤적은 서버와 같은18도 회전을 사용한다. 충돌/터치/쿼리·그림자는 끄고 전역 장식 파트128개로 제한한다. 예산 포화 시 장식을 생략하며 피해/실제 판정에는 영향이 없다. 보호·스턴·표식·피해·MP·쿨다운·해금·안정ID·보상·TD 권리는 변경하지 않는다.

## 미검증과 다음 담당

시작 시 Studio MCP 연결 목록이 비어 있었다. 실제 엔진 동작·R6/R15 손 접촉·팔 관통·총구/도끼 날 각도·원본 화살 메시 로드·평지/경사 표식·연타의 체감·실기기/4인+AI 부하·사용자 미술 수용은 아직 통과하지 않았다. 절차적 가족 동작이라 기술마다 완전히 독립적인 연기는 아니며 총·폭탄·상위 투척 도끼의 일부는 기본 도형이다. 프레임 수나 CPU 검사 수를 미술 품질의 증거로 삼지 않는다.

QA/DES/ART는 개별 검토표128행을 기준으로 실제 훈련장에서 준비→적중→회수, 방어/회피 취소, 이동/연속 입력, 낮은 품질/동시 궁극기를 관찰하고 손·무기 접촉과 시야를 교정한다. 기본 공격/Block/Dodge/Sprint는 이번 새 상위 기술 샘플러 대상이 아니며 기존 수정과 함께 회귀 확인한다. 위 수용 전에는 ‘최고 품질 완료’나 부모 티켓 Done으로 보고하지 않는다.
