## 변경·근거

[최신 사용자 결정](../../decisions/2026-11-14.md#기사-기본3타-지정-구간)에 따라 기본3타는 **내려베기→올려베기→크게 가로베기**다. [Diablo/WoW 비교·적용 한계](../../research/2026-11-14-knight-horizontal-finisher.md). 첫 타 원문은 유지하고, 둘째 타 끝자세를 가로베기 준비에 연결한다. 세 번째 타격은 오른쪽에서 왼쪽으로130도 수평 궤적을 계산해 기존 서버 접촉 시각에 중앙을 통과한다. 실제 R6/R15 손·검 소켓으로 자세를 계산하며 왼팔 방패를 낮춰 검과 겹치지 않게 한다. 폐기된 찌르기 런타임 모듈은 제거하고 과거 solver/자세와 검증 기록은 보존한다.

서버/기술 소스는 변경하지 않는다. 기존0.588/0.644/0.868초, 피해1.05/1.26/1.68, 자세12/14/24, 사거리5.5/5.5/6, 각도100/110/100, 최대3대상·높이7·입력 버퍼·DEX공속을 유지한다. 원본 Blender·TD 자산과 드워프 모션은 유지한다. 새 Blender 평가로 검증했다고 세지 않는다.
