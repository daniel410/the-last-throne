## 작업과 산출물

사용자 요청은 에픽5~8 각각의 전체 줄거리와 세부 스토리·몬스터 구상이다. 에픽5/6은6개,7/8은7개로 총26이야기(메인25·에필로그1)를 상세화했다. 각 시나리오는 독립 문서로 도입·사건/인물의 선택·3국면·완료 결과·안전SP·적/대응·재시도·보상 미정·영어 목표/대사와 다음 담당을 갖는다.4에픽 개요는 서사·지역 선택·숨은 퀘스트·보스 구성을 통합한다.

32교전 정의는 일반20·필수8·선택4다. Derived28/New4는 자산 후보 분류이며 신규 종/메시/완성 AI 수가 아니다. 현존 TD 모델 XML2종의 바이트 SHA256과 정확한 Model 키를 재확인해 후보 경로에 연결했다. 권한·라이선스·RPG 리그/모션·실행/시각·성능은 확인하지 않았다. 웹 조사도 직접 플레이나 이용자 관찰로 보고하지 않는다.

기존32구간의 보상 정본·성장 검증기·앞의 스토리/맵 데이터, 게임 소스·VERSION은 이번 작업에서 편집하지 않는다. 레벨 위치는 기존 완성상 목표를 이야기별로 배치한 제안이며 후반 XP/Coins는 `null`로 남겼다.8숨은 퀘스트 초안도 수치가 미정이고 본편/전직/지원의 필수 선행이 아니다. 문서 정합 확인으로 부모 TLT-065~070·G5/G8 또는 전체 게임을 완료하지 않는다.

## 검증 명령·조건·결과

결과의 구조화 사본은 [validation.json](validation.json)에 보존한다. 아래 검사는 문서/설계 데이터 범위다. 실제 Studio·게시 클라이언트·실기기·난도/재미·성장41~80·저장/재접속은 미실행이다.

- `python3 /private/tmp/tlt-validate-late-epics.py`: 임시 Python 검사로4에픽/26고유 스토리·26SP·78목표·32교전·8숨은 퀘스트·영어 키를 검사한다. 개별 스토리 선행/다음의 단일 연속 경로, 본편의 선택보스 미포함, 지역별5/2/1, 모든 필수 보스의 실제 메인 배치, 소스 Model 키/해시, JSON과 Markdown 제목/목표/대사의 일치, 상대링크/앵커/펜스를 확인한다. 최종 결과는 아래 마감 결과로 기록한다. 임시 스크립트는 런타임/정식 테스트로 추가하지 않았다.
- `python3 scripts/simulate_story_progression.py --output /private/tmp/tlt-late-epics-progression.json`: 기존32구간 회귀만 확인한다. 후반41~80 XP를 검증하는 명령이 아니다.
- `git diff --check`, 선별 스테이징 뒤 `git diff --cached --check`: 이번 변경의 공백/충돌 흔적을 확인한다.
- 기존32구간 보상·4시나리오 JSON·VERSION과 이전28스토리의 바이트를 검사 기준 커밋과 대조한다. 다른 진행 중 작업의 커밋/게임 변경을 이 문서 작업의 성과로 포함하지 않는다.
