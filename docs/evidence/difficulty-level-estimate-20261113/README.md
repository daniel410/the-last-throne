# 난이도 완주 시 영웅 레벨 추정

2026-11-13 · TLT-027/041/042/050 · PLAN/ENG → 난이도 설계·QA. 상태: 고정 소스 계산 완료, 실제 플레이 미검증. 난이도 수치 변경은 보류한다.

## 기준과 가정

사용자는 적 난이도를 정하기 전에 Easy·Hard·Hell 완주 시 각 영웅 레벨을 추정하도록 요청했다. 헬 입장 선행이 Insane 완료이므로 Insane도 포함한다.

기준 소스는 **2b08e66c37bc16e32e77cf0fbeae91604233af04**, 원정 규칙15다. 다른 작업의 미커밋 Easy 조정(규칙16 후보)은 읽거나 변경하지 않고, Git archive로 별도 /tmp에 추출한 소스로 계산했다. 신규 영웅 Lv1/XP0에서35본편을 Easy → Hard → Insane → Hell 순서로 각1회 완주한다. 새 원정 없이 이어지는 비전투 이야기 단계도 포함한다.

- 필수 본편: `CampaignContent.mainChapters`와 optional이 아닌 목표의 계획된 적·보스/증원/호위를 모두 처치한다. 훈련·과거 계획의 DS 보상, 부활/재생성·추가 반복·부스터·사망 손실은 제외한다.
- Easy는 임무별 최초 고정 XP를1회, 이후 모드는 현재 반복 완주 XP를 지급한다. 처음부터 고정 퀘스트 XP 전체에1.5/2/3배를 곱하지 않는다.
- 처치 XP는 실제 `EncounterSummary`·`DeepwoodEncounterBalance`의 분할/내림 및 난이도 배율을 사용한다. 적 유효 레벨 상승을 기본 처치 XP에 다시 적용하지 않는다.
- 레벨 곡선은 `HeroProgression.xpToNext`의100+25×(현재레벨−1), 최대80이다. 네 직업의 XP 곡선·지급량은 동일하다. 스탯·공격 성능/클리어 시간 차이는 레벨 차이로 자동 환산하지 않는다.
- 참여 자격을 갖춘 영웅1인당 계산이며1인/4인 결과는 같다. 참여 실패·사망/반복이 있으면 달라진다.

## 선택 콘텐츠에 따른 차이

| 경로 | Easy 완료 | Hard 완료 | Insane 완료 | Hell 완료 |
| --- | --- | --- | --- | --- |
| 필수 본편만 | 44 | 62 | 80 | 80 |
| 본편 선택 교전은 매 모드 전부 + 사이드12개는 Easy에서만1회 | 51 | 69 | 80 | 80 |
| 선택 교전·사이드12개를 각 모드 모두1회 | 51 | 73 | 80 | 80 |

이는 지정된 경로별 계산이며 실제 이용자 분포나 반복 파밍까지 포함한 통계적 범위는 아니다. 사망 손실은 빼지 않았으므로 실플레이의 보장 하한도 아니다.

## 난이도 설계에 주는 의미

필수 경로 기준 플레이어 레벨 구간은 Easy1→44, Hard44→62, Insane62→80, Hell80→80이다. 선택 콘텐츠까지 고려하면 Hard 시작은 대략44~51, Insane 시작은62~73 수준을 우선 시험할 수 있다. 이는 설계 검증에 쓸 표본 범위이며 새 입장 레벨 제한이 아니다.

따라서 헬은 추가 레벨 성장보다 Lv80의 장비·강화·스킬/스탯 배분·패턴 숙련을 기준으로 검증해야 한다. 현재 순차 경로에서는 헬 XP3배가 추가 레벨을 올려주지 않는다. 단순 HP/공격력2/3/4배 또는 새 자동 스케일링을 이번 작업에서 적용하지 않았다. 현재 레벨을 따라 적을 올리는 방식은 성장 체감까지 바꾸므로 별도 설계가 필요하다.
