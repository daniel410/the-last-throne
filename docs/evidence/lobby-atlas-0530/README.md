# 로비5에픽 지도0.53.0

TLT-028/061/084 · 2026-10-31

로비 MAPS의 텍스트 목록을 배틀 공용 지형/도로/탐험 안개를 쓰는 지도 화면으로 교체했다. 에픽5개 분류·스크롤·확대/FIT를 제공한다. Deepwood/Frozen Vale/Ember Caldera는 각10지역(본편7/선택3), 미해금 지역 이름/LOCKED 상태와 클릭 시 실제 선행 스토리 조건을 표시한다. 후속2에픽은 LOCKED / COMING SOON이며 미구현 지형을 지어내지 않는다. 선택 영웅의 서버 스냅샷을 읽고 영웅 교체/진행 갱신 시 반영한다. 실제 진행·해금·이동은 변경하지 않는다. [근거/사례](../../research/2026-10-31-lobby-epic-atlas.md).

변경: LobbyAtlas 신규 모듈, LobbyNavigation 연결, 공용 DeepwoodMapCanvas에 지역 집합 필터·내부 도로만 그리기·후반 에픽 본편 번호를 추가한다. 기존 배틀 전체/미니맵 호출과 호환된다.

검증: Studio 실제 GUI 네이티브66개(영웅 미선택·0/7/14/21 스토리 진척·전체30지역·지도 잠금/조건·후속 탭·1000x750/366x756/643x293 패널), 기존 battle atlas91개 통과. 로비 Navigation 생성과 MAPS/Atlas 연결도 확인했다. native.json과 build.json을 따른다.
