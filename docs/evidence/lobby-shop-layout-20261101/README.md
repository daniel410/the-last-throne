# 로비 확장과 아이템 상점 이전

2026-11-01 · TLT-028/061/084 · ENG/DES → QA · 0.58.10 로컬 시험판, 미게시.

사용자 요청에 따라 안뜰을160×160에서200×200studs로 확장했다. 바닥 면적은56.25% 증가한다. 성벽·모서리 탑·투명 안전 경계·서버 로비 허용 범위를 함께 조정하고, 내부 포장과 상점 접근 길을 넓혔다. 스폰과 기존 대장간/다른 시설 위치는 유지한다.

아이템 상점은 로비 상대좌표(47,0,-38)에서(75,0,6)으로 이전했다. 대장간(45,0,6) 오른쪽에 나란히 놓이며 건물 경계 사이8.5studs를 확보한다. Mira도(75,0,11)로 함께 이동하며 공통 시설 좌표를 사용해 상점/상인의 배치가 어긋나지 않게 했다. 기존 영어 간판·TD 외형·서버 상호작용/거래 경로를 재사용한다.

이번 작업은 사용자가 지정한 위치/공간 결함 교정이며 별도 신규 기능 조사 대신 기존 [Dawnspire 시설 조사](../../research/2026-10-30-dawnspire-facilities.md)의 원천과 접근/충돌 수용 기준을 재사용했다. 새로운 외부 비교 주장은 추가하지 않았다.

## 검증

- 로컬 Studio `TheLastThrone-Lobby-0.58.9.rbxlx`의 관련4개 모듈만 교체해 Play에서54개 검사 통과. 원래 파일명은 기존 버전이며 교체 소스는0.58.10이다.
- 실제 생성된200×200 바닥, 원래 스폰, 새 상점/Mira 좌표, 영어 간판, F/거리10 프롬프트, 대장간과 비중첩, 확장된 동쪽 안전벽/성벽, 중앙→상점 동선의 바닥 및 통행 raycast를 확인했다.
- 실제 Studio 화면에서 대장간과 아이템 상점의 인접 배치를 확인했다. 촬영을 위한 카메라/GUI 변경은 일시적이며 게임 소스에 넣지 않는다.
- `git diff --check` 통과. 기존 다른 작업의 미커밋 변경은 커밋/고정 빌드에서 제외한다.

빌드의 정확한 입력 커밋·명령·산출물 해시는 `build.json`을 따른다. Roblox 게시·실기기·실제 구매/판매 회귀·정상 도보 조작은 미검증이다. 다음 담당 QA는 실제 클라이언트에서 새 위치까지 이동해 Mira F 상점 열기와 대장간 접근을 확인한다. 상위 출시 티켓은 완료 처리하지 않는다.
