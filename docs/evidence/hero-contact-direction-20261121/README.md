# 영웅 스킬 명중 방향과 회수 동작

TLT-033/057/059 · 2026-11-21 · 후보 0.115.13

[공식 게임·Roblox 조사](../../research/2026-11-21-hero-contact-direction.md) · [고정 빌드](build.json) · [Studio 결과](studio-results.json)

| 영웅 | 동작과 효과 |
| --- | --- |
| Knight | Driving Thrust가 닿은 뒤 왼 무릎과 골반으로 돌진을 제동한다. 검이 들어가는 방향을 따라 얇고 긴 관통선을 보인다. |
| Dwarf | Hooking Chop 타격 직후 팔꿈치와 몸통을 접어 도끼를 당긴다. Returning Echo와 Crosscut Axe는 돌아오는 도끼의 방향으로 명중을 표현한다. 폭탄은 확정된 폭발 중심에서 바깥으로 타격을 내고, 포격은 적의 상체 위에서 탄착과 무게를 표현한다. |
| Elf | Heavy Draw는 서버의 발사 이벤트를 받은 뒤 시위를 놓고 앞무릎으로 반동을 받는다. 같은 발사 확인을 전직 단발에도 적용했다. Spirit Arrowfall과 다른 화살비는 머리 위에 짧고 좁은 화살 획을 남긴다. |
| Mage | Frost Lance는 전방을 짚고 나서 유도 팔을 짧게 접는다. Chain Lightning은 직전 표적에서 다음 표적으로 이어지고 Gravity 범위의 적은 중심으로 당겨진다. Ashfall은 위로 흩어지는 불씨, Hailfall은 아래로 떨어지는 얼음 획을 그린다. |

서버가 확인한 피해 이벤트의 경로·펄스가 피격 방향과 강세를 결정한다. 기존에 마지막 박자가 제작된 여덟 연속기는 마지막 타격의 적 반응 강도 1.25배와 명중 크기 1.2배를 적용한다. 아군 낙하 명중은 짧은 획 하나를 사용하고 피해 숫자를 표시한다. 서버 피해·범위·타격 간격·성장 계약은 동일하다.

## 전후 비교

- [네 영웅의 회수 자세](hero-follow-through.jpg) · 동일 R15 검토 리그, 카메라와 위치에서 기존 0.115.11과 후보 0.115.13의 명중 후 약 55~80ms 자세를 비교했다. 고정 프레임에서 Driving Thrust와 Heavy Draw의 왼 무릎은 각각 10°, Hooking Chop의 오른 팔꿈치는 23°, Frost Lance의 왼 팔꿈치는 24° 더 접힌다.
- [대표 낙하 기술의 마지막 명중](hero-descending-contact.jpg) · 같은 표적 리그와 조명에서 착탄 뒤 약 45ms에 효과를 비교했다. 연속 전투의 효과 밀도와 입력 반응은 실시간 세션에서 검증한다.
- [0.115.12](build-0.115.12.json)에서는 고정 높이에 생성한 명중 획이 표적 머리에 가려졌다. 0.115.13은 기존 몬스터 외형 높이와 리그 높이를 읽어 명중 획을 실루엣 위에 둔다. 낙하 스킬에 대해서는 피격 효과 높이와 별도로 피해 숫자 높이를 보정한다.

## 검증과 인계

- `tests/hero-skill-impact-native.luau`는 128개 스킬의 확인된 타격, 낙하 방향과 마지막 타격 크기, 실제 몬스터 외형 높이, 연쇄·폭발·귀환 방향을 검사한다. 4인 겹침 표본의 적 붉은 예고 선분 16개와 피해 숫자를 검사에 포함했다.
- 고정 Place의 Studio 묶음 검사에서 29개 묶음 281,455건을 통과했다. Gunner 묶음은 Edit 모드 일괄 실행에서 Shrapnel Toss의 첫 0.22초 비행 구간을 놓쳤다. 기준과 후보에서 같은 순서로 재현했을 때 검사가 각각 착탄보다 약 365ms, 381ms 늦게 깨어났다. 최종 후보에서 Studio Run을 시작하고 0.7초를 기다린 뒤 Gunner 묶음을 단독 재실행해 180건을 통과했다.
- 정적·CPU 검증에서 고정 빌드의 역할·로딩 336건, 전직 스킬 데이터 1,435건, 스킬 형상·취소·펄스 14,026건을 통과했다. 별도 `skill-action-interrupt.spec.lua`는 두 버전에서 동일하게 스텁 `TargetAssistRules` 누락으로 실행을 중단했다.
- 실서버 게시, 실제 4인 클라이언트, 저사양 터치 기기의 프레임 시간, 사용자 타격감 수용은 미검증이다. 전투 QA는 일반 플레이 카메라에서 아군 연속 스킬과 적 붉은 예고가 겹치는 장면을 확인한다.
