# 네 영웅의 준비 차단과 무기별 명중

2026-11-23 · TLT-033/057/059 · 기준 0.115.67 · 후보 0.115.69

| 영웅 | 기술 | 동작과 일반 명중 |
| --- | --- | --- |
| Knight | Challenging Strike | 방패로 먼저 진입한 뒤 앞무릎으로 검격을 받는다. 두 강철 획이 피격면에서 위로 비스듬히 열린다. |
| Dwarf | Mountain Sweep | 뒤꿈치에 하중을 싣고 빈손으로 균형을 잡은 뒤 앞발로 낮은 도끼 회전을 멈춘다. 지면 가까이 흙빛 두 획이 퍼진다. |
| Elf | Precision Volley | 조준점을 유지하면서 세 번의 시위 회수와 마지막 앞무릎 고정을 구분했다. 두 가는 화살 획이 첫 피격면으로 모인다. |
| Mage | Flame Dart | 지팡이 가까이 불씨를 모아 빈손을 짧게 털고 팔꿈치를 편다. 피격면의 두 불꽃이 위쪽으로 말려 올라간다. |

서버가 기존 판정으로 일반 적의 공격 준비나 무리의 지원 시전을 취소한 적중에 차단 결과를 실어 보낸다. 영웅·속성별 차단 획 두 개는 피격 방향을 기준으로 190ms 동안 바깥으로 벌어진다. 아군 화면에도 같은 주 형상을 사용한다. 자세 붕괴나 표식 효과가 겹치면 기존 상태 표현이 우선한다. 피해 숫자와 상태 전이는 기존 경로를 사용한다. [공식 사례 조사](../../research/2026-11-23-hero-windup-interrupt.md)

## 검증

- Rojo 7.7.1 단일 Place의 SHA-256과 변경 런타임 모듈 5개를 각 입력 커밋에 대조했다. 후보 검사는 식별용 Folder만 추가한 로컬 사본에서 실행했다. [고정 빌드 기록](build.json)
- 같은 R15 리그, 카메라, 무기와 조명에서 기존 차단 명중, 후보의 일반 명중, 후보의 차단 명중을 비교했다. 효과를 비교할 때 피해 숫자 레이어를 숨겼다. 0.115.68에서 기사의 팔에 차단 획이 가려졌다. 0.115.69에서 획을 올리고 폭과 벌어지는 움직임을 보강했다. [Studio 비교 화면](comparison.jpg)
- 차단 전용 검사는 실제 서버 모듈의 피해 처리와 클라이언트 명중 경로를 연결했다. 공격 준비 경계, 지원 시전, 지연 샘플, 중복 처리, 면역·흡수·처치 타격, 피해 숫자, 표식과 자세 붕괴의 우선순위, 양쪽 화면의 효과 예산 및 회수 자세를 확인했다. [재현 코드](../../../tests/hero-windup-interrupt-native.luau)
- 신규 217건을 포함해 Studio 15묶음 266,564건을 통과했다. 기준에서는 실행된 253개 조건 중 205개가 새 연출 기준을 충족하지 않았다. Studio 검사에는 R6·R15의 128개 스킬, 네 영웅의 동시 이펙트와 적의 붉은 예고선 16개, 엘프의 확정 발사, 몬스터 584개 공격 사례가 포함된다. 전직·스킬·몬스터 CPU 75,570건과 고정 빌드 정적 336건을 통과했다. 격리 Studio 실행기는 검토용 세션을 종료했다. 별도 순수 Lua 자세 검사는 기존 Luau 복합 대입 문법에서 중단됐다. 자세는 Studio에서 검증했다.
