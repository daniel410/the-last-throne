# 아이템·다이아 구매 리뷰

2026-11-25 · TLT-041 / TLT-049 / TLT-084 / TLT-088 · ENG → QA

## 결함과 수정

- 구매 확인 중 가격 조회나 계정 갱신으로 카드가 다시 그려지면 확인이 사라졌다. 같은 영웅과 같은 계정 리비전의 갱신에서는 확인한 상품을 유지한다. 영웅, 계정 리비전, 상점 구분 또는 구매·판매 탭이 바뀌거나 창을 닫으면 다시 확인한다. 계정이나 지갑을 읽을 수 없을 때는 거래 버튼을 비활성화한다.
- 상점 상태 조회가 진행 중 거래의 메시지를 지울 수 있었다. 거래 요청 ID가 맞는 응답만 진행 상태를 바꾼다. 저장 응답이 불명이면 같은 ID로 재시도하고, 계정 세션 소유권을 잃은 경우에는 재접속해 지갑과 아이템을 확인하도록 안내한다.
- Robux 영수증 처리가 계정 로드나 다른 저장과 겹치면 Roblox의 다음 전달 기회까지 지급이 보류됐다. 서버 콜백은 플레이어가 연결된 동안 일시적 Busy·SaveUnknown을 최대 130초 범위에서 재시도한다. 서로 다른 구매는 각각의 구매 ID로 확인한다. 계정 키에 Diamonds와 영수증을 함께 저장한 결과가 확인되면 Roblox에 지급을 확정한다. [Roblox 영수증 콜백 규칙](https://create.roblox.com/docs/reference/engine/classes/MarketplaceService#ProcessReceipt)
- 다이아 상품은 가격 갱신 중 이전 가격으로 결제창을 열 수 없으며 창을 닫은 알림은 결제 성공을 선언하지 않는다. 잔액은 서버 지갑 스냅샷에서 갱신한다.

- Lua 모의 저장·콜백 검사. 기본 구매, 잔액 부족, 중복 요청, 응답 유실, 별도 영수증 처리, 재접속 후 재전달과 이전 서버의 쓰기 차단을 확인했다. 구형 장비 가격과 판매 목록을 기대하던 테스트는 현재 카탈로그 기준으로 갱신했다.
