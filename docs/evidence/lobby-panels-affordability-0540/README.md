# 로비 창 크기·상점 잔액 표시 0.54.0

TLT-028/031/043/046/061/084 · 2026-10-31

로비 HEROES, BLACKSMITH, ITEM SHOP, DIAMOND SHOP, QUEST/MAPS, ADVENTURES, GEAR & BAG, STATS & SKILLS, SETTINGS와 미수령 팝업은 동일한 최대800×510 및 화면 기준 배치를 사용한다. 화면 높이400 미만에서는 공통 여백을 줄여 내용 공간을 확보한다. 상점은 작은 화면에서 머리글과 목록의 간격을 줄여 카테고리·스크롤 영역을 남긴다. 영웅/가방/성장/설정의 전투 화면 원래 크기는 세션 단계 전환 시 복원한다.

구매 상품의 잔액이 가격보다 적으면 원래 가격과 필요한 추가 Gold/Diamonds를 표시하고 구매 버튼을 비활성화한다. 잔액 스냅샷에 따라 즉시 재계산하며, 잔액 정보가 없을 때 0이라고 단정하지 않는다. 가격·상품·서버 권위 거래/저장 계약은 바꾸지 않는다. [비교/근거](../../research/2026-10-31-lobby-panels-affordability.md).

검증: 최종 빌드의 Studio 네이티브 GUI에서 HEROES와 각 창의 크기/배치·세 화면·전투 단계 복원88개와 Gold/다이아 잔액·가격11개가 통과했다. 같은 소스의 사전 Studio 회귀는 상점68·지도66·설정50개 통과, 서버 경제/물약/대장간 검사는42·170·181개 통과했다. 확정 결과는 native.json, 고정 소스 빌드/해시는 build.json에 기록한다.

미검증: 게시 클라이언트·실기기/컨트롤러 입력 및 사용자 시각 수용. 미게시·릴리스 태그 없음. 기존 다른 작업의 미커밋 파일은 제외한다. 다음 담당자는 QA다.
