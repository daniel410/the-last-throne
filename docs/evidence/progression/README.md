## 최신 결과

이 기록의 대상 로컬 빌드는 **0.24.1**, 입력 소스 `036809b8bf437b9e007b62f99e0d31a231f87463`이다. Roblox 게시·릴리스 태그 생성은 수행하지 않았다. 현재 확인된 게시판은0.18.3이다.

최신 사용자 결정은 **Lv1 Knight HP250 / Dwarf HP200 / Elf HP150 / Mage HP100·MP100**이다. 이전300/250/200/150HP 지시와0.23.x의 시작값을 대체한다. Lv80 궁극기는 기존5칸 중 하나에 편성한다는 사용자 응답을 반영했다.

- 서버 XP·Lv1~80·스탯4P/레벨·별도 스킬1SP/레벨, 스탯 투자·기술 숙련·전투 편성·전직 단계를 구현했다. Lv80 예산은316P/79SP다. 초안 취소는 무료지만 확정 투자 환급/계열 무료 변경은 제공하지 않는다.
- 공통12개 + 8계열×(액티브12+궁극기1) = **정의116개**다. 선택 경로는 기본3+추가12+궁극기1=16개이며 기본3슬롯→첫 전직4→두 번째 전직5다. 이 수는216개 강화 노드 전체의 완성이나 각 기술의 최종 모션·미술 수용 수가 아니다.
- H/HERO의 TD 초상·은색/금색 프레임·공유 TD 아이콘, STATS/SKILLS/ADVANCE, 전직 단계별 기술 필터, 직접 EQUIP→대상 슬롯, 잠금 사유·숙련·현재/다음 효과·저장/같은 요청 재시도를 제공한다. B/BAG와 상호 닫힘 및 메뉴 중 전투/이동 입력 차단을 연결했다.
- 계열 기술은 실제 서버 판정으로 연속 타격·부채꼴·직선 관통·범위/지연 펄스·연쇄·안전 이동·자기/근처 아군 보호·개인 소유 표식 생성/소비·감속/일반 적 도발을 처리한다. Ogre는 신규 강제 감속/밀기/도발을 받지 않지만 피해·자세 피해는 받는다. Gunner 총·폭탄·포격은 서로 선행 발동·표식 연계 없이 독립 사용한다. 임시 총/폭탄/포구와 지점 예고·경로·범위 효과는 코드 원형이다.

## 원천과 시험값

최신 [결정표](../../decisions.md), [강철기사](../../production/steel-knight-root-tree-2026-10-29.md), [성기사](../../production/paladin-root-tree-2026-10-29.md), [나머지6계열](../../production/dwarf-elf-mage-skill-trees-2026-10-29.md), [기본 숙련](../../production/hero-skill-progression-design.md), 승인 v2 영웅/스킬 화면과 기존 TD 아틀라스를 따른다. 새 자산 업로드나 TD 소스/자산 수정은 없다. 생성 컨셉의 글자·수치를 추출하지 않았다.

다음은 **사용자가 확정한 시작 HP·MP/포인트 예산과 구분하는 시험값**이다.

| 클래스 | 기본 STR/DEX/INT/VIT | 레벨당 자동 HP |
| --- | --- | ---: |
| Knight |12/6/4/12|15|
| Dwarf |11/7/4/10|13|
| Elf |6/12/6/8|10|
| Mage |4/6/14/6|8|

투자 VIT당 HP+10·투자 VIT4당 방어+1, 기본 Power100·레벨당+3·주 스탯 투자당+2다. 물리 Power는 Elf DEX/나머지 STR, 마법 Power는 INT다. 이번 시험의 Mage 지팡이 기본기는 마법 Power로 계산하고 자원은 소비하지 않는다. Mage MP는100+레벨당4+투자INT당3, 마법궁수는 첫 전직 후80+(Lv-20)×3+투자INT×3이다. 장비 HP/방어는 합산, Power는 기존 백분율 보너스를 유지한다. 당시에는 최대 자원 증가가 현재 HP/MP를 자동 충전하지 않았다. 최신 사용자 지시를 반영한0.25.0부터 **레벨업만 HP/MP 완충**하며 같은 레벨의 장비/스탯 갱신은 보존한다. [최신 기록](../battle-hud/levelup-and-bag-0.25.1.md).

기본 숙련은 기존 설계의 기술별 피해/자세/도발·감속 지속 보강이다. 계열 숙련은 현재 기술 기본 피해+4%/랭크·최대3랭크·랭크당1SP의 시험값이다. 기술 획득은 무료이며 기본3은 현재 원형처럼 즉시 제공한다. 중간 획득 레벨·효과·범위·피해·MP·쿨다운·가칭 명칭·마법궁수 MP·계열 숙련/전직 시험 수치는 최종 밸런스 승인값이 아니다.

전직은 **Lv20/40/60/80 + 이전 단계 + 누적 훈련 적 처치3/6/9/12 + Dawnspire에서 명시적 완료**라는 초기 시험이다. 정식 이야기/전직 퀘스트를 구현했다고 보고하지 않는다. 최초 계열은 저장하고 무료 전환은 막는다. 늦게 완료하면 이미 도달한 중간 기술도 조건 계산으로 복구한다. 레벨만으로 전직/슬롯/궁극기를 주지 않는다. Pyro 대지와 Cryo 번개는 Lv40 단계부터다.

XP는 승인 보상 정본의 `100+25×(Lv-1)` 곡선과 일반 적 `8+2×enemyLevel`을 따른다. 훈련 적 레벨 Slime1/Goblin2/Orc4/Ogre8은 시험 매핑이며 Ogre는 여기서 보스 배수를 사용하지 않는다. 분열 자식은 XP/시험 처치를 추가 지급하지 않는다. 마지막 서버 유효 공격자에게 지급하며 정식 파티 기여 배분·이야기/Coins 보상은 미연결이다. 승인 스토리 XP JSON은 수정하지 않았다.

## 저장·권한

기존 RPG 전용 계정 키·스키마1·lease/epoch 안에 영웅 `progression.version=2`를 추가했다. 기존 무성장/v1 성장은 아이템·소유권·레벨·투자를 보존해 이관한다. 별도 교차 키 거래를 만들지 않는다. Studio는 명시적 메모리 세션 어댑터, 실제 RPG는 기존 `TLT_RPG_Accounts_v1_Test` 경로다. 로드 실패를 신규 데이터로 덮어쓰지 않는다.

클라이언트는 선택 영웅·예상 계정 revision·요청ID와 투자/편성/전직 의도만 보낸다. `AwardXP`·레벨·금액·임의 해금은 RemoteEvent 허용 목록에 없다. 서버는 소유·원형 클래스·계열·단계·레벨·남은 예산·안전한 거점/생명 세대를 검사한다. 같은 작업ID의 다른 본문은 충돌로 처리한다. 같은 요청 재시도는 저장 영수증을 재조회하고 SP/전직을 중복 소비/완료하지 않는다.

XP는 서버 스트림별 순번 high-water cursor로 중복을 막으며 아이템 영수증96개가 퇴거돼도 재지급하지 않는다. 계정 fence가 이전 서버의 스트림 변경을 막는다. 미확정 쓰기는 동일 명령을 유지해 재시도하고 권한을 닫는다. 정상 퇴장 시 최대10초 큐 배출을 시도한다. **전투 이벤트와 DataStore의 원자 커밋은 아니므로 쓰기 전 서버 종료/장기 장애의 미기록 XP까지 보장하지 않는다.** 게시 저장·쓰기량·서버 경합 수용은 후속이다. 쿨다운은 고유 스킬ID로 세션 내 로비·재소환을 거쳐 유지하며 접속 종료를 넘어 저장하지 않는다.
