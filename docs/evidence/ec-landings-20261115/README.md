# Caldera 연결 경사의 보행면 단차 수정

2026-11-15 · TLT-063 · 맵 구현/ENG → QA · 로컬 구현·미게시

기존 [접근로 검증](../route-blockers-20261115/results.json)에 남은 EC-04→05·EC-05→06의 약1.30stud 단차를 수정했다. 두 접합부에서 겹친 바닥3개씩 총6파트가 검출되던 결함이며6개의 독립 장소가 아니다. 별도 작업 트리/인덱스에서 수정했다. 기존 공유 작업 트리와 동시 작업의 미커밋 변경은 수정/스테이징하지 않았다.

## 원인과 변경

기울어진 연결 바닥이 평평한 지역 사각형과 비스듬히 만난다. 경로 중앙의 좌우4stud 표본은 서로 다른 위치에서 지역 바닥을 만나므로, 평면 경사의 끝 높이만 맞추면 높은 쪽 입구에 턱이 남았다. 교체 전 `CalderaTrail_*`은 foundation 모델 안에 있는데 기존 충돌 은퇴 처리는 terrain의 직속 자식만 확인해 이들 역시 충돌이 남아 있었다.

`CampaignCombatRouteWorld`에서 Ember Caldera의 높이 차가 있는6연결부에 짧은 평탄 접근부→중간 경사→평탄 도착부를 만든다. 평탄 구간은 연결부 길이의20%, 최대10stud다. 세 보행면은 같은 재질·96stud 폭과 끝점 높이를 사용하며 이어지는 바닥을1stud씩 겹친다. 총12파트가 추가되고, 다른 지역의 연결 형상은 유지한다. 이전 Caldera 연결 바닥은 파괴하지 않고 숨김/충돌·쿼리 해제로 은퇴시킨다. 바닥·경계·목표를 통째로 비충돌로 바꿔 통과시키지 않는다.

공식 스토리 좌표·지역 높이·서버 Bounds/통행 자격·퀘스트/보상/저장은 바꾸지 않는다. 별도 새 에픽/지물/상품/TD 원본/외부 자산·프레임 루프를 추가하지 않는다. 기존 이동 차단 후속의 명확한 결함 수정이므로 별도 게임성 리서치는 필요하지 않았다. 전체 미술 재제작 또는 G5 완료와 구별한다.

## 검증

```bash
python3 tools/build-game.py --source dbbf9ccc --record /tmp/ec-landings-build.json
python3 tools/prepare-ec-landing-native.py
run-in-roblox --place builds/0.108.1/TheLastThrone-0.108.1.rbxlx --script /tmp/tlt-ec-landing-native.luau
```

검사기는 변경된 런타임 모듈의 바이트 일치와 전체 Luau 컴파일을 먼저 확인하고, 고정 빌드에 소스를 주입하지 않는다. GW/FV/EC/HG4지역 이동 sweep을 기존 `points`/Easy `worldPoints` 각각으로 실행한다. 차단·바닥·보정·안내 실패에 더해 `lowSteps`도0을 요구한다. 기존 전후 판정 기준을 완화하지 않았다. 이어 실제 R15가 문제의 두 연결부를 양방향으로 이동하며 점프/서버 위치 보정 없이 도착하는지 검사한다. 모든 기하 검사를 끝낸 뒤 Run/Stop 물리 검사를 실행한다.

최종 기존/Easy 두 sweep 모두 단차 검출0·차단0·바닥0·보정0·안내 실패0이었다. 실제 R15왕복4조건이 모두 도착했고 점프/보정0, 각 이동은 약24.1~24.3초였다. 원고1,054·전투 동선77,381·정적 안내106,051검사도 통과했다.

대표 건축·생활 구성·양수 고체 충돌·교전 바닥·FV-03 지형/조명/길 마감 회귀도 함께 실행한다. 이번 변경은 작은 보행면 결함 수정이며 검사 대상이 중앙 경로/좌우4stud 표본이라는 한계가 있다.96stud 폭 전체의 모든 비스듬한 횡단이나 기기별 회피/카메라 수용으로 확대 해석하지 않는다.
