# 0.107.7 최신 소스 재빌드

2026-11-14 · TLT-084 · ENG → QA

사용자 빌드 요청에 따라 `VERSION`을0.107.6→0.107.7로 증가했다. 버전만 변경한 입력 커밋 `56e7322059853458c45dcff16686d2649a32dead`을 먼저 커밋·푸시하고 해당 트리에서 단일 로비/배틀 파일을 생성했다. 기존 미커밋 자산 변경은 보존하고 빌드에 포함하지 않았다.

- 명령: `python3 tools/build-game.py --source 56e7322059853458c45dcff16686d2649a32dead --record docs/evidence/build-0.107.7-20261114/build.json`
- 산출물: `builds/0.107.7/TheLastThrone-0.107.7.rbxlx` ·19,551,901바이트.
- [입력·명령·SHA-256 기록](build.json), [무결성 검증](verification.json).
- Rojo 7.7.1 종료0·XML 파싱·SHA-256 일치 통과. 실행 스크립트 492개이며 이전0.107.6 산출물과 전체 바이트가 동일하다. 이번 재빌드는 게임 코드 변경 없이 버전/산출물 경로·기록만 갱신한다.
- 동일한 이전 산출물의 [파란 크리스탈 왕좌 고정 빌드·엔진 검증](../dawnspire-blue-throne-20261114/README.md)을 참조한다. 이번 빌드의 Studio 재실행·게시 클라이언트·실기기·사용자 수용은 미검증이다.
