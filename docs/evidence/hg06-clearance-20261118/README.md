HG-06은 왕릉 수비대와 Lich Sovereign을 저지한 뒤 봉인을 열고 귀환로를 확보하는 장이다. 이전 HG-05 후보 장면에서 발견한 봉인 접근 차단을 최신 소스의 깨끗한 장면으로 재현했다. 이번 실행은 결함 재현·수용 근거 보강이며 신규 미술 구현이나 신규 게임성 설계가 아니다. 별도 게임 리서치는 하지 않았다.
