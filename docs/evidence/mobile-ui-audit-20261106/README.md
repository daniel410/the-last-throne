# 모바일 UI 겹침·가용 공간 검사와 수정

2026-11-06 · TLT-028/031/052/057/084 · ENG/DES → QA · 0.79.7 · 로컬 수정·미게시. 부모 티켓 In Progress.

사용자 요청에 따라 로비/배틀의 주요 UI를 가용 GUI 1280×591·844×390·750×323·750×280·568×320·390×844·320×568에서 검사한다. 이미지 해상도와 기기 논리 해상도를 동일시하지 않는다. 실제 TD 원본 프레임·버튼·영웅 초상·아이콘을 유지하고, 저장/구매/스킬 자격·서버 가격/보상은 변경하지 않는다. 명확한 겹침/잘림 결함 수정으로 제작 스킬의 별도 사례 리서치 예외를 적용한다. 기존 [맵/장비 높이 설계](../../production/mobile-map-gear-height-2026-11-05.md)를 참고하며 지도 높이65% 등의 제안 수치를 모든 기기 수용 완료로 선언하지 않는다.

## 변경

- 작은 세로 화면의 공통 로비 패널에 좌우120px 대신24px 여백을 적용해 내용 폭을 확보한다. Heroes의 저장 안내가 닫기를 침범하지 않게 하고 선택 버튼44px을 유지한다.
- 영웅 능력치 가로 화면은 큰 초상 대신 작은 초상/왼쪽 분류를 쓰고, 높이가 더 낮으면 분류를2×2로 배치한다. Gear/Skills의 빈 하단 예약을 없애 8장비 슬롯과 이름 두 행이 처음부터 보이도록 한다. 568px 가로에서도 이 배치를 사용한다. `Hero saved.`만2초 후 해제하고 저장 중/실패/응답불명은 보존한다.
- 가방은568px 가로에서도 헤더를 한 줄로 만들고 목록 헤더를 압축한다. 장비/아이템 상세에서 불필요한 분류를 숨겨 내용 높이를 돌려준다. 가방 한 행 전체·8슬롯·상세 설명을 검사한다.
- 배틀 지도는 낮은 화면에서44px 도구행·현재 지역 선택 버튼과 펼침 목록을 사용해 지도 높이를 확보한다. 모든5에픽·FIT/확대/현재 위치·길 안내·체크포인트 이동은 유지한다. 지역 목록은 선택 후 닫고, 확대/선택/안전 영역에 따라 재배치한다. 기존28px 지점 선택 영역을44px로 늘린다.
- 로비 지도는 낮은 가로 화면에 지역 목록과 조작부를 옆으로 옮기고, 작은 화면은 처음부터 전체 지도를 맞춰 표시한다. 세로에서는44px 조작행을 쓰고 긴 잠금 설명 높이를 측정해 확보한다.
- 원정의 낮은 가로 화면은 난이도를 왼쪽으로 옮겨 내용 목록이0에 가까워지는 현상을 수정한다. 목록·안내·출발 버튼을 분리하고 난이도/탭44px을 확보한다.
- 설정의 제목/닫기 겹침을 제거하고 설명·안내·각 옵션 행 높이를 실제 영어 줄바꿈으로 계산한다. 대장간의 좁은 세로 화면은 제목·도움말·거래 탭을 서로 다른 행에 둔다.
- Selene 지원권은 좁은 세로 화면에서3구매 버튼을 세로로 표시하고, 낮은 가로 화면은 이름/역할을 헤더 옆으로 옮겨 필수 약관과 상세 목록을 확보한다. 구매 조건/가격/수량은 유지한다.
- 완료 안내는 카메라 전체 크기 대신 부모 GUI의 실제 가용 크기를 사용하고 긴 제목 높이를 측정해 닫기·본문과 분리한다.
- 배틀 터치 액션은 최소44px을 확보한다. 좁은 가로는 스킬2행, 세로는3열로 배치하고 이동 손가락 영역 위로 올린다. 미니맵의 펼침 메뉴는 축소를 상쇄해 원래 크기/터치 목표를 유지하며, 화면이 낮으면 미니맵 왼쪽에 표시한다. 원래 메뉴/지도 버튼도44px 이상으로 확보한다.
- UI 재생성 후 이전 메뉴 이벤트가 남아 파괴된 퀘스트/Heroes를 호출하지 않도록 해당 연결을 해제한다.

## 검증 범위와 재현

`tests/mobile-ui-audit-native.luau`는 실제 GUI 생성자를 사용하며 LocalPlayer/서버 상태만 fixture로 대체한다. 경계·명시적 형제 간 겹침·영어 줄바꿈·터치 목표·지도/목록 최소 공간·5에픽 전환을 검사하고 구매/저장/이동 요청은 보내지 않는다. 조상 스크롤 안의 모든 자식이 첫 화면에 있어야 한다고 가정하지 않고, 장비 두 행처럼 처음부터 보여야 하는 항목과 스크롤로 접근하는 항목을 구분한다. 실제 입력/전체 가림 판정/기기 렌더·성능 수용을 대신하지 않는다.

기준0.79.6에 새 검사(새 지역 버튼 존재 검사는 제외)를 적용하면2444조건 중243조건이 실패했다([기준 로그](before-native.log)). 조건 수는 같은 현상의 기기/상태 반복을 포함하며 고유 결함243개를 뜻하지 않는다. 제목/닫기 겹침·영어 높이 부족·작은 지도/원정 목록·작은 터치 버튼 등을 재현했다.

기존 검사 중 `diamond-gold-exchange-ui-native`의 폐기된 forged 무기 판매 기대, `k0-resource-ui-native`의 과거 피드백 배경 투명도 기대, `skill-stat-ui-native`의 과거 무기10% 기대는 변경 전0.79.6에서도 동일하게 실패했다([기준 로그](before-native.log)). 이 작업에서 상품/장비/피드백 디자인 값을 옛 기대에 맞춰 바꾸지 않으며 이3개 전체 검사를 PASS로 계산하지 않는다. 실제 수정 경로는 새 전용 검사와 관련 GUI 검사로 검증한다. 이전 실행에서 발견한 ReturningLobby의 런처 기대는 현행 로딩 중 숨김 계약에 맞춰 수정했다.

재현 명령:

```sh
python3 tools/assemble-mobile-ui-audit.py --output /tmp/tlt-mobile-ui-suite.luau
run-in-roblox --place builds/0.79.7/TheLastThrone-0.79.7.rbxlx --script /tmp/tlt-mobile-ui-suite.luau
python3 tests/single-build.spec.py --artifact builds/0.79.7/TheLastThrone-0.79.7.rbxlx
```

최종 소스/고정 빌드 결과는 후속 기록한다. 후보의 기존13개 GUI 검사와 체크포인트25조건은 통과([후보 로그](candidate-regressions.log)); 이후 추가한 미니맵 검사도 최종 빌드에서 확인한다. Studio에서 기존203785492 asset-type 경고가 발생했으며 이미지 권한/실기기 시각 수용으로 보고하지 않는다.

미검증: 실제 휴대폰 터치·회전/노치·OS별 렌더·최종 시각수용, 게시된 테스트 클라이언트, 모든 월드 상황/8인/장시간 성능. QA는 새 빌드에서 각 창 열기/닫기→마지막 스크롤 항목→가로/세로 전환·초안 보존·실제 터치와 배경 입력 차단을 확인한다. Roblox 게시/릴리스 태그는 수행하지 않는다. 기존 사용자 Blender/미추적 자산/첨부는 보존하고 커밋에서 제외한다.
