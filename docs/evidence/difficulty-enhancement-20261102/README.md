# 4단계 난이도·원정 반복 보상·장비 강화 구현

2026-11-02 · TLT-027/028/029/041/043/044/045/052/061/073/082/084 · ENG/DES → QA · 0.62.0 로컬 시험판·미게시

## 구현 범위

- 현재 제작된 Deepwood/Frozen Vale/Ember Caldera의 임무 선택과 Easy/Hard/Insane/Hell을 기존 TD 모험 상세창에 연결했다. Easy 최소Lv1(Deepwood 첫 임무1), 나머지20/40/80과 임무별 하한·개인 이야기/이전 난이도 완료를 서버에서 검사한다. 미제작 후반2에픽을 새로 구현했다고 보고하지 않는다.
- 리더의 임무/모드 변경·영웅/레벨/진행 변경 시 준비 상태를 무효화한다. 파티 전원 자격을 재검사하고 서버 원정 레코드/계정 활성 원정에 missionId/difficultyId/runId/rulesVersion을 고정한다. Battle 도착 때 동일 기록과 자격을 대조하고 다른 규칙 버전/구형 원정은 입장을 거부한다.
- 최초 이야기는 기존 개인 진행/초회 보상을 사용한다. 재도전은 별도 저장된 원정 저널을 사용해 원본 이야기·선택·Diamonds 권리를 보존한다. 같은 원정 재요청은 중복 지급하지 않으며 새 원정을 완주하면 반복Gold/재료/장비 상자 진도를 다시 지급한다. 처치 보상도 원정별 적ID로 중복을 막는다. 기본 교전 처치XP/Gold 예산은 보존한다.
- Hell은 횟수 제한 없이 반복한다. Lv80에서도 반복Gold3배·광석12·코어3·상자 진도4를 지급한다. 완료 후 PLAY AGAIN으로 로비에 돌아가 같은 임무/난이도의 준비창을 연다. 실서버 파티는 기존 방식대로 로비에서 다시 모이고 준비한다. XP는80 상한을 유지한다.
- 임무별 하한은 현재 Lv1 시작 필수 전투/보상을 계산해 정상 경로가 막히지 않도록 조정했다. 예: DW-02는 계획 초안Lv5 대신 실제 필수 경로 도달Lv3, Frozen Vale 첫 임무12·Ember Caldera 첫 임무20이다. 승인XP는 바꾸지 않았다.
- 난이도는 적 기본 공식에 한 번 적용하고 전투용 적 레벨과 보상용 원래 레벨을 분리한다. Insane에는 선두 Armored, Hell에는 Armored/Empowered 정예와 보스HP15% 이후 추가 경고 지면 공격을 시험 적용한다. 최종 재미/밸런스 수용이 아니다.
- 대장간 ENHANCE에서 강화(+1~+10 계산·성공100%·하락/파괴 없음), 실제 투입 재료80% 회수, 광석5+50Gold→코어1 교환, 장비 상자 선택을 제공한다. Gold/재료/아이템 단계/원장은 기존 단일 계정 거래와 함께 저장한다. 부족·잠금·타인/창고 장비·낡은 버전·동일 요청 충돌은 거부한다. 공간 부족 시 보상/상자는 미수령으로 보내며 회수는 가방 공간을 요구한다.
- 강화 결과는 서버 장착 능력치, 가방 이름/비교, 영웅 장비별 기여도에 반영한다. 기본 장비 정의에 덮어쓰거나 최종 영웅 공격력에30%를 다시 곱하지 않는다. 현재 제작된 Lv1/5 장비는+3, Lv10 장비는+5 상한이다. +7/+9/+10은 향후 해당 레벨 장비가 정의될 때 같은 공식이 적용된다. 무능력치 훈련 무기는 강화 불가다.
- 현재 획득 장비군에 맞춰 Lv1/5/10 선택 상자를 제공한다. 모드가 높다고 없는 Lv80 장비를 생성하지 않는다. 신규 Forge Core와 상자는 자료형/영어 문구를 추가했으며 전용 신규 미술 원본은 제작하지 않았다.

- 소스/버전 커밋을 고정한 Lobby/Battle Rojo 빌드 결과·해시는 별도 `build.json`에 기록한다. 새 이미지/3D/LFS 전송 대상은 없다. 일반 로컬 시험 빌드이므로 릴리스 태그/Roblox 게시를 하지 않는다.

## 한계·운영·다음 담당

게시된 테스트 클라이언트의 실제 입장/왕복/재접속·DataStore 동시 서버/불명 응답, 네 클래스의 정상 성장·유료/무료 경로·4인+AI1·실기기 성능/입력·최종 난이도/경제/미술 수용은 미검증이다. 모드 하한20/40/80과 재료/계수는 계획의 시험값을 구현한 것이며 최종 밸런스 확정이 아니다. 고레벨 장비·후반2에픽·Lv41~80 본편 성장 정본은 이번 구현에 포함하지 않는다.

기존 진행 중이던 TD 이동/모델/로비 장착 표시 변경은 별도로 보존하며 이 작업의 커밋/고정 빌드에 무단 포함하지 않는다. 새 데이터는 계정 스키마1에 선택 필드로 추가해 기존 프로필을 그대로 읽는다. 단, 새 강화/원정 데이터를 모르는 구버전 writer로 롤백하지 말고 호환 리더를 유지한 채 UI 진입/출발을 차단해야 한다. 초기화로 저장 실패를 덮지 않는다.

다음은 QA가 고정 빌드의 게시 클라이언트·기기·다인 수용을 수행하고, PLAN이 성공률/시간당 순보상·Lv40~80 장비/경제 수급을 관측해 조정한다. 상위 티켓 전체를 완료 처리하지 않는다.
