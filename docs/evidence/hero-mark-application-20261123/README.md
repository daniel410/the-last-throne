# 네 영웅의 표식 부여 공격 개선

2026-11-23 · TLT-033/057/059 · 기준 0.115.56 · 로컬 후보 0.115.57

| 영웅 | 기술과 자세 | 표식이 붙는 순간 |
| --- | --- | --- |
| Knight | Radiant Sweep은 방패 뒤로 몸을 감았다가 방패 팔을 열고 앞무릎으로 베기의 하중을 받는다. | 금빛 서약 인장의 두 반쪽이 피격면으로 모인다. |
| Dwarf Axe Thrower | Armor Splitter는 빈 팔을 접어 도끼를 받친 뒤, 타격 반동을 무릎으로 흡수하며 도끼를 거둔다. | 두 균열이 맞물리며 갑옷 파쇄를 표시한다. |
| Elf Archer | Weakpoint Shot은 화살 뒤로 고개를 낮추고 발사 뒤 시위를 놓은 팔꿈치를 당긴다. | 좌우 조준 괄호가 맞은 지점으로 좁아진다. |
| Mage | Ember Lance는 유도 손으로 지팡이 가까이 불씨를 모으고 손바닥을 돌려 내보낸다. | 두 불꽃 획이 명중 위치에서 모인다. |

Oathblade, Radiant Charge, Elemental Arrow, Frost Lance도 같은 서버 경로를 사용한다. 피해를 입고 살아남은 적에게 실제로 부여하거나 갱신한 표식만 확정 피해 이벤트에 담는다. 8개 기술에 쓰이는 6종 표식은 피격면 앞에서 색과 형태가 다른 Beam 두 개로 표현한다. 부여는 모이고 소모는 바깥으로 퍼진다. 아군 표시는 0.16초 지속되며, 표식 효과를 그리면 범용 명중 섬광을 생략한다. 피해 숫자는 별도로 표시한다. [표식 소모 작업](../hero-mark-impact-20261122/README.md) · [공식 사례 조사](../../research/2026-11-23-hero-mark-application.md)

## 확인 결과

- 커밋 `edd09fc9`에서 Rojo 7.7.1로 공용 로비·배틀 Place를 빌드했다. 산출물 SHA-256과 변경된 런타임 모듈 5개의 소스를 입력 커밋과 대조했다. [고정 빌드 기록](build.json)
- Luau에서 실제 서버 명중 함수와 VFX 곡선 함수를 추출하고 엔진 객체를 모의했다. 8개 부여 기술의 생존·사망·무피해·표식 소유·갱신, 기존 소모 시 1회 적용과 만료를 확인했다. 본인·아군과 두 명중 방향의 모이는 곡선, 팔·무릎 가산 자세도 확인했다. 기준 0.115.56은 401건 중 160건에서 새 조건을 충족하지 못했고, 후보는 서버 68건·곡선 931건·자세 10건을 모두 통과했다. 추가 곡선 샘플은 후보에 해당 곡선이 있을 때 평가했다.
- Luau 구문 검사 7파일과 기존 CPU 검사 14,077건을 통과했다.
- 기준과 후보의 로컬 Studio 실행기는 연결 단계에서 시간 초과했다. Mac 잠금 상태에서는 새 세션의 UI 확인도 막혔다. R6/R15 렌더·피해 숫자·실제 Humanoid 검사는 재현 스크립트에 남아 있다. [클라이언트 렌더 검사](../../../tests/hero-mark-application-native.luau) · [서버 명중 검사](../../../tests/k0-basic-attacks-native.luau)
