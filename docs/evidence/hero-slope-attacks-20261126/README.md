공통 준비·착탄·근접 범위선의 끝점은 가까운 지면 높이로 투영한다. 절벽 끝이나 서로 다른 높이의 평평한 발판은 큰 단차에서 연결을 끊는다. 기준 지면이 아직 없는 경우 평면 표기를 쓰고 카메라에서 먼 범위선은 생성하지 않는다. 서버의 피해·반경·시각은 기존 정의를 따른다. [RPG 참고와 기준 검토](../../research/2026-11-26-hero-slope-attacks.md)

- 동일 R15 리그·카메라·19° 경사에서 준비와 명중 후 50/145ms, 전후 24장을 확인했다. 0.115.131에서 약하게 읽히던 드워프 균열과 암석을 보강했다. 뒤쪽 카메라에서는 드워프 몸이 가까운 균열 일부를 가린다. [전후 화면](comparison.jpg)

- 자신 1명과 아군 3명의 효과를 겹친 Studio 장면에서 Beam 135→20, 표면 139→4, 보조광 24→0, 입자 요청 8→0을 기록했다. 적 붉은 예고선 16개와 피해 숫자 42를 양쪽에서 확인했다. 재생 중 생성된 효과의 개수를 계측했다. [겹침 검사](studio-results.json)
- 기존 Studio 회귀 26묶음 259,564건을 통과했다. R6·R15의 128개 스킬, 타격·발사·취소·VFX 예산을 포함한다. 0.115.132에서 Earth Rise와 Stone Lance의 왼팔 방출 자세가 비슷해지는 회귀를 확인했다. 0.115.133에서 Earth Rise의 팔꿈치를 구부려 두 기술의 동작을 다시 구별했다. [회귀 결과](studio-results.json)
- CPU 스킬·전직·스탯 미리보기 15,249건과 패키지 정적 검사 336건을 통과했다. 별도 CPU 자세와 난이도 검사는 기준·후보 모두 각각 Lua의 기존 Luau 복합 대입과 난이도 버전 기대치에서 중단됐다. [회귀 상세](studio-results.json)
