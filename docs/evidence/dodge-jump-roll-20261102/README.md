# 멀리 뛰어 옆으로 구르는 회피

2026-11-02 · TLT-005/028/032/033/084 · ENG → QA

사용자는 옆 구르기를 옆으로 점프하며 멀리 구르는 동작으로 개선하도록 요청했다. 첫 Dodge의 뒤로 피하기7스터드/0.30초와0.30초 더블탭·좌우 선택을 유지하고, SideRoll에만 거리14스터드·이동/회전0.55초·전신 점프 정점2.5스터드를 적용했다. 전체 행동0.65초·무적0.08~0.28초·스킬 즉시 전환 계약은 유지한다.

서버 `moveDodge`가 종류에 따라 별도 거리/이동 시간을 선택한다. 클라이언트는 동일한 이동 시간에 맞춰 몸을 띄우고 팔다리를 접어 한 바퀴 회전한 뒤 중립 자세로 돌아온다. 점프는 R6/R15 시각 루트 관절의 전신 연출이며 물리 HumanoidRootPart/피격 기준점을 공중으로 옮기지 않는다. 따라서 낮은 장애물이나 틈을 뛰어넘는 물리 점프는 아니며, 기존 지면 확인·벽 충돌·낭떠러지 차단을 계속 적용한다. 사용자 열린 Place·TD 자산은 변경하지 않았다.

[직전 회피 조사](../../research/2026-11-02-dodge-double-tap.md)의 연속 입력·서버 이동 검증 원칙과 [기존 관절 모션 대안](../../research/2026-10-31-sword-axe-motion.md)을 재사용했다. 사용자 지시의 더 긴 공중 회전을 구현하기 위한 수치는 시험값이며, 실제 기기의 조작감·낮은 천장/장비 겹침·최종 미술/밸런스는 미검증이다. 새 게임 동작을 위해 다른 게임의 애니메이션 자산을 복사하거나 업로드하지 않았다.
