# 전투 HUD 슬롯 높이 조정

2026-11-26 · TLT-028/084 · ENG → QA · 0.117.3

사용자 요청에 따라 기존 TD 슬롯 프레임 안에 단축키·수량·쿨다운·48×48 그림·이름을 다시 배치했다. 폭 64와 그림 크기를 유지하면서 높이를 기본 102→96, 좁은 화면 126→118로 줄였다. 기존 물약 그림 자르기 영역과 일곱 슬롯의 한 줄 배치를 유지했다.
