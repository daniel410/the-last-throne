# 스토리 연결부 바닥 틈·지형 끼임 수정

2026-11-15 · TLT-061/062/063/064/065/084 · ENG/맵 충돌 → QA · 로컬 구현, 미게시. G5/G7 전체 완료가 아니다.

사용자가 보고한 스토리 사이 이동 중 지형 아래에 갇히는 결함을 수정한다. 기존 사용자 미커밋 자산 변경은 수정하거나 스테이징하지 않았다. 명확한 충돌/복구 결함 수정으로 별도 게임성 리서치나 신규 미술 제작은 적용하지 않았다.

## 원인과 변경

기존 연결 바닥은 지역 중심선에 수직인 사각형이다. 실제 지역의 사각 경계는 이 선과 비스듬히 만나므로, 중앙 높이를 맞춰도 양옆 모서리에는 바닥 틈과 높은 턱이 남는다. 변경 전 0.110.28의 [진단 스크립트](before-probe.luau)·[표본](before.json)에서 DW-01→02 등 연결부의 8~20stud 낙차를 재현했다. 진단은 16,723표본이며 문제 목록은 첫30건/70건만 보존한 것으로 전체 발생 횟수가 아니다.

- `CampaignPassage`에서 두 지역의 실제 경계와 길 양옆의 교차점을 계산한다. 모서리에서 경계 방향이 달라지면 분할한다. `CampaignPassageFloor`는 이 표면을 고체 삼각기둥으로 구성하고 양 끝을 지역 바닥 안으로4stud 겹친다. 플레이어에게 허용되는 기존48stud 반폭은 유지하고 실제 바닥에는4stud 여유를 둔다. 물리 부동소수점 틈을 막기 위해 삼각형 면을 같은 평면 안에서0.1% 겹친다.
- `CampaignBounds`의 연결부 높이도 동일한 삼각면에서 구한다. 중앙선 높이만으로 측면의 정상 보행을 되돌리지 않는다. 스토리 접근 자격·수평 통행 범위는 유지한다.
- `CampaignCombatRouteWorld`가 교체한 옛 `SnowTrail_*`/`LateTrail_*`도 중첩 foundation 내부까지 찾아 충돌·쿼리·터치를 은퇴시킨다. 기존에는 중첩 경로 중 `CalderaTrail_*`만 포함돼 있었다.
- `EpicWorldArt`는 실제 연결면과 접근부의 전체 경계 상자로 voxel 지형을 비워, 사선 모서리의 벽/덮개가 새 바닥 위에 남지 않게 한다. 전체 맵의 충돌을 비활성화하지 않는다.
- `DeepwoodRegionAccess`는 Humanoid의 HipHeight·루트 크기·R6 다리 높이로 발의 접지를 판단한다. 일부가 묻힌 위치나 높이 뜬 위치를 안전 복귀 위치로 저장하지 않는다. 복귀 전에 영웅·캐릭터·현재 접근 자격과 바닥 높이를 다시 확인한다. 정상 위치 기록이 없으면 현재 스토리 체크포인트를 사용한다. 기존 서버 `relocateForStoryGate`를 사용해 전투 이동 검증을 동기화하며 HP/MP·진도·보상을 변경하지 않는다.

## 고정 빌드와 재현

빌드 **0.110.29**, 소스 `f35debee34132e59faf350cc35725f642f41321c`. [빌드/해시](build.json), [검사 입력 해시](inputs.json), [정적 기록](static.log), [엔진 기록](native.log).

```bash
python3 tools/build-game.py --source f35debee --record /tmp/tlt-story-passage-build.json
python3 tools/prepare-story-passage-native.py
run-in-roblox --place builds/0.110.29/TheLastThrone-0.110.29.rbxlx --script /tmp/tlt-story-passage-native.luau
```

빌드는 이미 사용한 버전의 파일을 덮어쓰지 않는다. 위 빌드 명령의 재시도에는 새 버전 예약이 필요하다. 엔진 검사는 빌드 내 변경 모듈의 바이트 일치와 전체 Luau 컴파일을 확인하며, 최종 검증에서 소스를 주입하지 않는다. `--preview`는 이전 격리 빌드에 후보 소스를 주입하는 개발용 옵션이다.

정적 검증: 기존 지도 안내106,051검사·전투 동선77,381검사·체크포인트 이동1,927검사, Python 구문/공백 검사를 통과했다. 별도 `story-respawn.spec.lua`는 현재 destination 테스트 어댑터의 nil 순회 오류로 실패하며 변경 전 작업 트리에서도 동일하게 재현했다. 이 기존 실패를 통과로 표시하지 않았다.

최종 엔진 검사 종료코드0. [결과 요약](results.json): 바닥43연결부·43,173표본의 누락0(최대 권위 높이 오차0.000344stud 미만), 옛 경사로39개 비충돌, R6/R15 복구8검사 통과. 대표 R15 보행28조건 모두 도착·점프0·강제 위치 보정0이다. 기존/Easy 두 안내 경로24,518/25,427표본 모두 바닥·차단·단차·위치 보정·안내 실패0이며, 기존 숨은 경계756검사와 저장 불명/실패·도보 잠금112검사도 통과했다. 바닥 검사는43연결부의 중앙·좌우4/24/40/46stud, 연결선 양 끝 바깥 접근부를 포함한다. 표본은 바닥 누락/권위 높이 불일치를 검사하며, 주변의 모든 장식물과 지형 돌출까지 무장애라고 보증하는 검사는 아니다. 실제 R15 보행은7개 대표 연결부의 좌우40stud·양방향28조건에서 모서리 양쪽8stud 접근부를 포함해 검사한다.

## 남은 수용과 인계

Roblox 게시·릴리스 태그 없음. 현재 게시된 게임에 아직 반영되지 않았다. 게시 클라이언트의 스트리밍/네트워크 소유권·재접속, 실제 PC/터치/패드 자유 조작·회피, 1~4인+AI 및 모바일 성능, 사용자 재현 장소의 수용은 미검증이다. 새 충돌 파트의 기기별 비용도 실제 기기에서 확인해야 한다.

다음 담당 QA는 고정 빌드로 보고된 스토리 경계의 일반 보행·회피·측면 횡단과 안전 복귀를 확인한다. 게시 담당은 이 검증 소스를 기준으로 로비/배틀 동일 파일 게시와 실제 클라이언트 수용을 별도 수행한다. 회귀 시 해당 구현 커밋을 되돌리고 새 버전으로 재빌드한다. 기존 릴리스 태그나 게시 이력을 덮어쓰지 않는다.
