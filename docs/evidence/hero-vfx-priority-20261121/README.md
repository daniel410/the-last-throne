# 파티 전투의 영웅 효과 우선순위 검증

TLT-033/057/059 · 2026-11-21 · 기준 0.115.34 · 후보 0.115.35

[조사 근거](../../research/2026-11-21-hero-vfx-priority.md) · [고정 빌드](build.json) · [검사 결과](studio-results.json)

아군 피격 장식으로 효과 슬롯이 찼을 때, 새 공격이 들어오면 가장 오래된 아군 피격 장식부터 양보한다. 검의 찌르기, 돌아오는 도끼, 활의 산개 화살, 표적 사이 번개와 착탄 전에 떨어지는 얼음이 이 규칙을 사용한다. 준비 효과도 본인의 무기 준비 자세를 보여 줄 자리를 남긴다. 이미 표시 중인 공격 궤적과 본인 피격 효과는 이 우선순위로 제거하지 않는다.

모든 자리가 진행 중인 공격으로 찬 경우 기존 대체 경로를 사용한다. Gunner Shot은 총구 섬광 한 번과 발사선을 표시한다. 아군 명중의 범용 구형 섬광과 표적마다 생성하던 추가 장식은 줄인다. 확인된 피해 숫자와 피격 반응은 계속 전달된다.

## 전후 검증

- 격리 Studio에서 같은 R15 리그와 카메라로 아군 피격 10건 뒤 Knight의 Vanguard Strike, Dwarf의 Returning Echo, Elf의 Grand Volley, 본인 Mage의 Chain Lightning을 같은 순서로 재생했다. 주 효과는 1/4→4/4, 대체 화살 궤적은 5→0, 범용 피격 섬광은 1→0이었다. 붉은 적 예고 16선분과 피해 숫자 42의 표시 객체를 양쪽에서 확인했다. [파티 전후 화면](party-vfx-priority.jpg)
- `run-in-roblox --place builds/0.115.35/TheLastThrone-0.115.35.rbxlx --script tests/hero-vfx-priority-native.luau`로 네 클래스의 발사, Hailfall 낙하, 무기 준비, 오래된 효과 정리, Gunner의 대체 발사와 확정 피해 42를 재현한다. [검사 소스](../../../tests/hero-vfx-priority-native.luau)

신규 검사 28건 중 기준은 12건에 실패했고 후보는 모두 통과했다. 후보의 Studio 10묶음 256,949건에는 128개 스킬의 전체 효과와 피격, 115개 무기 준비 효과, 여덟 궁극기, R6/R15를 포함했다. CPU 두 묶음 15,147건을 통과했다. 빌드 SHA-256과 클라이언트 모듈 세 개를 입력 커밋과 대조했다. 첫 화면 캡처는 시험 장면의 `Character` 리그 이름이 달라 시작하지 못했고 같은 이름으로 교정한 뒤 두 빌드에서 완료했다.
