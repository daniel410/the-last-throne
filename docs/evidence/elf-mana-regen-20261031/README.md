# 엘프 MP 자연 회복 강화

2026-10-31 · TLT-008/015/052/054/084 · ENG → QA

사용자의 후속 요청을 직전 마법사와 같은 2배 회복으로 해석했다. 엘프의 자연 MP 회복률을 초당 최대 MP의 0.15%에서 0.30%로 늘린다. Lv20 Magic Archer의 기본 MP 80은 초당 0.12에서 0.24로 회복한다. MP는 기존처럼 첫 전직 후에만 추가된다. 엘프 공격력·마법사 공격력/회복·MP 비용·쿨다운·시전 후 회복 대기 1초·최대 MP 상한은 변경하지 않는다.

[직전 마법사·엘프 비교 조사](../../research/2026-10-31-mage-elf-balance.md)를 재사용한다. 실제 전투의 물약 소비·엘프/마법사 균형은 여전히 기기 플레이 검증이 필요하다.

검증: 0.58.5 Battle 빌드에 직전 마법사 변경과 이번 `K0Config`/`CombatService`를 주입한 격리 Studio fixture에서 `tests/k0-basic-attacks-native.luau` 978개 통과. Magic Archer의 회복량·시전 지연·상한과 마법사 회복 및 전투 회귀를 확인했다. 실제 게시 클라이언트·기기·전 구간 밸런스는 미검증이며 현재 게시된 게임에는 반영되지 않았다. 다음 담당은 QA다.
