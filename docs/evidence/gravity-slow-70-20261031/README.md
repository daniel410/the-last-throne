# Gravity 이동속도 감소 70%

2026-10-31 · TLT-008/015/042/052/056/084 · ENG → QA

사용자의 후속 조정으로 Gravity의 이동속도 감소량을 100%에서 70%로 변경했다. 적은 원래 이동속도의 30%로 움직이며 기존처럼 공격할 수 있다. 반경 10스터드, 기본 지속시간 10초와 숙련당 +0.2초, 기본 주문 피해 및 MP 회복 변경은 유지한다. 스킬 상세는 공통 설정에서 70%와 실제 지속시간을 표시한다.

검증: `lua tests/skill-stat-preview.spec.lua` 1,298개 통과. 0.58.5 Battle의 관련 작업 모듈을 적용한 격리 Studio fixture에서 `tests/k0-basic-attacks-native.luau` 982개 통과: 중심과 확장 영역의 70% 감속, 10초 지속·복구, 차폐, 기본/후속 기술 및 양 직업 MP 회복을 확인했다. 실제 기기·다인·보스 밸런스는 미검증이다. 게시된 게임에는 미반영이며 다음 담당은 QA다.
