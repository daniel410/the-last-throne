# 로비·전투 UI 글자 가독성

2026-11-25 · TLT-028/084 · ENG → QA · 0.115.130

## 변경

- 공통 TD 버튼과 제목 이름표의 안쪽 여백을 확보했다. 글자는 지정한 크기를 상한으로 사용하고 공간이 좁아지면 안쪽 영역에 맞춘다. 로비 메뉴는 아이콘 옆에 여백을 두고 문구를 정렬한다.
- 로비 아이콘 글자를 승인 TD 이름표의 장식 테두리 안에 배치했다. 짧은 세로 화면에서는 같은 크기의 아이콘을 세 열로 배치해 하단 PLAY와 영웅 영역을 비운다. 영웅 카드의 이름과 초상, 선택 표시도 각각 공간을 확보했다.
- 작은 화면에서 가방의 제목과 닫기 버튼, 지도 제목과 Tessa 버튼을 분리했다. 긴 퀘스트 제목은 줄을 추가해 다음 상태 및 설명을 아래로 밀어낸다.
- 배틀 HUD는 물약·스킬 7칸을 한 줄로 유지한다. 아이콘 위에는 단축키와 수량·쿨다운을, 아래에는 이름을 배치했다. 작은 화면에서는 이름이 줄을 바꿀 수 있도록 슬롯을 높이고, 일반 스킬의 쿨다운을 초 단위로 올림해 표시한다. 세로 화면의 슬롯 행은 하단 터치 영역 위에 배치한다.

## 검증

기준 0.115.129에서 320×568 가방 제목이 닫기 버튼을 침범했고, 로비 이름표가 테두리까지 차지했으며, 배틀 슬롯의 단축키·수량·쿨다운 영역이 아이콘과 겹쳤다. 이 경계에 회귀 검사를 추가했다. 과거 진행 데이터 테스트에는 현재 난이도별 저널과 레벨 상한을 반영했다.

고정 빌드 0.115.130의 실제 모듈을 격리 Studio Edit에서 실행했다. 기본 모바일 검사 7개 크기(320×568~1280×591)와 로비 아이콘 검사(최대 3840×2160)를 포함해 **18개 묶음·38,999개 조건**을 통과했다. 텍스트 영역·줄바꿈, 아이콘과 글자 사이 간격, 터치 목표 크기, 슬롯 한 줄 배치, 팝업과 닫기 영역을 검사했다. 패키지 검증에서 역할 10개, 도착 로딩 326개, 프로젝트 마운트와 실제 파일 구성을 통과했다. [Studio 및 패키지 결과](studio-results.json)

빌드 소스는 `517933331605bd7141cebcc5c2250ad85fc7b077`이다. `python3 tools/build-game.py --source 51793333 --record <기록.json>`으로 단일 Place를 생성했다. 산출물은 `builds/0.115.130/TheLastThrone-0.115.130.rbxlx`이다. [빌드 기록과 SHA-256](build.json)
