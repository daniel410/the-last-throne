# 원정 지도 실측 지형 선명도

2026-11-26 · TLT-028/084/090 · 0.117.8 후보 · ENG → 릴리스/QA

Gloamwood 전체 지도에서 길과 숲이 가로 띠로 뭉개진 원인은 3개 열 × 18개 행의 그라데이션으로 지형을 다시 그리는 표시 방식이었다. 해당 경로는 [게시 환경의 이미지 API 권한 오류](../runtime-errors-20261120/README.md)를 없애기 위해 도입했다.

- Studio 및 이미지 API 사용을 허용한 환경에서 실제 월드 촬영본의 저장 해상도와 투명도를 표시한다. 원본보다 작게 표시할 때는 기본 샘플링을, 원본보다 큰 축이 생기면 픽셀 샘플링을 사용한다.
- 기본 보안 설정에서는 이미지 생성 API를 호출하지 않는다. 기존 대체 렌더러의 전체 지도 샘플링을 최대 46 × 18에서 91 × 48로 높였다. 이미지 생성, 픽셀 쓰기 또는 표시 연결이 실패한 경우에도 이 경로를 사용한다. 촬영 데이터가 누락되거나 손상되면 실측 도식을 계속 표시한다.
- 로비 전체 지도, 배틀 전체 지도, 지역 상세가 같은 렌더러를 사용한다. 기존 월드 좌표와 마커, 잠금 및 체크포인트 계약은 [제품 계약](../../product-contracts.md)을 따른다.

## 검증

- 고정 빌드 0.117.8의 [빌드 기록](build.json). 빌드 내부의 렌더러 소스가 커밋과 일치하며 44개 촬영 데이터는 Git LFS 원본과 일치한다. 소스 585개 구문 컴파일 통과.
- 격리 Studio에서 원본 44개 지역의 RGBA 픽셀 5,826,688개를 대조했다. 누락·손상 데이터와 비활성 환경, 예산 소진, 픽셀 쓰기·표시 연결 실패, 원본보다 작은 표시와 확대 샘플링을 포함해 렌더러 151검사 통과.
- 지역 상세 332검사 및 지형 3검사, 배틀 전체 지도 416검사, 로비 전체 지도 87검사 통과. 배틀 전체 지도 검사에는 2.5배 확대와 네 가지 화면 크기에서 지리 종횡비·지도 조작 확인이 포함된다.

## 게시 수용

릴리스/QA 담당은 테스트 Experience의 `Allow Mesh / Image APIs`와 `AtlasPlate` 모듈의 Boolean 속성 `EnableAtlasTextures`를 활성화한 구성에서 실제 게시 클라이언트의 Gloamwood 전체 지도와 지역 상세를 확인한다. 기본 보안 설정에서는 개선된 대체 지형이 표시된다. 게시 클라이언트, 휴대기기 메모리 예산 및 사용자 시각 수용은 미검증이다.
