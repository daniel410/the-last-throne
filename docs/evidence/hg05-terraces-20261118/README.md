# TLT-064 · HG-05 왕릉 묘역 테라스 원형

2026-11-18 UTC. **별도 Studio 장면에서 구현한 후보이며 본편 미반영, G5 미완료.** 맵 구현·환경 아트·환경 모델링·리서치를 순차 수행했다. 기존 외곽 구형 언덕 후보를 확대하지 않았다.

## 변경·서사·자산

HG-05는 서쪽/동쪽 방어 연결을 끊고 왕릉 진입을 여는 장이다. 중앙 교전장을 유지하면서 뒤편 묘역에 높이18stud의 3단 석축3개(각 바닥104×80)를 실제 제작했다. 석조/Slate/회녹색은 기존 EpicEnvironmentKit HauntedGraveyard 팔레트, 묘비/석관은 EpicArchitecture.grave 파생이며 신규 외부 자산·메시·텍스처 없음. 완전한 파괴/복원 상태는 선표현하지 않는다.

기존 TwinShieldPylons와 KeeperMemorialCluster 한 조립체씩을 석축 위로 옮겼다. 이는 시각용 RegionalConcept이며 실제 west/east 상호작용 좌표는 유지했다. 기둥과 실제 장치 사이의 의미가 플레이 카메라에서도 명확한지는 아직 확인이 필요하다. 첫 원형의 기존 무덤/기둥 겹침은 발견 후 수정했다. 겹친 GroundAndPaths의 CarvedHeadstone/Sarcophagus 전체를 후보 장면에서 제거하고 새 상면에 묘비5개를 배치했다. RegionalConcept의 같은 이름 KeeperMemorialCluster 잔여2개도 제거했다. 생산 원본은 변경하지 않았다. 최종 후보90 BasePart/고체42개는 기존에서 옮긴 조립체를 포함한 수이며 순증 수가 아니다.

`layout.svg`는 실제 목표·조사 지점·Easy 교전 중심 예약과 테라스 배치의 겹침 도면이다. 전체 안내/귀환 통로 도면이 아니며 정확한 경로는 엔진 검사로 확인했다. `RoyalBurialTerraces.candidate.luau`는 생성 순서/기존 소품을 재설계한 실험 파일이다. 본편에서 require하지 않는다. `setup.luau`는 fresh QA사본에서 재현하며, 후보를 같은 World 폴더의 RoyalBurialTerracesCandidate ModuleScript로 설치한 뒤 실행한다. 반복 호출 대신 fresh 장면을 사용한다.

## 판정·다음 담당

외곽 작은 언덕과 달리 기둥·묘역의 계단형 실루엣이 비교 화면에서 보인다. 다만 세 직사각 석축의 반복이 강하고 장치 접근과 지형의 관계도 아직 충분히 자연스럽지 않다. **후보 보존, 자동 본편 채택하지 않음.** MAP/ART는 왕릉 접근의 실제 전투 카메라에서 한 구간을 검토하고 석축의 길이/방향/풍화·중간 연결을 비대칭으로 다듬는다. ENG/QA는 실제 Play에서 기존 장치 조작/귀환 및 테라스 주변 회피·낙하를 확인한 뒤 생산 생성기에 통합한다. 같은 위치에 소품만 더하거나 외곽 언덕을 증량하는 작업으로 대체하지 않는다.
