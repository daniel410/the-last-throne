# Sentinel 기본 수치·Diamonds 가격 상향

2026-11-09 · TLT-029/041/052/057/084 · 0.93.6 · ENG→QA

사용자가 직전 부위별 표를 기준으로 “수치를 +30 +20, HP MP +70으로 높이고 다이아몬드 가격을 높여줘”라고 지시했다. 무기/방패/투구30, 장갑/부츠20, 상의HP/로브MP70으로 적용했다. 등급Rare·요구Lv10·단일옵션·아이템ID·모델/아이콘·강화율3%/단계·강화비50Gold를 유지한다. 기존 보유 Sentinel도 정의를 공유하므로 새 기본값을 따른다. 삭제/재지급·추가 장비/옵션/자원 생성은 없다.

| 부위 | 강화 전 기본 수치 | 이전→신규 Diamonds | 기존 되팔기 Gold 유지 |
| --- | --- | ---: | ---: |
| 검/도끼/활/지팡이 | 공격력20→30 | 40→60 | 400 |
| 기사 방패 | 방어력20→30 | 32→48 | 320 |
| 투구/후드 | 방어력20→30 | 28→42 | 280 |
| 일반 상의 | 최대HP50→70 | 32→45 | 320 |
| Mage Robe | 최대MP50→70 | 32→45 | 320 |
| 장갑 | 공격력15→20 | 24→32 | 240 |
| 부츠 | 방어력15→20 | 24→32 | 240 |

가격은 이전 Diamonds×(새 기본수치/이전 기본수치)를 올림했다. 기본부위50%·장갑/부츠약33%·상의/로브40% 성능 상승을 반영한다. 상의/로브32×70/50=44.8→45다. 기존1Diamond→50Gold 환전 기회비용도 유지한다. 무기60Diamonds는3,000Gold 상당이며 Gold 구매 SKU는 만들지 않았다.

되팔기를 소급 인상하면 과거8Diamonds(환전400Gold 상당)에 산 투구가 새 기준20%인420Gold로 판매되어 차익이 생길 수 있다. 따라서 Sentinel 매입가는 이전400/320/280/320/240Gold를 고정 유지했다. 다른 계열·장신구·물약·리셋·재료·지원·환전·승인 보상은 변경하지 않는다. Traveler 상품 제외도 유지한다.
