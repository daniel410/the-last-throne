# Dodge 1회 뒤로 피하기·2회 옆 구르기

2026-11-02 · TLT-005/028/032/033/084 · ENG → QA

사용자 요청을 구현했다. 첫 Dodge는 이동키와 관계없이 영웅 뒤로 즉시 피한다. 서버가 승인한 첫 회피 도중0.30초 안에 두 번째 Dodge를 받으면 옆 구르기로 전환한다. 왼쪽 이동 입력은 왼쪽, 나머지는 기본 오른쪽이며 이동 방향은 영웅 기준이다. PC R·패드 B·기존 터치 버튼이 같은 Dodge 경로를 사용한다. 연속 입력을 위해 첫 회피를 지연하지 않는다.

`DodgeRules`는 서버의 두 번째 입력 시점·좌우 선택과 클라이언트의 회전 곡선을 공유한다. `CombatService`는 승인된 회피 종류·시각·좌우를 게시하며, 기존 이동/충돌 검사로 위치를 확정한다. 단일 회피/옆 구르기 모두 기존7스터드·이동0.30초·전체0.65초·시작 후0.08~0.28초 무적을 사용한다. 두 번째 입력은 새 회피 시각을 시작한다. 첫 회피가 이미 이동한 거리와 두 번째 회피의 이동은 각각 적용되며, 과거 타격은 되돌리지 않는다. 구르기 자체를 추가 입력으로 재시작할 수는 없다. 새 Stamina/쿨다운은 없다.

`K0SwordVisual`은 네 영웅의 R6/R15 루트 관절에 옆 회전·몸 낮추기·팔/다리 접기를 적용한다. 물리 HumanoidRootPart를 돌리지 않는다. 기술로 취소할 때 회피 상태·무적·소유권과 회피 표시 속성을 정리한다. 기존 영어 훈련 안내에 단일/더블탭과 방향 선택을 추가했다. [사례 조사·선택·위험](../../research/2026-11-02-dodge-double-tap.md).
