# 마지막 웨이브 보스·일반 몬스터 동반

2026-11-06 · TLT-005/016/027/050/057/061~065/084 · ENG → QA · 0.78.9 · 로컬/미게시

사용자는 보스의 마지막 등장 순서는 유지하면서 일반 몬스터와 함께 나오도록 요청했다. 최신 지시는 과거 보스 단독 웨이브 조건보다 우선한다. 현재 코드의 `waves`가 마지막에 `{boss}`만 붙이던 구성을 수정했다. [기존 비교 조사 재사용/후속 확인](../../research/2026-11-06-boss-final-escort.md).

## 편성·보상·복구 계약

- **22개 보스전 모두 마지막 웨이브에 보스1명+일반 호위가 함께 등장**한다. 선행 일반 웨이브를 먼저 처리하며 최종 웨이브 이후 새 웨이브/무한 증원은 없다. 보스/호위를 모두 처리해야 완료한다.
- 기존 일반 적이 있던8전투는 그중 최대 `packCapacity-1`명을 마지막에 남기고, 나머지는 선행 웨이브에 배치한다. 기존 적의 종류/수/레벨/처치 보상 총량은 유지한다.
- 보스만 있던14전투에는 지역·종족에 맞는 일반 적1코호트를 추가한다. 기본 레벨은 보스-1(최소1), 인원별6/8/10/12마리이며 최종 동시 상한을 넘는 수는 선행 웨이브로 분리한다. 이는 시험 편성값이며 실전 난도 수용은 후속이다.
- 동시 개체 상한은 기존 `packCapacity`(최대12) 그대로다. 솔로 최종 팩은 보스 포함5~9명. 예: Warlord는 보스+5, King Shaman은 보스+8, King Ogre는 보스+7, 설원 선택 보스는 보스+4다.
- 신규 호위14코호트는 정상 처치 XP/Gold를 받는다. 기존 밀도 배분 공식을 적용해 코호트 전체는 해당 종류/레벨 일반 적1명의 보상 예산이며 인원이 늘어도 개인 총량은 동일하다. 따라서 신규14전투의 **처치 XP/Gold 총량은 이 코호트만큼 증가**한다. 기존 보스 보상/고정 스토리·퀘스트 보상 정본은 변경하지 않는다. 기존 호위8전투는 처치 총량도 증가하지 않는다.
- 생성 순서가 바뀌어 예전 일반 적 영수증ID를 보스에게 재사용하면 보상 누락이 생길 수 있다. `killIndex`를 편성 전에 지정해 기존 일반 적1..N·보스N+1을 보존한다. 보스만 있던 전투의 보스는 기존1, 새 호위는2부터 부여한다. Service의 `StoryKillId`에 이 인덱스를 사용하고 기존 원정/목표 prefix를 유지한다. 같은 원정 재접속/재시도의 기존 영수증은 같은 적 종류·레벨·보상에 대응한다.
- 보스 패턴·기둥/체력 단계·설원 진정·적 능력치 공식·개인/공동 진행·저장 권한은 변경하지 않는다. 호위 재배치에 따라 웨이브별 정예 위치/동시 압박은 달라질 수 있어 실전 수용 대상으로 남긴다. 사용자의 미커밋 Blender 파일/다른 미추적 자료는 포함하지 않는다.
