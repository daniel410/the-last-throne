Selene 제외. 구조/로드 검사 통과는 외형 수용을 뜻하지 않습니다. 가면처럼 떠 있는 얼굴은 교정했지만 헤어/수염은 원화와 차이가 남습니다.

  • mira: 단발 볼륨과 웨이브 부족. 옆머리 하단이 귀마개처럼 보이고 원화의 컬/귀걸이 표현 부족.
  • rowan: 회색 앞머리가 납작한 판처럼 보임. 턱수염 윤곽과 원화의 강한 성인 인상이 부족.
  • tessa: 높은 포니테일의 곡선과 연결이 단순함. 앞머리가 원화의 옆가르마와 다름.
  • oren: 옆머리 원반은 축소했지만 연속된 노인 헤어라인과 수염 형상이 부족.
