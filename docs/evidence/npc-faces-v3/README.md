# NPC 29명 개별 재검토와 표면 부착 교정

2026-11-01 · TLT-031/057/061/084 · ART/ENG → ART/QA · **미술 수용 보류**

사용자는 v2 미리보기를 거부하고 한 명씩 확인하라고 요청했다. 기존 로드/구조 검사가 외형의 적합성을 입증하지 못했는데도 개선 완료처럼 보고한 판단을 정정한다. v2는 미술 통과본이 아니다. Selene는 검토/변경 대상에서 제외했다.

[29명 수정 전후 갤러리](index.html): 각 페이지의 위 행은 정면, 아래 행은60도 측면이다. 모든 인물을 분리해 확인했으며 이전 미리보기처럼 뒤 줄의 머리가 겹치지 않는다. [개별 관찰 기록](review.json)은29명 각각의 문제와 잔여 작업을 담는다.

## 확인한 결함과 교정

- 전원: 투명 평면이 머리 앞에 떠 있어 측면에서 가면처럼 분리됨. 패널/SurfaceGui를 제거하고 **실제 Head 구면에 Decal을 직접 적용**했다. 기존 아틀라스의229px 셀을 Blender에서29장으로 분리하고 인물별 이미지 자산으로 업로드했다. 신규 AI 이미지 생성은 하지 않았다.
- 전원: 턱이 길고 목/칼라 연결이 약함. 머리 높이/중심을 조정했다. 몸체·복장·소품·안정ID·서비스·Selene는 유지한다.
- Aldric/Haldor/Brann 등: 수염이 독립된 알갱이처럼 보임. 연속된 기본 덩어리와 끝부분으로 바꿨다. 다만 여전히 원화의 실제 수염 실루엣/결과는 차이가 크다.
- Mira/Ketta/Maeve/Suri: 모두 같은 짧은 옆머리로 보이던 문제에 단발 측면과 끝 곡선을 추가했다. 아직 귀마개처럼 보이는 측면 덩어리와 균일한 앞머리는 남아 있다.
- Oren/Fen: 귀 위의 둥근 원반 같은 옆머리를 얇게 줄였다. Rowan의 수염은 드워프/노인과 분리해 짧은 턱수염으로 교정했다.
- Orik/Garrick: 네모난 모자 테두리를 둥근 실루엣으로 바꾸고 Orik 작업등을 추가했다. 최종 모자 형태/원화 재현은 남아 있다.

## 개별 검토 결과

29명 모두 `visualAccepted=false`다. 표면 부착 결함 교정과 최종 미술 수용을 구분한다. 특히 헤어를 타원 몇 개로 조합한 구조와 드워프 수염은 전용 메시/UV 작업이 필요하다. 정면에서 좋아진 점만으로 측면/원화 일치를 통과시키지 않았다. 실제 런타임은 기존 블록 복장을 유지하며 Blender의 단순 어깨 셸은 얼굴 위치 검토용이다.

## 검증과 한계

`tools/review-npc-heads.py`를 Blender MCP에서 실행해 전원 정면/측면 렌더6페이지씩을 만들고 직접 열어 비교했다. Blender 구면 UV 검토와 Roblox 엔진의 Decal 투영은 구현이 다르므로 동일 화면이라고 보고하지 않는다. [Studio Mira](studio-mira.png)는 실제 Edit 모드 캡처다.

Studio 격리 폴더 `TLTNPCFaceReviewV3`:29모델과29개 Decal 이미지의 AssetFetchStatus.Success를 확인했다. 최초 네이티브 검사에서 일부 신규 이미지에 `Asset content representation is being generated` 경고가 나왔으며, 뒤의 Studio 재확인에서는 모두 Success였다. 이 결과로 게시 Experience의 권한/최종 해상도/심사·실기기 성능을 수용하지 않는다.

최초 교정안 격리 네이티브 캐스트 검사 **3,574개/30인물/1,230파트 통과**. 최종 고정0.58.7 빌드의 명령·소스 커밋·해시·검증 결과는 `build.json`에 별도 기록한다. 기존 TD 자산203785492 유형 불일치 경고는 별개로 남는다. 전역 패키지·라이브 DataStore·TD 코드·Roblox 게시·릴리스 태그는 변경하지 않는다.

다음 ART 작업은 원화와 실제 시야를 함께 보며 **전용 헤어·수염 메시와 곡면 UV 얼굴**을 제작하는 것이다. QA는 외형 수용 후 기기/다인/스트리밍과 두 게시 테스트 Place의 자산 로드를 확인한다. 상위 티켓은 In Progress를 유지한다.
