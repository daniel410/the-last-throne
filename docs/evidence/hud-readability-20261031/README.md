# HUD 통화·안내 가독성 조정

2026-10-31 · TLT-028/052/084 부분 수정 · ENG → QA

사용자 요청: Gold/Diamonds 수치가 안 보임, 통화 UI 확대, MP 아래 안내/중앙 메시지는 글자만 확대.

- 통화: 168×44 → 208×56, TD 아이콘20 → 24px, 글자 최대13 → 17px와 Bold, 최소9 → 12px. 긴 금액의 자동 축소는 유지한다. 전투 미니맵 오른쪽에 맞춰 확대 영역이 화면 밖으로 나가지 않게 했다. 투명 배경/서버 잔액 계약은 유지한다. 펼친 메뉴를8px 내려 잔액과 간격을 확보했다.
- MP 아래 안내: 제목11 → 14, 목표12 → 15, 보조10 → 12px. 위치·창 크기·외형 유지.
- 중앙: 스토리 본문13 → 16px, 일시 피드백16 → 20px. 기존 본문 자동 높이 계산이 실제 Font/TextSize를 따르도록 변경했다. 버튼/색상/배치는 유지한다.
- 잔액 데이터 누락은 재현되지 않았다. 기존 작은 글자와 긴 문자열 자동 축소를 개선한 가독성 수정이며 실제 저장 잔액이나 서버 로직은 변경하지 않았다.

실행: `run-in-roblox --place builds/0.41.1/TheLastThrone-Battle-0.41.1.rbxlx --script /private/tmp/tlt-hud-readability-native.luau`
