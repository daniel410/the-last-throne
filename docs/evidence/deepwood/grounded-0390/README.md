# 0.39.0 열린 지상 Deepwood·밝은 낮·낙하/카메라 보호

2026-10-30 · TLT-005/031/050/061/084 부분 구현 · DES/ENG → QA.

사용자의 최신 요청은 **지면에 놓인 맵·맵 밖 낙하 방지·바닥 아래 카메라 금지**, 그리고 **다리 벽의 답답함/어두운 안개를 대체할 솔루션**이다. [리서치·대안 비교](../../../research/2026-10-30-grounded-deepwood.md). 상위 티켓은 In Progress다.

## 최종 변화

- 10개 기존 지역과9개 연결 밑에 연속 배경 바닥/흙 지지체를 추가했다. 낮은 지형도 허공이 아닌 지면으로 이어진다. 공유 TD 나무·절벽 원본 해시는 manifest와 일치하며 원본 자산은 수정하지 않았다.
- 연결 길은 **중앙24studs 길+전체96studs 잔디 어깨**다. 양쪽 경사 흙 지형이 바깥 바닥으로 내려간다. **연결 길의 벽/난간은0개**다. 멀리 떨어진 수목/낮은 둔덕으로 방향을 읽는다. 지역 최외곽 자연 경계와 개인 스토리 선행은 유지한다.
- 중심 높이끼리 잇던 다리를 실제 지역 가장자리의 높이에 맞춘 경사로로 바꿔 입구 단차를 없앴다. 지면·목표·NPC/활동의 기존 X/Z/높이와 승인 보상은 유지한다. 검토용 Studio에 남은 구형 생성 지형도 갱신해 예전 난간/벽이 재등장하지 않게 한다.
- 근거리 안개와 녹색/어두운 색보정을 제거했다. **낮14시·밝은 환경광**을 사용하고180~340studs의 아주 먼 배경만 밝은 하늘색으로 사라진다. 정상 전투 거리에는 안개가 없다. 장식 거리 제한은340에 맞춰 원경의 갑작스러운 사라짐을 줄인다. 거점/훈련 복귀 시 원래 조명을 돌려놓는다.
- 기본 카메라 입력은 유지하고 살아 있는 모험 시점에서 최대18studs, 장애물이 없는 회전22~72도, 반경0.6 충돌/끝점 겹침을 보정한다. 지형 아래 또는 장애물 속 끝점은 안전한 초점으로 물린다. 사망/Scriptable 카메라에는 간섭하지 않는다.
- 서버가 실제10지역/넓어진9연결 지면과 개인 자격을 검사한다. 낙하/이탈은 해당 영웅·생명의 마지막 안전 지면으로, 이력이 없으면 허용된 체크포인트로 복구한다. 허공 위치를 새 안전 위치로 저장하지 않는다. 체력·마나·보상/성장을 복구로 바꾸지 않는다.

전투 서버 부트 검사도 **10개 통과**했다. [빌드 입력/해시/명령/최종 로그](build.json). 두 Place용 로컬 산출물을 만들며 **미게시**다. 일반 빌드로 릴리스 태그를 만들지 않는다. 저장된 기존70829337938054 Studio/TD Place·라이브 DataStore는 수정하지 않았다. 시각 확인은 별도 임시 Place와 합성 계정/스토리 대역이며 실제 본편 플레이/게시 클라이언트 수용과 다르다.

초기 벽/짙은 안개 안은 사용자 피드백으로 폐기했다. 시각 검토 때 임시 Studio에 초기 생성 모델이 남아 있던 것을 발견해 실제 모델 폭/난간/벽 수까지 확인하는 갱신 경로를 추가했다. 포장길과 잔디 어깨의 표면 겹침도 발견해 포장길을0.1stud 높여 수정했다. 기존203785492 자산 유형 경고는 원시 로그에 보존한다. 마지막 원경 회귀의 첫 시도는 QA Player 대역의 새 GetAttribute 조회 누락, 두 번째는0.6초 고정 대기의 복구 경쟁으로 실패했다. 대역을 보완하고 실제 복귀 조건을 최대3초 기다리도록 바꾼 뒤637개가 통과했으며 원래 실패 로그도 보존했다. 게임 소스/빌드 바이트는 이 QA 보완으로 바뀌지 않았다.

정상 본편 전투 완주·4인 스트리밍/성능·실기기 터치/패드 카메라·최종 미술 사용자 수용은 미검증이다. 다음 담당 QA는 넓은 숲길 입구/회피·공격 예고 가독성·고도 차와 좁은 구역 카메라부터 시험한다.
