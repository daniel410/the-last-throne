# 0.38.0 전체 지도 개편·Mage 주문 강화

2026-10-30 · TLT-005/028/052/061/084 부분 구현 · DES/ENG → QA.

사용자 첨부 지도 화면과 마법/마나 조정 요청을 반영했다. [조사/선택 근거](../../../research/2026-10-30-atlas-and-mage-balance.md). 상위 티켓은 In Progress다.

## 변경

- 기존 검은 지역 사각형을 지형 윤곽·숲 수관·절벽·물 지형과 수레/거목/감시탑/폐허/뿌리/제단의 2D 랜드마크로 교체했다. 정본10지역의 영어 이름을 탐험 전에도 보이고 `UNEXPLORED / LOCKED / n% EXPLORED`를 별도 표시한다. 개인 탐험 셀144개/지역과 체크포인트 자격은 유지한다.
- 실제9개 연결을 모두 그리고 잠긴 경로는 회색, 열린 경로는 금색으로 표시한다. 회전선의 기준을 양 끝 중점으로 고쳐 지형 사이 길이 어긋나는 결함을 수정했다. 지도 X/Z 비율과 외곽 여백을 유지한다.
- 현재 위치/방향·목표·체크포인트, 이야기 완료 수/전체 탐험률·PC 이야기7개 목록·지역 선택/해금 선행 설명을 제공한다. `+ / −`, `FIT`, `YOU`, 드래그/스크롤과 기존 길 안내 토글을 지원한다. 작은 화면은 읽을 수 있는 지도 폭으로 이동하며 보고, FIT은 이름 겹침을 피하기 위해 극소 축척에서 이야기 번호/랜드마크만 표시한다. 터치/패드 실물 입력 수용은 별도다.
- Mage의 MP 소모 공격 주문 계수는 공통·Pyro/Cryo·궁극기 모두1.4배다. 기본 지팡이 공격·장벽량은 그대로다. Lv1/장비·마스터리 없음에서 Mana Bolt140, Water Ball119, Gravity98이며 이전은100/85/70이었다. 공유 Config에서 한 번 복사/적용해 원본 AdvancedSkills와 서버/미리보기의 중복 배율을 방지한다.
- MP 회복은 최대 MP의 초당0.1%→0.15%다. MP100이면0.10→0.15/초, MP80이면0.08→0.12/초다. 기존 공통 설정이므로 마법궁수도 적용된다.1초 지연·상한·비용/쿨다운·HP 회복은 유지한다.

고정 빌드 입력·해시·명령·검사 로그는 [build.json](build.json)에 연결한다. 최종 전투 시작 검사도 **10개 통과**했다. 네이티브 원시 로그의 기존 `203785492` 자산 유형 경고, 로컬 자산 가져오기 때 자동 발생한 TexturePack HTTP429 경고와 Studio MaterialManager 플러그인 진단을 보존한다. 새 텍스처 업로드나 게시를 의도적으로 수행하지 않았다. 최종 지도 검사는 엔진 JSON `pass=true`/91개와 별개로 run-in-roblox 종료코드1을 기록했으므로 CLI 성공과 혼동하지 않는다. 최초 전투 검사는 이전 피해/회복 기대값4개가 달라 실패했고 새 요청 수치로 정렬한 뒤 통과했다. 지도 검사의 첫 시도는 Play가 켜진 상태에서 격리 전제 검사로 중단했으며 Edit 재실행에서 통과했다. 임시 시각 검토 Place만 수정했고 기존70829337938054 Studio 편집 원본과 게시된 두 Place·TD/라이브 저장소는 변경하지 않았다.
