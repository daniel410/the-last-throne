# 0.40.2 Deepwood 장소·보스 배지·투명 잔액

2026-10-30 · TLT-028/031/052/061/084 부분 구현 · DES/ENG → QA. [비교 조사와 적용 판단](../../../research/2026-10-30-deepwood-places.md).

## 변경과 목적

- Vesteria 공식 소개의 수제 지역/사건 흔적, GW2의 관심 지점/전망 탐험, Diablo IV 환경 테마 조합을 비교했다. 소개/개발 문서 열람이며 직접 게임 플레이나 이용자 만족도 실험은 아니다.
- 10개 기존 지역에 서로 다른 장소 테마를 적용했다. 순례 숲·수레 보급 야영·레인저 전망·회랑 폐허·점령 안뜰·뿌리 성소·봉인 원·식량 야영·채석장 수로·패잔병 깃발이다. **9곳에 실제4~6studs 고도와 양방향 경사로/지상 귀환 길**, 활동 밀집 채석장에는 높은 충돌체 대신 지상 수로를 추가했다.
- 추가 군집 나무164그루와 잎 바닥·낮은 관목, 원본 TD 절벽/나무를 조합했다. 기존 지면·목표·체크포인트·본편 안내 선분을 예약해 새 충돌체가 침범하지 않게 한다. 지역 사이 직선 돌길을 굽은 흙길로 바꾸고96studs 지반과 열린 길 가장자리를 유지한다. 원본 TD 자산은 변경하지 않았다.
- 서버 StoryBoss=true인 적만 **◆ BOSS ◆** 금빛 배지를 표시한다. 이름/체력은 별도 행, 일반 적은 기존 소형 이름표다. 실제5종 보스와 호위/증원을 구분한다. 사망 시 전체 이름표가 숨고 MP/피해/보상은 바꾸지 않는다.
- Gold/Diamonds 상단 창을 없앴다. 모험에서는 **미니맵 아래 두 줄, TD 원본 아이콘+영어 이름/숫자, 배경/테두리/입력 표면 없음**으로 표시한다. 미니맵 배율을 상속하며 메뉴는 잔액 아래에서 열린다. 거점도 같은 투명 표시를 사용한다. 서버 InventoryState만 읽으며 미수신은 —이다.
- 시각 확인에서 기존 잔디 윗면과 석회암 윗면이 같은 높이라 각도에 따라 번갈아 보이는 것을 발견했다. 잔디 표면을0.08studs 분리해 해결하고 기존 생성 장면의 갱신도 지원했다.

## 시각 확인과 남은 수용

Studio Play의 별도 임시 복사본에서 네이티브 월드·TD Orc Warlord 모델·실제 머리 위 배지·HUD/미니맵/투명 잔액을 검토했다. 검토 장면은 기본 시작 스크립트를 끄고 합성 잔액12345/80·고정 보스 HP1800·Scriptable 검토 카메라를 사용한다. 전 지역 장면을 한 번에 확인하려고 이 임시 복사본에서만 Streaming을 끈다. 정식 빌드는 Streaming을 유지하며 별도 회귀로 검증했다. 실제 계정 저장·정상 캐릭터 성장/입력 전투 완주나 게시 클라이언트 증거와 구분한다.

정상 전투 완주·우회로 발견/만족도·모바일/패드·4인 성능·최종 사용자 미술 수용은 미검증이다. 실제 게시된 버전은 변경하지 않았고 릴리스 태그도 만들지 않는다. 다음 QA는 기존 본편 안내를 따라 이동/회피하며 새 나무 군집 주변의 적 추적, 경사로의 패드/터치 카메라, 미니맵 메뉴와 긴 잔액의 좁은 화면 가독성을 확인한다. 상위 티켓은 In Progress다.
