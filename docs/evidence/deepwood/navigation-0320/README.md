## 변경과 근거

사용자의 “네비 안내선을 모든 에픽1에, 미니맵 내 위치를 더 확실히, 진행이 안 되는 이유 설명” 요청이다.

- 기존 `DeepwoodJournal`의 `current.journal.main<3` 제한을 제거했다. DW-01~DW-07 모든 활성 목표와 발견 후 추적 중인 선택 퀘스트에 흐르는 바닥 안내를 제공한다. 기존 지역 연결 그래프/다리와 목표 위치를 사용한다. 목표 완료·전환·리스폰에 갱신하며 로비·트레이닝·사망·추적 목표 없음에는 숨긴다. 마지막 복원 선택의 거목 전초기지 귀환도 포함한다.
- 미니맵은28px 화살표/24px 글꼴, 어두운 원판·흰 테두리·청록 맥동·회전하지 않는 `YOU`로 플레이어를 강조한다. 적 표식 위에 그리며 지도 바깥/다리에서는 원 안쪽 가장자리로 고정해 사라지지 않는다. 이때 위치가 지도 안의 정확한 점이라는 의미가 아니며 `AtMapEdge` 상태로 구분한다. 지역 선택은 잘못된 고정 좌표 추정 대신 캠페인/훈련장까지의 실제 거리로 판단한다. 사망/캐릭터 없음에는 표식을 숨긴다.
- 서버는 현재 영웅이 참여 중인 교전의 `remaining`과 보호막 기둥 수를 읽기 전용으로 보낸다. 목표 아래에서 교전 시작/조사 상호작용, 남은 적, King Shaman 기둥 해제, 완료 저장 대기를 구분한다. 클라이언트의 표시가 피해/보상/완료 권한을 갖지 않는다.
- 승인 XP/Coins·스토리 선행·전투 참여/거리·사망·보스 전투 조건과 저장 스키마는 바꾸지 않았다. 새 게임 문구는 `K0Text`의 en-US 키로 관리한다.

## 스토리가 멈춰 보이는 조건과 조사 결과

기존 화면은 목표명과 범용 Interact 문구만 보여 주었고 교전 시작 여부·남은 적 수는 알리지 않았다. 코드는 다음 조건을 요구한다.

1. 로비의 **ENTER DEEPWOOD**로 들어간다. TRAINING은 스토리 진행을 제공하지 않는다.
2. 가까운 목표 표식에서 **F / 패드 X를0.3초 유지**하거나 터치/클릭 상호작용 UI를 유지한다. 이동만으로 교전이나 조사가 완료되지 않는다. 화면에 Reach가 있는 출구 목표도 현재 시험 런타임에서는 상호작용을 사용한다.
3. 시작한 교전의 적을 전부 처치한다. 이후 보급품·단서·주민·장치·출구의 각 상호작용이 남아 있다. 근처 임의 적 처치는 이 교전의 완료 기록을 대체하지 않는다.
4. King Shaman 보호막 중에는 임시 기둥2개를 상호작용으로 해제한다. 최종 복원 선택도 별도로 필요하다.
5. 사망/자격·거리 이탈·저장 대기에는 다음 목표가 확정되지 않을 수 있다. J의 RETRY CHECKPOINT는 완료한 기록을 초기화하는 기능이 아니다.

조사 시작 때 연결된 원본 Studio는 **Edit·Player0명**이었다. 사용자가 이전에 멈춘 정확한 개인 목표/남은 적/오류 상태는 읽을 수 없었으므로 특정 원인으로 단정하지 않는다. 이번 검사에서는 완료 엔진의 재현 가능한 결함을 찾지 못했다. 실제 Player로 첫 교전을 정상 공격으로 완료하고 보급품 조사 목표로 전환되는 것을 확인했다. 이는 전체 본편 정상 전투 완주나 게시 저장 수용이 아니다.
