## 바뀐 동작

- **성장 투자:** 실제 Studio의 Lv2 기사에서4스탯/1SP는 지급됐지만 모험 지역에서 거점 전용 편집 조건 때문에 +버튼이 비활성인 것을 확인했다. 안전한 야외에서는 스탯·스킬 숙련 투자를 허용하고 전투/적 근처/사망에는 거부한다. 편성·전직 등 나머지 거점 작업은 유지한다. HP 아래 남은 포인트 버튼과 레벨업 안내를 추가했다. 이 원인으로 확인된 상태와 과거 사용자의 모든 미지급 상황을 구분하며 임의 중복 지급은 하지 않았다.0.32.1 소스57e5ba4에서 먼저 반영했다.
- **일곱 스토리:** 기존58목표 ID와 보상을 보존하며 본편 필수57/선택3 하위 단계를 추가했다. 매복은 접근 시 시작하고 일부 기존 적 예산을2차 교전으로 나눈다. 단서 조사·발자국 추적·이동·주민 대화 선택·호위·순서 룬·장치를 사용한다. 호위 NPC는 플레이어가 멀어지거나 근처에 적이 있으면 기다린다. 각 완료 하위 단계·답변을 개인 저널에 저장한다. 기존 완료 저널은 다시 시작시키지 않는다.
- **지역 잠금:** 이전 스토리 완료 전에는 다음 지역을 막고, 클라이언트 벽을 우회해도 서버가 마지막 허용 위치로 돌린다. HP/MP 회복이나 보상을 지급하지 않는다. 선택 구역도 선행 본편 조건을 사용한다.
- **지도·카메라:** M 또는 **미니맵 왼쪽 위 꼭짓점 M버튼**으로2D 전체 지도를 연다. 내 위치·추적 목표·발견한 체크포인트와 잠김/미탐험/탐험을 구분한다. 서버 위치로 영웅별12×12셀을 지역마다 밝히며 클라이언트가 탐험 권한을 주장하지 않는다. 지도 텍스트에서 DW-01 같은 개발 ID를 제거했다. 줌은6~18studs다.
- **크기·표현 예산:** 기존 대비 지역 X/Z 길이와 배치 간격2.2배, 면적4.84배다. 지형 높이·몬스터·공격 사거리·승인 보상은 비례 확대하지 않았다. TD 나무를 보강하고 작은 원본 환경/적 리그는 Atomic으로 묶는다. 원본 환경 메시의 Automatic 상세도는 엔진에서 확인했다.
- **스트리밍:** 프로젝트에 최소64/목표384, Improved/Opportunistic/PauseOutsideLoadedArea를 직렬화했다. 로드된 TD 장식은100studs 밖 그림자/선택 조명,280밖 표시를 제한한다. 이는 클라이언트 장식 예산이며 서버 AI를 멈추거나 투명화만으로 메모리를 회수한다고 주장하지 않는다. 지도에는3D 월드를 복제하지 않는다. 스트리밍 재진입 때 길 안내 바닥 참조를 갱신한다.

## 실패와 수정 이력

최초 순수 검사는 새 단계 보상을 테스트 합계에 더하지 않아 실패했다. 테스트 누락을 고친 뒤 정본 합계를 통과했다. 보상 정본을 바꿔 맞추지 않았다.

0.33.0 Rojo 빌드는 생성됐지만 **런타임 RenderFidelity 쓰기 권한 오류로 월드 부팅 실패**했다. 쓰기를 제거하고 원본 Automatic 값을 확인하는 방식으로 바꿨다. [실패 로그](failed-0330-world.log).

0.33.1 월드 검사는 순서 룬이 개별 룬 대신 중심으로 안내되는 결함, 소수점 좌표에 대한 과도한 완전 일치 검사, 비스크립트 StreamingTargetRadius를 Lua에서 읽는 검사 오류로 실패했다. 룬 목적지를 고치고 좌표 허용 오차/빌드 XML 검사를 사용했다.0.33.1의 서버64·GUI331 통과와 월드 실패를 구분한다. [실패 로그](failed-0331-world.log). 버전/태그를 덮어쓰지 않았다.

기존 `rbxassetid://203785492`의 타입 불일치 경고와 Studio 내장 ManageCollaborators 플러그인 경고가 로그에 있다. 이번 기능의 assertion 통과와 음원·전체 자산 권한의 최종 수용을 동일시하지 않는다.

0.33.4는 스트리밍으로 parent=nil이 된 장식이 돌아올 때 원래 그림자/조명 값을 복구하도록 약한 참조 캐시를 보존한다. 실제 native Part/PointLight의 근거리→원거리→unparent/reparent→근거리 왕복3검사를 추가했고 원래 값/표시가 복원됨을 확인했다. UI/서버 스토리 코드는0.33.3과 같다.

0.33.5는 희소 탐험 셀을 문자열 키로 저장하고 이전 숫자 키도 읽는다. 실제 Roblox JSON 인코드/디코드 왕복 후 저널 유효성·기존 탐험 유지·추가 탐험·보상 불변4검사를 추가했다. 게시 DataStore 저장 자체의 수용을 대체하지 않는다.

## 실제 로컬 Play 관찰

0.33.2 미게시 Place의 실제 LocalPlayer를 생성하고 ENTER DEEPWOOD로 입장했다. Studio 세션만 확인한 서버 QA Script로100XP를 지급해 Lv2를 만들었다. **정상 처치로 레벨을 올린 증거는 아니다.** 실제 H UI에서 STR +4와 CONFIRM, Skills의 +1 MASTERY를 클릭했다. 서버 저장 상태는 STR4·Shield Bash mastery1, 잔여 스탯0/SP0으로 확인했다. 안전한 야외 투자와 M 키 전체 지도 열기가 동작했다. [서버/클라이언트 원시 관찰](play-0332.json).

시험 서버의 신뢰된 이동 API로 미완료2스토리 중심에 이동시킨 뒤1초 안에 이전 허용 위치로 교정됐고 HP265→265를 확인했다. 카메라 줌아웃 입력 후 실제 CameraType Custom에서 거리17.99999/max18이었다. 같은 시점 서버 장식996, 클라이언트 로드 장식115(그중 숨김68)를 관찰했다. **같은 빌드의 서로 다른 서버/클라이언트 집계이며 이전 빌드 대비 성능 개선율이나 메모리/FPS가 아니다.**

실제 화면에서 원형 미니맵의 사각 배경 누출을 발견해0.33.3에서 UICorner를 보존하고 원 밖 셀을 제한했다. 탐험한 구간의 실제 목표 연결 길도2D 지도에 추가했다.0.33.2 이후 두 지도 표시 파일만 변경했으므로 성장·서버 경계 증거는 재사용하며,0.33.3 표시 회귀는 별도로 확인했다. 최종0.33.3의 실제 LocalPlayer로 ENTER DEEPWOOD에 입장하고 미니맵 왼쪽 위 M버튼 클릭으로 전체 지도가 열리는 것, 원형 밖 사각 배경 누출 제거, 개발 ID 대신 Goblin Forest Trail 표시와3D 미리보기0개를 확인했다. [최종 Play 관찰](play-0333.json).

최종0.33.5 실제 Play에서는 Lv1 기사로 W+D7.2초 정상 이동해 첫 매복에 접근했다. F나 QA 강제 교전 없이 TD 고블린2마리가 자동 생성됐고 당시 HP250을 유지했다. [최신 Play 관찰](play-0335.json). 처치/전체 스토리 정상 완주 증거와 구분한다.

## 미검증과 다음 담당

실제7스토리 정상 공격 완주·스토리당 재미/길이·전면 선택 분기·최종 주민 리그/연출·모바일 실기기/패드/4인·게시 DataStore 재접속·저속망 경계/빠른 이동 스트리밍·프레임/메모리 개선량은 미검증이다.0.33.5는 시험 구현이며 “최고의 RPG 완성”이나 상위 티켓 완료로 처리하지 않는다. 카메라 제한만으로 지역 간 모든 원경이 미술적으로 가려지지는 않으며 수관·절벽·지형 굴곡을 후속 검증한다.

다음 QA는 같은 기기/품질/경로로0.32.0과0.33.5의 p50/p95프레임시간·GPU/메모리·로드 인스턴스·지역 왕복을 비교한다. 디자이너는 새 스토리가 단순한 이동/클릭 숙제로 바뀌지 않았는지 첫 방문을 관찰하고 목표 간 빈 시간·선택 이해·재도전 시간을 기록한다. 현재 개인 진행을 함께하는 동행자의 구출/진행 권한과 저장 실패 복구를 실제 서버에서도 확인한다.
