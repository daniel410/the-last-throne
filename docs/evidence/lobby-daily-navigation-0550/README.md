# 로그인 보상·로비 메뉴·Gold 교환 0.55.0

TLT-028/031/043/046/048/050/061/084 · 2026-10-31

- 로그인 보상: 7일 순서20/20/20/50/50/50/100 Gold(합310), UTC 날짜 기준, TD와 같은48시간 유예/7일 순환. 로비 로그인 아이콘과7칸 상태·수령/저장 확인을 제공한다. 같은 계정키에서 Gold와 수령 기록을 함께 갱신하며 응답 불명은 같은 요청ID/서버 시각으로 재시도한다. 로드 실패는0계정으로 대체하지 않는다.
- Diamond Shop: 10 RPG Diamonds→100 계정 RPG Gold를 GOLD 분류와 ALL에 추가했다. 서버 카탈로그 값과 RPG 계정 원자 거래를 사용하고 가방 공간과 무관하다. TD의 한 판용 Gold와 공유하지 않는다.
- 로비 퀘스트: 5에픽 카테고리, 기존3에픽별 본편7/선택4, 미수락 퀘스트 LOCKED와 선행/수락 안내, 진행·완료 표시. 후속2에픽은 COMING SOON이다. 옛 저장에서 이미 진행한 선택 퀘스트는 기존 수락 추론을 따른다.
- 로비 오른쪽 위: 배틀과 같은 메뉴 아이콘에 STATS & SKILLS / GEAR & BAG / JOURNAL / SETTINGS를 배치하고 메뉴가 열려 있는 동안 지갑과 겹치지 않게 한다. 로비 이외 기존 입력/표시 상태는 유지한다.
- ADVENTURES는 솔로를 항상 첫 행으로 표시한다. 파티 중에는 파티를 나가야 한다고 설명하며 서버 기존 규칙을 유지한다. Diamond Shop 아이콘은 TD 원본의 내부 문구 여백을 제외해 다른 아이콘과 비슷한 크기로 맞췄다.
