# 최종 DEX 속도 상한

2026-11-04 · TLT-015/027/050/052/084 · ENG → QA.

사용자 ‘좋아 적용해’에 따라 실제 게임 반영을 준비하던 중 ‘공속100% 이속30% 맥스’로 변경했다. 최종 계약은 네 영웅 DEX 기본 공격속도 최대+100%(2배), 이동속도 최대+30%(1.3배)다. 투자당 공속0.5%·이속0.1%는 유지하며 공속200P·이속300P에 상한 도달,316P 투자 결과는2배/1.3배다. 기존80%/40%를 대체한다. 스킬 시전/쿨다운/회피·방어 판정/다른 스탯/저장 배분은 유지한다.

- `lua tests/hero-stat-effects.spec.lua`:576 PASS. 네 영웅의 독립 효과·합법199/200/299/300/316P 경계·합성 예산 초과 입력의 계산 상한·원본 정의 보존.
- `lua tests/skill-stat-preview.spec.lua`:1,392 PASS. 기술 피해·숙련·장비 미리보기 회귀.
- 최신 native 재검사 첫 시도는 다른 run-in-roblox 프로세스의127.0.0.1:50312 점유로 실행 전 실패했다. 기존80%/40% 서버/모션106 PASS를 최신100%/30% 검사로 재사용하지 않는다.

0.71.4는80%/40%의 고정 커밋bf30285에서 Lobby/Battle 빌드에 성공했으나 게시하지 않았다. 이후 다른 작업이0.71.5를 예약했으므로 최신 변경은0.71.6으로 예약한다. 이전 산출물은 덮어쓰지 않는다. 빌드 소스/파일/해시/성공 여부는build.json에 연결한다.

게시 시도에서는 기존0.70.0 Studio에서0.71.4 로비 파일을 열었다. MCP 목록은 새 로비 창을 확인했지만 CUA가 기존 프로세스/빈 메뉴에 묶여 새 창을 선택하지 못했다. 기존 저장 창 종료와 CUA 재연결/초기화로도 해결되지 않았다. Publish/Overwrite는 실행하지 않았으며 공개 범위·TD Place는 변경하지 않았다. 최신0.71.6의 실제 게시 및 Roblox 클라이언트/기기/다인·입력·실제 UI/밸런스 수용은 후속 QA다. 미커밋 병행 작업은 빌드에서 제외한다. 부모 티켓은 완료 처리하지 않는다.
