## 조형과 빌드

Northern Windgap의 상부 적설 폭을 5.85에서 7.05스터드로 늘리고 깊이를 5.45에서 5.03으로 줄였다. 접근을 향해 밝게 드러나는 낮은 셰일 단부는 폭을 6.4에서 6.8로 늘렸다. 셰일 층과 눈 능선이 이어져 출구에서 다음 지역인 Frozen Vale을 예고한다. 지물 외곽, 부품 10개, 접지 높이와 장식 충돌 설정을 보존했다.

[형상 프로필](model-profiles.json)과 [Blender 비교판](blender-comparison.jpg)은 기존 모듈과 공통 Kit의 지물 데이터를 사용한다. Standard/sRGB 접근·귀환 렌더에서 적설 경사면과 전면 셰일의 노출을 확인했다. 비교판은 격리 모델과 비교용 조명을 사용했다.

[0.115.61 고정 Place](build.json)의 입력은 `7f3a0535`이다. Rojo 결과 해시와 포함 모듈의 바이트를 대조했다. 에픽 지도 105,907건, 도보 내비게이션 8,791건, 스토리 소품 4,264건, 전투 경로 77,381건의 Lua 회귀를 통과했다.
