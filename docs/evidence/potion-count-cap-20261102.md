# 스킬창 포션 수량 표시 상한

2026-11-02 · TLT-028/043/084 · ENG · 소스 수정·미빌드/미게시

사용자 요청으로 배틀 스킬바의 HP/MP 포션 수량이100개 이상이면 `99+`로 표시한다. 0~99개는 기존 `x0`~`x99` 표시를 유지한다. `src/client/K0Hud.luau`의 공통 아이템 버튼 갱신 경로만 수정하므로 두 포션 슬롯에 동일하게 적용된다. 아이콘·TD 셸·배치·실제 소유 수량·소비·서버 데이터는 변경하지 않는다.

검증: 로컬 Lua에서 변경 소스의 `button.ItemCount.Text` 우변을 직접 읽어 실행했다. 0/1/98/99/100/101/999/1000의 기대값 `x0`/`x1`/`x98`/`x99`/`99+`/`99+`/`99+`/`99+`와 모두 일치했다. `git diff --check` 통과. 별도 영구 테스트는 추가하지 않았다.

미검증: Studio 화면·게시 클라이언트·실기기 수용. 게임 빌드와 게시를 실행하지 않았으므로 VERSION 변경·릴리스 태그는 없다. 다음 담당 QA는 두 슬롯의100→99개 소비 시 `99+`→`x99` 전환과 기존 배지 가독성을 실제 화면에서 확인한다. 상위 티켓은 완료 처리하지 않는다.
