# 대장간 아이템: 왼쪽 큰 그림·오른쪽 설명

2026-11-09 · TLT-028/029/052/057/084 · 0.93.4 · ENG→QA

사용자 첨부 스크린샷의 Traveler Staff 카드를 기준으로 “이미지를 왼쪽에 크게, 설명을 오른쪽으로” 옮겼다. 앞선128px 확대만으로는 카드 하단 설명이 이미지 영역을 제한하므로 배치를 변경한 가독성 수정이다. 기존 승인 TD 프레임·이미지·영어 문구를 재사용했다.

- 대장간 구매/판매/강화 카드는 한 열로 넓게 표시한다. 물약/다이아 상점의 열 수와 배치는 유지한다.
- 왼쪽44%는 이미지, 오른쪽56%는 이름과 설명이다. 투명 PNG의 비율은 기존 Fit으로 보존한다. 구매/판매 이미지 영역은 카드 높이에서80px, 강화는128px를 뺀 높이를 쓴다. PC 구매 카드760×320에서 그림 영역318.4×240px, 정사각 PNG의 실제 Fit 크기240px로 이전128px보다1.875배 커진다.
- 이름은 우측 상단, 설명은 그 아래에 위 정렬한다. 거래/강화 버튼은 하단 전체 폭을 유지한다. 재료 아이콘과 구매 확인·가격·능력치·명령 계약은 변경하지 않는다.

검증: 격리 Studio(Edit, PlaceId0/플레이어0)에 실제 ArmoryView/EnhancementView와 현재 아이콘 레지스트리를 적용했다.1280×720/844×390/568×320/390×844 크기 Frame에서 구매/판매3분류와 강화,28경우를 실제 CoreGui로 생성해 **5,236검사 PASS**. 판매 가능한 카탈로그 fixture를 포함하며 렌더 중 거래 전송0회, 그림/우측 글자/하단 버튼 비중첩, 모든 이름/설명 TextFits,44px 터치 높이를 확인했다. [결과](layout.json). 사용자의 실제 기기/계정/게시 화면 검증과 구분한다. 일반 크기 조정이므로 새 별도 회귀 테스트 파일은 추가하지 않았다.

이번 연결 Studio에는 실제 서버 Place가 없으며 열린 로컬0.93.3 Play 세션은 중단하지 않았다. 새 소스·빌드로 반영하고, Roblox 게시는 하지 않는다. 다음 담당은 QA/사용자의 실제 대장간 화면에서 그림 크기·스크롤 밀도 수용이다. 부모 티켓 완료 처리 없음.
