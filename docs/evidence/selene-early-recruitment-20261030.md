# Selene 초반 합류 문서 반영

2026-10-30 · TLT-016/060/061/072 · PLAN · 문서 반영

사용자가 승인한 첫 만남/합류 제안을 승인 줄거리·통합 제안서·동료 설계·README/plan/backlog·시스템 계획·현재 상태·결정표에 반영했다. Dawnspire 첫 만남, Deepwood 초반 구조 완료/안전한 야영지 도착 시 무료 해금, 야영지 선택 편성으로 구분한다. 과거 HG에서 영입 시점 미정이라는 문구를 정리했다.

검증: `git diff --check` 통과. 승인 개요와 제안서의 줄거리 일치,5에픽 유지,무료/선택 편성·합류 조건 정적 검사,신규 로컬 링크 존재 확인 통과. 보상 정본·안정ID·런타임·VERSION 무변경을 변경 목록으로 확인했다. 기존 승인 내용의 문서 반영이며 새 사례 조사/기능 확장은 수행하지 않았다.

미검증: 정확한 구조 시나리오ID/체크포인트, 영어 대사/키,실제 개인 해금·편성·동행/지원 AI·저장 실패/재접속·4인 제한,실기기/연령대 재미. 게임 빌드·게시·릴리스 태그는 생성하지 않고 상위 구현 티켓도 완료하지 않는다.

다음 PLAN/DES: 기존 스토리/보상과 합류 체크포인트 대응·영어 원고를 확정한다. ART는 TD Priest/수녀 타워 원본을 확인한다. ENG/QA는 서버 권위 개인 해금과 중복/저장 실패·재접속/인원 변화 및 미동행 본편 완주를 구현/검증한다.
