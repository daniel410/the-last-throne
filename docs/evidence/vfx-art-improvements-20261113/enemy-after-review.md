## 증거와 판정 범위

고정26의 개선 후 `enemy/sheet-01~08.png`의60조합, `enemy-rings/sheet-01~02.png`의고리12개, `enemy-impacts/sheet-01~03.png`의근접접촉20개를 직접 열람했다. 개선 전 동일 도구의 enemy sheet03/04/05, ring sheet01, impact sheet01/02와 직접 비교했다. 또한 최종28 `warnings-final/sheet-01~02.png`의12개와 불가6종 개별640px 원본을 직접 열람해 기존26 `warnings`와 비교했다. enemy/ring/impact 렌더러는26→28 변경이 없어 기존 캡처를 유지한다. 전체146개의 새 개별 ART 수용을 뜻하지 않는다. 이전 리뷰의 source146·primary대표72·나머지74의 소스/공유모티프 구분은 유지한다.

## 유지 방향과 남은 확인

불/얼음/흙/물리의 승인 색·재질·외곽 모티프, 원래 지면을 따라가는 단일 경계, 고리의 안전 중심을 유지한다. 비활성 `BossHeroImpact.web` 라이브러리 분기를 실제 공격 결함처럼 평가하거나 활성화하지 않았다.

EN-ART-01 재수정은 원래 경계의 방향/면적을 건드리지 않고 화면 최소 크기만 확보하는 표현 보완이다. 기존 경계 Part의 부모 수명에 종속하고, 고리는 외곽만 선택하며, `AlwaysOnTop=false`로 실제 지형/캐스터 가림을 따른다. 추가 BasePart는0개다. 컴파일 PASS이며 root는 최종 고정 `c1b578d470a26536bd1a22895f265b91d3c16669`/0.104.28에서 enemy15,916·legacy66,030·전체17suite95,423 PASS와 빌드/15모듈 원문 일치를 확인했다. 최종 예고12 재촬영에서도 기존 미세쌍대시보다 명확한 평행 빗금이 보이는 것을 직접 확인했다.20px은 GUI 설정치이며640px 출력에서 실측20px라는 뜻은 아니다. 가시성 판정은 최종 그림을 근거로 하고 엔진 통과만을 근거로 삼지 않았다.

다음 담당은 root QA/ART다. 새 예고12의 해당 fixture 가시성 점검은 완료했다. 이후 실제 눈/용암/숲 바닥, 경사/절벽, 실제 종별 모델/크기·피격 위치/카메라·4인+AI 가림·낮은 그래픽/실기기 GPU·색 제거 판독·사용자 미술 수용을 분리 검증한다. 정적 도구/엔진 구조/정규화 그림 통과로 이 조건을 완료 처리하지 않는다.
