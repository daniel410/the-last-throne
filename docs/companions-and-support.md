## 1. 확정 방향과 설계 상태

사용자 결정에 따라 **플레이어 클래스는 기사·엘프·드워프·마법사4종**이다. 성녀는 주요 스토리NPC·선택형AI지원 동료·거점/왕좌 수호전 지원으로 활용한다. 성기사는 계속 기사 클래스의 두 전직 계열 중 하나이며 직접 검·방패·성광으로 싸운다.

플레이어 클래스 수와 세계관의 문명/팩션 수는 다르다. 성녀를 플레이어 선택에서 제외해도 **다섯 문명·다섯 수호자의 역사·TD 영웅5종·타워30종·주요 동료5명**은 유지한다. 교단의 기억·영혼 역할과 셀레네의 개인 이야기도 유지한다.

성녀의 NPC 전환은 확정 방향이다. Selene의 합류 흐름은 아래 사용자 승인 기준을 따른다. 능력 구성·AI 우선순위·수치·보상은 실제 플레이로 검증할 제작 기준안이다. 기존 심판/축복은NPC 기술의 역할 태그와 교단 인물의 개성으로 활용하며 플레이어의 두 전직이나79P 트리로 만들지 않는다.

### Selene의 첫 만남·합류·편성 · 사용자 승인

2026-10-30 · TLT-016/060/061/072. 플레이어는 **Dawnspire에서 만나고, 에픽1 Deepwood 초반 구조 임무를 마친 뒤** Selene를 동료로 해금한다.

| 순서 | 사건 | 플레이어에게 생기는 변화 |
| --- | --- | --- |
| 첫 만남 | Dawnspire 습격에서 플레이어는 주민을 구하고 Selene는 다친 주민을 돌봄 | 서로 돕고 얼굴을 익힘. 아직 전투 동료로 해금하지 않음 |
| 함께하는 구조 | Deepwood 초반 보급대 구조 과정에서 주민을 함께 구함 | 회복·보호 역할을 짧게 소개. 기존 동행 상한을 유지하며 4인에서도 선택 동료 슬롯 내 지원 또는 이야기/구조 연출로 소개 |
| 동료 해금 | 구출한 주민이 안전한 야영지에 도착하고 구조 임무를 완료 | Selene가 앞으로 함께하겠다고 제안. 무료로 동료 해금, 유료 구매·숨은 퀘스트·신뢰도 반복 요구 없음 |
| 선택 편성 | 야영지에서 동행 여부를 선택 | 해금과 편성은 별개. 자동 강제 편성하지 않으며 나중에 거점에서 선택 가능 |

정확한 기존 스토리ID/체크포인트 대응은 새 5에픽 상세 시나리오에서 정한다. 초반 구조를 완료한 뒤의 해금이며 King Shaman 격파나 에픽1 전체 완료까지 기다리지 않는다. 기존 보상 정본·스토리ID를 임의 변경하거나 새 XP/Gold 보상을 추가하지 않는다.

이후 Frozen Vale에서는 피난민, Ember Caldera에서는 광부, 어둠의 숲에서는 구출 정찰대를 돌본다. Haunted Graveyard에서는 친구들과 최종전을 돕고 Dawnspire 귀환 축제에 함께한다. 미편성 상태에서도 주요 이야기에는 등장하지만, 추가 전투AI로 계산하지 않는다. Selene 동행 없이도 모든 필수 진행이 가능하다.

해금은 개인의 해당 구조 임무 완료로 서버가 확정해야 한다. 파티장의 해금만으로 다른 사람을 해금하지 않는다. 재보고는 동료/지원 보상을 중복 생성하지 않고 저장 실패 시 성공으로 표시하지 않으며 재접속 후 확정 상태에서 복구한다. 4인일 때도 해금과 선택 편성이 가능하며 파티 전체 AI최대1명 제한을 적용한다. 저장 단위·영어 키·구체 구현은 ENG 후속이다.

## 3. 인원과 동행 슬롯

| 실제 플레이어 | 일반 모험의 전투AI동료 | 성녀 적용 |
| --- | --- | --- |
| 1명 | 최대2명 | 선택 편성 중1명으로 동행 가능, 성녀 없이도 본편 진행 가능 |
| 2명 | 파티 최대2명·플레이어별 최대1명 | 기존 슬롯 안에서 선택, 성녀라는 이유로 추가 슬롯 없음 |
| 3명 | 파티 최대1명·대표 편성 | 선택 후보 중 하나, 자동 강제 배정 없음 |
| 4명 | 파티 최대1명 | Selene를 포함한 추가 AI동료를 선택 편성 가능 |

선택형 동료 없이 출발하는 것도 허용한다. 동료 수에 따른 난도/지원 보정은 플레이테스트에서 조정한다. 위 최대값과 실제 동료 수를 서버에서 구분하며 존재하지 않는 동료의 피해/회복 기여를 계산하지 않는다.

이야기에 필요한NPC는4인에서도 대화·연출에 등장할 수 있다. 왕좌 수호전의 고정 성역·지원 병력은 일반 동행 슬롯과 다른 임무 예산으로 산정하고 적·플레이어·VFX를 포함해 부하를 검증한다.8인 레이드는 성녀AI나 힐러 플레이어를 입장 필수 조건으로 두지 않는다.

AI동료는 전투/서버 이동 중 중복 소환하지 않는다. 편성 변경은 거점에서 하고 재접속·파티 인원 변경 시 유효 슬롯을 다시 확인한다.4인 파티에서도 선택 편성한 AI최대1명만 전투에 참여하고 대사NPC를 추가 전투원으로 자동 활성화하지 않는다.

## 4. 지원 능력의 우선순위

성녀의 전투 목적은 위험한 순간을 완화하고 다시 공격할 기회를 주는 것이다. 플레이어의 공격·방어·회피 판단을 유지한다.

| 기능 후보 | 사용 목적 | 필수 제약 |
| --- | --- | --- |
| 보호의 인장 | 예고된 큰 공격에 짧은 보호막 | 지속/흡수량/재사용 제한, 실제 예방 기여만 계산 |
| 정화 | 제거 가능한 저주·위험한 상태 해제 | 해제 불가 보스 기믹과 구분, 파티 전체 상시 자동 면역 없음 |
| 축복맥동 | 전열 정비를 돕는 제한 회복 | 초당/전투당 회복 예산·재사용 제한, 과잉 회복으로 자원 획득 없음 |
| 성광창 | 지원이 필요 없을 때 적을 견제하고 연계 보조 | 낮은 공격 기여, 플레이어 대신 표적을 자동 처치하는 주력으로 만들지 않음 |

위4개는 우선 검증할 행동 후보이며 별도 지원 기술 제작량이 최종4개로 확정된 것은 아니다. 이전 성광·정화·성역·심판/축복 기술 아이디어는NPC별 행동/연출의 참고로 남긴다. 플레이어용9액티브/3궁극기나 두 전직 계보를 성녀NPC에 그대로 제작할 의무는 없다.

AI는 `자기 위험 회피 → 유효한 보호/정화 판단 → 제한 회복 → 기본 성광 견제/집결` 순서를 초기안으로 삼는다. 효과 범위·시야·경로·생존·쿨다운·자원을 확인하고 대상을 고른다. 실전에서는 보호가 치유보다 필요한지와 대상 우선순위를 관찰해 수정한다.

자신이 적의 위험 구역에 서서 계속 시전하거나, 대상이 이미 다른 보호막으로 충분히 안전한데 같은 지원을 반복하지 않는다. 큰 공격의 회복 구간에는 플레이어가 다시 공격하도록 짧은 명령/이펙트로 기회를 보여 준다. 무적·전멸 판정·즉사 기믹을 무조건 무효화하지 않는다.

## 5. 조작·생존·다른 보호 효과와의 관계

지원은 기존 동료의 집결·집중 공격·상황 명령 체계에서 사용한다. 플레이어가 장착하는 액티브 기술 및 궁극기와 분리하며, 성녀를 동행했다는 이유로 상시 정밀 조준 버튼을 여러 개 추가하지 않는다. 터치 명령 UI와 자동/수동 우선순위는 후속 조작 검증으로 확정한다.

네 플레이어 클래스는 성녀 없이도 이동·회피·고유 방어·솔로 공격과 무료 체크포인트 재도전으로 본편을 완주한다. 클래스 공통의 전투 밖 회복·체크포인트/일반 회복 소모품 규칙을 별도로 설계하고 유료 상품·특정 동료 합류로 잠그지 않는다. 유료 회복·부활로 성녀의 빈자리를 채우지 않는다.

보스의 필수 저주/장치 해제는 모든 클래스가 사용할 수 있는 상호작용·위치 이동·환경 장치 등의 경로를 둔다. 성녀의 정화는 위험 완화와 선택의 편의이며 필수 기믹을 혼자 독점하지 않는다. 보호/정화 지원이 없어도 실패 원인을 배우고 재도전할 수 있어야 한다.

성기사의 서약 표식·폭발은 플레이어 근접 기술로 유지한다. 성녀는 그 표식을 대신 쌓거나 소비하지 않는다. 성녀 보호막과 성기사 보호막이 같은 중첩 태그를 쓰면 [기사 전투 명세](knight-combat-spec.md)의 큰 잔량 우선 규칙을 적용하고, 별도 태그라면 합산/순서/상한을 명시한다. 성녀가 막은 피해를 성기사의 개인 자원 기여로 자동 복제하지 않는다.

동료의 쓰러짐·재기·이탈은 후속 공통AI 사양에서 정한다. 전투 중 무한 자동 부활과 회복을 기본안으로 두지 않으며, 특정 동료 생존만으로 메인 퀘스트의 완료를 잠그지 않는다.

## 7. 성장·저장·제작량

NPC/동료에는 `companionId`, 합류/개인 임무·관계 이력, 해금한 지원 행동, 편성·명령 설정을 기록하는 초기안을 둔다. 플레이어의 `baseClassId`·전직 단계·79P 투자와 구분한다. 성녀NPC 키를 플레이어 생성/전직 요청으로 보내도 서버는 허용하지 않는다.

관계/개인 임무는 지원 방식·연출·대화의 선택을 넓히되 기본 생존 수단을 잠그지 않는다. 무료 편성 실험과 거점 회복을 지원하며NPC 성장에 Diamonds·플레이어 스킬포인트를 요구하지 않는다. 수치 성장·해금 순서·RPG 캐릭터 사이의 기록 공유 범위는 미정이다.

플레이어 제작 예산은 **36액티브·12궁극기·216노드·8전직 계열·32단계 정의**다. 동료5명의AI·모션·대사·지원 행동·교단NPC·수호전 지원은 별도로 산정한다. 플레이어 성녀1종을 제외했다고 이 별도 제작량까지 사라진 것으로 계산하지 않는다.

## 8. 후속 검증

- 성녀 동행/미동행으로 같은 본편의 이동·전투·보스·저주 해제를 끝까지 진행할 수 있는가.
- 위험 회피·보호/정화·회복의 우선순위가 읽히고 무한 지원·무한 부활이 생기지 않는가.
- 성기사·다른 성녀NPC와의 보호막 중첩·정화 동시 처리·지원 기여가 중복되지 않는가.
- 1/2/3/4인 슬롯·개별 편성·인원 변경·재접속/서버 이동에서 유령/중복 동료가 생기지 않는가.
