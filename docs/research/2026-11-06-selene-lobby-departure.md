# Selene 로비 동행과 모험 출발

2026-11-06 · TLT-016/028/043/057/061/072/084 · 조사/설계 근거. 사용자 지시가 제품 결정의 원천이다.

문제: 로비에서 지원권을 산 뒤 사용하려면 다시 모험 캠프를 찾아야 해서 구매 결과가 보이지 않는다. 사용자는 로비에서부터 따라와야 한다고 지정했다.

비교 원천은 Blizzard의 [Diablo IV: Vessel of Hatred 용병 소개](https://news.blizzard.com/en-us/article/24128995/delve-deeper-into-nahantu-with-mercenaries-dark-citadel-and-more)다. 2026-11-06 웹 원문 확인, gamescom/Vessel of Hatred 소개 맥락이며 현행 시즌 수치 검증은 아니다. 공식 설명의 관찰 사실: 해금한 용병을 고용해 주요 동료로 선택하면 솔로 전투를 함께하고, 별도 Reinforcement는 전투 조건에 반응한다. 실제 플레이를 관찰한 결과는 아니다.

적용 해석: 동료 선택의 결과가 출발 전부터 보이고 이후 전투 동행으로 이어져야 한다. TLT는 사용자 지시에 따라 로비의 외형 동행을 지원권 활성화와 분리한다. 신규 구매는 서버 계정에 출발 선택을 함께 저장하고 기존 보유권도 선택 영웅 로비 진입 시 준비한다. 로비에서는 무료로 따라오고, 확인된 메인 모험 입장 뒤 파티 슬롯이 비면 한 스토리 권리를 소비한다. 무료 체험은 기존 영웅별1회가 먼저다. 캠프에 가서 다시 초대하는 절차를 출발 조건에서 제거한다.

디아블로의 솔로 전용/용병 성장·Rapport·별도 통화·스킬 구성은 가져오지 않는다. TLT의4인+AI1·Priestess NPC·영입 해금·Gold 가격·한스토리 이용권·동일 스토리 재접속 무추가소비를 보존한다. 캠프의 휴식/재초대는 기존 대안으로 유지한다. 사이드 원정 입장만으로 다음 메인 지원권을 소비하지 않는다. 로비 자동 동행 승인과 별개로 모험 내 스토리 완료 후 유료 연속 갱신은 추가하지 않는다.

비용/위험: 로비에 플레이어별 외형 모델1개와 기존 추적/스킨 모션을 재사용한다. 로비 인원은 전투 파티와 다르므로 외형 동행에는 파티 전투 슬롯을 쓰지 않는다. 모험에서는 기존 파티 전체1명을 지키며 슬롯이 차면 나머지 계정의 출발 선택과 credits를 보존한다. 소비 전 계정 저장 확인, 불명 응답의 동일 요청 재조회, 입장 후 원정 scope 확정이 필요하다. Roblox 별도 사례는 이번 변경의 결정 질문에 추가 근거가 필요하지 않아 조사하지 않았다. 성능 수치는 실제 기기 측정 전 미확인이다.

최소 검증: 구매/기존권→로비 모델 생성·실제 추적→캠프에서 먼 입장→1회 소비, 계정 재로드·저장불명 복구,4인 경쟁 시1명만 활성화, 스토리 완료 후 비갱신, 사망/계정불명/출발 때 로비 모델 정리. 엔진 모의 계정 검사와 게시 Teleport/실계정/모바일 수용을 구분한다. ENG 구현 후 QA가 정상 사용자 경로와 프레임 비용을 확인한다.
