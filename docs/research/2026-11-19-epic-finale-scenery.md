# 다섯 에픽의 결말 지형과 귀환 장면

2026-11-19 UTC · G5 · TLT-061 Deepwood / TLT-065 Gloamwood / TLT-062 Frozen Vale / TLT-063 Ember Caldera / TLT-064 Haunted Graveyard

0.113.24 Studio 비교에서 Frozen Vale의 접근로 암빙은 낮아지고 중앙 표지판과 분리됐지만 먼 거리의 방풍 울타리는 여전히 작았다. Gloamwood 뿌리와 Haunted Graveyard 석조는 야간에 윤곽 일부가 드러나도 배경과 대비가 작았다. 이번 제작 범위는 각 에픽의 마지막 이야기다. 화물 이동의 흔적, 기후가 바뀌는 북쪽 길, 동맹이 확보한 귀환 방향을 기존 상호작용 주변의 지형과 시설로 전달한다. ## 배치와 검증 인계

- 공유 원본 후보는 `model.maps`의 바위·설원·묘지 복합 지물과 `model.forest-kit`의 지형·식생이다. 복합 지물의 형태, 스케일, 접지를 검토하고 각 결말 장면의 얕은 단면과 작업 시설은 RPG 입체로 조형한다. [공유 자산 레지스트리](../../assets/shared/td-asset-registry.json)
- 모델은 진행 전후에 성립하는 고정 장식으로 배치한다. 기존 스토리 물체, 보스 공간, 통과로와 목표 표지를 분리해서 읽을 수 있도록 위치와 높이를 조절한다. 대표 장면부터 같은 카메라, 조명, 스토리 상태의 전후 화면을 비교한다. [맵 제작 공통 수용 기준](../../agent.md#맵-제작-호출과-공통-수용-기준)
- Studio에서 실제 챕터 생성, 접지와 비충돌 속성, 접근·귀환 시야, 조사 조작면과 기존 이동로를 확인한다. 실기기의 야간 판독, 전투 카메라와 스토리 완료 직후 실제 귀환, 사용자 미술 수용은 플레이 검증에서 다룬다. [제품 계약](../product-contracts.md)
