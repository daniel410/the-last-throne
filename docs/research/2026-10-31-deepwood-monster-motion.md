## 제작과 실험

Blender MCP 내부 API로 TD 텍스처 검토 GLB10종을 불러오고 실제 분리 파츠를 강체 컨트롤러에 연결한다. 종류마다 Idle/Walk/Attack/Heavy/Stunned의5개 논리 클립, 총50개를 제작한다. 컨트롤러5개별 Action이므로 Blender Action 수는250이다. Bezier F-curve를61표본으로 내보내 게임에 연결한다. 별도 Python 모델 생성 스크립트는 사용하지 않는다.

걷기는 실제 수평 이동 거리/종별 보폭으로 위상을 진행한다. 보행 정지·텔레포트 시 헛걸음을 방지하고, 캐시한 메시 경계와 모터 변환을 이용해 발 높이를 보정한다. 공격은 서버에서 시퀀스·시작 시각·준비/활성/회수 시간을 단일 문자열로 발행하며 첫 활성 시점을 제작 곡선 .62에 대응한다. 관찰자가 늦게 로드돼도 같은 시각의 포즈를 얻는다. 클라이언트는 서버 루트·피해·보상·판정을 변경하지 않는다.

기존 원본의 파츠 분할 한계는 유지한다. Goblin/Orc/Ogre/Warlord는 독립 다리가 있지만 Shaman·일부 보스는 하반신 일체형, Enraged Warlord와 Slime은 몸체 일체형이다. 관절이 없는 메시를 새 리그로 완성했다고 보고하지 않는다. 전신 스키닝·무릎/팔꿈치 추가·지형별 발 IK·실기기/다인 성능·최종 미술 수용은 후속이다.

스턴은 피해가 실제 적용된 드워프 root3 계열10개 기술에만5초를 적용한다. 재타격은 최근 타격부터5초로 갱신하고 합산하지 않는다. 이동·준비/활성 공격·대기 중 경로 결과를 취소하며 사망/리셋에서 지운다. 보스 예외는 추가하지 않았다. 초기5초는 사용자 지정값이며 보스 공략 밸런스 수용은 남아 있다.

DW-01의 유한 웨이브 구성만 G→S→G→혼합으로 반복한다. 기존 레벨·각 웨이브 수·동시2/3명·합계30명·XP/Gold 총량은 유지한다. 스토리 슬라임은 기존 스토리 사망 경로를 사용하므로 분열 무한 증원을 만들지 않는다.

검증·빌드·남은 수용은 [제작 기록](../evidence/deepwood-motion-0450/README.md)을 따른다. 다음 QA/DES는 실제 전투에서 경고 가독성,5초 제어의 난이도, 조합 변주와 기기 성능을 수용한다.
