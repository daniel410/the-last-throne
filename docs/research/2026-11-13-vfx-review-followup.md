# VFX 재리뷰 후속 적용 근거

TLT-033/054/055/056/057/084 · 2026-11-13 · [재리뷰](../evidence/vfx-rereview-20261113/README.md)의 수정 요청.

[Diablo IV VFX 개발 설명](https://news.blizzard.com/en-us/article/23746639/diablo-iv-quarterly-updatedecember-2021)의 VFX Philosophy/Combat Improvements를 다시 열어 확인했다. 2021년 개발 자료의 사실은 전투 정보의 우선순위, 강한 기술의 시각 위계, 조명별 가독성, 공격 방향에 맞는 접촉이다. 현행 시즌의 밸런스 근거로 사용하지 않는다.

[WoW Legion7.3 공식 전투 효과 설명](https://worldofwarcraft.blizzard.com/en-us/news/20946579/patch-73-new-combat-animations-its-magic)은 재열람403이었다. 직접 본문을 확인했던 [기존 조사](2026-11-12-wow-vfx.md)의 직업/전문화 정체성·반응성과 원형 보존 원칙을 재사용한다. 이번에 현행 Retail/Classic 영상을 새로 분석했다고 주장하지 않는다. Roblox/RPG 보완은 같은 날 작성된 [원소 동작 조사](2026-11-13-roblox-element-motion.md)와 [기존 후속 조사](2026-11-13-vfx-art-followthrough.md)를 유지한다.

우리 게임에 적용하는 해석은 궁극기의 긴 범위선보다 포탄/활 왕관/수관이라는 집중 형상을 읽히게 하고, 일반 기술은 회전축·끊어진 호·조준 괄호·깃·상승/뒤쪽 흐름으로 나누는 것이다. 구체 치수·형상은 우리 게임의 미술 선택이며 타 게임에서 측정한 값이나 가져온 자산이 아니다.

대안은 전체 광량/면적 확대, 외부 원본 추가, 기존 절차적 형상 재배치다. 기존 예산·팔레트와 로드 경로를 유지하는 마지막을 채택한다. 비용은 왕관 면/수관 잎의 제한된 추가와 일부 프레임 변환이며, 기존 장식을 재배치·감소하는 부분도 있다. 성능 향상으로 단정하지 않는다.

예고 결함2건은 별도 게임성 설계 없이 기존 설정 문구와 서버 돌진 시간에 맞춘다. 피해/보상/스킬 범위·펄스·속성·해금·MP/쿨다운은 수정하지 않는다. 최소 실험은 기존18묶음 엔진 회귀,146공격의 설정 전환과11돌진의 서버 충돌/표시 대조, 동일 카메라/시점의 전후 표본이다. 실제 지역·다인·실기기·사용자 미술 수용은 후속 QA다.
