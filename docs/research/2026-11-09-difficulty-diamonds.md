# 난이도별 초회 Diamonds 적용

2026-11-09 · TLT-027/041/050/052/057/084 · PLAN/ENG → QA. 같은 대화에서 확인한 [기존 조사](2026-11-09-all-epic-diamonds.md)의 공식 근거를 재사용한다.

Diablo III 1.0.4 [공식 패치](https://news.blizzard.com/en-us/article/7029347/patch-1-0-4-now-live)는 난이도별 최초 퀘스트 완료의 XP/Gold 보상을 구분한다. TLT 적용은 최신 사용자 요구에 따른 난이도별 초회권 분리이며 디아블로 유료재화 지급 방식/최신 수치라는 주장이 아니다. 기존 문서의 난이도별 권리 미도입 설명은 이번 사용자 결정으로 대체한다.

Roblox [경제 균형 가이드](https://create.roblox.com/docs/production/game-design/balance-virtual-economies)의 신규 유입 영향·소비 관점에서, Easy만105→4난이도 총420개로 한정 공급 상한이315개 늘어난다. 현행 초기화권100개 기준 전부 모아 소비하지 않았다면4장 구매와20개 잔여가 가능하다. 다른 영웅 중복은 사용자 선택대로 계정에서 차단하고 가격·전투·일반재화 보상은 바꾸지 않는다. 실제 소비/성장 속도·구매0 진행 수용은 후속이다. 최소 검증은 실제35스토리×4난이도 연속 진행·재시도·다른 영웅·기존 완료 복구·영수증과 잔액 저장 응답 불명 회복이다.
