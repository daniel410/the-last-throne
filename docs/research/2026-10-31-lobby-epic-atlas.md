# 로비 에픽별 지도

TLT-028/061/084 · 2026-10-31

[기존 지도 조사](2026-10-30-atlas-and-mage-balance.md)를 재사용하며 [GW2 공식 New Player Guide](https://www.guildwars2.com/en/new-player-guide/)와 [Roblox UI 제약](https://create.roblox.com/docs/ui/size-modifiers)을 재확인한다. 탐험 지도는 지역 발견/잠금 구분과 지명 가독성이 필요하다. 이 사례에서 착안해 작은 화면을 축소만 하기보다 에픽별 분류·스크롤·확대·FIT를 적용한다. 이는 시장 성과를 검증한 결론이 아니다.

사용자 요청에 따라 Deepwood/Frozen Vale/Ember Caldera의 실제 좌표·지형·경로·개인 탐험 상태를 배틀 Canvas와 공유한다. 잠긴 구역은 숨기지 않고 선택 시 선행 스토리 이름을 설명한다. 후속 에픽 Gloamwood(영문 가칭)/Haunted Graveyard는 실제 콘텐츠가 없으므로 COMING SOON으로 구분한다. 별도 순간이동/퀘스트 해금 기능은 만들지 않는다.

비용/최소 실험: 한 번에1개 에픽10지역의2D 지도를 만들고 탭 전환 시 파기한다. 개인 진행 스냅샷과 CampaignAccess를 읽기만 한다. 신규 영웅/에픽 경계/완료 영웅/영웅 미선택·작은 세로/가로 화면, 기존 배틀 전체/미니맵 회귀를 검사한다. 실제 기기 가독성·입력 수용은 후속이다.
