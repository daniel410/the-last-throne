사용자가 확률 실패 도입을 요청했으므로 기존100% 강화안을 대체한다. 실패 시 단계 유지/재료 소모를 추천하고 하락/파괴는 제외한다. 이 판단은 대상층 손실 부담·복구/권리 구현 비용을 줄이려는 설계 가설이며 타 게임 유지율로 입증한 사실이 아니다. 천장을 도입하면 극단 비용을 제한할 수 있으나 실패 누적 이관/영웅·장비 이동 계약이 늘어나므로 첫 안에는 제외하고 실제 연속 실패/중단 비율을 본다.

최소 실험은 현재4클래스/동일Lv 장비와9단계 서버 모형이다. 실패 횟수 분포·실제 보석/마석·교환Gold 순소비·+3/+5/+9까지 시간·실패 후 중단/오해·실제 요청 중복0건을 관측한다. 무료 본편에는 특정 강화 단계를 강제하지 않는다. 제작 비용은 확률 규칙/서버 내구성 시도·성공/실패 원장·두 신규 재료·TD 안내/결과 UI·독립 저장/기기QA다.

PLAN은 기대 비용과 무료 수급을 조정하고 ENG는 재시도 재추첨/중복 소비를 막으며 DES는 성공·실패·저장 대기를 구분한다. QA는 경계 난수/다중 서버/재접속·4인+AI 기기를 독립 검증한다. [새 강화 계약](../production/equipment-enhancement-v2-2026-11-03.md)에 인계하며 실제 재미/기기/저장 결과는 미검증이다.
