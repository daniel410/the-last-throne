# 기사 가로베기 마무리 비교

2026-11-14 · TLT-005/084 · ENG/RES → QA

질문은 사용자 지정 세 번째 공격을 크게 가로베기로 읽히게 하는 방법이다. 최신 사용자 요청이 기존 영상의 찌르기 해석보다 우선한다. PC/터치 공통 모션만 바꾸며 피해·사거리·각도·최대대상·시간은 유지한다.

- Diablo III Barbarian [Cleave 공식 가이드](https://eu.diablo3.blizzard.com/en-us/class/barbarian/active/cleave): 넓은 호로 무기를 휘두르는 공격을 명시한다. 2026-11-14 열람. 넓은 궤적으로 방향을 구분하는 원리만 참고한다. 피해·분노·룬은 적용하지 않는다.
- World of Warcraft Retail의 역사적 [Shadowlands Class Updates](https://worldofwarcraft.blizzard.com/en-gb/news/23310980): 전방 적을 공격하는 Cleave 설명을 검색 결과에서 확인했다. 본문은403으로 열람하지 못했으며 현행 패치·동작 프레임·각도는 미확인이다. 전방 베기의 비교 사례일 뿐 수치나 자산 근거로 쓰지 않는다.
- 기존 사용자 지정 D&D 영상은 첫 두 타의 원천이다. 마지막 찌르기는 최신 요청으로 대체하며 영상에 가로베기가 있었다고 재해석하지 않는다.

적용 해석: 검끝이 오른쪽에서 왼쪽으로 가슴 높이를 유지하며 넓게 지나가고 중앙 통과를 기존 서버 접촉 시각에 맞춘다. 완전 회전·추가 적중·사거리 확대는 필요하지 않다. 기존 TD 검/방패와 소유 관절 곡선을 사용한다. 제작 비용은 R6/R15별 소켓 자세 계산과2→3타 연결 재저작이며 방패 관통·경계 급변이 주요 위험이다.

최소 실험은 두 리그의 실제 검 소켓에서 좌우 이동·수평 높이 편차·전방 접촉·방패/지면 여유·연결/복귀 연속성을 검사하는 것이다. 게시 클라이언트·실기기·동작 크기/타격감 사용자 수용은 별도다. [구현·측정](../evidence/knight-horizontal-finisher-20261114/README.md)에 인계한다.
