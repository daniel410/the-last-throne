# 몬스터·보스 공격 다양성 리뷰와 비교 조사

2026-11-05 · TLT-005/027/050/057/061~065/084 · RESEARCH/PLAN · 설계 검토 완료, 구현·수용 미완료

## 질문과 검토 범위

사용자는 몬스터와 보스의 공격이 단순하다고 보고하고 패턴·효과·특성 개선 리뷰와 계획을 요청했다. 기준 소스는 `8f488a2bbbd3b77cd9518614b907329e592f1a77`, VERSION `0.75.12`다. 다섯 에픽의 실제 출현49종(일반27·보스22)을 검토한다. 구형8에픽 후보 카탈로그를 구현된 적으로 합산하지 않는다. 코드·기존 검증 기록·공식 웹 문서를 읽었으며 새 Studio 실행, 영상 관찰, 직접 플레이, 실기기 검증은 하지 않았다. 사용자가 체험한 게시본과 로컬0.75.12가 같다고 가정하지 않는다.

위 해석은 소스 구조에서 도출한 가설이다. 실제 명중률·재미·불공정성·효과 가림 정도를 측정한 결과로 표현하지 않는다.

최소 실험은 일반 Slime/Goblin/Orc/Shaman/Ogre와 보스 Warlord/KingShaman이다. 동일 장비·스탯·난이도·원정 규칙에서 예고 인지, 무피격 대응, 반격 횟수, 완주·사망·물약, 프레임 시간을 전후 비교한다. 수용 기준과49종 인계표는 [개선 계획](../production/enemy-pattern-improvement-plan-2026-11-05.md)에 있다. 다음 담당 PLAN/DES→ENG/ART→QA. 기존 티켓과 게임 빌드의 완료 상태는 유지한다.
