# 모든 에픽 초회 Diamonds 보상 적용 근거

2026-11-09 · TLT-027/041/050/052/057/084 · PLAN/ENG → QA. 사용자 요청한 다른 에픽 보상 추가를 기존 Deepwood3개 규칙으로 확장한다.

- Diablo III 1.0.4 [공식 패치](https://news.blizzard.com/en-us/article/7029347/patch-1-0-4-now-live)는 최초 퀘스트 완료와 반복 보상 처리를 구분한다. 해당 역사적 패치의 XP/Gold 사례이며 최신 디아블로 정책·계정 유료재화 지급 모델이라는 뜻은 아니다. 적용 해석: TLT도 초회 권리와 반복 Gold/재료를 분리한다. 디아블로의 난이도별 초회권은 가져오지 않고 기존 TLT 계정1회 규칙을 따른다.
- Roblox [Balance virtual economies](https://create.roblox.com/docs/production/game-design/balance-virtual-economies)는 유입·소비·구매/획득 통화의 사용과 신규 유입 영향을 추적하도록 안내한다. 이번 변경은 계정 최대84개를 추가하는 유한 공급이다. 신규 계정105개는 초기화권100개 한 장을 살 수 있으며, 기존1:50 교환율의 이론 환산은5250 Gold다. 실제 Gold 묶음은10/20/40 Diamonds 단위이므로105개로 즉시 교환 가능한 최대는5000 Gold와 잔여5개다. 기존 가격/환율/강화비는 변경하지 않는다.

최소 실험: 다섯 지역35개 완료·두 영웅·반복 원정·계정 로드/저장 응답 불명에서 지급량과 영수증 보존을 확인한다. 기존 완료 기록도 신규 권리를 받을 수 있게 복구한다. 실제 구매 선택/소모 시점·실기기/협동 수용과 경제 계측은 후속이다. 순수 규칙/격리 엔진 테스트로 실제 계정 검증을 대신하지 않는다.
