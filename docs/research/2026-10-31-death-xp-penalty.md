# 사망 XP 패널티 비교와 적용

2026-10-31 · TLT-005/015/028/050/052/084 · RESEARCH/ENG → QA

사용자는 사망 XP 차감, 트레이닝 제외, 손실량 표시, 레벨 강등 없음을 요청했다. 차감률은 지정하지 않아 현재 레벨에서 모은 XP의10%(올림)를 시험값으로 선택했다. 전체 누적XP나 다음 레벨 필요량의10%가 아니다. 모은XP가0이면 손실0이며 Lv80의 기존 진행XP0 계약도 유지한다.

- [Path of Exile Community Wiki — Experience](https://www.poewiki.net/wiki/Experience),2026-10-31 확인: 사망 XP 손실이 레벨 바닥을 넘거나 강등시키지 않는다고 설명한다. 커뮤니티 자료이며 공식 패치의 현재 배율로 인증한 것은 아니다. 우리10%의 기준/예외는 사용자 계약과 입문 플레이어 보호를 바탕으로 별도 설계했다.
- [Grinding Gear Games — Game Mechanics Q&A](https://www.pathofexile.com/forum/view-thread/3284453),2022-06-19,2026-10-31 확인: 사망을 현재 Life가0인 상태로 설명한다. 우리는 실제 서버 Humanoid의HP0, 현재 영웅/생명 세대, 서버 경로가 검증된 Died 이벤트만 받으며 캐릭터 교체/일반 제거/경계 이동/로비에서는 차감하지 않는다. 이 출처는10% 배율 근거가 아니다.

서버 계정의 기존 직렬 성장 큐에 사망 명령을 넣어 이전XP 보상과 순서를 유지한다. 사망ID별 실제 손실 영수증을 같은 계정 트랜잭션에 기록해 저장 응답 유실과 재시도에서 한 번만 차감한다. 트레이닝은 저장 차감 없이0손실 안내만 보낸다. 저장 미확정 상태는 확인 중이라고 표시하며 예상치를 확정 손실처럼 보여주지 않는다. 전투/퀘스트 피드백과 별도 안내를10초 표시한다.

실제 게시 계정·서버 강제 종료 전 최초 쓰기 미완료·기기/네트워크 장애 수용은 후속이다. 특히 최초 기록 이전 서버 프로세스 종료까지 견디는 별도 영속 이벤트 아웃박스는 구현하지 않았다. 정상 종료는 기존 큐 flush로 저장을 시도한다.
