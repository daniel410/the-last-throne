# Dawnspire 세 시설의 컨셉 적용

2026-10-30 · TLT-011/028/040/041/042/053/084 · DES/ENG → QA.
사용자 요청: 로비 컨셉의 원정 포탈·훈련장·대장간 구현.

시각 원천은 [보존된 로비 컨셉](../../assets/concepts/2026-10-27-shared-ui-v2/world/dawnspire-lobby-v1.png)이다. 왼쪽 앞 훈련장·왼쪽 뒤 보라 포탈·오른쪽 파란 지붕/금색 장식 대장간의 관계를 현재160×160 안뜰에 맞췄다. 그림 전체 왕성·성녀·TD 이동문을 구현한 것은 아니다. 그림 속 한국어·개발용 지명 코드는 간판으로 가져오지 않는다.

[Roblox Proximity prompts](https://create.roblox.com/docs/ui/proximity-prompts)(확인2026-10-30)는 접근 시 대상·행동·입력 표시와 PC/패드/터치 상호작용을 지원한다. 기존 커스텀 F / 패드 X / 터치 프롬프트를 재사용한다. 포탈 통과만으로 강제 출발하지 않고 원정 메뉴를 열어 Solo/파티를 선택한다. 훈련장은 기존 영웅 소유·로비·파티·생명/생성 준비 검사 경로로 진입한다. 대장간은 기존 서버 권위 Gold/Diamonds 무기 매입·판매로 연결하며 제작/강화 기능을 임의로 약속하지 않는다.

구현 해석: 천막·화로·모루·과녁·허수아비·석조 포탈을 네이티브 지오메트리로 만들고 대장간에 이미 추출/매핑된 TD 무기 원본4개를 전시한다. 기존 TD UI 원본과 거래 코드는 유지한다. 외부 모델/스크립트나 자산 업로드를 추가하지 않는다. 장식은 충돌/쿼리에서 제외하고 바닥·대장간 카운터만 실제 충돌을 갖는다. 포탈 룬7개의 회전/맥동은 근거리 클라이언트20Hz, 화로 빛/불꽃은 고정된 작은 예산으로 제한한다. 실기기 성능 수용을 의미하지 않는다.

수용 조건: 생성 위치에서 세 시설을 구분하고 도보 접근할 수 있으며, F키로 원정 메뉴·상점·선택 영웅 훈련 진입이 각각 작동한다. 먼 위치·사망·생성 미완료·모험·이동 중 사용을 서버에서 거부한다. 훈련에 잘못 표시되던 에픽 완료 문구는 훈련 안내로 대체한다. [고정 빌드·실제 Player·미검증](../evidence/lobby-landmarks-0370/README.md)을 따른다.
