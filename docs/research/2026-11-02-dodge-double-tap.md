# 회피 1회 뒤로 피하기·2회 옆 구르기 적용 조사

2026-11-02 · TLT-005/028/032/033/084 · RES → ENG/QA

사용자는 Dodge 한 번은 뒤로 피하기를 유지하고 두 번 연속은 옆으로 구르도록 요청했다. PC R·패드 B·기존 터치 회피 버튼에 동일하게 적용한다. 별도 버튼 추가나 Stamina·회피 쿨다운은 도입하지 않는다.

비교 자료(2026-11-02 공식 문서 확인): [ESO 지원 문서](https://help.elderscrollsonline.com/app/answers/detail/a_id/3883/)는 Double Tap to Dodge와 Double Tap Speed 조정을 안내한다. [Bethesda 회피 안내](https://help.bethesda.net/app/answers/detail/a_id/3924/~/how-do-i-dodge-and-roll%3F)는 방향키 두 번 입력으로 해당 방향에 회피하는 PC/Mac 조작을 설명한다. 이는 비교 사례이며 현재 인기도·직접 플레이·최적 입력 간격의 근거가 아니다. 문서 갱신일/게임 버전은 확인되지 않았다.

Roblox에서는 [네트워크 소유권/이동 검증](https://create.roblox.com/docs/scripting/security/network-ownership)과 [클라이언트/서버 경계](https://create.roblox.com/docs/scripting/security/client-server-boundary)가 서버의 입력·이동 검증을 설명한다. 다른 Roblox RPG의 비공개 회피 판정/유지율은 확인하지 않았다. 실제 플랫폼 제작 지침으로만 적용한다.

이번 적용 판단: 첫 입력은 기다리지 않고 바로 뒤로 피한다. 서버가 승인한 첫 회피에서0.30초 이내 두 번째 Dodge를 받으면 현재 뒤로 피하기를 옆 구르기로 교체한다. 좌우 이동 벡터를 영웅의 오른쪽 축에 투영해 방향을 고르고, 유의미한 왼쪽 입력이 없으면 오른쪽을 기본값으로 쓴다. 0.30초·기본 오른쪽은 구현 선택이며 최종 기기 수용값은 아니다. 첫 입력을 보류한 뒤 두 번 여부를 판단하는 대안은 반응을 늦추므로 채택하지 않았다. 구르기 중 추가 입력은 같은 구르기를 재시작하지 않는다.

서버가 기존7스터드/0.30초 이동·전체0.65초·0.08~0.28초 무적·벽/낭떠러지 차단을 유지하며, 클라이언트는 승인 시각·종류·좌우를 읽어 물리 루트를 돌리지 않고 시각 리그만 한 바퀴 회전한다. 새 업로드/외부 애니메이션은 없다. 위험은 통신 지연에 따른 두 번째 입력 도착 간격, 작은 터치 버튼의 연속 입력 실패, 리그별 지면/장비 겹침이다. 최소 실험은 같은 장비·거리에서 R/B/터치를 각각1회/2회/3회·느린2회로 입력해 성공률/방향/무적/복귀를 측정하는 것이다. 원격 전송·실기기·최종 미술/밸런스는 QA 후속이다.
