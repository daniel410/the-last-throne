비교 대안은 모든128기술의 신규 Blender 클립/메시를 먼저 제작하는 방식과 기존 저작 곡선+명시적인 기술별 연출 계약을 연결하는 방식이다. 이번에는 후자를 구현한다. 기사·드워프의 상위 기술58개에는 준비→접촉→회수의 절차적12관절 동작, 마법사는 기존6가족의 반복 방출, 엘프는 기존 서버 확정 재장전/시위를 재사용한다. 독립 Blender Action128개를 만든 것이 아니다.

현재 근거로 확인한 결함은 공통 원판이 부채꼴까지 표현하던 범위 오독, 고정2.5stud 하향 위치, 화살비/덩굴/포격/증기 등이 같은 선/원판인 문제, 상위 기사·드워프의 단계별 고정 자세, 긴 Mage 연타가 단일 방출을 늘여 쓰던 문제다. 새 효과는 지면 Raycast와 실제 각도/반경, 서버 각 pulse를 사용한다. 장식은 최대128파트·비충돌·짧은 수명이며 실제4인 성능 통과를 뜻하지 않는다.

최소 수용 실험은 각 기술의 준비/접촉/회수3시점, 30/60/144Hz, R6/R15, 정지/이동, 장애물/경사/무기 스트리밍, 회피/사망 취소,4인+AI 동시 궁극기다. CPU 검사는 대응 누락·유한값·범위/타이밍·소품 정리를 확인하고, 최종 손 접촉·카메라 가림·읽기 쉬움·기기 프레임은 실제 Studio/클라이언트에서 확인한다. [구현과 한계](../evidence/hero-skills-20261104/README.md).
