# 장비 착용 레벨 제한 제거 비교

2026-11-11 확인 · TLT-029/041/043/044/084 · ENG/리서치 역할 → QA.

Diablo III 패치2.3.0 공식 설명은 Kanai’s Cube의 Remove Level Requirement로 영웅 레벨과 무관하게 해당 장비를 착용하게 한다. 이는 당시 패치의 개별 장비 처리 사례이며 현재 Diablo 전체 장비 규칙으로 일반화하지 않는다. [Blizzard 공식 근거](https://news.blizzard.com/en-us/article/19859662/patch-2-3-0-now-live).

Roblox 보완은 [직전 난이도 조사](2026-11-11-difficulty-level-free.md)의 Dungeon Quest 공식 소개를 재사용한다. 협동 던전과 클래스·장비 성장만 관찰되며 공개 소개로 장비 레벨 제한을 추정하지 않는다. [공식 소개](https://www.roblox.com/games/2414851778/Dungeon-Quest-RPG-Adventure).

적용 판단: 사용자가 전체 무기·장비 제한 제거를 명시했으므로 별도 해금/소모품 비용 없이 착용 제한만 없앤다. 장비의 내부 보상 구분값과 능력치/가격/강화는 보존한다. 전체 level 값을1로 바꾸는 대안은 기존 보상 상자 선택군까지 바꾸므로 채택하지 않는다. 클래스·귀속·안전 조건은 남긴다.

위험은 낮은 레벨의 고성능 장비 조기 착용에 따른 밸런스 변화다. 임의 능력치 재조정은 하지 않는다. 최소 실험은 전체 비삭제 장비57종×4클래스의 Lv1 착용/클래스 거부, +9·잠금·재시도 보존, 기존 저장/응답 유실/재접속과 꽉 찬 가방 이관이다. 실제 초반 전투·상점/가방 UI는 QA 기기 수용 후속이며 조사로 수용 완료를 선언하지 않는다.
