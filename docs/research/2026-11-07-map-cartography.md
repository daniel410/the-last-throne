# 실제 월드 특징을 반영하는 상세 지도와 미니맵

2026-11-07 · TLT-028/031/050/057/061~065/084 · RESEARCH/DES/ENG → QA

사용자 요청은 상세 지도·미니맵의 지역 특징과 실제 맵 대응을 충분히 개선하는 것이다. 기존 구현은 전 지역에 같은 숲 윤곽·직선 길을 반복했고, compact 분기에서 주요 랜드마크를 생략했다. 체크포인트도 실제 SpawnLocation 대신 공통 비율 좌표를 사용했다.

## 조사 근거와 채택

- [Blizzard, Diablo IV: Vessel of Hatred 접근성 소개](https://news.blizzard.com/en-us/article/24139219/a-crucible-for-allaccessibility-features-in-vessel-of-hatred): 2024년 확장 출시 시 지도 핀으로 향하는 공간 음향 안내를 설명한다. **관찰**은 지도 목표와 현장 안내를 연결한다는 점이며, 현행 시즌 수치·모든 작품의 공통 동작으로 일반화하지 않는다. **적용 해석**은 지도 지형과 목표 표식이 같은 좌표를 사용해야 길찾기를 돕는다는 것이다. 새 음향 시스템은 이번 범위가 아니다.
- [Roblox Viewport frames](https://create.roblox.com/docs/ui/viewport-frames): ViewportFrame으로 3D 미니맵을 만들 수 있다. **대안**으로 검토했으나, 이번에는 월드 복제/스트리밍 의존을 늘리지 않는 정적 2D 도면을 채택한다. 실제 생성 월드를 오프라인에서 수직 투영해 통합한 사각형·실제 도로 선분을 사용한다.
- [Roblox 성능 개선 지침](https://create.roblox.com/docs/performance-optimization/improve): 투명 레이어의 중첩 비용을 설명한다. **적용**은 매 프레임 월드 스캔을 추가하지 않고 동일 종류의 투영 격자를 병합해 GUI 수를 줄이는 것이다. 엔진 성능 수용을 이 문서만으로 주장하지 않는다.

공식 웹 자료 확인일은 2026-11-07이며 직접 Diablo 플레이 비교는 아니다. 기존 TD 공통 프레임/버튼/아이콘을 보존한다. 도면은 새 일러스트나 상상한 지형이 아니라 실제 로컬 CampaignWorld 생성 결과에서 추출한다. 지역색은 가독성을 위한 지도용 대비이며 실제 3D 텍스처의 사진 복제는 아니다.

## 비용·위험·최소 수용

40×40 투영 격자는 건축·숲·바위·물의 큰 형태를 나타내는 요약도이며 정밀 충돌 판정도가 아니다. 도로는 격자 대신 실제 WornCurvedRoute/ReturnLoop 선분의 위치·폭을 사용한다. 월드 변경 뒤 도면 재생성이 필요하며 도구와 추출 증거를 함께 저장한다. 플레이어별 영구 저널과 장면의 가변 소품 상태는 정적 도면을 바꾸지 않는다.
