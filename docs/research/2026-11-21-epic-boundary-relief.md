# 다섯 에픽의 도보 경계 재질과 윤곽

2026-11-21 UTC · TLT-061, TLT-065, TLT-062, TLT-063, TLT-064

환경 아트와 환경 3D가 [기존 길어깨의 Studio 비교](../evidence/epic-road-shoulders-20261120/README.md)와 [본편 결말·다음 지역 도입](../production/campaign-context-review-2026-11-10.md)을 검토했다. 해빙로 끝의 낮고 어두운 현무암은 중간 카메라에서 배경 둔덕과 겹쳤다. 기존 96스터드 도로의 양쪽 여백과 지역 팔레트 안에서 깊이와 재질 변화를 설계했다. Roblox 기본 입체를 사용했다.

## 확인한 사례와 TLT 적용

- Diablo IV 환경팀은 지역의 기후와 역사에 따라 재질을 정하고, 화면에서 세부 밀도와 명도를 조절한다. TLT의 해빙로에서는 현무암 바닥과 새로 드러난 절단면의 명도를 다르게 했다. [Diablo IV 환경 제작 노트](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022)
- WoW의 Azure Span은 안개 낀 숲에서 설원과 얼음 봉우리로 고도와 지표가 바뀐다. TLT에서는 Windgap의 어두운 셰일 아래부터 밝은 압설이 쌓이게 했다. [The Azure Span](https://news.blizzard.com/en-us/article/23823429/dragonflight-zone-preview-the-azure-span)
- Lost Ark는 North Kurzan의 다음 전장을 Antares 화산의 분연으로 소개한다. TLT에서는 해빙 구간에서 드러나는 현무암으로 다음 제련 지역을 먼저 보여 준다. [Arkesia Ignited](https://www.playlostark.com/en-us/game/releases/arkesia-ignited)
- Roblox 환경 제작 예시는 기존 플레이 공간의 의도를 유지하면서 층과 재질로 이동 환경을 구분한다. TLT는 기존 바닥 위 바깥 길어깨에만 지물을 조립한다. [Roblox 환경 제작](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/construct-your-world)
