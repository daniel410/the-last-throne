## 채택·비용·수용 기준

- **직접 적용:** 비대칭 시간 곡선, 밝은 중심과 부드러운 가장자리, 속성별 궤적/잔향, 충돌 후 실제 파편의 방사/중력, 주변의 짧은 국소광.
- **TLT에 맞게 단순화:**35모티프/50종의 기존 실루엣은 원형 식별자로 두고 재질과 동작을 바꾼다. 얼음 창은 유리 재질·작은 흔들림으로 전진하고, 불은 느린 회전·다중 화염 꼬리·식는 연기를 사용한다. 비전/영혼/균열은 서로 다른 궤도와 흐름을 쓴다. 독은 짧고 묵직하게, 거미줄은 얇고 담백하게 둔다.
- **보류:** 화면 전체 후처리/카메라 흔들기·전역 조명 변경·새 상태 이상·큰 판정 확장. 과장된 효과가 실제 피해 범위를 오해하게 만들 수 있고 기존 제품 계약을 바꿀 필요도 없다.
- **구현 예산:** 데스크톱 곡선 Beam192/예약 입자480/광원6/광륜32, 터치 Beam96/입자240. 기존 기하640/효과64 상한과 별도이며 실측 FPS 보장치가 아니다. 취소/사망/새 행동/거리/수명 경계에서 전부 해제한다.
- **최소 검증:** 실제 몬스터와 표적이 있는 Studio 표본의 준비/비행/충돌18프레임을 전후로 검토한다. 엔진 생성·변환·시간 변화·메모리 예약/정리와 기존 서버 피해·회피·안전 영역을 회귀한다. 게시 클라이언트·낮은 그래픽·작은 화면·다인 성능과 사용자의 미술 수용은 별도로 남긴다.

기능 수나 검사 횟수로 미술 품질을 수용하지 않는다. [실제 변경·움직이는 표본·검증 및 남은 수용](../evidence/monster-spell-art-20261112/README.md).
