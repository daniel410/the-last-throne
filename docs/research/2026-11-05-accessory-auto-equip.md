# 장신구 슬롯 선택 제거

2026-11-05 · TLT-028/043/052/084 · 제작 스킬 적용 · ENG/DES → QA.

사용자 요청은 액세서리1/2 선택 없는 자동 장착이다. 기존 대상 선택 계약은 이 지시로 대체한다. 다음 공식 자료를2026-11-05 확인했으며 직접 게임 조작·인기도 측정은 하지 않았다.

- [FFXIV 공식 Recommended Gear 안내](https://eu.finalfantasyxiv.com/uiguide/equipment/equipment-saikyo/equipment_best.html): 현재/추천 장비를 보여 주고 Equip으로 적용하는 흐름을 설명한다. 자동 결정 전 결과를 보여 주는 참고다. 본 작업은 선택한 장신구의 자리만 자동 지정한다.
- [Roblox 공식 UI/UX 설계](https://create.roblox.com/docs/production/game-design/ui-ux-design): Spellbound RPG의 상황별 메뉴와 작은 화면의 과도한 버튼을 줄이는 예시를 제공한다.1/2선택 버튼 제거에 참고했으며 해당 게임의 장신구 장착 규칙을 확인한 자료는 아니다.

적용 판단: 고유그룹이 일치하면 그 장비를 교체해 중복 오류를 피한다. 그 외에는 빈1/2슬롯, 모두 차면1번을 교체한다. 낮은 전투력 장비를 추정하는 대안은 직업/HP/방어/고유효과의 가치 판단을 추가해야 하므로 제외한다. 교체 이름·능력치 변화를 미리 보여 주면 고정 교체 결과를 확인할 수 있다는 것은 본 프로젝트 적용 판단이다.

비용은 공통 슬롯 함수·서버 거래/가방/상점 미리보기 연결이다. 위험은 미리보기와 서버 선택 불일치·오래된 snapshot으로 다른 장비를 교체하는 경우다. 같은 함수를 사용하고 기존 revision/item version·동일 요청 멱등 검사를 유지한다. 수용은 빈 두 칸/한 칸·둘 다 참·고유그룹2번·가방 가득참·영웅별 격리·재요청·실제 비교 일치, PC/모바일/패드 선택 없는 장착이다. 실제 기기 검증은 남아 있다.
