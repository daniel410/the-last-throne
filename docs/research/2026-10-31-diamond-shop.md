# Diamond Shop 조사

2026-10-31 · TLT-041/044/050 · 리서치 → 기획/엔지니어/QA

질문: 로비에서 RPG Diamonds로 장비를 쉽게 구매하면서 실제 Robux 결제와 혼동하지 않으려면? 기존 [로비 경제 조사](2026-10-30-lobby-economy-and-expeditions.md)의 사례와 지갑 계약을 재사용한다. PC·터치·패드, 솔로/파티 공통이다.

Roblox [Developer Products](https://create.roblox.com/docs/production/monetization/developer-products) 공식 문서(2026-10-31 확인)는 반복 구매 상품과 ProcessReceipt 기반 지급을 설명한다. 실제 구매 실험이나 타 게임 최신 상점 화면은 확인하지 않았다. 해석: 게임 재화로 기존 장비를 사는 경로와 Robux로 재화를 충전하는 경로는 별도 거래다. 추천: 기존 서버 권위 장비 거래와 명시적 가격 확인을 사용하고 실제 충전은 영수증/상품 ID 검증 전 비활성으로 둔다. 가격은 가설이다.

최소 시험: 로비에서 여러 화면 크기의 메뉴 진입, 가격 확인, 잔액 부족, 가방 부족, 중복 요청과 저장 불명 복구를 확인한다. 성공 기준은 재화 차감과 장비 지급이 한 번만 저장되고 가격이 결제 전 보이는 것. PC/터치/패드 조작성, 경제 균형 및 실제 결제는 QA 후속이며 인기·매출 효과는 추정하지 않는다.
