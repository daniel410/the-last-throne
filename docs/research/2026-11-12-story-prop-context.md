# 스토리 물품의 반복과 장소 맥락

2026-11-12 · TLT-037/057/061~065/084 · DES/ENG → QA

사용자 문제: 숲길과 제단에 같은 책상·책·잉크가 반복된다. 사용자 DW07 화면에서 포털을 끄는 목표 옆에 사무용 책상이 보인다. 코드에서도 원본 목표의 `ledger`/미분류를 `LedgerDesk`로, 확장 사건의 모든 기록 단계를 책상으로 바꾸고 있었다. 사용 종류와 물건의 의미를 혼동한 구현이다.

## 재확인한 비교 근거

- [Blizzard, Diablo IV Quarterly Update—March 2022](https://news.blizzard.com/en-gb/article/23788294/diablo-iv-quarterly-updatemarch-2022), 2022-03-29 개발 중 환경 미술 설명, 2026-11-12 재확인. 지역 재료·역사·상황에 설득력 있는 물품과 장소를 만들고 게임 카메라의 가독성을 위해 디테일을 조정한다. 현행 시즌 수치나 직접 플레이 근거로 사용하지 않는다.
- [Roblox Creator Hub, Construct your world](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/construct-your-world), 게시일 미표기, 2026-11-12 재확인. 블록아웃 의도를 보존하며 자산으로 각 공간의 역할을 구별하는 제작 원리를 참고한다. RPG 플레이/흥행 자료는 아니다.

해석: 문서를 읽는 행동도 숲의 전령 가방, 캠프의 명단, 광산의 작업 슬레이트로 표현할 수 있다. 같은 기능을 동일 가구로 치환할 필요가 없다. Diablo의 고유 자산/어두운 실사 미술을 복제하지 않고 기존 TD 양식의 목재·철·황동·천 재료를 사용한다. 관련 기존 [소품 조사](2026-11-02-story-props.md)와 [맵 구성 조사](2026-11-12-story-map-composition.md)를 보완한다.

## 채택과 비용

안정된 장/목표/단계ID에 물품을 직접 지정한다. 문구 키워드/활동 종류 자동 추측은 폐기한다. 35본편·12선택의 배치 가능한 단계 전체를 검사하고 기존 NPC/호위/개인 Crownheart 장면은 중복 생성하지 않는다. 새 인벤토리 아이템·필수 재료·보상·퍼즐 정답은 추가하지 않는다. 순수 native 기하를 원본으로 사용해 추가 업로드/외부 모델 로딩 없이 재현한다.

비용은 모델과 명시적 지정표의 유지보수, 물리 파트 증가다. 지역 색상만 바꾸는 대안은 형태 반복을 해결하지 못하고, 모든 물건을 유일한 고해상도 메시로 제작하는 안은 현재 제작/로딩 비용이 크다. 새 소품은 각60파트 이내, 전체 배치는 기존18,000파트 상한과 비교한다. 책상0·지정 누락0·저장/목표 위치 보존·5에픽 실제 엔진 배치·대표 화면을 최소 수용 증거로 삼는다. 실제 플레이 식별성/카메라/모바일/다인 성능은 QA 후속이다.
