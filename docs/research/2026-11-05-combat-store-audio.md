# 무료 Creator Store 전투 효과음 적용 조사

2026-11-05 · TLT-005/027/032/050/057/084 · 리서치/ENG → QA

## 문제·출처·관찰

기존 공격·스킬에는 발동음이 없고 적 명중은 Roblox 기본 착지/물소리로만 분류돼 있었다. 기본 공격·공통/전직 스킬·궁극기의 무기/원소와 실제 명중을 소리로 구별하는 것이 이번 범위다. 음량 최종 수용이나 적 패턴 전체 음향 설계는 별도다.

- [Diablo IV Quarterly Update—October 2021](https://news.blizzard.com/en-us/article/23731236/diablo-iv-quarterly-updateoctober-2021): 출시 전 개발자 설명이다. 소리를 입력 확인·들어오는 피해·전투 강도 전달 수단으로 설명하며 변형/레이어링으로 반복감을 줄이는 방향을 소개한다. 현행 시즌/패치의 수치나 직접 플레이 검증으로 취급하지 않는다. 확인일2026-11-05.
- [Roblox Audio assets](https://create.roblox.com/docs/audio/assets): Creator Store의 무료 사용 오디오와 오디오 파트너 라이브러리를 설명한다. [Sound objects](https://create.roblox.com/docs/sound/objects)는 Part/Attachment 하위 공간 재생·거리 감쇠를 설명한다. 확인일2026-11-05.
- Roblox Studio MCP `search_asset`: `scope=creator_store`, `assetType=Audio`, `priceFilter=free`로 검/휘두르기/화살/방패/마법/원소/총을 검색했다. 길이 필터는 설명 길이와 차이가 있어 실제 Studio 로드를 별도로 확인했다. 선택 결과의 이름·ID·제작자·무료 여부·직접 URL은 [manifest](../../assets/audio/combat-store-v1/manifest.json)다.12개 모두 별도 빈 로컬 Studio에서 `Success`, `IsLoaded=true`, 양수 길이를 확인했다. Roblox 비교 게임의 실제 플레이나 청취 증거는 아니다.

## 해석·채택

디아블로의 입력/접촉 구별과 반복 변형 원리를 우리 서버 승인 속성→발동음/피해 확정→명중음의 두 경로로 단순화했다. 기존 무기/원소 분류를 공유해128개 스킬의 연결 누락을 방지한다. 데이터 해금·피해/자원 규칙은 유지하므로 기존 결정과 충돌하지 않는다. 외부 게임 음원/고유 자산은 복제하지 않는다.

Roblox1~4인+AI와 모바일을 고려해 전역 전투음 대신80stud 거리 감쇠, 층별8개 제한, 광역 명중70ms 중복 억제, 짧은 생명주기와 비동기 프리로드를 채택했다. 발동음은 공격 속도와 속사/반복 타격 간격을 따르되 과거 발동이 뒤늦게 몰아 들리는 것을 막는다. 비용은12개 다운로드와 최대16개 음원/발신 파트다. 이 수치는 구현 상한이며 측정된 모바일 성능 예산은 아니다.

대안인 스킬마다 독립 원음/다층 재생은 제작량·혼잡도를 늘리므로 보류한다. 먼저 기본4클래스/128기술 프로필·199발동·취소·중복·거리·정리를 엔진에서 검사했다. 다음 QA는 실제 로비/배틀 테스트 Experience의 자산 권한, PC/모바일·4인+AI에서 공격/명중 구별, 속사 피로·음량/잔향, 배경음/포션과의 균형을 청취한다. 부모 티켓의 실기기 수용을 대신하지 않는다.
