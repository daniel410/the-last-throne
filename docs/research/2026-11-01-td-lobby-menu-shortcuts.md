# TD 로비 메뉴의 기존 목적지 재사용

2026-11-01 · TLT-028/031/043/061/084 · RESEARCH/DES → ENG/QA

사용자가 TD 메뉴 리스트를 참조해 TLT에도 다이아 샵과 보상 진입을 추가하도록 요청했다. 로컬 TD src/Client/UIController.lua의623~629행에서 SUPPLIES/Diamond Shop 및 PROGRESS/Login Rewards·52px 버튼/16px 글꼴·기존 아이콘 사용을 확인했다. RPG의 기존 상점과7일 로그인 보상 화면이 이미 있으므로 새 경제 기능 대신 같은 목적지에 추가 진입을 연결한다. 레퍼런스 파일 SHA-256과 이번에 사용한 icon atlas/영역 일치는 작업 evidence/td-source.json으로 고정한다. TD 실제 클라이언트를 실행하거나 TD 운영 코드를 변경한 것은 아니다.

대안은 왼쪽 진입만 유지하는 방식과 메뉴 리스트에 같은 화면으로 가는 진입을 추가하는 방식이다. 사용자가 후자를 선택했다. 새 구매/수령 흐름을 복제하면 중복 지급/불일치 위험이 있으므로 기존 LobbyCommerce/openStore와 DailyLoginGui를 재사용한다. 메뉴 높이를 늘리되 작은 화면은 스크롤하며 마지막 행 도달/캡션 적합·기존 메뉴 동작을 검사한다. 현재 프로젝트에 이미 승인된 TD 자산 권한/공유 계약 안에서 원본 아이콘을 재사용하며 새 자산 업로드나 TD 지갑 공유를 하지 않는다.

최소 검증은 두 메뉴의 실제 목적지,QUEST 이름/J키 유지,작은 화면 끝 행 도달,원래 보상 중복/저장 재시도 회귀다. 별도 계정 결제·수령·게시/실기기 수용은 이번 UI fixture 검증에서 제외한다.
