# 에픽별 상세맵과 옆 낙법 회피 적용 근거

2026-11-03 · TLT-005/028/032/033/061/084 · RES/DES/ENG → QA

사용자는 상세맵을 한 에픽의7개 본편 지역 중심으로 바꾸고, 옆 회피는 기사·드워프·마법사·엘프 모두 양손을 뻗어 낮게 몸을 던진 뒤 낙법 구르기로 바꾸도록 요청했다. 최신 지시를 구현 기준으로 삼는다.

[기존 지도 조사](2026-10-31-lobby-epic-atlas.md)·[기존 회피 조사](2026-11-02-dodge-double-tap.md)를 재사용한다. 2026-11-03 [GW2 공식 초보 안내](https://www.guildwars2.com/en/new-player-guide/)를 재확인했으며 스토리 목적지를 미니맵의 별/원으로 안내하고 방향키 더블탭 회피를 설명한다. 본문으로 확인한 것은 안내와 입력 원칙이며, 이번 옆 낙법의 자세나 에픽당7지역 UI의 직접 근거가 아니다. 직접 플레이·신규 인기도/성과 조사는 수행하지 않았다.

[Roblox 공식 ScrollingFrame 문서](https://create.roblox.com/docs/ui/scrolling-frames)는 제한된 공간의 내용과 가로/세로 CanvasSize·CanvasPosition·터치 스크롤을 설명한다. 기존 승인 TD 버튼을 담는 가로 에픽 선택기와7스토리 목록에 적용한다. 비교 대상으로 특정 Roblox RPG의 비공개 지도/회피 구현은 추정하지 않고 Roblox 제작 제약만 확인했다.

적용 판단: 전체44지역을 축소하는 대안은 요청한7지역의 집중도를 충족하지 못하므로 선택 에픽의7개 본편 좌표로 지도를 다시 생성한다. 화면이 낮을 때 번호와 선택 상세를 사용하고 확대/드래그를 유지한다. 에픽 선택은 진행 권한을 바꾸지 않는 보기 필터다. 한 번에7지역의 탐험 셀만 생성해 전체44지역보다 GUI 제작량을 줄인다. 잠긴 에픽도 선행 조건을 확인할 수 있다.

회피는 사용자 지시의 명확한 자세 결함을 교정한다. 몸을 옆으로 눕힌 후 길이 축을 따라 한 번 구르는 곡선을 선택했다. 기존 공중 수레바퀴/지상 앞구르기는 발이 크게 머리 위로 올라갈 수 있어 채택하지 않았다. 서버 시간·물리 루트·무적·거리·벽/낭떠러지 차단은 유지한다. 기술별 외부 애니메이션 업로드 없이 R6/R15 관절에서 같은 곡선을 샘플링한다.

비용/위험: 에픽 전환 시 이전 GUI를 파기/재생성한다. 작은 화면 지명 가독성, 장착 무기와 지면 겹침, 경사에서 낮은 회피의 지면 접촉은 실제 기기 수용이 필요하다. 최소 실험은5에픽×화면4종의 필터/진행/위치 복귀와4클래스×2리그×좌우의 손 방향·수평 회전·착지·물리 루트 보존이다. [지도 검증](../evidence/epic-map-scope-20261103/README.md)·[회피 검증](../evidence/side-breakfall-20261103/README.md)을 연결하며 최종 미술/기기 수용은 QA/사용자에게 남긴다.
