# Hollowbark Sovereign 스토리 보스 적용 조사

2026-11-10 · TLT-065/032/033/057/084 · ENG/PLAN → QA. 사용자 요청은 TD 신규 모델을 TLT Gloamwood 보스로 재사용하는 것이다.

주 비교: [Diablo IV 2.1 공식 패치 노트](https://news.blizzard.com/en-us/article/24171214/diablo-iv-patch-notes-2-1)는 Pit 보스 그림자 공격의 시각과 판정 불일치 수정을 기록한다. 이는 해당 패치의 사실이며 현재 전체 디아블로 밸런스로 일반화하지 않는다. 적용 해석: 새 외형을 넣을 때 예고·판정·피해는 기존 서버 경로로 유지하고, 모델 크기 때문에 판정까지 무작정 키우지 않는다. 기존 엔트의 cone/line/ring 네 패턴과 명시적인 회피 경고를 재사용한다. 별도 드롭 경제·입장 재료는 도입하지 않는다.

Roblox 비교는 타 게임의 검증되지 않은 관찰 대신 [공식 자산 권한 문서](https://create.roblox.com/docs/production/creator-store)를 사용했다. Restricted 자산은 대상 Experience의 사용 권한이 필요하다. TD 권한을 RPG 권한으로 추정하지 않고 메시와 Image 각각 TLT Experience를 연결한다. 소유권·공개 배포 범위는 확장하지 않는다.

추천/채택: GW-06 마지막 정찰대 후위 전투를 Sovereign 결전으로 강화한다. 기존 일반 적2개와 목표 ID를 유지하고 보스1개를 추가해 기존 처치 영수증의 번호·보상을 유지한다. GW-04 Ancient Hollowbark와 GW-05 Venomcoil King, GW-07 Widow Queen의 역할을 보존한다. 대안인 마지막 여왕 교체는 승인 서사를 바꾸므로 채택하지 않았다. 별도 GW-08 추가는 7장 진행/보상 계약 변경을 요구하므로 보류했다.

제작 비용/한계: TD Idle/Walk 그대로, TLT 엔트 전투·피격 클립의 동일10본 델타 재사용. 전용 공격 애니메이션 신규 제작은 하지 않았다. 새14stud 외형과 기존 판정의 체감·공격 접점·카메라·솔로 난도는 실제 플레이 수용이 필요하다. 1~4인에 보스는1개, 마지막 wave, 기존 완료는 재개방하지 않음·중복 보상0을 자동 검사한다. 다음 QA는 실제 이동/공격·메시/텍스처 로드·모바일 가시성·퇴로 폭·HP/처치시간을 확인한다. 재미와 실기기 성능은 미검증이다.
