# TD 맵을 기준으로 한 TLT 지역 구성 개선

2026-11-07 · TLT-050/057/061~065/084/087 · RESEARCH/DES/ART/ENG → QA

## 확인한 원천

이번 요청은 TD 원본 맵을 참고해 TLT의 실제3D지역을 개선하는 구현 작업이다. 프로젝트 제작 스킬·디자인/모델링/엔지니어 지침을 적용한다. TD 저장소는 읽기만 하고 RPG 월드 모듈과 그 지도 도면을 변경한다. 기존 본편 확장 계획 전체를 이번에 구현했다고 간주하지 않는다.

현재 TD `VisualFactoryMapThemes`/`VisualFactoryMapMeshes`/`VisualFactoryMapRelief`/`VisualFactoryMapConcept`/`MapRouteData`와 TD290 조형 지침, TD 네 테마의 실제 native 렌더를 확인했다. TD의 숲/설원/화산/묘지 실제 메시 원본과 TLT의 pinned 파일 두 개가 현재도 바이트 단위로 일치한다. [경로·해시·사용 범위](../evidence/td-inspired-world-20261107/td-sources.json). 공유 사용은 기존 사용자 승인 범위이며 새 업로드·운영 TD 편집을 하지 않는다. 독립 RPG Experience의 게시 자산 권한 수용은 기존처럼 별도다.

TD 실제 원본의 관찰과 TLT 적용을 구분한다.

| TD에서 확인 | TLT의 변경 판단 |
| --- | --- |
| 큰 주연 랜드마크와 낮은 보조군, 열린 중앙 전장 | 지역별 주연1개·규모/방향이 다른 보조 지형. 밀집된 동일 높이의 나무벽을 줄인다. |
| ForestLandmark/SnowLandmark/VolcanoLandmark/CemeteryLandmark의 실제 메시·서로 다른 실루엣 | 네 원본과 SnowTree를 사용하고 Gloamwood는 Forest 원형의 어두운 파생 재질+실제 수목 사이 거미줄로 구분한다. |
| 고정 경로와 회전된 메시 bounds의 여유 검사 | RPG의 실제 목표·활동·스폰/연결로와 회전 후 전체 footprint를 비교해 배치한다. TD 적 경로·타워 패드·U턴 규칙을 도입하지 않는다. |
| 전경을 낮추고 먼 곳의 주연을 높여 경로를 읽히게 함 | TLT의 반복 외곽 수목/같은 성문·성당을 줄이고 숲길/협곡/거점/최종 지역을 구분한다. 폭포는 Deepwood 거점과 Waterfall Quarry의 특성으로 제한한다. |
| CliffRock 계열은 자연 부유섬의 테이퍼형 메시 | 몸체를 지면 아래 묻어 낮은 지형 은행처럼 사용한다. 녹색 상면이 화산/묘지에서 어울리지 않으면 복제 인스턴스의 재질만 파생한다. |

## 디아블로 비교 근거와 적용 범위

[Blizzard, Diablo IV Quarterly Update—March 2022](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022)을 확인했다. 제작 중 환경의 지역별 바이옴·문화·자연 랜드마크와 명암 대비를 설명한다. 여기서 차용하는 원리는 같은 공용 자산을 사용해도 지역 구성과 실루엣을 구분해야 한다는 것이다. 이는2022년 개발 소개이며 최신 시즌 규칙·실제 플레이 수치나 현재 Diablo 전체의 품질 수용으로 일반화하지 않는다. 사용자 지시상 미술 원본은 TD를 우선하며 Diablo의 사실적 고어/세계관을 TLT로 옮기지 않는다.

## 비용·위험·최소 검증

주연/보조는 전투 콜라이더와 서버 판정에 참여하지 않는 고정 장식이며 스트리밍 거리 예산에 참여한다. 작은 장식을 더하는 대신 반복 나무·건축물을 줄인다. 파츠/메시 감소는 모바일 FPS 통과 증거가 아니다. 원본 교체가 아니라 복제 배치/지역별 파생이므로 pinned 원본과 TD 운영은 유지한다.

대표5지역 동일 카메라 전후 캡처·44지역 주연/예산·실제 목표/스폰/활동·도로 충돌/바닥·전투 동선·구버전 월드 재사용·상세 지도/미니맵 재생성 및 회귀가 최소 검증이다. 실제 사람의 길찾기·낮은 카메라의 시야·모바일/4인+AI 성능·게시 권한은 별도 수용한다. 새 목표·보상·지역 ID·필수 점프·클래스 열쇠는 추가하지 않는다.
