# 드워프 기본 3연격 참고

2026-11-14 확인 · TLT-055/084 · ENG/RES

사용자 지정 [라이너TV D&D 드워프 공략](https://www.youtube.com/watch?v=BQtb9t-Csv4)을 브라우저에서 재생했다. 1:01~1:11은 슬라이딩 공격 설명, 약2:06~2:12는 도끼를 높이 회수하고 근접 적을 상대하는 실제 전투 화면을 확인했다. 이것만으로 영상의 정확한 3타별 프레임/입력/대미지 수치를 측정했다고 주장하지 않는다. 횡스크롤 D&D의 도트 자산은 가져오지 않는다. 사용자 요청인 기사 방식의 3연속 기본 공격을 우선하고, 한손 도끼의 짧은 첫 동작·다른 방향의 후속 베기·넓은 마무리라는 원리를 기존 TLT 소유 모션으로 구성한다.

우선 비교 기준은 [Diablo IV 2.0 공식 패치 기록](https://news.blizzard.com/en-gb/article/24140808/diablo-iv-patch-notes-2-0)의 Barbarian Double Swing/Frenzy와 [WoW Warrior 공식 직업 소개](https://worldofwarcraft.blizzard.com/en-us/game/classes/warrior)다. Diablo는 2024년 2.0 문서이며 현행 시즌 수치로 취급하지 않는다. WoW 소개의 검색 결과에서는 한손/양손 무기와 근접 역할 설명을 확인했으나 본문 직접 열기는403이었다. 두 작품에 동일한 고정3타 입력 규칙이 있다고 해석하지 않는다. 근접 직업의 연속된 무기 동작이 읽히게 한다는 원리만 적용하며 분노 자원·새 쿨다운·피흡을 추가하지 않는다.

TLT는 기본 공격 쿨다운 없이 기존 동작의 완료/버퍼 규칙으로 속도를 제한한다. 서버가 1→2→3→1과0.6초 이탈 초기화를 결정하고 클라이언트는 승인된 콤보/시각으로 재생한다. 기존0.8초 평균 주기와 시간당 피해 예산을 유지하면서 첫0.8/둘째0.68/셋째0.92초로 차이를 준다. 3타 합계2.4초이며 각 타마다1회만 피해를 적용한다. 기사의3타 수치/몬스터/장비는 변경하지 않는다.

최소 검증: 서버 입력 버퍼·DEX1~2배·30/60/144Hz 접촉/중복 방지, R6/R15의3타 실제 도끼 소켓/전방 궤적/마무리 복귀, 기존 공통 기술 회귀. 실제 터치/패드·이동/멀티플레이·영상과의 시각적 유사성 및 사용자 타격감 수용은 후속이다.
