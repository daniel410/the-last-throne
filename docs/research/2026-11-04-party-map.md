# 협동 파티 지도 위치 표시 조사

2026-11-04 · TLT-028/031/050/057/061/084 · RESEARCH/DES/ENG → QA

사용자 요청: 파티로 플레이하는 동료를 전체 지도와 미니맵에 표시한다. 서버가 검증한 같은 원정의 인간 파티원과 내 위치를 구분하고, 멀리 떨어져 합류할 때 도움이 되는 표시를 만든다.

2026-11-04 웹 열람 자료(직접 플레이/인기 실측 아님):

- [Guild Wars 2 공식 Megaserver 소개](https://www.guildwars2.com/en/news/introducing-the-megaserver-system/): 파티/길드 등을 고려해 같은 맵 인스턴스로 배치하는 협동 구조를 설명한다. 현재 TLT는 같은 로비 접속보다 같은 검증 원정이 표시 자격의 원천이 되어야 한다는 적용 해석이다. 이 문서만으로 지도 마커의 실제 색/주기를 확인한 것은 아니다.
- [Guild Wars Factions 공식 매뉴얼](https://legal.guildwars.com/en/docs/gwf-manual.pdf): 파티원에게 미니맵 위치를 ping하는 소통 기능을 설명한다. 이는 파티 지도 정보의 비교 사례이며 자동 위치 표시·현행 동작/우리 게임의 업데이트 주기 증거는 아니다.
- [Dungeon Quest 공식 Roblox 설명](https://www.roblox.com/games/2414851778/Dungeon-Quest-RPG-Adventure): 친구와 던전/보스를 함께 진행하는 구조를 확인했다. 지도 마커의 실제 동작은 미검증으로 남긴다.

적용: 기존 TD 지도/미니맵·내 청록색 삼각형·목표/적 아이콘은 유지한다. 파티원은 초록색 번호 원, 전체 지도에는 이름을 추가하고 쓰러진 상태는 주황색+로 구분한다. 미니맵은 이름을 생략해 좁은 공간을 보존한다. 화면 밖 위치는 가장자리 방향으로 나타내며 좌표는 서버가 제공한다.

클라이언트의 주변 Players 검색만 사용하면 다른 원정·훈련/로비 플레이어와 스트리밍으로 사라진 캐릭터를 잘못 표시할 수 있다. 서버가 같은 runId의 현재 모험 인원만 0.5초마다 전달하고, 캐릭터가 로드되지 않으면 좌표를 생략한다. 2초간 새 수신이 없으면 위치를 숨긴다. 업데이트 주기·색/형태·가장자리 표시는 구현 시험값이다.

최소 수용:4인에서 자신 제외3명·다른 원정0·다른 영웅/훈련/로비0·재생성/이탈/쓰러짐·오래된 수신 제거·서버 좌표와 지도 북쪽 방향 일치·미니맵 원형 가장자리·기존TD 메뉴/자산 유지. 위치 정보는 표시용이며 전투/피해/진행/보상의 권한으로 사용하지 않는다. 실제2~4인 네트워크/실기기 가독성 수용은 QA 후속이다.
