# 몬스터 원소 효과를 실제 공략으로 연결하기

2026-11-15 · TLT-005/027/033/050/057/061~065/084 · RESEARCH/ENG → QA

사용자는 몬스터 특징·무기·난이도에 맞는 RPG 전투 개선을 요청했고, 후속으로 이동·표현 조정만으로는 부족하다고 지적했다. [앞선 역할·공정성 조사](2026-11-15-monster-combat-design.md)를 유지하면서 원소가 실제 피해 시간·이동·반격 선택에 영향을 주도록 확장한다. 문서 열람과 서버 규칙의 자동 검증이며 직접 플레이·미술·재미 수용의 증거는 아니다.

## 이번 서버 규칙

다음 수치는 타 게임의 정답이 아니라 네 클래스 솔로·터치 대응을 확인하기 위한 자체 시험값이다. `EnemyAfflictionRules`가 정본이며 피해·HP·보상·성장 수치 자체를 추가 상향하지 않는다.

| 원소 | 실제 효과 | 대응·제약 |
| --- | --- | --- |
| Fire | 기존 원시 피해의 25%를 최대 2회·0.6초 간격으로 분배 | 직접 피격을 방어·회피·흡수하면 화상 없음. 지속 피해가 새 상태·경직을 만들지 않음 |
| Venom | 기존 원시 피해의 30%를 같은 유한 지속 구간으로 분배 | 같은 독의 중첩·갱신 없음. 해독 상품·동료를 필수로 하지 않음 |
| Frost | 1.4초 동안 이동 배율 0.8 | 스프린트·방어·공격·회피를 금지하지 않으며 root/빙결/stun 없음 |
| Web | 1.2초 동안 이동 배율 0.75 | 냉기와 곱하지 않고 가장 강한 감속 하나만 적용. 원소 감속 자체 하한 0.7 |
| Shadow | 1.5초 동안 가하는 피해 배율 0.85 | 독립 공격력 자원·속성 면역을 만들지 않음. 다른 약화와 곱하지 않고 가장 강한 하나만 사용, 하한 0.8 |
| Soul | 1.4초 동안 가하는 피해 배율 0.9 | MP가 없는 클래스에 유리한 자원 강탈이나 보스 무한 회복을 피하고 전 클래스에 같은 짧은 저주로 적용 |

직접 HP가 실제 감소한 `Hit` 결과와 흡수량 0이 함께 있어야 적용한다. Blocked/PerfectBlock/Dodged/Absorbed/Prevented와 전부 방어된 ForceField 결과에는 적용하지 않는다. 불·독은 정수 분배의 합이 원래 원시 피해를 정확히 보존한다. 방어·방어구·보호막은 각 tick에서도 기존 서버 판정을 다시 통과한다. 실제 HP 결과는 그 판정의 배율·방어구·반올림을 포함하므로 원시 예산 보존과 구분해 통합 검사한다.

정상 공격 종료 뒤 남은 지속 효과는 유지한다. 스턴·피격 중단·귀환·서사 pause·비살상 진정·사망·삭제에 따른 실제 소스 취소는 남은 효과를 제거한다. 대상 캐릭터·Humanoid·영웅·원정 자격도 매 tick 다시 확인한다. 재접속·respawn·다른 원정에서 늦은 피해를 새 생명에 이전하지 않는다. source actor와 원래 cast sequence를 보존한다.

동일 종류는 중첩·시간 갱신 없이 하나만 유지한다. 큐는 128개, 한 step의 피해 콜백은 최대 32회, 늦은 tick 허용은 0.18초로 제한하고 과거 피해를 한꺼번에 재생하지 않는다. 제한 초과나 취소로 실행하지 못한 지속 피해를 나중에 보충하지 않는다.

## 검증과 남은 수용

- 규칙 검사: 원시 피해 0~1000 범위의 직접+지속 합, 정수 분배, 감속/약화 하한, 복사된 정본과 방어 결과를 확인한다.
- 모듈 독립 검사: 정상 공격 완료 뒤 지속, 동일 효과 비중첩, 강한 감속/약화만 적용, 모든 방어·흡수 결과, 소스/대상 수명·원정·서사 pause, 지연 프레임, 큐/step 상한과 콜백 중 동기 취소를 검증한다.
- 다음 담당 ENG/QA: 실제 `CombatService`의 split→실 HP 판정→예약→tick 재판정, 감속 적용/해제 시 WalkSpeed 및 이동 검증, 약화의 실제 영웅 피해, tick의 무경직, 정상 입력으로 방어·회피와 맞춘 표시를 엔진에서 확인한다.
- 미검증: 게시 클라이언트·실기기·다인 성능·최종 밸런스·사용자의 자연스러움과 재미 수용. 위 코드/문서만으로 이 항목을 완료 처리하지 않는다.
