# 다섯 에픽 3장 구조 동선의 재료와 접합

2026-11-22 · TLT-061/DW-03 · TLT-065/GW-03 · TLT-062/FV-03 · TLT-063/EC-03 · TLT-064/HG-03 · G5

환경 아트와 환경 3D 모델링 담당이 0.115.42 후보의 고정 Studio 화면 10쌍을 검토했다. 옆에서 보면 밝은 셰일이 Gloamwood 표식 아래에서 먼저 보이고 뿌리는 지면에 묻힌다. Haunted Graveyard의 관리 통로는 밝은 앞면과 어두운 귀환면 사이에서 윤곽이 끊긴다. Frozen Vale에서는 조사점 앞의 근접 시점에서 교량 뒤 난간이 읽힌다. [3장 이전 후보의 Studio 비교판](https://github.com/daniel410/the-last-throne/blob/f4f9009b/docs/evidence/epic-third-chapter-landmark-readability-20261122/README.md)

## 공식 사례와 적용

- Diablo IV 환경 팀은 재질과 풍화에 지역의 날씨와 쓰임을 반영하고, 게임 카메라를 기준으로 암부의 초점을 조절한다. TLT는 Gloamwood의 뿌리 심재와 Haunted Graveyard의 석재 모서리를 두 접근 방향에서 읽을 수 있게 잡는다. [Blizzard 환경 제작기](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022)
- World of Warcraft의 Azure Span은 고도에 따라 숲·동토·빙봉이 이어진다. Ringing Deeps에서는 제련 설비를 고치는 주민의 일이 장소의 쓰임을 설명한다. TLT는 Frozen Vale의 암반과 압설 경계, Ember Caldera의 내화벽과 냉각 수위 자국에 적용한다. [Azure Span](https://news.blizzard.com/en-us/article/23823429/dragonflight-zone-preview-the-azure-span) · [The Ringing Deeps](https://news.blizzard.com/en-us/article/24125258/explore-the-zones-and-dungeons-of-the-war-within)
- Lost Ark의 Voldis 제작진은 현자 탑의 규모로 주민들의 발전 의지를 표현했다. TLT는 구조 명부를 고정한 받침, 피난처로 향하는 표식, 관리 통로의 문턱처럼 현장 인물의 일을 보여 주는 구조에 적용한다. [Smilegate RPG 제작 인터뷰](https://www.playlostark.com/en-us/news/articles/creating-voldis)
- Roblox 환경 제작 과정은 지형 블로킹에서 캐릭터 축척과 통과 난점, 시점을 점검한다. TLT는 두 접근 카메라와 R15 왕복을 기록하고 조사 프롬프트가 있는 플레이에서 최종 판독을 확인한다. [Roblox Creator Hub](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/greybox-your-environment)

## 제작 범위

| 에픽 | 사건과 확인할 형상 |
| --- | --- |
| Deepwood | 구조 인원을 기록하는 명부대의 종이 받침턱과 주춧돌의 접합을 접근 사선에서 확인한다. |
| Gloamwood | 피난처 귀환 표식 아래 넓은 뿌리 노출면과 불규칙한 셰일 파단을 야간 양방향에서 확인한다. |
| Frozen Vale | 교량을 지난 협곡 난간의 기둥 받침과 압설 아래 암반을 조사점 앞에서 확인한다. |
| Ember Caldera | 구조로 아래 냉각 점검구의 내화벽돌, 어두운 개구와 광물 자국을 확인한다. |
| Haunted Graveyard | 관리 통로 문턱과 문설주 귀돌이 야간 접근 및 귀환에서 이어지는지 확인한다. |

## 최신 소스 통합 후 조형

환경 아트가 0.115.44↔0.115.45 고정 카메라 10쌍을 다시 확인했다. Gloamwood에서는 표식보다 낮은 뿌리와 지면이 야간 첫 접근에서 하나의 어두운 면으로 읽힌다. Haunted Graveyard에서는 문설주 앞면보다 귀환 사선의 모서리와 단차가 구별하기 어렵다. [이전 Studio 비교판](../evidence/epic-third-chapter-integrated-20261122/README.md)

- Gloamwood의 셰일 파단과 뿌리 속목 폭을 키워 표식 아래의 지형 단면을 드러냈다. Diablo IV 환경 제작기의 기후에 따른 표면 차이와 WoW Hallowfall의 방향 기준 지물을 참고했다. [Diablo IV 환경 제작기](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022) · [WoW Hallowfall](https://worldofwarcraft.blizzard.com/en-gb/news/24125258)
- Haunted Graveyard의 문턱과 귀돌은 마모된 석회석 면을 넓혀 관리 통로로 돌아오는 방향을 나타낸다. Lost Ark Voldis의 건축물이 주민의 일을 설명하는 방식과 Roblox의 캐릭터 규모 검증을 참고했다. [Voldis 제작기](https://www.playlostark.com/en-us/news/articles/creating-voldis) · [Roblox 환경 블로킹](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/greybox-your-environment)
