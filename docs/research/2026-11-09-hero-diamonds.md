# 영웅별 초회 Diamonds 보상 적용

2026-11-09 · TLT-027/041/050/052/057/084 · PLAN/ENG → QA. 이번 최신 사용자 지시가 앞선 계정당 난이도별1회 결정을 대체한다. [난이도별 조사](2026-11-09-difficulty-diamonds.md)와 동일 대화에서 확인한 공식 출처를 재사용한다.

Diablo III 1.0.4 [공식 패치](https://news.blizzard.com/en-us/article/7029347/patch-1-0-4-now-live)의 최초/반복 퀘스트 보상 분리 원리를 참고한다. 영웅별 유료재화 지급량을 디아블로에서 가져왔다는 뜻이 아니며, TLT의 다른 클래스 성장 보상은 이번 사용자 지시에 따른다.

Roblox [경제 균형 가이드](https://create.roblox.com/docs/production/game-design/balance-virtual-economies)의 유입/소비 영향 관점에서, 공유 지갑 공급 상한은 계정420에서4영웅 전체1680개로1260개 늘어난다. 신규 영웅당420개는 스탯/스킬 초기화권100개 기준4장과20개 잔여에 해당하며 가격은 바꾸지 않는다. 기존 계정 초회 원장에서 이미 지급한 몫을 차감해 이관하며 모든 과거 보상을 다시 주지 않는다. 실제 소비 선택과 성장 속도·협동/기기 수용은 후속이다. 최소 검증은 실제4클래스×35스토리×4난이도, 같은 영웅 반복, 구계정 원장/잔액 보존·다른 영웅 누락분 복구, 저장 응답 불명·상한 뒤 재시도다.
