# 에픽 공격 범위와 표시 설정

2026-10-31 확인 · TLT-028/031/061/084 · 리서치/디자인/엔지니어 → QA

사용자 요청은 에픽에도 트레이닝과 같은 몬스터 공격 범위를 표시하고 메뉴에서 공격 범위·내비게이션을 켜고 끄는 것이다. 기존 공격 선은 Y=0 고정이라 지면 높이가 다른 Deepwood에서 묻혔다. 기존 지도 내비게이션 토글은 같은 접속 동안만 유지하는 계약이다.

선택한 최소 구현은 Enemy Attack Ranges / Navigation Trail / Objective Markers의 독립 토글이다. 기본 모두 ON이며 기존 지도 토글과 같은 Player-local 속성으로 동기화한다. 리스폰·메뉴 재생성에는 유지하고 재접속은 초기화한다. 계정 영구 저장·서버 간 이동 복구를 새로 추가하지 않는다.

공격 선은 서버가 확정한 원점·방향·거리·각도·공격 국면을 읽어 지면으로 투영한다. 같은 방식으로 트레이닝0고도·Deepwood 높은 지반·경사를 처리한다. 가까운 적의 실제 공격에만 선을 할당하고 먼 적/스트림 아웃의 선을 정리한다. 왕 주술사의 보라색 범위 경고도 LocalTransparencyModifier로 표시만 제어한다. 서버 피해·보상·AI·공략 게이트에는 영향이 없다.

비용/위험: 경고가 활성인 적에 지면 Raycast가 추가되므로 실기기/4인 비용 측정은 남는다. 바닥이 아직 스트리밍되지 않았으면 해당 선을 숨기며 잘못된 Y=0 경고는 만들지 않는다. 범위 OFF는 기본 전투 애니메이션까지 숨기는 설정이 아니다.

수용 실험: 기본ON·독립 토글·지도 동기화·높이/경사·공격 종료·꺼진 중 생성되는 보스 경고·스트림 복귀·모달 입력/작은 화면·로비/전투 메뉴 진입을 검증한다. 인기도/매출/유지율과 특정 옵션의 인과관계는 주장하지 않는다. 다음 담당 QA는 실제 Deepwood와 실기기에서 가독성·4인 부하를 확인한다.
