# 네 영웅의 타겟·이동·조준 보조 비교

2026-11-03 · TLT-005/006/028/032/033/050/061/084 · Research/ENG → QA/DES.

## 질문과 범위

사용자는 이동해도 타겟이 남는 현재 전투가 적절한지 조사하도록 요청했고, 엘프뿐 아니라 네 영웅 모두가 대상임을 명시했다. 후속 대화에서 10~15세 대상의 쉬운 조작을 논의한 뒤 자동 타겟의 설정 OFF 옵션을 요청했다. 제작 스킬의 리서치 절차를 적용한다. 아래는 공식 문서 확인이며 직접 플레이·연령별 사용자 실험·현재 패치 전수 검증이 아니다. 게임들은 서로 다른 조준 설계를 비교하기 위해 선정했으며 현재 인기 순위·동시접속자 수를 근거 없이 주장하지 않는다.

타겟 정보의 유지, 몸/카메라의 방향 고정, 자동 적 선택, 공격 입력 반복, 공격 동작 취소는 각각 다른 규칙이다. 타겟이 남아 있다는 사실만으로 이동이 불편하다고 판단할 수 없다.

## 관찰과 판단

확인한 사례에는 지속 고정, 전방 조준 보조, 의도적인 고정 입력이 함께 존재한다. 이동만으로 반드시 해제해야 한다는 단일 정답을 뒷받침하지 않는다. 고정을 도입한 게임도 방향·카메라·수동 해제·선택 우선순위·옵션을 함께 설계한다.

어린 플레이어에게 자동 선택이 더 쉬울 것이라는 판단은 **우리 게임에 대한 설계 가설**이다. 인용 문헌에10~15세 사용자 실험이나 유지율 개선 수치는 없다. 터치에서 작은 몬스터를 반복 탭하는 부담을 줄일 가능성이 있으나 의도하지 않은 적 선택과 전투의 단조로움은 실제 관찰이 필요하다.

| 대안 | 기대 이점 | 비용/위험 | 판단 |
| --- | --- | --- | --- |
| 네 영웅 모두 이동 즉시 해제 | 탈출 의도가 간단히 반영됨 | 공격을 피하면서 매번 다시 선택, 모바일 조작 증가 | 기본안으로 비추천. 직전 엘프 수정은 후속 승인으로 대체 |
| 항상 지속 고정·강한 자동 회전 | 집중 공격 용이 | 달아나는 방향과 충돌, 뒤쪽/멀리 있는 적에 묶임 | 기본안으로 비추천 |
| 공격할 때 전방 자동 선택+수동 우선+OFF | 적 클릭 부담 완화, 공통 조작, 숙련자의 수동 선택 보존 | 범위/각도/유지 규칙과 피드백 검증 필요 | 사용자 후속 요청에 따라 채택 |

## 적용 계약과 최소 검증

- 기본 ON. 공격 입력 때 현재 기술 사거리/높이·전방·화면·장애물을 만족하는 적을 선택한다. 공격하지 않을 때 자동 공격을 시작하지 않는다.
- 조건을 만족하는 직접 선택 타겟이 우선하며, 자동 선택도 가능한 동안 유지해 근처 적 사이에서 흔들리지 않게 한다.
- 보통 이동은 즉시 선택을 지우지 않는다. 공격 시 이동 방향을 기준으로 뒤쪽 적 보조를 제외해 후퇴를 방해하지 않는다. 새로운 공격 때 기존 자동 타겟이 부적합하면 다른 전방 적을 고른다.
- 기사/드워프/마법사 지팡이 기본기는 근거리, 엘프 기본기·마법사 주문·드워프 투척은 각 기술 사거리다. 마법사 기본 공격을 원거리로 바꾸지 않는다.
- 회전 광역/자기 중심/자기 강화/도끼 회수는 자동 적 선택에서 제외한다. 피해·MP·쿨다운·최종 판정은 서버가 확정한다.
- SETTINGS의 Auto Target OFF는 새 자동 선택/자동 선택 표식을 끈다. 직접 선택과 기존 전방 공격 판정은 사용한다. 다른 설정처럼 현재 접속 동안 유지하며 재접속 때 기본값으로 돌아간다.
- 각도120°와 이동 임계값은 첫 시험값이다. 수치가 다른 게임과 같거나 연령별로 최적화됐다고 주장하지 않는다.

QA는 네 영웅×ON/OFF×키보드/패드/터치를 비교한다. 적1명/무리/사망 직후/벽 뒤/화면 밖/사거리 경계/후퇴/옆 이동/다인에서 재선택 횟수, 의도와 다른 선택, 뒤돌림, 공격 실패 이유와 회피 성공을 관찰한다. 동일 상황의 수동 설정보다 재선택 입력이 줄고, 공격 입력 없는 공격과 후퇴 중 뒤돌림이 없어야 한다. 최종 임계값·연령별 수용은 실험 후 결정한다. 실제10~15세 관찰·실기기/게시 플레이는 미검증이다.
