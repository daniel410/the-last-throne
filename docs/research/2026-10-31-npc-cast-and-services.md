# NPC 역할·서비스·식별성 조사

2026-10-31 · TLT-001/002/016/031/057/061/065/072/084 · DES/ART/ENG

사용자 요청은 승인된 다섯 에픽 검토, 로비 대장간·상점과 지역별 NPC 컨셉 생성 및 게임 적용이다. 얼굴은 비블록형, 몸통·팔다리는 블록형이다. 비교 관찰은 웹 자료이며 직접 플레이나 영상 분석으로 보고하지 않는다.

추천은 고유 인물30명과 기존 퀘스트 별칭의 공통 모델 체계다. 역할마다 새 상거래/보상을 만드는 대신 기존 대장간·Armory·창고·원정·훈련 서비스에 연결한다. 원본 그림에서 수치/문구를 추출하지 않는다. 새 이름은 제작 제안이며 기존 Selene/Eryn/Brann과 안정ID·진행·보상을 보존한다.

대안은 완성형 메시30개를 외부 생성·업로드하는 방법이다. 이번에는 업로드 권한/다운로드 지연 없이 재현 가능한 native 모델 원형을 만들었다. 그림의 질감·머리카락 세부와 같은 완성도는 후속 메시/텍스처 작업이다. 모델 라이브러리는 서버 저장소에만 두어 미구현 에픽 주민이 현재 전투 월드에 나타나지 않게 한다. 정적 NPC는 Humanoid나 전투AI 슬롯을 사용하지 않으며 Selene 동행만 기존 서버 편성 규칙을 따른다.

최소 수용: 모든 모델의 얼굴/코/눈/입·블록 팔다리, 비충돌·비쿼리, 영문 이름/대사, 기존 prompt 서비스, Deepwood escort 피벗 및 Selene 무료해금/지원 회귀를 로컬 엔진에서 확인한다. 최종 미술 일치, 실기기 성능, 실제 계정 거래·저장과 후반 맵의 실제 배치는 별도 검증이다. 다음 담당 ART/QA는 실제 플레이 거리·기기에서 외형·가독성과 부하를 측정한다.
