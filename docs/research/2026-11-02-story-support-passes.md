# 스토리 지원권: 수량·소비 시점 안내

2026-11-02 · TLT-016/028/043/046/061/072/084 · Research/ENG → QA

## 질문과 확정사항

사용자는 무제한 재동행으로 물약 소비가 사라지는 문제를 지적했다. 로비 구매와 스토리1회200 RPG Gold를 확정하고5/10스토리 묶음 및 명확한 설명을 요청했다. 묶음은 동일 단가1,000/2,000 Gold로 적용한다. 시간제·회복 횟수제가 아니다. 이 가격은 사용자 결정이며 타 게임에서 추정한 최적 가격이 아니다.

## 비교 자료와 확인 한계

- [ArenaNet 공식 과거 Gem Store 안내](https://www.guildwars2.com/en-gb/news/free-transmutation-charges-new-armors-and-more-in-the-gem-store/): 계정별 편의 소모품과 개별 가격을 별도로 설명한다. 2014년 시기의 역사적 사례이며 현재 판매 가격/기능의 근거로 사용하지 않는다. 2026-11-02 문서 확인, 직접 플레이 미실시. 적용 해석: 영구 해금과 유료 편의 사용권을 구분해 보여주면 혼동을 줄일 수 있다. 동행 성능/가격 비교 근거는 아니다.
- [Roblox 공식 플레이어 데이터·구매 설계](https://create.roblox.com/docs/cloud-services/data-stores/player-data-purchasing): 한 테이블 안에서 구매 검증·차감·지급·기록을 원자적으로 수행하고, 재시도 순서와 세션 잠금을 다루도록 안내한다. 2026-11-02 현재 문서 확인. 적용: 기존 RPG AccountStore 단일 키 안에서 Gold/credits/receipt를 함께 저장하고 같은 영수증을 재사용한다. Roblox 개별 게임의 비공개 경제·전환율은 추정하지 않는다.

## 적용안·비용·검증

영구 모집은 무료이며 실제 지원은 캠프의 명시적 초대 시1 credit을 소비한다. 한 credit은 현재 메인스토리가 끝나거나 Return to Lobby를 선택할 때 끝난다. 같은 스토리 내 휴식/사망/재접속은 추가 차감하지 않는다. 자동 갱신은 없다. 미사용 credits는 계정에 보관한다. 파티AI1상한과 기존 회복/보호/정화 능력은 유지한다.

PC/가로 터치/패드의 TD 상세창에1/5/10상품·계정 잔여 횟수·현재 지원·종료 조건을 표시하고 핵심 약관은 구매 버튼 위에 고정한다. 문구·버튼 배치와 저장 분기가 비용이다. 위험은 긴 문구의 가독성과 물약 수요/Gold 소비 밸런스이며, 자동 테스트가 실제 이해도와 경제 수용을 대신하지 않는다.

최소 시험은 세 상품의 서버 가격, 중복 요청, 저장 후 응답 유실, 캠프 권한, 스토리 완료, 재접속, Return to Lobby, 667×375/844×390/1280×720 화면이다. QA 후속: 게시된 각 테스트 Experience에서 잔여 횟수 유지·실제 이동 및 파티4인+AI1·터치/패드 조작·물약 사용률과 스토리별 Gold 순수입을 관찰한다. 이번 조사로200 Gold의 최종 밸런스를 검증했다고 보고하지 않는다.
