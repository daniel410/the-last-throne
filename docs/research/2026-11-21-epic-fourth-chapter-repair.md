# 다섯 에픽 4장 복구와 귀환 지물

2026-11-21 UTC · TLT-061/065/062/063/064

[4장 기존 Studio 화면과 치수](../evidence/epic-fourth-chapter-landmarks-20261120/README.md)를 검토했다. DW 버팀의 늘어진 케이블이 받침과 떨어져 보이고, GW 야간 정면에서는 파손 등불이 어둡다. FV는 돌과 금속의 구분이 이미 보이며, EC는 두 관의 입구가 접근 시 잘 보이지 않는다. HG는 낮은 석재가 정찰 등불의 시야를 확보한다.

- Diablo IV의 Nahantu 소개는 지역마다 번지는 오염과 환경을 구분한다. TLT에서는 흙, 파손 목재, 광물, 마모석으로 각 지역에서 사건이 남긴 흔적을 표현한다. [Blizzard의 Nahantu 소개](https://news.blizzard.com/en-us/article/24128995/delve-deeper-into-nahantu-with-mercenaries-dark-citadel-and-more)
- WoW의 The Ringing Deeps는 고장 난 기계 설비를 배경으로 삼고, The Stonevault는 중앙 처리 시설로 연결되는 광차를 소개한다. TLT에서는 DW 케이블과 FV·EC의 관을 받침과 연결해 설비가 작동하던 방향을 드러낸다. [Blizzard의 지역·던전 소개](https://news.blizzard.com/en-us/article/24125258/explore-the-zones-and-dungeons-of-the-war-within)
- Lost Ark의 South Kurzan은 오염된 바다에서 화산의 원인을 추적하게 한다. TLT의 GW-04와 EC-04에서는 들린 지층과 끊긴 관을 조사 단서와 연결한다. [Lost Ark Summer Heat](https://www.playlostark.com/en-gb/game/releases/summer-heat)
- Roblox 환경 제작 지침은 플레이어 규모와 배치 검사를 권한다. 이번 실험은 이전과 같은 접근·귀환 카메라, 실제 조사 위치와 R15 왕복으로 검증한다. [Roblox 그레이박스 지침](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/greybox-your-environment)

| 장 | 이야기의 기능 | 대표 지물 개선 |
| --- | --- | --- |
| DW-04 | 망루에 남은 구조 시설을 조사한다 | 케이블을 하단 철제 고정구와 연결한다 |
| GW-04 | 뿌리 융기와 부서진 길을 읽는다 | 들린 셰일 단면과 등불 소켓 절단면을 드러낸다 |
| FV-04 | 중계 설비를 지나 돌아온다 | 압설과 석축 사이 금속 슬리브를 드러낸다 |
| EC-04 | 냉각 회로의 파손을 찾아낸다 | 서로 다른 결손이 난 두 관 입구에 깊이를 만든다 |
| HG-04 | 동료를 모아 다시 출발한다 | 집결로 측 마모석과 낮은 끝단을 이어 준다 |

기존 환경 킷과 기본 도형을 사용한다. EC 조사선과 HG 동료 배치의 간격을 우선 확인하고, 새 부품은 장식으로 구성한다.
