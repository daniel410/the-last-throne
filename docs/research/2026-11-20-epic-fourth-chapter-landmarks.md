# 다섯 에픽 네 번째 장의 작업 흔적

2026-11-20 UTC · TLT-061/DW-04 · TLT-065/GW-04 · TLT-062/FV-04 · TLT-063/EC-04 · TLT-064/HG-04 · G5

환경 아트가 0.114.11을 검토했다. Frozen Vale의 교량 고정부는 접근 정면에서 기존 교량판에 가리고 Gloamwood의 귀환 목재 표식은 야간 대비가 낮다. 네 번째 장의 지물은 각각 접근과 돌아보는 시점에서 조사한다. 사용 흔적은 모서리의 닳은 면과 바닥 접점에서 표현하고, 목표와 비슷한 발광이나 문양은 피한다. [세 번째 장 전후 화면과 보행 검증](../evidence/epic-third-chapter-landmarks-20261120/README.md)

## 사례와 적용

- **Diablo IV.** 개발진은 지역의 기후와 역사를 재료, 건축, 소품 표면에 반영한다. TLT는 망루의 철제 케이블 홈, 뿌리에 눌린 등불 받침, 마모된 성문 석재로 시설의 용도를 드러낸다. [Blizzard 환경 아트 제작기](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022)
- **World of Warcraft.** Azure Span은 설봉과 안개 낀 숲을 거쳐 Azure Archives로 이어진다. Frozen Vale 기록고의 정연한 석재와 비정형 압설을 맞대어 바깥 설면과 건축 경계를 구분한다. [Blizzard Azure Span 소개](https://news.blizzard.com/en-gb/article/23823429/dragonflight-zone-preview-the-azure-span)
- **Lost Ark.** Luterra의 Luoden River 서사는 오염과 정화 시설이 지역에 남긴 변화를 설명한다. Ember Caldera에는 냉각이 끊긴 원인을 읽을 수 있는 파손 단면을 놓고, 진행에 따른 복구는 기존 밸브와 회로가 표현한다. [Lost Ark Luterra 소개](https://www.playlostark.com/en-gb/news/articles/tales-of-arkesia-luterra)
- **Roblox.** 환경 그레이박스는 캐릭터 대비 규모, 통행, 관측 위치를 확인한다. 조립체는 기존 환경 킷의 기본 도형으로 제작하고 조사선 양쪽의 시야와 여유 폭을 검사한다. [Creator Hub 환경 그레이박스](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/greybox-your-environment)
