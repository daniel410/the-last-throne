# Selene 첫 동행 무료 체험

2026-11-05 · TLT-016/028/043/061/072/084 · Research/ENG → QA

플레이어 문제: 영입 해금과 유료 스토리 지원을 설명만으로 구별하기 어려워 실제 지원 사용을 배우기 전에 이탈한다. 사용자는 Deepwood 퀘스트 뒤 한 스토리 무료 지원과 추가 지원의 로비 방문 안내를 승인했다.

확인한 사례와 적용:

- [ArenaNet 공식 2022-08-02 업데이트](https://en-forum.guildwars2.com/topic/118935-game-update-notes-august-2-2022/)는 신규 플레이어의 레벨10 랩터 체험을 소개하고, 이전 영웅이 체크포인트를 놓쳤을 때 후속 기회를 설명한다. 2026-11-05 원문 재확인. 역사적 도입 사례이며 현재 상품이나 수치를 비교하지 않는다. 적용 해석: 기능을 실제 사용한 뒤 필요성을 판단할 수 있도록 하며 기존 완료 영웅에게도 아직 사용하지 않은 첫 기회를 허용한다. TLT는 시간제 대신 사용자 승인대로 메인스토리 한 편을 쓴다.
- [FFXIV 공식 Duty Support](https://na.finalfantasyxiv.com/game_manual/dutysupport/)는 지원 NPC로 본편 던전을 진행하는 기능과 진입 경로를 설명한다. 2026-11-05 재확인(페이지 표시 갱신2026-10-13). 적용 해석: 설명을 읽는 데서 끝내지 않고 Selene의 실제 동행/치유 경로를 연결한다. FFXIV의 경제·무료 정책을 TLT에 복제한다는 뜻은 아니다.
- 기존 [지원권 조사](2026-11-02-story-support-passes.md)의 [Roblox 공식 데이터/구매 지침](https://create.roblox.com/docs/cloud-services/data-stores/player-data-purchasing)을2026-11-05 재확인했다. 동일 계정 데이터의 원자적 변경·세션 잠금·순서 있는 재시도·중복 지급 방지 원칙을 첫 체험에도 적용한다. 특정 Roblox 게임의 비공개 경제/체험 규칙을 추정하지 않는다.

채택: DW-03 전체 완료 이후 영웅별 한 번, 안전 캠프/동료 슬롯 확인 후 자동 시작. 현재 메인스토리 한 편을 지원하며 구매 credits/Gold는 보존한다. 기존 계정도 아직 체험하지 않았다면 같은 자격으로 받을 수 있다. 시작은 역할/근접/이후 로비 방문, 종료는 로비 Selene→지원권→캠프 초대를 영어로 안내한다. 체험 후 자동 유료 갱신은 없다.

비용은 선택형 체험 사용 표식·권리 필드와 기존 TD 상세/완료창의 문구 추가다. 신규 UI 프레임·모델·상품ID는 필요 없다. 위험은 파티 슬롯 경쟁, 저장 응답 유실, 체험 종료를 상시 무료로 오해하는 것이다. 최소 검증은 저장 멱등성/응답 유실, 구매 잔여권 보존, 슬롯 점유 시 미사용 유지, 실제 동료 생성/지원 루프, 종료 알림·완료 카드다. 실제10~15세 이해도·기기/다인·물약 소비와 경제 밸런스는 QA 후속이다. 직접 타 게임을 플레이하거나 사용자 실험을 수행한 결과는 아니다.
