Roblox [UI/UX 설계](https://create.roblox.com/docs/production/game-design/ui-ux-design)(2026-10-31 확인)는 비교 사례 Spellbound RPG의 작은 화면 버튼 혼잡과 단계적 표시를 설명한다. [적응형 디자인](https://create.roblox.com/docs/production/publishing/adaptive-design)은 화면 크기와 패드 포커스 검증을 권고한다. 실제 타 게임을 직접 플레이한 것은 아니며 인기나 효과는 추정하지 않는다.

추천과 시험: 그림+영문 이름을 가진 다섯 버튼을 로비에서만 보이며 화면이 짧으면 크기를 줄인다. 무기와 물약/기타 장비의 메뉴·NPC를 분리하고 가격 확인을 유지한다. 복잡도와 화면 공간이 비용이며, 작은 터치 화면에서 축소와 기본 이동 조작의 충돌 위험이 있다. QA는 실제 화면 크기·방향별 겹침과 버튼 선택, 각 상점 상품 분류·중복 구매/매각·실패 복구를 관찰한다. 정식 디자인과 가격 수용은 후속이다.
