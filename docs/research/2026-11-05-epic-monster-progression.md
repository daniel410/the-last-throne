# 에픽 진행에 따른 몬스터 성장 검토

2026-11-05 · TLT-027/050/057/061~065/084 · RESEARCH/PLAN/ENG → QA.

사용자 관찰: 에픽2·3 몬스터가 에픽1과 비슷하게 느껴진다. 소스 추적 결과 레벨은 정상 전달되지만 HP는 일반100+25×레벨, 피해는10+레벨의 공통 선형식이며 지역 보정이 없다. 얼음늑대/임프는 낮은 가족 HP계수를 사용한다. 에픽1 Orc/Ogre에는 별도 Easy HP상향이 있어 지역 차이가 더 줄어든다. 따라서 능력치 전달 누락으로 단정하지 않고 성장 곡선의 문제로 처리한다. 실제 기존 게시 클라이언트의 실행 수치는 이번에 관측하지 않았다.

[이전 RPG·Roblox 조사](2026-11-04-monster-damage-review.md)를 재사용하며 아래 공식 자료를 재검색했다(확인일2026-11-05, 웹 열람, 직접 플레이 아님).

- [Blizzard Undermine(d) 공식 패치](https://news.blizzard.com/en-us/article/24179386/undermine-d-content-update-notes): 상위 Delve 난도를 해당 콘텐츠의 성장 장비와 맞추는 방향이다. 해석: 몬스터 레벨 숫자만 높이기보다 영웅 성장·장비에 대한 실제 위협을 확인해야 한다. 본 게임 배율의 수치 근거는 아니다.
- [Roblox 공식 제작 전략](https://create.roblox.com/docs/get-started/strategies): 초반부터 반복 플레이테스트와 플레이어 피드백을 권장한다. 적용: 정적 수치 증가와 10~15세·모바일의 실제 생존성 수용을 분리한다.

대안: 레벨 선형식만 유지하면 현재 체감 문제를 해결하기 어렵다. 모든 몬스터를 일괄 상향하면 에픽1 난도도 함께 변한다. 선택은 저작된 현재 교전의 에픽을 전달하여 후반 HP·피해만 보정하는 것이다. 캐릭터 레벨에 맞추어 적을 자동 강화하지 않는다. 가족·레벨·난이도·파티·정예 계수와 조합하되 보상은 원래 레벨/정본을 유지한다.

시험값: 에픽1~5 HP1/1.35/1.75/2.2/2.7, 공격력1/1.2/1.45/1.7/2.0. 보스에도 같은 지역 계수를 적용한다. 이는 사용자 요청에 따른 로컬 조정이며 최종 수용된 밸런스가 아니다. 기존 원정은 규칙1~3에 고정해 재접속 중 갑자기 바뀌지 않게 한다. 새 원정은 규칙4, 무난이도 로컬 경로도 지역 보정을 사용한다.

최소 후속 실험: 같은 클래스·장비·투자 기록으로 DW-07→FV-01, FV-07→EC-01의 일반 무리/보스 처치 시간·실피해·물약 사용·사망 원인을 비교한다. 특히 1~4인 동시 피격과 VIT0 Mage, 후반 잠정 성장 예산에서 위험을 측정한다. HP 증가는 전투 지연을, 피해 증가는 보스 급사를 만들 수 있어 실제 수용 전 추가 상향을 확정하지 않는다. 다음 담당 QA/PLAN.
