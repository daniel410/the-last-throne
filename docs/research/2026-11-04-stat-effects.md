# 네 영웅 스탯 역할 수정

TLT-015/027/028/050/052/084 · 2026-11-04 · 리서치/ENG → QA.

사용자가 STR 공격력, DEX 공격·이동속도, VIT HP, INT MP로 엘프를 수정하고 다른 영웅도 검토하도록 요청했다. [기존 비교 조사](2026-10-29-skill-stat-relationship.md)를 재사용하며 아래 출처를 재확인했다. 직접 플레이나 인기 순위를 주장하지 않는다.

- [Elden Ring 공식 스탯 설명](https://www.bandainamcoent.com/es_mx/news/elden-ring-introduction-part-1-stats): 무기 공격 계열과 HP/주문 자원의 역할을 따로 설명한다. 우리의 적용안은 같은 이름이라도 실제로 달라지는 결과를 설명하는 것이다. 타 게임의 스탯별 수치·장비 요구조건을 이식하지 않는다.
- [Blox Fruits 커뮤니티 Stats](https://blox-fruits.fandom.com/wiki/Stats): 검색 색인으로 공격 분류별 스탯/숙련 분리를 재확인했다. 직접 본문은 접근 제한으로 재검증하지 못했다. 수치나 현행 상한을 근거로 사용하지 않는다.
- [Roblox 공식 Humanoid](https://create.roblox.com/docs/reference/engine/classes/Humanoid): WalkSpeed는 이동속도 속성이다. 적용안은 서버의 이동속도와 이동 허용 예산을 함께 늘리고, 공격은 서버 판정과 클라이언트 포즈의 시간축을 같은 비율로 조정하는 것이다.

기존 엘프 DEX 피해를 유지하면 사용자 지시와 충돌한다. 전환 시 기존 DEX 집중 배분의 한 발 피해는 감소하며 속도 이득을 받는다. 자동 STR 이관은 플레이어 선택을 바꾸므로 하지 않는다. INT의 기존 마법 피해를 삭제하면 Mage와 Magic Archer에 별도 피해 재설계가 필요하므로 유지한다.

기본 공격속도 투자당0.5%/상한50%, 이동속도0.1%/상한20%는 이번 구현의 시험값이다. 316P 극단 배분에도 기존 이동 검증·서버 틱·모션을 유지할 상한을 두었다. 이 값이 재미/밸런스에 적절하다는 관찰 증거는 아직 없다. 스킬 시전/다단 간격·쿨다운·회피·방어 판정창은 이번 속도 적용에서 제외한다. 최소 검증은 네 영웅×레벨 경계의 독립 스탯 효과, 서버 시간축/클라이언트 포즈 일치, 기본 배분/장비/자원 회귀다. 다음 QA는 같은 레벨/장비/총 예산에서 STR·DEX·혼합의 처치 시간과 이동/입력 감각을 기기로 비교한다.
