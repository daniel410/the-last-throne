## TLT의 실제 원인과 추천

`HeroProgression.derived`의 physicalPower/magicPower는1레벨 무투자100이다. `CombatService.startAttack/damageEnemy`는 장비 보너스 적용 후 각 기본 공격/스킬 계수와 전투 효과를 곱하고 최종 반올림한다. 따라서 표시Power100은 피해100의 약속이 아니다. 기존 스킬 미리보기는 이미 스탯·숙련·장비를 반영한 기술별 피해를 계산하지만, 기본 공격 피해가 없고 포인트 화면은 정적 힌트만 제공해 관계가 불명확했다.

현재 무장비·Lv1·무투자·일시 효과 없는 기본 공격의 실제 계산 예:

| 영웅 | 계산용Power | 기본 공격1타당 피해 |
| --- | --- | --- |
| Knight |100| 콤보1/2/3타75/90/120 |
| Elf |100|70 |
| Dwarf |100|75 |
| Mage |100|75(INT 마법Power 사용) |

출처: `K0Config.BasicAttackProfiles`와 서버의 최종 반올림. 이는 적HP가 충분하고 보호/일시 효과가 없는 기준값이며 적의 HP 실제 감소량은 남은HP·면역·전투 상태에 따라 달라질 수 있다. 이번에 확인한 일반 적 피해 경로는 일괄 적 방어력 차감 공식을 사용하지 않고 Exposed·표식·반격 등의 배율을 사용한다. 미래의 적 방어 설계를 현행으로 설명하지 않는다.

추천/이번 구현:

1. 기본 공격 피해를 전투 요약에서Power보다 먼저 표시한다. 기사 콤보를 평균1개 숫자로 숨기지 않고 각 타격으로 제공한다.
2. 기존 공격력 레이블을 `Physical Power / Magic Power`로 명확히 구분하고 기본 공격/기술 배율의 기준값임을 설명한다.
3. 포인트 화면 안에 `Current → After confirm (increase)`를 표시한다. 기본 공격 피해 증가와 장비 보너스까지 포함한 파생 증가량을 함께 계산한다.
4. VIT4단위 경계·DEX 상한에서 증가가 없으면+0을 표시한다. 미해금MP도0→0으로 명시한다. 속도는 정확한 배율과 기준속도 대비 증가%를 함께 표시한다.
5. 기존 장착 스킬의1타/다단총합 미리보기와 숙련·영어 설명을 유지한다. 기본 공격 피해가 모든 기술의 피해라는 의미로 보이게 하지 않는다.

TD 공통 프레임·버튼·초상·아이콘을 유지한다. 서버 피해/계수·스탯 배분·저장·전직·MP자격은 변경하지 않는다. 힘의 방어 추가/자동 회피 확률은 조사 제안일 뿐 이번 구현에 포함하지 않는다.

## 비용·수용·인계

기존 순수projection을 확장하고 데스크톱/모바일에 같은 수치/영어 텍스트를 사용한다. 비용은 UI 내용 높이·스크롤 증가, 좁은 화면 문장 가독성 검증이다. 실측 전체 DPS·선택한 적에 대한 실시간 최종 피해는 이번 범위가 아니다.

검증은 [구현 증거](../evidence/stat-investment-preview-20261105/README.md)에 기록한다. QA는 PC/터치에서+·−·취소·확정/재시도, 장비/영웅 변경, 기술별 예상 피해와 일반 무효과 대상의 서버 피격을 대조한다.10~15세 사용자가Power와 기본 공격/스킬 피해를 구분하고 투자 이득을 설명하는지 관찰한다. 최종 글자 가독성·실기기/실계정 수용은 후속이며 부모 티켓 완료로 기록하지 않는다.
