# The Last Throne에 맞는 에픽·스토리·퀘스트 방식

2026-10-29 확인 · TLT-001/011/018/025/026/028/050/052/061/084 · RESEARCH/PLAN/DES/ENG → QA.
대상: 솔로~4인 협동 액션 RPG, PC/터치/패드.0.33.5의 단순 클릭 반복을 늘리지 않으면서 목적·선택·진행·완료를 명확히 하는 조사다. 비교 게임을 직접 플레이한 결과나 인기 순위 조사가 아니라 공식 자료/개발자 발표 개요 비교다.

## 현재 문제의 실제 근거

- `DeepwoodContent`의7본편과4선택 퀘스트를 저널이 같은 행으로 그렸다. 지역 이름과 이야기 제목도 같아 “장소에 도착”과 “갈등 해결”의 차이가 희미했다.
- 저장된 수주 상태가 없었다. 선택 퀘스트 NPC의 request노드가 첫 현장 목표와 같은 goal을 실행해, 주민의 말을 듣기만 해도 현장 조사가 끝날 수 있었다.
- 기본 안내가 배열의 첫 가용 목표를 골라7스토리의 선택 구출을 필수처럼 안내할 수 있었다.
- 조사 활동에도 순서를 강제해 단서를 발견한 플레이어보다 화살표가 정한 순서를 우선했다. 룬 퍼즐과 현장 조사가 같은 순서 계약이었다.
- 끝난 목표 수는 있었지만 이야기의 목적·단계·결과/답변 기록과 보고 대기 상태가 분명하지 않았다. 선택 퀘스트의 고정 XP/Coins가0인 것도 설명하지 않았다.

이 비교를 통해 제안한 혼합 방식은 우리 게임의 솔로 완결·개인 선택·1~4인 협동·모바일·서버 권위 계약에 맞춘 **설계 판단**이다. 다른 게임의 장점이 동일하게 재현되거나 유지율이 올라간다고 입증한 것은 아니다. Roblox 특정 RPG의 비공개 퀘스트 로직·보상 수치를 추측해 복제하지 않았다.

## 채택 방식

**에픽 → 스토리(메인 퀘스트) → 목표 → 활동**으로 정의한다. 선택 퀘스트는 같은 에픽 안에서 별도 가지다. Deepwood의7스토리는7개 메인 퀘스트이며, 기존58목표나60하위 활동을 각각 신규 퀘스트라고 세지 않는다.

| 구분 | 시작·진행 | 완료·보상 | 역할 |
| --- | --- | --- | --- |
| 메인 스토리 | 해당 모험/이전 스토리 완료 시 자동 활성. 기본 추적은 필수 목표. 이야기 이유가 있을 때만 보고/대화 필요 | 필수 목표 전체를 서버가 저장한 순간 자동 확정. 기존 정본 XP/Coins·아이템 지급 | 지역 갈등·다음 지역 해금·주요 인물/핵의 진실 |
| 선택 지역/주민 퀘스트 | NPC 요청이나 현장 단서를 발견 → 요청/효과를 읽고 ACCEPT 또는 LATER → 수주 저장 | 수행과 보고를 구분. 고정 보상/처치 보상·기록 결과를 명시 | 탐험·주민 사정·선택 보스·세계 이해. 본편 진입을 강제 차단하지 않음 |
| 전직 퀘스트 | 해당 클래스/레벨/선행 자격과 전용 시험 | 기존 Lv20/40/60/80 계약 | 전투 성장. 이번 저널에 가짜 미구현 탭을 노출하지 않으며 정식 연결은 후속 |
| 반복 의뢰/던전 | 향후 별도 반복 실행·보상 계약 필요 | 초회 보상과 구별 | 장기 성장용 후보. 본편 분량을 대체하거나 이번에 구현됐다고 보고하지 않음 |

현장 조사는 **자유 순서**로 단서를 모으고 모두 모아야 결론이 열린다. 룬 퍼즐은 단서에 근거한 **정해진 순서**를 유지한다. 호위는 주민과 동행하며 위험에 대응하고, 고정 시간 대기로 분량을 채우지 않는다. 선택 구출은 기본 필수 안내에서 제외하지만 플레이어가 직접 추적할 수 있다.

선택에는 실제 다른 행동/전투 지원이 있는 선택과 대화 태도만 기록하는 답변을 구분한다. 기존 제단 포로 구출은 King Shaman 최종 단계의 도움과 연결된다. 새 대화 답변을 저장했다는 것만으로 새로운 대규모 분기나 지역 재건이 구현됐다고 하지 않는다.

## 제작 규칙과 시험

각 메인 퀘스트는 목적1개·2~4개 의미 있는 국면·필수/선택 목표·알아낸 사실/세계 결과·실패/재개 지점·보상 확정 조건을 정의한다. UI에 전체 내부 ID나 모든 미래 이야기를 노출하지 않는다. 개발 데이터 ID와 이미 완료한 기록은 보존한다.

최소 시험은 Deepwood7본편의 목적/국면 표시,4선택 퀘스트의 수주/보고 상태, 조사 자유 순서, 제단 선택 구출의 기본 추적 제외다. 기존 보상·영웅 진행·거점 전용 트레이닝·전체 에픽 길 안내/지도 토글을 보존한다. [제작 사양](../production/quest-and-story-flow.md)에 상태·예외·검증과 다음 담당을 연결한다.

수용 가설: 처음 보는 플레이어가10초 안에 현재 목적과 필수/선택 여부를 설명하고, NPC 수주만으로 조사 완료가 되지 않으며, 현장 수행 후 어디에 보고할지 이해해야 한다. 조사에서 다른 단서를 먼저 발견해도 막히지 않고 사망/재접속 뒤 이미 모은 단서와 수주가 유지되어야 한다. 실제 플레이 관찰로 판단하며 순수/GUI 검사만으로 재미가 수용됐다고 하지 않는다.

선택 퀘스트의 현재 고정 XP/Coins0은 사실대로 표시한다. 승인 보상을 임의 증액하지 않는다. 기록만으로 충분히 가치 있는 탐험이 되는지와 선택 보스 처치 보상을 포함한 체감은 별도 관찰하고, 필요하면 아이템/지역 기능 보상을 경제 기획과 함께 검토한다. 정식 전직·전면 분기·모든 에픽 런타임·4인/게시 저장/실기기 수용은 남아 있다.
