# 스킬 Lv9 상한 참고 조사

2026-11-07 · TLT-027/028/052/057/084 · 문헌 확인, 직접 플레이 아님.

사용자가 요청한 Lv9 상한을 적용하며 제한된 포인트의 집중 투자 원리만 비교한다. Blizzard 원작 Diablo II/LoD [공식 FAQ](https://classic.battle.net/diablo2exp/faq/skills.shtml)는 레벨당1SP·스킬당20포인트 투자 상한을 설명한다. [공식 투자 전략](https://classic.battle.net/diablo2exp/skills/skillplanning.shtml)은 분산 투자 시 개별 기술 위력이 낮아질 수 있다고 안내한다. 확인일2026-11-07이며 현행 D2R/Diablo IV 패치 규칙으로 일반화하지 않는다.

적용 해석: 제한된 포인트 내 집중 투자 선택을 확대한다. TLT는 자동 해금 Lv1+8SP=Lv9·총79SP로 단순화하며20포인트/퀘스트 추가SP는 도입하지 않는다. 기존 TD UI·터치/패드/PC 버튼은 유지한다. Roblox 타 게임의 구체 상한은 이번 사용자 지정 수치 결정에 필요하지 않아 조사하지 않았다.

대안은 기존 Lv4 유지 또는 요청한 Lv9이며 후자를 채택한다. 비용은 공통 상한·클라이언트 안내 수정, 위험은 높은 랭크의 피해/제어 집중이다. 최소 실험은 네 클래스·8계열 전체 학습 가능 기술의 Lv9 도달/초과 거부·79SP 보존·저장 재시도다. 실전 난도·기기 수용은 QA 후속이며 비교 자료만으로 효과 계수를 바꾸지 않는다.
