# 다른 게임 VFX 조사와 The Last Throne 적용 방향

2026-11-12 · TLT-033/057 · Researcher/DES → ART/ENG/QA.

사용자 요청은 ‘안어울리는 VFX 찾기’에 이어 ‘다른 게임 VFX 리서치’다. 이 문서는 비교 근거와 수정 후보를 제시한다. 게임 소스·VERSION·게시·기존 결정은 변경하지 않는다. 무료 자산 확보나 타 게임 자산 복제 제안이 아니다.

## 결론과 조사 범위

추천은 **Diablo의 명중·정보 위계 + Minecraft Dungeons/Vesteria의 단순한 형상 + 필요한 순간의 짧은 광원**이다. 사실적인 연기·조명이나 더 많은 입자를 일괄 추가하는 방향은 보류한다. 사용자 승인 ‘선과 함께 면이 보이는 화려한 효과’는 유지하고, 면을 실제 무기/지면/폭발 의미에 맞게 다듬는다.

이번에 직접 확인한 것은 개발자 원문, 공식 정지 이미지, Last Epoch Fireball 짧은 시연의 시작/종료 프레임이다. 게임을 직접 플레이하거나 현재 라이브 패치의 모든 스킬을 전수 조사하지 않았다. 자료별 시대와 관찰 방법을 아래에 구분한다. 게임 선정은 미술·전투/기술 조건의 유사성 때문이며 인기·매출 효과를 주장하지 않는다.

우리 게임은0.104.16의 [4효과 Studio 캡처와 적용 기록](../evidence/curated-vfx-20261112/README.md), 현행 `CuratedVFX`·`HeroVFX`·`AdvancedSkillVisual`·`SelenePresentation` 소스를 비교했다. 기존128스킬 보드의 일부는 면/체적 보강 이전 자료여서 현행 전수 화면으로 간주하지 않았다.

## 1. Diablo IV — 주 기준: 명중과 효과 강도

원천: Blizzard, [Diablo IV Quarterly Update—December 2021](https://news.blizzard.com/en-us/article/23746639/diablo-iv-quarterly-updatedecember-2021), 2021-12 개발 자료. 확인일2026-11-12. 출시 전 제작 설명이며 현행 시즌/패치 규칙이 아니다.

**확인 사실:** 개발자는 전투 예고·위험 영역·캐릭터 상태의 정보 위계를 설명하고 강한 효과를 궁극기 등 강력한 기술에 배분한다. 무기 모션과 시각/타격 영역을 맞추고 피격 위치·방향을 따르도록 한 개선을 설명한다. 환경광과 독립 발광을 조절해 여러 조명에서 읽히게 한다.

**우리 게임의 차이와 제안:** Roblox 회전 카메라·터치·4인+AI를 고려해 캐릭터와 위험 바닥이 계속 보이게 한다. 기사 검기는 휘두르는 면과 같은 방향, 드워프 도끼는 실제 투척/귀환 방향, 마법은 발사/접촉/잔류를 구별한다. 궁극기의 강도를 일반 공격에 일괄 적용하지 않는다. 서버 피해 영역·타격 시점·기존 밸런스를 변경할 근거로 사용하지 않는다.

## 2. Minecraft Dungeons — 형상과 기능의 연결

원천: Mojang, [9 essential artifacts](https://www.minecraft.net/en-us/article/minecraft-dungeons--9-essential-artifacts), 2020-08-24. 문서·Corrupted Beacon 물품 이미지 열람. [공식 Gameplay Reveal Trailer](https://www.youtube.com/watch?v=076mjMOL6R8)는2019-06-09 참고 영상 링크이며 이번 조사에서 전체 재생/장면별 타임코드 분석은 하지 않았다. Dungeons II와 구분한다.

**확인 사실:** 공식 설명에서 Corrupted Beacon은 보라색 광선, Corrupted Seeds는 자라나는 덩굴을 통한 얽힘/독, Soul Healer는 회복 기능을 가진 별도 아티팩트로 소개된다. 물품 이미지에서 각진 외형과 밝은 중심색의 결합을 확인했다. 회복의 현재 수치나 라이브 외형을 이번 근거로 확정하지 않는다.

**우리 게임의 해석·제안:** 각진 영웅/무기를 유지하고, 기술 정체성을 읽히는 주 형태를 하나씩 정한다. 화살은 궤적/촉, 얼음은 각진 파편과 차가운 경계, 뿌리는 지면에서 자라는 가지, 폭탄은 팽창 후 흩어지는 파편/연기로 표현한다. 치유·보호·정화는 같은 색 고리만 교체하지 않고 상승 흐름/감싸는 면/씻겨 나가는 흐름으로 구분하는 원형을 비교한다. 이 구체적 변형은 우리 게임 제안이며 Mojang이 제시한 VFX 제작 규칙이라는 주장이 아니다.

## 3. Last Epoch — 국소광과 생성 비용

원천: 개발팀 공식 포럼 [Upcoming Graphical Improvements for Skills](https://forum.lastepoch.com/t/upcoming-graphical-improvements-for-skills/31908), 2021-03-24. Ice Barrage/Fireball/Arcane Ascendance 예시와 주변 표면에 빛을 반영하려는 설명을 확인했다. Fireball의 공개7.007초 클립에서0.063초 부근 발광/방사형 불꽃과7.007초의 잔류 효과가 사라진 장면을 브라우저로 확인했다. 전체 동작을 프레임별로 분석하지 않았으며 중간 타격 시점/발사 속도를 측정했다고 주장하지 않는다.

[Performance & Optimization | Coming in Convergence](https://forum.lastepoch.com/t/performance-optimization-coming-in-convergence/52263), 2023-03-05·0.9 소개에서는 VFX별 벤치마크, 빈번한 효과의 풀링, 투명 효과의 오버드로 비용을 개발자가 설명한다. 현행2026 성능 수치가 아니다.

**우리 게임의 제안:** Bomb Toss의 명중 순간에 작은 발광 중심과 바깥으로 퍼지는 불꽃을 집중하고, 뒤에는 짧은 연기만 남긴다. 지속하는 큰 구형 코어의 비중을 줄이는 A/B를 먼저 한다. 국소광은 선택 효과 몇 개에 한정해 저사양에서 비교한다. 풀링은 실제 생성 비용을 측정한 뒤 검토하며 이 자료만으로 현재 게임의 병목이나 성능 향상을 단정하지 않는다.

참고 시연: [Ice Barrage](https://i.imgur.com/zldmNS2.mp4), [Fireball](https://i.imgur.com/UqN6KPw.mp4), [Arcane Ascendance](https://i.imgur.com/IOJXrn2.mp4). 링크는 개발자 글에서 제공한 영상이며 원본을 저장소에 재배포하지 않는다.

## 4. Vesteria — Roblox 로우폴리 미술의 일관성

원천: 제작자 berezaa의 [Legacy lighting 비교](https://devforum.roblox.com/t/compatibility-is-not-a-valid-replacement-for-legacy-lighting/279628), 2019-05-13. 본문과 Legacy 정지 이미지를 브라우저로 직접 열었다. 캐릭터·모자·장비의 큰 단순 면이 읽히는 이미지를 확인했고, 제작자가 로우폴리 미술에 맞는 평평한 조명 표현을 의도했다고 설명한다.

[개발자 공개 저장소](https://github.com/berezaa/vesteria)의 README는2020년 재작업이 완성되지 않았고 게임이 이전 버전으로 돌아갔다고 명시한다. 이 저장소를 현재 Vesteria 런타임으로 간주하거나 이번에 코드를 가져오지 않는다.

**우리 게임의 제안:** TD 원본 영웅·방패·도끼·활의 큰 형태를 먼저 읽히게 한다. 반투명 면의 화려함은 유지하되 몸을 크게 덮는 아이콘·오라, 모든 표면을 하얗게 만드는 광량을 줄이는 비교를 한다. 2019 Roblox 조명 설정으로 되돌리는 제안은 아니다. 이 근거는 미술 일관성 보완 자료이며 Vesteria의 현행 스킬 VFX 전수 분석이 아니다.

## 5. Torchlight II — 면과 입자의 대비

원천: [공식 Steam 제품 페이지](https://store.steampowered.com/app/200710/Torchlight_II/)에서 제공하는 [정지 이미지](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/200710/ss_ef25ab64b8f02f73692c3ee4177565f631093540.1920x1080.jpg?t=1792118316)를 직접 열었다. 게임 출시일은2012-09-20이며 해당 이미지의 정확한 패치/촬영일은 미확인이다. Torchlight III/Infinite 자료와 혼합하지 않는다.

**직접 관찰:** 어두운 돌 구조/캐릭터 위에 녹색의 넓은 바닥 표현과 작은 금색 입자가 구분돼 보인다. 정지 이미지이므로 기술ID·독/치유 여부·잔류 시간은 확정하지 않는다.

**우리 게임의 제안:** 넓은 바닥 면은 질감·알파·빈 영역으로 지면을 읽히게 하고, 타격의 밝은 입자는 작은 영역에 집중한다. Frost Ring의 청록색 단색 면이 수영장처럼 보이는지, 얼음처럼 보이는지 비교한다. 색만으로 냉기 의미가 전달됐다고 판정하지 않는다.

## 현재 적용분에서 어울리지 않는 후보

아래는 현재 소스와 격리 캡처에 대한 **디자인 판단/가설**이다. 엔진 결함 판정이나 사용자 최종 미술 수용이 아니다.

| 우선 | 대상·관찰 근거 | 어긋나는 인상 | 추천 원형 |
| --- | --- | --- | --- |
| 1 | Frost Ring. `HeroVFX`의 큰 청록 면 + 지면 위1.4stud에 올린 카메라 지향 Frost Nova 이미지 | 큰 범위 면과 작은 그림의 시점·높이가 다르다. 별도 원근을 가진 카드가 뜨는 구조다. 실제 카메라 회전 시 어긋나는 정도는 미검증 | 기존3D 범위 유지, 얼음 경계/파편을 주 표현으로 정리하고 바닥 원근이 그려진 이미지 제거 비교 |
| 2 | Bomb Toss. `BlastVolume` 구3.2stud + 흰 `BlastCore` 구1.5stud + 새 폭발 PNG | 캡처에서 둥근 주황 구가 주로 읽혀 에너지 구체/보호막의 인상이 강하다 | 작은 짧은 중심광→방사 파편→얇은 연기 순서. 기존 큰 구형 층을 줄여 새 폭발이 읽히는지 비교 |
| 3 | Selene Heal. 대상 몸 옆의 큰 밝은 Plus 입자 | 치유 의미는 분명하지만 UI 의료 아이콘의 인상이 강하고 영웅 외형을 가릴 수 있다 | 작은 십자 몇 개와 MINT 상승 입자를 주 표현으로 비교. 기존 +HP 결과·지원 연결은 유지 |
| 유지 | Spirit Rain. 자연색 낙하 파편·5접촉 지점·기존4펄스 | 마법궁수의 역할과 맞는다. 일반 궁수의 물리 화살과 같은 표현으로 확장할 근거는 없음 | 마법궁수 전용으로 유지하고 낙하 방향/촉·시전4펄스의 동시성을 실제 재생에서 확인 |

앞서 선정한 무료 팩이 게임 전체 미술에 자동으로 어울린다고 볼 수는 없다. 기능·수명·예산 검사를 통과한 사실과 미술 적합성은 별개다. 특히 Frost Ring/Bomb Toss는 새 원본 자체와 기존 기하 층을 각각 켜고 꺼 원인을 분리해 비교해야 한다.

## 최소 비교 실험과 인계

1. DES/ART: 위4개를 현재안/정리안으로 만들고 실제 TD 영웅 모델·무기·적과 함께 같은 카메라에서 비교한다. 회색 모형 캡처만으로 미술 수용하지 않는다.
2. ENG: 피해·펄스·범위·회복·성장 계약을 유지한다. 새 효과 생성보다 겹치는 장식 층의 교체부터 실험한다. 위험 예고와 실제 범위 정보는 보존한다.
3. QA: 밝은 Deepwood/어두운 지역, 카메라 상하·좌우 회전, 솔로/4인+AI를 비교한다. 기술 종류 식별, 영웅/목표/위험 바닥 가림, 최초 로드 지연, 같은 기기의 GPU/프레임 시간·동시 효과 수를 관찰한다. 수치 합격 기준은 현재안 기준 측정과 함께 정한다.

다음 담당은 DES/ART의 **Frost Ring → Bomb Toss → Selene Heal** 정리 시안이다. 사용자 승인 전에는 이 조사로 게임 코드를 자동 변경하지 않는다. 실제 플레이·전체 동영상 분석·실기기·다인 성능·최종 미술 수용은 미검증이며, 문서 조사 완료가 TLT-033/057의 Done을 뜻하지 않는다.
