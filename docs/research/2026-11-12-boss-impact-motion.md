# 보스 피격 VFX·공격 동작 개선

2026-11-12 · TLT-005/027/032/033/057/084 · ENG → QA

기존 [적 패턴 조사](2026-11-05-enemy-pattern-review.md)를 재사용하고 관련 공식 문서를 다시 확인했다. 사용자 요청은 보스 공격이 영웅에게 주는 시각적 효과와 몬스터 공격 움직임 개선이다.

- [Diablo IV 개발자 VFX 설명, 2021-12](https://news.blizzard.com/en-us/article/23746639/diablo-iv-quarterly-updatedecember-2021): 다수 전투의 가독성과 판정/효과 시점의 정밀도를 설계 원리로 제시한다. 출시 전 개발 설명이며 현행 패치 수치나 직접 플레이 관찰이 아니다. 이번 적용은 서버 명중 시점과 클립 접촉 자세를 일치시키고 피격 위치에 짧은 속성 모티프를 붙이는 것이다.
- [Roblox Highlight 공식 문서](https://create.roblox.com/docs/effects/highlighting): 윤곽과 내부 색을 별도 조절하며 모바일 화면 점유 비용을 설명한다. 기존 짧은 Highlight를 유지하고 별도 전신 Highlight를 겹치지 않는다. 추가 모티프는 최대5파트·12묶음·0.55초로 제한한다. 이 상한 자체가 실기기 성능 증거는 아니다.

해석·선택: 준비 자세를 읽을 시간을 유지하고 타격 후 회수와 다음 타격 준비를 연속 보간한다. 원거리 시전은 마지막 발사 뒤 자세를 유지한다. 영웅의 불꽃/얼음 결정/독 방울/실 가닥/영혼·비전 표식은 짧은 접촉 표현이다. 지속 피해·감속·구속을 추가하지 않아 기존 피해/상태 이상/회피 계약과 충돌하지 않는다. 원본 자산·서버 피해 수치·전투 빈도는 유지한다.

최소 실험: 전체50종146공격의 각 펄스 접촉 자세, 30/60/144Hz 연속성, 실제 리그 변환/루트·HP 보존, 명중/방어/회피·중복/지연/정리를 검사한다. 이후 QA는 정상 보스전에서 맞은 속성을 구분할 수 있는지, 움직임과 판정의 체감 차이, 작은 화면의 영웅/위험 경고 가림과 4인+AI 성능을 관찰한다. [결과·수용 경계](../evidence/boss-impact-motion-20261112/README.md).
