# 마법사 모자 게임 등록

2026-11-11 · TLT-028/029/032/041/052/057/084

기존 [등급 외형 조사](2026-11-08-equipment-rarity-visuals.md)를 재사용하며 공식 자료를 재확인했다. [Diablo IV 2020년 12월 개발 설명](https://news.blizzard.com/en-gb/article/23583664/diablo-iv-quarterly-updatedecember-2020)은 장비로 클래스의 판타지를 강화하는 방향을 설명한다. 출시 전 디자인 근거이며 현행 패치 수치를 가져오는 근거가 아니다. [Roblox 접근성 지침](https://create.roblox.com/docs/production/publishing/accessibility)은 색상에 기호를 함께 사용하도록 안내한다.

적용 판단: 사용자가 지정한 TD 기반 모자 PNG를 전용 Mage Hat 이름·Mage 자격·기존 희귀도 표시와 함께 등록한다. 최신 사용자 지시로 기본 옵션은 지력3/6/15/30으로 적용하고 동일 계열의 가격·레벨을 재사용하며 신규 특수 효과나 드롭 규칙은 만들지 않는다. 후드를 모두 삭제하는 대안은 기존 보유품 계약을 깨므로 채택하지 않는다. 실제 3D는 PNG와 별도 산출물이며 이번에 만들지 않는다. 최소 검증은 마법사 착용/다른 클래스 거부·가격/재시도·신규 착용/기존 저장 보존·전 메뉴 원본 이미지 로딩이다. 실기기 가독성·3D 미술 수용은 QA/ART 후속이다.


지력 후속 확인(2026-11-11): [Blizzard 원문](https://news.blizzard.com/en-us/article/23583664/diablo-iv-quarterly-updatedecember-2020)을 검색 결과 본문으로 재확인했다. 2020-12 출시 전 개발 방향의 클래스 정체성 원칙만 참고하며 현행 Diablo IV 수치를 적용하지 않는다. [Roblox 서버 검증 지침](https://create.roblox.com/docs/scripting/security/server-side-detection)은 서버가 판단하는 구조를 안내한다. 적용 판단은 사용자 요청과 기존 기본 옵션1개 계약에 따라 모자의 방어력을 같은 수치의 INT로 교체하는 것이다. 복합 옵션 대안은 기본 옵션 수를 늘리므로 채택하지 않는다. INT당 마법 공격력2·최대MP3은 이 저장소의 기존 투자 공식을 장비 지력에도 확장한 값이다. 위험은 방어 감소와 MP/피해 증가이며 모자4계열·강화·교체·기존 보유품을 회귀 검증한다. 엔진/실기기에서 실제 피해·MP 상한 갱신과 영어 표시를 확인하는 작업은 QA 후속이다.
