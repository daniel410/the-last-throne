# 마법사 모자 게임 등록

2026-11-11 · TLT-028/029/032/041/052/057/084

기존 [등급 외형 조사](2026-11-08-equipment-rarity-visuals.md)를 재사용하며 공식 자료를 재확인했다. [Diablo IV 2020년 12월 개발 설명](https://news.blizzard.com/en-gb/article/23583664/diablo-iv-quarterly-updatedecember-2020)은 장비로 클래스의 판타지를 강화하는 방향을 설명한다. 출시 전 디자인 근거이며 현행 패치 수치를 가져오는 근거가 아니다. [Roblox 접근성 지침](https://create.roblox.com/docs/production/publishing/accessibility)은 색상에 기호를 함께 사용하도록 안내한다.

적용 판단: 사용자가 지정한 TD 기반 모자 PNG를 전용 Mage Hat 이름·Mage 자격·기존 희귀도 표시와 함께 등록한다. 최신 사용자 지시로 기본 옵션은 사용자 지정 최대MP10/20/30/60으로 적용하고 동일 계열의 가격·레벨을 재사용하며 신규 특수 효과나 드롭 규칙은 만들지 않는다. 후드를 모두 삭제하는 대안은 기존 보유품 계약을 깨므로 채택하지 않는다. 실제 3D는 PNG와 별도 산출물이며 이번에 만들지 않는다. 최소 검증은 마법사 착용/다른 클래스 거부·가격/재시도·신규 착용/기존 저장 보존·전 메뉴 원본 이미지 로딩이다. 실기기 가독성·3D 미술 수용은 QA/ART 후속이다.


최대MP 후속 판단(2026-11-11): 사용자 중지/후속 요청으로 지력안을 대체한다. 최종 수치는 Traveler +10, Tempered +20, Veteran +30, Sentinel +60이다. 같은 날 재확인한 [Blizzard 개발 설명](https://news.blizzard.com/en-us/article/23583664/diablo-iv-quarterly-updatedecember-2020)의 클래스 정체성 원칙만 참고하고 현행 Diablo 수치를 적용하지 않는다. [Roblox 서버 검증 지침](https://create.roblox.com/docs/scripting/security/server-side-detection)에 맞춰 기존 서버 장비 정의 기반 MP 집계를 사용한다. 사용자 지정값은 같은 계열 로브20/30/50/80보다 작고, 마법 공격력 증가를 동반하지 않는다. 단일 최대MP 옵션으로 기존 MP 장비/강화 경로를 재사용하며 현재 MP 회복은 제공하지 않는다. 최소 검증은4계열·강화·착용/해제·기존 보유품·공격력/지력 무변화다. 엔진/실기기 MP 상한 갱신과 영어 표시 수용은 QA 후속이다.
