# FV-03 식생 군집과 전투 거리의 시야

2026-11-15 · TLT-062 · 리서치/환경 아트/환경 모델링/맵 구현 순차 수행

기존 대표 빙하를 유지하면서 작은 설목의 반복과 균일한 크기 때문에 전경/중경이 약하게 읽히는 문제를 실험한다. 솔로~4인+허용AI, PC/터치/패드의 전투 가독성이 대상이며, 이번 근접 Edit 화면을 실제 게시 클라이언트 관찰로 보고하지 않는다.

- [Diablo IV 개발자 환경 아트 설명](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022), 2022-03 개발 중 자료, 2026-11-15 재확인: 게임 카메라에서 디테일의 양과 위치를 조절해 전투·이동·서사를 지원한다고 설명한다. 해석/채택은 전투 바닥을 비우고 외곽 군집의 큰 형태를 먼저 구별하는 것이다. 현행 시즌 수치/직접 플레이/흥행 원인으로 일반화하지 않는다.
- [WoW Retail Dragonflight Azure Span 공식 지역 소개](https://worldofwarcraft.blizzard.com/en-gb/news/23823429/avance-de-zona-de-dragonflight-las-tierras-azures), 2022-07-14, 2026-11-15 검색 원문 확인: 숲/툰드라/설빙 첨탑의 변화와 주민의 장소성을 설명한다. 해석/채택은 식생 덩어리와 열린 빙하 공간의 대비다. Classic이나 현행 패치 규칙을 섞지 않는다. 타 게임의 지역·설목 자산을 복제하지 않는다.

전체 설원을 조밀하게 채우는 안은 시야/인스턴스 비용 때문에 보류한다. 신규 수종/외부 메시 제작보다 승인 TD SnowTree의 크기·회전·군집 파생을 먼저 채택했다. Blender/원본 메시/텍스처/전역 조명을 바꾸지 않는다. 기존 모델별3파트, 최대18모델/54파트라는 유한 구현 상한을 두며 실측을 기기 성능 통과로 해석하지 않는다.

최소 실험은 FV-03 한 구간이다. 신호선과 사건/전투/통행 예약 밖에 불균일 크기 군집을 배치하고 기존2열 식생만 대체한다. 원본 메시/텍스처 일치, 실제 접지·줄기 고체/잎 비충돌, 봉화 시야, 기존/Easy 이동 sweep과 실제 R15 봉화 왕복/접근을 확인한다. 동일 카메라/조명의 전후 화면을 별도 fresh Edit 장면에서 남긴다. 미술 취향·자유 조작·기기 성능 수용은 후속이다.
