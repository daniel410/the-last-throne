# 영웅 공격/방어 총합과 장비 기여도 표시

2026-10-31 · TLT-028/043/046/052/084 · RESEARCH/DES/ENG → QA

사용자는 공격력·방어력을 어디서 확인하는지, 장비로 추가된 수치를 어떻게 보는지 물었고 다른 게임 조사와 개선을 요청했다. 기존 H→STATS는 배분창 아래 작은 POWER/MAGIC/ARMOR 한 줄에 장비 포함 총합을 표시하므로 발견/출처 구분이 어려웠다.

## 공식 비교 근거

- [Guild Wars 2 — Learn About Critical Damage Changes](https://www.guildwars2.com/en-gb/news/learn-about-critical-damage-changes/),2014 Feature Pack의 공식 설계 설명,2026-10-31 확인: 속성창에서 기본 치명타 피해와 보너스를 합쳐 표시하도록 바꾼 이유를 설명한다. 이 역사적 버전의 UI 원칙을 참고했으며2026년 실제 클라이언트의 현재 전체 배치를 확인했다는 뜻은 아니다. 우리 적용은 총합을 크게 표시하고 영웅/장비 기여를 그 아래 분리하는 것이다.
- [Throne and Liberty — Update3.11.0](https://www.playthroneandliberty.com/en-us/news/articles/update-3-11-0?language-picker=true),2025-12-03,2026-10-31 확인: 개인 Combat Meter 요약과 별도 Combat Analyzer의 스킬/통계 상세를 설명한다. 이는 장비 속성창 자체의 근거가 아니라 요약과 상세 진입을 분리하는 공식 비교 사례다. 우리는 H→STATS의 총합과 SHOW GEAR BONUSES 펼침으로 이 원칙을 제한 적용한다. 전투 로그/DPS 미터를 구현한 것은 아니다.

실제 비교 게임 플레이·이용자 실험·인기 순위는 조사하지 않았다. Roblox 게임의 비공개 구현이나 특정 경험의 미확인 UI를 근거로 추가하지 않았다. 모바일/패드는 기존 TD 패널·44px 펼침 버튼·단일 바깥 스크롤 구조에 맞춰 네이티브 텍스트 폭/높이를 검증한다.

## 적용과 수치 계약

- 물리 공격력/마법 공격력/방어력/최대HP/MP를 화면 위 COMBAT STATS로 올린다. 각 행은 현재 총합과 Hero + Gear를 표시한다. Hero는 클래스·레벨·확정 배분, Gear는 실제 장착된 영웅 장비다.
- 장비 power는 정수 공격력 가산이 아니라 물리/마법 공격력에 공통 적용되는 비율이다. 예:영웅127,장비7%라면 총135.89와 장비+8.89를 표시한다. 공격력은 스킬 배율을 곱하기 전 power이며 DPS/최종 모든 피해량이라고 표현하지 않는다.
- 방어력은 기존 서버의 VIT 투자4당1+장비armor다. 공격마다 피해에서 빼되 최소1피해인 규칙을 설명한다. 미구현 치명타/공격속도/저항/방어율을 임의 생성하지 않는다.
- SHOW GEAR BONUSES에서 고정8슬롯 순서로 장착 아이템 이름·+n% attack power/+n defense/+n Max HP를 표시한다. 다른 영웅·가방·창고 물품은 제외한다. 훈련 장비처럼 수치가 없는 아이템은 No combat stat bonus로 밝힌다.
- 현재 총합은 확정 수치로 유지하고 미확정 포인트는 DRAFT 전후/차이로 별도 표시한다. 서버 저장/전투 공식·기존 수치·경제·장착 권한은 변경하지 않는다. 영웅 창이 이미 수신하는 InventoryState 변경으로 갱신된다.

공간이 작은 경우 총합→장비→배분→스킬 예상치로 수직 배치한다. 장비 펼침은 길이를 늘리지만 별도 중첩 스크롤을 추가하지 않는다. QA는1160/740/390/280px·네 클래스/8계열·현재/초안·장비 장착/해제 갱신·가방 제외·단위/반올림과 서버 계산 일치를 확인한다. 실제 기기 입력·사용자 발견성은 별도 수용이다.
