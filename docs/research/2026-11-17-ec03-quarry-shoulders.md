## 대안·선택

첫0.111.29는 내부 여백에 반경64의 낮은 현무암 돌출부1곳을 추가했다. 두 동선은 통과했지만 지형 경사 검사로 대표 광산이 다른 곳으로 재배치되고 원본 암반의 분리된 외곽이 두드러져 기각했다. 기준을 낮추지 않고 원래 시설을 유지하는 외곽 기저 개선으로 범위를 바꿨다.

최종안: 기존 반경96 안에서 구88/54 두 번의 Terrain 쓰기를 각 능선에 추가한다. 중심 아래68/49stud에 묻고 기저를 넓힌다. 각 구의 수평 반경88 및 sqrt(12²+24²)+54=80.83은 voxel 여유8을 포함해96 안이다. 전체 쓰기6→10, 추가 BasePart/메시/광원/입자/반복루프0. TD/Blender 원본·권한/해시는 변경하지 않는다. 도구 생성 형상이므로 새 외부 자산 도입이 아니다.

수용: 원래 능선2·시설의 월드 변환/크기/고체 속성, 두 동선, 실제 Terrain 재질·기저 높이와 동일 시점 화면. 비용은 네 번의 추가 Terrain 생성과 넓어진 voxel 지형이다. 대상 기기 메모리/생성 시간/스트리밍 비용은 실측 전이며 성능 통과로 쓰지 않는다. 게시 클라이언트·실제 영웅 카메라/조작·다인/AI·사용자 미술 수용은 QA/ART 후속이다. [결과](../evidence/ec03-quarry-shoulders-20261117/README.md).
