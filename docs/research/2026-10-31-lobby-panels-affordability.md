# 로비 창 크기와 구매 가능 상태

TLT-028/031/043/046/061/084 · 2026-10-31

관찰: [Roblox UI 크기 제약](https://create.roblox.com/docs/ui/size-modifiers)은 화면 크기에 따른 UI 크기와 텍스트 가독성을 다룬다. [Guild Wars 2 공식 상점 UI 소개](https://www.guildwars2.com/en/news/introducing-the-new-trading-post/)는 구매/판매에서 현재 상태와 거래 내용을 분명히 알려 주는 방향을 설명한다. 이전 [대장간 조사](2026-10-31-blacksmith-and-td-icon.md)를 재사용해 2026-10-31 재확인했다. 인기나 수익성의 비교 실험은 하지 않았다.

적용: 로비 HEROES의 최대800×510과 배치를 공통화하고 높이400 미만에서는 모든 창에 동일한 안전 여백을 적용한다. 작은 상점 창은 스크롤 목록 공간을 확보한다. Gold 또는 Diamonds 잔액이 부족한 상품은 원래 가격과 부족액을 보이고 버튼을 비활성화한다. 잔액 스냅샷이 갱신되면 재계산한다. 금액 검증은 기존 서버 거래 로직이 확정한다. 잔액을 받지 못한 상태를0으로 추정하지 않는다.

최소 검사: 실제 UI 생성자에서 여러 화면 크기·로비/전투 전환·목록 영역과 지도를 검사한다. Gold/다이아 부족·정확한 잔액·잔액 감소·미수신과 원래 가격을 검사하고 서버 재요청/부족액 거부 회귀를 확인한다. 실기기 터치·게임패드 및 시각 수용은 후속이다.
