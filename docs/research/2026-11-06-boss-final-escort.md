# 마지막 웨이브의 보스·호위 조합

2026-11-06 · TLT-005/016/027/050/061~065/084 · 사용자 직접 지시 적용 · RESEARCH/ENG

기존 [적 패턴 비교 조사](2026-11-05-enemy-pattern-review.md)를 재사용하고 공식 [Diablo IV Quarterly Update—February 2020](https://news.blizzard.com/en-gb/article/23308274/diablo-iv-quarterly-updatefebruary-2020)의 monster family 역할 구분을 검색 결과에서 재확인했다. 이는2020년 출시 전 설계 설명이며 현행 Diablo IV 패치나 실제 보스 동반 몬스터 수의 근거가 아니다. 해당 자료는 같은 종족의 근접/원거리/중량/보스 역할 구분을 설명한다. 사용자 결정을 우선하며 디아블로 관찰로 기존 결정을 자동 변경한 것이 아니다. 최초 en-US URL 열기는 redirect-loop로 실패했고 공식 en-GB 원문 검색 결과를 확인했다. 직접 플레이/영상 관찰은 하지 않았다.

적용은 보스의 마지막 등장 시점과 같은 지역의 일반 적 역할을 함께 읽게 하는 것이다. Roblox의1~4인·AI동료 환경에서 기존 동시 개체 상한을 보존하고, 신규 소환 AI/무한 증원 없이 미리 확정된 유한 편성만 쓴다. 기존 호위가 있으면 일부를 최종 웨이브에 남기고, 보스만 있으면 같은 지역의 일반 적 한 코호트를 추가하는 안을 채택했다. 수를 제한 없이 늘리는 안과 보스가 다시 소환하는 안은 사용자 요청 범위를 넘고 성능/반복 보상 위험이 커 이번에는 적용하지 않는다.

최소 검증은22보스×1~4인에서 마지막 단일 보스+일반 적·동시 상한·영수증/보상 중복 방지다. 실제 엔진에서는 보스부터 처리해도 살아 있는 호위를 건너뛰지 않는지 확인한다. 최종 체감 난도·기기 성능은 실플레이 수용 대상으로 남긴다. [구현과 결과](../evidence/boss-final-escort-20261106/README.md).
