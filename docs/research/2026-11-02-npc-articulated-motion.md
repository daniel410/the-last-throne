# NPC 관절·보행 개선 근거

2026-11-02 · TLT-031/057/061/084 · 리서치/ART/ENG

질문: 둥근 머리·블록 몸체와 인물별 소품을 보존하면서 고정 인형처럼 보이는 NPC29명을 어떻게 개선할까? 기존 Selene는 별도 TD6메시 보행을 사용하므로 이 변경에서 제외한다.

[FFXIV Duty Support 공식 설명](https://na.finalfantasyxiv.com/game_manual/dutysupport/)(페이지 갱신2026-10-13, 확인2026-11-02)은 NPC와 본편 던전에 함께 입장하는 기능을 설명한다. [기존 조사](2026-11-01-selene-follow-and-healing.md)를 재확인했다. NPC의 인물성과 역할을 유지하는 비교 사례로만 사용하며 내부 리그·보행 알고리즘이나 인기 순위는 확인하지 않았다.

[World // Zero 공식 Roblox 소개](https://www.roblox.com/games/2727067538/World-Zero-Anime-RPG)(확인2026-11-02)는 다양한 세계의 퀘스트·던전·친구와의 모험 및 캐릭터 장식을 안내한다. 우리 게임과 가까운 협동RPG 비교 사례다. 게임 소개만 확인했으며 NPC 실제 동작·접지 품질은 미검증이다. 장식과 종족 실루엣을 유지한 채 움직임을 개선하자는 해석이며 타 게임 동작을 복제하지 않는다.

[Roblox Motor6D](https://create.roblox.com/docs/reference/engine/classes/Motor6D)는 관절 애니메이션을 지원하지만 현재 NPC는 서버의 anchored Model:PivotTo 이동/프롬프트 계약을 사용한다. Motor6D·Humanoid로 즉시 교체하면 별도 물리·이동 통합이 필요하다. 이번에는 기존 분리형 블록을 어깨·팔꿈치·손목·골반·무릎·발 그룹으로 묶는 rest-space 변환을 채택했다. 완전한 스키닝/R15 제작으로 보고하지 않는다.

[Roblox 성능 지침](https://create.roblox.com/docs/performance-optimization/improve)과 [스트리밍](https://create.roblox.com/docs/workspace/streaming)(확인2026-11-02)을 근거로 서버는 원래 이동 앵커를 유지하고 시각 변형만 클라이언트에서 처리한다. 100stud 밖/개인 숨김 NPC는 업데이트를 멈추고 원자적 스트림 인 시 재연결한다. 이 거리와 비용은 우리 구현 선택이며 공식 성능 보장 수치가 아니다.

적용: 기존 얼굴·헤어·블록 치수 보존, 손에 붙는 소품, Nia 양손 왕관, 책/지도 팔 굽힘, 머리의 제한된 시선·호흡, 거리 기반 교차 보행과2관절 접지, 서버 갱신 사이의 위치/회전 보간. 추가 인스턴스·이미지·외부 업로드 없이 기존29명에 적용한다. 고정 상점NPC가 멀리 떠돌거나 상점에서 벗어나는 행동AI는 추가하지 않는다.

검증 가설:29명 장식 비충돌·서버루트 불변·소품 강체 부착·왕관 양손 접촉·평지 발 관통 없음·30/60/144Hz 거리 기반 보행·순간이동 오인 방지·제거 시 원형 복원. 엔진 검증과 실제 게임 입력/모바일·다인 성능/최종 미술 수용은 구분한다. 다음 담당 QA/ART는 실제 호위 경사로 접지·가속감·근거리 얼굴·소품 관통과 프레임 비용을 수용한다.
