# 다섯 에픽 6장 접근과 귀환의 설비 단면

2026-11-21 UTC · TLT-061/DW-06 · TLT-065/GW-06 · TLT-062/FV-06 · TLT-063/EC-06 · TLT-064/HG-06

환경 아트와 3D 모델링 리뷰에서 0.115.16의 고정 카메라 10쌍을 확인했다. Gloamwood의 밤에는 끌것의 목재만 먼저 보이고 견인 줄은 어두운 바닥에 묻힌다. Frozen Vale의 귀환에서는 전달관에 석축이 겹친다. Deepwood에는 석판 밖으로 이어지는 유수 흔적이 약하고, Ember Caldera에서는 차열판 발치가 받침과 겹치며, Haunted Graveyard의 첫 접근에서는 난간과 받침이 한 덩어리로 읽힌다. [이전 화면과 측정](../evidence/epic-sixth-chapter-fixtures-20261121/README.md)

## 사례와 적용

- Diablo IV 환경 제작진은 Scosglen의 해안 침식과 바람의 영향을 환경에 반영했다. Deepwood에는 물이 빠진 방향을 나타내는 퇴적 사면을, Frozen Vale에는 압설과 대비되는 노출 정비면을 적용한다. [Blizzard 환경 제작기](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022)
- World of Warcraft의 Ringing Deeps에는 Machine Speakers가 유지하는 산업 설비가 등장한다. Ember Caldera의 바닥 작업면과 Frozen Vale 관의 받침·고정 띠에 실제 정비 방식이 드러나게 한다. [Blizzard 지역 소개](https://news.blizzard.com/en-gb/article/24125258/explore-the-zones-and-dungeons-of-the-war-within)
- Lost Ark 제작진은 Voldis의 장소와 건축에 과거 사건과 주민의 선택이 드러나도록 구성했다고 설명한다. Gloamwood는 당겨 쓰는 끌것으로 정찰대 구조를, Haunted Graveyard는 오랫동안 손이 닿은 난간으로 왕릉 귀환로를 뒷받침한다. [Smilegate RPG 제작 인터뷰](https://www.playlostark.com/en-us/news/articles/creating-voldis)
- Roblox 환경 제작 가이드는 캐릭터 축척과 통과 가능성을 초기 공간 검증에 포함한다. 양방향 화면과 R15 보행, 기존 조사 앵커, 지면 접촉을 비교한다. [Roblox Creator Hub](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/greybox-your-environment)
