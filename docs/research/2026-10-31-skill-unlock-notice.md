# 스킬 해금 안내 조사

2026-10-31 확인 · TLT-005/032/033/084 · 리서치/ENG/QA

기존 [표시 가독성 조사](2026-10-31-display-guides-settings.md)의 대비·읽기 쉬운 표시 원칙을 재사용했다. [Roblox UI 트윈 문서](https://create.roblox.com/docs/ui/animation)는 UI 크기와 위치의 부드러운 전환을 설명한다. [Guild Wars 2 신규 플레이어 안내](https://www.guildwars2.com/en/new-player-guide/)는 레벨 성장과 스킬 습득 안내를 제공하나 이번 팝업의 동작이나 인기를 검증하는 근거는 아니다. 직접 플레이 비교는 하지 않았다.

서버가 확정한 영웅 성장 스냅샷 사이에서 새로 자격이 생긴 기술만 비교한다. 공통 기술·선택 계열·전직 궁극기를 구분 없이 실제 해금 규칙에 맞춰 알리고, 여러 개는 순서대로 표시한다. 첫 로딩과 영웅 교체는 기준값으로만 사용한다. TweenService의 짧은 확대와 영어 스킬명·사용 위치 안내를 사용하며 전투/성장 수치와 해금 권한은 변경하지 않는다. 기기 가독성·실제 대규모 레벨 상승에서 알림 대기 시간은 후속 수용 항목이다.
