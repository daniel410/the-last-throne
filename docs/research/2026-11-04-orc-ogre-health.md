# 오크·오우거 HP 조정 검토

2026-11-04 · TLT-005/057/061/084 · RESEARCH/ENG → QA

사용자가 지적한 문제는 오크·오우거의 낮은 생존력이다. 기존 [파티 스케일 조사](2026-10-31-party-enemy-scaling.md)와 [난이도 조사](2026-11-03-difficulty-reward-materials.md)를 검토했다. 이번에는 적 수·공격력·보상 체계를 바꾸지 않고 해당2종의 HP만 약2배로 시험한다. 배율은 우리 게임의 시험 판단이며 외부 게임에서 확인한 수치가 아니다.

- RPG 비교: [Guild Wars 2 공식 Dynamic Events](https://www.guildwars2.com/en/the-game/dynamic-events/), 2026-11-04 재열람. 인원 증가에 따른 도전 강화와 개인별 보상을 설명한다. 이는 기존 파티 배율과 개인 보상을 유지하는 판단의 참고이며 종족별HP 수치를 제공하지 않는다. 게시/갱신일·플레이 버전 미표시, 직접 플레이 아님.
- Roblox 비교: 기존 조사에서 인용한 [The Mystic Land 2 RPG 업데이트](https://devforum.roblox.com/t/the-mystic-land-2-rpg-update-log/3485419)를 재열람했으나 봇 확인 화면으로 본문을 확인하지 못했다. 과거 조사상의 인원별HP 증가 설명을 최신 확인 사실로 사용하지 않는다. 인기 지표/현재 수치도 미검증이다.

대안은1.5배의 완만한 상향 또는 HP와 공격력을 함께 올리는 방식이다. 사용자의 명시적인 생존력 개선 요구에 맞춰 체감 차이가 큰2배를 우선 적용한다. 코드 비용은 낮지만 처치 시간이 길어지고 시간당 보상 효율이 낮아질 수 있다. PC/터치/패드의 입력 계약과1~4인 파티 배율은 유지한다. QA는 동일 레벨/장비로 변경 전후 오크·오우거의 처치 시간·공격 패턴 노출 횟수·피격/회복 소모를 솔로/4인에서 비교한다. 수치 반영 검증과 실제 재미/실기기 수용은 구분한다. 다음 담당 QA의 실전 비교와 사용자 수용 전에는 최종 밸런스로 확정하지 않는다.
