# WoW 주문 정체성과 현재 VFX 비교

TLT-033/057 · 확인일2026-11-12 · 비교 대상은 **World of Warcraft: Legion 7.3(2017)**이다. 현행 Retail/Classic 외형이나 성능을 전수 조사한 기록이 아니다. 기존 [Diablo 우선 전투 VFX 조사](2026-11-12-combat-vfx-game-references.md)의 타격/범위 가독성 기준을 유지하고, 이번 사용자 요청에 따라 WoW를 중심으로 계열 식별을 개선한다.

## 확인한 공식 근거

- Blizzard, [Patch 7.3 New Combat Animations: It’s Magic!](https://worldofwarcraft.blizzard.com/en-us/news/20946579/patch-73-new-combat-animations-its-magic), 2017-08-16. 검색 도구는403이었으나 브라우저에서 공식 본문·작성자·게시일을 직접 확인했다. Lead Class Designer Adam Kugler는 입력에 대한 반응과 타이밍 일관성을, FX Artist Sarah Carmody는 직업/전문화별 정체성과 성능의 균형을 설명한다. 같은 냉기라도 마법사/주술사/죽음의 기사의 표현 의도를 구별한다. Arcane Missiles의 기존 발사 묶음 구조를 보존하면서 외형을 재해석한 사례를 설명한다.
- [공식7.3 패치 노트](https://news.blizzard.com/en-us/article/20947822/world-of-warcraft-7-3-patch-notes)의 Combat Animations에서 마법사·사제·주술사 등의 애니메이션/효과 업데이트 범위를 확인했다.
- 공식 글에 연결된 [Blizzard 예시 영상](https://www.youtube.com/watch?v=fSEGGgvN_8U), [Arcane Missiles 예시 영상](https://www.youtube.com/watch?v=i2nFMCg_GDg)은 후속 시각 비교용 링크다. 이번에 전체 영상을 재생하거나 시간/색/입자 수를 측정하지 않았다. 직접 플레이했다고 주장하지 않는다.

이 자료에서 **확인한 사실**은 직업별 시각 언어·반응성·원형 보존·성능 고려라는 제작 방향이다. 아래 인장/결정의 구체적인 형태는 우리 게임의 해석이며 WoW 원본 주문을 복제한 것이 아니다. WoW 모델·텍스처·음향은 가져오지 않았다. 현행 Essential 주문 밀도 설정의 동작은 검증하지 않았으므로 근거로 쓰지 않는다.

## 현재 소스와 비교해 적용한 개선

| 대상 | 0.104.19 관찰 | 개선·가설 | 보존한 의미 |
| --- | --- | --- | --- |
| Dawn Burst / Dawn Spiral / Oath of Dawn | `holy` 형상이3~4개 겹친 고리와 채운 원반을 사용한다. 물 계열과 같은 `ElementalSurface` 분기다 | 원반을 제거하고 바깥 고리1개, 분리된 햇살 인장6개, 상승 광선6개로 교체. 성기사의 빛을 빈 중앙과 방사형 형태로 식별 | 서버 피해/반경/펄스/재사용 시간, 기본 `SkillSector` 범위선 유지 |
| Arcane Ward | 비전 궤도3개와 전사와 같은 전방 오각 방패 면을 사용한다 | 비전 궤도2개와 시전자 주위6방향의 열린 마름모 면. 전사의 방패/돌진 방향 표시와 구별 | 기존3초 `PersonalWard` 지속 표시와 서버 보호막 수치 유지. 새 결정은 발동 장식이며 보호막 잔여량 표시가 아님 |
| 전사 Guard / 냉기 / 폭탄 / Selene Heal | 기존 승인 방향과 개별 정리 증거가 있다 | 이번에는 유지하고 회귀 확인 | 물리/원소/지원의 기존 판독과 자산 권리 조건 |

성기사/비전 계열을 **색뿐 아니라 형상으로 구별**하고, 일반 공격에 궁극기급 광량을 더하지 않는 것이 최소 실험이다. 비용은 원반1개를 분리된 면/광선으로 교체하는 생성 수 증가와 고리 Beam 감소가 함께 있다. GPU 성능 향상으로 단정하지 않는다. 전역 장식 예산·거리 컬링·만료 해제는 기존 경로를 사용한다.
