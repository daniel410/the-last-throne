# 수정 왕좌 로비: 거점 기능과 서사 상태 비교

2026-11-11 확인 · TLT-001/028/031/050/052/057/084 · DES/ENG → QA

질문: 로비에서 사라진 유물과 귀환의 성취를 보여 주면서 기존 상점·창고·출발 사용을 어렵게 만들지 않는가? 대상은 10~15세, PC/터치/패드·공용20인 로비다. 아래는 공식 문서 관찰이며 직접 플레이/사용자 지표가 아니다.

- **Diablo IV Season of Blood / 1.2.0 당시 설계:** [Blizzard 개발자 업데이트](https://news.blizzard.com/en-us/article/24009151/descend-into-the-diablo-iv-developer-update-livestream)의 Town Adjustments는 주요 상인 가까이 창고 추가, 웨이포인트 주변 서비스 이동을 설명한다. 현재 모든 시즌 배치가 같다는 주장은 하지 않는다. 적용 원리: 서사 랜드마크 때문에 준비 동선을 늘리지 않는다. 기존 창고/상점/출발 좌표를 유지하고 성소를 북쪽 공간에 추가한다. Diablo의 어두운 미술·경제·도시 규모는 복제하지 않는다.
- **Roblox 엔진:** [공식 스트리밍 기법](https://create.roblox.com/docs/workspace/streaming/techniques)은 모두 필요한 부품을 가진 모델의 논리적 묶음에 Atomic을 권장한다. [공식 모델 문서](https://create.roblox.com/docs/parts/models)는 Atomic 모델의 일괄 유입/이탈을 설명한다. 적용: 왕좌를 Atomic으로 묶고 서버 진행 스냅숏을 보관해 모델 유입 때 개인 심장을 복원한다. 엔진 문서는 특정 RPG 성공/인기 근거가 아니며 그런 인과를 주장하지 않는다.
- **TLT 기존 구현/승인 컨셉:** 왕좌는 완료 때만 남쪽에 생성됐고 기본 북쪽 포치는 비어 있었다. 왕좌를 북쪽 상시 랜드마크로 만들면 빈 받침→복원 받침을 같은 자리에서 비교할 수 있다는 설계 가설이다. 기존 TD 공통 메뉴와 초상/아이콘은 유지한다.

대안은 공용 심장 일괄 복원 또는 개인별 복원이다. 같은 서버에 미완료/완료 영웅이 있으므로 개인별 표시를 채택한다. 신규 저장키/재화/보상을 추가하지 않고 기존 HG07 완료만 읽는다. 비용은 네이티브 성소·성벽 장식과 클라이언트 소규모 개인 장면이며, 실제 FPS·가독성은 아직 미측정이다.

최소 실험: 동일 로비에서 미완료/완료 영웅 교체, 스냅숏 선도착/왕좌 재유입, 스폰에서 성소와 모든 기존 시설로 걷기. 엔진 경로에 차단/바닥 누락이 없어야 하며 완료자의 심장이 미완료자로 넘어가면 실패다. 이후 QA는 스폰에서 왕좌 발견 여부, 도난/복원 상태 설명 가능 여부, 기존 준비 동선의 혼동과 기기별 읽기/FPS를 관찰한다. 시간/성공률 수치는 사용자 시험 전 확정하지 않는다.
