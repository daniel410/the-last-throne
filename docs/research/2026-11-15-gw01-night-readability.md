# TLT-065 / GW-01 밤 조사 흔적 판독

2026-11-15 확인. 맵 구현·환경 아트·환경3D·리서치 순차 수행. 기존 GW-01 개선의 후속이며 티켓/G5 완료 판정이 아니다.

- [Diablo IV Quarterly Update, March 2022](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022): 본문 확인. 게임 카메라에서 디테일을 가감해 플레이 공간 가독성과 서사를 지원한다는 개발 원리를 참고했다. 출시 전 환경 아트 설명이며 현행 패치/인기 지표의 근거가 아니다.
- [WoW Retail Dragonflight Deep Dive, April 2022](https://news.blizzard.com/en-us/article/23785116/world-of-warcraft-dragonflight-deep-dive): 이번에는 본문 확인. Azure Span의 숲→툰드라→눈 지형과 주민/지역 서사 연결을 설명한다. TLT에서는 광대한 지형을 복제하지 않고 지면의 물성 차이로 이동 흔적을 구분하는 해석만 채택한다.
- [Roblox Materials](https://create.roblox.com/docs/parts/materials): 재질은 외관뿐 아니라 물리 특성에도 관여한다. 이번 대상은 anchored·비충돌·비쿼리·비터치 흔적이며 플레이 바닥 재질은 바꾸지 않는다.

## 관찰과 선택

기존 GW-01 exp_1의 밤 조명/게임 범위 카메라 재현에서 바퀴는 보이지만 작은 발자국은 어두운 바닥에 묻혔다. 단순 Ground 색상 변경 후보는 효과가 작았다. 안내판 독서등 후보도 현재 Studio 화면에서 유의미한 개선을 확인하지 못해 제외했다. 원인은 확정하지 않았으며 빌드에 넣지 않았다.

발자국20파트만 밝은 압착 토양(Sand/RGB181·165·131)으로 표현하고 바퀴14파트는 기존 어두운 Ground를 유지했다. 가벼운 정찰대 흔적과 무거운 화물 흔적의 갈림을 구분하는 가설이다. 새 사건·조사 단계·목표·등불은 추가하지 않는다. 원본/메시·형태·파트 수·조명 비용 증가0. 기존 기본형 파생이며 TD 원본·Blender 변경 없음.

수용 실험은 같은 월드에서 발자국 색/재질만 토글해 같은 카메라/밤 프로필로 비교하고 접지·물리·기존/Easy 동선을 검사한다. 전투 중 판독률·모바일 화면·사용자 선호는 아직 측정하지 않았다. 압착 흙의 최종 질감/자연스러움은 후속 미술 수용 대상이다. 다른 RPG/Roblox 게임의 플레이를 직접 관찰한 것으로 보고하지 않는다.
