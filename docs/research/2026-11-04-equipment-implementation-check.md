# 장비 구현 계획 근거 재확인

2026-11-04 · TLT-028/029/041/043/044/045/052/073/082/084 · RESEARCH → PLAN/ENG/QA

이번 질문은 생성된 Rare/Epic/Legendary120종을 기존 장비·강화·보스 보상에 어떤 순서로 연결할지다. [기존 RPG 장비 조사](2026-11-04-hero-gear-levels-sets.md)와 [보스 보상 재리뷰](2026-11-04-boss-loot-independent-review.md)를 재사용하며, 아래 공식 자료를 2026-11-04 다시 열람했다. 비교 목적이며 인기 순위·실제 플레이·시장 성과를 측정한 조사가 아니다.

| 출처 | 확인한 사실 | 프로젝트 적용 판단 |
| --- | --- | --- |
| [Roblox Data stores](https://create.roblox.com/docs/cloud-services/data-stores) | 서버에서 영속 데이터를 다루며 네트워크 호출은 실패할 수 있다. UpdateAsync는 현재 키를 읽어 갱신하고 콜백은 yield할 수 없다. | 보상 결과·아이템·영수증을 같은 계정 키의 일관된 갱신으로 처리한다. 여러 키에 걸친 보스 기록/계정 지급은 복구 저널을 별도 설계한다. 콜백 안에서 재추첨하거나 외부 작업을 하지 않는다. |
| [Grim Dawn 공식 아이템 가이드](https://www.grimdawn.com/guide/items/the-hunt-for-loot/) | 세트는 테마·기능의 상승효과를 제공한다. 세트 아이템의 개별 속성은 비세트보다 낮춰 그 상승효과를 보상한다. | 개별 능력치·세트·강화·고유 효과를 하나의 예산으로 검증한다. 레전더리 외형만 완성됐다는 이유로 새 효과를 추가하지 않는다. |

권고는 기존 저장 경로와 카탈로그를 확장하고 Deepwood 단일 보스에서 소규모 수직 구현을 먼저 검증하는 것이다. 별도 신규 인벤토리 시스템은 이중 소유권·이관 비용이 크다. 120개를 즉시 라이브 드롭에 넣는 대안은 미정 레벨/수치/빈 등급 풀과 내구성 복구를 한 번에 노출하므로 채택하지 않는다. 120이미지의 실제 크기 UI 검수는 데이터 설계와 독립적으로 병행할 수 있다.

최소 실험은 네 클래스 무기·공통 MP 장신구·기사 방패·5부위 세트의 장착/교체/강화 비교와 단일 보스의 저장 장애 복구다. 동일 레벨/부위/강화에서 Rare→Epic→Legendary 기본 예산 순서, 마나 없는 클래스의 MP0 유지, 슬롯 교체의 현재MP 비충전, 동일 처치 중복 지급0을 검사한다. 처치시간·사망·재료 순소비·목표 아이템 획득 분위수는 네 난이도·1~4인/AI 조건으로 후속 측정한다. 외부 자료가 본 게임의9.375%·드롭률·천장 값을 검증하는 것은 아니다. [구현 계획](../production/equipment-implementation-plan-2026-11-04.md)에서 단계와 수용 조건을 정한다.
