# 상위 난이도 레벨 제한 제거 비교

2026-11-11 확인 · TLT-027/028/050/084 · ENG/리서치 역할 → QA. 사용자 승인 범위는 Hard/Insane/Hell 레벨 제한 제거다.

- **Diablo IV 2.0 / Season of Hatred Rising 당시 공식 설명**: Normal/Hard 기본 개방, Expert 프롤로그 완료, Penitent 캠페인 완료/건너뛰기로 개방한다. 레벨과 콘텐츠 완료 조건을 분리하는 비교 사례다. 이는 2024년 해당 시즌 계약이며 현재 라이브 규칙으로 일반화하지 않는다. [Blizzard 원문](https://news.blizzard.com/en-us/article/24140803/conquer-colossal-foes-in-season-of-hatred-rising).
- **Roblox Dungeon Quest** 공식 소개: 친구와 던전·보스를 공략하고 직업·장비를 성장시키는 협동 RPG다. 파티원별 입장 자격과 안내를 검증할 비교 맥락으로만 사용한다. 소개 페이지는 세부 난이도 레벨 규칙을 설명하지 않아 이를 추정하지 않는다. [Roblox 원문](https://www.roblox.com/games/2414851778/Dungeon-Quest-RPG-Adventure).

적용 해석: 레벨 대신 기존 이야기/이전 난이도 완료 조건을 남기면 사용자 요청과 순차 도전을 함께 반영할 수 있다. 타 게임의 보상·해금 수치·자산을 도입하지 않는다. Easy의 기존 하한도 유지한다. 대안인 전체 선행 조건 해제는 이번 요청 범위 밖이다.

비용은 공통 입장 함수와 버튼 표시의 소규모 변경이다. 낮은 레벨의 전투 위험·성장 속도 변화는 후속 플레이 수용 대상으로 두고 적/보상 수치를 자동 조정하지 않는다. 최소 실험은 Lv1 영웅의 전 전투 임무 자격, 버전1~14 입장/재접속, 혼합 레벨 4인 파티와 이전 클리어/스토리 거부 조건이다. 순수 Lua 결과는 작업 증거에 기록하며 실제 기기/클라이언트는 QA 후속이다.
