# 로스트아크 비교 후 VFX 격차 수정

TLT-033/057/059 · 2026-11-16 · ART/ENG. 사용자의 “그 격차 개선”, “로스트아크 VFX 리뷰·비교 후 개선점 수정” 요청을 적용한다.

[전날 상용 RPG 직접 시연 비교](2026-11-15-rpg-vfx-quality-comparison.md)와 [독립 ART의 구체적인 문제](../evidence/roblox-vfx-polish-20261115/art-review.md)를 제작 입력으로 재사용한다. 이번에 같은 외부 영상을 새로 직접 플레이했다고 주장하지 않는다. Diablo IV의 전투 가독성/강도 위계, WoW Retail7.3의 직업·주문 정체성 보존을 유지하며 로스트아크를 상시 비교 기준으로 적용한다.

핵심 원천은 공식 [Berserker Whirlwind 약0:04/0:09](https://www.youtube.com/watch?v=0EO4YTZJl8A&t=4s)의 밝은 주날·다른 폭/불투명도의 잔상과 [Sorceress Incinerate 약0:05/0:17](https://www.youtube.com/watch?v=ef4qjxx7ZE4&t=17s)의 유색 불꽃·어두운 덩어리·지면 반응이다. 전체 게임/현행 라이브 버전의 수치나 성능을 비교한 자료는 아니다. 원본 문양·이미지·스크립트는 복제하지 않는다.

[Roblox Beam 문서](https://create.roblox.com/docs/effects/beams)를 이번 작업에서 재확인했다. 폭·곡률·텍스처를 독립적으로 다룰 수 있으므로, 선명한 날과 부드러운 잔상을 기존 Beam 두 층에 분리했다. 품질별 외형/실기기 수용은 따로 확인해야 한다. 사용한 gradient와 fire atlas는 이미 승인된 [Yuruzuu/ParticleFX 입력](../../assets/effects/curated-vfx-v1/README.md)이다. 신규 다운로드/설치/업로드나 외부 게임 자산 복제는 없다.

최소 실험은12대표×낮/밤 전후, 적 IceElf 야간, Oathbound의3펄스와 영웅128종/199펄스·적50종146공격/40투사체·지원3종의 엔진 회귀다. 실제 동일 빌드를 별도 Studio 문서에서 다시 검사한다. ART는 중간 회귀 지적과 최종 개선/잔여를 분리한다. [구현·화면·독립 ART·빌드 검증](../evidence/rpg-vfx-gap-20261116/README.md).

기존 제품 결정·서버 권위·원소 팔레트·TD 원본을 유지한다. 외부 시연의 광량·입자량·지속 시간을 그대로 가져오지 않는다. 다음 담당은 ART/QA의 실제 캐릭터/지역·연속 교전·4인/AI·그래픽 품질 양끝·저사양 실기기와 사용자 미술 수용이다. 이번 로컬 수정은 상용 RPG와 동급이라는 인증이 아니다.
