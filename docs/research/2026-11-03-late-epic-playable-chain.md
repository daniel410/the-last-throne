# 후반 두 에픽의 플레이 가능한 이야기 연결

2026-11-03 · TLT-064/065/057/084 · 리서치/ENG 적용 기록

질문: 승인5에픽을 솔로/1~4인·선택 Selene에서 이해하기 쉬운 목표와 재개 가능한 구간으로 어떻게 연결하는가? 직접 플레이나 인기 순위를 조사했다고 주장하지 않는다.

## 확인한 사례와 근거

- [Roblox 퀘스트 설계](https://create.roblox.com/docs/production/game-design/introduction-to-quest-design), 2026-11-03 열람. 목표·수량·보상으로 퀘스트 구조를 설명하며 World // Zero의 퀘스트 화면, Jailbreak의 성취 보상 사례를 제시한다. 복잡한 행동을 개별 목표로 나누는 방식이 본 작업에 맞는다. 공개 문서/화면 설명만 확인했으며 실제 게임 조작·유지율·인기와 기능의 인과관계는 미검증이다.
- [Roblox 서버 경계](https://create.roblox.com/docs/scripting/security/client-server-boundary), 같은 날 열람. ProximityPrompt도 서버 검증이 필요하며 거리·생존·권한 확인을 요구한다. 기존 DeepwoodService의 서버 위치/영웅/이전 목표 검사와 저장 큐를 재사용한다.
- [Guild Wars 2 Story Journal](https://wiki.guildwars2.com/wiki/Story_Journal)은 비교 후보였으나 본문403으로 열람하지 못했다. 이 자료에 근거한 상세 기능 채택은 하지 않는다.

## 적용 판단

구출→친구와 협력→보스→회복 결과의 짧은 연쇄를 채택했다. Gloamwood7개는 정찰대/개인 Tali 호위/엔트·지네·여왕으로, HG7개는 동맹/친근한 유령/성문/왕좌 장치/최종전/회수·포탈 폐쇄로 잇는다. 동시 발판/특정 클래스/유료 동행을 필수로 요구하지 않는다. 여러 NPC가 다른 지역에 등장할 때 지역별 역할 인스턴스를 구분한다.

대안인 하나의 긴 전투 임무는 저장·목표 이해/휴식 지점이 불명확해 채택하지 않았다. 기존 목표·서브스텝 저장을 사용하면 새 저장 서비스 비용 없이 복구 가능하나 정상 입력/실계정 저장/실기기/4인+AI 검증은 필요하다. Gloamwood 임시 모델은 사용자 최신 지시로 채택했고 안정된 EnemyKind를 후속 모델 교체 경계로 삼는다. 신규 고정 보상 예산0은 승인 전 임시값으로 명시하며 기존 HG 승인 예산을 재계산하지 않는다.

최소 시험: 기존21개 완료 저장→GW7→HG7, 각 단계 중복 호출/중단 복사/재개, Veyr70%보호 장치/35%경고와 유한 증원, 동일 클리어 보상 중복 배제, 실제 지형/모델/지도 표시. 정적 통과를 정상 전투 완주·사용자 이해도 통과로 올리지 않는다. 다음 담당은 QA/DES의 실제 입력·목표 이해/솔로 밸런스 수용과 ART의 Gloamwood 모델 교체다.
