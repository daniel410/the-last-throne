# 다섯 에픽 길목의 재질 대비

2026-11-19 UTC · TLT-061 / TLT-065(GW) / TLT-062 / TLT-063 / TLT-064 · G5

[0.113.19 Studio 비교](../evidence/epic-route-perspectives-20261119/README.md)에서 GW-05 양면 긁힘의 정면 대비 저하, FV-03 윗살과 FV-04 도관 체결부의 원거리 판독 한계, HG-03 배수구와 귀환 동선의 큰 각도를 확인했다.

- Diablo IV 팀은 Scosglen의 바람 방향을 초목 형태에, Dry Steppes의 지표 대비를 카메라 높이에서 보이는 층에 반영했다. GW-05에선 긁힘의 방향을 보존하고 노출된 밝은 지층의 폭과 재질을 조정했다. [Blizzard 환경 제작](https://news.blizzard.com/en-us/article/23788294/diablo-iv-quarterly-updatemarch-2022)
- World of Warcraft의 The Ringing Deeps는 노후 산업 시설과 주민의 작업을 지역 이야기로 엮는다. DW-05에는 재사용 석조 위 현장에서 자른 목재를, EC-05에는 공급·회수 설비를 구분하는 체결부를 표현했다. [Blizzard 지역 소개](https://worldofwarcraft.blizzard.com/en-us/news/24125258/explore-the-zones-and-dungeons-of-the-war-within)
- Lost Ark의 Voldis는 Sage’s Tower와 지역 건축에 주민의 기술과 역사를 드러낸다. Frozen Vale에는 악천후 대응 설비와 피난 신호 설비가 각각 목재 윗살과 금속 띠로 구분되도록 반영했다. [Voldis 제작 인터뷰](https://www.playlostark.com/en-us/news/articles/creating-voldis)
- Roblox 환경 블록아웃 지침의 주요 시야 점검을 따라 같은 조명과 카메라에서 이전 빌드와 후보를 비교한다. [Roblox Creator Hub](https://create.roblox.com/docs/tutorials/curriculums/environmental-art/greybox-your-environment)

| 장 | 서사와 제작 | 확인 장면 |

| GW-05 | 밧줄을 조사하는 곳의 긁힌 흙 단면을 양쪽 경사에서 넓히고 밝은 모래질로 표현한다. | 밤의 정면과 측면 |
| FV-03 | 서쪽 신호기에 접근할 때 눈이 벗겨진 방풍 울타리 윗살의 어두운 띠를 넓힌다. | 가까운 끝단과 굽이에서의 실루엣 |
| FV-04 | 동쪽 피난 신호 도관의 노출 금속 띠를 넓고 어둡게 표현한다. | 가까운 체결부와 진행 방향에서의 몸체 |

| HG-03 | 묘역 관리 배수구의 전면 석조 아치를 밝히고 후면 물끊기 돌을 낮춰 닫힌 수로의 위계를 보인다. | 전면 아치와 귀환 방향의 후면 물구멍 |
