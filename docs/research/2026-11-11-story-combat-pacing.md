# 스토리 길목 전투 공백 보강

2026-11-11 · TLT-061~065/084 · RES → PLAN/ENG/QA

사용자는 [47장 검사](../evidence/story-combat-audit-20261111/README.md)에서 확인한 전투 부족을 수정하도록 지시했다. 기존 [경로 교전 조사](2026-11-10-monster-respawn-and-route-encounters.md)를 재사용하고 관련 공식 근거를 다시 열람했다. 이번 적용은 새 던전이나 거점 전투가 아닌 현재 주동선의 유한 길목 전투13개다.

## 근거·해석·적용

- **관찰:** [Blizzard의 Diablo IV 베타 회고](https://news.blizzard.com/en-us/article/23938289/diablo-iv-open-beta-retrospective-transforming-feedback-into-change)는 2023년 출시 전 던전 설계 사례다. 목표를 주동선에 배치해 왕복을 줄이고 구조물 목표에 전투 기제를 추가했다고 설명한다. 2026년 현행 시즌의 밀도·보상 수치로 해석하지 않는다. 확인일2026-11-11, 공식 문서 열람이며 직접 플레이하지 않았다.
- **보완:** [Dungeon Quest 공식 소개](https://www.roblox.com/games/2414851778/Dungeon-Quest-RPG-Adventure)는 동료와 던전을 싸워 통과하고 보스를 만나는 흐름을 소개한다. Roblox 협동 전투를 비교하는 참고이며 인기·적 수·목표 사이 시간·효과의 인과관계는 이 자료로 확인할 수 없다. 확인일2026-11-11.
- **TLT 차이:** 구조/대화/개인 저장이 있는35장 캠페인이다. 거점까지 일괄 전투로 채우거나 같은 장소에서 반복 생성하면 현재 계약과 충돌한다. 단순 적 체력 증가도 공백 이동을 해결하지 못한다.
- **채택:** GW/HG의 기존 전투 장12개와 EC-05에 일반 적3원본(솔로18/4인36)의 길목 목표를 추가한다. GW-01/02와 EC-05는 조사와 마지막 이동 사이에 끼워 전투가 초반에만 몰리지 않도록 한다. 현재 접근 기반 활성화·서버 권위·최대 동시 무리·보스1회를 사용한다. 기존 사건/선택/완료 보상과 적 수는 줄이지 않는다. 새 적은 기존 일반 처치 보상을 받으며 XP/Gold의 총 유입은 증가한다.
- **호환:** 진행 중13/14원정에도 새 저널 투영을 적용하되, 추가 전투 뒤의 목표를 이미 완료했거나 일부 진행했다면 새 전투를 면제해 역주행/부분 저장 손실을 막는다. 구형1~12의 진행 규칙을 자동 바꾸지 않는다. 재플레이는 해당 원정에서 새로 싸운다.

## 비용·위험·실험

기존 적/승인 미술을 재사용하며 새 자산 업로드는 없다. 목표·경로39최대지점과 저장 이관/지도 갱신 비용이 생긴다. 총234마리의 솔로 적 추가는 처치 XP/Gold·물약 소모·완료 시간을 늘린다. 그 비용을 숨기기 위해 승인 완료 XP나 기존 적 보상을 낮추지 않는다. 낮은 동시 상한과 접근 전 생성0은 유지하지만 실제 기기 성능을 정적 검사로 보장하지 않는다.

최소 검증은 GW-01 정상 전투→조사→새 전투→이동→등불, EC-05 회로/안전 재시도, HG-07 마지막 보스 전 접근, 기존 부분 저장/확정 처치/중복 사건/재플레이를 포함한다. 실제 사용자 수용은 PC/터치/패드·솔로/4인+AI에서 빈 이동 시간·길찾기 정지·물약/사망·다음 목표 이해·프레임을 비교한다. 재미 수용이나 계정/실기기 검증은 이번 구현으로 완료 처리하지 않는다. [실행 증거](../evidence/story-combat-pacing-20261111/README.md).
