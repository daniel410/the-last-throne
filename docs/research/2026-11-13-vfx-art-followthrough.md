# 전체 VFX 아트 리뷰의 우선·후속 적용 근거

TLT-033/054/055/056/057/084 · 2026-11-13 · 사용자 지시: 리뷰의 우선·후속 항목 모두 개선. 정본은 [ART3인 리뷰](../evidence/vfx-art-review-20261113/README.md)와 [원소 계약](../production/element-vfx.md)이다.

기존 [Roblox RPG 비교](2026-11-13-roblox-rpg-vfx.md)와 [원소 동작 후속](2026-11-13-roblox-element-motion.md)을 같은 날 재사용한다. 이번에는 확인된 팔레트 불일치 수정과 승인된 미술 개선 범위를 구현한다. 새 피해/속성·클래스·성장 규칙은 제안하지 않는다.

- [Diablo IV VFX 개발 설명](https://news.blizzard.com/en-us/article/23746639/diablo-iv-quarterly-updatedecember-2021), 2021-12 개발 중 자료를2026-11-13 다시 열어 전투 가독성·주/보조 읽기와 강한 기술의 시각 위계를 확인했다. 이를 일반 명중의 넓은 흰 강조를 줄이고 궁극기별 주 형상에 집중하는 원리로 적용한다. 현행 시즌 수치나 서버 판정을 가져오지 않는다.
- [WoW Retail Legion7.3 전투 효과 설명](https://worldofwarcraft.blizzard.com/en-us/news/20946579/patch-73-new-combat-animations-its-magic), 2017-08-16의 직업/전문화 정체성은 [기존 조사](2026-11-12-wow-vfx.md)를 재사용한다. 이번 본문 재열람은403으로 제한됐다. 원소별 준비→시전→명중의 색과 각 직업의 형상을 이어 주며 Classic/현행 Retail 수치와 혼합하지 않는다.
- [Roblox 공식 RPG 소개](https://www.roblox.com/spotlight/roleplaying-games)를 재열람했다. World // Zero/Dungeon Heroes/Deepwoken을 인기 사례로 소개하지만 실시간 순위를 확정하지 않는다. Blox Fruits/World // Zero의 구체적인 그림 관찰은 위 기존 조사에 연결하고, 이번에 전체 영상을 추가 분석했다고 주장하지 않는다.

채택: 원소 표시 팔레트 공통화, 전방 장식의 실제 방향 정렬, 비색상 예고, 산탄/포탄/뿌리/증기/용암의 주 단서 분리,8궁극기와 보스의 시각 초점, 원소별 접촉/치유/정화 구별. 새로운 외부 텍스처/모델 업로드 대신 현재 원본과 절차적 기하·내장 입자로 구현한다.

비용/위험: 시각 차별화를 위해 단순히 면/입자를 누적하면 다인 오버드로와 정보 가림이 늘어난다. 기존 장식을 교체하고 짧게 소멸시키며 기존 전역·터치 예산, 거리 컬링, 취소/만료 정리를 유지한다. 고리의 안전 중심과 서버 예고 경계는 바꾸지 않는다.

최소 검증은 모든128스킬의 표시 연결/원소 명중, 기존 몬스터146공격·표시 예산/고리 안전 영역, 지원3종, 준비→시전→명중 전후,8궁극기 첫/후속 펄스, 밝고 어두운 조명 및 다중효과 합성의 로컬 관찰이다. 실제 게시 클라이언트·PC/터치/패드·1~4인+AI·GPU/실기기·최종 사용자 수용은 로컬 검사를 대신해 완료 처리하지 않는다. [적용/검증 기록](../evidence/vfx-art-improvements-20261113/README.md).
