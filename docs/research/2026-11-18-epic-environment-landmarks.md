## 모델·검증 인계

환경 3D는 기존 모델 식별자와 TD 원본부터 확인하고, 사건을 읽히는 대표 실루엣 한 곳부터 현행 에셋의 파생 또는 기본형으로 비교한다. 기존 소품 존재 이유와 중복되는 장식을 줄이고, 재질은 TD 팔레트의 명도와 형태 대비를 먼저 사용한다. 모델 원본을 편집하거나 렌더할 때 Blender Standard / sRGB / Look None / Exposure 0 / Gamma 1 / Curves Off를 사용한다. 모든 후보에 새 LOD 또는 라이트를 추가하기 전에 기존 인스턴스 수·그림자·스트리밍 비용을 재측정한다. 전체 구역 재절개는 도보 경사·안전 생성·로딩을 함께 바꾸는 비용이 있어 지역 시안 수용 뒤 재검토한다.
