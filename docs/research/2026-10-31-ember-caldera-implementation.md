# Ember Caldera 제작 조사·적용

2026-10-31 · TLT-063/057/084 · 공식 설명/문서 열람, 직접 타 게임 플레이와 구분

질문: 광부 구조와 기계 수리를 솔로로 이해하고 수행할 수 있는가? 큰 보스의 공격 예고와 단계별 유한 증원을 전투 거리에서 읽을 수 있는가?

- [GW2 Champions 공식 소개](https://www.guildwars2.com/en/news/the-icebrood-saga-champions/)를 다시 확인했다. 솔로/파티로 지역을 보호하고 큰 적에 대응하는 구조를 명시한다. 원문은2020년 소개이며 현재 전투 수치·이용 지표의 근거로 사용하지 않는다. 구조/장치 복구와 보스의 순서를 적용하고 인간4명/AI현재1명 계약을 유지한다.
- 앞선 [Frozen Vale 조사](2026-10-31-frozen-vale-implementation.md)의 Dungeon Quest 협동 던전 비교를 재사용한다. 인기 순위·체류 시간·수익 개선을 추정하지 않는다. 우리 변경은 마지막 보스까지의 목표와 보상을 명료하게 연결하는 가설이다.
- [Roblox Motor6D 공식 문서](https://create.roblox.com/docs/reference/engine/classes/Motor6D)를 확인했다. 표시 관절과 서버 판정 분리를 유지하고 기존 PreSimulation 파이프라인에 새 Blender 표본을 연결한다. 새 네트워크 피해 권한이나 외부 애니메이션 업로드는 추가하지 않는다.

채택: 승강기는 수리 저장이 확정된 뒤 준비된 도시 안전 체크포인트로 이동한다. 도보 연결길도 남기며 물리 승강기 탑승 실패가 필수 열쇠가 되지 않도록 한다. 밸브는 순차 조작이며 특정 클래스·동시 발판을 요구하지 않는다. 광부는 개인 호위로 걷고, 떨어지거나 적이 가까우면 멈추는 기존 서버 계약을 적용한다.

보스 단계는65%/30%에서 유한 증원을 예약한다. 주황색 지면 예고는 기존 서버 지면 위험 계약을 사용한다. 준비/타격/회수를 Blender에서 제작하고 슬라임 압축·벌레 몸 기울임·주술사 시전·큰 적의 양팔 강타를 구분한다. 고비용 전신 스키닝 대신 기존 강체 분할을 사용한 시험 제작이며 손목/팔꿈치·경사 IK/실기기 성능 수용은 별도다.

검증 가설: 기존 개인 저장의 재개, 순차 장치와 광부 호위 완료, 보스 단계/유한 증원/중복 보상 배제,10종 실제 관절/표본과 지도·저널/영어 표기를 확인한다. 정상 난이도/Lv30 성장·4인+AI 성능은 자동 통과하지 않는다. [검증 기록](../evidence/ember-caldera-0510/README.md)과 다음 QA/DES 수용을 연결한다.
