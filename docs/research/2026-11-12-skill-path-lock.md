# 전직 후 다른 계열의 잠금 가독성

2026-11-12 확인 · TLT-052 · RESEARCH/DES → ENG/QA

질문: 첫 전직으로 배제된 계열과 아직 레벨이 부족한 기술을 어떻게 구분할 것인가. PC·터치·패드 공통으로 색과 영어 상태 문구를 함께 제공한다.

관찰: [Diablo II 공식 Arreat Summit 기술 안내](https://classic.battle.net/diablo2exp/skills/basics.shtml)는 사용할 수 없는 기술 아이콘의 색상과 사유, 기술 트리의 레벨·선행 자격을 설명한다. 원작/LoD 안내이며 현행 D2R 패치나 직접 플레이 검증으로 간주하지 않는다. D2의 기술 탭은 우리 게임의 영구 전직 분기와 다르므로 탭 간 배타성은 차용하지 않는다. 적용 원리는 사용 가능 여부를 아이콘과 사유에 함께 표시하는 것이다.

보완: [Roblox 공식 접근성 지침](https://create.roblox.com/docs/production/publishing/accessibility)의 Color non-reliance는 색만으로 상태를 전달하지 않고 다른 기호를 함께 쓰도록 안내한다. 플랫폼 가이드 비교이며 특정 인기 게임의 성과 근거가 아니다.

채택: 다른 계열의 탭·기술·연결선을 회색으로 처리하고 LOCKED · PREVIEW / PATH LOCKED, 선택 계열에 따른 학습 불가 사유를 표시한다. 기술 미리보기와 공통 기술 사용은 보존한다. 대안인 탭 완전 비활성화는 다른 계열의 설명 비교를 막으므로 보류한다. 서버 계약·전직 조건·밸런스 변경은 없다. 비용/위험은 화면 표시 변경과 긴 영문 줄바꿈이며, 8계열×4단계×3화면 크기에서 글자 적합·공통 기술 유지·다른 계열 강화/편성/전직 차단을 확인한다. 직접 플레이·실기기와 사용자 이해도는 미검증이다. 결과와 다음 담당은 [작업 증거](../evidence/skill-path-lock-20261112/README.md)를 따른다.
