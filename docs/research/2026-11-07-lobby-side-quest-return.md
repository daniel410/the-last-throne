# 에픽 귀환 후 사이드 의뢰 안내·보고 조사

2026-11-07 · TLT-028/031/041/050/052/057/061~065/084 · 확인일2026-11-07

질문: 본편 에픽을 끝낸 플레이어가 남은 선택 활동을 쉽게 찾고 결과 보상을 받을 수 있는가? 대상은10~15세·PC/터치/패드·솔로~4인이다. 공식 문서 열람이며 직접 플레이 수용이나 유지율 근거는 아니다.

| 근거/버전 | 확인한 사실 | 적용 해석 |
| --- | --- | --- |
| [Diablo IV Quarterly Update—June 2020](https://news.blizzard.com/en-us/article/23463858/diablo-iv-quarterly-updatejune-2020), 출시 전 팀 테스트 | 본편 집중 플레이와 도중 선택 활동을 구분하며 지역 본편 이후에도 사이드 콘텐츠를 할 수 있었다고 설명한다. | 본편 완주 후 미완료 의뢰로 돌아가는 흐름을 지원한다. 로비 단일 NPC 보고가 Diablo의 현행 기능이라는 근거로 사용하지 않는다. |
| [Roblox Data stores](https://create.roblox.com/docs/cloud-services/data-stores), 열람 시점 공식 문서 | 같은 Experience의 Place/서버가 저장소에 접근할 수 있고 UpdateAsync는 여러 서버의 갱신 시도에 대응한다. 네트워크 호출은 실패할 수 있다. | 로비와 현장이 같은 계정 권리를 사용하고 중복/응답 유실을 처리해야 한다. UpdateAsync 하나가 다중 키 거래를 보장한다고 해석하지 않는다. |

현재 프로젝트의 조회 전용 LobbyQuestJournal, 기본 인사만 하는 Tessa,12개 사이드의 고정XP/Gold0을 대조했다. [기존 발견·퍼즐 조사](2026-11-07-quest-discovery-and-puzzles.md)의 현장 발견 재미를 보존한다.

대안은①저널 안내만 강화(저비용·NPC 보고 요구 충족 어려움),②기존 Tessa의 지역별 의뢰 접수/대리 보고(추천·중간 비용),③새 전담 NPC와 전용 건물(추가 미술/동선 비용)이다.②를 설계안에 채택하며 새 보상 수치는 확정하지 않는다. 소문으로 현장을 안내하고 실제 목표 달성 후 로비 보고를 허용한다. 기존 본편 우선 Continue·발견형 수락·서버 보상 계약과 충돌하지 않도록 구현해야 한다.

최소 실험은 DW-Q1~Q4의 귀환 목록→현장 수행→로비 보고다. 남은 의뢰를 도움 없이 찾는지, 선택/입장 오류·중복 지급이 없는지, 다음 본편 선택에 간섭하는지를 관찰한다. 보상 만족은 실제 보상 확정 후 별도 플레이로 평가한다. 정량 성공률·시간 목표는 아직 측정/확정하지 않았다.

다음 담당: 기획/경제가 보상과 소급 방침 확정 → 디자인/ENG가 [설계안](../production/lobby-side-quest-npc-2026-11-07.md)의 상태/복구 구현 → QA가 게시 클라이언트·기기 수용. Diablo 현행 시즌·다른 Roblox RPG의 동일 NPC 기능은 이번 조사에서 미검증이다.

## 보상 필수 지시 후속

사용자는 완료 보상이 없는 퀘스트를 허용하지 않는다고 확인했다. 기존 TLT 전수 대조에서 사이드12개와GW본편7개가0임을 확인했다. 본편 이후 선택 활동을 할 이유를 제공하는 원칙은 채택하고, 확정 완료XP/Gold·실용 재료를 추가했다. 기존 비영점 본편예산은 유지하며 값은 TLT 기존 보상 규모를 참고한 초기 튜닝이다. 영웅별 완료/지급 영수증으로 기존 완료자 누락분도1회 복구한다. [실제19개 지급표/검증](../evidence/quest-completion-rewards-20261107/README.md). 보상체감/시간당 유입·실기기 수용은 후속 QA이며 자동 만족을 주장하지 않는다.

## 로비 NPC 적극 추천·기호 안내 후속

사용자가 느낌표/물음표로 사이드를 적극 알려야 한다고 지시했다. 2026-11-07 [Diablo II 원작 Act I 공식 퀘스트](https://classic.battle.net/diablo2exp/quests/act1.shtml)를 재확인했다. NPC에게 듣는 의뢰와 현장 발견형 시작이 구별된다. Tessa가 소문을 알려 주되 현장 발견 조건을 대신하지 않는 데 적용한다. 해당 페이지는 로비 느낌표/물음표의 직접 근거가 아니며 기호 체계는 사용자 요구와 TLT 설계다. Quest Basics 원문은 도구 접근에 실패해 새 사실 근거로 쓰지 않았다. 현행 D2R 패치/시즌을 주장하지 않는다.

[Roblox 접근성 공식 지침](https://create.roblox.com/docs/production/publishing/accessibility)을 같은 날 확인했다. 색과 기호를 함께 쓰고 소리만으로 상태를 전달하지 않으며 모션 감소 선호를 고려하도록 안내한다. TLT의 `!`/`?`/`…`와 영어 보조 문구·정적 배지·로비 지도에 적용한다. 구체적인 추천 순위/알림 빈도/30초 인지 목표는 TLT 제안이며 공식 표준 수치가 아니다.

저널만 강화하는 대안은 NPC를 발견해야 한다는 요구를 충분히 충족하지 못한다. 기존 Tessa에 개인 표식·귀환 안내·추천1개/전체 목록을 연결하는 안을 채택한다. 신규 NPC/건물은 추가 비용이 있어 보류한다. 비용은 기존 진행 조회의 상태 투영·NPC/지도 표시·UI/입력·영웅 전환/재접속 알림 억제·기기 QA다. 추천/표식은 읽기/안내 단계로 먼저 제작하고 실제 지급/대리 보고는 별도 계약 뒤 연결한다. 최소 실험은 DW4사이드와 로비 귀환, PC/터치의 자발적 인지/추천 열기다. 실제 효과는 미검증이다. [최신 표식/추천 계약](../production/lobby-side-quest-npc-2026-11-07.md)을 따른다.
