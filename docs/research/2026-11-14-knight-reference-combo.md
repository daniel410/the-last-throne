# 기사 기본3타 지정 영상 관찰

2026-11-14 · TLT-005/084 · ENG/RES → QA

사용자가 최종 지정한 참조는 [영상2:25~2:27](https://www.youtube.com/watch?v=xUhOca48eLQ&t=145s)뿐이다. 이 범위를 벗어난 동작이나 다른 게임의3단 베기를 제작 근거로 쓰지 않는다.

브라우저 플레이어를 정지하고 재생시각145.00부터147.00미만까지 프레임 단위로 확인했다. 약146.08에는 검을 옆으로 회수하고,146.16~146.33에는 위에서 아래로 베며,146.41~146.50에는 검을 올린다.146.58~146.99에는 검이 수평으로 정면에 길게 뻗는다. 이에 따라 TLT 적용 동작은 **Downcut → Rising Cut → Forward Thrust**로 정한다. 화면 관찰을 게임 내부 판정·정확한 입력·대미지 측정으로 취급하지 않는다. 특히 마지막 타는 별도 올려베기로 해석하지 않는다.

관찰에서 가져오는 것은 검의 방향 전환·다음 동작을 위한 회수·정면으로 뻗는 마무리다.2D 횡스크롤의 스프라이트·이펙트·적의 공중 동작은 복제하지 않는다. TLT의 기존0.588/0.644/0.868초, 서버 승인·판정·피해·사거리·최대대상·입력 버퍼를 유지한다. 새 점프/넉백/전진 이동을 추가하지 않는다.

기존 소유 검/방패와 Mixamo 파생 내려베기 곡선을 재사용하고, 올려베기는 접촉 자세를 보존하며 역방향으로 재저작한다. 찌르기는 실제 R6/R15 손·검 소켓의 전방운동학으로 준비/접촉/신전 자세를 구한다. R6의 짧은 강체 팔에 별도 자세를 적용하고, 첫 두 타는 기본 방어 자세로 매번 돌아가기보다 다음 타격의 준비로 이어진다.

수용 기준은 지정된 순서·검끝의 전방 접촉/찌르기 방향·방패 관통 없음·지면 여유·1→2/2→3/3→1 자세/속도 연결·입력 중단 뒤 자연스러운 복귀다. 실제 게시 클라이언트·기기·타격감 사용자 수용은 엔진 수치 검증과 구분한다.
