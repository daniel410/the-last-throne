# 대표 퀘스트 현장의 지형과 지물 제작표

2026-11-19 · TLT-061 / TLT-065(GW) / TLT-062 / TLT-063 / TLT-064 · G5 · 환경 아트 → 환경 3D·맵 구현·QA

## 기준 리뷰

0.114.0의 [다섯 대표 퀘스트](2026-11-19-epic-quest-variety.md)는 구조, 후위 방어, 신호 판단, 회로 시험, 성문 확보로 지역별 행동을 구분한다. [Studio 검증](../evidence/epic-quest-variety-20261119/README.md)은 각 이벤트와 기존 진행 데이터의 호환성을 확인했다. 이번 제작은 [본편 서사](../production/campaign-context-review-2026-11-10.md)와 런타임의 행동 위치, 배우, 물리 소품, 단계별 결과를 대조해 첫 행동 직전에 만나는 시설 다섯 곳으로 범위를 잡았다.

[이전 랜드마크 Studio 비교](../evidence/epic-story-landmarks-20261118/comparison.jpg)에서 DW-02의 목조 보호소는 수직 기둥과 상판으로 숲과 구분된다. 보호소와 비슷한 크기의 건물을 더 두기보다 약품이 놓이는 작은 시설로 기능을 보강한다. [0.113.12 접근 비교](../evidence/epic-approach-readability-20261118/comparison.jpg)에서는 GW의 낮은 뿌리가 밤에 암석과 겹치고 FV의 파란 도관은 밝은 눈과 구분된다. GW 후위에서는 드러난 목질과 기존 등불의 대비를 쓰고 FV에서는 관측 지점을 이웃 도관과 다른 단면으로 만든다. EC-04 수로와 HG-03 배수구는 낮은 몸체와 반복된 부재가 기능을 설명한다. EC 작업대와 HG 윈치도 기존 상부 소품의 기능을 하부 구조에서 읽을 수 있게 한다.

현장 시설은 전달, 구조, 신호 복원, 설비 가동, 동맹 합류 전부터 존재할 수 있는 형태로 만든다. 변화를 알리는 기존 단계별 소품과 조명은 퀘스트 장면에서 읽힌다. 이전 배치와 기능 소품을 공간·색의 기준으로 삼고 엔진의 기본 입체 형상으로 하부 구조를 조합한다. 단일 시설마다 하나의 주 실루엣을 정해 낮은 시점에서 반복적인 배경 소품과 구분한다. 재질과 판정 기준은 [제품 계약](../product-contracts.md)의 승인 미술 자산 규칙을 따른다.

## 수용 관찰

기준과 후보에서 해당 사건의 첫 접근, 측면 조작, 이탈 또는 귀환 카메라를 같은 위치로 비교한다. 야간 GW/HG는 기존 지역 조명 안에서 관찰한다. 지면과 모델 접촉, 시각 부품의 충돌 플래그, 배우·프롬프트·신호 요소의 차폐, Original/Easy 보행을 확인한다. GW는 본선 양방향, FV는 정답 전후 신호를 각각 관찰한다. 다음 담당인 QA는 실제 입력에서 첫 행동을 찾는 데 걸린 시간과 잘못 접근한 횟수를 기록하고, 게시 클라이언트·실기기·사용자 미술 수용은 각 결과의 검증 조건을 함께 남긴다.
