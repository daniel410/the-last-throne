## 채택한 변형과 비용

번개는 각 링크의 실제 꺾인 경로에서 가지가 출발하도록 하고 선/면이 같은 점들을 공유한다. 긴 체인은 분기 수를 줄이고 기존 확정 목표만 사용한다. 큰 흰 면 대신 청색 면과 밝은 중심을 사용하며 장식은0.16초 안에 소멸한다. 반복 스트로브는 추가하지 않는다.

냉기 광역은 낮은 타일 대신 높이가 다른8개 결정을0.18초에 걸쳐 지면에서 자라게 한다. 중앙은 비워 두고 얼음창에는 얇은 측면 결정을 겹친다. 우박/화살비는 본체와 잔광이 같은 가속 하강 곡선/짧은 장식 지연을 사용한다. 모두 기존 서버 확정 펄스가 시작한 표시이며 새 피해/피격 이벤트를 만들지 않는다. 구체적인 높이·시간은 우리 게임의 미술 선택이고 타 게임에서 측정한 수치가 아니다.

이전안 유지/새 원본 자산 도입/절차적 면 보강을 비교해 마지막을 채택했다. 신규 권한·로드 의존성이 없고 기존 원소 계약과 충돌하지 않는다. 비용은 번개 Beam/면 증가와 결정/낙하 CFrame 갱신이다. 기존 전역 면160/터치80, Beam240/터치144, 파편48, 입자192/터치96, 동시12/터치8 제한을 유지한다. 성능 향상은 주장하지 않는다.

최소 실험은 같은 모형/카메라/조명의9기술 전후, 확정 체인 끝점·분기 접속,0.16초 소멸, 결정 밑동 고정/성장, 낙하 본체·잔광 일치/시간 재샘플, 기존128기술 회귀다. [실행 증거](../evidence/roblox-element-motion-20261113/README.md).

다음 ART/QA는 실제 TD 영웅/무기·밝고 어두운 지역에서 색 없이도 번개/얼음/화살비의 형상과 방향을 구별하는지, 동시 교전의 목표/위험 바닥을 가리는지 확인한다. 같은 기기 GPU/프레임 시간·실기기·최종 미술 수용은 별도다. 후속 후보는 자연 덩굴의 성장 방향과 물리/마법 화살의 명중 구별이며 이번 완료로 취급하지 않는다.
