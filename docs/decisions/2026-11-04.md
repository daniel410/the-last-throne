## 2026-11-04 — 모든 본편 스토리 자동 전개·네비 유지

사용자는 특정 Deepwood 구간이 아니라 모든 스토리 완료 뒤 로비 복귀 안내/다음 목표·네비 소실을 문제로 명시했다. 본편35스토리는 모든 난이도·초회/재도전에서 저장 진도에 따라 다음 스토리를 연다. 에픽 경계도 다음 지역을 필요할 때 생성하고 안전 시작 지점으로 이동하며 로비 복귀를 필수 경로로 삼지 않는다. 완료 카드의 계속/닫기 버튼과 무관하게 저장된 메인 진도 증가 시 다음 메인을 자동 추적한다. 이 지시는 아래0.69.5의 Easy·초회·동일 에픽 한정보다 우선한다. 개별 선택 퀘스트의 별도 임무 계약과 최종35번째 본편 종료는 유지한다. 재도전으로 입장했더라도 미완료 본편에 도달하면 해당 스토리의 실제 초회 보상을 지급하고 기존 보유 권리를 재지급하지 않는다. 지원권은 여전히 스토리별 명시적 재초대이며 자동 갱신하지 않는다. [변경/검증/게시 상태](../evidence/all-story-handoff-20261104/README.md) · TLT-057/061/062/063/064/065/084.


## 2026-11-04 — Easy 본편 초회 원정의 동일 에픽 자동 진행 복구

사용자의 Deepwood 스토리2→3 자동 진행 실패 보고에 따라, Easy 초회 본편은 같은 에픽의 다음 스토리 목표를 열고 완료 카드에서 추적하도록 수정한다. 입장/재접속용 원래 임무ID·원정ID는 유지한다. 기존 완료 저장도 다음 접속 시 동일하게 투영한다. 재도전·상위 난이도·선택 임무는 기존 개별 임무 방식을 유지하고 에픽 경계는 로비 입장을 안내한다. 스토리 지원권은 다음 스토리에 자동 갱신하지 않으며 캠프에서 명시적으로 재초대한다. 보상 정본·안정ID·TD·게시 상태는 변경하지 않는다.
