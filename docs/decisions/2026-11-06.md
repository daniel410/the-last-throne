## 2026-11-06 시작 장비 세트·물약 최초 지급 유지 확인

TLT-029/041/043/052/084. 사용자는 기존 처음 주는 장비 세트와 물약은 지급하고 반복 지급만 중단하라는 뜻임을 확인했다. 계정 첫 영웅 생성 시 기존 시작 장비 키트·HP물약7개(Small3/Medium2/Large1/XL1), Mage는 MP물약7개도 지급하는 현재 구현을 유지한다. 재접속·후속 영웅 생성·소진 후에는 시작 보급을 반복하지 않는다. 후속 영웅의 기본 무기/기사 방패와 기존 보유품은 유지한다. `src/server/Inventory/InventoryRules.luau`의 최초 지급/수령표시 경로를 확인했고 `lua tests/starter-potions-and-shop.spec.lua`의308검사가 통과했다. 이번 작업은 의도 명확화 기록이며 런타임·VERSION·게시 변경은 없다. 실제 게시 계정/실기기 지급 수용은 미검증이며 다음 QA가 확인한다. 부모 티켓 상태는 유지한다.

## 2026-11-06 최종 확인: 시작 보급은 영웅마다 최초1회

TLT-029/041/043/052/084. 사용자는 수정 빌드의 Knight에게 시작 장비와 물약이 없다고 보고한 뒤 **영웅마다 최초1회 지급**을 명시했다. 현재 Studio 계정의 Mage/두 번째 Knight와 Knight 가방0을 확인했으며 기존 계정 단위 제한이 원인이다. 이전 계정 첫 영웅1회 해석을 대체한다. 신규 영웅마다 기존 장비 키트·HP물약7개·Mage MP물약7개·기존 재료를 지급하고 영웅별 수령표시를 같은 계정 키에 저장한다. 재접속·영웅 선택·소진 후 재지급은 금지한다. 기존 저장의 수령 이력이 불명확하면 소진한 아이템의 재지급을 막기 위해 자동 보충하지 않는다. 현재 Studio 저장은 세션 전용이므로 새 빌드의 새 Play에서 새로 생성한 모든 영웅에 적용한다. [0.78.2 검증·한계·QA 인계](../evidence/starter-per-hero-20261106/README.md). 부모 티켓 상태는 유지한다.
