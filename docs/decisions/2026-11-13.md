# 2026-11-13 결정

## 다섯 에픽 도보 연결

사용자는 에픽의 마지막 스토리 완료 후 갑자기 포탈로 순간이동하는 흐름을 제거하고 다음 에픽으로 걸어갈 수 있도록 요청했다. Deepwood 옆으로 Gloamwood를 옮겨 Frozen Vale로 연결하며, 추가 지시로 Deepwood → Gloamwood → Frozen Vale → Ember Caldera → Haunted Graveyard 전체에 적용한다. 선행 완료 후 길을 열고 왕복 도보 이동을 제공한다. 기존 지역 내부 구성·스토리ID·보상·저장된 진행 조건을 보존한다. 2026-11-04의 에픽 전환 시 안전 시작 지점 자동 이동 안내를 대체한다. [구현·검증 상태](../evidence/epic-overland-20261113/README.md) · TLT-061/062/063/064/065/overland.

## Hard 개방·보상 리뷰

사용자는 Hard를 언락하고 Insane/Hell은 유지하도록 지시했다. Hard의 같은 임무 Easy 완료 조건만 제거하고 이야기 선행·비전투 제한·상위 모드 레벨 무제한을 유지한다. Insane은 Hard 완료, Hell은 Insane 완료가 필요하다. 보상 수치 변경은 요청하지 않았으므로 현행을 보존하고 [리뷰·검증·미검증](../evidence/hard-unlock-20261113/README.md)에 남긴다. TLT-027/028/050/084 · ENG/PLAN → QA.

## 난이도별 Diamonds·Gold·XP 확정

TLT-027/028/041/050/084. 사용자는 Easy/Hard/Insane/Hell 보상을 Diamonds 3/5/7/10, Gold 1/1.5/2/3배, 추가 지시로 XP도1/1.5/2/3배로 확정했다. 대화 중 Hell19는 후속10으로 정정됐다. Diamonds는 기존 영웅·본편ID·난이도별 초회 권리를 유지하고 이미 지급된 기록/잔액은 보존한다. 미수령 권리만 새 금액으로 지급하며 차액 소급은 하지 않는다. Gold는 처치/반복 완주의 모드 배율을 변경하고 XP는 이미 같은 배율이므로 유지한다. 임무 초회 고정 XP/Gold·재료·장비·난이도 입장 조건은 유지한다. ## XP 누적과 고레벨 요구량 · 정상 수행 시 예상 레벨

TLT-027/029/050/084. 후속 사용자 지시로 에픽 완료 레벨은 정상 수행의 XP가 쌓여 도달하는 예상치이며 무조건 보장/강제 설정하지 않는다. XP0이나 반복 지급량 감액으로 성장을 막지 않고 레벨 요구XP 증가로 느려져야 한다. 이에 앞선16의 완주 예산 역산·Hell 반복 감액/6회차 XP0을 대체한다. 처치/퀘스트 고정 지급과 독립된 요구량 곡선을 적용하고, 새 원정17·기존16의 남은 지급도 정상화한다. 상한99·예상 경로·기존 레벨/레벨 내XP·진도/영수증과 Gold/Diamonds/재료/장비는 유지한다.
