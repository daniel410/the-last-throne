# 기본 스탯과 전투 능력치

문서 묶음 v0.24 · 2026-10-27, America/Toronto · 상태: 구현 전 설계

상위 기준은 [기획 결정](decisions.md), [개발 기획안](game-design.md), [클래스·전직·스킬트리](class-advancement-and-skill-trees.md)다.

## 1. 확정 범위와 설계 초안

**힘·민첩·지력·체력의4종 기본 스탯을 도입한다.** 공격력·방어력·공격속도 같은 전투 능력치도 함께 사용한다. 레벨·전직·스킬트리·장비에 기본 스탯 성장을 더하는 구조다. 기본 스탯을 제외하고 자동 성장만 제공하는 제안은 채택하지 않는다.

4종 스탯 도입과 **Lv2~80에 레벨업마다4포인트, 총316포인트의 자유 배분**은 사용자 결정이다. 아래의 효과 배분·클래스별 기본 성장·추천 기능·재분배 정책은 구현과 밸런스를 검증할 설계 초안이다. 기본 스탯 초기값·효과 계수·스탯별 투자 상한은 아직 확정하지 않는다.

## 2. 기본 스탯과 파생 능력치

| 기본 스탯 | 주된 효과 초안 | 보조 효과·설계 제약 |
| --- | --- | --- |
| 힘 STR | 근접 물리 공격력, 힘을 사용하는 무기 피해 | 일부 기술의 자세 피해. 원거리·마법 피해 전체를 동시에 올리는 만능 스탯으로 만들지 않음 |
| 민첩 DEX | 활·총포 등 정밀 무기의 공격력 | 치명타 확률·공격속도에 제한적으로 기여. 회피 무적 시간·완벽 방어 판정창은 늘리지 않음 |
| 지력 INT | 마법 공격력, 마법 기반 보호·회복의 위력 | MP를 사용하는 경우 최대 MP에 기여. 성광·마법 화살·원소 주문을 같은 마법 분류로 연결 |
| 체력 VIT | 최대 HP | 방어력에 보조 기여. 피해 완전 면역·무한 생존을 만드는 성장 금지 |

**체력(VIT)은 성장 능력치이고 HP는 현재 생명력이다.** UI에서 기본 스탯은 ‘체력(VIT)’, 자원은 ‘생명력(HP)’으로 구분한다. MP와 스태미나는 별도 자원이며 VIT와 혼용하지 않는다.

전투 능력치는 기본 스탯·장비·스킬트리·일시 효과를 조합해 계산한다. 캐릭터 화면에서 물리/마법 공격력·방어력·최대 HP·사용 자원의 최대치·공격속도·치명타를 확인할 수 있게 한다. 방어의 피해 감소 곡선, 치명타/공격속도의 상한과 점감은 별도 수치 작업으로 정한다.

전 클래스 공통 MP와 기존 서약·집중·열기·마력의 통합 방식은 별도 설계 항목이다. 이번4스탯 도입만으로 기사 기술에 MP 비용을 추가하거나 기존 자원 규칙을 바꾸지 않는다. 자원 통합 시에는 전직·기사 명세·HUD·기술 비용을 함께 개정한다.

## 3. 클래스·계열별 활용 방향

| 클래스·계열 | 주 활용 스탯 초안 | 빌드 선택의 예 |
| --- | --- | --- |
| 기사 / 강철기사 | 힘·체력 | 검격·반격 피해 강화 또는 HP·방어 강화 |
| 기사 / 성기사 | 힘·지력, 체력으로 생존 보완 | 검격 중심 또는 성광 피해·보호 중심 |
| 엘프 / 명궁 | 민첩, 체력으로 생존 보완 | 정밀 사격·치명타·속사 중심 |
| 엘프 / 마법궁수 | 민첩·지력 | 화살 운용 중심 또는 속성 효과 중심 |
| 드워프 / 강철 | 힘·체력 | 도끼·장갑 파쇄 또는 근접 생존 중심 |
| 드워프 / 화약 | 민첩·힘 | 총포 정밀 사격 또는 중화기·폭발 중심 |
| 마법사 / Pyro·Cryo | 지력, 체력으로 생존 보완 | 주문 위력·자원 여유 또는 생존 중심 |

추천 스탯은 투자 강제가 아니다. 힘을 올려도 마법사에게 기사 기술이나 클래스 변경 권리가 생기지 않는다. 전직·기술 해금은 기존 클래스·계열·레벨·시험 조건을 따른다. 성녀NPC는 플레이어 배분 포인트를 사용하지 않고 별도 지원 성장 규칙을 따른다.

혼합 계열은 주 스탯 두 개를 모두 올려야 기본 기능이 작동하는 구조를 피한다. 혼합 기술은 정규화한 가중 합산 또는 한 가지 유효 공격력을 사용하는 방식으로 설계하고, 두 스탯의 곱을 요구하지 않는다. 같은 피해에 물리·마법 공격력을 각각 온전히 더해 이중 보상하지 않는다. 보호·회복 기술도 실제로 참조하는 스탯을 툴팁에 표시한다. 가중치와 기본 기여는 단일 스탯 계열과 같은 투자 예산으로 비교한 뒤 확정한다.

## 4. 포인트와 초보자 지원

- Lv1은 기본 능력치로 시작하고 레벨업 배분 포인트는0이다. Lv2부터80까지 매 레벨4포인트를 지급한다. 레벨 L의 누적 획득량은 `4 × (L - 1)`이며 만렙80에서 총316포인트다. 초기 기본 능력치는 이 배분 예산에 포함하지 않는다.
- 힘·민첩·지력·체력에 원하는 정수만큼 자유롭게 배분한다. 한 번 받은4포인트를 한 스탯에 모두 투자할 수도 있으며, 각 스탯에1개씩 강제로 나누지 않는다. 사용하지 않은 포인트는 잔량으로 보관한다. 스탯별 누적 투자 상한은 별도 밸런스 항목이다.
- 스탯 포인트는 스킬포인트와 별도 예산이다. 스탯은316포인트, 기존 Lv2~80 총79P는 스킬트리 전용이다. 두 예산을 서로 전환하거나 한쪽 투자에 다른 쪽 포인트를 소비하지 않는다.
- 클래스별 기본 성장을 함께 제공하는 것은 설계 초안이다. 포인트를 아직 배분하지 않아도 초반 기본 전투를 수행할 수 있는 성장선을 검증한다.
- 클래스·계열에 맞는 추천 배분과 적용 전 미리보기를 제공한다. ‘힘+1 → 물리 공격력 변화’처럼 실제 결과를 표시한다. 자동 추천 적용은 플레이어가 선택한다.
- 거점의 확정 스탯 배분 전체 초기화는 스탯 리셋권1개를 소비한다. 스킬 초기화는 별도 스킬 리셋권이며 두 권을 수익화한다. 새로 얻은 포인트의 첫 배분·적용 전 미리보기/취소는 무료다. 포인트 자체를 판매하지 않고 투자분만 기존 예산으로 반환한다.
- 전투·원정 중에는 배분/재분배를 제한한다. 저장할 때는 기본 스탯 투자량과 포인트 잔량을 보존하고 파생 능력치는 현재 규칙으로 다시 계산한다.

## 5. 구현과 검증

서버가 레벨·획득 포인트·투자량·잔량·재분배 자격을 확정한다. 현재 예산에서 `투자량 합계 + 잔량 = 4 × (레벨 - 1)`을 유지하고, 여러 레벨을 한 번에 올려도 오른 레벨 수×4만 지급한다. 재접속·동일 보상 재처리로 이미 지급한 포인트를 다시 지급하지 않는다. 음수·소수·허용 범위 밖 투자·중복 요청·포인트 복제를 거부한다. 기존 저장에 스탯 필드가 없을 때의 초기화/이관은 원래 클래스·전직·장비·스킬 기록을 보존해야 한다.

기사 전투 실험은 기존 고정 ATK/HP 프리셋을 기준선으로 유지한 뒤 스탯 계산을 연결한다. 민첩이 공격속도에 영향을 줄 때에도 회피·방어 판정창·비용·명세상 취소 규칙을 임의로 함께 단축하지 않는다. 공격속도를 반영한 모션과 서버 타격 시각은 일치시킨다.

Lv1/2/20/40/60/80의 누적 배분 포인트0/4/76/156/236/316과 한 번에 여러 레벨 상승·미배분 잔량·재접속 중복 지급 방지를 확인한다. 통합 단계에서는 같은 레벨·장비·총 스탯 투자 예산으로 공격형/생존형과 혼합형을 비교한다. 처치 시간·받은 피해·자원 부족·공격속도/치명타 상한·재접속 후 보존·중복 배분을 확인하고, 새 이용자가 추천과 미리보기를 통해 스탯 효과를 설명할 수 있는지 관찰한다. 현재는 문서 설계이며 게임 코드 구현이나 플레이 검증은 수행하지 않았다.

[28스토리 성장 예산 시뮬레이션](story-progression-budget.md)에 레벨별 필요XP의 반영된 기준식·스토리별 XP/Coins 유입·이월XP·예상 완료 레벨을 기록했다. 사용자 승인으로 Lv5~40 기획 성장 예산에 반영했다. 스탯4P/별도 스킬1P 지급 규칙은 유지하고 게임 런타임/플레이테스트 수용은 아직이다.
