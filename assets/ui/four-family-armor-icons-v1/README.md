# 4계열 방어구·방패 아이콘

2026-11-09 · TLT-028/029/032/041/052/073/082/084

Traveler·Tempered·Veteran·Sentinel의 현재 컨셉8개 보드(후드, 기사 헬멧, 드워프 헬멧, 방패, 공용 코트/갑옷, Mage Robe, 장갑, 부츠)를 직접 확인하고 각 계열의 개별 투명 PNG32개를 내장 `image_gen`으로 제작했다. 이전 Rare/Epic 보드를 새 계열로 섞지 않았다. [출처/정의/업로드ID](manifest.json) · [모든 프롬프트/원본 생성 경로](generation.json) · [Roblox 최종 응답](uploaded.json) · [픽셀 검사](alpha-report.json).

컨셉의 베이지/청회색/올리브/네이비 팔레트, 재료·문양·봉제·헬멧 능선/후드 형태를 따랐다. 이름표·비교 보드·바탕·프레임·외부 광원 효과는 제외했다. 장갑/부츠는 한 쌍을 하나의 아이콘으로 쓴다. 공용 상의에는 코트/갑옷 컨셉을, 마법사 전용 MP 상의에는 Mage Robe를 사용한다. 새 모델·아이템 정의나 수치/가격을 만들지 않는다.

- `icons/`: 네이티브 생성 RGBA PNG32개, 실제 크기1254×1254. 픽셀 편집/색 변환/알파 임계처리를 하지 않고 도구 출력 그대로 보존했다.
- 투명도0~255, 완전 투명 면적48% 이상. 주 윤곽(알파128 이상)에 충분한 여백이 있다. 원본 생성 알파의 가장자리 미세 잔여는 최대1/255로 기록하며 제거하지 않는다. “모든 가장자리 픽셀이 정확히0”으로 보고하지 않는다.
- `gallery.html`: PNG를 그대로 보여 주는 자산 비교표이며 실제 게임 UI 화면 증거가 아니다.
- `four-family-armor-icons-v1.zip`: 개별 PNG32개와 출처/알파/사용 설명.

런타임은24개 장비 정의의 기본 아이콘과8개 기사/드워프 머리 변형을 등록했다. 기존 공유 head 정의를 유지하며 기사/드워프는 각 헬멧, Elf/Mage는 후드를 선택한다. 영웅 정보가 없으면 기본 후드로 표시한다. 같은 아이템이 같은 영웅 문맥에서 대장간·강화·기어·가방·상세/보관함/미수령·PC/모바일에 같은 이미지로 표시된다. 장비 소유 영웅이 있는 가방/착용/미수령은 그 영웅을, 공용 보관함은 현재 선택 영웅을 사용한다. 물약/무기/재료/장신구 및 다른 Rare/Epic의 기존 atlas 경로는 유지한다.

검증 명령: `uv run --with pillow python tools/validate-four-family-armor-icons.py`. 이 도구는 픽셀을 읽어 검사할 뿐 PNG를 수정하지 않는다. 장비 정의/소유/강화/가격/착용 자격과 실제3D 외형은 이 아이콘 작업으로 변경하지 않는다. [엔진·빌드 증거](../../../docs/evidence/four-family-armor-icons-20261109/README.md).
