[검색·자산 정본](manifest.json)에 무료 Audio12개의 ID·제작자·가격0·Store URL·설명·Studio 디코딩 결과를 보존한다. ProSoundEffects11개와 Iogician의 활 발사1개를 사용한다. 외부 게임명이 명시된 재업로드 검색 결과는 선택하지 않았다. 원본 음원 파일은 복제/재배포하지 않고 Roblox 경험에서 Store ID로 참조한다.

`CombatAudioCatalog`의16개 분류는 검·도끼·방패·화살·비전·중력·바람·신성·자연·물·불·서리·번개·대지·총·폭탄이다. 모든128개 스킬의 기존 `PixelFXCatalog`/`SkillPresentation` 분류를 재사용하며 마법사 기본기는 지팡이 휘두르기/둔탁한 접촉음으로 처리한다. 같은 원본을 음량/속도로 변형하는 분류도 있으며16종의 독립 녹음이라는 뜻은 아니다. 폭탄은 낮은 타격음으로 구분하며 전용 폭발 원본 선정은 후속으로 개선할 수 있다.

기본 공격/기술의 발동음과 실제 명중음을 나눈다. 무기 휘두르기·화살 발사·마법/원소음은 허공 공격에도 발동하고, 명중음은 서버 피해 확정 이벤트만 사용한다. 상위 전직·궁극기도 기존 해금/편성 계약을 따른다. MP·피해·쿨다운·보상·애니메이션·포션/배경음악은 변경하지 않는다.

재생은 클라이언트별 공간음원(8~80stud), 발동8+명중8 최대16개다. 같은 음원·8stud 셀의70ms 내 접촉은 합치며 미세한 피치 변형을 준다. 짧은 재생 제한과 Ended 정리로 음원/투명 파트가 누적되지 않는다. 원음의 긴 잔향은 의도적으로 제한하며 음량/길이의 청취 수용은 후속이다. [검증 및 한계](../../../docs/evidence/combat-store-audio-20261105/README.md).
