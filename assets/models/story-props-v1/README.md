# 스토리 소품 v1

TLT-031/057/061/062/063/084 · 2026-11-02. 신규 제작13종. [모델 미리보기](gallery.png).

보급 상자/풀린 운송 밧줄/장부 책상/대장 배지/파손 수레/구조 감옥/문 윈치/냉각 밸브/길 랜턴/각인 이정표/포탈 제단/추적 흔적/석조 아치. 실제 승인 스토리의 보급·구조·귀환·포탈 폐쇄·용광로 복구에 대응한다. TD의 숲 메시와 캐릭터는 그대로 두고, 공유 원본에 없는 서사 물건을 별도 제작했다.

`python3 tools/author-story-props.py`로 `geometry.json`과 런타임 기하 테이블을 동일하게 생성한다. `tools/author-story-props-blender.py`는 `STORY_GEOMETRY` 사전과 절대 출력 폴더 `STORY_OUTPUT`을 받은 Blender 스크립트다. 새 씬에서 모델을 만들고 각각 GLB와 전체 검토 이미지를 내보낸다. 사용자 원본 씬을 삭제하지 않는다. GLB는 형상/소켓 검토·향후 메시 병합용 원본이며 현재 게임에는 같은 형상의 native 모델을 연결한다. 별도 Roblox 업로드가 필요 없다. GLB에만 추가 디테일을 넣은 미리보기가 아니다.

모델별6~124개 부품, 모두 정적·장식/비충돌/비쿼리. ModelStreamingMode.Atomic. 재료와 작은 조각의 그림자를 제한한다. 기존 이동용 충돌체는 투명 프록시로 보존한다. 장부/배지/기계에는 의미 있는 조립 구조를 추가했지만 사진 실사/PBR 텍스처가 있는 최종 환경 완성본은 아니다.

지형 전체·모든 건물 교체와 후반2에픽 배치는 후속이다. 실제 모바일 성능과 미술 수용은 엔진 정합성 검사와 별개다. 해시/제작 분류는 `manifest.json`, 적용 증거는 `docs/evidence/story-props-20261102/README.md`.
