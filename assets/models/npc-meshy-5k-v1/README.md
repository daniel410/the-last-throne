# NPC Meshy 5k 게임 자산

작업ID `NPC-APPLY-20261117`. 사용자 승인 모델29명과 수정된 Aldric·Brann 해머를 게임 생성 경로에 연결했다. Selene는 기존 모델을 사용한다.

`<id>.glb`와 `<id>_base_color.png`는 Meshy 원본, `candidates/<id>-5k.glb`는 승인된 정적 외형, `skinned/<id>.glb`는 같은 표면·UV에 하체 이동용5본을 추가한 Roblox 업로드 원본이다. 상체와 손 소품은 하나의 강체로 유지한다. 모든 모델은4,401~4,995삼각형이다.

`runtime.rbxm`은 업로드 승인된 모델을 고정한29개 템플릿 폴더다. 게임 정면은-Z, 루트는 발바닥, 성인 높이6.2 / 드워프5.456 / 아이4.588 stud다. 충돌·접촉·쿼리는 끄고 기존 서버 NPC 루트와 역할·별칭 계약을 유지한다. 기본·배틀 프로젝트가 같은 파일을 참조한다.
