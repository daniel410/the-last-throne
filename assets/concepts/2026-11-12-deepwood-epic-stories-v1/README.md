# Deepwood 에픽·스토리 2D 콘셉트

2026-11-12 · `TLT-061/concepts-epic-stories-20261112` · DES → 사용자 미술 검토

사용자 요청에 따라 기존 에픽 콘셉트와 현재 3D 모델 장면을 함께 참고한 **에픽 대표 1장·본편 7장·선택 4장, 총 12장**이다. 전체 5에픽 52장 중 Deepwood 우선 작업이며, 나머지 에픽은 이 산출물에 포함하지 않는다. [갤러리](index.html), [전체 프롬프트](prompts.json), [참조·산출물 해시 및 검토](manifest.json).

## 원천과 해석

- 기존 [Deepwood 에픽 콘셉트](../2026-10-27-shared-ui-v2/world/epic-01-deepwood.png)의 녹색/금색 숲, 이끼 낀 유적, 파랑/금색 장식, 깊은 뿌리숲으로 향하는 여정을 재사용한다. DW-01은 기존 스토리 콘셉트도 참조한다. 과거 이미지의 한국어 제목·게임 표식은 새 그림에 넣지 않는다.
- 현재 모델은 [환경 제작 화면](../../../docs/evidence/epic-environment-20261111/README.md)의 DW-03과 [최신 소품 구성 화면](../../../docs/evidence/story-map-composition-20261112/README.md)의 DW-02를 참조한다. 실제 Studio 캡처의 거대 나무·수관·뿌리·저지형·넓은 길·보급 운반대 형태를 연결한다. 새 3D 모델 제작이나 새 Studio 촬영은 수행하지 않았다.
- 장별 사건은 [최신 전체 맥락 정본](../../../docs/production/campaign-context-review-2026-11-10.md)의 DW-01~07/DW-Q1~Q4를 따른다. 영어 제목과 안정 ID는 `DeepwoodContent.luau`를 따른다. Eryn/Fen은 기존 NPC 보드, Selene는 현재 모델의 흰색/금색 로브와 등불을 참고한다.
- 내장 `image_gen`으로 각 장면을 개별 생성했다. 한 그림을 분할하거나 같은 구도를 제목만 바꿔 재사용하지 않는다. 초반의 3D 화면만 참고한 초안과 가까운 시점의 초안은 최종 12장에 포함하지 않는다. 원본은 생성 도구 기본 경로에 보존한다.

## 수용 범위

각 이미지는 각 스토리 지역 전체를 약65도 위에서 내려다보는 높은 조감도다. 입구·출구·목표 장소·우회/귀환로를 한 장에서 읽도록 하며, 인물은 작은 축척 단서로 쓴다. 환경 중심의 2D 미술 해석이다. 원본 콘셉트의 밀도·층위와 현재 3D 모델의 형태를 함께 사용하므로, 모든 구조물·높이·카메라 위치가 현재 게임에 그대로 구현됐다는 증거가 아니다. 인물은 장면을 설명하는 보조 요소이며 최종 캐릭터 모델 정본을 대체하지 않는다.

보급대의 식량/약품과 적의 심장 화물을 구별하고, Deepwood에서 심장 회수·Veyr 공개·최종 침공 계획을 앞당기지 않는다. DW-07은 지역 제단 대치, DW-Q4는 제단 폐쇄 후 별도 잔당 사건이다. 장면 안의 서류는 읽을 수 없는 그림 표현이며 신규 게임 문구를 확정하지 않는다.

검증 결과: 12장 모두 직접 시각 검토했으며 PNG 시그니처·청크 CRC·압축 해제·주사선 길이/필터, 12개 ID/장수, 전 이미지1672×941, 중복 없는 SHA-256, 참조 파일·갤러리 링크 검사를 통과했다. 높은 시점에서 지역별 입구/출구와 장소 구성이 보이는지 확인했다. 일부 인물·깃발·장식은 생성 해석이며 최종 자산 정본을 대체하지 않는다. 파일별 검토와 한계는 `manifest.json`에 기록했다.

최종 사용자 미술 수용, 그림의 세부 요소 전부에 대한 현재 모델 일치, Studio/게시 클라이언트·실기기·성능·동선 검증은 미검증이다. 부모 TLT-061/G5/G7을 완료 처리하지 않는다. 게임 코드·VERSION·빌드·게시·릴리스 태그는 변경하지 않는다.

다음 담당은 사용자/DES다. 12장 중 수정할 구도·분위기·스토리 표현을 검토한 후 나머지 에픽의 같은 형식 제작으로 이어간다.
