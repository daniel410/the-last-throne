## 3D 제작 목표

사용자의 ‘2~3k tries’는 **모델당2,000~3,000 triangles(tris) 목표**로 해석했다. LOD0의 얼굴/이빨·몸통·팔다리·날개·잎 등 보이는 전체 메시를 합산하는 기준이다. 복제 부품도 실제 등장 개수만큼 포함한다. 얼굴은 눈 배치/색·송곳니·표정·해골 문양을 우선 보존하고, 몸통은 큰 상자·다리는 단순 각기둥/쐐기 끝·나뭇가지/지네 마디는 적은 모듈로 구성한다. 잔 나뭇결/갑각 무늬/털은 우선 텍스처 표현으로 제안한다.

모델별 배분은 [modeling-targets.json](modeling-targets.json)에 제안했다. 일반2200~2400, 여왕2600, 엔트/지네 보스2750tris를 내부 배분 목표로 두며 **실측값은 전부 null, 모델 파일도 null**이다. 단순 종을 억지로 분할해 하한을 맞추지 않는다. 큰 보스도 장식 수보다 몸통 비례/큰 다리/큰 턱으로 위계를 표현한다.

이미지로 삼각형 수를 세거나 2~3k 달성을 선언하지 않는다. 최종 삼각분할 내보내기에서 모든 부품을 합산하고, 그 파일/해시와 Roblox 가져오기 결과·관절/이동·공격 자세/모바일 가독성을 검증해야 한다. 현재3/4면 컨셉은 블록아웃 방향이며 정확한 후면·관절 도면·UV·리그를 대신하지 않는다.

## 생성·보정·보존

**built-in image_gen**을 사용했다. 최초 지역/보드/여왕3회 뒤, 이번 연속 작업에서7종 보드1회·일반 블록형1회·보스 첫 시안1회·보스 단순화 보정1회를 수행해 총7회다. Python은 파일 복사/메타데이터·갤러리 작성/정적 검사에만 썼고 이미지 편집에는 사용하지 않았다. CLI/API 우회나 별도 키를 쓰지 않았다.

처음 보드를 view_image로 열람한 뒤7종 보드의 편집 입력으로 썼다. 생성된7종 보드와 직접 열람한 여왕 단독 장면을 일반/보스 새 보드의 참조로 전달했다. 보스 첫 결과는 몸통/장식이 복잡해 그 결과를 다시 입력으로 주고 얼굴/배치/이름은 이어가면서 몸체/팔다리만 큰 블록으로 줄였다. 호출별 최종 프롬프트·입력/출력 경로·해시와 미선정 시안 사유는 catalog/prompts에 기록했다.

기본 생성 위치의 원본은 남기고 선정본을 프로젝트에 복사했다. v1/v2 보드와 프롬프트/검증은 이력으로 남기되 현재 갤러리/목록에서 제외했다. TD 원본/전경/기존 여왕 분위기 이미지는 변경하지 않았다. 현재 모델링 형태는 새 일반/보스 보드가 우선한다.

## 직접 시각 검토·한계

새 일반6셀과 보스3셀을 도구 출력으로 직접 확인했다. 일반은 기존 거미3종·박쥐·엔트·지네이고, 보스는 여왕·엔트·지네로 구분된다. 제거한2종은 현재 보드에 없다. 일반의 큰 각진 배/다리, 보정 후 여왕의 계단형 상자 배·각진 다리, 엔트의 상자형 어깨/팔·큰 발, 지네의 반복 상자 마디가 더 명확해졌다. 눈 색/배치와 얼굴 인상은 계승했지만 픽셀 단위 동일성을 검증하지 않았다.

얼굴/나뭇결의 음영과 세부가 실제 메시 분할을 뜻하지 않는다. 그림의 다리 수/마디 수·복잡한 얼굴의 정확한 구조·후면/접지·리그/모션·실제 tris/기기 성능은 미검증이다. 보스 후면·정면 비례/부품 분리는 후속 모델링에서 원형과 맞춰야 한다. 생성 글자는 OCR로 런타임에 추출하지 않는다.

새 전투 시스템이나 외부 게임/자산을 추가로 조사/차용한 작업이 아니라 기존 [숲 후보 조사](../../../docs/research/2026-10-30-dark-forest-candidate.md)를 이어가는 시각 수정이다. 2~3k 기준은 비교 게임의 수치가 아니라 최신 사용자 목표다.

## 검증·다음 담당

[validation.json](validation.json)에 PNG 서명/청크CRC·크기/바이트/원본 복사/해시·프롬프트 원문·현재9종/등급·제외2종·편집 원본/기존 이미지 불변·목표 배분 합산/실측 null·로컬 링크를 기록한다. PNG는 Git LFS로 선별 커밋/푸시하며 현재 작업 외 릴리스 증거는 포함하지 않는다.

기존 통합 줄거리·에픽1~4·보상·기존 후반 JSON/VERSION·런타임을 수정하지 않는다. 후보 목록/갤러리 안내만 동기화하며 게임 빌드/게시/릴리스 태그·부모 티켓 완료를 수행하지 않는다. 다음 담당은 사용자/DIR의 얼굴/블록형 방향 검토, ART의 실제 메시·측정/UV/리그, DES/ENG/QA의 공간·전투/모바일 수용이다.

실제 정적 검사: `python3 /tmp/tlt-validate-gloamwood-v3.py` 종료0. 현재4장/이전2장의 PNG CRC·크기/해시/원본 복사,9종/6일반·3보스 분류, 제외2종, 목표 배분/실측 null,프롬프트와 패키지 링크38개를 확인했다. 이번 새 PNG는 중간7종 보드와 최종 일반/보스 보드의3개,총6,372,719바이트다. 편집 범위 밖 기존950개 추적 파일은 바이트 불변이다. `git diff --check` 종료0. 이는 실제 메시/삼각형 수 측정이나 엔진/기기 수용이 아니다.
