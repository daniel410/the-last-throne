## 생성 방식·원본

**built-in image_gen**으로 신규 지역/몬스터 보드 생성2회, 첨부 원본을 숲 배경으로 변환한 여왕 장면1회를 수행했다. 기본 생성 위치의 원본3개를 보존하고 선정본을 이 폴더에 복사했다. CLI/API 우회·별도 API 키는 사용하지 않았다. 각 호출에 전달한 최종 프롬프트는 위3개 텍스트와 JSON에 저장했다.

첨부 TD 원본 `/Users/daniel/Workspace/project/roblox/throne-defense/assets/boss-spider-queen-concept.png`를 view_image로 직접 열람했다. 지역/보드는 텍스트로 정리한 방향으로 새로 생성했고, 여왕 단독 장면은 해당 파일을 직접 참조 입력으로 전달했다. 참조 역할·원본/생성 경로·현재 SHA256은 catalog에 있다. TD 원본을 편집/이동하지 않았다. 공유 레지스트리를 확인했지만 이번 개념 그림이 실제 RPG용 메시·애니메이션·사용 권한을 증명하지는 않는다.

새 시스템 제안은 추가하지 않았다. [직전 조사](../../../docs/research/2026-10-30-dark-forest-candidate.md)의 작은 지역 갈등·행동 중심 모험·조명 가독성 방향을 시각화한다. 새 외부 게임/작가의 자산이나 줄거리를 참고 입력으로 추가하지 않았다.

## 직접 시각 검토

도구의3개 출력 픽셀을 직접 확인했다. 전경의 매달린 마차·피난처/위협의 색 대비·길·옛 요새가 보이고, 보드는6개의 별도 셀/영문 가칭과 나방·위장/중장갑/가느다란 거미의 실루엣이 구별된다. 단독 여왕은 원본의 둥근 갑각·해골 문양·보라 독니를 유지하는 방향으로 표현됐고 원본의 포탈/수정/세 단계 작은 패널은 제거됐다. 추가 재생성/수정 호출은 하지 않았다.

전경은 일부 수관이 열려 달이 보이는 변형이며, 고치에 얼굴 일부가 드러난 표현도 있다. 실제 구조 대상/알집 구별과 수관 밀도는 블록아웃에서 조정한다. 보드 여왕은 단독 장면보다 갑각이 더 각진 변형이다. 원형 비교의 우선 참조는 사용자 첨부와 단독 장면으로 두고 최종 형태는 후속 미술 검토에서 맞춘다. 다리의 정확한 수·관절/뒷면·접지·공격 높이·종별 실제 크기는 이 그림만으로 검증하지 않았다.

이름은 en-US 가칭이며 생성 글자를 OCR로 런타임 문자열에 추출하지 않는다. 유적/거미줄/고치/호위 수와 조명은 컨셉 표현이다. 어두운 배경에서도 실제 전투 가독성이 충분한지, 터치/저품질에서 숲/줄이 시야를 가리는지, 여왕/군집의 성능·솔로/협동 난이도는 미검증이다.

## 검증·인계

PNG3개의 서명/청크CRC·크기·바이트·해시/원본 복사 일치, 프롬프트3개와 JSON 원문 일치, 참고 원본 해시,6종 보드 매핑/로컬 링크를 검사한다. 결과는 [validation.json](validation.json)에 기록한다. PNG는 `.gitattributes`에 따라 LFS로 저장하고 선별 커밋·푸시/원격 확인을 수행한다.

게임 소스/보상·통합 줄거리·에픽1~4·기존 후반 JSON/이미지/VERSION은 변경하지 않는다. 갤러리 안내를 관련 문서에 연결하며 게임 빌드/게시·릴리스 태그·부모 티켓 완료는 수행하지 않는다. 다음 담당은 사용자/DIR 시각 검토, DES 공간/가독성 블록아웃, ART 원본 적합성·정확한 모델/리그, ENG/QA 실제 전투/성능/기기 수용이다.

실제 정적 검사: `python3 /tmp/tlt-validate-gloamwood.py` 종료0. PNG3개/8,173,222바이트의 서명·모든 청크CRC·크기/해시·원본 복사 일치와 프롬프트 원문·참고 원본 해시·6종 매핑·패키지 링크27개를 확인했다. 기존 문서/서사·성장 데이터/통합 줄거리/VERSION522파일은 이번 갤러리 안내3문서를 제외하고 바이트 불변이다. `git diff --check` 종료0. 스테이징된3PNG 모두 LFS 포인터의 SHA256/size가 실제 파일과 일치한다. 갤러리 열기는 `open_in_codex`가 queued로 응답했으며 실제 브라우저 렌더/사용성 수용으로 기록하지 않는다.
