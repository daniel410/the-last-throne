## 출처·검증

built-in `image_gen`으로 승인 v2 UI 및 종전 가방/창고 컨셉을 시각 참조하여 새 파일을 생성했다. 원래 승인 9장과 원본 파일은 수정하지 않았다. 각 파일은 실제 게임 스크린샷·승인 대체본이 아니며 아이콘/텍스트/수치를 런타임 정본으로 사용하지 않는다. 시안에 나타난 가방 그리드 수량, 품목, 실제 계수와 UI 입력은 디자인 검토용이다.

이미지를 각각 열어 4클래스, 기사 검·방패, 장비 8칸, Stamina 부재, 전투 물약 2·스킬 5, 영어 라벨의 시각적 표현을 검토했다. 스킬 노드는 예시이며 Lv20/40 슬롯 개방, 실제 12개 파생 자격, 유료 리셋권·MP/아이템 비용, 다인·터치·실제 사용자 수용은 이미지로 검증하지 않았다. 생성 수치·기능과 기존 0.18.7 시험판의 차이는 기획/현재 상태 문서를 따른다.

다음 담당: DES가 사용자 검토와 PC/모바일 레이아웃을 확정하고 ART가 TD 원본 권리/모델을 검사한다. ENG가 서버 가방/창고/퀵슬롯 및 8칸을 구현하고 QA가 저장 실패·중복 수령·기기·소유권을 검증한다. 기존 구현 티켓을 완료 처리하지 않는다.
