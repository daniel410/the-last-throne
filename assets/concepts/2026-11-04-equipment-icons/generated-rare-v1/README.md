# Rare 장비40종 추가 및 Epic40종 분류

2026-11-04 · TLT-028/029/052/084 · ART → DES/ENG/QA

사용자 지시로 기존40개 이미지를 Epic으로 지정하고 같은40품목의 장식이 적은 Rare 이미지를 개별 생성했다. [등급 비교 보드](../comparison.html) · [Rare 보드](index.html) · [Epic 보드](../generated-v1/index.html). 두 등급 합계80개며 240개 전체 등급 외형 완성이나 게임 구현을 뜻하지 않는다. 공통11·기사8·엘프7·드워프7·마법사7이라는 구성은 등급마다 동일하다.

Rare는 각 Epic 원본을 개별 참조해 금장·큰 보석·덧판·문양·광채를 줄였다. 기사 검 직선 축, 마법사 천 후드, 활/도끼/지팡이 유형을 유지했다. 원본은 수정하지 않고 신규 PNG로 저장했다. 각 실제 생성 프롬프트/참조 해시/출력 해시는 generation.json에 있다. 새 이미지와 전체 비교에서 형태/등급 차이를 육안 확인했다. 일부 기사 문양과 엘프 깃털은 남아 있어 최종 단순화 수준에 대한 사용자 미술 수용은 후속이다.

## 식별 이름

사용자 요청을 적용해 `Rarity_ClassOptional_ItemName.png`로 파일명을 통일한다. 예: `Epic_Knight_Oathguard_Sword.png`, `Rare_Knight_Oathguard_Sword.png`, `Rare_Mana_Ring.png`. 클래스 토큰은 Knight/Elf/Dwarf/Mage이며 공통품은 생략한다. 표시용 name/assetName에도 같은 영어 식별 이름을 기록하고 baseName은 사람이 읽기 좋은 기존 영문 품목명을 보존한다. 기존 런타임 안정ID와 familyId/proposalId는 변경하지 않는다. 이전 PNG 경로→새 경로는 ../asset-name-mapping.json에서 조회한다. 과거 커밋의 파일/표시는 당시 상태이며 현재 메타데이터가 우선한다.

등급 지정은 사용자 결정이다. 이전 보드의 Rare 후보 분류는 Epic40종 지정으로 대체한다. 착용Lv10은 과거 시험 제안이었으며 이번에 등급별 최소 레벨이나 능력치·세트 효과·드롭률을 새로 확정하지 않는다. 비교 보드에서 착용Lv를 확정값처럼 표시하지 않는다. 기존 스토리·보유 아이템/상품·게임 소스는 그대로이며 향후 실제 정의를 별도로 구현한다.

## 검증과 다음 작업

Rare40/Epic40 레코드·PNG·고유 파일명80개, SHA256, 40개 쌍의 경로/클래스·등급 연결을 검사했다. AppKit으로40개 새 PNG 디코딩/알파채널과 전체 비교 이미지를 생성하고 육안 확인했다. 실제 치수는 generation.json 참조. 새 Rare Mage Signet 왼쪽 위 등 모서리의 미세 알파 잔여는 alpha-check.json에 기록하며 원본을 임의 보정하지 않았다. 엄격한 알파 정리·48px 실제 UI·TD 프레임 합성·이미지 로딩·최종 미술·모바일/패드 수용은 후속이다. PNG는 LFS로 보존한다.
