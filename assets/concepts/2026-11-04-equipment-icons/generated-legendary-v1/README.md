# Epic 기반 Legendary 장비40종

2026-11-04 · TLT-028/029/052/084 · ART → DES/ENG/QA

사용자 요청으로 기존 Epic40종을 각각 참조해 더 강한 인상의 Legendary40종을 만들었다. [Legendary 보드](index.html) · [Rare/Epic/Legendary 비교120종](../comparison.html) · [전체 모아보기](contact-sheet.png). 공통11·기사8·엘프7·드워프7·마법사7이며, 마나 증가 공통 장신구3종도 포함한다. 이전 Epic/Rare 원본은 보존한다. 여섯 등급240개 제안 중 실제 PNG는 세 등급120개이며 게임에 등록된 아이템 수와 구분한다.

금장·겹친 방어판·클래스별 문장·보석과 더 뚜렷한 실루엣을 추가했다. 기사 검의 직선 축, 엘프 활, 드워프 도끼, 마법사 지팡이/천 후드를 유지한다. PNG에는 문구/등급 테두리를 굽지 않고 보드/메타데이터에서 식별한다. 예: `Legendary_Knight_Oathguard_Sword`, `Legendary_Elf_Briarwatch_Bow`, `Legendary_Mana_Ring`. 파일명도 같은 이름+.png이며 기존 familyId/proposalId/런타임 안정ID는 바꾸지 않는다.

## 강도·레벨·강화의 연결

기존 장비 설계의 동일 착용레벨·동일 부위 기준 기본 예산 Epic1.28 → Legendary1.40을 연결한다. **에픽 대비 약9.375% 높은 기본 능력치 예산 제안**이다. 모든 공격력/방어력/HP/MP를 일괄9.375% 올린 확정 수치나 처치시간 실측이 아니다. 품목별 실제 능력치 배분·정수 반올림·세트/피해경감 결합은 후속이다. `generation.json`의 balanceProposal과 manifest의 budgetRatio는 설계 메타데이터이며 서버 카탈로그가 아니다.

착용 레벨과 등급은 별개다. 이전 Lv10 시각 시험 레코드는 유지하되 등급 최소 레벨로 확정하지 않는다. 이번의40은 **아이템 개수**다. 새로운 착용Lv40 조건을 추가하지 않는다. 같은5부위 세트 후보의 상위 외형이며 새 세트 보너스/Unique 고정 효과를 발명하지 않는다. 방패·장신구·공통품은 세트 외 품목이다.

현재 +9 강화 계약을 유지한다. 양수 Power/Armor/Health에 기본치×(1+0.03n), 최대MP/세트 보너스/고유 효과는 강화하지 않는다. 성공률100/90/80/70/60/50/40/30/20%, 목표n의 보석2n·마석max(0,n−3), Gold0, 실패 시 재료 소모·단계 보존이다. 같은 강화단계라면 예산비1.40/1.28이 유지되지만 실제 능력치 반올림/전투 결과는 별도 검증한다. MP 전용품은 현재 강화 대상이 아니며 혼합품은 HP만 강화하는 기존 제안을 따른다. 보스 드롭·높은 난이도의 상위 등급 비중 방향은 기존 [드롭 설계](../../../../docs/production/boss-drop-reward-design-2026-11-04.md)를 연결하며 이번에 드롭률/보상을 변경하지 않는다.

## 제작·검증 기록

- image_gen 개별 생성40종. Epic 참조 경로/해시·실제 프롬프트·출력 원본·SHA256·치수는 generation.json에 기록했다. 검 최초 요청1건은 도구 입력 필터에서 거절되어 중립적인 게임 장비 아이콘 설명으로 다시 생성했다. 드워프 목걸이 배경 안개는 image_gen 편집으로 제거했고 편집 참조도 기록했다.
- `python3 scripts/validate_equipment_icon_assets.py` PASS: 120개 고유 이름/PNG·SHA256·40계열×3등급·클래스별 개수·240개 고유 제안ID·Epic 참조 해시·보드 상대 링크/120카드. 이 명령은 저장소 루트에서 실행한다.
- macOS AppKit으로 새40개 PNG 디코딩·1254×1254 RGBA 확인, contact-sheet.png 생성 후 육안 확인. alpha-check.json의 네 모서리 중 Mage Treads 왼쪽 위와 Arcane Reservoir Pendant 왼쪽 아래에1/255 알파가 남았고 다른 모서리는0이다. 투명 채널 존재와 엄격한 전체 배경 청결은 다른 검사이며 후자를 통과했다고 주장하지 않는다.
- PNG는 LFS로 저장한다. 게임 소스/보상 정본/VERSION은 변경하지 않았으며 Roblox 업로드/Place 게시/릴리스 태그를 만들지 않는다.

미검증: 최종 사용자 미술 수용, 엄격한 알파 정리, 48px 실제 TD 프레임 합성/모바일 가독성, Roblox 자산 연결, 실제 능력치·장착/세트/MP·강화·보스 드롭·저장·다인 밸런스. 부모 구현 티켓을 완료 처리하지 않는다. 다음 담당은 DES/사용자 미술 검토 → ART 잔여 보정 → ENG 카탈로그/아이콘/드롭 연동 → QA 실제 기기·서버 검증이다.
