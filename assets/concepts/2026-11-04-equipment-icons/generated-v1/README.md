# 장비 아이콘 생성 v1

2026-11-04 · TLT-028/029/052/084 · ART → DES/ENG/QA

요청된40개 장비 계열의 개별 PNG 후보를 image_gen.imagegen으로 생성했다. 공통 방어구4·공통 장신구7(최대MP3종 포함)·네 영웅 전용28·기사 방패1이다. **각 계열 기본 외형40개이며 240개 등급별 외형 완성이 아니다.** 최종 사용자 미술 수용과 Roblox 등록/게임 연결은 후속이다.

[전체 비교 보드](index.html)는 클래스 필터·48px 보기·밝은 배경 전환 및 개별 원본 열기를 제공한다. [전체 비교 이미지](contact-sheet.png), [품목별 생성 프롬프트·원본 경로·해시](generation.json), [알파 검사](alpha-check.json)를 포함한다. 원본은 모두1254×1254 PNG, 알파 채널 포함이다. 40개 이미지 각각을 생성했고 마법사 머리는 기사형 투구가 나와 천 후드로1회 보정했다. 보정 전 결과는 superseded에 보존했다.

참조는 승인 TD 영웅 기사 로컬 원본이다. 해당 이미지와 TD 미술 참고 이미지를 육안 확인하고 재질·입체감·조명을 맞췄으며 참조파일 SHA256을 generation.json에 기록했다. 참조 스냅샷을 사용했으며 TD 현재 운영 원본의 최신성과 신규 각 품목의 최종 일치 수용을 완료했다는 뜻은 아니다. 기존 프레임/배지·아이콘을 덮어쓰지 않는다. 개별 PNG에는 등급 프레임·텍스트·강화 수치를 넣지 않았으며 최종 게임에서는 TD 공통 UI 레이어로 표시해야 한다.

검증: AppKit으로40개 PNG 디코딩·크기/알파 확인, 보드/manifest 품목40개 연결 및 SHA256 확인.40개 전체 비교 이미지를 육안 확인해 슬롯·기본 무기 유형과 클래스별 재질/팔레트를 검토했다. 공통 Vigor/Valor 반지는 형태가 비슷해 추가 구분 검토 대상이다. 엘프 머리와 드워프 목걸이의 왼쪽 위 모서리에 alpha1/255인 픽셀이 있어 엄격한 완전0 배경 조건은 보류이며 나머지 모서리는0이다. 원본을 임의 삭제/보정하지 않았다.48px 실제 UI의 가독성·TD 프레임 합성·모바일/패드·실제 게임 이미지 로딩은 미검증이다. 생성 이미지에서 장비 능력치/가격/영어 원문을 추출하지 않는다.

게임 소스·보상/세트/효과·VERSION·Place는 변경하지 않았다. 다음은 DES/사용자 미술 검토(유사 장신구·낮은 알파 잔여 포함) → ART 등급/Unique 차별화 → ENG TD UI 연결 → QA 실기기 수용이다. PNG는 프로젝트 Git LFS로 보존하고 해당 작업 파일만 커밋/푸시한다.
