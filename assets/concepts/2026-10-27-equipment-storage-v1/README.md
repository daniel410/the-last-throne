## 적용 한계와 공유 원칙

이미지에는 일부 한글 오탈자/자간과 예시 장비명/수치가 남아 있다. 창고 중앙의 스킬 리셋권 문구와 가방 귀속 설명은 HTML/기획 문서가 정본이다. 기사/장비 외형의 방향과 셸을 보는 자료이며 생성된ATK/방어/희귀도·스택 수를 카탈로그에 적용하지 않는다. 새 이미지의 아이콘을 잘라 게임용 TD 원본 대신 사용하지 않는다. 슬롯은 정확히9개이고 망토 성능 슬롯을 추가하지 않는다.

동작 보드는 기존 승인 기사 이미지와 TD status-atlas 원본을 직접 참조한다. 상태/장비 카드의 읽을 수 있는 텍스트는 기획 규칙을 설명하는 검토 UI다. 실제 Roblox UITheme/컴포넌트 연결·3D장착/저장/판매/결제는 없다. 로컬 JS는 새로고침 때 초기화되는 샘플만 다루고 실제 소유/구매/지갑을 바꾸지 않는다.

## 확인 가능한 동작

9슬롯 장착/해제·Lv/클래스/고유그룹 검사,전투 상태 차단,가방 가득 찬 교체/해제,잠금·수량 선택·스택 병합/보관 이동,공간 부족 시 대기품 보존을 확인할 수 있다. 리셋권 사용/판매/결제·다중 서버 원자성·실제 모델 변화는 데모에 구현하지 않았다. 새 데이터가 확정되면 용량/스택/불가 이유와 시각 콘셉트를 함께 개정한다.
