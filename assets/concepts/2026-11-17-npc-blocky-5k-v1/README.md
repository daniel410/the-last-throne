# NPC별 블록형 생성 입력

작업ID `NPC-5K-20261117`. 기존 NPC 지역별 콘셉트를 내장 image_gen으로 개별 전신 PNG29장으로 제작했다. Selene는 제외한다.

`<id>.prompt.txt`는 실제 최초 생성 프롬프트다. Freya·Orik은 `*-prop-fix.prompt.txt`에 따라 직선 손잡이로 수정한 `<id>.png`가 최종 입력이며 `*-before-prop-fix.png`는 수정 전 비교 증거다. 첫6명의 PNG 디테일 가이드는 생성 당시10k였지만 실제3D는 전원 최종 지시5k를 적용했다.
