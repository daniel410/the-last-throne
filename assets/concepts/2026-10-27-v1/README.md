## 원본과 외형 기준

- 플레이어4종은 TD에서 승인·연결된 hero-icons의 Knight v2 / Elf v1 / Dwarf v1 / Mage v2를 최우선 외형 기준으로 사용했다. 원본 초상과 신규 전신은 분리 보존한다.
- 기사 은청·엘프 녹색/갈색 머리·드워프 주황 수염/청동·마법사 보라 비전 복장을 유지한다. 전신 후면·하체는 원본 초상에 없던 부분을 확장한 컨셉이며 실제 3D 모델/리그의 완전 일치 검증은 아니다.
- 성녀는 TD 팩션 그림의 첫 번째 등불 성녀를 기준으로 한 지원NPC 후보다. 셀레네 개인 얼굴의 최종 확정이나 다섯 번째 플레이어 클래스 도입을 뜻하지 않는다.
- 몬스터10개는 TD 현행 blocky-v1/forest 개별 PNG를 바이트 변경 없이 복사했다. 예전 forest-preview.jpg는 좀비가 포함돼 있어 재사용 목록에서 제외하고 현행 Cave Slime을 사용했다.
- 환경은 TD Deepwood 목표 컨셉의 거목·초지·석조·폭포·보라 포탈을 사용했다. 새 전경은 RPG 공간 제안이며 실제 맵의 좌표·자산·기하를 그대로 렌더한 화면이 아니다. 에픽1/스토리1은 이번 이미지 제목이며 기존 프롤로그·전체 장 구성을 바꾼 결정이 아니다.

## 화면 검토와 수치

스탯 화면은 Lv20 강철기사와 남은 스탯4포인트를 보여준다. 표시된49/13/9/21·HP/공격력/방어력은 화면 예시이고 초기 스탯5씩 또는 계수의 확정을 뜻하지 않는다. 확정한 규칙은 레벨업4포인트·Lv80 총316포인트다.

스킬 화면 최종안은 v2다. Lv28에서 누적27P, 표시한 공통7P+강철8P=15P 투자, 잔여12P로 맞췄다. 공통6/강철7노드 명칭을 문서와 맞추고 Lv40/60/80은 접힌 잠금 단계로 표시했다. 화면의 연결선·아이콘·다음 랭크 설명은 제작 초안이며 선행 조건/효과의 구현 기준은 전직 명세다. 스킬3+궁극기1, 클래스 내부 두 계열을 유지한다.

전투 HUD 최종안은 v2다. Lv10 기사 공통3기술과 Lv15 궁극기 잠금, HP/스태미나/서약을 보여준다. 공통 MP 통합을 확정하지 않는다. 고블린에게 잘못 추가됐던 보조 무기를 제거했다. 미니맵·퀘스트·터치 영역은 실제 기기 검증 전 배치 초안이다.

영웅 선택은 신규 캐릭터 생성 화면이며4개 클래스만 제공한다. 다른 클래스로 전직 불가·Lv20 계열 선택을 명시한다. 전신 확대/새 카메라 각도는 원본과 대조하며 추가 피드백으로 조정한다.

## 생성 기록과 검증

- 최종 프롬프트는 각 신규 PNG 옆 `.prompt.txt`에 저장했다. [전체 생성 기록](generation-manifest.json)에 참조 파일·생성 결과 경로·선택 여부를 기록했다. 14번 생성 중12개를 최종안으로 선택했고, 스킬/HUD 구 버전은 수정 이력으로 보존한다.
- [원본 출처/해시](source-manifest.json)는 재사용 몬스터10종과 참고 이미지8개를 기록한다. 모두 원본과 SHA256 일치를 검사했다.
- [갤러리 목록](catalog.json)은 최종22개 이미지와 해시를 기록한다. 생성된 이미지는 화면으로 확인했다. 실제 Studio·모바일 조작성·전투 판정·텍스트 최종 품질 검증과는 구분한다. 앱 브라우저의 file URL 정책으로 갤러리 브라우저 렌더 확인은 수행하지 못했으며, HTML 참조 파일·이미지 헤더·해시·목록 정합성은 정적으로 검사했다.
- 이번 작업은 이미지와 검토 갤러리 제작이다. 실제 Roblox 에셋 업로드·UI 구현·게임 게시를 수행하지 않았다.

## Dawnspire 로비 추가

2026-10-27 로비 컨셉 요청에 따라 내장 image_gen으로 추가했다. 왕성·청금 배너·석조 광장·보라 원정 포탈을 TD 로비와 공유하고, 최신4클래스 외형/성녀NPC 시트를 참조했다. 원정 포탈·훈련장·대장간·동료 구역·TD 복귀 아치는 배치 초안이며 실제 로비 구현이나 이동 정책 확정을 뜻하지 않는다. 기존 ZIP은 최초21개 이미지 스냅샷이며 이 추가 이미지는 갤러리와 개별PNG 링크로 제공한다. 프롬프트는 PNG 옆에 보존했다.
