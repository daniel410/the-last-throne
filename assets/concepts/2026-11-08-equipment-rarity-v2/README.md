## 범위와 상태

사용자는 승인 후드 r3 방향으로 나머지 장비를 제작하고, 아이콘160종과 착용3D도 만들도록 요청했다. 이후 **컨셉 이미지부터 먼저** 만들도록 제작 순서를 바꿨다. 이 묶음은 그 선행 컨셉 단계다.

- 현재 비교 보드40장: 공통11·기사8·엘프7·드워프7·마법사7. 한 장마다 Rare/Epic/Legendary/Unique4개, 총160개 등급 외형 컨셉이다.
- 신규39장 + [승인된 Wayfarer Hood r3](../2026-11-08-rarity-shapes-v2/hood-comparison-r3.png) 복사1장이다. 수정 과정의20장은 `archive/`에 별도 보존했다. 60장을 최종 품목 수로 세지 않는다.
- 내장 `image_gen` 사용. 최종 생성 프롬프트는 `generation.json`의 품목별 `prompt`, 후드 원본 입력은 이전 폴더의 `prompt-r3.txt`다. 생성 도구의 원본 절대 경로는 provenance로만 기록하며 갤러리는 저장소 상대 경로로 동작한다.
- **개별 투명 아이콘160개·실제3D 메시·장착·Studio·빌드·게시는 아직 아니다.** 생성 보드는 Blender Standard 렌더도 아니다. 게임 VERSION/안정ID·수치·드롭·보유품은 변경하지 않았다.

## 반영한 사용자 리뷰

1. 에픽 후드의 너무 뾰족한 꼭대기를 제거한다. 이 규칙은 후드에만 적용하며 헬멧 장식/능선을 일괄 둥글게 만들지 않는다.
2. 유니크는 거친 돌 덩어리 대신 고급 금속·정교한 금 인레이·에나멜·보석 세팅으로 표현한다. 보스 차이는 문양/구조에 둔다.
3. 같은 장비군+같은 등급의 천/에나멜·금속·보석 색을 맞춘다. Wayfarer 유니크는 승인 후드의 남색/백금/금/호박색, Oathguard는 왕청색/에메랄드, Briarwatch는 숲색/에메랄드, Stonehearth는 버건디/청동/호박색, Aetherweave는 보라/자수정으로 고정한다. 정확한 목표 팔레트는 JSON에 있다. 생성 그림 픽셀을 최종 재질 RGB로 추출하지 않는다.
4. 기사와 드워프 머리장비는 후드가 아닌 금속 헬멧이다. 기존 Epic/Legendary/Unique 원본6장을 직접 열어 참고했다. 기사=사자 문장·중앙 능선·각진 볼가리개, 드워프=두꺼운 청동 띠·넓고 낮은 각진 판금/문양. 원본6장의 경로는 해당 레코드의 `references`에 남겼다.
5. 무기가 너무 짧다→긴 수정본은 조금 짧게→검 손잡이는 더 길게라는 피드백을 반영했다. 과도하게 긴 원본과 초기 짧은 버전은 보존했다. 검은 균형 길이+손잡이 연장본, 도끼/지팡이는 긴 수정본에서 자루 길이를 줄인 버전이다. 최종 비율 수용은 사용자 리뷰 후속이며 실제 stud 길이를 확정하지 않는다.

## 알려진 미반영·검증 한계

**활의 중간 길이 보정은 이미지 생성 도구가 safety system/violence 사유로 거부했다.** 우회/재시도하지 않고 기존 긴 활 컨셉을 그대로 보존했다. 갤러리와 메타데이터에 별도 표시했으며 중간 길이 수정 성공으로 보고하지 않는다. 요청ID: `b1561639-a344-49e9-a20a-7b15db8d98a8`.

생성 결과를 직접 육안으로 확인하여 각 품목의4등급/종류·쌍 장갑/부츠·팔레트 주조색·유니크 금속 표현·기사/드워프 헬멧을 검토했다. 생성 그림에서 미세한 조명/재질 색 편차나 후면/내부 구조가 없는지 정량 검증한 것은 아니다. 48px 사용자 식별률·색각 조건·실제 착용/애니메이션/실기기 성능은 미검증이다. 품목별 컨셉은 사용자 최종 수용 전이며 전체 UI/게임 기능 수용과 구분한다.
