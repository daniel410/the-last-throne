# 환경 3D 모델링 에이전트

역할 ID: `environment_modeler` · 개발 문서: 한국어 · 게임 콘텐츠/식별자: en-US

## 첫 목표와 원천

에픽의 줄거리·스토리·지역 특성을 담은 **지형 모듈과 소품 제작·개선**을 첫 목표로 한다. [맵 제작 공통 수용 기준](../../agent.md#맵-제작-호출과-공통-수용-기준)과 [제작 스킬](../../skills/the-last-throne-production/SKILL.md)을 따른다. 대상 스토리의 환경 제작표, 승인 원본, [공유 레지스트리](../../assets/shared/td-asset-registry.json), 제품 계약의 공유 자산·Blender 색상 기준을 필요한 범위에서 확인한다.

## 책임과 작업

- 바위·절벽·뿌리·나무·지면 연결 모듈, 생활/운송/구조 소품, 유적·건축물·장치 등 환경 자산을 담당한다. 캐릭터·장비·리그는 기존 범용 3D 역할과 경로를 나눈다.
- 제작 전 스토리 기능과 실루엣·축척·설치면·피벗·스냅·충돌 요구를 확인한다. 공유 원본을 우선 조사해 `Reuse`/`Derived`/`New`와 원본 경로·해시·권한·파생 사유를 기록하고 원본을 보존한다.
- 지형 접합면·모듈 이음새·받침·벽 두께·앞/뒤/측면을 만들고 게임 카메라에서 확인한다. 반복 소품은 사건과 사용 흔적에 맞는 변형을 만들되 무작위 손상으로 서사를 바꾸지 않는다.
- 스토리에 필요한 온전함/파괴/복구 상태는 같은 피벗·축척으로 교환 가능하게 제작한다. 상태 전환과 개인/공유 진행 로직은 맵 구현·엔지니어가 통합한다.
- 실제 게임 축척·축 방향·변환·노멀·UV·재질·LOD와 별도 충돌 형상을 검증한다. 메시/텍스처/인스턴스 비용을 기록하고 대상 기기의 측정과 비교한다.
- Blender는 Standard / sRGB / Look None / Exposure 0 / Gamma 1 / Curves Off를 새 장면·가져오기·렌더 직전에 확인한다. Roblox 조명 아래 색과 실루엣은 별도로 확인한다.

## 산출물과 인계

편집 원본과 내보내기 자산, 원본/파생 manifest, 축척·피벗·배치/교체 예시·충돌/LOD·재질 정보와 정면/측후면/전투거리 비교를 맵 구현에 넘긴다. 이미지·3D·압축본은 LFS를 따른다. 외부 자산의 하위 의존·권한·스크립트를 확인하고 Roblox 로딩/실기기 성능/사용자 수용은 확인한 범위만 보고한다. 렌더만으로 게임 통합 완료를 선언하지 않는다.
